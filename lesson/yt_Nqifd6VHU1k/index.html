    ↳ multi-angle character sheet 是角色設定圖，把正面、側面、背面等角度放在同一張圖上。這張圖不用自己去拍，用 AI 從你的照片生成就可以。

    ↳ 有了各個角度的資訊，AI 不用再猜你的長相，換鏡頭、換場景都比較能維持同一張臉。這張圖之後會一直拿來當參考。

    ↳ 接下來做飲料罐的產品圖。產品不像人臉有那麼多細節要對齊，所以比做角色設定圖容易很多。

📘 術語
MCP (model context protocol)（模型上下文協定）：一個讓 Claude 聊天機器人能存取 AI 影片生成器的軟體
custom connector（自訂連接器）：在 Claude 的 settings → connectors 新增，填入 Higgsfield 的 MCP URL，用來建立連線
multi-angle character sheet（多角度角色設定圖）：把角色多個角度的畫面放在同一張圖，讓 AI 完整理解長相，保持角色一致
reference image（參考圖）：生成影片時提供給 AI 參照的圖片，例如角色圖、產品圖、storyboard
avatar image（角色場景圖）：把角色放進廣告實際場景裡的圖片
TV spot ad（電視廣告）：方法一示範製作的能量飲料廣告影片類型
marketing studio（行銷工作室（Higgsfield 功能））：專為廣告風格影片打造，用高轉換率廣告訓練，會沿用這些廣告的模式
credits（點數）：生成內容時消耗的點數；重新生成影片會很快燒光
storyboard（分鏡圖）：先把整段影片規劃成多格圖片，成本低、可反覆修改，再當參考圖生成影片
generation（一次生成）：影片生成器產出一段影片；片子較長時需要多次生成
voice-over（旁白配音）：方法一設定為音訊開啟，但不要 voice-over
Claude skill / AI skill（Claude 技能）：給 Claude 的一組指令，每次執行就照裡面的步驟做；安裝後符合需求時會自動觸發
shot / shot list（鏡頭／鏡頭清單）：skill 產出的 prompt 把每次生成拆成數個 shot，讓生成器知道何時切換場景
wide cinematic tracking shot（廣角電影感跟拍鏡頭）：skill 為 shot 1 指定的鏡頭角度，從側面拍攝
CapCut（CapCut（剪輯軟體））：用來把多段生成片段放上時間軸接起來、編輯並匯出
