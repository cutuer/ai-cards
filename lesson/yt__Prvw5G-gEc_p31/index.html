🧑‍🏫 這段是 xAI（做 Grok 的 AI 公司）行銷團隊的 Josh Kim，現場示範怎麼用一組 GrokBot（能替你動手做事的 AI 機器人）從零開始跑一檔行銷活動。值得看，是因為他把「AI 陪你想」和「AI 替你做」的差別講得很清楚，也真的一步步操作給你看。

  • 356:04 前一段 Dan 的分享收尾：想做得更快、更好的事，都可以交給 GrokkBot，這些 bot 能做的事不少
    ↳ 這是上一位講者 Dan 的收尾：想做得更快、更好的工作，都可以試著交給 GrokBot。它能接手的事其實不少。
  • 356:34 切回 Dreamforce 旁的主舞台，由 Josh Kim 講解如何用 GrokkBot 做行銷
    ↳ 畫面切回 Dreamforce（Salesforce 每年辦的大型商業科技大會）旁邊的主舞台，換 Josh Kim 上台講怎麼用 GrokBot 做行銷。
  • 357:11 議程：GrokBot 是什麼、xAI 內部怎麼用它來行銷和推動產品成長，以及你的團隊怎麼開始用 GrokBot
    ↳ 他先交代要講三件事：GrokBot 是什麼、xAI 內部怎麼靠它做行銷和推動產品成長，以及你的團隊可以怎麼開始用。
  • 357:45 最早用 AI 的方式是固定用一、兩個 AI chatbot 當 thought partner（聊天、問問題、討論、改文案），它不是 doing partner
    ↳ 早期用 AI，多半是固定開一兩個 chatbot（打字跟你對話的 AI）當 thought partner，陪你聊天、問問題、改文案。但它不是 doing partner，不會真的替你動手做事。
  • 357:45 後來出現通用型和專用型 agent，可以跟你一起做任務，xAI 內部稱它們為 co-pilots
    ↳ 後來出現了 agent（能自己跑步驟、完成任務的 AI），有什麼都能做的通用型，也有專做某件事的專用型。xAI 內部叫它們 co-pilot（副駕駛），會陪你一起做事。
  • 358:18 co-pilots 通常還是要人盯著、推著走，碰到複雜任務時尤其如此，很難真的把工作交出去
    ↳ 問題是 co-pilot 還是要你在旁邊盯著、一步步推，任務越複雜越明顯。你人還是被綁住，很難真的放手把整件事交出去。
  • 358:18 有了 GrokBot，行銷團隊能真正把部分工作自動化；可以把它想成永遠在線、非同步的 AI 隊友，會照你的做法把工作做完
    ↳ GrokBot 讓行銷團隊能把部分工作真正自動化。可以把它想成一個隨時在線、非同步（不用你在旁邊等，它做完再回報）的 AI 同事，會照你的做法把事情做完。
  • 358:50 xAI 行銷團隊不只用 bot 自動化工作和任務，還用 bot 撐起整個職能，組成一整隊 bot 來做事
    ↳ xAI 行銷團隊不只拿 bot 處理零碎任務，而是組了一整隊 bot，連整個職能（例如研究、分析這種角色）都交給它們撐起來。
  • 359:22 跟其他 AI 工具的差別：不是跟單一 agent 在同一個聊天裡開多串對話，而是每份工作各建一個 bot
    ↳ 跟其他 AI 工具最大的差別：不是在同一個 AI 的聊天視窗裡開好幾串對話處理不同事，而是每種工作各建一個專屬 bot。
  • 359:22 一個 bot 就是一位隊友，交給它單一任務，或一組相關任務
    ↳ 所以一個 bot 就等於一位隊友。你可以交給它一件任務，或一組彼此相關的任務，就像在團隊裡分配職務。
  • 359:22 可以像在 Slack 或 Teams 上傳訊息一樣跟 bot 對話，也能在群組聊天裡跟 bot 協作
    ↳ 跟 bot 講話，就像在 Slack 或 Teams（公司常用的工作聊天軟體）傳訊息給同事一樣。也能開群組，讓人和 bot 在同一個聊天室一起做事。
  • 359:54 合作越久，bot 越會學到你的工作方式、偏好和記憶，越來越聰明；給越多回饋、投入越多，長期能幫你做的事就越多
    ↳ bot 會慢慢記住你的做事方式、偏好和過去的內容，合作越久越上手。跟帶新人一樣，你回饋越多、教得越用心，它之後能扛的事就越多。
  • 360:26 bot 能串接你現在用的所有 MCP 和 API，而且有自己的電腦和瀏覽器；只要給它工具的存取權，它就能像你一樣操作那些工具
    ↳ API 是軟體之間互相串接的接口，MCP 是讓 AI 接上外部工具的標準做法，你現在用的這些 bot 都能串。它還有自己的電腦和瀏覽器，給它權限，就能像你一樣操作工具。
  • 360:57 行銷例子：教 bot 你在廣告平台上怎麼優化出價策略、campaign brief 怎麼寫的細節，甚至你怎麼管理電腦
    ↳ 拿行銷舉例：可以教它在廣告平台上怎麼調出價策略（每次曝光或點擊願意花多少錢）、campaign brief（活動企劃說明）要寫到多細，甚至你的電腦怎麼整理。
  • 360:57 bot 最獨特的價值在於它能客製化，並彈性配合你的工作方式
    ↳ Josh 認為 bot 最特別的是可以客製：不是你去配合工具，而是它照你的工作習慣彈性調整。
  • 361:32 不必盯著、推著或一直提醒 bot 繼續做；GrokBot 很有企圖心也很主動，會想把工作完成
    ↳ 不用一直盯著它、催它或提醒它繼續做。GrokBot 很主動，會自己想辦法把交代的事做完。
  • 361:32 bot 架在雲端，24-7 運作，不用一直開著筆電，也不用另外架 Mac mini；固定要看的報表和指標可以交給它抓
    ↳ bot 跑在雲端（網路上的伺服器），24 小時不停，筆電關了也沒差，不必為了讓 AI 一直跑另外買一台 Mac mini 放著。每天要看的報表和數字，可以交給它去抓。
  • 362:07 介面像 iMessage 一樣熟悉直覺，不論哪個專業領域的行銷人，都能輕鬆把 agent 放進日常流程
    ↳ 介面跟 iMessage 這類手機聊天 App 很像，一看就會用。所以不管做哪一塊的行銷人，都能輕鬆把 agent 放進每天的工作流程。
  • 362:07 Demo 目標：從零開始、端到端推出一檔行銷活動，第一步是市場研究分析
    ↳ 接下來實際示範：從什麼都沒有開始，把一檔行銷活動從頭做到尾。第一步是市場研究，先搞清楚市場長什麼樣子。
  • 362:42 流程：市場研究 → 發想並驗證 positioning → 更新 landing page → 建立並監控廣告活動 → 分析 → 最後做自動化
    ↳ 流程是：市場研究 → 想出並驗證 positioning（產品在顧客心中的定位）→ 更新 landing page（廣告點進去看到的網頁）→ 開廣告並監控 → 分析 → 自動化。
  • 362:42 這套流程橫跨行銷組織裡許多團隊、職能和專業，例如市場研究員要和 product marketer 一起定 positioning，再把任務交給網站團隊
    ↳ 這條流程要跨很多角色：市場研究員要先跟 product marketer（負責產品對外怎麼說的行銷人）一起定出定位，再把工作交給網站團隊去改頁面。
  • 363:15 Josh 認為這種 context 管理、協調和編排才是行銷工作的核心與功夫所在
    ↳ Josh 覺得行銷真正的功夫不在單一步驟，而是把 context（背景脈絡）在團隊之間傳好、互相協調、把工作的先後順序排好。
  • 363:48 這些 bot 不是 Josh 一人建的，而是從整個 xAI 團隊 crowdsourcing 來的（他說這是一個之後會介紹的功能）
    ↳ 示範裡這些 bot 不是 Josh 一個人做的，而是向整個 xAI 團隊 crowdsourcing（找很多人各自貢獻）來的。他說這是一個之後會介紹的功能。
  • 363:48 行銷 bot 團隊共六個：market researcher、product marketer、website ops、performance marketer、marketing analyst、project manager
    ↳ 行銷 bot 團隊共六位：市場研究員、產品行銷、網站維運、成效行銷（專管廣告投放成效）、行銷分析師、專案經理，就像一個小型行銷部。
  • 363:48 Demo 用的是為這次示範做的全新航空產品 XAir，拿來建立一檔全新的行銷活動
    ↳ 示範用的產品叫 XAir，是專為這次示範做的全新航空產品，用它從零建立一檔全新的行銷活動。
  • 364:23 XAir landing page 可以搜尋航線、查票價，上面也已經有 positioning 和價值主張
    ↳ XAir 的 landing page 可以搜尋航線、查票價，頁面上也已經寫好 positioning 和 value proposition（價值主張，也就是客人為什麼該選你）。
  • 364:53 GrokBot 介面左側邊欄放 bot，可以像 iMessage 一樣把 bot 釘選在最上面
    ↳ GrokBot 介面左側排著各個 bot。常用的可以像 iMessage 釘選聊天那樣固定在最上面，方便找。
  • 364:53 給 market researcher 的指令：研究 XAir 網站，了解產品和所處市場，再做競爭分析，找出並深入了解競爭對手
    ↳ 他給市場研究員 bot 的指令：先研究 XAir 網站，搞懂產品和它所在的市場，再做 competitive analysis（競爭分析），找出對手並深入了解它們。
  • 365:28 指令還包括：看競爭對手的行銷網站、了解它們的 positioning，並找出我們在行銷策略上可以用來做競爭定位的缺口與機會
    ↳ 指令還要它去看對手的行銷網站，弄清楚對手怎麼定位自己，再找出我們在行銷上的缺口和機會，也就是對手沒講到、我們可以主打的點。
  • 365:28 這段 prompt 是用口述輸入的；送出後 bot 會爬網站、理解產品，再找競爭對手的 landing page 開始分析
    ↳ 這段 prompt（給 AI 的指令）是用說的輸入。送出後，bot 會自己去逛網站、理解產品，再找出對手的 landing page 開始分析。
  • 365:59 可以非同步派工：你可能只有一個主要窗口 bot，但能同時讓一整隊 bot 平行開工；產品永遠在線，所以編排在背景進行
    ↳ 派工可以非同步：你平常可能只跟一個主要的 bot 對話，但背後能讓整隊 bot 同時開工。系統一直在線，協調都在背景進行，你不用一件一件等。
  • 366:34 market researcher 先附上網站截圖，再產出第一份分析：產品、市場、主要競爭對手（都是大家熟悉的航空公司），以及缺口和該主打的地方
    ↳ 市場研究員 bot 先附上網站截圖，再交出第一份分析：產品、市場、主要對手（都是大家熟悉的航空公司），還有我們的缺口和該主打的地方。
  • 367:05 就像請真人市場研究員幫忙了解市場現況，目標是突破雜訊，真正打動目標受眾
    ↳ 這跟請一位真人市場研究員幫你摸清市場是一樣的。目的是在一堆廣告雜訊裡，找到真正能打動目標客群的說法。
  • 367:05 分析找出的缺口，字幕原文為 useful time、day design、long hauls，並建議每則訊息都以 useful time 開頭
    ↳ 分析找到的缺口，字幕記成 useful time、day design、long hauls（長程航線）。bot 建議每則行銷訊息都用 useful time 開頭，把它當主打。
  • 367:36 畫面可以看到 bot 自己控制的瀏覽器，它會回報進度，實際前往網站、抓截圖，讓你看它在背景的進展
    ↳ 畫面上看得到 bot 自己操作的瀏覽器。它會回報進度、真的點進網站去截圖，讓你看到它在背景做了哪些事，不是只丟一個結果給你。
📘 術語

doing partner（執行夥伴）：實際動手做事的夥伴；字幕用它跟 thought partner 做對比
co-pilot（副駕駛型 agent）：xAI 內部對能一起做任務、但仍要人盯著推進的 agent 的稱呼
agent（代理）：字幕提到通用型和專用型 agent，能跟你一起做任務
asynchronous（非同步）：可以同時派工給多個 bot 平行進行，在背景編排，不必一件件等
