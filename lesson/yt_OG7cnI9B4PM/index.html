🧑‍🏫 這支影片教你把 Claude 接上 3D 軟體 Blender，先用打字的方式排好場景和鏡頭，確認沒問題再花點數讓 AI 生成正式影片。如果你用 AI 做影片時常常抽好幾次都不滿意、點數一直被扣，這套流程就是在解決這個痛點。

  • 00:00 核心概念：在花任何 credit 生成之前，先把鏡頭運動、blocking（走位）和時間點都鎖定
    ↳ 核心概念是先想清楚再花錢。鏡頭怎麼動、人和物件站哪裡、往哪走（blocking，走位安排）、什麼時候發生，全部定好才開始生成。
  • 00:00 用文字 prompt 直接生成影片（text to video）仍然像賭博，每次生成失敗都會燒掉 credits
    ↳ text to video 是只打一段文字就讓 AI 生出影片。結果常常跟想像的不一樣，每重來一次就扣一次 credits（生成用的點數），很像在抽獎。
  • 00:00 Higgsfield 的 Blender plugin 就是為了解決這個問題：先在 3D 裡 block 整個場景、鎖定鏡頭，最後才花 credits 生成成品
    ↳ Blender 是免費的 3D 軟體，plugin 是替它加功能的外掛。這個外掛的做法是先在 3D 裡把場景排好、鏡頭定好，最後一步才付點數生成。
  • 00:33 步驟一：從影片描述欄的連結免費下載 Higgsfield Bridge plugin
    ↳ 第一步：到影片說明欄找連結，免費下載 Higgsfield Bridge 這個外掛。
  • 00:33 步驟二：複製 bridge.higsfield.ai/mcp 這個 URL，開啟 Claude desktop，點左側的 Customize
    ↳ 第二步：複製 bridge.higsfield.ai/mcp 這串網址（MCP 是讓 AI 連接外部工具的通用規格），打開 Claude 桌面版，點左邊的 Customize。
  • 00:33 步驟三：進入 Connectors，按右上角的 Add，新增 custom connector
    ↳ 第三步：進入 Connectors，這裡是讓 Claude 接上外部服務的地方。按右上角的 Add，新增一個自訂連接器（custom connector）。
  • 01:04 步驟四：貼上 bridge.higsfield.ai/mcp endpoint，並確認已連上你的 Higgsfield 帳號
    ↳ 第四步：貼上剛才的網址。這種網址叫 endpoint，就是 Claude 要連過去的位址。貼好後確認已經連上自己的 Higgsfield 帳號。
  • 01:04 步驟五：開啟 Blender，把下載好的 Higgsfield Blender plugin 直接拖放進 Blender；詢問是否啟用 add-on 時按 OK
    ↳ 第五步：打開 Blender，直接把下載的外掛檔拖進視窗。跳出「是否啟用 add-on（附加功能模組）」時按 OK。
  • 01:04 步驟六：登入 Higgsfield，按 Allow 讓它連接 Blender，完成後 Blender 裡會出現 prompt bar
    ↳ 第六步：登入 Higgsfield，按 Allow 允許它連接 Blender。成功後 Blender 裡會多出一條 prompt bar，就是讓你打字下指令的輸入列。
  • 01:04 可用功能包含 scene building、3D modeling、character animation，以及 image、video、camera control 和 available assets
    ↳ 連好之後能做的事包括：搭場景、做 3D 模型、讓角色動起來，也能處理圖片和影片、控制鏡頭，還能叫用現成的素材。
  • 01:40 Higgsfield Bridge 把 Claude 直接接上 Blender：描述場景（包含鏡頭運動），Claude 就會在 Blender 裡建出可編輯的 3D previz，不需要 Blender 專業
    ↳ 重點是你不用會 Blender。用說的描述場景和鏡頭怎麼動，Claude 就會在 Blender 裡蓋出可以修改的 previz，也就是正式製作前的預覽版。

    ↳ 整個流程分三站：在 Claude 下指令，到 Blender 的 viewport（3D 預覽畫面）看成果，最後交給 Higgsfield 生成完成的影片。
  • 02:14 範例 prompt：描述一個方塊一邊翻轉一邊沿著走廊前進的場景，並寫明鏡頭角度
    ↳ 示範指令寫得很具體：一個方塊一邊翻滾、一邊沿著走廊往前，還指定鏡頭從哪個角度拍。把鏡頭角度寫進去是關鍵。

    ↳ 按 Enter 後，Claude 會先載入它的 skills（完成特定任務用的能力包），再問你能不能繼續。選 Always Allow，之後就不用一直按同意。

    ↳ Claude 動手前會先列出計畫大綱，讓你知道它打算做什麼。接著你能在 Blender 畫面裡直接看它一步步把場景蓋出來。

    ↳ 要把預覽輸出成影片，先到 Output Properties（輸出設定面板）選存檔資料夾、取檔名，檔案類型選影片。

    ↳ 解析度設 1920×1080，也就是常見的 Full HD。每秒 24 格（frames per second，每秒幾張畫面）。編碼選 MPEG-4，就是常見的 MP4。

    ↳ 到 View 選單按 Render Playblast，快速輸出一支預覽影片。這支就是 reference video（參考影片），用來告訴 AI 鏡頭和動作該怎麼走。

    ↳ 加碼技巧：如果要用 Fable 5，可以把 Blender 輸出的影片和素材圖丟給 Claude，請它幫你寫生成用的 prompt，不用自己想。

    ↳ 實際生成：上傳想放進畫面的卡車照片和參考影片，貼上 prompt，模型選 Seedance 2.5。長度設 14 秒來配合參考影片，再按 Generate。

    ↳ 成果是 Seedance 2.5 生出的影片，鏡頭運動完全照著 Blender 裡排好的走，不是讓 AI 自己亂發揮。

📘 術語

blocking / 3D blocking（走位／3D 場景排布）：先在 3D 裡排好整個場景，作為 motion reference，鎖定動作並消除 camera drift
3D blockout（3D 草模排布）：字幕用 before/after 對比有無 3D blockout 的生成結果；未另外定義
text to video（文字生成影片）：用文字 prompt 直接生成影片，字幕說這仍然像賭博
previz（預視覺化）：Claude 在 Blender 裡建出的可編輯 3D 預覽場景
MCP（MCP）：字幕未解釋，僅出現在 bridge.higsfield.ai/mcp 這個 connector URL 中
custom connector（自訂連接器）：在 Claude desktop 的 Connectors 裡按 Add 新增，貼上 Higgsfield 的 endpoint
endpoint（端點）：字幕指 bridge.higsfield.ai/mcp 這個網址，要貼進 custom connector
add-on（附加元件）：把 plugin 拖進 Blender 時，會詢問是否啟用 add-on，按 OK
prompt bar（提示輸入列）：連接成功後出現在 Blender 裡的輸入列
viewport（視圖區）：字幕列為創作迴圈中 Blender 的那一步，未另外解釋
skills（技能）：按 Enter 後 Claude 會先取得它的 skills，未另外解釋
Output Properties（輸出屬性）：匯出時在這裡選資料夾、命名檔案、設定媒體類型與解析度等
frames per second（每秒影格數）：匯出時選 24 frames per second
Render Playblast（Playblast 渲染）：位於 View 選單，用來渲染出參考影片
reference video（參考影片）：由 Render Playblast 渲染出的影片，之後與素材圖一起上傳生成
Seedance 2.5（Seedance 2.5）：在 Higgsfield 選用的模型，可做無浮水印 video-to-video，最長 30 秒
video-to-video（影片轉影片）：以影片為輸入生成影片；Seedance 2.5 可生成無浮水印、最長 30 秒
camera drift（鏡頭漂移）：字幕說用 3D blocking 當 motion reference 可以消除它
spline rails / orbital passes / robo arm snaps（曲線軌道／環繞運鏡／機械手臂快速運鏡）：full camera control 可以用純文字指揮的鏡頭運動類型
multi-pass iteration（多輪迭代）：用純文字調整材質、鏡頭感和 handheld weight
handheld weight（手持鏡頭的重量感）：可用純文字調整的鏡頭感之一，未另外解釋
master file（主檔）：剪輯和鏡頭鎖定一次後可重複使用，替換角色或場景
multimodal reference（多模態參考）：Seedance 2.5 可使用角色、場景與風格參考
eyeline matching（視線匹配）：字幕說可做到完美的 eyeline matching，未另外解釋
seat swaps（座位錯置）：字幕說可做到零次意外的 seat swaps，未另外解釋
speed ramps（變速效果）：用於 hyper-motion 產品廣告的戲劇化效果
shot blockouts（鏡頭排布）：汽車廣告範例中包含 19 個 shot blockouts
style reskins（風格換皮）：讓同一個 blocking master file 變成無限多種美學風格
