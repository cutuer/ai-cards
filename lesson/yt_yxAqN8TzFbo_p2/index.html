🧑‍🏫 這段接著處理馬克杯的 UV。UV 就是把 3D 模型表面攤平成一張平面，決定貼圖的哪一塊貼到模型的哪裡。作者用免費外掛 Mio3_UV 的 Gridify 把歪斜的 UV 整理成方格，讓陶瓷花紋對齊，順便說明什麼時候 UV 可以重疊、什麼時候不行。最後進材質節點微調杯子，並準備把太淡的地板調深。

  • 11:15 要找的 extension 叫 Mio3_UV（不是 Moi3），搜尋時直接打 UV 就能找到
    ↳ extension 是幫 Blender 加新功能的擴充程式。要找的叫 Mio3_UV，名字很容易看成 Moi3，所以搜尋時直接打 UV 最快找到。
  • 11:15 安裝不需要下載、解壓縮：把瀏覽器縮成半個視窗，和 Blender 並排
    ↳ 不用先下載檔案再解壓縮。只要把瀏覽器縮成半個螢幕，跟 Blender 左右並排，下一步就能直接用拖的安裝。
  • 11:48 在網頁視窗下方角落的 Get add-on 點一下並拖曳，游標會變成十字，放進 Blender 後確認安裝；底部會顯示 Installed mio3_uv
    ↳ add-on（外掛）的網頁角落有 Get add-on 按鈕。按住它拖進 Blender，游標會變成十字，放開後按確認。底部出現 Installed mio3_uv 就是裝好了。
  • 12:18 在 UV Editor 按 N 叫出 properties，會多一個 Mio3 分頁；作者最常用的是最上面的 Gridify
    ↳ UV Editor 是專門編輯攤平後 UV 的視窗。在裡面按 N 會打開側邊的 properties（屬性面板），這時會多一個 Mio3 分頁。作者最常用最上面的 Gridify。
  • 12:18 Gridify 能把原本拉伸的 UV 轉成方正的格狀，陶瓷上的那條線因此能對齊
    ↳ Gridify 會把被拉扯變形的 UV 整理成整齊的方格。原本歪掉的貼圖線條因此變直，杯身上那條陶瓷紋路就能對齊。
  • 12:53 握把也要套用：在 face select mode 按 L 只選握把，或直接選 UV island，再按 Mio3 的 Gridify
    ↳ island 是 UV 裡彼此不相連的一整塊。握把也要整理：在 face select mode（以面為單位選取）下按 L，只會選到握把那一塊；或直接選它的 island，再按 Gridify。
  • 13:24 按 L 選取 island 後，可以把它移到任何位置，對到貼圖的不同區塊
    ↳ 選好一塊 island 後可以整塊拖到別處。這等於改用貼圖的另一個區域，你可以自己決定握把要顯示哪一段花紋。
  • 13:24 看不清楚底下貼圖時，可以關掉畫面上方的 overlay；它會關閉所有 overlay，要記得自己關過
    ↳ overlay 是畫面上疊加的輔助資訊，例如網格線。它擋到貼圖時，可以用上方按鈕關掉。但這個按鈕會一次全關，之後畫面看起來怪怪的，記得是自己關的。
  • 13:54 UV 縮小，貼圖看起來會比較大；放大則相反。作者選擇介於兩者之間，讓紋理從左到右大致填滿
    ↳ UV 縮小，模型上同一塊面只對到貼圖的一小區，花紋就被放大；UV 放大則花紋變小。作者取中間值，讓紋理從左到右大約剛好鋪滿。
  • 13:54 UV 拖出畫面範圍也沒關係，因為貼圖會往上下左右無限 tile
    ↳ tiling 是指貼圖像磁磚一樣往四面八方無限重複。所以 UV 拖出方框外，也只是對到下一塊重複的貼圖，不會出錯。
  • 14:27 UV 上的空白區塊對應到握把的切割處，可以對照找到它在模型上的位置
    ↳ UV 上有空缺的地方，就是握把模型被切開的接縫位置。拿它對照 3D 模型，就能找到接縫在模型上的哪裡。
  • 15:00 想要精準對齊，就要讓各個 island 的 texel density 一致，也就是把 island 縮放到大致相同的比例
    ↳ texel density 指每塊面積分到多少貼圖像素。各 island 的密度一致，花紋大小才會一樣。做法是把各塊 island 縮放到差不多的比例。
  • 15:00 比較兩邊格子的大小：一邊偏長方、一邊偏正方時，選整個 island 按 S 再按 Y 單軸拉伸，最後再整體縮小
    ↳ 看兩邊的方格：一邊偏扁長、一邊是正方，代表比例不一樣。選整塊 island，按 S 再按 Y，只沿上下方向拉伸成正方，最後再整體縮小。
  • 15:35 把 UV 往上移，讓貼圖上像沾釉的區段對到握把；作者不確定現實陶器能不能這樣做
    ↳ 把握把的 UV 往上移，讓貼圖上像沾了釉的那段落在握把上。作者也老實說，不確定真實陶器能不能做成這樣。
  • 16:06 3D 作品不一定符合現實，例如沒學過工程的藝術家設計的機器人，工程師會說根本飛不起來；這也是樂趣的一部分
    ↳ 3D 作品不必完全照現實。像沒學過工程的藝術家畫的機器人，工程師看了會說根本飛不起來。作者覺得這種自由也是樂趣所在。
  • 16:37 Gridify 把某一段壓成細線，造成拉伸。按 2 進 edge select mode，Shift 逐一加選邊，往上拉增加細節，再把那條線往外 scale
    ↳ Gridify 把某一段擠成細線，那裡的貼圖就被拉長。按 2 進 edge select mode（以邊為單位選取），按住 Shift 逐條加選邊，往上拉出空間，再把那條線往外放大。
  • 17:13 調整後接縫融合得很自然，作者認為大概只能做到這樣
    ↳ 調整後接縫處的花紋接得很自然。作者認為大概只能做到這樣，不必再追求完美。
  • 17:13 底部用同樣方式處理。那條線橫跨兩個 island，在 UV 編輯器中選取可同時選到兩邊；往下拉再往外 scale
    ↳ 杯底也用同樣方法處理。那條線剛好橫跨兩塊 island，在 UV 編輯器裡選取，兩邊會一起被選到。往下拉，再往外放大。
  • 17:44 UV island 重疊在這裡沒關係，但如果要在模型上彩繪就有影響
    ↳ 這個杯子只是套用現成貼圖，所以 island 疊在一起沒關係。但如果要直接在模型上畫圖，重疊就會出問題。
  • 18:14 island 重疊時彩繪，同一筆畫會在模型上出現兩次
    ↳ 兩塊 UV 重疊，等於共用同一塊貼圖位置。你在其中一處畫一筆，模型上另一處也會同時出現同一筆。
  • 18:14 UV 展開有兩種風格：套用網路圖片或 tile 貼圖時，重疊無妨，眼睛看不出來；要彩繪的話，各部分就必須分開
    ↳ UV 展開有兩種做法。用網路圖片或重複貼圖時，重疊了眼睛也看不出來，可以不管。要在模型上手繪時，每個部分都得分開。
  • 18:49 遊戲資產更複雜：island 要全部分開，還要留大 margin，因為遊戲有多種解析度的 mesh 和貼圖。想學的話建議看遊戲貼圖教學
    ↳ 遊戲模型的要求更嚴格：island 全部分開，彼此之間還要留大 margin（間距）。原因是遊戲會用多種解析度的模型和貼圖。想深入可以找遊戲貼圖的教學。
  • 18:49 其餘拉伸可以修但不必修：杯口之後會加咖啡奶泡，杯底也看不到
    ↳ 剩下的拉伸可以修，但沒必要。杯口之後會被咖啡奶泡蓋住，杯底鏡頭也看不到。
  • 19:22 網路上有人批評模型很爛，但模型可能只為特定用途設計，例如只從上方看，鏡頭根本不會拍到內部或底部
    ↳ 網路上常有人批評模型做得很爛，但模型可能只為特定畫面而做。例如只從上方拍，鏡頭根本不會拍到內部或底部，那些地方就不必花力氣。
  • 20:00 切到上方的 Shading 分頁操作節點。這些貼圖是從實際掃描的陶瓷取得的物理精確資料，而且經過色彩校正
    ↳ Shading 分頁在畫面上方，專門用來調材質。材質由 nodes（節點）組成，節點就是一個個用線連起來的功能方塊。這組貼圖來自實際掃描的陶瓷，數據貼近真實，也做過色彩校正。
  • 20:30 有時需要藝術上的控制：斷開 roughness 貼圖，改用滑桿讓杯子更亮；bump 還在，所以細節大多保留
    ↳ 有時想照自己的美感調整。作者斷開 roughness（粗糙度，決定表面霧或亮）貼圖，改用滑桿讓杯子更亮。bump（凹凸貼圖，模擬細小起伏）還接著，所以細節大多保留。
  • 20:30 這個材質不需要 metallic，是多餘的
    ↳ metallic 控制表面像不像金屬。陶瓷杯用不到這個效果，所以這個節點是多餘的。
  • 21:00 AO 用來表現凹縫資訊，但平滑陶瓷沒有凹縫所以不需要；會提供是為了讓所有材質規格統一
    ↳ AO（ambient occlusion，環境遮蔽）用來表現縫隙角落的陰影。光滑陶瓷沒有縫，所以用不到。材質包附上它，只是為了讓每組材質的規格統一。
  • 21:00 刪除節點時按 Control+X，可以刪掉節點並保留前後連線，不必手動重接
    ↳ 刪除節點時按 Control+X，節點會被刪掉，前後兩端會自動接起來，不用再手動重新拉線。
  • 21:30 回到 layout 搭配燈光檢視，發現混凝土地板太淡，看起來不像高級咖啡廳（付 $9 買咖啡那種），反而像滿是灰塵的工地地板
    ↳ 回到 Layout 主畫面搭配燈光檢查，發現混凝土地板顏色太淡。看起來不像會花 9 美元買咖啡的高級咖啡廳，反而像滿地灰塵的工地。
  • 22:00 到 Shading 分頁看混凝土材質：這是手動設定的，只有 base color 和 normal map；可以在兩者連接處之間調整顏色
    ↳ 到 Shading 分頁看，混凝土材質是手動接的，只有 base color（底色貼圖）和 normal map（模擬表面凹凸光影的貼圖）兩張。在這兩者的連線之間插入節點，就能調整顏色。
  • 22:30 按 Shift+A，或點上方的 Add，再進入 Color，開始加入調色節點
    ↳ 按 Shift+A，或點上方的 Add 選單，進入 Color 類別，就能加入調色用的節點。
📘 術語
extension / add-on（擴充功能／附加元件）：從網頁拖曳 Get add-on 到 Blender 即可安裝，例如 Mio3_UV
Mio3_UV（Mio3_UV 擴充）：安裝後在 UV Editor 按 N 會出現 Mio3 分頁，內含 Gridify 等選項
UV Editor（UV 編輯器）：編輯 UV 的視窗，按 N 可叫出 properties
Gridify（格狀化）：把拉伸的 UV 轉成方正格狀，讓紋理對齊
island（UV 島）：UV 中各自獨立的一塊，可按 L 選取、移動、縮放
face select mode（面選取模式）：作者在此模式下按 L 選取握把
edge select mode（邊選取模式）：按 2 進入，用來選取邊並拉動、縮放
overlay（疊加顯示）：畫面上方可關閉，關掉後模型上不顯示任何疊加資訊，方便看貼圖
tiling（平鋪／重複拼貼）：貼圖往上下左右不斷重複，所以 UV 拖出範圍也沒關係
texel density（貼圖像素密度）：讓各 island 的貼圖比例一致，稱為 matching the texel density
margin（邊距）：遊戲資產因有多種解析度的 mesh 和貼圖，需要留大 margin
Shading tab（Shading 分頁）：畫面上方的分頁，用來操作材質節點
nodes（節點）：材質的組成單元，可在 Shading 分頁連接、斷開或刪除
roughness（粗糙度）：作者斷開 roughness 貼圖，改用滑桿讓杯子更亮
bump（凹凸）：斷開 roughness 後仍保留 bump，所以細節大多還在
metallic（金屬度）：作者認為這個陶瓷材質不需要，是多餘的
AO (ambient occlusion)（環境光遮蔽）：表現凹縫的資訊；平滑陶瓷沒有凹縫所以不需要
base color（基本色）：混凝土材質的顏色貼圖，可在它和後續節點之間加節點調色
normal map（法線貼圖）：混凝土材質手動設定的兩張貼圖之一
