🧑‍🏫 這支影片是 Wonderful 的 Barak Kaufman 分享他們和 OpenAI 怎麼合作，以及大企業導入 AI agents 時，跑得快的公司做對了什麼。值得看的地方在於，他講的不只是技術，還有企業要調整哪些做事方法，才能真的把 AI 用起來。

  • 00:01 講者認為現在是人類歷史上最令人興奮的時刻之一。
    ↳ 講者一開場就表態：他覺得現在這個時期，是人類史上數一數二令人興奮的時刻。這是他個人的看法，也替整場演講定下樂觀的基調。
  • 00:01 Wonderful（字幕作 Wondr）是 applied AI implementation partner，服務全球最大、最複雜的企業。
    ↳ Wonderful 的定位是 applied AI implementation partner，意思是幫企業把 AI 實際導入、用起來的合作夥伴。他們的客戶是全球最大、流程最複雜的企業。
  • 00:01 合作第一部分：他們必須極快建出平台，開發團隊使用 OpenAI 的 Codex。講者說沒有 OpenAI 和 Codex 就做不到。
    ↳ 他們得在極短時間內做出自家平台，開發團隊靠的是 Codex，也就是 OpenAI 出的 AI 寫程式工具。講者直說，沒有 OpenAI 和 Codex，這件事做不到。
  • 00:01 合作第二部分：把 OpenAI 提供的智慧帶給他們在全球合作的企業。
    ↳ 第二部分是對外。OpenAI 提供 AI 模型的能力，Wonderful 負責把這些能力帶進他們在全球合作的企業，讓企業在日常工作中實際用上。
  • 00:31 他們的產品有兩部分：一是建立、管理、優化 agents 的基礎設施平台，二是 on-premises 部署團隊。兩者結合讓企業能真正部署 agents。
    ↳ agent 指能自己執行任務的 AI。他們提供兩樣東西：一是建立、管理、優化 agents 的平台，二是 on-premises 部署團隊，會派人到企業現場協助導入。兩者缺一不可。
  • 00:31 進展最快的公司明白，自己不是在建 AI 基礎設施，而是在用 AI 轉型整個組織。
    ↳ 跑最快的公司想通了一件事：他們不是在「蓋一套 AI 系統」，而是在「用 AI 改造整個公司的運作」。目標放在組織本身，不是技術本身。
  • 00:31 建議：聚焦在幫團隊更快前進，並做好推出 agents 所需的 change management。
    ↳ 講者建議做兩件事。第一，專注讓團隊跑得更快。第二，做好 change management，也就是組織改變時的配套，例如教員工新做法、調整分工，讓大家真的接受並用起來。
  • 01:01 現在進入新階段，已經可以執行長期的 agent 任務。這通常需要多個 agents 協作，也會用到不同的互動模式。
    ↳ 現在 AI 已經能執行 long-term agent tasks，也就是耗時長、步驟多的任務，通常由多個 agents 分工完成。這也會用到不同的 interaction modalities（互動方式），影片沒有細講。
  • 01:01 要提升生產力，不只是自動化現有的手動任務，而是真正重新思考企業在 2026 年以後該如何運作。
    ↳ 真正的生產力提升，不是把現在手動做的事改成自動跑就好。要回頭問：2026 年以後，公司的工作本來就該怎麼安排？等於是從頭重新設計流程。
📘 術語
applied AI implementation partner（應用 AI 導入夥伴）：Wonderful 的自我定位，協助大型、複雜企業導入 AI。
Codex（Codex）：OpenAI 的工具。Wonderful 開發團隊用它快速建出平台。
agent（AI 代理）：字幕沒有定義，只說企業可以建立、管理、優化並部署 agents。
on-premises deployment team（駐點部署團隊）：Wonderful 搭配平台提供的團隊，讓企業能真正部署 agents。
change management（變革管理）：推出 agents 時需要的配套，用來幫團隊更快前進。
long-term agent tasks（長期 agent 任務）：現在已可執行的任務類型，通常需要多個 agents 協作。
interaction modalities（互動模式）：執行長期 agent 任務時會用到不同的互動模式。字幕沒有細講。
✏️ 小考一題

根據講者，進展最快的公司明白了什麼？

A. 應該等模型更成熟後再開始部署 agentsB. 只要把現有的手動任務自動化就足夠C. 他們不是在建 AI 基礎設施，而是在用 AI 轉型組織D. 他們最重要的工作是打造自己的 AI 基礎設施
看答案
答案：C。[00:31] 講者說進展最快的公司明白自己 not building AI infrastructure, but transforming their organization with AI。
