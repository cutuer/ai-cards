看全部 4 條重點

🧑‍🏫 這支影片是 Zapier 工程師分享他們怎麼用 OpenAI 的 Codex。重點不在 AI 幫忙寫程式，而是讓 AI 把散在各個工具裡的資料串起來，把一份要花好幾週的規劃工作縮短到幾小時。想知道 AI 除了寫東西還能怎麼幫忙整理工作，這支很有參考價值。

  • 00:01 Zapier 工程師 Ryan Fitzgerald 說，Codex 用起來不太像寫程式用的 AI，比較像現代工程工作的 operating layer
    ↳ Codex 是 OpenAI 做給工程師用的 AI 助手。講者說它不只會寫程式，更像 operating layer，也就是每天做事都要經過的那一層，查資料、整理、交辦都靠它。
  • 00:01 Zapier 是 remote-first 公司，平常用 Slack、Google Docs、Coda 等很多工具，Codex 把這些工具串在一起
    ↳ remote-first 指公司預設大家遠端上班，溝通全靠線上工具：Slack 用來聊天，Google Docs 和 Coda 是線上文件。資訊散在很多地方，Codex 能跨這些工具一起查、一起用。
  • 00:01 主要用途之一是透過 Codex 在 Jira 產出 full-scope tickets，並用 Zapier MCP 和 SDK 把 context 拉進 Codex
    ↳ Jira 是追蹤工作進度的系統，ticket 是一張待辦工單，full-scope 指範圍寫齊全。MCP 是讓 AI 接上外部工具的規格，SDK 是開發工具包，兩者讓 Codex 讀到背景資料（context）。
  • 00:32 以前要花好幾週研究才能湊齊資料，現在 Codex 可以查遍各個知識來源，在幾小時內整理出附詳細指示的完整 epic，也更快幫客戶解決卡關的問題
    ↳ epic 是一個大目標，底下拆成很多張工單。以前要人工翻遍文件和對話好幾週才寫得出來，現在 Codex 幾小時就查完各處資料，產出附詳細做法的 epic，客戶卡住的問題也更快解決。
📘 術語
operating layer（作業層）：講者形容 Codex 比較像現代工程工作的 operating layer，而不只是寫程式用的 AI
Zapier MCP（Zapier MCP）：跟 SDK 一起用，把 context 拉進 Codex
epic（epic（大型工作項目））：Codex 整理各知識來源後產出的完整 epic，裡面有詳細的待辦指示
