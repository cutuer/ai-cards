🧑‍🏫 這段是 Blender 甜甜圈教學第三集的前半，先把場景物件整理和命名，再從甜甜圈複製出上半部，做成糖霜的雛形。值得看的原因是它示範了很實用的建模思路：與其用複雜的模擬硬算，不如拿現成的形狀來改，順便學會好幾個之後一直會用到的工具。

  • 00:00 本集做甜甜圈糖霜。上集原本說要做材質與燈光，但他改成先把建模完成。
    ↳ 這集要做甜甜圈上面那層糖霜。上一集預告要做材質和燈光，但他決定先把形狀全部做完，顏色和光線之後再處理。
  • 00:00 場景裡已有攝影機、燈、物件、圖片等多個物件，需要整理。
    ↳ 場景裡已經有攝影機、燈、杯子、甜甜圈、參考圖片好幾樣東西。不整理的話之後很難找，所以這集先收拾。
  • 00:32 右上角的 Outliner 像試算表，列出場景所有物件；之後會用它建立 collections 來整理。
    ↳ Outliner 是右上角的物件清單，像試算表一樣一行列一個物件。之後會用它建 collections，也就是把物件分組的資料夾。
  • 00:32 第一步是幫物件取有意義的名字。例如杯子目前叫 Cylinder，大場景裡會找不到，命名是好習慣。
    ↳ 新增的物件會帶預設名字，例如杯子叫 Cylinder（圓柱）。物件一多就分不清誰是誰，所以一開始就取好懂的名字。
  • 00:32 命名方法一：在 Outliner 雙擊物件名稱後輸入新名字，例如 mug。
    ↳ 第一種改名方法：在 Outliner 裡對物件名稱點兩下，名字就能編輯，直接打新名字，例如 mug（杯子）。
  • 01:02 命名方法二：在 3D viewport 按 F2（和 Windows 重新命名的熱鍵相同），例如改成 doughnut；在 Outliner 裡按 F2 也可以。
    ↳ 第二種方法：在 3D viewport（中間主要操作的 3D 畫面）選好物件按 F2 改名，跟 Windows 改檔名是同一個鍵。在 Outliner 按 F2 也可以。
  • 01:02 刪掉不再需要的圖片，場景只剩 camera、doughnut、light、mug。
    ↳ 參考圖片用完了就刪掉。清完後場景只剩四樣：camera（攝影機）、doughnut（甜甜圈）、light（燈）、mug（杯子）。
  • 01:02 按 G 再按 X，把杯子沿 X 軸移到旁邊，專心處理甜甜圈。
    ↳ G 是移動，接著按 X 會鎖定成只沿 X 軸（左右方向）移動。把杯子推到旁邊，畫面只剩甜甜圈，比較好專心。
  • 01:35 3D 裡做東西的方法很多，每種各有優缺點。Blender 有 fluid simulator，可模擬糖霜掉落、潑灑在甜甜圈上，但他認為不太好用。
    ↳ 同一個東西在 3D 裡有很多做法，各有好壞。Blender 內建 fluid simulator（液體模擬器），能模擬糖霜淋下來，但他覺得不太好用。
  • 02:06 不用模擬的原因：非常複雜、容易出錯、無法控制最終結果、需要一直 re-bake。
    ↳ 用模擬的問題有四個：設定複雜、容易出錯、成品長怎樣控制不了，而且每改一點就要 re-bake（重新計算一次模擬結果）。
  • 02:06 改用手工製作：一開始看似較慢，但更好控制，其實也很簡單，還能順便認識更多工具與 Blender 的不同區域。
    ↳ 所以改用手做。一開始好像比較慢，但每一處都能自己決定，其實也不難，還能順便多學一些工具和介面區域。
  • 02:06 糖霜會順著底下物體的形狀，基本上就是甜甜圈的上半部，再加些變化就像糖霜。
    ↳ 關鍵在於糖霜是貼著甜甜圈長的，形狀其實就是甜甜圈的上半部。所以直接拿上半部來改，再加點變化就很像了。
  • 02:39 Shift D 複製物件，也可從選單 Object > Duplicate Objects 執行。
    ↳ Shift D 是複製物件的快捷鍵。不記得的話，也可以從上方選單 Object > Duplicate Objects 找到同一個功能。
  • 02:39 複製後會進入放置狀態。按 Escape 會留在原位但不會取消複製，Outliner 會出現 Doughnut.001。
    ↳ 複製出來的新物件會跟著滑鼠等你放。按 Escape 只是取消移動，複製品還在原地，Outliner 會多出一個 Doughnut.001。
  • 03:11 絕對不要讓兩個物件佔用完全相同的空間，攝影機移動或播放動畫時會出現閃爍。
    ↳ 現在兩個物件完全疊在一起，這種情況一定要避免。兩個表面搶同一個位置，鏡頭移動或播放動畫時畫面會一直閃。
  • 03:11 把複製的物件改名為 Icing 以便區分；切到前視圖，進入 edit mode，從 face select 改成 vertex select。
    ↳ 把複製品改名成 Icing（糖霜）免得搞混。切到前視圖，進 edit mode（編輯點、線、面的模式），選取單位從 face（面）改成 vertex（點）。
  • 03:44 直接框選下半部只會選到該視角看得到的點。必須先開 Toggle X-ray 或切到 wireframe 再框選，才能選穿到物體另一側。
    ↳ 從正面直接框選下半部，只會選到你看得見的點，背面的選不到。要先開 Toggle X-ray（半透明透視）或切成 wireframe（只顯示線框），框選才會穿透到背面。
  • 05:00 若無法拖曳框選、游標變成圓圈，是誤按了 W。W 會在畫面上方循環切換選取模式。
    ↳ 如果拖不出選取框、游標變成圓圈，通常是不小心按到 W。W 會在畫面上方輪流切換幾種選取方式。
  • 05:00 他向 Blender 團隊抱怨過 W 太靠近其他常用鍵，很多人誤按。大部分時間應使用框選模式，特殊選取時才切換其他模式。
    ↳ 他跟 Blender 團隊反映過 W 離常用鍵太近，很多人會誤按。平常用框選就夠了，有特殊需求時再切換其他選取方式。
  • 05:33 他提供本教學專用的免費 troubleshooting guide「Unstuck Yourself」，連結在影片下方。
    ↳ 他為這套教學做了免費的 troubleshooting guide（疑難排解手冊），名字叫「Unstuck Yourself」，連結在影片下方。
  • 06:04 若 guide 裡找不到解答，可到 Discord 求助，連結也放在他的網站上。
    ↳ 手冊裡找不到答案，可以去 Discord（線上聊天社群平台）發問，連結也放在他的網站上。
  • 06:04 按 X 刪除時會詢問要刪除哪一部分。選 vertices 會連中間那一排線一起刪掉，結果剩不到一半。
    ↳ 選好下半部按 X 刪除，Blender 會問要刪哪一種。選 vertices（點）的話，中間交界那一排點也會被刪，剩下的不到一半。
  • 06:38 應選 faces：只刪除完整的面。中間那排點無法單獨構成完整的面，因此會保留。
    ↳ 應該選 faces（面），只刪完整被選到的面。中間那排點單獨組不成完整的面，所以會被留下來。
  • 06:38 刪完後關閉 toggle x-ray 以便看清模型。
    ↳ 刪完記得把 Toggle X-ray 關掉，不然模型是半透明的，看不清楚形狀。
  • 07:11 點選別處後看起來仍像完整甜甜圈，因為兩個物件共用同一空間；在 Outliner 選得到，但畫面上完全看不見。
    ↳ 點到別處後，畫面看起來還是一整顆甜甜圈，因為糖霜跟原本的甜甜圈疊在同一個位置。Outliner 選得到糖霜，畫面上卻看不出來。
  • 07:11 先幫糖霜加厚度：在 modifiers 裡加入 solidify modifier，它能為任何面加上厚度。
    ↳ 現在的糖霜只是一層沒有厚度的薄皮。到 modifiers（修改器面板）加入 solidify，它可以讓任何面長出厚度。
  • 07:41 solidify 預設往內加厚，看起來像沒作用。把 offset 改成反向（1），就會往外加厚。
    ↳ solidify 預設是往內加厚，所以看起來像沒作用。把 offset（控制厚度往哪一邊長的設定）改成反向的 1，就會往外長出來。
  • 08:13 他常說「imperfection is the digital perfection」。糖霜邊緣完全筆直，像雷射切割，所以看起來假。
    ↳ 他常說「imperfection is the digital perfection」，意思是不完美才是數位作品的完美。現在糖霜邊緣整齊得像雷射切的，所以一看就假。
  • 08:13 邊緣必須加入隨機感，肉眼看起來才真實。
    ↳ 邊緣要刻意做得高低不一、有點隨機，眼睛看了才會覺得是真的。

    ↳ 進 edit mode 後，solidify 加出來的厚度會擋住網格。可以先按 disable in viewport（只在畫面上暫時關掉效果），編輯完再打開。
  • 08:48 逐一選點再按 G 往下移雖然可行，但會非常耗時。
    ↳ 一個一個點選起來再按 G 往下拉也做得到，但點很多，會非常花時間。
  • 08:48 改用上方的 proportional editing tool 加快作業。
    ↳ 改用畫面上方的 proportional editing（比例編輯）工具來加快速度：移動一個點時，周圍的點也會跟著一起動。
  • 09:23 開啟後按 G，會連同周圍一個 falloff 範圍一起移動。
    ↳ 開啟後選點按 G，周圍一個 falloff（影響範圍）內的點都會被一起帶動。
  • 09:23 若整個網格都跟著動，是因為 falloff 太大、超出目前視野。他在去年 Blender conference 的 usability talk 提過這個問題。
    ↳ 如果整個模型都跟著動，是 falloff 設太大，超出了你眼前看得到的範圍。他去年在 Blender 研討會談介面易用性的演講提過這個問題。
  • 10:00 拉遠鏡頭可看到代表 falloff 大小的圓圈。在移動狀態中滾輪往上縮小範圍，往下放大範圍。
    ↳ 把鏡頭拉遠，就能看到代表 falloff 大小的圓圈。移動的時候滾輪往上會縮小範圍，往下會放大範圍。
📘 術語
Outliner（大綱視窗）：右上角像試算表的清單，列出場景所有物件
Collections（集合）：之後會用 Outliner 建立，讓物件更容易查看與整理
3D viewport（3D 視圖）：主要操作的 3D 畫面，可在此按 F2 重新命名
Fluid simulator（流體模擬器）：可模擬物體掉落潑灑來做糖霜，但字幕說它不太好、很複雜
Re-bake（重新烘焙）：使用模擬時需要一直重新 bake，是不用模擬的缺點之一
Duplicate Objects (Shift D)（複製物件）：複製後進入放置狀態，按 Escape 留在原位但不取消複製
Edit mode（編輯模式）：用來選取與修改網格上的點、面
Vertex select / Face select（頂點選取／面選取）：edit mode 中的選取模式，字幕從 face select 切換到 vertex select
Toggle X-ray（X 光切換）：開啟後框選才會選穿物體到另一側，否則只選到看得見的部分
Wireframe mode（線框模式）：與 Toggle X-ray 一樣，可讓選取穿透整個物體
Faces（刪除選項）（面）：只刪除完整的面，不構成完整面的點會被保留
Modifier（修改器）：在 modifiers 面板加入，例如 solidify
Solidify modifier（實體化修改器）：為任何面加上厚度，預設往內加厚
Offset（偏移）：solidify 的設定，改成反向（1）即往外加厚
Disable in viewport（在視圖中停用）：暫時隱藏修改器效果，方便編輯網格
Proportional editing（比例編輯）：按 G 移動時會連同周圍 falloff 範圍一起移動
Falloff（衰減範圍）：proportional editing 影響的範圍，拉遠可見圓圈，用滾輪調整大小
