🧑‍🏫 OpenAI 的 Codex app 推出 Windows 版了。Codex 是 OpenAI 做的 AI 寫程式助手，可以幫你讀程式、改程式、下指令。這支影片介紹 Windows 版有哪些功能，平常用 Windows 電腦的人可以看看它在自己的電腦上能做到什麼。

  • 00:02 Codex app 推出 Windows 版，可以在同一個介面裡同時處理多個專案
    ↳ 手上同時有好幾個專案時，不用各開一個視窗來回切換。在 Codex app 同一個畫面裡，就能分別交代每個專案的工作、分別追進度。
  • 00:02 Windows 版完全原生執行，透過全新的專屬 Windows sandbox 使用 PowerShell
    ↳ 「原生執行」是指它直接跑在 Windows 上，不用先裝別的系統。sandbox（沙盒）是一個隔開的空間，用來限制 AI 能動到的範圍。它在沙盒裡用 PowerShell（Windows 內建的指令工具）下指令。
  • 00:02 Windows 版同樣有 skills、automations 功能，automations 可以讓 Codex 在背景替你工作
    ↳ skills 是可以加裝的技能包，裝了之後 Codex 就多會幾件事。automations 是自動化功能，你把固定要做的工作交給它，它會在背景自己跑，你可以同時去忙別的。
  • 00:32 支援 work trees，可以在同一個專案裡處理多個獨立任務；skill gallery 也新增了 Windows 專屬 skill，例如 WinUI skill
    ↳ work trees 能把同一個專案分成幾個獨立的工作區，例如一邊修錯誤、一邊加新功能，兩邊不會互相干擾。skill gallery 是挑選 skill 的清單，新加入的 WinUI skill 可以幫你做 Windows 程式的介面。
  • 00:32 coding agent 和內建終端機都可以切換到 WSL 裡執行，適合習慣用 Windows Subsystem for Linux 開發的人
    ↳ WSL 是 Windows 的一項功能，讓你在 Windows 裡面跑 Linux。coding agent 是負責寫程式的 AI，終端機是打指令的視窗，這兩個都可以切到 Linux 環境裡執行。
  • 00:32 可以從 Microsoft Store 或 openai.com/codex 下載，用現有的 ChatGPT 訂閱或 API key 登入
    ↳ 可以從 Microsoft Store 或 openai.com/codex 下載。有 ChatGPT 訂閱的話直接登入就能用。API key 是開發者用的通行碼，按使用量計費，也可以拿來登入。
📘 術語
Windows sandbox（Windows 沙箱）：新推出的專屬 Windows sandbox，Codex app 在裡面用 PowerShell 原生執行
skills（技能）：用來輕鬆找到並擴充 Codex 的能力
automations（自動化）：讓 Codex 在背景替你工作
work trees（工作樹）：用來在同一個專案裡處理多個獨立任務
WSL (Windows Subsystem for Linux)（Windows 的 Linux 子系統）：可以把 coding agent 和內建終端機切換到 WSL 裡執行

根據影片，Codex app 在 Windows 上原生執行時使用什麼？

A. 在 Docker 容器裡使用 BashB. 只能透過 WSL 執行C. 在雲端虛擬機器裡使用 Command PromptD. 在專屬 Windows sandbox 裡使用 PowerShell
