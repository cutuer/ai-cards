📘 術語
scheduled task（排程任務）：讓 ChatGPT 定期自動執行的任務，例如每個工作日寄送 daily brief，或每週 triage 回饋
daily brief（每日簡報）：ChatGPT 每個工作日寄送的摘要，讓人看出哪些事需要注意
triage（分類整理）：字幕中指彙整來自 Slack、Notion、Drive 的回饋，並產出每週摘要 Google Doc
onboarding（新人到職引導）：講者的工作範圍是 OpenAI 的技術 onboarding，同事會提出改善它的點子
Workspace Agent（工作區代理）：把本機 workflow 搬到雲端、以獨立 agent 執行，讓團隊能從 ChatGPT 或 Slack 使用
workflow（工作流程）：字幕舉例為回饋的 triage 流程，原本在本機（筆電）上執行
agent（代理）：由可重複任務轉成、能為你和團隊 24/7 持續工作的程式
