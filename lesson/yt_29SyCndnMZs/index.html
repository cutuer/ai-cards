🧑‍🏫 這支是 OpenAI 示範給公司管理員看的操作影片。ChatGPT Work 是影片裡用來操作的工作環境，在裡面裝一個叫 ChatGPT admin plugin 的外掛後，就能直接用聊天的方式查全公司的 AI 使用狀況，也能審核同事提出的額度申請。如果你負責管理公司的 ChatGPT 帳號，或想知道公司導入 AI 之後，管理那一端實際怎麼運作，看這支很快就能懂整個流程。

  • 00:00 日常管理 workspace 要整理大量資訊、判斷哪些事需要處理並採取行動，現在通常得在設定、分析和報表之間切換，手動作業很花時間
    ↳ workspace 是公司或團隊共用的 ChatGPT 帳號空間。管理員平常要看用量、找出問題、改設定，但資料分散在不同頁面，只能一頁一頁點開再自己整理，很花時間。
  • 00:00 ChatGPT admin plugin 把這些工作集中到單一對話中，讓你用既有的權限分析資訊、修改設定、處理申請
    ↳ plugin 就是額外加裝的功能，admin 是管理員的意思。裝了這個外掛，就能直接在聊天框裡查資料、改設定、處理申請。能做哪些事，跟你原本的管理員權限一樣。
  • 00:00 步驟一：在側邊欄進入 plugins 分頁
    ↳ 打開 ChatGPT 左邊的側邊欄，點進 plugins 分頁。這一頁專門用來找外掛、裝外掛。
  • 00:32 步驟二：搜尋 ChatGPT admin plugin 並安裝
    ↳ 在 plugins 分頁的搜尋框輸入 ChatGPT admin plugin，找到之後按安裝，就可以開始用了。
  • 00:32 情境：準備每月的 AI rollout review，在 Work 分頁提問
    ↳ rollout 指公司把 AI 工具一步步推廣給員工使用。影片的情境是管理員要做每月一次的導入成效檢討，所以到 Work 分頁，直接打字問問題。
  • 00:32 範例提示：顯示過去 30 天 ChatGPT、Codex、Work 三者的 adoption 變化，並依團隊比較 credit usage 變化，用兩張圖呈現並點出最大變化
    ↳ adoption 是用來看大家使用程度的指標。這裡請它比較 ChatGPT、Codex（OpenAI 寫程式用的 AI 工具）和 Work 近 30 天的變化，再按團隊比較 credit usage（額度用量），畫成兩張圖並標出變化最大的地方。
  • 00:32 結果可同時看到整體趨勢，以及推動這個趨勢的是哪些團隊
    ↳ 一張圖看全公司的使用量是增加還是減少，另一張看是哪些團隊造成的。這樣不只知道「用量變多了」，還知道「是哪些團隊讓它變多」。
  • 01:03 Finance 團隊增幅最大，於是追問原因，請它依產品、模型和 reasoning effort 視覺化拆解
    ↳ 圖上 Finance（財務）團隊增加最多，於是接著追問原因。請它按產品、模型和 reasoning effort 拆開畫圖。reasoning effort 是 AI 回答前要想多深，想得越深通常越耗用量。
  • 01:03 這樣拿到的是變化背後的原因，而不只是一個數字
    ↳ 只知道「財務用量暴增」還看不出該怎麼處理。拆開之後才知道是哪個產品、哪種設定造成的，才能判斷這是正常成長，還是需要調整。
  • 01:03 收尾：請它把圖表和重點更新進每月 AI rollout 簡報、加上簡短變化摘要，並分享到 AI rollout 的 Slack 頻道
    ↳ 分析完不用自己複製貼上。直接叫它把圖表和重點放進每月的導入簡報，補一段簡短的變化摘要，再分享到 Slack（很多公司在用的團隊聊天軟體）的 AI rollout 頻道。
  • 01:03 接著查看哪些額度申請（limit requests）需要處理
    ↳ 分析做完後換下一件事：看看有哪些同事申請提高使用額度，正在等管理員處理。
  • 01:33 範例提示：列出待審的 usage limits，包含目前用量、effective limit 和申請人提交的理由
    ↳ 請它列出所有待審的申請，每筆都附上申請人目前的用量、effective limit（字幕沒有解釋，字面意思是目前實際生效的上限），以及申請人寫的 justification，也就是申請理由。
  • 01:33 可在同一個對話中打開任一申請、查看前後脈絡，並核准或駁回
    ↳ 不用切到別的頁面，在同一個對話裡就能點開任何一筆申請，看完前因後果後直接核准或駁回。
  • 01:33 範例：打開目前用量最高的那筆申請，顯示它近期的趨勢和提議的額度
    ↳ 示範時先挑目前用量最高的那筆，請它顯示這個人最近的用量變化，以及申請要調到多少，方便判斷是不是真的需要。
  • 01:33 確認合理後，以提議的額度核准，並加註說明是為了即將到來的上線（launch）而核准
    ↳ 確認合理後，照申請的額度核准，並附上一句備註：這是為了對方即將上線（launch）的專案而核准的。之後有人回頭查，也知道當初為什麼批准。
  • 02:03 總結：用 ChatGPT admin plugin 在單一對話內完成分析與審核，不必在多個畫面之間拼湊資訊
    ↳ 整個流程的重點是：看數據、找原因、更新簡報、審核申請，全部在同一個對話裡完成，不用在好幾個畫面之間來回拼湊資料。
  • 02:03 影片呼籲安裝這個 plugin，把下一個管理任務帶到 ChatGPT Work
    ↳ 影片最後鼓勵管理員安裝這個外掛，下次有管理工作時，直接到 ChatGPT Work 裡用對話處理。
📘 術語
ChatGPT admin plugin（ChatGPT 管理員外掛）：把設定、分析、報表等管理工作集中到單一對話，用你原有的權限操作
ChatGPT Work（ChatGPT Work）：影片示範操作的環境，在其中的 Work 分頁下指令
plugins tab（外掛分頁）：側邊欄裡的分頁，用來搜尋並安裝 plugin
adoption（採用率）：影片用來觀察 ChatGPT、Codex、Work 過去 30 天使用變化的指標
credit usage（credit 用量）：影片中依團隊比較過去 30 天變化的使用量指標
reasoning effort（推理強度）：分析 Finance 用量增加時，用來拆解的其中一個面向（另外兩個是產品、模型）
usage limit / limit request（用量上限／額度申請）：待審的額度申請，可看目前用量、effective limit、理由，再核准或駁回
effective limit（實際生效上限）：查看待審申請時要求列出的欄位之一，字幕未進一步解釋
justification（申請理由）：申請人提交額度申請時附上的理由
