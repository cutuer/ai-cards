🧑‍🏫 這是 OpenAI DevDay 2026 主題演講的第一段。重點有兩個：一是會主動幫你做事、全天候運作的 AI 助手「dots」，二是讓人和 AI 一起工作的共用空間 ChatGPT Space。它講的是 AI 從「你問它才答」變成「它主動接手工作」，想了解 AI 接下來往哪走的人值得一看。

  • 00:18 開場：上次 DevDay 後推出了很多東西。開發者在 Twitter 上送出上千則改進建議，團隊盡量全部讀過並盡快處理
    ↳ OpenAI 開場先說，上次 DevDay 之後推出了不少新東西。開發者在 Twitter（現在叫 X）上送出上千則建議，團隊說盡量都讀過，並盡快處理。
  • 00:18 應開發者要求，Codex 已推出 Linux 版
    ↳ Codex 是 OpenAI 幫人寫程式的 AI 工具。現在推出 Linux 版。Linux 是很多工程師和伺服器在用的作業系統，所以能用 Codex 的地方又多了一個。
  • 00:53 應開發者要求，一個 Codex 專案現在可以同時跨多個資料夾運作
    ↳ 一個 Codex 專案現在可以同時處理好幾個資料夾。程式或資料分散在不同地方時，不用拆成好幾個專案分開跑。
  • 00:53 應開發者要求，Codex 已推出手機版
    ↳ Codex 推出手機版，不在電腦前也能用手機操作它。
  • 00:53 接下來的產品是大家最常要求的東西之一。官方形容它是和 AI 工作的全新方式，像電影裡那種一直挺你的 AI 助手
    ↳ 接下來要發表的是大家最常許願的東西。官方拿電影裡那種隨時在身邊的 AI 助手來比，意思是它不只是回答問題的工具，而是一直在旁邊幫你的角色。
  • 01:27 目標是 24/7 工作，接手你不想做的事，讓你專注在更高層次的工作
    ↳ 目標是全天候運作。你不想做的雜事交給它，自己把力氣留給需要判斷和思考的事。
  • 01:27 訂位、買機票這類虛擬助理雖然有用，但和技術能做到的相比很瑣碎，所以這次想更有野心
    ↳ 訂位、訂機票的 AI 助理有用，但官方認為這只用到 AI 能力的一小部分。這次想做的是能接更大、更複雜工作的東西。
  • 01:27 理想中的 AI 知道發生了什麼、知道什麼對你重要，不必交代每件小事，不用開口就會替你做好
    ↳ 理想中的 AI 自己掌握狀況，也知道你在乎什麼。所以你不用一件件交代，甚至還沒開口，它就先處理好了。
  • 02:03 發表 dots：能力很強的 always-on agents，能處理幾乎任何事。它把 AI 帶進新的 form factor，讓你有更多時間與注意力
    ↳ dots 是新產品。agent 指能自己動手完成任務的 AI，always-on 是一直開著、持續工作。form factor 原指產品形態，這裡是說用 AI 的方式變了。
  • 02:46 示範影片：dot 是 ChatGPT 的新功能，可以替它取名（示範中取名 Alfred）。遇到重要事項時，它會先請你核准
    ↳ 示範影片裡，dot 是 ChatGPT 的新功能，可以幫它取名，示範中叫 Alfred。碰到重要的事，它會先問你同不同意，才動手。
  • 02:46 示範工作一：dot 依照已核准的設計，準備秋季上線的網站；並依 Teams 上新進的 consumer experience 數據更新董事會簡報
    ↳ 第一件工作：它照已核准的設計，準備秋天要上線的網站。又根據 Teams（微軟的團隊通訊軟體）上新進的使用者體驗數據，更新董事會簡報。
  • 03:17 示範工作二：dot 依 Google Meet 筆記規劃 app migration。使用者要求它先拿每個 flow 對照現有產品檢查，再交給他審查
    ↳ 第二件：它依 Google Meet 會議筆記，規劃把 app 搬到新系統（migration）。使用者要它先把每個操作流程（flow）和現有產品對照檢查，再交給他看。
  • 03:17 示範工作三：婚禮蛋糕廠商取消，dot 已找好備案，並安排週六上午 11 點試吃
    ↳ 第三件是私事：婚禮蛋糕廠商取消了，dot 已經找好替代廠商，還排好週六早上 11 點試吃。工作和生活的事它都能接。
  • 04:00 網站更新後，使用者要求把第一張和第三張照片對調，dot 調整後直接發布上線
    ↳ 網站更新後，使用者只說了一句「第一張和第三張照片對調」，dot 就改好並直接發布上線。
  • 04:00 董事會簡報顯示產品使用量上升、營收年增 51%。使用者要求改成先講 consumer experience，再講成長數字
    ↳ 簡報顯示使用量上升，營收比去年成長 51%。使用者要它調整順序，先講使用者體驗，再講成長數字，就像跟助理交代改簡報一樣。
  • 04:00 app 重建版在測試中變快，目前沒發現 regressions，預覽和結果放在 PR 裡。使用者請 dot 把結果分享到 Slack，並準備好 stage rollout 等他核准
    ↳ 重建的 app 測試變快，也沒有 regressions（改版後舊功能壞掉）。結果放在 PR（交給團隊審的程式修改）裡。他請 dot 貼到 Slack，並備好分批上線（stage rollout），等他核准。
  • 04:33 dot 在報名一開放就幫孩子報好課後課程；發現財務會議和女兒的發表會撞期，主動協調改期
    ↳ 生活上，課後課程一開放報名，dot 就幫孩子報好名。它也發現財務會議和女兒的發表會撞期，主動去協調改時間。
  • 05:05 使用者心得：dot 會隨時間了解他的工作方式和想關注的事，會先看過夜間進來的東西，早上提醒緊急事項
    ↳ 使用者說，dot 用久了會越來越懂他的做事方式和在意的事。半夜進來的訊息它會先看過，早上只提醒他緊急的。
  • 05:05 使用者表示自己拿回了一些注意力，不再像以前那樣沉迷手機
    ↳ 他覺得自己拿回了一些注意力，不再像以前那樣一直黏著手機。
  • 05:37 dots 可以處理小事，例如機票、晚餐時間、拖延已久的居家裝修
    ↳ 小事也能交給它，像訂機票、約晚餐時間，或一直拖著沒處理的居家裝修。
  • 05:37 dots 由 Astra 驅動，因此能委派有野心的工作，就像交給 high agency engineer 或 chief of staff
    ↳ Astra 是驅動 dots 的 AI 模型。官方說因為它夠強，你能交付有挑戰的工作，就像交給很主動的工程師，或幫主管統籌大小事的幕僚長。
  • 05:37 可委派的責任舉例：監控 bug reports、測試修正並草擬 PR；啟動明年預算規劃並追蹤各團隊進度；找出 app 變慢的原因、修好並展示快了多少
    ↳ 能交出去的是一整段責任，不是單一指令。例如盯錯誤回報、測試修正、草擬程式修改；啟動明年預算規劃並追進度；查出 app 變慢的原因、修好並證明快了多少。
  • 06:10 範例：在舊 API 停用前讓 app 脫離 legacy API。難點是 API 可能散布整個 codebase，改了不知道會壞什麼
    ↳ API 是程式之間溝通用的介面。範例是舊 API（legacy API）快停用了，要讓 app 換掉它。難在它可能散在整套程式碼（codebase）各處，改了不知道哪裡會壞。
  • 06:10 dots 能追蹤相依性、找出所有要改的地方，並寫 code、跑測試，把 pull request 交給團隊審查
    ↳ dots 會追蹤 dependencies（哪些程式依賴哪些），找出所有要跟著改的地方。接著寫程式、跑測試，最後整理成 PR 交給團隊審查，由人做最後把關。
  • 06:41 dots 會依照你的存取權限運作，擁有自己的雲端電腦和瀏覽器，可以視需要寫程式、測程式
    ↳ dots 只能動你本來就有權限的東西。它有自己的雲端電腦和瀏覽器，需要時可以自己寫程式、測程式。
  • 06:41 今天可以先從一個 dot 開始，未來可以和一整隊 dots 合作
    ↳ 現在可以先從一個 dot 開始用。之後的方向是和一整隊 dots 合作，各自處理不同的事。
  • 06:41 即將推出：不必在 ChatGPT 裡也能傳簡訊給 dot。它會用簡訊回覆、報告進度、提醒變動，或請你做決定
    ↳ 即將推出：不用打開 ChatGPT，直接傳簡訊給 dot。它也會用簡訊回你、報進度、通知變動，或請你做決定。
  • 07:12 也可以直接打電話給 dot 和它對話
    ↳ 也可以直接打電話給 dot，用講的跟它溝通。
  • 07:12 dots 可與 ChatGPT 上超過 4,000 個 apps 合作。onboard 時會沿用你已連接的 plugins，跟著你在各處的工作走
    ↳ dots 能搭配 ChatGPT 上 4,000 多個 apps。onboard（第一次設定）時會沿用你已連接的 plugins（讓 ChatGPT 接上其他服務的外掛），你在哪個工具工作它都跟得上。
  • 07:12 控制權在你手上：Astra 是 OpenAI 最 aligned 的模型，內建保護與 safeguards
    ↳ 官方強調主控權在你。aligned 指 AI 的行為符合人的意圖和規範，他們說 Astra 是自家最 aligned 的模型，而且內建保護機制（safeguards）。
  • 07:12 你可以設定 app 與 computer use 的邊界，也能為 dot 的任何動作自訂指令，依自己的信任程度交付責任
    ↳ computer use 指 AI 直接操作電腦，像點按鈕、打字。你可以限制它能用哪些 app、能操作電腦到什麼程度，也能為任何動作寫規則，信任多少就交多少。
  • 07:45 dots 和個人的 context、工作流程緊密綁定，但團隊也需要協作空間。問題是幾乎所有生產力軟體都不是為 AI 和人協作設計的
    ↳ dots 綁著你個人的 context（它對你狀況的了解）和工作流程，但團隊也需要一起工作。官方指出，現有的生產力軟體幾乎都是設計給人用的，沒考慮 AI 一起參與。
  • 07:45 發表 ChatGPT Space：讓你、隊友和 agents 一起工作的地方
    ↳ ChatGPT Space 是新的共用工作區。你、同事和 AI agents 在同一個地方一起做事。
  • 07:45 Space 從一個 page 開始，可以在裡面寫計畫、做研究、做圖片、產生資料或建構新東西
    ↳ Space 的起點是 page（頁面），像一份空白文件。你可以在裡面寫計畫、查資料、做圖、產生資料，甚至直接做出新東西。
  • 08:17 dots 可直接在 page 裡和你一起工作，例如請它追蹤相依性；在 comment 裡 tag dot，它就會開始動工
    ↳ dots 可以直接在 page 裡幫忙，例如追蹤相依關係。在留言（comment）裡 tag 它，就跟 tag 同事一樣，它就會開始做。
  • 08:17 page 和檔案像放在 drive 裡一樣集中在 Space。可以給 page 指令，例如每天檢查 API platform 的 Slack channel 並把發現更新到 page
    ↳ page 和檔案都集中在 Space 裡，像放在雲端硬碟一樣。還能給 page 固定指令，例如每天去看某個 Slack 頻道，把新發現更新到頁面上。
  • 08:17 即將推出：在 Space 內直接做簡報，和團隊、你的 dot、他們的 dots 一起協作
    ↳ 即將推出：在 Space 裡直接做簡報。你、團隊、你的 dot 和同事們的 dots，可以一起編同一份。
  • 08:49 這個簡報功能是 agents 容易讀取和修改的 slides 版本
    ↳ 這是為 AI 設計的投影片格式。agents 讀得懂內容，也能直接動手改，不是只有人能編。
  • 08:49 OpenAI 產品團隊的 Holly 上台 Demo，用虛構的音樂 app「Blossom」示範 OpenAI 團隊怎麼用 dots，並提到 dots 也改變了他們打造產品本身的方式
    ↳ OpenAI 產品團隊的 Holly 上台，用虛構的音樂 app「Blossom」示範團隊怎麼用 dots。她也提到，dots 改變了他們自己做產品的方式。
  • 09:21 Blossom Music 是虛構的歌單製作 app；Holly 的 dot 叫 Dotty（字幕後段拼作 Dodi）
    ↳ Blossom Music 是虛構的歌單製作 app，只是拿來示範。Holly 的 dot 叫 Dotty，字幕後段拼成 Dodi，指的是同一個。
  • 10:00 dots 可以加上 connectors，也可以加進 Slack。Holly 說 Dodi 是她的第二雙眼睛，更是能實際接手工作的第二雙手
    ↳ connectors 是讓 dot 接上外部服務的連接器，dot 也能加進 Slack。Holly 說 Dodi 不只幫她盯著狀況，還能真的把工作接過去做。
  • 10:00 Demo 情境：Blossom Music 明天上線。Dodi 發現 launch review 提前後已自動更新行事曆，也已看過昨晚新功能的測試用戶回饋
    ↳ 情境是 Blossom Music 明天上線。launch review（上線前的審查會議）提前了，Dodi 已經自己改好行事曆，也看完昨晚測試用戶對新功能的回饋。
  • 10:30 Dodi 發現設計團隊臨時修改了首頁，主動把設計送給 Holly 看
    ↳ 設計團隊臨時改了首頁。Dodi 發現後，主動把新設計拿給 Holly 看。
  • 10:30 因為 Dodi 能存取這台筆電和它的 dev tools，Holly 直接叫它把新設計做出來，讓她可以實際操作
    ↳ Dodi 能使用這台筆電和上面的開發工具（dev tools），所以 Holly 直接叫它把新設計做成可以點、可以用的版本，讓她實際操作看看。
  • 11:01 Holly 最喜歡的是 Voice。她說講話幫助思考，而 Dodi 已知道她是誰、在做什麼、為什麼，所以能直奔重點，像第二個大腦
    ↳ Holly 最愛語音功能（Voice）。她說邊講邊想比較順。Dodi 已經知道她是誰、在做什麼、為什麼做，不用從頭解釋，可以直接切入重點。
  • 11:33 現場語音 Demo：請 Dodi 整理昨晚的 user testing，但它一直回應「還在檢查」
    ↳ 現場用語音請 Dodi 整理昨晚的 user testing（請真實用戶試用並收集意見），但它一直回答「還在檢查」，當場沒有拿到結果。
  • 12:04 Holly 改請 Dodi 在 page 裡放一份 FAQ，供她稍後審閱 go-to-market leads 時用
    ↳ Holly 改請 Dodi 在 page 裡放一份 FAQ（常見問答）。她等一下和 go-to-market（負責產品上市推廣）的主管們審查時會用到。
  • 12:34 Space 裡輸入 slash，會列出可建立的東西：互動圖表、sheets、live prototypes 等
    ↳ 在 Space 打一個斜線「/」，會跳出可以建立的東西，例如互動圖表、試算表（sheets），以及 live prototypes（可以實際點擊操作的產品雛形）。
  • 12:34 在 Space 裡可以 tag 隊友（如 Rennie、Rishab），也能 tag Dodi 本身
    ↳ 在 Space 裡可以 tag 同事，例如 Rennie、Rishab，也能 tag Dodi，把它當成團隊的一員來叫。
  • 13:06 Holly 請 Dodi 把資料轉成長條圖。Space 裡的視覺化是動態的，可依回饋類型篩選，也可檢視個別資料點
    ↳ Holly 請 Dodi 把資料轉成長條圖。Space 裡的圖是動態的，可以依回饋類型篩選，也能點進去看單筆資料，不是一張固定的圖片。
📘 術語
dots（dots（ChatGPT 的 agent））：能力很強、always-on 的 agents，能處理幾乎任何事，有自己的雲端電腦和瀏覽器
always-on agent（隨時運作的代理）：24/7 工作，接手你不想做的事，不必你開口就主動處理
form factor（產品形態）：字幕說 dots 把 AI 帶進全新的 form factor 來工作
Astra（Astra（模型名））：驅動 dots 的模型，字幕稱它是 OpenAI 最 aligned 的模型
legacy API（舊版 API）：即將停用的舊 API，可能散布整個 codebase，改動時不易知道會壞什麼
dependencies（相依性）：dots 能追蹤相依性，找出所有需要跟著改的地方
PR / pull request（拉取請求）：dots 寫好 code、跑完測試後交給團隊審查的變更
regressions（回歸問題）：字幕中提到重建版在測試裡「沒發現 regressions」
stage rollout（分階段上線）：使用者請 dot 準備好，等他核准後才執行
plugins（外掛）：你已連接的 plugins，dot onboard 時可以沿用
connectors（連接器）：字幕提到 dots 可以加上 connectors
computer use（電腦操作）：你可以為 dot 設定 app 與 computer use 的邊界
ChatGPT Space（ChatGPT 協作空間）：讓你、隊友和 agents 一起工作的地方，從 page 開始
page（頁面）：Space 的起點，可寫計畫、做研究、做圖、產生資料，也可給它每日更新之類的指令
live prototypes（可互動原型）：在 Space 輸入 slash 後可建立的項目之一
high agency engineer / chief of staff（高度自主的工程師／幕僚長）：字幕用來比喻：委派給 dots 就像委派給這類人
