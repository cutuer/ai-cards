🧑‍🏫 這支是 OpenAI 介紹 ChatGPT work 的影片，主題是行銷點子怎麼更快變成成品。講者先講行銷工作正在發生的三個改變，再示範 ChatGPT 怎麼接上你平常用的工具、直接幫你把事情做出來。最後他提醒，工具越方便，人的判斷力越重要。這一點對所有會用 AI 的人都適用。

  • 00:03 講者表示現在人人都參與行銷，engineering、product、finance 團隊都會提出行銷點子
    ↳ 講者說行銷已經不只是行銷部的事。engineering（寫程式的工程團隊）、product（規劃產品的團隊）、finance（管錢的財務團隊）也都會提出行銷點子。
  • 00:03 其他團隊不只傳文字訊息說「這是好點子」，而是帶著圖片和創意構想來找行銷團隊
    ↳ 其他團隊不再只傳一句「這點子不錯」就結束，而是直接帶著圖片和畫好的構想來找行銷部。點子一提出來，就已經有初步的樣子了。
  • 00:03 好點子從誕生到實作的距離正在縮短
    ↳ 以前一個點子要排時程、找人做，常常拖很久。現在想到之後很快就能做出東西，從點子到成品的等待越來越短。
  • 00:03 例子：講者早上和 Chad 在餐廳吃早餐時聊到點子，到午餐時間 Chad 就做出投影片形式的版面，可能午餐前就完成
    ↳ 講者早餐時跟同事 Chad 聊到一個點子，還沒到午餐，Chad 就做出了投影片版面。從想到點子到做出成品，只隔了半天。
  • 00:34 ChatGPT work 是使用 ChatGPT 的新方式，把熟悉的問答機器人變成「世界上最聰明的個人助理」
    ↳ ChatGPT work 是使用 ChatGPT 的新方式。以前是你問它答，現在它更像會幫你辦事的助理，影片形容它是「世界上最聰明的個人助理」。
  • 00:34 示範從 chat 模式切換到 work 模式，tooltip 會展開並顯示 plugins
    ↳ 示範一開始在 chat 模式（平常一問一答的聊天）。切換到 work 模式後會展開 tooltip（跳出來的小提示框），裡面列出 plugins（外掛連接器，下一條會說明）。
  • 00:34 打開左側的 catalog 可以看到 plugins，講者說可以把它當成了解 ChatGPT 如何運作的入門介紹
    ↳ 打開畫面左側的 catalog（目錄清單），可以看到所有 plugins。講者建議先逛一遍，等於快速認識 ChatGPT 能接上哪些東西、是怎麼運作的。
  • 00:34 plugins 基本上就是 ChatGPT 這個助理連接你所有 contacts 的方式
    ↳ plugins 就是讓 ChatGPT 這個助理連上你所有 contacts（影片原話，指你工作上往來的各種服務和資料）的管道。接上之後，它才碰得到你的東西。
  • 01:04 可連接的服務從最簡單的 Google Drive、Microsoft Office，到 email、行事曆，甚至 Figma、Canva、Notion 等專業 app
    ↳ 能連接的服務，從最基本的 Google Drive（雲端硬碟）、Microsoft Office（Word、Excel 那套），到 email、行事曆，甚至 Figma、Canva（設計工具）、Notion（筆記協作工具）。
  • 01:04 因為 plugins 連接你的工作流程，ChatGPT 能在你的 workflows 裡運作，這是 ChatGPT work 與一般 ChatGPT 真正不同之處
    ↳ 這是最關鍵的差別。一般 ChatGPT 只在對話框裡回答你；work 模式透過 plugins 接進你的 workflows（平常做事的流程和工具），直接在裡面幫你做事。
  • 01:04 ChatGPT work 能依照你的範本製作簡報、投影片、試算表和文件
    ↳ 它能照著你現成的範本，做出簡報、投影片、試算表和文件，不用從一張白紙開始。
  • 01:04 ChatGPT work 也能生成圖片、開發應用程式
    ↳ 除了文件，ChatGPT work 也能直接生成圖片，甚至幫你開發應用程式（app，也就是可以實際操作使用的小程式）。
  • 01:04 ChatGPT work 甚至能依排程，在你的電腦或瀏覽器上自動化重複性工作
    ↳ 它還能照你設定的時間表，在你的電腦或瀏覽器上自動做重複性的工作。像每週都要做一次的例行整理，就可以交給它定時處理。
  • 01:34 ChatGPT work 也能建立網站，講者表示會展示相關 demo
    ↳ ChatGPT work 也能幫你建立網站，講者說後面會實際示範。
  • 01:34 組織各處都有好點子，加上點子落地比以往更快，兩者結合帶出影響行銷主管與行銷從業者的第三個現象
    ↳ 講者把前兩個現象串起來：好點子到處都有，點子又能很快做出來。兩者加在一起，帶出第三個會影響行銷主管和行銷人員的現象。
  • 01:34 第三個現象：基本功比以往任何時候都更重要
    ↳ 第三個現象是：基本功比以前任何時候都重要。工具越強，越考驗你懂不懂行銷本身。
  • 01:34 在點子多、實現點子又比以往更容易更便宜的世界，我們更需要自己的判斷力
    ↳ 當點子到處都是，做出來又快又便宜，「做得出來」就不稀奇了。真正難的是判斷哪些值得做，這要靠人自己的判斷力。
  • 02:04 這份判斷力用來了解該提供使用者什麼，並確保以顧客為中心、考量顧客的觀點
    ↳ 這份判斷力用來搞清楚該給使用者什麼，並做到 customer-centric（以顧客為中心），也就是先從顧客的角度想，而不是自己覺得好就做。
  • 02:04 講者觀察到行銷人員表現更好，因為與 ChatGPT 一起工作而得到更好的訓練，被推著用需求導向思考
    ↳ 講者觀察到行銷人員反而變強了。跟 ChatGPT 一起工作就像一種訓練，會推著人用 demand orientation（需求導向，先問對方需要什麼）來思考。
  • 02:04 重點不只是做得更快或減少官僚流程，而是做出更好的行銷，這才是真正推動業務前進的力量
    ↳ 最終目標不只是做得更快、少跑一些公司流程，而是做出更好的行銷，因為真正推動生意前進的是行銷做得好不好。
📘 術語
ChatGPT work（ChatGPT 工作模式）：使用 ChatGPT 的新方式，把問答機器人變成個人助理，能在你的工作流程中運作
chat mode（聊天模式）：影片示範時一開始所在的模式，之後切換到 work
plugins（外掛程式）：ChatGPT 這個助理連接你所有 contacts 的方式，例如 Google Drive、Figma、Notion
catalog（目錄）：畫面左側可打開的清單，列出 plugins，可當作了解 ChatGPT 如何運作的入門
tooltip（提示框）：切換到 work 模式後會展開並顯示 plugins
workflows（工作流程）：plugins 連接到你的工作流程，讓 ChatGPT 能在其中運作
customer-centric（以顧客為中心）：確保考量顧客的觀點，決定該提供使用者什麼
demand orientation（需求導向）：與 ChatGPT 一起工作會推動行銷人員用這種方式思考
