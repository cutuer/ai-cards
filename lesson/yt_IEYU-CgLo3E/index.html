🧑‍🏫 這支是 OpenAI 財務技術負責人 Way Loh 分享他們財務部門怎麼用 Codex。重點不是寫程式，而是把月結、簡報、報表這類又雜又常重複的工作整理成固定流程。如果你常被每個月都要重做一次的工作卡住，這支很有參考價值。

  • 00:02 Codex 已是核心工作流程中不可或缺的工具，不只是小眾工具，也不只用來寫程式
    ↳ Codex 是 OpenAI 推出的 AI 工具，原本以幫忙寫程式出名。影片強調，在 OpenAI 內部，它已經是日常工作流程（一連串固定做事的步驟）裡少不了的工具，用途也不只寫程式。
  • 00:02 講者 Way Loh 在 OpenAI 領導 finance technology（財務技術）；本片屬於「OpenAI on OpenAI」系列
    ↳ Way Loh 負責 OpenAI 的 finance technology，也就是替財務部門打造系統和工具。從系列名稱「OpenAI on OpenAI」來看，這是 OpenAI 分享自家團隊怎麼用自家產品的系列。
  • 00:02 用 Codex 建立 skills，讓其他 Codex 工作流程使用
    ↳ skills 可以想成把某件事的做法整理好、打包起來，讓其他 Codex 工作流程直接拿去用，不用每次從頭交代一遍。
  • 00:02 用 Codex 建立跨 finance、procurement、accounting（財務、採購、會計）的內部 app
    ↳ procurement（採購）是公司買東西、找廠商的流程，accounting（會計）是記帳和整理帳目。他們用 Codex 做出只給公司內部用的 app，同時服務這幾個部門。
  • 00:02 也用 Codex 處理較簡單的任務，例如製作簡報和備忘錄（memo）
    ↳ 不只大工程用得上。做簡報、寫 memo（內部備忘錄，用來說明事情或提建議的短文件）這種日常小事，他們也交給 Codex 處理。
  • 00:02 財務部門的用途：month-end（月結）、主管簡報（executive slides）
    ↳ month-end（月結）是每月底把當月帳目核對、結清，步驟多又趕時間；executive slides 是給高層看的簡報。這兩件事都用到 Codex。
  • 00:32 財務部門的用途：客製化儀表板（custom dashboards）、廠商風險審查（vendor risk reviews），以及協助準備分錄（journal entry）
    ↳ custom dashboard 是照需求做的數據看板；vendor risk review 是評估合作廠商可不可靠；journal entry（分錄）是把交易記進帳本的紀錄，Codex 幫忙先準備好。
  • 00:32 最主要的價值是用 Codex 把雜亂的工作流程變成可重複的工作流程，也帶來許多新的可能
    ↳ 最大價值是把原本每次做法不一、靠人記步驟的雜事，變成可以照著重複跑的固定流程。流程整理好以後，還能延伸出很多以前沒想過的用法。
