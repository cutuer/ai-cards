🧑‍🏫 這支影片示範行銷人員怎麼用 Codex（OpenAI 的 AI 助理工具）搭配 Creative Production plugin，把產品上市需要的圖片一路做成文宣和廣告。值得看的地方是：生圖、改細節、換風格都可以用講的交代，最後還能把成品丟進 Canva 繼續改。

  • 00:00 OpenAI Creative Production plugin 的定位：幫助行銷專業人員改變工作方式
    ↳ Creative Production plugin 是加裝在 Codex 上的外掛（plugin＝額外裝上去的功能包），專門給行銷人員用，目的是改變他們做宣傳素材的方式。
  • 00:00 範例情境：一位行銷人員請 Codex 和 plugin 幫忙，為即將上市的產品製作圖片
    ↳ 情境很日常：產品快要上市了，行銷人員請 Codex 和這個外掛幫忙，生出宣傳要用的產品圖片。
  • 00:00 第一步：先說明希望圖片呈現的外觀與風格（look and feel）
    ↳ 動手前先講清楚 look and feel，也就是整體的感覺和風格，例如要明亮清爽還是暗調高級，AI 才知道要往哪個方向做。
  • 00:00 幾分鐘內就能生成圖片，之後還能繼續用 Codex 和 plugin 修改
    ↳ 交代完，幾分鐘就有圖。不滿意也不用從頭來，可以接著跟 Codex 說要改哪裡，一輪一輪慢慢調。
  • 00:00 可以直接在圖片上加註解（annotate）來調整圖片細節
    ↳ annotate 就是直接在圖上圈出來、寫註記，指出「這裡要改」。比只用文字描述更清楚，AI 比較不會搞錯你講的是哪一塊。
  • 00:00 註解範例：讓圖片變成拍攝過程中早幾秒的畫面
    ↳ 影片裡的例子是在圖上註明「改成拍攝時早幾秒的畫面」，等於把時間往回倒一點，讓圖片呈現另一個瞬間。
  • 00:31 好處：不必靠拍攝當下剛好拍到完美的照片，可以用 Codex 和 plugin 修到想要的樣子
    ↳ 以前要靠拍攝當下剛好按到完美的那一刻，現在就算拍得不夠理想也沒關係，事後可以用 Codex 和外掛修成想要的樣子。
  • 00:31 用 plugin 的 remix 功能，改變整組圖片中某一張的外觀與風格
    ↳ remix 是這個外掛的功能之一，可以在一整組圖片裡只挑其中一張，改掉它的外觀和風格。
  • 00:31 創意人員從中挑出喜歡的一組圖片，作為這次活動的素材
    ↳ 創意人員從產出的結果裡，挑出最喜歡的一組圖片，定為這次活動正式要用的素材。
  • 00:31 接著請 Codex 和 plugin 用這些圖片，為這次上市製作文宣（brochure）或展示型廣告（display ads）
    ↳ 素材定好後，再請 Codex 用這些圖做 brochure（宣傳小冊子、DM）或 display ads（網站、App 上常見的圖片型廣告）。
  • 01:04 送出 prompt 後，幾分鐘內就得到要求的成果
    ↳ 把需求寫成 prompt（給 AI 的文字指令）送出去，幾分鐘內就拿到要求的文宣或廣告。
  • 01:04 行銷人員可以瀏覽生成的多份文宣，挑一份喜歡的，再拿到其他工具繼續編輯
    ↳ 會一次產出好幾份文宣讓你瀏覽，挑一份喜歡的，再拿到其他工具繼續編輯，不必期待 AI 一次就做到完美。
  • 01:04 示範中 Codex 已連接 Canva，可以直接在 Canva 裡建立這張圖
    ↳ Canva 是常見的線上設計工具。示範中 Codex 已經和 Canva 連上，所以可以直接在 Canva 裡把這張圖做出來。
  • 01:04 在 Canva 裡產生的不只是一張圖，而是由多個元件組成、可以編輯的檔案，方便精準做出這則廣告想要的風格
    ↳ 在 Canva 裡拿到的不是一張死死的圖，而是由很多元件組成的檔案，像文字、圖片可以分開移動或修改，方便把廣告調成想要的樣子。
📘 術語
Creative Production plugin（創意製作外掛）：搭配 Codex 使用的 plugin，幫助行銷人員生成、修改圖片並製作文宣與廣告
look and feel（外觀與風格）：影片中生成圖片前要先說明的圖片風格，也可以用 remix 功能改變
annotate（註解標記）：直接在圖片上加註解，指定想修改的地方，例如變成拍攝中早幾秒的畫面
remix（重新混製）：plugin 的功能之一，用來改變整組圖片中某一張的外觀與風格
brochure（宣傳手冊／文宣）：用挑選好的圖片請 Codex 與 plugin 製作的上市宣傳品之一
display ads（展示型廣告）：和文宣並列，可請 Codex 與 plugin 為產品上市製作的廣告素材
Canva（Canva）：示範中與 Codex 連接的工具，可以在裡面產出由多個元件組成、可編輯的檔案
