🧑‍🏫 這支影片由 OpenAI 的資料分析師示範，怎麼用 ChatGPT Work（影片裡的工具，可以蒐集資料、分析變化、寫報告，還能設定固定時間自動執行）把每週的產品指標報告交給 AI 準備。以前要花好幾小時的例行報告，現在變成每週一早就有草稿可以看。如果你每週也得交固定格式的報告，這支影片幾分鐘就能看完整套做法。

  • 00:04 每週四早上，ChatGPT Work 會準備好一份準確的報告，等講者審閱
    ↳ AI 不會自己把報告發出去。它會在每週固定時間把報告準備好，人再來檢查、確認沒問題。最後把關的還是人。
  • 00:04 ChatGPT Work 會蒐集最新產品指標、解釋與上週相比的變化、更新圖表，並草擬一則給團隊的 Slack 訊息
    ↳ 一份週報其實有四件事：抓最新數字、比上週差在哪並說明原因、把圖表換成新資料、寫好通知同事的訊息。Slack 是很多公司用的團隊聊天工具。
  • 00:04 講者 Unji 是 OpenAI 的 data analyst，主要工作之一是準備週報，描述產品狀態與一週內的變化
    ↳ data analyst（資料分析師）的工作是整理數字，從中看出狀況。講者每週要告訴團隊兩件事：產品現在表現如何，這一週哪裡有變化。
  • 00:04 在使用 ChatGPT Work 之前，這份週報每週要花講者 3-4 小時
    ↳ 每週 3~4 小時，一個月下來大約十幾個小時，都花在重複性很高的整理工作上。這就是值得交給 AI 的原因。
  • 00:04 如果你是 data scientist 或工作需要處理報告，可以照以下步驟開始
    ↳ data scientist（資料科學家）是用數據做分析和預測的人。不過不一定要有這個職稱，只要你每週得交固定的報告，就能參考這套流程。
  • 00:35 步驟一：進入 ChatGPT Work，可以用桌面應用程式或網頁版
    ↳ 桌面應用程式是裝在電腦上的軟體，網頁版是用瀏覽器打開。兩種都能用，挑你習慣的就好。
  • 00:35 步驟二：從 Google Drive 連接資料
    ↳ Google Drive 是 Google 的雲端硬碟。先把它連上，ChatGPT Work 才讀得到你存在裡面的數據資料。
  • 00:35 步驟三：安裝 data analysis plugin，幫助 ChatGPT 做出更好的視覺化圖表與報告
    ↳ plugin（外掛）是額外裝上去、用來增加功能的小工具。這個專門做資料分析的外掛，能讓圖表和報告做得更清楚好讀。
  • 00:35 步驟四：加入關鍵指標（key metrics）、目標，以及一份你需要的報告範例
    ↳ key metrics（關鍵指標）就是你最在意的那幾個數字。再加上目標和一份範例，它就知道該看什麼、跟什麼比、報告要長成什麼樣子。
  • 00:35 步驟五：審閱第一份報告，並做必要的調整
    ↳ 第一次產出的報告不一定完全合用。你要自己看過，把不準或不符合需求的地方指出來，讓它修正到你要的樣子。
  • 00:35 步驟六：對結果滿意後，設定為每週四自動執行
    ↳ 格式和內容都確認沒問題，再讓它定時自動跑。先調好再自動化，才不會每週收到一份還得大改的報告。
  • 01:09 ChatGPT Work 搭配 data analysis plugin 會處理整個每週流程：載入當週指標、分析變化趨勢、找出主要因素，並用數字說出背後的故事
    ↳ 它不只列出數字，還會判斷趨勢往上還是往下，找出造成變化的主要原因，再用文字說清楚這些數字代表什麼。
  • 01:09 以前要花好幾個小時的工作，現在可以直接從一份完成的草稿開始
    ↳ 你不用從一片空白開始整理，拿到的是已經寫好的草稿。你的工作變成檢查和修改，最花時間的整理階段就省下來了。
  • 01:09 因為設定成週期性流程（recurring process），每週四早上報告就已經準備好等著講者
    ↳ recurring process（週期性流程）指的是設定一個固定時間讓它重複執行。只要設定一次，每週四早上報告就會自己出現，不用每次重新下指令。
📘 術語
