🧑‍🏫 這支影片介紹 Codex（OpenAI 的 AI 助理工具）的「Record & Replay」功能。意思是先把你的操作錄下來，之後讓它照著重做。你只要實際做一次給它看，它就能學會整套流程，下次自己完成。值得看的原因是，教 AI 做事不必再寫一大段指令，直接示範就好，不寫程式的人也用得上。

  • 00:00 現在可以示範給 Codex 看怎麼做一件事、教它你的偏好，並把它學到的內容變成可重複使用的 skill
    ↳ 「skill」是 Codex 學會後可以重複使用的一套做事方法。以前要用文字一條條交代，現在直接做給它看，它就會把步驟和你的習慣一起存下來。
  • 00:00 範例情境：團隊每次發布 YouTube 影片都走固定流程
    ↳ 影片拿「發布 YouTube 影片」當例子。這種每次步驟都一樣、做久了很煩的例行工作，最適合交給它。
  • 00:00 手動做法：從發布用的 spreadsheet 拉 metadata、找對應的素材，再到 YouTube Studio 逐一處理同樣的欄位與設定
    ↳ 手動時，要先從 spreadsheet（試算表）抄出 metadata（標題、描述等影片資訊），再找齊素材，然後到 YouTube Studio（YouTube 發影片的後台）一格格填寫、一項項設定。
  • 00:00 這次讓 Codex 看著使用者操作，藉此學會團隊的做法
    ↳ 這次不寫說明書，而是讓 Codex 在旁邊看你實際操作，從你的做法學會你們團隊的規矩。
  • 00:00 示範過程：填入標題與描述，加上 thumbnail 和英文字幕，最後將影片儲存為 private
    ↳ 示範內容是填好標題和描述，加上 thumbnail（影片縮圖）和英文字幕，最後存成 private（不公開）。這些細節就是它要學的偏好。
  • 00:30 操作完成後，Codex 會檢視錄下來的過程，把學到的內容轉成一個 skill
    ↳ 做完之後，Codex 會回頭看剛剛錄下的操作過程，整理成一份 skill。等於把你的示範變成它自己的作業流程。
  • 00:30 這個 skill 記住了 metadata 放在哪裡、上傳包怎麼整理，以及怎麼加字幕、儲存並驗證每次上傳
    ↳ 它記下的不只是按了哪裡，還包括資料放在哪、素材怎麼整理、字幕怎麼加，以及存好後要再檢查一遍有沒有成功。
  • 01:00 接著開一個新的 thread，附上下一支影片的 package，請 Codex 處理
    ↳ 下次要發新影片時，開一個新的 thread（一段新對話），把下一支影片的 package（整包素材檔）交給它，請它處理。
  • 01:00 Codex 會把 package 對應到 spreadsheet 中正確的那一列，並填入 metadata
    ↳ Codex 會自己判斷這包素材對應到試算表的哪一列，再把正確的標題和描述填上去，你不用告訴它是第幾列。
  • 01:00 Codex 接著加上 thumbnail 與英文字幕，以 private 上傳影片，最後驗證所有內容都正確儲存
    ↳ 接著它會照你示範的方式加上縮圖和英文字幕，以不公開狀態上傳，最後自己檢查每樣東西都有存好。
  • 01:34 重點：只要示範一次，Codex 就會記住你的流程與偏好，下次沿用
    ↳ 這支影片的核心是：只要示範一次，它就會記住你的流程和偏好，之後同樣的事可以直接交給它。
  • 01:34 其他可套用的例子：發布影片的方式、pull request 的格式與分享方式、設定行事曆邀請的習慣
    ↳ 這招不只能用在發影片。像工程師用 pull request（把改好的程式碼送給同事審核）時要用什麼格式、怎麼分享，或你習慣怎麼設行事曆邀請，都能教給它。
  • 01:34 再次使用 skill 時，Codex 可以用 computer use、browser use、已連接的 plugins，或把它們組合起來完成任務
    ↳ 實際執行時，Codex 可以用 computer use（直接操作電腦畫面）、browser use（操作瀏覽器），或你已連接的 plugins（串接其他服務的外掛），也可以混著用。
  • 01:34 不需要在 prompt 裡解釋每個步驟或偏好，只要示範你的做法，下次它就能代勞
    ↳ 你不必在 prompt（打給 AI 的指令文字）裡把每一步、每個偏好都寫清楚，只要做一次給它看，下次就能讓它代勞。
📘 術語
skill（技能）：Codex 從你的示範中學到的流程與偏好，整理成可以再次使用的形式
metadata（中繼資料）：字幕中指影片的標題、描述等資訊，存放在發布用的 spreadsheet
thumbnail（縮圖）：上傳 YouTube 影片時要加上的圖片素材之一
YouTube Studio（YouTube 工作室）：手動發布時要在這裡處理各種欄位與設定
private（私人）：示範中影片儲存和上傳時採用的狀態
thread（對話串）：字幕中開一個新的 thread，附上影片 package，請 Codex 處理
package（上傳包）：下一支影片的素材包，Codex 會把它對應到 spreadsheet 的正確列
pull request（合併請求）：字幕舉例：可教 Codex 你如何格式化和分享 pull request
computer use（電腦操作）：Codex 再次使用 skill 時可用來完成任務的方式之一
browser use（瀏覽器操作）：Codex 再次使用 skill 時可用來完成任務的方式之一
plugins（外掛）：你已連接的 plugins，也是 Codex 完成任務可用的方式之一

A. 排程發布B. 私人（private）C. 公開（public）D. 不公開連結（unlisted）
