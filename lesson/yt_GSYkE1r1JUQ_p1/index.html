📘 術語
credits（點數）：OpenArt 上生成影片的計價單位，依長度與畫質不同（例：Seedance 2.0 1080p 15 秒約 3,000 credits）
native 4K（原生 4K）：字幕未解釋。作者說除了 Kling 3.0，Seedance 2.0 基本上是唯一有原生 4K 的模型
references（參考素材）：可放進模型的圖片、影片、音訊參考。Seedance 2.5 最多約 50 個，Minimax 最多 15 個
run locally（本機執行）：Minimax H3 可在自己的電腦上跑，不透過 OpenArt，但需要很強的機器
benchmark（基準）：作者稱 Seedance 2.0 為基準，是過去大家都在用的模型
crash zoom（急推鏡頭）：字幕未解釋，是運鏡測試 prompt 的第一個鏡頭
whip pan（甩鏡）：字幕未解釋，是運鏡測試 prompt 的第二個鏡頭；作者說 Flux 的版本不像 whip pan
earth zoom out（拉遠至地球）：字幕未解釋，是運鏡測試 prompt 的最後一個鏡頭
image reference（參考圖）：作為影片起點的圖片。電影感測試中，各模型用同一張參考圖搭配不同 prompt
text to video（文字生成影片）：字幕未解釋，作者用來稱呼只靠文字 prompt 生成的維京場景測試
prompt coherence（prompt 一致性）：字幕未明確解釋。作者在進階測試中把這項給了 Minimax H3
