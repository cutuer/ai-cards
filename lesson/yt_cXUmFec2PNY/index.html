🧑‍🏫 這支影片示範怎麼在 ChatGPT 裡用 data plugin，把公司散落在各處的資料和說明，整理成一份 AI 能直接用的背景知識，再分享給全公司。如果你常用 AI 查公司數據，卻覺得它不懂你們的指標和資料放哪，這支影片示範了一套解法。

  • 00:04 思考方式：想想你會給團隊新進分析師什麼 context，就把同樣的 context 給 agent
    ↳ context（背景資訊）就是做事前要知道的前情提要。新分析師上工時，你會告訴他資料放哪、指標怎麼算、有問題問誰。agent（能代你查資料、做事的 AI 助手）也需要同一份交代。
  • 00:04 分析前先確認 ChatGPT 使用、並連接到講者自己做這份工作時用的同一套工具
    ↳ 重點是讓 ChatGPT 連上你平常真的在用的工具和資料，不必另外準備一套。你平常去哪裡查數字，就讓它連到哪裡，它給的答案才會跟你的工作對得上。
  • 00:04 連接方式：到左上角的 plugins 分頁
    ↳ plugin（外掛）是讓 ChatGPT 接上外部工具的擴充功能。想連接工具，就到畫面左上角的 plugins 分頁，可以安裝的外掛都在那裡。
  • 00:04 講者在這裡也已安裝了 Molly 剛才提到的 data agent
    ↳ 講者的 plugins 分頁裡已經裝好一個 data agent。影片沒有多解釋它，只說是 Molly 前面提過的東西，先知道有這個工具就好。
  • 00:34 安裝任一個 plugin：點「plus」按鈕，必要時登入你的帳號
    ↳ 安裝方法是在想要的外掛旁點「plus」（加號）按鈕。如果外掛需要存取你在某個服務的帳號，就照畫面指示登入授權。
  • 00:34 若使用 business plan 或 enterprise plan，可能需要請管理員啟用某些 plugins
    ↳ 如果你用的是 business 或 enterprise 方案（給團隊或企業用的付費版），有些外掛可能預設沒開放，要請公司的管理員幫你啟用。
  • 00:34 講者把 data plugin 指向幾個不同資源，第一個是 Databricks 裡的資料表
    ↳ data plugin 是專門處理資料的外掛，可以同時指向好幾個資料來源。講者接的第一個來源是 Databricks（企業常用來存放和分析大量資料的平台）裡的資料表。
  • 00:34 第二個資源是 Slack 上的 analytics 頻道
    ↳ 第二個來源是 Slack（團隊常用的聊天工具）上的 analytics（數據分析）頻道。同事在頻道裡討論數字的內容，也是理解資料的重要背景。
  • 00:34 最後一個資源是一份 Google Drive 文件，內容是網站指標（site metrics）的資訊
    ↳ 第三個來源是 Google Drive 上的一份文件，內容是 site metrics（網站指標，像流量、訪客數這類數字）的相關資訊。
  • 01:04 data plugin 可處理以上所有來源，並產生畫面右側的 data context skill
    ↳ data plugin 會讀過並整理這三個來源，產生一個 data context skill，也就是一份 AI 可以反覆使用的資料背景說明，顯示在畫面右側。
  • 01:04 應由資料團隊中熟悉這些資訊的人審閱並修改這個 skill
    ↳ AI 整理出來的內容不一定全對，所以要交給資料團隊裡最熟這些資料的人檢查和修改，把寫錯或漏掉的地方補好。
  • 01:04 他們確認沒問題後，可把它打包成 plugin，在公司內部發布
    ↳ 確認沒問題後，可以把這個 skill 打包成外掛，在公司內部發布。同事裝上之後，用的就是同一份確認過的背景知識，不必每個人各自重教 AI 一次。
📘 術語
data agent（資料代理）：字幕只提到講者已安裝、是 Molly 提過的東西，未進一步解釋
plugin（外掛）：從 plugins 分頁點「plus」安裝，可連接工具；企業方案可能需管理員啟用
data plugin（資料外掛）：可指向多個資料來源並處理它們，產生 data context skill
data context skill（資料脈絡技能）：data plugin 處理來源後產生，需熟悉資料的人審閱修改，再打包發布
Databricks（Databricks）：字幕中存放資料表的地方，是 data plugin 的資料來源之一
site metrics（網站指標）：Google Drive 文件的內容主題，是資料來源之一
