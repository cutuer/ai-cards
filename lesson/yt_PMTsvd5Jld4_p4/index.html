🧑‍🏫 這段是 xAI 在發表會上介紹 Grockbot：它是一組能在雲端自己用電腦做事的 AI 同事。講者說明為什麼要做這個產品，也現場示範三個 bot 分工合作、怎麼手把手教 bot 新技能、怎麼設定哪些事要先經過你同意。如果你想知道 AI 除了聊天，還能怎麼真的幫你把工作做完，這段很值得看。

  • 35:48 做 Grockbot 的動機來自 coding 領域：過去兩年開發者的工作徹底改變，從手寫每一行程式碼，變成負責成果與方向、指揮一群 agent 完成任務
    ↳ 寫程式的人這兩年工作方式變了：以前一行行自己寫，現在比較像主管，負責定方向、驗收成果。實際的活交給一群 agent（能自己動手完成任務的 AI 助手）去做。
  • 36:18 講者認為知識工作還沒有這種轉變：現在的做法和 2024、2025 年差不多。Grockbot 的目標是成為公司內運用這些模型做實際工作最有用的方式
    ↳ knowledge work（知識工作）就是寫報告、做簡報、整理資料這類靠腦力的工作。講者覺得這塊的做法還跟一兩年前差不多，Grockbot 想成為公司裡用 AI 真正把事做完的主要工具。
  • 36:48 設計理念是「簡單到令人愉快」：AI 產品要好用、好上手，再慢慢帶使用者接觸更進階的功能
    ↳ 他們的原則是先讓人覺得好用、一上手就會，不必先學一堆設定。等你用順了，再一步步帶你碰比較進階的功能。
  • 36:48 常見使用歷程：先給簡單任務，再給更有野心的任務，一路往上加，直到感受到目前 AI 能力的極限
    ↳ 大家通常這樣用：先丟件小事試試，成功了就交代更難的，一路加碼，直到它做不到為止。到那時候，你就知道現在 AI 的能力到哪裡了。
  • 37:19 他們押注模型會越來越聰明，所以想提供一個安全的執行環境，讓模型對公司員工發揮最大用處
    ↳ 他們認定模型只會越來越強，所以把重點放在打造一個安全的工作環境，讓 AI 在公司裡可以放心做事，對員工發揮最大用處。
  • 37:19 Grockbot 是永遠在線的「雲端隊友」，就算你在睡覺或電腦闔上也不會停，而且會把工作做完：你給它成果目標，它負責交付
    ↳ Grockbot 在雲端運作，不需要你的電腦開著。你去睡覺、闔上筆電，它照樣繼續做。你只要講清楚想要什麼結果，過程由它自己搞定。
  • 37:50 講者認為現在的 AI 大多還是「單人遊戲」，下一步是團隊裡共用的 AI 同事，以及內部工具未來的樣貌
    ↳ 現在多數 AI 是一個人對著一個聊天視窗，別人看不到也用不到。講者認為下一步是整個團隊共用的 AI 同事，這也會是公司內部工具未來的樣子。
  • 38:20 本週有多場企業應用場次：Grockbot 用於 GTM、engineering、marketing 和 admins。報名網址（講者說的）：x.ai/galaxy
    ↳ 這週還有企業場次，分別講 GTM（go-to-market，產品上市推廣與銷售）、工程、行銷、系統管理員怎麼用 Grockbot。報名網址是講者口頭說的 x.ai/galaxy。
  • 38:20 今天的 demo 要展示三件事：agent 當同事、agent 使用自己的電腦、agent 有記憶並能從你教的東西中學習
    ↳ 今天的 demo（現場示範）要證明三件事：AI 能像同事一樣分工；它有自己的電腦可以操作；它會記得你教過的東西，下次自己做。
  • 39:21 示範用三個 bot：Data Dan、Slide Sonia、Email Ethan。流程是收集使用者資料、用資料做投影片和圖表，再用 email 寄給外部利害關係人
    ↳ 三個 bot（專門做事的 AI 帳號）各自分工：Data Dan 收資料，Slide Sonia 做簡報和圖表，Email Ethan 寫信寄給外部 stakeholder（跟這件事有關的外部對象）。
  • 39:51 重點是讓 agent 操作那些可能沒有原生 MCP 或 API 的工具，把這類工作外包出去，你就能專心處理更要緊的事
    ↳ 很多軟體沒有開放 MCP 或 API（讓 AI 或程式直接串接軟體的接口），AI 原本很難碰。Grockbot 改用人的方式，自己開電腦點畫面操作，所以這類雜事也能交給它。
  • 39:51 Grockbot 介面長得很像 iMessage 之類大家熟悉的工具。側邊已經有 Email Ethan 和 Slide Sonia 兩個 bot
    ↳ 介面做得很像 iMessage 這種傳訊息的 app：旁邊一排是 bot 名單，點進去就像跟同事聊天。畫面上已經有 Email Ethan 和 Slide Sonia。
  • 40:21 現場從零建立 Data Dan。建立 bot 時，Grockbot 會根據名字猜你想拿它做什麼（例如取名 workflow builder），並提供「你主要想用我做什麼」的選項
    ↳ 現場從零建立 Data Dan。取名時系統會從名字猜用途，例如叫 workflow builder（流程建構器），它就會猜你要做自動化流程，並列出常見用途讓你選。
  • 40:52 選 Google Form 當例子，因為它是向員工、客戶或做使用者研究時收集大量資料最常見的方式；Qualtrics（字幕拼作 Qualrixs）等表單軟體也能這樣做
    ↳ 用 Google Form 示範，是因為要向員工、客戶大量收集意見時，線上表單最常用。換成 Qualtrics 這類專業問卷軟體也能照樣做。
  • 41:22 用 voice mode 下指令：建立一份 Google Form，問兩題：每天喝幾杯咖啡？最喜歡舊金山哪家咖啡店？選項有 Ritual、Fails、Sight Glass、Blue Bottle（照字幕原文）
    ↳ 用 voice mode（語音模式）直接開口交代：做一份表單，問每天喝幾杯咖啡、最愛舊金山哪家咖啡店，選項有 Ritual、Fails、Sight Glass、Blue Bottle。
  • 41:52 目前的 voice mode 是語音轉文字。內部已部署可以來回對話、Grok voice 會回話的版本，講者說希望一週左右推出
    ↳ 現在的語音模式只是把你說的話轉成文字送出去。能一來一回、由 Grok 用聲音回話的版本，內部已經在用，講者說希望一週左右推出。
  • 42:23 送出請求後 Grockbot 會馬上開始工作，並使用自己的電腦。右上角可以點進去即時看它在做什麼
    ↳ 話一講完它就開工，用的是它自己的電腦，不是你的。點右上角可以即時看它的螢幕，確認它正在做什麼。
  • 42:23 每個 bot 有自己的 Linux VM，可以登入 Google Slides、Google Forms、Google Docs 等，你也能監看它建表單的過程
    ↳ 每個 bot 有一台自己的 Linux VM（開在雲端的虛擬電腦），能登入 Google 簡報、表單、文件去做事。你可以在旁邊看它一步步把表單建出來。
  • 42:54 Grockbot 也有內建的 MCP／plugins，可以依任務連接或管理，也能請 Grockbot 幫你設定
    ↳ 除了自己操作電腦，它也內建 MCP／plugins（外掛，替 AI 加上連接特定工具的能力），可以依任務決定要接哪些。不會設定的話，直接請 Grockbot 幫你弄就好。
  • 43:26 bot 執行任務前會請求批准（approval）。示範時先按允許
    ↳ bot 做某些事之前，會先發出 approval（批准）請求，你按同意它才會動手。示範時直接按了允許。
  • 43:26 可以設規則，例如寄 email 前要先問我、傳 Slack 訊息給外部客戶前要我批准。這讓企業更容易控制 bot 能做和不能做的事
    ↳ 你可以自訂規則，例如寄 email 前先問我、傳 Slack（公司常用的通訊軟體）訊息給外部客戶前要我同意。這樣公司就能管住 AI 什麼能做、什麼不能做。
  • 43:58 Slide Sonia 的電腦上已經開好要編輯的投影片。你可以自己改投影片，也可以用「teach a task」教她做某件事
    ↳ Slide Sonia 的電腦上已經開好要改的投影片。你可以自己上去改，也可以用 teach a task（教任務）功能，親自示範一次讓她學起來。
  • 44:29 教學示範：按 teach a task 後，由人直接操作 bot 的電腦（不是 bot 自己在做），依序點 Insert → 加 fly-in 動畫 → 播放確認
    ↳ 按下 teach a task 後，是人親手操作 bot 的電腦，bot 在旁邊觀察：點「插入」、加上飛入動畫、播放確認效果。就像帶新人時親自做一遍給他看。
  • 45:00 示範時 bot 會監測動畫花的時間。按停止任務後，Slide Sonia 會把這段錄製轉成一個 skill
    ↳ 示範過程中，bot 也會記下動畫花了多少時間。按停止後，Sonia 會把這段錄製整理成一個 skill（技能），也就是她之後能重複使用的做法。
  • 45:30 之後只要請她把那個動畫加到某段文字或某張圖片上，她就能從頭自己完成
    ↳ 之後只要說「把那個動畫加到這段文字或這張圖上」，她就能從頭自己做完，不用你再示範。
  • 45:30 可以在多個 agent 之間切換，看它們各自怎麼運作：Sonia 正在學剛教的 skill，Dan 正在即時建立表單
    ↳ 可以在不同 bot 之間切換，看各自的進度：這時 Sonia 正在學剛才教的技能，Dan 正在即時建表單，兩邊同時進行。
  • 46:00 接下來的計畫：Dan 把表單轉成 QR code 讓現場觀眾填，資料交給 Sonia，再由 Email Ethan 彙整分析結果，寄給得票最高的咖啡店老闆
    ↳ 接下來要串成一條流程：Dan 把表單做成 QR code 讓現場觀眾掃描填寫，資料交給 Sonia，再由 Ethan 彙整分析結果，寄信給得票最高的咖啡店老闆。
  • 46:31 應用例子：活動企劃處理 10,000 人 on-site 活動的飲食限制；使用者研究員向各個客戶收集資料。這些都能在 Grockbot 裡統籌完成
    ↳ 實際例子：活動企劃要統計一萬人活動的飲食限制，像素食或過敏；使用者研究員要向很多客戶收資料。這類收集、整理、回報的工作，都能在 Grockbot 裡一次安排好。
  • 47:01 Settings 往下捲可以找到一組規則，設定 Grockbot 哪些事要先問你、哪些不用
    ↳ 在 Settings（設定）往下捲，有一區專門放規則，讓你決定哪些事 Grockbot 要先問過你、哪些可以直接做。
  • 47:01 規則範例：沒有先明確問過我就不准代回 email；可以不問我直接自動做投影片。這樣就能細部控制 Grockbot 的權限
    ↳ 例如：回 email 一定要先問我；做投影片可以直接做，不用問。寄出去的信收不回來，做壞的投影片可以再改，依風險決定放多少權，就能細部控制它。
📘 術語
agent（代理）：開發者指揮一群 agent 完成個別任務，替人處理很多瑣碎工作
knowledge work（知識工作）：講者說知識工作現在的做法和 2024、2025 年差不多，還沒像寫程式那樣被改變
MCP（MCP（模型連接協定））：字幕把 MCP 和 plugins 並列，說可以依任務連接、管理，或請 Grockbot 幫你設定
API（應用程式介面）：有些工具沒有原生 MCP 或 API，Grockbot 會改用自己的電腦去操作
voice mode（語音模式）：目前是用說的，轉成文字（speech to text）；能互相對話的版本已在內部部署
Linux VM（Linux 虛擬機）：每個 bot 都有自己的 Linux VM，能登入 Google Slides、Forms、Docs
approval（批准／授權）：bot 執行某些任務前會先請你批准，也可以設規則決定哪些事要先問你
teach a task（教一個任務）：由人直接操作 bot 的電腦示範，停止後 bot 會把這段錄製轉成 skill
skill（技能）：教學錄製轉成的能力，之後 bot 就能自己從頭重做那件事
GTM（進入市場（go-to-market））：字幕只把它列為本週 Grockbot 應用場次之一，沒有解釋
stakeholder（利害關係人）：demo 最後要把資料 email 給一位外部利害關係人
✏️ 小考一題

在 demo 中，講者用「teach a task」教 Slide Sonia 做什麼？

A. 加上 fly-in 動畫B. 寄 email 給外部客戶C. 把 Google Form 轉成 QR codeD. 把投影片改成特定配色
看答案
答案：A。[44:29]–[45:00] 講者按下 teach a task，點 Insert 加動畫，並說「let's do a flyin animation」。改配色只是 [43:58] 舉的可能例子，實際沒有教；QR code 是 Data Dan 的工作（[46:00]）；寄 email 是 Email Ethan 的工作。
