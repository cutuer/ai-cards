🧑‍🏫 這是 Meta 推出的 AI agent（能自己動手幫你把事情辦完的 AI 助理）MetaMuse 評測影片的後半段。作者把它的優缺點、適合和不適合哪些人講清楚，最後也分享自己實際在用的 AI 工具組合。如果你在想免費的 AI 助理值不值得用、該怎麼挑，這段給了很實用的判斷標準。

  • 12:05 作者認為做 e-commerce 最好的平台就是 Instagram，用 Instagram ads 可以賺到數百萬美元，所以這個整合對電商族群會非常有用
    ↳ e-commerce 就是電商，也就是在網路上賣東西。很多賣家靠在 Instagram 投廣告找客人，作者認為 IG 是做電商最好的平台，所以 MetaMuse 能直接串 IG，對賣家特別實用。
  • 12:35 大多數人覺得 Facebook 是阿姨、祖父母在用的，但 Facebook Marketplace 還是很值得一看；MetaMuse 跟 Facebook Marketplace 有深度整合
    ↳ Facebook 常被當成長輩在用的社群網站，但 Facebook Marketplace（FB 上的二手買賣市集）還是很值得逛。MetaMuse 能直接進去市集操作，整合得很深。
  • 12:35 舉例：直接跟 MetaMuse 說「幫我在 Facebook Marketplace 找 Mac mini」，它就會找出一堆 Mac mini 的刊登
    ↳ 意思是你不用自己打開 FB 一筆一筆搜尋，只要講一句話，它就把符合的商品刊登整理給你，等於有人替你逛市集。
  • 12:35 作者覺得這裡可能有商機（例如做套利），也就是把 Facebook Marketplace 自動化，但還不確定具體做法
    ↳ arbitrage（套利）就是低價買進、再高價轉賣賺差價。作者想到可以讓 AI 自動盯著市集找便宜貨，但這只是初步想法，作者自己也還沒想好怎麼做。
  • 13:05 常逛 Facebook Marketplace 的人會很受用，因為現在幾乎可以把 Facebook Marketplace 自動化
    ↳ 平常就愛在 FB 市集挖寶或賣東西的人，以前要自己一直刷新、一直問賣家，現在很多步驟都可以交給 MetaMuse 代勞。
  • 13:05 MetaMuse 的 computer use 很強，但它完全在雲端，沒有任何本機元件，不能控制你的電腦；所有工作都在它自己的 VM 裡完成
    ↳ computer use 是指 AI 自己點滑鼠、打字來操作電腦。MetaMuse 這方面很強，但它只操作自己在雲端的 VM（虛擬電腦，一台放在遠端、不在你家的電腦），碰不到你的電腦。
  • 13:37 比較：Grockpot 雲端和本機都有，由你選擇；Hermes 基本上完全在本機；ChatGBT 雲端和本機都有
    ↳ 雲端（cloud）是在服務商的電腦上跑，本機（local）是在你自己的電腦上跑。Grockpot、ChatGBT 兩種都能選，Hermes 幾乎只跑在本機，MetaMuse 則只有雲端一種。
  • 13:37 對 power user 的作者來說這是很大的缺點：作者想透過 Tailscale 網路去操作 DGX Spark、RTX5090 電腦、Omachi 電腦，並載入 local models
    ↳ power user 指重度、進階的使用者。作者想讓 AI 透過 Tailscale（把自家多台裝置串成私人網路的工具）操控家裡幾台高階電腦，並跑 local models，MetaMuse 做不到。
  • 14:09 不過對大多數「幫我訂餐廳」的使用者來說，不能在本機操作沒差，他們只需要它在虛擬電腦上把事情辦好
    ↳ 一般人只想要「幫我訂個位」，根本不在意 AI 是在哪台電腦上做事，只要事情有辦好就行，所以這個限制對多數人來說不是問題。
  • 14:09 實例：MetaMuse 幫作者買到隔天晚上在 Palo Alto 的 Resident Evil 電影票，大約 10 秒就完成
    ↳ 作者只下了一句指令，它就在自己的虛擬電腦上把隔天的電影票買好，大約 10 秒就完成，比自己開網站點來點去快很多。
  • 14:09 另一個優點是速度超快，所以能很快用掉大量額度
    ↳ 因為每件事都做得很快，你能在短時間內交代很多事，把給你的使用額度充分用完，不會卡在等它做事。
  • 14:40 作者認為 Meta AI 團隊最近明顯扭轉了局勢，希望他們能追上 OpenAI、Anthropic 和 SpaceX
    ↳ 作者覺得 Meta 的 AI 團隊最近明顯進步、扭轉了原本的局面，希望他們能追上 OpenAI、Anthropic 這些領先的公司。
  • 14:40 小結：MetaMuse 非常快、VM 裡的線上 computer use 很強、用量很多，而且非常主動
    ↳ 整理下來有四個特點：速度快、在虛擬電腦上操作網頁很強、給的用量多，而且會主動做事，不用你每一步都交代。
  • 14:40 作者之前用過最主動的 agent 是 Instinct（強項是自己想到事情就去做），但作者認為 MetaMuse 在主動性上勝過它
    ↳ proactive（主動）是指 AI 不等你開口，自己想到該做的事就去做。作者之前覺得最主動的是 Instinct，但 MetaMuse 在這一點上更勝一籌。
  • 15:11 跟 Instagram、Facebook 的深度連結很好，特別適合投放 meta ads 來經營電商的人；訂位這類用途它也非常擅長
    ↳ meta ads 就是投放在 FB、IG 上的廣告。靠這些廣告賣東西的人最能受益；另外像訂餐廳、訂位這類跑腿小事，它也很擅長。
  • 15:41 優點 1：非常便宜，完全免費就有大量用量，作者說在 AI 時代幾乎前所未聞
    ↳ 現在很多好用的 AI 服務都要付月費，MetaMuse 卻是免費就給你大量用量，作者覺得在這個時代幾乎沒看過。
  • 15:41 優點 2：速度超快，交代什麼都做得非常快
    ↳ 不管是查資料、訂東西還是做內容，交代下去它都很快就完成，你不用坐在旁邊乾等。
  • 15:41 優點 3：超級主動，你沒要求它也會自己做出 artifacts、網站、podcast、影片
    ↳ artifacts 是 AI 做出來的成品，例如網頁、文件。你只是問個問題，它可能主動幫你做成網站、podcast 或影片，給你比預期更多的東西。
  • 15:41 優點 4：Instagram / Facebook 整合非常好，可以抓 reels、貼文等你需要的內容
    ↳ 它可以直接抓 IG 的 reels（短影音）和 FB 貼文這些內容，你不用自己截圖或複製貼上給它。
  • 16:11 優點 5：可以完全客製化，跟 Rockbot 不同，記憶、個性等都能自訂
    ↳ 你可以調整它要記得哪些事（記憶），以及說話風格和個性，讓它更像你專屬的助理；作者說 Rockbot 就沒辦法這樣自訂。
  • 16:11 優點 6：手機 app 非常好用
    ↳ 手機 app 做得很好，出門在外也能隨手叫它辦事，不用一定坐在電腦前。
  • 16:11 作者認為有三個主要缺點。缺點 1：生態系弱，MetaMuse 的生態系只有 Instagram 和 Facebook
    ↳ ecosystem（生態系）是指一個 AI 背後能串接的整套產品。MetaMuse 能串的只有 IG 和 FB，選擇比較少。
  • 16:11 對比 Grockbot 的生態系：有 Cursor（內含 Cursor cloud agents）、有 X（取得 X 上的社群貼文），還可能有其他即將推出的東西
    ↳ Grockbot 能串 Cursor（寫程式的工具，含會在雲端自己寫程式的 cloud agents），還能串 X（前身是 Twitter）抓社群貼文，之後可能還有更多。
  • 16:41 對比 ChatGBT work 的生態系：內建 codec 的 coding 能力、ChatGBT voice、頂尖的圖片生成，還有 creator micro keyboard 之類的小硬體
    ↳ ChatGBT work 背後有寫程式能力（codec）、語音對話、頂尖的生成圖片功能，甚至還有小鍵盤之類的硬體，能串的東西比 MetaMuse 多元。
  • 17:12 作者已經 15 年沒上 Facebook，也不想花更多時間在 Instagram 上，所以這個生態系對作者沒吸引力；但對電商來說 Instagram 生態系很棒
    ↳ 生態系好不好，要看你本來用不用那些產品。作者幾乎不用 FB、IG，所以不加分；但對靠 IG 做生意的人來說就是大加分。
  • 17:43 缺點 2：沒有 frontier models，只能用 Meta 自己的模型。模型夠用、不弱，但比不上 Astra、fable，沒辦法下一個 prompt 就一次做出很驚人的成品
    ↳ frontier models 指各家最頂尖、最新的 AI 模型。MetaMuse 只能用 Meta 自家模型，夠用但不夠頂尖，做不到 one-shot（一句指令就做出驚豔的成品）。
  • 17:43 缺點 3：只能在雲端。對作者這種 power user 來說，它沒辦法在 Tailscale 網路裡控制各台電腦或載入 local models，只有雲端 VM
    ↳ 跟前面講的一樣：它只存在於雲端虛擬電腦裡，進不了你自己的電腦和網路。對想控制多台電腦的進階使用者來說，這是硬傷。
  • 18:13 適合族群 1：懶得自己 Google 餐廳、按「訂位」，想讓 AI agent 在雲端 VM 幫忙訂位的人
    ↳ 懶得自己查餐廳、按訂位按鈕的人，只要交代一句，它就會在雲端虛擬電腦上幫你辦好。
  • 18:43 適合族群 2：很投入 Instagram 生態系的人，例如做電商、投 Instagram 廣告，或只是想看 reels 的人
    ↳ 很常用 IG 的人，不管是靠 IG 廣告做生意，還是單純愛滑 reels，都能直接叫它幫忙抓 IG 上的內容。
  • 18:43 作者自己主要在 X 上看新聞、學 AI，Instagram 那些東西不適合作者
    ↳ 作者主要是在 X 上看新聞、學 AI，不是用 IG，所以 MetaMuse 最強的 IG 整合對作者沒用。換句話說，適不適合要看你平常活在哪個平台。
  • 18:43 適合族群 3：在意價格的人。基本上免費、人人都能用，可能是最好的選擇；作者用了很多次，一毛錢都還沒付
    ↳ 基本上免費、人人都能用，想省錢的人它可能是最佳選擇。作者已經用了很多次，到現在還沒付過一毛錢。
  • 19:13 適合族群 4：想用最前沿功能的人。它非常主動，做什麼都會幫你生成 HTML 網站和 artifacts，而且速度飛快、用起來很順
    ↳ 喜歡嘗鮮的人會喜歡它：它常主動把回答做成 HTML 網頁（直接用瀏覽器就能打開的網頁）或其他成品，而且又快又順。
  • 19:13 適合族群 5：只需要一個助理的人，例如幫你查 email、看下一個行事曆行程；作者認為這大概是世上大多數人的需求
    ↳ 多數人需要的其實只是個助理，幫忙看 email、提醒下一個行程。作者認為這才是世上大部分人真正的需求，而 MetaMuse 正好適合。
  • 19:43 不適合：做深度技術應用、自己動手打造東西、載入 local models、用 Linux distros 的族群（也就是這個頻道常講的內容）
    ↳ 想自己動手做技術專案、跑 local models、用 Linux distros（各種版本的 Linux 作業系統）的人不適合，而這些正是作者頻道主要在講的內容。
  • 20:14 作者不用 Instagram，也不介意花 10 秒自己訂餐廳；而且作者本來就付費用了一堆服務，所以價格優勢對作者不重要
    ↳ 對作者來說，MetaMuse 的強項都用不上：不用 IG、自己訂位只要 10 秒，而且本來就付費用了很多工具，免費這點也不稀罕。
  • 20:14 作者確實喜歡它的主動性和速度，認為這是很大的優點，但作者不需要個人助理
    ↳ 作者承認主動和速度確實是大優點，只是作者要的不是幫忙跑腿的個人助理，所以對作者吸引力不大。
  • 20:44 作者想要的 agent：新的 open-source model 一推出，就自己檢查電腦硬體、下載最適合的版本、載入、測試、做好 harness，再傳訊息說可以用了
    ↳ open-source model 是公開給大家下載的 AI 模型；harness 是讓模型能實際跑起來、使用工具的外層框架。作者希望 agent 自己下載、裝好、測完再通知作者。
  • 21:14 MetaMuse 幾乎沒涵蓋打造東西、創業、local models、自建 harness 這類用途，所以作者不會換過去
    ↳ 作者重視的是自己動手做東西、創業、跑本機模型、自己搭 harness，這些 MetaMuse 幾乎都沒顧到，所以作者不打算換過去。
  • 21:14 作者目前的組合：深度技術工作用 ChatGBT work。作者認為 Chad GBT6 Astra 是世界上最好的 AI 模型，而且遙遙領先
    ↳ 做深度技術工作時，作者用 ChatGBT work，因為作者認為裡面的 Chad GBT6 Astra 是目前全世界最強的模型，而且領先很多。
  • 21:46 一般知識工作用 Grockbot：作者幾乎為生活中每項責任各建了一個 agent bot，每個都有那一塊生活的專屬 context
    ↳ 一般的知識工作用 Grockbot：作者替生活中每一項責任各建一個 bot，每個 bot 都有那一塊的 context（AI 做事時參考的背景資料），分工很清楚。
  • 21:46 網路管理和個人工作用 Hermes：作者經常換不同 AI models、跑實驗
    ↳ 管理網路和處理個人事務時用 Hermes，因為作者常常換用不同的 AI 模型做實驗，需要一個能自由切換的工具。
  • 22:16 Hermes 是 open-source harness，基本上能在你的電腦本機上做任何事，作者認為這是目前做這類事情最好的方式
    ↳ Hermes 是開源的 harness，裝在自己的電腦上，就能讓 AI 在你電腦裡幾乎做任何事。作者認為這是目前做這類事最好的方式。
  • 22:16 作者認為生態系是最重要的因素：MetaMuse 在軟體上比別人強的地方都可能被抄走
    ↳ 作者認為挑 agent 最該看的是生態系，因為 MetaMuse 在軟體功能上領先的地方，別家很快就能學走，優勢撐不久。
  • 22:46 例如 Grockbot 幾乎一夜之間就能加上主動功能，ChatGBT work 也能一夜之間加上客製化功能
    ↳ 舉例來說，「主動做事」這種功能 Grockbot 很快就能補上，「可自訂」ChatGBT work 也能馬上加。軟體功能很容易被追上。
  • 22:46 作者認為這些 agent 和公司目前唯一的護城河（moat）就是生態系：別人抄不走 Instagram 的護城河，MetaMuse 也抄不走 X 的
    ↳ moat（護城河）是指別人抄不走的優勢。功能可以抄，但 IG、X 這種平台本身和上面的使用者抄不走，所以生態系才是唯一的護城河。
  • 23:16 MetaMuse 的生態系不適合作者（作者不需要看更多 reels）；作者猜常看這個頻道、做很多打造和深度知識工作的觀眾，也比較會用作者組合裡的其他工具
    ↳ 作者不需要再多看 reels；而且作者猜常看這個頻道的觀眾多半喜歡自己動手、做深度工作，會比較適合作者組合裡的其他工具。
  • 23:47 作者請觀眾在留言區分享自己平常主要用哪些工具
    ↳ 作者邀請觀眾在留言區分享自己平常主要在用哪些 AI 工具，大家互相交流。
📘 術語
e-commerce（電子商務）：字幕說做電商最好的平台是 Instagram，可以用 Instagram ads 賺到數百萬美元
Facebook Marketplace（Facebook 二手交易平台）：Facebook 上的交易平台；MetaMuse 有深度整合，例如可以幫你找 Mac mini
arbitrage（套利）：作者提到可能可以靠自動化 Facebook Marketplace 做套利，但沒有進一步說明
computer use（電腦操作能力）：agent 自己操作電腦；MetaMuse 只能在自己的雲端 VM 裡操作，不能控制你的電腦
VM (virtual computer)（虛擬機／虛擬電腦）：MetaMuse 在雲端有自己的 VM，所有工作都在裡面完成
cloud / local（雲端／本機）：MetaMuse 只在雲端；Grockpot、ChatGBT 兩者都有；Hermes 基本上完全在本機
power user（進階使用者）：像作者這樣對 AI agent 期望很高，希望它能控制多台電腦、載入 local models 的人
Tailscale network（Tailscale 網路）：作者希望 agent 透過這個網路連到自己的 DGX Spark、RTX5090 等電腦
local models（本機模型）：在自己電腦上載入執行的模型；MetaMuse 沒辦法幫你載入
proactive / proactivity（主動性）：自己想到事情就去做；例如沒被要求就做出 artifacts、網站、podcast、影片
artifacts（成品（artifacts））：MetaMuse 會主動產出的東西，字幕跟網站、HTML sites 一起提到
ecosystem（生態系）：agent 背後可串接的產品群，例如 MetaMuse 是 IG/FB，Grockbot 是 Cursor、X
cloud agents（雲端 agent）：字幕提到 Grockbot 生態系裡有 Cursor cloud agents，作者說很優秀
frontier models（前沿模型）：MetaMuse 沒有，只能用 Meta 自己的模型，比不上 Astra 或 fable
one-shot（一次到位）：下一個 prompt 就直接做出很驚人的成品；作者說 MetaMuse 做不到這種程度
open-source model（開源模型）：作者希望新開源模型一推出，agent 就自動下載、載入、測試
harness（harness（模型外層框架））：作者希望 agent 能幫忙建好；Hermes 被形容為能在本機做任何事的 open-source harness
moat（護城河）：別人抄不走的優勢；作者認為目前唯一的護城河就是生態系
