🧑‍🏫 這支是 Claude 官方的九月更新整理，主軸是讓你少做設定：不用再選模式、挑工具，講出需求就能開始。影片也介紹了背後的新模型 Claude 5.5。如果你常用 Claude 寫報告、做簡報，這些改變會直接影響你每天的用法。

  • 00:00 九月更新的共同理念：你說出想要什麼，Claude 自己想辦法完成。
    ↳ 九月這幾項更新都朝同一個方向：你只要講清楚想要的結果，中間怎麼做、該用哪個功能，交給 Claude 自己判斷。
  • 00:00 過去要先選模式、選工具，切換時還得重新解釋專案。本集介紹兩項減少這些設定的改變，以及背後的新模型。
    ↳ 以前開工前要先決定用哪種模式、哪個工具，換地方還得把專案背景再講一次。這集介紹的兩項改變，就是要拿掉這些前置步驟。
  • 00:00 改變一：chat 與 Cowork 合併成同一個 Claude，不用再選模式。你提出需求，其餘由 Claude 處理。
    ↳ chat 是一般的聊天對話，Cowork 是原本和 chat 分開、要另外切換的模式。現在兩者合成同一個 Claude，打開直接講需求就好。
  • 00:00 簡單問題會得到快速回答。交付較大的任務（例如整理一份報告）時，Claude 會在同一個對話裡開始執行工作。
    ↳ Claude 會自己判斷事情大小。問簡單問題，它直接回答；交代「幫我整理一份報告」這種大工作，它會在同一個對話裡直接動手做。
  • 00:31 工作改在雲端執行，闔上筆電後仍會繼續。可以在筆電上開始，外出時用手機追蹤進度。
    ↳ cloud（雲端）指工作在遠端的伺服器上執行，不靠你的電腦。所以闔上筆電它照樣在做，出門時也能用手機看進度。
  • 00:31 原本就在用 Cowork 的人，之前做過的東西都還在原處。
    ↳ 已經在用 Cowork 的人不用擔心合併後東西不見，之前做的成果都留在原本的位置。
  • 00:31 改變二：任何對話都能做出 doc、deck 或 design，不用再選工具。
    ↳ doc 是文件，deck 是簡報檔，design 是設計稿。現在在任何一段對話裡都能直接要這三種成品，不必先挑工具。
  • 01:02 只需思考一次，再要求產出設計素材，Claude 會根據對話中已有的內容建構，不必重新說明或另開新對話。
    ↳ 例如你和 Claude 討論完企劃方向，接著說「做成設計稿」，它會直接拿剛剛聊的內容來做，不用重講一次或另開新對話。
  • 01:02 用 Opus 5.5 完成報告、要做 deck 時，可以試試 Sonnet 5.5。它速度較快，適合快速多輪修改，例如精簡投影片、換圖表、換整套配色。
    ↳ Opus 5.5 和 Sonnet 5.5 都是 Claude 的模型。報告用 Opus 做完後，做簡報可以換 Sonnet 5.5。它比較快，適合反覆小改：砍短投影片、換圖表、換 color palette（整套配色）。
  • 01:02 產出的不是截圖。你可以自己修改投影片，也可以反白特定段落，明確告訴 Claude 要改什麼。
    ↳ 做出來的是可以編輯的檔案，不是一張圖片。你可以自己動手改，也可以把某段反白，直接告訴 Claude 這段要怎麼改。
  • 01:33 Claude 只會修改你指定的那個部分。
    ↳ 你指定哪裡，Claude 就只改哪裡。沒提到的部分不會被順手動到，不用擔心改一段結果整份跑掉。
  • 01:33 新功能 Claude Docs：團隊可以和 Claude 同時編輯同一份文件，任何人都能在註解中 mention Claude 請它修改。
    ↳ Claude Docs 是新的共同編輯文件，團隊和 Claude 能同時改同一份。想改哪段，就在註解裡 mention（像 @ 標記人那樣點名）Claude，它就會去改。
  • 01:33 Docs、Slides、Design 今天起在所有付費方案都可使用。
    ↳ paid plans 是付費方案。從影片發布當天起，所有付費方案都能用 Docs（文件）、Slides（簡報）、Design（設計）這三項功能。
  • 01:33 Pro tip：可以描述需求，讓 Claude 自己選格式。如果已經知道要做簡報，輸入 /slides 就能直接開始。
    ↳ Pro tip 是實用小技巧的意思。還不確定要做成什麼，就直接描述需求，讓 Claude 挑格式。已經確定要簡報，就輸入 /slides 這個指令，直接開始做。
  • 02:04 上述做法對 docs 和 designs 同樣適用。
    ↳ 做文件和設計稿也是同樣的方式：不確定格式就描述需求讓 Claude 決定，已經知道要什麼就直接指定。
  • 02:04 這些功能都靠底層模型實現。Claude 5.5 是一系列模型，能力足以理解你想要的工作方式。
    ↳ 這些新功能做得到，是因為背後的模型變強了。Claude 5.5 是一整個系列的模型，能力已經足以理解你想用什麼方式工作。
  • 02:04 還在釐清需求時先用 Opus 5.5，確定需求後切換到 Sonnet 5.5。
    ↳ 簡單分工：還在想「到底要做什麼」時用 Opus 5.5，把方向理清楚；需求確定、進入動手修改的階段，就換 Sonnet 5.5 加快速度。
📘 術語
Cowork（Cowork）：原本和 chat 分開的模式，現已與 chat 合併為同一個 Claude，過去的成果都會保留

deck（簡報）：可在任何對話中產出的設計素材之一，與 doc、design 並列

Sonnet 5.5（Sonnet 5.5）：Claude 5.5 系列模型之一，速度較快，適合快速多輪修改，以及確定需求後使用
