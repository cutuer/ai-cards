📘 術語
real-time audio model（即時音訊模型）：OpenAI API 新推出的模型類型，本片示範 GPT Real-Time Translate 與 GPT Real-Time 2
voice agent（語音代理）：能遵循指示並執行動作的語音助理，例如查行事曆、更新 CRM
transcription（逐字稿／轉錄）：翻譯示範時，模型語音輸出旁附帶的文字紀錄
reasoning（推理）：GPT Real-Time 2 帶給語音 agent 的智慧推理能力，可在背景思考同時維持對話
parallel tool calling（平行工具呼叫）：字幕提到模型新具備此能力，也因此更需要用 preamble 向使用者說明
preamble（前導說明）：讓模型在執行動作前先說明自己要做什麼並更新使用者，因為動作可能要花幾秒
CRM（CRM 系統）：字幕未解釋；示範中請助理在 CRM 寫入會議摘要與下一步
computer use（computer use）：字幕只把它當作翻譯時能正確處理的技術術語例子，沒有另外解釋
