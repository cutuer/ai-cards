🧑‍🏫 這支 OpenAI 官方短片介紹 ChatGPT 的 Visualize skill，它能把又長又雜的內容，例如會議紀錄，變成一眼看得懂的畫面。如果你常被長文件淹沒，或要把重點整理給團隊看，這個功能可以幫你省下不少時間。

  • 00:02 使用 ChatGPT 或 Codex 時，有時你不只想要文字或輸出結果，而是想把它視覺化
    ↳ Codex 是 OpenAI 偏向寫程式用的 AI 工具。平常問 AI 多半拿到一大段文字，但有些內容用看的比用讀的快，這時你會希望它直接做成畫面給你看。
  • 00:02 Visualize skill 可以把任何東西轉成視覺化，適合用來處理密集資訊
    ↳ skill 是 ChatGPT 針對特定任務的附加能力，Visualize skill 專門把內容變成圖表或畫面。資訊越多越雜，越適合交給它整理成一眼能看懂的樣子。
  • 00:02 例子：面對很長的文件（如會議紀錄），不必逐字讀完，可以請 ChatGPT 為它產生一個好看的介面
    ↳ 像一小時會議的逐字紀錄，自己讀要花很久。你可以直接請 ChatGPT 把它做成一個整理好的頁面，重點都排好，不用從頭讀到尾。
  • 00:32 示範：一份活動籌備的會議紀錄，一眼就能看到已決定事項、交付時程，以及還待決定的事項
    ↳ 影片用活動籌備會議當例子。畫面把「已經拍板的事」「什麼時候要交什麼」「還沒決定的事」分開放，你一眼就知道進度卡在哪、下一步該追什麼。
  • 00:32 可以持續迭代，例如要求改成日曆檢視（calendar view），就會得到日曆版本
    ↳ 第一版不滿意可以繼續叫它改。例如說「改成 calendar view」，也就是日曆檢視，它就會把各項時程排到日曆上，比清單更容易看出哪幾天最趕。
  • 00:32 可做互動式視覺化：需要分頁（tabs）檢視時，甚至能加上按鈕，按下後直接在對話中替你送出 prompt
    ↳ interactive visualization 指可以點、可以切換的畫面。它能分成幾個 tabs（分頁）切換著看，還能放按鈕，按下去就自動送出一段 prompt（給 ChatGPT 的訊息），不用自己打字。
  • 01:02 要和團隊分享時，可匯出成圖片，或發布成網站（site）並分享連結
    ↳ 要給同事看有兩種方式。一種是存成圖片直接傳，另一種是發布成 site（一個網頁），把連結丟到群組，對方點開就能看。
  • 01:02 講者自己常用它來做晨間簡報、快速掌握任何主題，以及處理手上的各種專案
    ↳ 講者自己每天早上用它整理晨間簡報，想快速搞懂一個新主題時也用它，還拿來掌握手上各個專案的狀況。
📘 術語
Visualize skill（視覺化技能）：ChatGPT／Codex 的一項 skill，能把任何東西轉成視覺化，方便處理密集資訊
calendar view（日曆檢視）：示範中要求 ChatGPT 把會議紀錄改用日曆形式呈現
interactive visualization（互動式視覺化）：可有分頁，並加上按鈕，按下後直接在對話中替你送出 prompt
prompt（提示詞）：字幕未解釋；指送進對話給 ChatGPT 的訊息，互動按鈕可代你送出
✏️ 小考一題

根據影片，想把 Visualize skill 做出的視覺化分享給團隊時，可以怎麼做？

A. 只能截圖後貼到對話中B. 匯出成 PDF 並用 email 寄出C. 匯出成圖片，或發布成網站並分享連結D. 只能在 ChatGPT 對話中邀請團隊成員檢視
看答案
答案：C。[01:02] 講者說要分享給團隊時，可以匯出成圖片（export it as an image），或發布成網站並分享連結（publish it as a site and share a link）
