💡 你可以怎麼用：挑一件你平常要等別人幫忙、或一直想做卻沒資源做的小事，例如整理一份清單、把收到的需求分類。把目標、手上的資料和你想要的結果寫清楚，整件交給 ChatGPT 去做，最後再自己檢查成果、要求它修改。

🧑‍🏫 這支影片請 Shopify（知名的電商開店平台）一位負責營運、不是工程師的人，分享他們公司裡不寫程式的部門，怎麼用 AI 自己把事情做完。重點在 agent，也就是能接下一件任務、自己把它做完的 AI 助手。如果你常覺得「想做的東西要等工程師有空才做得出來」，這支會讓你知道現在可以怎麼自己動手。

  • 00:05 AI 讓講者能用更少的依賴更快推進工作，並做到以前做不到的事
    ↳ 講者說，有了 AI 以後，很多事不用再等別人配合就能往前推，速度變快了。連以前他根本做不到的事，現在也能自己完成。
  • 00:05 講者從營運角度出發，專注於讓非技術部門有效導入並使用 AI 工具
    ↳ 他不是工程師，而是站在公司營運的角度，在意的是不寫程式的部門能不能真的把 AI 用進日常工作，而不是只試用一下就放著。
  • 00:05 講者把 ChatGPT 當成真正的主力工具，認為它非常適合這類工作
    ↳ 對他來說，ChatGPT 不是偶爾拿來問問題的工具，而是每天真正拿來做事的主力。他認為這類工作交給它很合適。
  • 00:05 對多數人來說，最主要的改變是學會與 agent 協作，本質上就是「委派任務」的能力
    ↳ 他說對多數人來說，最大的改變是學會跟 agent 合作。說穿了就是學會委派任務：把一件事交代清楚、交出去，讓它做完再交回來，就像交辦工作給同事。
  • 00:05 委派任務讓人能做到過去因缺乏資源與依賴而辦不到的事
    ↳ 以前很多想法卡在沒人手，或要等別人幫忙才能做。現在把任務交給 agent，一個人也能做出原本辦不到的東西。
  • 00:05 非技術人員不再需要找工程團隊取得資源，才能打造自己需要的工具
    ↳ 影片裡的「依賴」（dependencies）指的是：以前想要一個自己用的小工具，得先去找工程團隊要資源、排隊等他們做。現在非技術人員可以自己做，不用等。
  • 00:35 講者用 Codex 或 ChatGPT 搭配 agent 重新設計任務分類流程，這在以前是不可能的
    ↳ Codex 是 OpenAI 推出、主要用來寫程式的 AI 工具。講者用它或 ChatGPT 搭配 agent，重新設計「任務怎麼分類」的流程。這件事以前他自己做不到。
  • 00:35 過去需要大型團隊完成的工作，現在由一個能處理個別任務的 agent 完成
    ↳ 以前這種工作需要一個大團隊分工才做得完，現在由一個 agent 一件一件接手，把個別任務處理掉。
  • 00:35 講者表示這從根本上改變了他們的工作方式
    ↳ 講者的結論是：AI 不只是多了一個方便的小幫手，而是從根本上改變了他們整個做事的方式。
📘 術語
agent（代理（AI agent））：字幕說與 agent 協作，本質上就是委派任務的能力；agent 能處理個別任務
dependencies（依賴）：字幕指過去要仰賴工程團隊提供資源，才能打造需要的工具
Codex（Codex）：字幕沒有解釋，只提到與 ChatGPT 並列，是用來搭配 agent 重新設計任務分類流程的工具
✏️ 小考一題

講者認為，對多數人來說最主要的改變是什麼？

A. 學會撰寫更精準的 promptB. 學會管理大型工程團隊C. 學會與 agent 協作，也就是委派任務的能力D. 學會自己寫程式
看答案
答案：C。[00:05] 講者說 the main change for most people is learning how to work with agents，本質上是 the ability to delegate tasks
