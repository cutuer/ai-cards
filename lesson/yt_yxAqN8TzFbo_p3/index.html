🧑‍🏫 這段影片把桌面材質調得更自然，接著用馬克杯現有的模型做出咖啡泡沫，並套上一張「一圖多款」的泡沫貼圖。整段示範了調色節點、重複利用模型、基本 UV 攤平這幾個常用技巧，照著做就能看出畫面質感的差別。

  • 22:30 按 Shift+A 或上方 Add > Color 可加入各種調色節點；作者不會用 brightness and contrast，因為「什麼是亮度、對比」本身就有很多爭論
    ↳ 在節點畫面按 Shift+A，或點上方 Add > Color，就能加入各種調色節點。節點是一格格串起來處理畫面的小方塊。作者不用亮度對比節點，因為大家對亮度、對比的定義本來就有爭議。
  • 22:30 Color Ramp 適合把東西轉換成你自己指定的一組顏色；Hue Saturation Value 他們會用；這次要找的是 RGB Curves
    ↳ Color Ramp 會把原本的明暗換成你指定的一組顏色。Hue Saturation Value 等一下會用到，這次先找 RGB Curves。
  • 23:00 RGB Curves 跟 Photoshop、DaVinci 裡的 RGB curves 類似，可以做出 S-log 那種曲線
    ↳ RGB Curves 是用一條曲線調整明暗的節點。用過 Photoshop 或調色軟體 DaVinci 曲線功能的人會覺得眼熟。作者提到它能拉出 S-log 那類曲線，字幕沒有再多解釋。
  • 23:00 曲線由下往上依序對應：暗部、中間調、亮部，最上方是 clipped（爆掉）的亮部
    ↳ 曲線由下往上分別控制暗部、中間調、亮部，最頂端是亮到爆、細節變成全白的區域。想改哪一種亮度，就拉哪一段。
  • 23:00 把曲線拉成 ramp 般的形狀，畫面就變得更有對比；往下拉到底可以大幅改變外觀
    ↳ 把曲線拉成斜坡狀，亮的更亮、暗的更暗，對比就出來了。把點往下拉到底，整體外觀會大幅改變。
  • 23:30 在曲線上方再加一個反方向的小彎，可以誇大白色部分、把亮部帶出來
    ↳ 在曲線上段再做一個反方向的小彎，會特別加強白色區域，讓桌面的亮部更明顯。
  • 24:00 拉高對比後顏色也被帶出來，偏黃綠色，看起來像桌子發霉、不好看
    ↳ 拉高對比有副作用：原本藏著的顏色也跟著浮出來，偏黃綠色，桌面看起來像發霉。
  • 24:00 加入作者很常用的 Hue Saturation Value 節點；放在 curves 之前或之後都可以，沒什麼差別
    ↳ 所以再加一個作者常用的 Hue Saturation Value 節點，可以分別調色相、飽和度、明度。它放在曲線前面或後面，結果差不多。
  • 24:30 把 saturation 調低，畫面就完全變樣、好看很多
    ↳ 把 saturation（飽和度，也就是顏色鮮不鮮豔）調低，黃綠色就被洗掉，桌面馬上變自然好看。
  • 24:30 想暫時關掉某個節點可以選取後按 M（M 代表 mute）
    ↳ 想比較有沒有某個節點的差別，選取它按 M 就能暫時停用。M 是 mute（靜音）的意思，不用刪掉，再按一次就恢復。
  • 24:30 只用兩個節點，就把原本蒼白的混凝土變成現在的效果；roughness 等之後講 lighting 時再調
    ↳ 只靠曲線和 HSV 兩個節點，就把灰白平淡的混凝土調出質感。Roughness（粗糙度，決定表面反光是霧面還是亮面）留到講打光時再調。
  • 25:00 接著加咖啡泡沫，這也是介紹另一種 texture 類型的機會，這類 texture 可在 Poliigon 之類的網站找到
    ↳ 接著做咖啡泡沫，順便介紹另一種貼圖。Texture 就是貼在物件表面的圖片，這類泡沫貼圖可以在 Poliigon 這種素材網站找到。
  • 25:00 雖然可以另外新增 circle，但更聰明的是重複利用已有網格省時間；馬克杯裡已經有一圈大小剛好的圓
    ↳ 泡沫需要一個圓，可以另外新增 circle。不過馬克杯模型裡本來就有一圈尺寸剛好的線，直接拿來用比較省時間。
  • 25:36 選取那圈線，按 Shift D 複製，再按 Escape 讓它回到原位
    ↳ 選取那圈線，按 Shift D 複製。複製出來的線會跟著滑鼠跑，按 Escape 取消移動，它就會留在原本的位置。
  • 25:36 按 P 可以把網格的一部分分離成新物件，選 Selection
    ↳ 按 P 再選 Selection，把剛複製的那圈線從杯子拆出來，變成獨立物件，之後才能單獨編輯。
  • 25:36 到 Outliner 會看到兩個 mug：原本的 mug 和 mug.001
    ↳ Outliner 是列出場景中所有物件的清單。這時會看到兩個：mug 是原本的杯子，mug.001 是剛拆出來的線。
  • 26:11 把 mug.001 改名為 foam，進入 Edit Mode；要切到 wireframe mode 才看得到那圈線
    ↳ 把 mug.001 改名為 foam，比較好認。接著進入 Edit Mode，也就是編輯點、線、面的模式。杯子會擋住視線，所以要切到 wireframe（只顯示線框）才看得到那圈線。
  • 26:11 作者發現自己在 Shading 裡，應該回到 Layout 再做，同樣切 wireframe mode
    ↳ 作者發現自己還在 Shading 分頁（調材質用的畫面），就切回一般建模用的 Layout 分頁繼續做，一樣切到線框顯示。
  • 26:54 這圈 circle 沒有面（face），所以不會被算圖；按 F 建立一個完全平的面
    ↳ 這圈線只有邊、沒有面（face），算圖時會完全看不到。按 F 把它補成一個完全平的面，泡沫才有表面。
  • 26:54 平面大多數情況都可以，但真實咖啡跟杯緣接觸處因表面張力會沿著杯壁往上升
    ↳ 大多情況用平面就夠了。但真實咖啡碰到杯壁時，受表面張力影響，液面邊緣會沿著杯壁微微往上爬。
  • 27:27 這條邊雖看似可忽略，但總會抓到光；少了它，眼睛就會覺得看起來很假
    ↳ 這圈上揚的邊很細，但一定會反光。少了它，觀眾說不出哪裡怪，就是會覺得假。
  • 27:27 在 Edit Mode 對這個面按 I 做 inset，會在這單一面周圍產生一圈線
    ↳ 在 Edit Mode 選取這個面，按 I 做 inset（內縮），面的內側會多出一圈線，把面分成外圈和中間兩塊。
  • 28:00 inset 放到適當位置後，按 G 再按 Z 把中間往下移，切回 solid view mode 檢查
    ↳ 把內圈放到合適的位置後，按 G 再按 Z，把中間往下壓，外圈就像貼著杯壁翹起來。接著切回 solid view mode（實體顯示）檢查。
  • 28:00 因為邊緣有種皺摺（crimped）效果，再按 I 做一次 inset，讓它不那麼明顯
    ↳ 邊緣看起來有折痕，像被捏過一樣。再按 I 內縮一次多加一圈線，讓轉折變得比較緩和。
  • 28:30 右鍵選 Shade Smooth，泡沫就有一圈微微隆起的邊
    ↳ 按右鍵選 Shade Smooth（平滑著色，讓面與面的交界看起來圓滑），泡沫就會有一圈微微隆起的邊。
  • 28:30 那圈邊因光線關係不太明顯；建模時改變顯示方式很有幫助，右上角預設 lighting 是 Studio
    ↳ 在預設的 Studio 燈光下，那圈邊不太明顯。建模時換一種預覽方式很有幫助，選項在畫面右上角。
  • 28:30 改選 MatCap 並點那顆球，可以選很多不同的顯示效果
    ↳ 把顯示方式改成 MatCap，再點那顆預覽球，就能換成各種預設質感。MatCap 只影響預覽畫面，專門用來看形狀。
  • 29:02 作者有些 YouTube 縮圖就是用 MatCap 做的，因為有些看起來很漂亮；也更容易看清那圈邊的樣子
    ↳ 有些 MatCap 很好看，作者部分 YouTube 縮圖就是用它做的。換成 MatCap 後，也更容易看清那圈邊的起伏。
  • 29:02 有些 MatCap 專門用來揭露網格上的 artifacting，讓你看到原本可能沒發現的網格問題
    ↳ 有些 MatCap 專門放大 artifacting，也就是網格上的瑕疵，例如不平順的面，讓你發現平常看不出來的問題。
  • 29:02 MatCaps 在 Blender 5.0 重新製作過；很好用但這次其實不需要
    ↳ Blender 5.0 版重新做過這些 MatCap。這工具很實用，但這次做泡沫其實用不到，知道有這功能就好。
  • 29:36 按 N 叫出右側 Properties，下載 Coffee Foam Atlas texture，選取物件後按 Apply，rendered view 下檢查
    ↳ 按 N 叫出右側面板，下載 Coffee Foam Atlas 貼圖。選取泡沫物件後按 Apply 套上，再切到 rendered view（接近最終成品的預覽）檢查。
  • 29:36 到 UV Editor 發現泡沫還沒 UV unwrap；按 7 切到 top view
    ↳ 到 UV Editor 發現泡沫還沒做 UV unwrap。這一步是把立體表面攤平成平面，貼圖才知道每個位置該貼哪裡。接著按 7 切成從正上方看。
  • 29:36 按 U，選 Unwrap Angle Based 展開
    ↳ 按 U，選 Unwrap Angle Based，讓 Blender 依照角度自動把這個面攤平。
  • 30:10 atlas texture 是特殊的 texture，一張圖裡有多種不同咖啡泡沫可選
    ↳ atlas texture 是一張圖裡放了多款素材的貼圖。這張就排了好幾種不同的咖啡泡沫，可以任選。
  • 30:10 在 edit mode 下把 UV 選取範圍縮小蓋在泡沫圖上，再移動到你想要的那一款
    ↳ 在 edit mode 下把攤平的 UV 縮小，讓它只蓋住其中一款泡沫的範圍，再移到你想用的那一款上。
  • 30:46 開素材公司的麻煩是每個主題都像重新發明輪子；拍照拿不到泡泡的形狀細節
    ↳ 作者分享經營素材公司的難處：每換一個主題都得從頭摸索。泡沫光靠拍照，拿不到泡泡形狀的細節。
  • 30:46 他們先雇人做很貴的 Substance materials，作者記不清價格，大約 $2,000 左右，但有些東西很難用 procedural 方式做
    ↳ 他們先花大錢請人做 Substance 材質，作者記不太清楚，大約 2,000 美元。但有些東西很難用 procedural（用規則自動生成）的方式做出來。
  • 31:20 Substance 是完全獨立的 texturing 軟體，很複雜、全以節點為基礎；即使找了很厲害的人仍難做出泡泡細節
    ↳ Substance 是 Blender 以外的專門貼圖軟體，全靠節點組合，非常複雜。就算請到高手，還是做不出像樣的泡泡細節。
  • 31:20 團隊一位成員拍了咖啡照片，在 Substance Painter 裡手動擺放泡泡，讓形狀細節正確，結果成功
    ↳ 最後，團隊成員拍了咖啡照片，在 Substance Painter（可以直接在模型上畫貼圖的軟體）裡手動擺放泡泡，形狀終於對了。
  • 31:50 那方法仍花了他一天；作者說很多時候只能猜哪種方法行得通、邊做邊試
    ↳ 這個方法也花了他整整一天。作者坦言，很多時候事先不知道哪招有效，只能猜、邊做邊試。
  • 31:50 共有 9 種泡沫可選，有些綿密、有些像 espresso；作者動畫裡用的是最上面那一款
    ↳ 這張圖共有 9 款泡沫，有的綿密，有的像 espresso 表面。作者動畫裡用的是最上面那一款。
  • 31:50 第一次匯入時 Shading 分頁裡它被當作 Alpha 處理
    ↳ 剛匯入貼圖時，到 Shading 分頁會看到其中一張圖被接到 Alpha（透明度）。
  • 32:25 Alpha 會讓東西變透明，但泡沫沒有透明部分；若看到透視的情況，可能要把 Alpha 斷開
    ↳ Alpha 控制哪裡要透明，但泡沫整片都不透明。如果發現能透過泡沫看到底下，就把接到 Alpha 的那條線斷開。

    ↳ 不需要 metallic（金屬感）。保留 Roughness、Base（基本顏色）、Normal（做出凹凸感的圖）。AO 一般指記錄縫隙陰影的圖，這裡也不用，選取後按 X 刪掉。

    ↳ 更進階的內容都在作者的課程 The Beginners Academy，包括：硬邊物件的細緻攤平、接縫放哪裡才不會把貼圖拉歪、曲面展開、程序化與手繪貼圖。

📘 術語
RGB Curves（RGB 曲線）：調色節點，類似 Photoshop、DaVinci 的曲線；由下到上對應暗部、中間調、亮部
S-log curve（S-log 曲線）：RGB Curves 可以做出的一種曲線形狀，字幕未進一步解釋
Color Ramp（色彩漸層節點）：想把東西轉換成你自己的一組顏色時很有用
Hue Saturation Value（色相／飽和度／明度節點）：作者很常用的節點，這裡用來降低飽和度，去除偏黃綠的顏色
Mute (M)（靜音／停用節點）：選取節點按 M，可暫時關掉該節點
Separate (P)（分離）：按 P 把網格的一部分分離成新物件
Outliner（大綱視窗）：可看到場景中的物件，例如 mug 與 mug.001
Wireframe mode（線框模式）：要切到這個模式才看得到那圈沒有面的 circle
Face（面）：circle 沒有面就不會被算圖；按 F 建立面
Inset（內插面）：按 I，在單一面周圍產生一圈線
Shade Smooth（平滑著色）：右鍵選取套用，讓泡沫呈現平滑的隆起邊緣
MatCap（材質捕捉顯示）：右上角顯示選項，有多種觀看效果，有些能揭露網格問題；Blender 5.0 重新製作
Artifacting（瑕疵／假影）：網格上的問題，某些 MatCap 能讓它現形
UV Unwrap（UV 展開）：字幕示範按 U 選 Unwrap Angle Based，讓貼圖能正確對應到物件
Atlas texture（圖集貼圖）：一張圖裡有多款咖啡泡沫，縮放移動 UV 到想要的那款
Substance / Substance Painter（Substance（貼圖軟體））：完全獨立的 texturing 軟體，很複雜、全以節點為基礎
Procedural（程序化）：有些東西很難用 Substance 以 procedural 方式做出來，字幕未詳細解釋
Alpha（透明度通道）：會讓東西變透明；泡沫不需要，出現透視就斷開
AO（AO 貼圖）：字幕未解釋，作者只說不需要並按 X 刪掉
Poliigon（Poliigon）：可以找到這類 texture 的網站
