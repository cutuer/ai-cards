  • 01:01 SeaDance 2.0 現已可在 Arc Ads 上使用；影片會示範開箱、街訪、房地產導覽、ASMR、黏土動畫、綠幕、縮時等用例

  • 01:01 之後會示範如何在自己電腦設定 Claude Code 重現任何廣告，避免為了摸索 prompt 而浪費 credits
    ↳ 後面會教你在自己電腦上設定 Claude Code，用它照做任何廣告。這樣就不用一直改 prompt 試錯，因為每試一次都會扣 credits（平台的生成費用點數）。
  • 01:31 Arc Ads 介面：在專案底部 settings 選 video，可選模型有 Sora 2、Sora 2 Pro、Kling、Kling 3.0、Vio 3.1、SeaDance 1.5、Grok video，以及 SeaDance 2.0
    ↳ 在 Arc Ads 專案下方的 settings 切到 video，就能選要用哪個影片模型，例如 Sora 2、Kling、Vio 3.1、Grok video 等，SeaDance 2.0 也在選單裡。
  • 02:03 畫面比例可選 9:16 或 16:9；長度 4 到 15 秒，價格依長度而不同
    ↳ 畫面比例可以選 9:16（直式，手機短影音用）或 16:9（橫式，像 YouTube）。影片長度是 4 到 15 秒，越長越貴。
  • 02:03 講者認為價格也會因 480p 或 720p 而不同；示範 10 秒影片為 0.6 credits，切到 480p 價格減半
    ↳ 解析度也會影響價錢。480p、720p 指畫面清晰度，數字越大越清楚。示範中 10 秒影片要 0.6 credits，切成 480p 就只要一半。
  • 02:33 省 credits 小技巧：用 480p 生成。內容反正在社群、手機上看，畫質較低反而更像真的、不像 AI；講者認為 4K 反而較容易看出是 AI
    ↳ 省錢建議直接用 480p。觀眾都是在手機上滑社群，畫質普通反而像隨手拍的真人影片。講者覺得畫質太精緻（像 4K）反而容易被看出是 AI。
  • 03:03 SeaDance 2.0 可同時吃多張參考圖、多段參考音訊、多段參考影片
    ↳ SeaDance 2.0 一次能吃好幾種參考素材，包括多張圖片、多段聲音、多段影片。AI 會照著這些素材做，不用只靠文字去想像。
  • 03:03 Vio 3 只能用參考圖、不能用參考影片；講者認為這是第一個同時支援音訊與影片參考的模型
    ↳ 比較起來，Vio 3 只能給參考圖，不能給參考影片。講者認為 SeaDance 2.0 是第一個聲音和影片都能拿來當參考的模型。
  • 03:34 Arc Ads 操作：上傳影片、圖片、音訊後，在 prompt 裡打斜線（/）即可選擇要引用的 image／video／audio
    ↳ 在 Arc Ads 先上傳影片、圖片、聲音，再到 prompt 裡打「/」，就會跳出選單讓你點選要引用哪個素材，用法很像聊天軟體裡 @ 某個人。
  • 04:05 prompt 範例：以 video one 作為要重現的影片氛圍，換成 image one 的產品，並使用 audio one 的音訊
    ↳ 實際 prompt 會這樣寫：照 video one 的感覺重拍，產品換成 image one 裡的，聲音用 audio one。等於分別指定要學誰的風格、賣什麼、用誰的聲音。
  • 04:36 可在 prompt 中動態引用不同參考素材；例如喜歡某人念稿的方式或聲音，就把它當音訊參考，再用圖片參考換掉角色、氛圍或手上的產品
    ↳ 素材可以混搭。例如你喜歡某人講話的語氣，就拿他的錄音當聲音參考，再用圖片把人物、場景或手上拿的產品換成你要的。
  • 05:06 影片、圖片、音訊三個變數可自由組合，幾乎每次都能做出不同的影片
    ↳ 影片、圖片、聲音三種素材可以各自替換，組合方式很多，幾乎每次都能做出不同版本，很適合大量測試不同的廣告。
  • 05:06 用影片參考可延長影片：Vio 3.1 有 extend 功能但只能延長；這裡可寫「continue /video one」並指定接下來的台詞、動作或場景變化
    ↳ 參考影片也能用來接著拍。Vio 3.1 的 extend（延長）只能往後接；這裡可以寫「continue /video one」，還能指定接下來的台詞、動作或換到什麼場景。
  • 06:07 延續影片時會保留參考影片的角色、光線、聲音等一致性
    ↳ 接續的片段會保留原片的人物長相、光線和聲音，不會接起來突然換了個人，或色調整個跳掉。
  • 06:07 也能編輯影片：SeaDance 網站範例用 prompt「remove any visible production mistakes」，保留原片內容但把入鏡的攝影機移除
    ↳ 也能拿來修片。SeaDance 官網的範例用「remove any visible production mistakes」（移除看得到的拍攝失誤），內容不變，只把不小心入鏡的攝影機拿掉。
  • 06:37 參考圖範例：起始幀是空的水泥房間、結束幀是設計好的客廳，生成整個轉變的縮時影片，適合房地產相關用途
    ↳ 用圖片指定頭尾畫面：開頭是空的水泥毛胚屋，結尾是裝潢好的客廳，AI 會生出中間整段 time lapse（縮時，快轉呈現變化過程），很適合房仲或裝潢業。
  • 07:07 綠幕範例：上傳兩人打鬥的綠幕影片加上角色參考圖，讓模型用這兩個角色在指定場景重現動作
    ↳ green screen（綠幕，拍完可以換背景的綠色布景）的用法：上傳兩人在綠幕前打鬥的影片，加上兩張角色圖，AI 會讓這兩個角色在你指定的場景做出同樣動作。
  • 07:38 實例一：網紅開箱虛構的 Mr. Paid Social Vans 鞋款，prompt 只寫「create an influencer try-on video promoting these shoes」
    ↳ 第一個例子是網紅試穿虛構的 Mr. Paid Social Vans 鞋款。prompt 只寫一句「做一支推這雙鞋的網紅試穿影片」，其他都交給模型。

    ↳ 做法是上傳鞋子圖片，在 prompt 裡用 image one 指到它。講者認為最多能放 9 張參考圖，也可以分別寫每張圖要拿來做什麼。
  • 08:38 實例二：開箱影片，prompt 要求 image one 做成 POV、ASMR 風格，拉高開箱、紙張摩擦聲，不要音樂，只有包裝聲
    ↳ 第二個例子是開箱，要求用 POV（第一人稱視角，像自己的手在拆）和 ASMR（放大細小聲音、讓人放鬆的風格），只留拆包裝和紙張的聲音，不配音樂。
  • 09:09 實例三：推廣 App 時，可到官網抓 App 的手機截圖當參考圖，prompt 要求網紅拿手機展示這個 App，並附上 App 網址
    ↳ 第三個例子是推 App：直接到官網截 App 的手機畫面當參考圖，prompt 寫「讓網紅拿手機介紹這個 App」，並附上 App 網址。

    ↳ 截圖就算沒裁、很粗糙，AI 還是把它放進 iPhone 螢幕裡。它自己寫台詞，鏡頭在網紅和手機之間切換遠景與特寫，做出 15 秒片段。

    ↳ 第四個例子：把虛構品牌 Mr. Paid Social 的 Gen Z 穿搭單品拼成一張圖，要求做成 Instagram 網紅的生活感穿搭廣告，快節奏、自然光、像 iPhone 拍的。

    ↳ 成品裡的人真的穿上了衛衣、墨鏡、牛仔褲和鞋子，AI 還自己配了音樂，看起來就像真人創作者發在 TikTok 上的內容。

📘 術語
repo（程式庫）：字幕說這套工具是免費 repo，把連結丟進 Claude Code 就會自動完成設定
Claude Code agent（Claude Code 代理）：串接 Arc Ads AI 與 SeaDance 2.0，用來產生 AI 影片內容
credits（點數）：生成影片的費用單位，例如 10 秒影片 0.6 credits，480p 減半
aspect ratio（畫面比例）：可選 9 by 16 或 16 by 9
reference image / video / audio（參考圖片／影片／音訊）：上傳後在 prompt 用斜線引用，可指定各自的用途
extend（延長）：Vio 3.1 的功能，只能延長影片；SeaDance 可延續並改變場景
deepfake（深偽）：字幕提到模型早期因名人影片和 deepfake 惹上麻煩
POV（第一人稱視角）：開箱影片 prompt 中要求的拍攝風格
ASMR（ASMR 聲音風格）：開箱 prompt 要求拉高開箱、紙張聲，不要音樂
green screen（綠幕）：上傳綠幕打鬥影片加角色圖，重現動作到新場景
time lapse（縮時影片）：用起始幀與結束幀圖片生成整段轉變過程
remix（混製）：Arc Ads 中下載影片後按 remix 放入影片，用來延長超過 15 秒
