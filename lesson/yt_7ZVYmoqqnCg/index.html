看全部 7 條重點

🧑‍🏫 這支是 OpenAI 示範 ChatGPT 的 workspace agents（在公司工作環境裡替團隊代辦事情的 AI 助手）。示範的例子是軟體審查 agent「Slate」。它讓你看到，員工申請新軟體這種瑣碎又常卡關的流程，可以交給 AI 先處理。

  • 00:03 Arjun 介紹他們打造的軟體審查 agent「Slate」，Slate 每次都會透過 skill 照團隊的審查流程執行
    ↳ Agent 是能自己一步步把任務做完的 AI 助手。Slate 專門審查同事想用的新軟體，每次都照團隊定好的流程走，不會今天這樣審、明天那樣審。
  • 00:03 Skills 定義最佳做法，也包含必要指示，讓 agent 能準確、一致地完成工作
    ↳ Skill 就像給新人的作業手冊，寫清楚怎麼做最好、哪些步驟一定不能漏。agent 照著做，結果才會準確，每次也都一致。
  • 00:03 Slate 用 skill 做網路研究、檢查核准軟體清單等條件，並評估各系統的訊號來建議下一步，必要時會轉交 IT
    ↳ Slate 會先上網查這套軟體，再看它在不在公司核准清單上、符不符合其他條件，綜合各系統查到的資訊給建議。自己處理不了的，就轉給 IT 部門。
  • 00:35 Slate 可以輕鬆設定在 Slack 裡使用，也就是團隊現在提出這類申請的地方
    ↳ Slack 是很多公司在用的工作聊天軟體。Slate 可以直接放進 Slack，同事照平常在 Slack 提申請的習慣，改成找 Slate 就好。
  • 00:35 實例：有員工在 Slack 向 Slate 申請高品質的錄影工具來錄 demo，Slate 會研究這個工具，並和已核准軟體裡的類似工具比較功能
    ↳ 例如有同事想要一個好一點的錄影工具，用來錄產品展示（demo）。Slate 會先查這個工具，再拿公司已核准軟體（approved stack）裡功能相近的工具來比功能。
  • 00:35 Slate 會回覆建議，並幫使用者開 Jira ticket，因為這個申請需要 IT 支援增加授權席次
    ↳ Slate 給完建議，還會幫忙開 Jira ticket，也就是在工作追蹤系統 Jira 裡開一張待辦工單。這是因為這次需要 IT 增加授權席次，也就是多開可以使用的帳號名額。
  • 01:07 Slate 可以自己處理大量、有時效性的申請，幫 IT 和採購團隊省時間，也讓使用者不被卡住
    ↳ 這類申請量大又趕時間，Slate 能自己先處理掉，IT 和採購就不用一件件回。申請的人也不必乾等，工作不會卡住。
📘 術語
skill（技能）：定義最佳做法，也包含必要指示，讓 agent 準確、一致地完成工作
approved stack（已核准軟體清單）：公司已核准的軟體工具，Slate 會拿申請的工具和裡面的類似工具比較功能
✏️ 小考一題

影片示範中，員工申請錄影工具後，Slate 為什麼要幫使用者開 Jira ticket？

A. 因為員工要求退回已購買的軟體B. 因為 Slack 無法直接回覆建議C. 因為這個工具不在網路上查得到D. 因為這個申請需要 IT 支援增加授權席次
看答案
答案：D。字幕 [00:35]–[01:07] 說 Slate 會回覆建議並開 Jira ticket，因為這個申請需要 IT 支援增加授權席次
