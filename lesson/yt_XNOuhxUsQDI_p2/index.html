🧑‍🏫 這是 Meta 官方影片的後半段。Zuckerberg 說明個人 AI 助理 Muse 會主動幫你做哪些事、怎麼保護你的隱私和錢，也談他對未來兩年的想像。如果你想知道「把生活交給 AI 代辦到底安不安全」，這段講得最具體。

  • 12:42 Muse 能檢查你訂閱的所有服務，找出重複的訂閱，經你同意後幫你取消來省錢
    ↳ Muse 會把你每個月被扣款的訂閱全部翻一遍。像是同時付了兩個功能差不多的影音平台，它會指出來。你點頭後它才去取消，幫你省下冤枉錢。
  • 12:42 Muse 越了解你，越會提出為你量身打造的點子：Zuckerberg 和女兒玩電腦遊戲，Muse 主動提議做一個講 Civilization 遊戲策略的網站
    ↳ 它越懂你，建議就越合你的需要。Zuckerberg 常和女兒玩《文明帝國》（Civilization，一款經營文明的策略遊戲），Muse 就自己提議幫他做一個專講這款遊戲攻略的網站。
  • 13:14 之後 Muse 又提議在網站加一個分頁，讓他邊玩邊教女兒遊戲中各文明的歷史
    ↳ 接著它又加碼，建議在網站多開一頁，介紹遊戲裡各個文明的真實歷史。這樣他陪女兒玩遊戲，也能順便教她歷史。
  • 13:44 Muse 的一大重點是會主動提出改善生活的方法，也會提議可以替你做、或讓你和在乎的人一起做的專案
    ↳ 重點是它不只等你下指令，還會主動提點子：生活哪裡可以更順、哪件事它可以代勞、哪個專案適合你和家人朋友一起做。
  • 14:14 做面向一般消費者的 agentic AI，最重要的是信任與安全：Muse 至少要了解你的目標，而使用者會放很多資訊進去
    ↳ agentic AI 指的是會實際動手替你辦事的 AI，這種 AI 常被叫做 agent。要做給一般人用，最關鍵的是信任：它得懂你的目標，你也會交給它大量私人資料。
  • 14:48 團隊借鏡 WhatsApp 的端對端加密（Meta 看不到訊息內容），設計出叫 confidential VM（virtual machine）的架構
    ↳ 他們參考 WhatsApp 的端對端加密（訊息全程上鎖，連經手的 Meta 都讀不到），做出 confidential VM：雲端上一台上了鎖、只屬於你的虛擬電腦。
  • 15:20 使用 confidential VM 時，連 Meta 也看不到你放進 Muse agent 的內容；他說就他所知別人沒有類似的東西
    ↳ 意思是你交給 Muse 的內容，連 Meta 自己都看不到。Zuckerberg 說就他所知，目前別家沒有類似的設計，不過這是他本人的說法。
  • 15:50 Secure credential store：帳號密碼、信用卡號放在 vault 裡，agent 本身不知道；要用的時候會先徵求你的同意
    ↳ secure credential store（又稱 vault，保險庫）專門放帳密和卡號。agent 本身看不到裡面的內容，真的要用時會先問你同意。
  • 15:50 設計原則：重大決策都要讓使用者 in the loop，不能讓 agent 自己跑去替你做一堆決定
    ↳ in the loop 是「讓你留在決策流程裡」的意思。大事一定要經過你，不會讓 agent 自作主張，一口氣替你做一堆決定。
  • 16:22 還有第二個 agent 叫 Sentinel，負責監看主 agent 在做什麼，發現你可能需要參與的事情就會提醒你
    ↳ Sentinel（哨兵）是第二個 agent，像在旁邊盯場的人：看著主 agent 在做什麼，一發現需要你出面決定的事，就提醒你。
  • 16:55 這類 agent 要成功，使用者必須對安全有信心，才敢交出大量生活脈絡，所以團隊從底層就花很多心力做安全
    ↳ 道理很簡單：你不放心，就不會把生活細節交出去；沒有這些細節，agent 也幫不上忙。所以團隊從最底層就先把安全做紮實。
  • 17:25 主持人提到自己 Muse 的 VM（私人電腦）裡存著記憶和資料，只給自己的 agent 使用
    ↳ 主持人說，她那台 Muse 專屬的雲端電腦裡存著她的記憶和資料，只有她自己的 agent 能用。
  • 17:25 哪些事要先問你：第一次存取新服務或第一次做交易時，都要取得你的同意
    ↳ 什麼時候一定會先問你？有兩種情況：第一次連進某個新服務（例如第一次碰你的信箱），或第一次幫你花錢交易。
  • 17:58 能自主做什麼不是主 agent 自己決定的，而是由 Sentinel 監看從 VM 流出的資料，遇到敏感內容就先交給你審查再執行
    ↳ 能不能放行不是主 agent 自己說了算。Sentinel 會檢查從那台私人電腦往外送的資料，碰到敏感內容就先擋下來，等你看過同意才繼續。
  • 18:30 Muse 系統由多個 agent 組成：一個替你做事，另一個專門確保資料安全、讓該由你看的事交給你看
    ↳ 所以 Muse 其實是一組 agent 分工合作：一個負責幫你辦事，另一個負責守門，確保資料安全，該你拍板的事一定送到你面前。
  • 18:30 主持人說她會用 Muse 購物、訂旅遊行程，這些都會用到付款功能
    ↳ 主持人會用 Muse 買東西、訂旅遊行程。這些事都得付錢，所以接下來談的是它怎麼處理你的信用卡。
  • 19:02 信用卡存在安全的付款系統；實際交易時 Muse 用一次性虛擬卡號付款，商家看不到真實卡號
    ↳ 信用卡存在安全的付款系統裡。結帳時 Muse 改用 one-time virtual card number（一次性虛擬卡號），用完就作廢，商家看不到你的真卡號。
  • 19:34 Zuckerberg 說自己常因為麻煩就不開虛擬卡，而 agent 不怕多做這些工作，所以預設就是盡量少揭露資訊
    ↳ Zuckerberg 坦言自己常嫌麻煩，懶得開虛擬卡；但 agent 不嫌煩，多幾道手續也照做。所以預設就是能少給就少給，盡量不透露你的資料。
  • 19:34 連接新系統（像 email）時預設給最小權限，例如不一定要給能編輯內容的寫入權限
    ↳ least privilege（最小權限）是只給剛好夠用的權限。例如連上你的 email 時，可以只讓它讀信，不一定要給它修改內容的權限。
  • 20:05 大多數人最常要的只是讓 agent 取得生活各方面的脈絡；架構的基礎是最小權限、最少揭露
    ↳ 大多數人其實只需要 agent 看得到生活各方面的狀況，不一定要它動手改東西。所以整個架構的基礎就是：權限給最少、資料露最少。
  • 20:35 長期記憶大多由 Muse 自己判斷；但像帳密這類跟安全有關的東西放在 secure credential store，不放在 agent 的資料庫或記憶裡
    ↳ 長期要記住什麼，大多由 Muse 自己判斷。帳密這類跟安全有關的東西是例外，只放在保險庫裡，不會混進 agent 的資料庫或記憶。
  • 20:35 Muse 每天晚上會回顧當天做過的事，壓縮成記憶；他比喻成人類睡覺時整理記憶
    ↳ 每天晚上 Muse 會回顧當天做過的事，把重點濃縮成記憶，這叫 compact（壓縮）。他把這比喻成人睡覺時整理白天的記憶。
  • 21:08 每個月都會推出更強的新模型；剛推出 Muse Spark 1.3，你的 Muse agent 近幾天內可能就會升級
    ↳ 更強的新模型大約每個月出一版。最新的是 Muse Spark 1.3（驅動 Muse 的 AI 模型，可以想成它的大腦），你的 Muse 可能這幾天就會升級。
  • 21:08 升級後會更聰明、能自動做更多事，也更會壓縮記憶：記住對的事、不記無關的事
    ↳ 升級後會更聰明、能自己完成更多事，記憶也整理得更好：該記的記住，無關的瑣事就不存。
  • 21:40 預測兩年後：很多人會用個人 agent 經營事業
    ↳ 他預測兩年後，會有很多人靠自己的個人 agent 經營一門生意。
  • 22:15 目標之一是「business in a box」：有了點子，agent 幫你做出產品、建立網路曝光、串接 Meta 各項服務、跑廣告、處理後端，替你經營、幫你賺錢
    ↳ business in a box 是「整套生意打包好」的意思：你只要出點子，agent 就幫你做產品、讓網路上找得到你、串接 Meta 各項服務、下廣告、處理後台，替你經營賺錢。
  • 22:48 離這個目標還有多遠要再看看，但模型進步很快；每個人喜歡的環節不同，讓 agent 做其餘的部分會很有價值
    ↳ 離這個目標還多遠，他說還要再看，但模型進步很快。每個人喜歡做的環節不同，把自己不想碰的部分交給 agent，就很有價值。
  • 22:48 健康用途：現在已經有人用在運動、睡眠等健康和訓練方面
    ↳ 健康方面，現在已經有人用它來管理運動、睡眠這類健康和訓練的事。
  • 23:21 他猜未來幾年 AI 模型會開始為不同疾病設計治療方式
    ↳ 他猜未來幾年，AI 模型會開始替各種疾病設計治療方式。這是他個人的預測，還不是已經做到的事。
  • 23:21 他在 Meta 以外主要的慈善工作是和 Priscilla 一起創立的 Biohub；他們的心得是罕見疾病有很長的長尾
    ↳ 他在 Meta 以外主要的慈善工作，是和太太 Priscilla 一起創立的 Biohub。他們的心得是：罕見疾病種類多到數不完，但每一種的病人都很少，這就叫「長尾」。
  • 23:53 產業主要研究常見疾病，因為市場大；只有幾十或幾百人得的病，生技公司沒有足夠誘因去研發
    ↳ 藥廠多半研究常見病，因為病人多、市場大。一種病如果只有幾十、幾百人得，研發不划算，生技公司就沒有動力去做。
  • 23:53 代表你行事的模型如果掌握你的病況、你是誰、你的病史等資訊，可能可以幫你想出個人化的治療方式
    ↳ 如果替你辦事的 agent 掌握你的病況、你是怎樣的人、你的病史，也許能幫你想出只適合你的治療方式，補上藥廠不會去做的那一塊。
  • 24:25 他猜幾年內就會出現或接近出現；人們會有個人 agent 有效幫忙處理健康問題，因為每個人都不一樣
    ↳ 他猜幾年內就會出現，或至少很接近。因為每個人的身體狀況都不一樣，一個真正懂你的個人 agent，能實際幫你處理健康問題。
📘 術語
agentic AI（代理式 AI）：主持人用來形容 Muse：會替你執行任務、面向一般消費者的 AI 產品
end-to-end encrypted（端對端加密）：WhatsApp 的架構，訊息經過 Meta 伺服器時是加密的，Meta 看不到內容
confidential VM (virtual machine)（機密虛擬機）：Muse 的架構，使用時連 Meta 也看不到你放進 Muse agent 的內容
secure credential store / vault（安全憑證庫／保險庫）：存帳密和信用卡號的地方，agent 不知道內容，要用時會先徵求你的同意
in the loop（參與決策迴圈）：重大決策讓使用者參與，不讓 agent 自己做一堆決定
Sentinel（Sentinel（哨兵 agent））：第二個 agent，監看主 agent 和從 VM 流出的資料，發現敏感內容就交給你審查
one-time virtual card number（一次性虛擬卡號）：Muse 付款時用的卡號，商家看不到你真正的卡號
least privilege（最小權限）：連接新系統時預設只給最少的權限，例如不給編輯內容的寫入權限
compact (memories)（壓縮（成記憶））：Muse 每晚回顧當天做的事，整理成記憶，就像人睡覺時整理記憶
Muse Spark 1.3（Muse Spark 1.3）：剛推出的模型，Muse agent 近幾天內可能會升級到這版
business in a box（一盒裝的事業）：有了點子，agent 就幫你做產品、建立網路曝光、跑廣告、處理後端，替你經營事業
Biohub（Biohub）：Zuckerberg 和 Priscilla 創立的慈善計畫，是他在 Meta 以外主要的慈善工作
✏️ 小考一題

根據影片，Muse 用什麼方式決定某個動作要不要先讓使用者審查？

A. 每一個動作都一律先徵求使用者同意B. 由主 agent 依自己的判斷，決定哪些事可以自主完成C. 由另一個叫 Sentinel 的 agent 監看從 VM 流出的資料，發現敏感內容就交給使用者審查D. 由 Meta 的人工審核團隊檢查每一筆交易
看答案
答案：C。[17:58] 字幕說主 agent 自己不能決定能做什麼，而是由另一個叫 Sentinel 的 agent 監看從 VM 流出的資料，發現敏感內容就先交給使用者審查，再執行動作
