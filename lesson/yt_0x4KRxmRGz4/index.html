看全部 9 條重點

🧑‍🏫 這支影片是美國汽車買賣平台 CarGurus 分享他們怎麼在全公司導入 OpenAI 的 AI 工具。重點不在技術細節，而是一家公司把 AI 用到多深：讓工程師不必親手寫程式，還能在兩天內做出一個一年省下大量人力成本的小工具。想知道 AI 在真實公司裡實際省下什麼的人，值得一看。

  • 00:06 CarGurus 的使命是把世界各地的買車者和賣車者連結起來
    ↳ CarGurus 是一個線上買賣汽車的平台，做的事就是讓想買車和想賣車的人找到彼此。先記住這點：這是一家靠網站和軟體在運作的公司。
  • 00:06 CarGurus 在整個組織裡大量使用 CodeX
    ↳ CodeX 是 OpenAI 做的 AI 寫程式工具，你用文字交代要做什麼，它就幫你寫程式、改程式。CarGurus 不是只有少數人在試用，是整間公司都大量在用。
  • 00:06 他們的目標是讓每位工程師都「不用自己寫程式」（free from coding）
    ↳ 「free from coding」不是說工程師從此沒事做，而是不用再親手一行一行寫程式。他們改成負責想清楚要做什麼、交代給 AI 去做，最後檢查成果。
  • 00:06 他們認為如果能做到，效率提升會是指數級的，而且不只是程式碼的數量，也包括程式碼的品質
    ↳ 他們認為把寫程式交給 AI 以後，程式不只寫得更多，品質也會更好，而且效益會一直往上疊加，不會只是多個一兩成就停住。
  • 00:06 OpenAI 在幾週前推出 agents，發布後 48 小時內，他們就做出一個給所有產品團隊用的 CAPEX agent
    ↳ agent（代理）指的是會自己去讀資料、使用各種工具，把一整件事做完的 AI，而不只是你問一句它答一句。OpenAI 推出 agents 後，他們兩天內就做出一個全產品團隊都能用的 agent。
  • 00:36 這個 CAPEX agent 會查看行事曆、Slack 和團隊正在處理的 Jira issues，整理出每週時間表，顯示時數花在哪裡
    ↳ CAPEX 是「資本支出」的縮寫，公司需要知道人力花在哪些專案上。這個 agent 會自己看行事曆、Slack（工作聊天軟體）和 Jira（追蹤工作任務的系統）裡的任務，整理出每週時數表。
  • 00:36 光靠這一個 agent，整個組織一年大約可省下一百萬（a million a year）的人力工時成本
    ↳ 以前這種時數表要每個人自己回想、自己填，現在交給 agent 做。把全公司省下來的時間換算成人力成本，一年大約一百萬。光一個小工具就能省這麼多。
  • 01:06 模型變化得很快，3 個月前試過的東西，現在的運作方式可能已經完全不同
    ↳ AI 模型進步得很快，三個月前試過、覺得不好用的做法，現在可能已經行得通了。所以不要試一次失敗就放棄，隔一陣子值得再試一次。
  • 01:06 講者說之後有幾個晚上睡不著，腦中不斷冒出各種可能：工作方式會怎麼改變、這會怎麼改變他們的產業
    ↳ 講者說自己興奮到好幾個晚上睡不著，一直在想大家的工作方式、甚至整個汽車買賣產業會被怎麼改變。講者覺得這不是小改善，而是整個產業的大轉變。
📘 術語
CodeX（CodeX（OpenAI 產品））：CarGurus 在整個組織大量使用的工具，目標是讓工程師不用自己寫程式
agent（代理程式）：字幕沒有定義；只提到 OpenAI 幾週前推出 agents，CarGurus 在 48 小時內做出自己的 agent
CAPEX agent（CAPEX agent）：給產品團隊用的 agent，會看行事曆、Slack、Jira issues，整理出每週時數分配
Jira issues（Jira 工作項目）：字幕只說是產品團隊正在處理的 Jira issues，agent 會讀取這些資料
man hours（人力工時）：這個 agent 每年大約可替整個組織省下一百萬的工時成本
✏️ 小考一題

OpenAI 推出 agents 之後，CarGurus 花了多久做出 CAPEX agent？

A. 一個月B. 48 小時C. 24 小時D. 72 小時
看答案
答案：B。字幕 [00:06] 說 “48 hours after you guys released the agents … we had already created a CAPEX agent”
