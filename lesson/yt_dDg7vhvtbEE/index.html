    ↳ 第一次見客戶前，她要先弄清楚：對方是誰、在做什麼、怎麼用 Claude、目前花多少錢，還有這個客戶是有流失的跡象，還是正在成長。

    ↳ skill file 就是一份文字說明書，寫清楚要去哪裡找資料、哪些使用數據要特別注意、結果要怎麼整理。之後每次都照這份做，不用每次重講一遍。

    ↳ Claude 要讀得到資料，得先在設定裡把這些系統接上。她已經接好資料倉儲、Salesforce、網路、email 和 Slack，skill 才有地方抓資料。

📘 術語
Growth account executive（成長型客戶經理）：講者的職稱，負責管理一組最具策略性的新創客戶帳戶
Cowork session（Cowork 工作階段）：在 Cowork 裡開的對話階段，可以用來建立 skill 或執行 skill；會後回到同一個 session，帳戶脈絡還在
Skill / skill file（技能／技能檔）：基本上是一個文字檔，告訴 Claude 怎麼處理任務：要看哪些資料來源、哪些訊號重要、怎麼呈現結果
Salesforce（Salesforce（客戶管理系統））：客戶資訊分散的來源之一，Claude 會從這裡抓 open opportunities
Data warehouse（資料倉儲）：客戶資訊分散的來源之一，已在設定裡連接
Open opportunities（進行中的商機）：存在 Salesforce 裡、Claude 執行 skill 時會抓取的資料
Account brief（客戶帳戶簡報）：產出的策略文件讀起來就像這樣的簡報，內容包括花費、使用的模型、進行中的交易、風險訊號
Account strategy builder（帳戶策略產生器）：會前準備用的 skill 名稱，輸入 / 後選取，再輸入帳戶名稱
Call transcript processor（通話逐字稿處理器）：會後用的 skill，會抓取通話逐字稿，產出待辦事項、內部 Slack 訊息和客戶跟進訊息
