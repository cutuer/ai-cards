📘 術語
Claude skill（Claude 技能）：本質是一份文字文件，指示 Claude 如何存取各模型，可依工作高度客製化。
/generate（生成指令（slash generate））：作者自建的 skill，用斜線指令在 Claude 中呼叫，負責選模型、寫 prompt、生成與記錄。
wrapper（包裝層）：作者說 Higgsfield 的核心就是這些創意 AI 模型的包裝。
model aggregator（模型聚合商）：把多家模型的串接整合起來，透過自家網站或一個帳號提供，例如 fall、wave speed、key。
pay as you go（用多少付多少）：不收月費，只按實際生成量收費，例如只生成五張就只付五張的錢。
API key（API 金鑰）：聚合商讓你用一個帳號、一個 API key 存取所有模型。
terms of use（使用條款）：Higgsfield 即將更新的條款，提到他們可使用你生成的內容並擁有權利。
deletion window（刪除期限）：刪帳號或退訂後，只有有限時間可下載圖片，之後永久刪除。
hard rules（硬性規則）：寫進 skill 的強制規則，例如送出前一定先報價，避免耗光 credits。
logging（記錄機制）：儲存 Claude 傳給模型的所有 prompt，需要時可回頭查。
masonry grid / infinite canvas（瀑布流網格／無限畫布）：把所有生成的圖片和影片放在同一個畫布上瀏覽，類似 Higgsfield 的介面。
aspect ratio（長寬比）：字幕舉例：生成 2k 解析度、1:1 長寬比的圖片來比較價格。
one shot prompt（一次性提示）：只下一個指令，Claude 就完成約 70%–80% 的網站。
