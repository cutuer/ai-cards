🧑‍🏫 這支是甜甜圈系列第 5 集的前段，教你幫桌子貼上真實的混凝土材質，並第一次打開 Blender 專門調材質的 Shading 分頁。看完你會知道：為什麼網路上隨便抓一張照片貼上去總是假假的，以及專業做法要多準備哪些圖、怎麼把它們接進 Blender。

  • 00:00 簡單材質對某些物件就夠用，例如一個白盤子不需要貼圖；但大多數東西都需要貼圖。
    ↳ 不是每樣東西都要貼圖。白盤子這種單色物件，調個顏色就像了。木頭、石頭這類有花紋的表面，就得靠貼圖（Texture，蓋在物體表面的圖片）才會真實。
  • 00:00 選取桌面（table floor），到材質面板。因為它還沒有材質，所以先新增一個材質。
    ↳ 先點選桌面這塊平面，打開材質面板（Material panel，調材質設定的區塊）。它原本沒有材質，所以第一步是按新增，建立一個材質。
  • 00:00 要加彩色貼圖，就點 Base Color 旁邊的黃色小點。講者說這一步現在看不太懂，之後講 nodes 就會清楚。
    ↳ Base Color 是材質的基本顏色。旁邊的黃色小點能把「單一顏色」換成「一張圖」。現在看不懂沒關係，之後講到節點就會串起來。
  • 00:36 點下去會跳出選單，選 Image Texture，再按 Open 選圖片。示範用的是從網路下載的木紋貼圖。
    ↳ 點黃點後選 Image Texture（載入圖片當顏色來源的功能），再按 Open 找圖檔。這裡先用網路上下載的木紋圖示範。
  • 00:36 Blender 5.0 新功能：檔名裡如果有 1,000 到 2,000 之間的數字（講者說「我想」），Blender 會把它當成 UDIM。
    ↳ Blender 5.0 會看檔名。檔名有 1000～2000 之間的數字，可能被當成 UDIM（把一個物件的貼圖拆成多張編號圖的專業做法）。講者自己也說「我想」，不是很確定。
  • 01:10 遇到被當成 UDIM 的情況，改成 Single Image 即可。大多數圖片結尾沒有那串數字，會正常載入。
    ↳ 如果圖片載入怪怪的、被誤判成 UDIM，把選項改回 Single Image（單張圖片）就好。多數檔名結尾沒有那串數字，不會碰到這個問題。
  • 01:10 只貼單張照片，看起來還可以，但沒有 bump 資訊。
    ↳ 只貼一張照片，遠看像木頭，但表面其實是平的。它沒有 bump（表面凹凸起伏）資訊，光打上去也不會在細縫裡產生陰影。
  • 01:41 原因：照片是單一相機拍的，3D 軟體不知道哪裡有凹縫或細木紋。技術上有辦法猜，但效果通常不好，所以不示範。
    ↳ 照片只是從一個角度拍下的顏色，軟體分不出哪裡凹、哪裡是木紋。雖然有方法從照片硬猜高低，但效果通常不好，講者就不教。
  • 02:13 3D 貼圖通常不會隨便抓網路圖片，而要用 PBR textures（physically based rendering textures）。
    ↳ 做 3D 通常不用隨手抓的圖，而是用 PBR textures：一整組照物理光學規則設計的貼圖，分開記錄顏色、高低、粗糙度等資訊。
  • 02:13 講者推薦 Poliigon（poliigon.com），這是他 10 年前創立的公司，他說現在是成長最快的線上貼圖庫。
    ↳ 講者推薦貼圖網站 Poliigon，也坦白說這是他 10 年前創立的公司。「成長最快」是他本人的說法，參考就好。
  • 02:47 攝影師用專門設備拍攝表面，通常拍上百次，才能捕捉高度、bump、光澤、反射等資訊，也就是各種 maps。
    ↳ 這些貼圖是攝影師用專門設備、拍上百次做出來的。高度、凹凸、光澤、反射分開記錄，每種資訊各存成一張 map（一張負責一種資訊的圖）。
  • 02:47 這些看起來很怪的 maps，正是 Blender 讓材質看起來寫實所需要的。
    ↳ 下載後會看到幾張灰灰紫紫、看不出是什麼的圖，別嚇到。這些 maps 正是 Blender 算出寫實質感的原料。

    ↳ 第一個要用的是 concrete（混凝土）貼圖，把桌子做成咖啡廳常見的水泥桌。

📘 術語
Texture（貼圖）：字幕說多數物件都需要貼圖；只用簡單材質只適合像白盤子這類東西。
Material panel（材質面板）：字幕說是簡化視圖，適合對材質做小修改。
Base Color（基礎色）：點旁邊的黃點可加入彩色貼圖；只載入這個會沒有高度資訊。
Image Texture（圖片貼圖（節點））：用來載入圖片檔的選項／節點，按 Open 選圖片。
UDIM（UDIM）：字幕說是完整的專業製作流程；檔名含特定數字時 Blender 5.0 會誤判成 UDIM。
Single Image（單張圖片）：圖片被誤判成 UDIM 時，要改成這個選項。
Bump（凹凸資訊）：表面凹縫、紋理起伏等資訊，單張照片沒有這些資訊。
PBR textures（PBR 貼圖）：physically based rendering textures，能提供高度、bump、光澤、反射等資訊。
Maps（PBR texture maps）（貼圖通道圖）：下載的那些不同圖片，是 Blender 讓材質寫實所需要的。
Add-on（外掛）：字幕說 Poliigon 的 Blender add-on 能讓下載和匯入貼圖更簡單。
8K（8K 解析度）：下載按鈕給的解析度；講者說大概用 4 就夠。
De-lit（去光照）：字幕用來形容乾淨的混凝土貼圖，未進一步解釋。
Shading tab（Shading 分頁）：螢幕上方的分頁，適合做複雜的貼圖工作。
Join Left / Join Down（向左合併／向下合併）：在視窗分隔線按右鍵，用來合併視窗。
Vertical Split（垂直分割）：在分隔線出現小箭頭處按右鍵，可把視窗左右分割。
Shader Editor / Shader nodes（著色器編輯器／著色器節點）：和材質面板是同樣的資訊，用來做較複雜的材質。
Material Output（材質輸出）：代表最終的材質。
Principled BSDF（Principled BSDF 著色器）：一種 shader，講者說現在約 99% 的材質都用它。
Material Preview（材質預覽模式）：專為預覽材質設計，會載入 HDR 環境，不必調燈光就能看材質。
HDR（HDR 環境）：Material Preview 周圍載入的假世界環境，可以更換。
Roughness（粗糙度）：材質數值之一；調整時材質面板和節點會同步改變。
Normal map（法線貼圖）：檔名含 _nor 的紫色圖，要接到 shader 上紫色的 normal 輸入。
✏️ 小考一題

用 Poliigon 的 PBR 貼圖時，檔名含 _nor 的那張紫色圖片，要接到 Principled BSDF 的哪個輸入？

A. Roughness 輸入B. Normal 輸入C. Material Output 節點D. Base Color 輸入

答案：B。字幕 [10:00] 說 _nor 紫色那張是 normal map，要接到 shader 上紫色的 normal 輸入。
