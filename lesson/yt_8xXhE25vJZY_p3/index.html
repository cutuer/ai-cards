🧑‍🏫 這段示範怎麼用 Grok bot 組一支 bot 小隊：把 bot 分組，用「示範給它看」的方式教它做 Google 表單，並存成之後能重複使用的技能，再讓 bot 之間互相交接工作。想讓 AI 幫忙處理重複性工作、又不會寫程式的人，可以從這裡看到「教一次、之後讓它自己做」實際怎麼操作。

  • 22:40 將新 teammate 命名為 Dex。label 不會改變 bot 的運作方式，用途是讓人記得這個 bot 是做什麼的
    ↳ 講者把新 bot 取名 Dex，再幫它加一個 label（標籤，像貼在 bot 旁邊的職稱）。label 不會改變 bot 怎麼做事，只是讓你一眼記得它負責什麼。
  • 22:40 label 範例：Cliff 的 bot 標為 driver，講者的 Bobo 標為 life stabilizer，Dex 標為 designer
    ↳ label 可以隨你取，像職稱或綽號都行：Cliff 的 bot 負責開車就叫 driver，講者的 Bobo 叫 life stabilizer（生活穩定器），Dex 負責設計就叫 designer。
  • 22:40 設定好之後，只要用純文字（plain text）告訴 bot 它的角色是什麼即可
    ↳ 真正決定 bot 做什麼的不是 label，是你用 plain text（一般文字，就像平常傳訊息那樣打字）交代給它的角色，不需要寫程式或用特殊格式。
  • 23:12 左側有不同的 section，例如 unassigned bots。section 用來把 bot 分組，之後組成 bot 團隊時能清楚知道各自負責什麼
    ↳ 畫面左邊有 section（分組區塊），功能像資料夾，用來把 bot 分組；unassigned bots 放的是還沒分組的 bot。分好組之後，團隊裡誰負責什麼就很清楚。
  • 23:12 講者事先建好今天要用的三個 bot：Maya、Penny、Dex，選取後將三個 bot 移到一個新的 section
    ↳ 講者事先建好今天要用的三個 bot：Maya、Penny、Dex。她把三個一起選起來，搬進一個新的分組，等於組成一支小隊。
  • 23:42 新 section 移到最上方，命名為 sticker team（字幕記為「rock bot sticker team」）
    ↳ 新分組被拉到最上面方便找，取名 sticker team（貼紙小組），代表這三個 bot 是專門處理今天貼紙任務的團隊。
  • 23:42 本段目標：建立 Google 表單和 QR code，讓觀眾投票選出第一名的 Grok bot 貼紙（貼紙當時還沒做出來）
    ↳ 這段的實際任務是做一份 Google 表單，加上 QR code（手機一掃就能開啟連結的方形條碼），讓觀眾投票選出最喜歡的 Grok bot 貼紙。貼紙這時還沒做出來。
  • 24:12 用純文字告訴 Maya：她的角色是建立 Google 表單讓觀眾投票選貼紙，她唯一的工作就是做 Google 表單，講者會示範給她看
    ↳ 講者用一般文字告訴 Maya：妳唯一的工作就是做投票用的 Google 表單，我等一下會示範給妳看。交代的範圍越單純，bot 越不容易做到別的地方去。
  • 25:15 如果不知道怎麼讓 bot 運作起來，做法和 Cursor 很像：用自然語言說出你想完成的事，它甚至能引導你走對方向
    ↳ 如果不知道怎麼讓 bot 動起來，做法和 Cursor（內建 AI 的寫程式工具）很像：用平常說話的方式講出你想完成的事，它還會反過來引導你往對的方向走。
  • 25:15 請 Maya 在她的電腦上打開 Google 表單，讓講者可以接手操作
    ↳ 講者請 Maya 在「她自己的電腦」上打開 Google 表單。這裡的 bot 有一台自己能操作的電腦，講者等一下會在那台電腦上接手示範。
  • 25:48 點進 Maya 可看到 details，裡面是 Maya 的 routines。routines 讓 bot 不必等人下指令，可依每週、每月、每天、每小時甚至每分鐘的排程自動執行任務
    ↳ 點進 Maya 可以看到 details（詳細資料），裡面有 routines（例行任務）：設好排程，bot 就會每天、每小時甚至每分鐘自動去做，不用你每次下指令。
  • 25:48 library：和 Maya 合作後產生的照片或影片會顯示在這裡
    ↳ library（作品庫）是你和 Maya 合作後產出的照片、影片集中存放的地方，之後要找東西直接來這裡看就好。
  • 26:18 computer：可以看到 Maya 的螢幕和她正在做的事。畫面中可見 Maya 直接在電腦上開啟了 Google 表單
    ↳ computer（電腦畫面）可以即時看到 Maya 的螢幕和她正在做的事。畫面中可以看到她已經在自己的電腦上打開了 Google 表單。
  • 26:18 講者輸入「take over now」來接手控制
    ↳ 講者想自己動手時，直接輸入「take over now」（我現在接手），控制權就回到人身上，可以直接操作那台電腦。
  • 26:50 bot 會主動回頭詢問使用者，這就是和 Grok bot 之間的來回互動。講者回覆：跳過這步，讓我示範建立表單
    ↳ bot 遇到不確定的地方會主動回頭問你，你回答後它再繼續，這種一來一往就是合作的方式。講者回它：這步先跳過，讓我示範表單怎麼做。
  • 26:50 使用 teach a task 功能，讓 Maya 看講者如何完成一個特定流程
    ↳ teach a task（教一個任務）就是讓 bot 在旁邊看你實際操作一遍，類似帶新同事時「你先看我做一次」，它會從中學會這套流程。
  • 27:21 teach a task 不限於 Google 表單，也適用於內部 dashboard 或任何平台，包括需要多種輸入、從不同來源打字的工作。示範時 Maya 處於觀看學習狀態
    ↳ 這招不只能教做表單，公司內部的 dashboard（數據儀表板）或其他平台也都能教，包括要從不同來源複製、打字填很多欄位的工作。示範時 Maya 就在旁邊觀看學習。
  • 27:51 示範表單標題為 Practice Grok bot sticker vote，說明為讓觀眾投票選貼紙。第一題「你最喜歡的顏色？」只用來示範，不會放進 QR code 發出
    ↳ 示範表單的標題是 Practice Grok bot sticker vote，說明寫的是讓觀眾投票選貼紙。第一題「你最喜歡的顏色」只是用來示範操作，不會放進 QR code 發給觀眾。
  • 28:21 第一題選項設為 blue、red 並設為必填。第二題加入圖片，圖片來自連結到帳號的 Google Drive
    ↳ 第一題的選項設成 blue、red，並設為必填（沒回答就不能送出）。第二題插入一張圖片，圖片是從帳號連結的 Google 雲端硬碟拿的。
  • 28:55 第二題「哪個貼紙是你的最愛」設為選擇題，選項為 Option 1、Option 2 並設為必填
    ↳ 第二題「哪個貼紙是你的最愛」做成選擇題，選項先寫 Option 1、Option 2，同樣設為必填。因為貼紙還沒做好，先用代稱占位。
  • 28:55 按 publish，權限設為 anyone with a link，讓所有觀眾都能存取
    ↳ 最後按 publish（發布），權限設成 anyone with a link（拿到連結的人都能填），這樣所有觀眾都能打開表單投票。
  • 29:26 暫停錄製後告訴 Maya：之後進到貼紙階段時，她要建立 QR code 讓觀眾使用 Google 表單
    ↳ 停止錄製後，講者再用文字補一句：之後進到貼紙階段時，妳要做 QR code 讓觀眾用表單。示範教的是「怎麼做」，文字補上的是「什麼時候做」。
  • 29:57 錄製結束後，bot 會告知它會用哪個 skill 來學習。若只叫 Maya 直接建表單，她會去看 HTML div 猜測講者要什麼選項
    ↳ 錄完後 bot 會說它要用哪個 skill 來學。如果沒有示範、只叫 Maya 直接做，她會去讀網頁原始碼（HTML div）來猜你要哪些選項，容易猜錯又浪費時間。
  • 29:57 從 tokenomics 以及引導 bot 照我們想要的方式做事的角度來看，這就是 skills 派上用場的地方
    ↳ tokenomics 指 AI 的使用成本：AI 依處理的文字量（token）計算，來回試錯越多就越花費。skill 能讓 bot 照你要的方式做，也省下這些浪費。
  • 30:28 原本要五個步驟的工作，可以把反覆嘗試的過程壓縮成一步
    ↳ 原本 bot 可能要摸索、試好幾輪才做得對，有了示範存成的 skill，就像直接照 SOP 做，可以一步到位。
  • 30:28 Grok bot 內建一個名為 learn from demonstration 的 skill，能把示範轉成可重複使用的 skill
    ↳ 能把示範變成 skill，是因為 Grok bot 本身內建了一個叫 learn from demonstration（從示範中學習）的 skill，專門把你的操作轉成能重複使用的能力。
  • 30:28 在公司 onboarding bot 時，可以把 skills 和 workflows 交給它，再做成 template，讓其他同事都知道這份工作怎麼操作
    ↳ 在公司讓 bot 上工時，可以把 skills 和 workflows（工作流程）交給它，再做成 template（範本），其他同事就能知道這份工作怎麼操作，不用每個人重教一次。
  • 30:59 Maya 看完示範後，把流程存成了一個 skill
    ↳ Maya 看完示範後，把這整套做表單的流程存成一個 skill（技能）。之後要做類似的表單，她可以照這套方法做，不用再從頭教。
  • 30:59 下一步：讓 bot 依序工作並彼此溝通。表單已經會做了，接下來需要知道要用哪些貼紙
    ↳ 表單已經會做了，但投票要放哪些貼紙還不知道。下一步是讓 bot 依序接力、互相溝通，像同事之間交接工作一樣。
  • 31:34 請 Maya 傳訊息給 @Dex：說明自己能建 Google 表單、會有觀眾投票，請 Dex 和 Martin 一起做貼紙，在和 Martin 談過之前什麼都不要做
    ↳ 講者請 Maya 傳訊息給 Dex：說明自己會做表單、觀眾會來投票，請 Dex 和 Martin 一起做貼紙，而且在跟 Martin 討論之前什麼都先不要做。
  • 32:04 bot 團隊不只能處理你工作中的一部分，完成後還能把工作再委派下去
    ↳ bot 團隊不只能幫你分擔一部分工作，做完之後還能把下一棒交給別的 bot，你不用每一步都親自轉交。
  • 32:04 Maya 存下的 skill 名為 create and publish Google form
    ↳ Maya 存下的 skill 叫 create and publish Google form（建立並發布 Google 表單），名稱直接說明了用途，以後也很好認。
  • 32:35 下次只有在 prompt 和這個 skill 相關時，bot 才會套用它，否則即使有很多 skill 也不會帶進來
    ↳ skill 不會每次都被帶進來。只有當你的 prompt（給 AI 的指令）和它有關時，bot 才會使用；就算存了很多 skill，無關的也不會被拿出來用。
  • 32:35 Grok bot 的優點是能清楚看到 bot 們在做什麼。可看到 Maya 傳給 Dex 的訊息：自我介紹、說明她的工作，並請 Dex 和 Martin 一起做貼紙選項
    ↳ Grok bot 的好處是看得到 bot 們在做什麼。例如可以直接看到 Maya 傳給 Dex 的訊息：她先自我介紹、說明自己的工作，再請 Dex 和 Martin 一起做貼紙選項。
  • 33:43 接著要思考能給 Grok bot 哪些 connectors，例如可以在 marketplace 找到的 Figma MCP
    ↳ 接著要思考能給 bot 接哪些 connectors（連接器，讓 bot 能使用外部工具），例如在 marketplace（工具商店）裡找得到的 Figma MCP，用來把設計軟體 Figma 接給 AI 使用。
  • 33:43 本例講者改用 Cursor 和 SpaceX AI 內部的一份 Figma 設計規範（字幕在此中斷）
    ↳ 這次講者沒有用 Figma MCP，而是改用 Cursor，搭配 SpaceX AI 內部的一份 Figma 設計規範。字幕在這裡中斷，後面怎麼做在這段看不到。
📘 術語
label（標籤）：不會改變 bot 的運作方式，用途是標示這個 bot 負責做什麼，方便記住
section（分區）：左側的分組區塊，例如 unassigned bots，用來把 bot 分組並了解各自的工作
unassigned bots（未分組的 bot）：左側的一個 section，存放尚未分組的 bot
routines（例行任務）：不必手動下指令，依每週、每月、每天、每小時或每分鐘的排程自動執行特定任務
library（資料庫）：和 bot 合作後產生的照片或影片會顯示在這裡
computer（bot 的電腦畫面）：可以看到 bot 的螢幕和它正在做的事，也能接手操作
teach a task（教學任務）：讓 bot 觀看你如何完成特定流程並從中學習，適用於表單、內部 dashboard 和各種平台
skill（技能）：把示範過的流程存成可重複使用的能力，只有在 prompt 相關時才會套用
learn from demonstration（從示範中學習）：Grok bot 內建的 skill，能把示範轉成可重複使用的 skill
tokenomics（token 經濟）：字幕在談引導 bot 照我們期望的方式做事時提到，作為 skills 有用的理由之一
template（範本）：把 skills 和 workflows 做成範本，讓其他同事知道某份工作怎麼操作
connectors（連接器）：可以提供給 Grok bot 使用的外部連接，例如 Figma MCP
Figma MCP（Figma MCP）：字幕舉的 connector 例子，可以在 marketplace 找到
marketplace（市集）：可以在這裡找到 Figma MCP 等 connector
