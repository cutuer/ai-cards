🧑‍🏫 這段講怎麼在 Blender 裡做分鏡：用 Grease Pencil（在 3D 空間裡畫 2D 線條的工具）畫圖，再搭配團隊新做的分鏡流程，在 VSE（內建剪輯時間軸）排鏡頭。講者特別強調要先把聲音做好，再補畫面。他也把 2D 和 3D 的三種分鏡做法講清楚了，適合想用 Blender 快速做廣告或短片提案的人。

  • 24:07 在色彩研究（color study）中加一點有形體的小塊，增加深度與體積，同時維持以色彩為主的簡單研究
    ↳ 色彩研究（color study）是先用色塊試配色和氣氛的練習圖。在裡面加幾塊有明暗形體的小物件，畫面就有前後深度，但主角仍然是顏色。
  • 24:37 新的 leaf 與 grass pieces 可以直接用，不必自己處理樹葉和草的紋理，就能在色彩研究中快速放進植物
    ↳ 新的樹葉（leaf）和草（grass）素材拿來就能用，不必自己一片片畫葉子紋理，做色彩研究時放植物會快很多。
  • 25:07 講者在 LA 時接過商業廣告工作。這段從 visual development 轉到 storyboarding 與 2D/3D storyboarding
    ↳ 講者在洛杉磯接過廣告案。這段從視覺開發（visual development，先想角色和環境長什麼樣）轉到分鏡（storyboarding，把故事畫成一格格鏡頭）。
  • 25:07 2D/3D storyboarding 可以當真人拍攝的藍圖：到片場前就知道要拍什麼、拍攝順序、需要租哪些鏡頭
    ↳ 2D/3D 分鏡等於真人拍片的施工圖：開拍前就決定好每個鏡頭拍什麼、先拍哪個、要租哪種鏡頭，到了現場不用臨時想。
  • 25:07 練好這項技能，就能把劇本轉成由多個鏡頭剪接而成的故事
    ↳ 劇本只是文字。分鏡能力就是把文字拆成一個個鏡頭，再剪接成觀眾看得懂的故事。
  • 25:47 團隊最近開發了新的 storyboarding project file workflow。講者說有點複雜，Pablo 在網路上有很棒的教學
    ↳ 團隊新做了一套專門給分鏡用的專案檔流程（project file workflow）。講者承認上手有點難，建議去看 Pablo 在網路上的教學。
  • 25:47 打開專案後可以看到各個 scenes
    ↳ 打開這個專案檔，會看到裡面已經分成好幾個場景（scenes）。scene 是 Blender 裡各自獨立的一組內容。
  • 26:24 建議（講者自稱可能跟紀錄片背景有關）一開始就在下方的 VSE editor 加入音樂和音效
    ↳ VSE（Video Sequence Editor）是 Blender 內建的剪輯時間軸，位在畫面下方。講者建議一開始就把音樂和音效放進去，他說這習慣可能來自拍紀錄片。
  • 26:24 流程：先做 vis dev 想角色與環境，畫很粗略的 thumbnails，再做 radio cut，最後把視覺疊上去
    ↳ 順序：vis dev 想角色和環境→畫超粗的小草圖（thumbnails）→做 radio cut，也就是先只用聲音剪出完整版本→最後才把畫面填上去。
  • 26:54 觀眾比較能原諒爛畫面，不太能原諒爛聲音。畫面粗糙可以被當成風格，音訊好壞則比較二元
    ↳ 畫面粗糙，觀眾會當成風格接受；聲音差就是差，沒有灰色地帶。所以聲音品質比畫面精緻更要緊。
  • 26:54 抓好節奏、有好的音訊和音樂就能傳達很多內容，所以前期要多投資在音訊上
    ↳ 節奏抓對、配樂和音效好，畫面再簡單也能把故事講清楚。所以前期要多花時間在聲音上，不要一開始就先磨畫面。
  • 27:28 講者聽說有新 plugin，可以直接對麥克風說出想要的台詞
    ↳ 講者聽說有新的外掛（plugin，裝進軟體的額外功能），可以直接對麥克風說台詞。這只是他聽說的，細節沒有講。
  • 27:28 音訊可以用拖放（drag and drop）方式放進去並播放
    ↳ 音檔可以直接從資料夾拖進時間軸，放進去就能播放，不用走複雜的匯入步驟。
  • 28:00 打開專案時最重要的是認識 auto-keying 按鈕
    ↳ 打開專案後最該先認識 auto-keying 按鈕。key（關鍵影格）會記下物件在某個時間點的位置或狀態。
  • 28:34 開啟 auto-keying 後，在時間軸上移動物件就會自動打 key。打開後可看到這些 key，並調整它們的時間
    ↳ 開啟 auto-keying 後，在某個時間點移動物件，就會自動記下 key，不用每次手動按。之後在時間軸上看得到這些 key，拖動就能改時間。
  • 28:34 storyboarding 有三種做法
    ↳ 講者把分鏡分成三種做法，後面逐一說明。
  • 29:08 第一種是把每個鏡頭都當成獨立、完整的 2D scene
    ↳ 第一種：每個鏡頭各做成一個獨立、完整的 2D 場景，就像每格分鏡各畫一張圖。
  • 29:08 新的 VSE editor 設定讓你可以在時間與空間中跳躍
    ↳ 新的 VSE 設定讓剪輯很自由：可以跳到不同時間點，也可以切到不同的鏡位空間，不必照原本的順序播放。
  • 29:40 例子：香港老電影裡重要的一擊有時會出現兩次。在同一個 3D 場景裡可以放兩個相機位置，分別拍第一擊和第二擊
    ↳ 老港片常把關鍵一擊從不同角度播兩次來強調。在同一個 3D 場景架兩台相機，一台拍第一擊、一台拍第二擊，剪起來就有這種效果。
  • 29:40 新的 storyboarding workflow 可以加速動作，也可以把踢擊重複兩次、放慢，或直接跳過讓它消失
    ↳ 同一段動作在剪輯時可以加速、重複兩次、放慢，也可以直接跳過讓觀眾看不到，全都在剪輯階段決定。
  • 30:10 三種做法：純 2D workflow，以及兩種不同的 2D/3D hybrid
    ↳ 三種做法整理：一種是純 2D，另外兩種是 2D 和 3D 混用（hybrid），差別在哪些部分用 3D 做、哪些用手畫。
  • 30:10 傳統 hybrid 是 3D 環境搭配 2D 角色，因為角色的建模、rig、動畫又貴又耗時，直接畫人物很有效率
    ↳ 常見的混用法是 3D 場景配手畫角色。角色要建模、做 rig（讓角色能擺動作的骨架控制）、做動畫，又貴又慢，直接畫人最省事。
  • 30:43 3D 環境＋2D 角色特別適合動作場面，或全部發生在同一地點的鏡頭與故事
    ↳ 3D 環境配 2D 角色，最適合打鬥這類動作戲，或整個故事都在同一個地點發生的情況。
  • 30:43 講者跟 Gaku 聊到想做一支 Mitsubishi 廣告，但它是 montage。環境一直切換，把 3D 環境建出來就沒有意義
    ↳ 講者想做三菱汽車廣告，但它是蒙太奇（montage，多個不同場景快速接連切換）。每個場景只出現一下，每個都建 3D 並不划算。
  • 31:46 第三種做法：montage 環境一直切換時，直接用已畫好的 2D sketches 當靜態圖，因為很多 anime 本來就很靜態
    ↳ 第三種做法：場景一直換的時候，直接把畫好的 2D 草圖當靜態圖用。很多日本動畫本來畫面就不太動，這樣做很自然。
  • 32:17 範例提案：清晨的京都，一輛車呼嘯穿過街道，驚擾了一隻貓
    ↳ 範例提案的內容：清晨的京都，一輛車飛快開過街道，把一隻貓嚇了一跳。
  • 32:17 參考圖可以在網路上找：很多人拍開車或走路穿過各地的影片，比 Google Maps 更好，因為能隨鏡頭移動看到立體感
    ↳ 找參考可以搜網路上別人開車或散步拍的街景影片。它比 Google 地圖好用，因為畫面會移動，看得出空間的前後立體感。
  • 32:47 要及早把 audio bed 放進時間軸。有很好用的音訊淡出方式，講者期待之後加入更多剪輯功能
    ↳ audio bed 是墊在最底下的基礎音軌，例如配樂，要早點放進時間軸。音訊淡出很好操作，講者也期待之後加入更多剪輯功能。
  • 33:19 音訊時間軸長度要符合作品長度：廣告通常是 30 秒，也可能是 5 秒，例如 YouTube 影片前或不可略過廣告前的小片段
    ↳ 時間軸長度要先配合成品長度。廣告常見是 30 秒，也有 5 秒的，例如 YouTube 影片開始前或不可略過廣告前的小片段。
  • 33:19 剪輯秘訣：取音樂的開頭與結尾對齊音軌，數 1 到 8 拍，找一小節結束、另一小節開始的點接起來，剪成需要的長度
    ↳ 剪音樂的技巧：保留曲子開頭和結尾，跟著拍子數 1 到 8，在一小節結束、下一小節開始的地方接起來，就能剪到需要的長度又不突兀。
  • 33:54 可以多試不同音樂。講者試過較 hardcore 的曲子，最後選了日本 City Pop
    ↳ 可以多換幾首音樂試試感覺。講者試過比較激烈的曲子，最後選了日本 City Pop。
  • 33:54 版權提醒：個人網路散布授權（personal internet distribution license）不涵蓋國際片廠授權，別被告
    ↳ 版權提醒：只授權個人在網路上發布的音樂，不包含國際片廠的使用授權。商業案別拿來用，免得被告。
  • 34:26 車子可以放進 asset library，在不同鏡頭中重複使用
    ↳ 做好的車子放進 asset library（素材庫），之後每個鏡頭都能直接拿出來用，不用重做。
  • 34:26 不小心把畫面版面弄掉時要叫回來：video sequence editor 在下方，timeline 在上方，也可以用 dope sheet
    ↳ 版面不小心關掉，要自己叫回來：VSE 放在下方，timeline（時間軸）放在上方。也可以改用 dope sheet，它是專門列出和調整 key 的視窗。
  • 35:00 較完整的版本中，有一個 grease pencil 物件 parent 到車子上
    ↳ 較完整的版本裡，有一個 grease pencil 物件 parent（綁成子物件）到車子上。車子移動時，畫上去的線條會跟著一起動。
  • 35:00 把車子做成 3D 資產的好處是可以重複使用，而且每個鏡頭都保持一致
    ↳ 把車子做成 3D 資產，可以一直重複使用，而且每個鏡頭裡的車都長得一樣，不會每格畫得不一致。
  • 35:30 用新的 pencil 筆刷畫，會加上不錯的質感，感覺更有機、更有趣、比較不數位
    ↳ 用新的 pencil 筆刷畫，線條會帶鉛筆質感，看起來更有手感、更有趣，比較沒有電腦繪圖的死板感。
  • 35:30 2D/3D 分鏡師喜歡用以 material 為基礎的簡單外框（outline），也可以用 Geometry Nodes 做，後者比較新
    ↳ 2D/3D 分鏡師常用 material（材質設定）做簡單外框。也可以用 Geometry Nodes（用節點組合出幾何效果的系統）來做，這個做法比較新。
📘 術語
color study（色彩研究）：以色彩為主的簡單研究，可加一點形體增加深度與體積
visual development (vis dev)（視覺開發）：先想出角色、環境可能的樣子
2D/3D storyboarding（2D/3D 分鏡）：可作為真人拍攝藍圖，知道要拍什麼、順序、要租什麼鏡頭
storyboarding project file workflow（分鏡專案檔工作流程）：團隊新開發的分鏡流程，講者說有點複雜，Pablo 有網路教學
VSE editor / video sequence editor（影片序列編輯器）：可加入音樂音效並排列鏡頭，版面上位於下方
radio cut（廣播剪輯（純聲音版））：先把聲音剪好，再把視覺疊上去
thumbnails（縮圖草稿）：非常粗略的小草圖
auto-keying（自動關鍵影格）：在時間軸上移動物件就會自動打 key，之後可調整時間
2D/3D hybrid（2D/3D 混合）：例如 3D 環境配 2D 角色，省去角色建模、rig、動畫的成本
rig（綁定骨架）：字幕只提到角色建模、rig、動畫又貴又耗時
montage（蒙太奇）：環境一個接一個切換，這時建 3D 環境沒有意義
audio bed（底層音軌）：要及早放進時間軸的音訊基底
asset library（資產庫）：把車子放進去，可在不同鏡頭重複使用
dope sheet（Dope Sheet（關鍵影格表））：字幕只說可以用來代替 timeline
grease pencil（Grease Pencil（蠟筆））：可 parent 到車子上；新 pencil 筆刷帶來較有機的質感
Geometry Nodes（幾何節點）：也可用來做外框，比 material 做法更新
✏️ 小考一題

講者說傳統 2D/3D hybrid 分鏡為什麼用「3D 環境＋2D 角色」？

A. 因為 VSE editor 無法播放 3D 角色B. 因為角色的建模、rig、動畫又貴又耗時C. 因為 2D 角色才能使用 auto-keyingD. 因為客戶都要求 anime 風格
看答案
答案：B。[30:10] 講者說 it is expensive and time-consuming to model, and rig, and animate a character，所以直接畫 2D 人物很有效率
