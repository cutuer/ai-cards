🧑‍🏫 這支是 Claude 官方的入門影片，介紹 Claude Code 是什麼，還有它跟你平常聊天用的 Claude 差在哪。如果你用 AI 寫過程式，也覺得把程式碼貼來貼去很累，看完就會懂「讓 AI 自己動手做事」是怎麼運作的，以及用的時候要注意什麼。

  • 00:05 Claude Code 是 agent-based 的程式開發工具：能理解你的 codebase、編輯檔案、執行指令，並整合你的工具，幫你更快完成工作
    ↳ Claude Code 是 agent-based 的工具，意思是它會自己動手做事，不只回答問題。它看得懂你的 codebase（專案裡全部的程式碼），能直接改檔案、下指令，也能串接你平常用的工具。
  • 00:05 可以在 terminal、Visual Studio Code、Claude desktop app、網頁版和 JetBrains IDE 使用；這支影片示範的是 terminal 版
    ↳ 它有好幾個地方可以用：terminal（用打字下指令操作電腦的視窗）、VS Code 和 JetBrains（工程師常用的寫程式軟體），還有 Claude 桌面版和網頁版。影片示範的是 terminal 版。
  • 00:36 和 Claude AI 不同，Claude Code 可以直接存取你的檔案、terminal 和整個 codebase，不用一直複製貼上程式碼，它能自己把事情做完
    ↳ 在一般的 Claude 聊天裡問程式，你要先把程式碼貼進去，再把答案貼回去。Claude Code 可以直接打開你的檔案和 terminal，自己改、自己執行，你不用在中間搬來搬去。
  • 00:36 兩者最主要的差別：Claude Code 是以 AI agent 的方式運作
    ↳ 兩者最大的差別不在誰比較聰明，而在做事的方式。聊天版是你問一句它答一句；Claude Code 是 AI agent，會接下一件任務，自己一步一步做完。
  • 00:36 AI agent 的定義：會和環境互動、執行動作來達成設定目標的軟體；最簡單的做法是讓大型語言模型在即時迴圈（real-time loop）裡運作
    ↳ AI agent 就是會自己採取行動、去達成目標的軟體。最簡單的做法是讓大型語言模型（像 Claude 這種讀寫文字的 AI）在即時迴圈裡不停運作：看狀況、做一步、看結果，再決定下一步。
  • 01:06 AI agent 可以使用工具、外部服務或其他 agent，來幫忙達成設定的目標
    ↳ 它不是只靠自己想，還能拿工具來用、連到外部服務（例如網路上的其他系統），或把工作分給其他 agent。只要能幫忙達成目標，這些它都會用上。
  • 01:06 例一：它能讀懂你的 codebase，你可以請 Claude Code 解釋某個 function，或追查程式碼裡的錯誤
    ↳ 舉例來說，你看不懂某段程式時，可以請它解釋某個 function（程式裡專門負責做一件事的一段程式碼），也可以請它幫你找出程式哪裡出錯。
  • 01:06 例二：Claude Code 能跑 build script、跑測試、安裝套件，再拿這些輸出結果做下一步
    ↳ 它能自己執行 build script（把程式組裝成可以用的成品的腳本）、跑測試、安裝套件（別人寫好、可以直接拿來用的程式），再依照執行結果決定下一步要做什麼。
  • 01:36 例三：Claude Code 能上網搜尋，例如需要最新的 API 參考文件時，它可以幫你查
    ↳ 它也能上網查資料。例如你需要某個 API（不同程式之間互相溝通的接口）的最新說明文件，它可以自己去找，不會只靠它原本記得、可能已經過時的內容。
  • 01:36 要把 Claude Code 用好，有三個重要觀念要先懂
    ↳ 影片接著講三個觀念。先懂這三點，你會比較清楚它為什麼這樣做事、什麼時候要特別盯著它，用起來也比較順手。
  • 01:36 觀念一：context window，可以想成 Claude 的工作記憶，裝得下很多東西，但沒辦法一次裝下全部
    ↳ 第一個觀念是 context window，意思是 Claude 同一時間能記住、能處理的內容量。這個量很大，但還是有上限，大一點的專案通常沒辦法一次全部塞進去。
  • 01:36 這就是它發揮 agent 能力的地方：它會有策略地在程式碼裡找答案，而不是把整個 codebase 都載入 context
    ↳ 因為沒辦法一次全部裝進去，它會先判斷該看哪些檔案、搜尋相關的段落，只讀需要的部分。這種自己找方向、自己找答案的能力，就是 agent 厲害的地方。
  • 02:06 觀念二：它會先徵求許可。預設情況下，Claude Code 在執行指令或修改程式碼前都會先問你
    ↳ 第二個觀念是權限。在預設設定下，它要執行指令或修改程式碼之前，都會先問你同不同意，不會自己默默動手。
  • 02:06 不管你是主動參與還是被動在旁邊看，整個過程都由你掌控
    ↳ 你可以每一步都仔細看、一起做決定，也可以比較放手讓它做。不管哪一種，要不要按同意都由你決定，主導權一直在你手上。
  • 02:06 觀念三：它可能會出錯。Claude Code 跟任何工具一樣不完美，可能誤解你的意圖、製造新的錯誤，或把解法弄得太複雜
    ↳ 第三個觀念是它會出錯。它可能誤會你的意思、改出新的錯誤，或把簡單的問題弄得很複雜。所以它做完之後，你還是要自己檢查、實際跑過一次再用。
  • 02:38 總結：Claude Code 會讀你的程式碼、編輯檔案、執行指令、串接外部工具，幫你更快把產品發布出去
    ↳ 總結一下：它會讀程式、改檔案、下指令、串接外部工具，目的都是讓你更快把產品做完、推出去。
  • 02:38 現在就可以下載，支援 Terminal、VS Code、JetBrains 和 Claude desktop app
    ↳ 現在就能下載來用，terminal、VS Code、JetBrains 和 Claude 桌面版都支援，從你最習慣的那個開始就好。
📘 術語
agent-based（以代理為基礎的）：Claude Code 是 agent-based 工具，會自己採取行動完成工作，而不只是回答問題
AI agent（AI 代理）：會和環境互動、執行動作來達成設定目標的軟體，可以使用工具、外部服務或其他 agent
codebase（程式碼庫）：你專案的整套程式碼；Claude Code 能直接存取並理解它
terminal（終端機）：Claude Code 可以使用的環境之一，本片就是在 terminal 裡示範
large language model（大型語言模型）：實作 AI agent 最簡單的方式，就是讓大型語言模型在即時迴圈裡運作
real-time loop（即時迴圈）：讓大型語言模型持續運作的迴圈，是實作 AI agent 最簡單的方式
build script（建置腳本）：Claude Code 能執行的腳本之一，執行後的輸出可以拿來做下一步
API reference（API 參考文件）：例如需要最新的 API 參考文件時，Claude Code 可以上網幫你查
context window（上下文視窗）：可以想成 Claude 的工作記憶，裝得下很多東西，但沒辦法一次裝下全部
