🧑‍🏫 這段是甜甜圈教學第二部的收尾，重點是把馬克杯把手真正接到杯身上。接完之後常會出現陰影怪怪的、冒出黑色瑕疵等問題，這段也教你怎麼修，最後留一個做碟子的小作業。「把兩個零件接起來」和「修正面的方向」幾乎每次建模都會碰到，值得先弄懂。

  • 20:38 按住 Control 再右鍵可以一路放點，Blender 會自動旋轉，不用自己轉。這招主要只適合把手這類延伸部件
    ↳ 在編輯模式按住 Ctrl 再按右鍵，會從選取處往滑鼠位置長出一段，連續點就像畫線，新的一段還會自己轉向。適合把手、管子這種一路延伸的東西。
  • 20:38 接下來的難題：怎麼讓把手的網格和杯身的網格接在一起
    ↳ 把手做好了，但它和杯身還是兩塊分開的網格（mesh，由點、線、面組成的 3D 外殼）。接下來的問題是：怎麼讓它們真的長在一起。
  • 21:09 錯誤做法是把兩者硬擠在一起互相穿插（早期 3D 常這樣做），這樣接縫處不會出現能捕捉光線的邊緣
    ↳ 偷懶做法是把把手直接插進杯身，看起來像黏住了。可是交界處沒有真正的邊，光打上去不會出現那條細細的反光，看起來就假。
  • 21:09 要得到那條邊，唯一的方法是把網格實際連接起來，也就是把手的面要和杯身的面接在一起
    ↳ 想讓交界處有自然的邊和反光，只能讓兩塊網格真的相連：把手末端的面要和杯身的面接起來，這件事沒有捷徑。
  • 21:39 杯身原有的線剛好切過把手中間，所以要再加一條環線，讓這一區變成一個面來對應把手
    ↳ 杯身原有的一條橫線剛好從把手接點正中間穿過，位置對不上。所以要再加一圈線，讓杯身在那裡剛好空出一格面，對應把手的切口。
  • 21:39 加線方式：按 Ctrl-R（loop cut），點擊後把線滑到大約合適的位置
    ↳ loop cut（Ctrl-R）會沿著模型繞一整圈加一條新線。按下去先看到預覽，點一下確定，再拖動讓線滑到大概的位置，不用很精準。
  • 22:13 按住 Z 可以快速切換檢視模式。切到 wireframe 能看穿網格；另外兩種模式等講到材質和算圖時再介紹
    ↳ 按住 Z 會跳出檢視模式選單。wireframe（線框模式）只畫出線，能看到後面被擋住的點和線。另外兩種模式跟材質、算圖有關，之後才會講。
  • 22:13 另一種看穿網格的方法是畫面上方的 X-ray，快捷鍵 Alt-Z。它和 wireframe 很相似
    ↳ X-ray 是讓模型變半透明、可以看穿的開關，在畫面上方，快捷鍵 Alt-Z。效果和線框很像，挑順手的用就好。
  • 22:46 選取杯身上的面稍微拉出來，方便之後抓取，然後切回 solid view
    ↳ 把杯身上要接把手的那幾格面稍微往外拉，等一下比較好點選。弄完切回 solid view，也就是平常看到的實心模型畫面。
  • 22:46 網格由一個個點組成（vertice mode 看到的就是這些點）。三個以上的點就能建立一個面
    ↳ 網格最基本的單位是點（vertex，複數 vertices），切到點模式看到的一顆顆小點就是。三個以上的點連起來，就能圍出一個面（face）。
  • 23:16 按住 Shift 選兩個點，按 F（F for face）建立新面。兩側、上方、下方各做一次
    ↳ 按住 Shift 可以加選點，把手和杯身兩邊的點都要選到。選好後按 F（face 的 F）就會補上一個面。左、右、上、下四個缺口各補一次。
  • 23:50 講者刻意先用這種方式接合，是為了示範接下來會出現的著色問題
    ↳ 講者故意先用這種不完美的做法，讓大家親眼看到接下來會冒出的著色問題，學會怎麼認出來、怎麼修。
  • 23:50 smooth shading 是依照連續的面來計算。把手接合前，內部原本就有一個面存在
    ↳ smooth shading（平滑著色）會讓有稜角的模型看起來圓滑，靠相連的面彼此計算。問題在於：接把手前，杯身那格面其實還在，被包在裡面。
  • 24:21 因為內部那個面還在，平滑著色不知道該往哪延續，結果算出一種怪異的混合效果
    ↳ 那片藏在裡面的面還在，平滑計算分不清該往把手延伸還是往那片面延伸，結果算出一塊奇怪、髒髒的混合陰影。
  • 24:21 解法是在 face select mode 下選取那個內部的面，把它刪掉
    ↳ 解法很直接：切到 face select mode（選取面的模式），點選那片多餘的內部面，把它刪掉。
  • 24:21 初學者很常選錯面，因為相鄰的面靠得很近
    ↳ 內部面和旁邊的面貼得很近，從同一個角度點下去，很容易選到隔壁那片，初學者常在這裡出錯。
  • 24:54 許多 3D 藝術家會轉動視角，確認選到的真的是自己要的那一個面
    ↳ 很多做 3D 的人選完面會轉一下視角，從不同角度確認亮起來的真的是自己要的那一片，才動手刪。
  • 24:54 按 X 再選 Faces 刪除面。另一側內部也有一個面，用同樣方式刪掉
    ↳ 選好後按 X，選 Faces，只刪面、不刪周圍的點和線。把手另一端的接點裡也藏著一片，用同樣方式刪掉。
  • 25:29 刪完後還不正確，需要右鍵選 shade smooth 才修好
    ↳ 刪完畫面還是怪，要在物件上按右鍵選 shade smooth，重新套一次平滑著色才會正常。
  • 25:29 修改幾何後有時要重新計算 normals。每個面都有一條隱藏的線，永遠朝外
    ↳ normals（法線）是每個面都有、看不見的一根方向線，正常應該朝向模型外面，Blender 靠它分辨面的正反。改過形狀後，有時要重新計算。
  • 25:29 建立新網格或修補時，某條 normal 可能朝錯方向，畫面會出現很醜的黑色著色瑕疵
    ↳ 自己補面或修補時，有些面的法線可能被做成朝內，畫面就會出現難看的黑色陰影。看到這種黑塊，通常就是法線反了。
  • 26:03 修正方式：選取整個網格，按 Shift N 重新計算 normals
    ↳ 修正方式：選取整個網格，按 Shift N，Blender 會重新計算，把法線統一轉成朝外。
  • 26:03 先建面再刪面的做法不要照學。實際上應該在接合前就先把兩個面刪掉
    ↳ 先補面、再回頭刪內部面，是為了教學才繞遠路。實際做的時候，接合前就先把兩個擋路的面刪掉，後面的問題就不會出現。
  • 26:03 更快的接合法：用 Alt 選取一圈 edge loop，再用 Shift Alt 加選另一圈
    ↳ edge loop 是繞一整圈、頭尾相連的一串邊。按住 Alt 點一條邊，可以一次選到整圈；再按 Shift Alt 點另一圈，就能加選。
  • 26:38 選好兩圈後右鍵選 Bridge Edge Loops。前提是兩邊的頂點數量必須完全相同
    ↳ 選好兩圈後按右鍵，選 Bridge Edge Loops，Blender 會自動在兩圈之間搭出面、把它們接起來。前提是兩圈的點數要完全一樣，才能一對一接上。
  • 26:38 示範手動建面，是因為「選四個頂點、建立新面」是很常見的接合建模方式
    ↳ 雖然有 Bridge 這種快招，講者還是示範手動補面，因為「選四個點、按 F 補一個面」是建模時非常常用的接合手法。
  • 26:38 對照參考圖，把手有明顯的折痕，比較銳利
    ↳ 對照參考照片，真實的把手有明顯的折角，轉折處比較尖，不是整條圓滾滾的。
  • 27:09 要做出折痕，可以加更多 loop cut
    ↳ 想讓轉折變銳利，可以在那附近多加幾圈 loop cut。線排得越密，平滑之後那裡越不容易被磨圓。
  • 27:09 另一種方法：按住 Alt 選取一條邊，雙擊 G 把它滑進來。但這樣該區會變得比較直，可切到前視圖檢查
    ↳ 另一招：按住 Alt 選一整圈邊，快速按兩下 G，邊會沿著表面滑動。缺點是那一段可能變得比較直，可以切到前視圖檢查形狀。
  • 27:09 如果想要更多細節就加 loop cut。要用哪種方法由你決定，也可以直接移動調整形狀
    ↳ 想要更多細節就加 loop cut。用哪種方法你自己決定，也可以直接抓點或邊移動，把形狀調到順眼為止。
  • 27:39 這系列的目標是學 Blender，不一定要做出物理上精確的杯子。不必每件事都做到完美，但也不要做出很糟的結果
    ↳ 這系列的目的是學會 Blender，不是做出物理上精準的杯子。不用每處都完美，但也別隨便到很難看。

    ↳ 講者自己只處理把手彎折處被擠得太緊的地方：選那條邊，按兩下 G 往上滑，讓那裡不那麼擠。

📘 術語
mesh（網格）：由一個個點組成，點之間可以建立面
loop cut（Ctrl-R）（環切）：按 Ctrl-R 加入一整圈線，點擊後可滑動到想要的位置
wireframe（線框模式）：一種檢視模式，可以看穿網格。按住 Z 就能切換
X-ray（Alt-Z）（X 光透視）：另一種看穿網格的方式，在畫面上方，快捷鍵 Alt-Z，和 wireframe 很相似
solid view（實體檢視）：原本的一般檢視模式，看完線框後切回這裡
vertex / vertices（頂點）：組成網格的個別點，在 vertice mode 下看到的就是這些點
face（面）：三個以上的點可以建立一個面。選點後按 F 建立
face select mode（面選取模式）：用來選取面的模式，例如選取內部多餘的面來刪除
smooth shading / shade smooth（平滑著色）：依連續的面計算平滑效果。內部有多餘的面會讓效果變怪。右鍵可選 shade smooth
normals（法線）：每個面都有的隱藏線，永遠朝外。方向錯誤會出現黑色瑕疵，按 Shift N 重新計算
edge loop（環狀邊）：一整圈的邊，可以用 Alt 選取
Bridge Edge Loops（橋接環狀邊）：選好兩圈 edge loop 後右鍵使用，能快速接合。兩邊頂點數必須相同
double-tap G（雙擊 G）：選取邊後雙擊 G，可以滑動它的位置，用來調整形狀或減少夾擠
