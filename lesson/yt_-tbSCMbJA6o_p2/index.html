🧑‍🏫 這段接著把場景裡的杯子從一個圓柱，改成有開口、有厚度、邊緣圓順的咖啡杯雛形，最後教你怎麼安全地存檔。重點不只是做出杯子，還包括 Blender 的兩個基本習慣：先分清楚「選物件」和「改形狀」兩種模式，以及盡量用之後還能回頭改的方式來做。

  • 14:15 按 G 進入移動狀態時，再按軸的字母即可鎖定軸向：X 軸、Y 軸前後、Z 軸上下
    ↳ 按 G 物件會跟著滑鼠移動，這時再按 X、Y 或 Z，就只能沿那個方向（軸，axis）走，不會亂飄。Y 是前後，Z 是上下。
  • 15:00 Blender 是 Z 朝上、Y 為前後；各 3D 軟體的設定不同，沒有統一標準
    ↳ 在 Blender 裡 Z 是上下、Y 是前後。換別套 3D 軟體可能不一樣，從別處學來的方向習慣不一定適用。
  • 15:00 忘記字母對應哪個軸時，可以看畫面上方那個小圓圈，上面標有 X、Y、Z
    ↳ 記不住哪個字母對應哪個方向沒關係。畫面上方有個小圓圈標著 X、Y、Z，看一眼就知道要按哪個。
  • 15:00 把杯子往後移，讓甜甜圈位於畫面前方正中央
    ↳ 這一步只是擺位置：把杯子推到後面，讓甜甜圈待在畫面正前方中間，當主角。
  • 15:00 要讓視角改以選取的物件為中心，按數字鍵盤的句點（numpad period）
    ↳ 按數字鍵盤的句點（numpad period），鏡頭會拉到你選的物件上，之後轉視角就繞著它轉，方便近看細節。
  • 15:36 也可以按住 Esc 下方的 tilde 鍵，再選 View Selected，效果相同
    ↳ 筆電沒有數字鍵盤也沒關係：按住 Esc 下面的 tilde（~）鍵，選 View Selected（聚焦到選取的物件），效果一樣。
  • 15:36 要編輯物件必須切換模式：從左上角下拉選單選 Edit Mode，選取的物件會出現許多點和線
    ↳ 要改物件形狀得先進 Edit Mode（編輯模式）。從左上角選單切換後，物件會冒出很多點和線，這些就是可以動手改的地方。
  • 16:11 在 Edit Mode 裡無法選取其他物件，是初學者常見問題；選物件要在 Object Mode，編輯要在 Edit Mode
    ↳ 新手常卡在 Edit Mode 裡點不到別的物件。記住分工：Object Mode（物件模式）用來挑物件，Edit Mode 用來改形狀。
  • 16:44 Tab 鍵可在 Object Mode 與 Edit Mode 之間切換，會一直用到
    ↳ Tab 鍵一按就在這兩個模式之間切換，之後會一直用到，先記起來。
  • 17:14 Edit Mode 中的點叫 vertices，構成 mesh 的形狀；另外還有 edges 和 faces
    ↳ 那些點叫 vertices（頂點），決定 mesh（網格，也就是物件形狀）的樣子。點連成 edges（邊），邊圍起來就是 faces（面）。
  • 17:14 選取類型預設是 vertices，可點按鈕改為選 edges 或 faces
    ↳ 預設點下去選的是點，可以按按鈕改成一次選邊或選面，看你要改的是哪一種。
  • 17:44 快捷鍵：1 是 vertex select、2 是 edge select、3 是 face select；講者建議取得他的快捷鍵指南
    ↳ 切換選取類型的快捷鍵：1 選點、2 選邊、3 選面。講者也推薦去拿他整理的快捷鍵表。
  • 17:44 在 Face Select 模式選取杯子頂部的蓋子面，按 X 刪除，Blender 會詢問要刪除哪個部分
    ↳ 切到選面模式，點杯頂那塊「蓋子」，按 X 刪除。Blender 會跳出選單，問你到底要刪掉哪一種。
  • 18:16 會多問一次，是因為很多時候即使選了 faces，也會想刪除那些面的全部 vertices；這裡選只刪 Faces，得到有開口的杯子
    ↳ 會多問一次，是因為很多人選了面其實想連點一起刪。這裡只刪 Faces，點和邊都留著，杯子就開了口。
  • 18:16 杯子太薄，杯緣可能割到手指，需要加厚度；雖然可在 Edit Mode 全選後 extrude，但不必這麼做
    ↳ 現在杯壁像一張沒有厚度的紙，邊緣薄到像會割手。可以手動把面擠出（extrude）厚度，但有更省事的方法。
  • 18:49 點扳手圖示進入 modifier stack，按 Add Modifier，在 Generate 底下選 Solidify
    ↳ 點扳手圖示打開 modifier stack（套在物件上的效果清單），按 Add Modifier，在 Generate 分類裡選 Solidify（加厚）。
  • 18:49 若未來版本位置改變，可用上方的 Search 直接輸入 Solidify；加上後 mesh 會有厚度，並可調整數值
    ↳ 選單位置以後改版可能會換，直接在上方 Search 輸入 Solidify 最保險。加上後杯壁就有厚度，數值可以隨時調。
  • 19:30 進入 Edit Mode 後無法選取杯子內側的厚度部分，因為 modifier 並沒有真正修改原本的 mesh
    ↳ 進 Edit Mode 會發現選不到杯子內側那層厚度，因為那層是效果算出來的，原本的形狀根本沒被改動。
  • 19:30 點螢幕圖示（monitor button）在 viewport 關閉 modifier，可看到原 mesh 沒有改變，效果是事後套上去的
    ↳ 點螢幕圖示可以在 viewport（工作畫面）暫時關掉效果，會看到原本的杯子還是薄薄一層，厚度是事後疊上去的。
  • 20:00 Solidify 會拿你給的 mesh，替每個面加上厚度；這是 non-destructive workflow，之後隨時能回來調整厚度
    ↳ Solidify 是拿原形狀替每個面加厚。這種做法叫 non-destructive workflow（非破壞性流程）：原稿不動，隨時能回來改。
  • 20:35 杯緣轉角太尖銳，要圓滑化：Add Modifier > Generate > Subdivision Surface，很常用但藏得很深
    ↳ 杯緣轉角太尖，要磨圓。加 Subdivision Surface（細分曲面，簡稱 subsurf，加點讓表面變平滑），一樣在 Generate 裡，很常用但藏得深。
  • 21:05 加上後 mesh 看起來像壞掉；調高 Levels Viewport，每多一級就讓幾何加倍（1、2、3 級）
    ↳ 剛加上時看起來會怪怪的。把 Levels Viewport（畫面上細分的次數）調高，每升一級點數就加倍，形狀越來越圓順。
  • 21:05 Subdivision Surface 會把邊緣變平滑，但原本 90° 的轉角會被平滑得太大
    ↳ 問題是它會把所有邊都磨圓，連原本接近直角的杯緣也磨得太圓，看起來軟軟的。
  • 21:42 原理：取相鄰點的平均位置加入新點，每多一級就再加點；杯子兩側都這樣處理，因此形成很圓的橢圓形邊緣
    ↳ 它的做法是在相鄰點之間取平均位置補新點，一級一級補下去。杯緣兩側的點離得遠，平均下來就變成很大的圓弧。
  • 22:19 解法是在平滑發生處加入更多幾何，讓邊緣收緊，只在很小的範圍內平滑
    ↳ 解法是在想保持俐落的地方多加幾條線。點靠得近，圓弧就只出現在很小的範圍，邊緣看起來就乾淨。
  • 22:53 用 loop cut 加入一圈新的 edge，快捷鍵 Ctrl+R；也可從選單 Edge > Loop Cut and Slide 找到
    ↳ 加線用 loop cut（環切，繞物件一圈加一條新邊），快捷鍵 Ctrl+R。忘記的話，從 Edge 選單找 Loop Cut and Slide。
  • 23:24 按 Ctrl+R 後選擇要切的位置，單擊確認，再上下滑動位置；越靠近頂部，邊緣就越緊
    ↳ 按 Ctrl+R 後，游標移到要切的位置點一下確定，再上下滑動調整。線越靠近杯口，那個轉角就越銳利。
  • 23:55 杯底也用 Ctrl+R 加一條 loop cut，並滑到底部附近
    ↳ 杯底轉角也一樣處理：再按 Ctrl+R 切一圈，滑到靠近底部的位置，讓杯底邊緣也收緊。
  • 23:55 杯底的面被 subsurf 變成星形：subsurf 處理由四個 vertices 組成的面時，能正常平滑
    ↳ 這時杯底被磨成星形。原因是 subsurf 擅長處理四個點圍成的面，只有那種面才會平滑得漂亮。
  • 24:34 超過四個 vertices 組成的面叫 n-gon，subsurf 的處理結果難以預料，可能讓外觀變醜
    ↳ 杯底是一大塊由很多點圍成的面。超過四個點的面叫 n-gon（多邊面），subsurf 算出來的結果很難預料，常常變醜。
  • 25:08 n-gon 在 3D 領域有點像髒話；它其實有用途，但不確定自己在做什麼時，一般最好避免
    ↳ 3D 圈裡提到 n-gon，大家的反應就像聽到髒話。它不是不能用，但沒把握的時候先避開比較安全。
  • 25:08 修法是在杯底面內側再加一圈 loop，讓醜的星形藏在杯底；但 loop cut 無法只切單一個面
    ↳ 想把醜星形縮到杯底中央藏起來，就要在底面內側再加一圈線。可是 loop cut 會繞整個物件切，沒辦法只切一個面。
  • 25:41 改用 inset：替單一個面在周圍加一圈 loop，快捷鍵 I；工具一啟動就進入操作狀態，移動游標決定邊緣鬆緊
    ↳ 改用 inset（內縮，在單一個面內側再圍一圈），快捷鍵 I。按下就直接開始操作，移動滑鼠決定這圈的鬆緊。
  • 26:15 完成後杯子好看許多；因為是 non-destructive，仍可調 Solidify 厚度，做成很厚或很薄的杯子
    ↳ 處理完杯子順眼多了。因為效果都還能改，Solidify 的厚度隨時可調，要厚實的馬克杯或薄杯都可以。
  • 26:46 也能調整杯子的解析度；保持彈性的工作流程，客戶要求修改時很方便，講者認為這是 3D 最好的工作方式
    ↳ 杯子的解析度（精細程度）也能再調。保留這種彈性，客戶要求修改時不必重做，講者認為這是做 3D 最好的方式。
  • 26:46 完成咖啡杯雛形與甜甜圈後存檔：File > Save As，或 Shift+Ctrl+S
    ↳ 杯子和甜甜圈都有了就存檔：File > Save As（另存新檔），或按 Shift+Ctrl+S。
  • 27:18 講者的命名方式：名稱加底線再加編號；不覆蓋舊檔，以便需要時回到先前版本
    ↳ 講者習慣在檔名後面加底線和編號，例如「檔名_1」「檔名_2」。每次都另存新檔、不蓋掉舊檔，改壞了還能回到前一版。
  • 27:50 在存檔檔名欄旁按 + 或 −（或數字鍵盤的 +/−），會自動替檔名加上編號；這裡改成 2 後存檔
    ↳ 存檔視窗的檔名旁有 + 和 − 按鈕（也可以按數字鍵盤的 +/−），按一下編號就自動加一或減一。這裡改成 2 再存。
📘 術語
Axis (X/Y/Z)（軸向）：移動時可鎖定的方向；Blender 中 Z 朝上、Y 為前後
View Selected（檢視選取物件）：把視角焦點移到選取的物件上，同數字鍵盤句點
Object Mode（物件模式）：要選取物件時必須在此模式
Edit Mode（編輯模式）：編輯物件用的模式，會顯示點和線，但無法選取其他物件
Vertices（頂點）：構成 mesh 形狀的點
Edges（邊）：mesh 上的線，可切換成 edge select 來選取
Faces（面）：mesh 上的面，可用 face select（快捷鍵 3）選取
Mesh（網格）：由 vertices 等構成的物件形狀
Modifier（修改器）：在扳手圖示下加入的效果，不會真正修改原本的 mesh
Solidify（實體化）：替每個面加上厚度的 modifier，位於 Generate 底下
Non-destructive workflow（非破壞性工作流程）：效果是事後套上的，之後可隨時回來調整
Subdivision Surface (subsurf)（細分曲面）：加入更多幾何讓邊緣平滑的 modifier，每級讓幾何加倍
Levels Viewport（視圖細分級數）：控制幾何加倍的次數
Loop Cut（環切）：在 mesh 加入一圈新的 edge，快捷鍵 Ctrl+R
N-gon（多邊形面）：由超過四個 vertices 組成的面，subsurf 的處理結果難以預料
Inset（內插面）：在單一個面周圍加入一圈 loop，快捷鍵 I
✏️ 小考一題

根據影片，什麼叫做 n-gon？

A. 由剛好三個 vertices 組成的面B. 被 Solidify 加上厚度的面C. 用 loop cut 新增出來的邊D. 由超過四個 vertices 組成的面

答案：D。[24:34] 講者說：面一旦由超過四個 vertices 組成，就叫 n-gon。
