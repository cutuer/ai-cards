🧑‍🏫 這支影片介紹 Claude Cowork。它是 Claude 桌面版裡的一個功能，讓你把一整件工作交給 Claude，它會直接在你的電腦上動手做，不只是給建議。影片先講怎麼設定，再用整理亂七八糟的下載資料夾示範整個流程。如果你想讓 AI 真的幫你做事，而不只是跟它聊天，這支很適合入門。

  • 00:01 Claude Cowork 會在你工作的地方協助你，讓你把完整的任務交給 Claude 處理
    ↳ Claude Cowork 是 Claude 桌面版裡的一個分頁，專門用來把整件事交給 Claude 去做。它直接在你的電腦和檔案上工作，不是只回答問題。
  • 00:01 電腦裡的檔案，Claude 能找到並編輯；雲端上的資料，則透過 Google Drive、Notion、Slack 等服務連接
    ↳ 你電腦裡的檔案，Claude 可以自己找、自己改。放在 Google Drive、Notion、Slack 這些線上服務的資料，要先把服務接上，它才看得到。
  • 00:01 瀏覽器裡的工作，Claude 可以透過 Claude in Chrome 處理
    ↳ Claude in Chrome 是讓 Claude 操作 Chrome 瀏覽器的工具。所以查網頁、在網站上找資料這類要開瀏覽器的事，也能交給它做。
  • 00:01 描述你要完成的事，Claude 就會去做；你可以在旁觀看、在關鍵時刻引導，或先離開再回來看結果
    ↳ 你只要講清楚想要什麼結果，不用自己一步步操作。過程中可以在旁邊看，在重要關頭插話指揮，或先去忙別的，晚點再回來看成果。
  • 00:01 Claude Cowork 已在 macOS 和 Windows 版 Claude Desktop app 正式開放，適用 Pro、Max、Team、Enterprise 使用者
    ↳ Claude Desktop 是裝在電腦上的 Claude 應用程式，不是網頁版。Mac 和 Windows 都能用，但要付費方案：Pro、Max、Team 或 Enterprise。
  • 00:41 開始使用：打開 Claude Desktop，點選 Cowork 分頁
    ↳ 開始的方式很簡單：打開 Claude 桌面版，點 Cowork 這個分頁就進去了。
  • 00:41 一般 Claude chat 是和 Claude 一步一步合作；Cowork 則是把任務交出去，由 Claude 處理剩下的部分，你可以專心做別的工作
    ↳ 平常聊天是你問一句、它答一句，你得一直在旁邊接著下指令。Cowork 比較像把工作派給同事，交代完你就能去做自己的事。
  • 00:41 第一步：選一個讓 Claude 操作的資料夾或專案，授權 Claude 存取電腦上的這個資料夾
    ↳ Claude 不會自己去翻你整台電腦。你要先指定一個資料夾，明確同意它可以進去，它的工作範圍就限定在那裡面。
  • 00:41 Claude 修改你的檔案系統前會先徵求許可；授權後就能直接在該資料夾中讀取、建立、編輯檔案
    ↳ 它要動你的檔案之前，會先問你可不可以。你同意之後，它就能直接在那個資料夾裡讀檔、開新檔、改內容。
  • 01:13 常用的資料夾可以加入最愛，也可以同時選擇多個資料夾，把分散在不同地方的資料來源串起來
    ↳ 常用的資料夾可以加到最愛，下次直接選。也能一次選好幾個資料夾，例如合約在 A、報價單在 B，讓它把兩邊一起拿來用。
  • 01:13 第二步：連接你的工具。Cowork 支援 connectors，讓 Claude 從你工作原本所在的服務取得脈絡
    ↳ connectors（連接器）的作用是把 Claude 接到你平常在用的服務，例如雲端硬碟或團隊聊天工具。接上以後，它能直接讀那邊的資料，搞清楚你工作的來龍去脈。
  • 01:13 第三步：如果已設定好 Claude in Chrome，Cowork 可以用它做瀏覽器任務，例如讀網頁、從網站擷取資料、在分頁間切換
    ↳ 如果你已經裝好 Claude in Chrome，Cowork 就能透過它開網頁、讀內容、把網站上的資料抓下來，也能在不同分頁之間切換。
  • 01:13 在 Settings 裡點 Cowork 分頁，可以設定套用到每個 session 的全域指示
    ↳ 在 Settings（設定）的 Cowork 分頁，可以寫 global instructions（全域指示），也就是一段固定的交代事項。之後每個 session（每次開的一項工作）都會自動套用，不用每次重講。
  • 01:46 全域指示的例子：說明你的職務背景，或要求建立檔案時用 Word 檔而不是 markdown
    ↳ 例如先告訴它「我是業務，常處理報價」，它做事會更貼近你的需要。或是要它產出 Word 檔，不要 markdown（一種用符號標格式的純文字檔）。
  • 01:46 注意：Cowork sessions 存在你自己的裝置上；Claude 執行任務時，desktop app 必須保持開啟
    ↳ 你的 Cowork 工作紀錄存在自己的電腦上。Claude 在做事的時候，桌面版 app 要一直開著，不能關掉。
  • 01:46 範例情境：下載資料夾累積了好幾個月的 PDF、試算表、截圖和重複檔案
    ↳ 示範的情境很常見：下載資料夾好幾個月沒整理，PDF、試算表、截圖，還有重複下載的檔案全混在一起。
  • 02:21 指令示範：請 Claude 整理下載資料夾、掃描內容後提出計畫，並在動手修改之前先給你看
    ↳ 這個指令最關鍵的是「先提計畫、給我看過再動手」。這樣它不會一上來就搬動你的檔案，你有機會先把關。
  • 02:21 指令要求計畫包含：要建立哪些分類、檔案怎麼歸類、採用什麼命名規則，以及哪些檔案要標記出來待檢查或刪除
    ↳ 指令把計畫要包含的內容講得很具體：分哪幾類、檔案怎麼歸、檔名怎麼取、哪些可疑要標出來。講得越清楚，它交出來的計畫越好檢查。
  • 02:21 Claude 提出的結構：documents、spreadsheets、presentations、images，外加一個收集多餘副本的 duplicates 資料夾
    ↳ Claude 提議分成文件、試算表、簡報、圖片四類，另外開一個 duplicates（重複檔案）資料夾，專門放多出來的副本。
  • 02:51 Claude 建議採用以日期為基礎的命名規則，並標記出 4 個疑似重複的檔案，等你檢查
    ↳ naming conventions（命名規則）就是統一檔名的取法。Claude 建議用日期當基礎來命名，也挑出 4 個疑似重複的檔案，先等你確認。
  • 02:51 使用者發現其中 2 個其實是想保留的不同版本，於是請 Claude 把它們移到 review 資料夾而不是刪除，其餘照計畫執行
    ↳ 這就是先看計畫的好處：使用者發現其中 2 個其實是想留的不同版本，就請它改放到 review（待檢查）資料夾不要刪，其他照原計畫做。
  • 02:51 Claude 會依指示調整後繼續執行；執行過程中可以在右上角看進度
    ↳ 你改了計畫之後，它會照新的交代接著做，不用從頭再來。執行過程中，畫面右上角可以看到進度。
  • 03:21 可以點開每個任務查看細節或提問；檔案會在你的電腦上實際移動
    ↳ 每個步驟都能點開看細節，有疑問可以直接問它。要注意，這不是模擬，檔案是真的在你電腦裡被搬動。
  • 03:21 完成後，下載資料夾就整理好、重新命名並清理乾淨了
    ↳ 做完以後，下載資料夾已經分好類、檔名統一，多餘的檔案也清掉了。
  • 03:21 差別在於：一般 chat 中 Claude 只能說明怎麼整理檔案，在 Cowork 中 Claude 會直接動手做
    ↳ 最大的差別在這裡：一般聊天時，Claude 只能教你怎麼整理，還是得你自己動手；在 Cowork 裡，它會直接幫你做完。
  • 03:21 Cowork 的核心流程：Claude 先提出計畫，等你核准後才行動；你可以調整計畫、改變做法，或叫它跳過某些步驟
    ↳ Cowork 的基本流程是：它先提計畫，你同意了才動手。計畫不滿意的話，你可以修改、換個做法，或叫它跳過某幾步。
  • 03:54 你核准之後，Claude 會直接在你的檔案系統中執行
    ↳ 你一按同意，它就會直接在你電腦的檔案上執行，所以核准之前要看仔細。
  • 03:54 建議先從範圍明確的任務開始（像這個例子），而且一定要檢查 Claude 做出來的結果
    ↳ 剛開始先挑範圍小、目標清楚的事來試，像整理一個資料夾這種。做完一定要自己檢查結果，不要看都不看就相信。
  • 03:54 你交出去的是工作，判斷還是你自己來（You're delegating the work, not the judgment）
    ↳ 費力的活可以交給 Claude，但什麼要留、什麼要刪、結果對不對，還是要你自己決定。判斷的責任不會跟著交出去。
📘 術語
Claude Cowork（Claude Cowork（協作模式））：Claude Desktop 裡的 Cowork 分頁，可以把完整任務交給 Claude 處理
Claude Desktop（Claude 桌面版應用程式）：Cowork 在這個 app 裡使用，支援 macOS 和 Windows
Claude in Chrome（Chrome 版 Claude）：設定好之後，Cowork 可以用它讀網頁、擷取網站資料、在分頁間切換
connectors（連接器）：把 Claude 連到各種服務，從你工作原本所在的地方取得脈絡
global instructions（全域指示）：在 Settings 的 Cowork 分頁設定，套用到每個 session，例如你的職務背景
session（工作階段）：Cowork sessions 儲存在你自己的裝置上
naming conventions（命名規則）：範例中 Claude 建議採用以日期為基礎的命名規則
markdown（Markdown 格式）：字幕的例子是可以指示 Claude 建立 Word 檔，而不是 markdown
