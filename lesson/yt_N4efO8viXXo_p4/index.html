🧑‍🏫 這段是 Code with Claude 東京場開幕演講的最後一段，介紹 Claude Code 能在哪些介面使用，以及一系列新功能。重點是：現在可以同時派很多個 AI 分頭做事，而你只要負責看進度和審核。最後的示範用一個指令，就把網站同時翻成 12 種語言，很直觀地展示了「平行分工」有多省時。

  • 31:49 很多人用 auto mode 把權限交給 Claude，等 Claude Code 自己測試完、開好可審查的 PR 後才回來看
    ↳ auto mode 是讓 Claude 自己執行動作、不用每一步都問你的模式。很多人開了就去忙別的，等它測完、送出 PR（一包等人審核的程式修改）再回來看。
  • 31:49 Claude Code 最早從 CLI 起步，CLI 仍適合想要極簡文字介面、最多控制權與自訂空間的進階使用者
    ↳ CLI（命令列介面）就是在終端機裡打字操作的黑底文字畫面。Claude Code 從這裡起步，現在它仍然適合想完全掌控、喜歡自己調設定的老手。
  • 32:20 之後加入 IDE 介面，給想用同樣強大 agent、又想同步看到所有程式碼變更的使用者
    ↳ IDE 是寫程式用的編輯軟體，例如 VS Code。在裡面用 Claude Code 這個 agent（會自己動手做事的 AI 助手），能力一樣，還能同步看到它改了哪些程式。
  • 32:20 很多使用者同時平行跑好幾個 Claude Code（暱稱 multi-clauding），因此新增兩個介面讓這件事更容易
    ↳ 很多人會同時開好幾個 Claude Code，各自做不同的事，大家戲稱這叫 multi-clauding。為了讓人更容易同時管好幾個，官方做了兩個新介面。
  • 32:50 Claude Desktop 裡的 Claude Code：全螢幕圖形介面、內建預覽、側邊欄 control plane，也能呈現圖片等豐富輸出
    ↳ Claude Desktop 是 Claude 的電腦版 App。裡面的 Claude Code 有完整視窗，能直接預覽成果，也能顯示圖片。側邊欄是 control plane（總控台），用來看各任務的狀態。
  • 32:50 Desktop 用單一畫面整合所有本機與雲端 session，並用視覺標示顯示哪些 agent 正在工作、哪些在等你回應
    ↳ session 是一次獨立的工作對話。Desktop 把跑在你電腦上的和跑在雲端的 session 放在同一個畫面，並用標示告訴你哪個在忙、哪個在等你回覆。
  • 33:20 最新介面是 CLI 裡的 agents view：不離開終端機就能看到哪些在等你、哪些在跑、哪些已完成
    ↳ agents view 是 CLI 裡的新畫面，像一張任務清單：哪些在等你、哪些還在跑、哪些已經做完，一眼就看得到，不用離開終端機。
  • 33:20 agents view 可以直接在該列回覆來解除卡關，也能跳進跳出任一 session 而不會搞丟進度
    ↳ 某個任務卡住、在問你問題時，直接在清單那一列回答，它就能繼續。你也可以進去細看某個任務再退出來，不會打斷它原本的進度。
  • 33:20 VS Code IDE 擴充套件和 Desktop 版的 Claude Code 都建立在 Claude Agent SDK 上，和很多觀眾正在用的是同一套
    ↳ Claude Agent SDK 是 Anthropic 提供給開發者、用來打造自己 AI agent 的工具包。VS Code 外掛和 Desktop 版的 Claude Code 都是用它做的，跟外面開發者用的是同一套。
  • 33:51 許多企業已全面導入 Claude Code；Anthropic 工程師平均出貨的程式碼是過去的 8 倍，且工程團隊規模也大幅成長
    ↳ 很多公司已經讓整個工程部門都用 Claude Code。講者說，Anthropic 自家工程師平均產出的程式碼是以前的 8 倍，團隊人數同時也大幅成長。
  • 34:21 回應「想少花時間在 code review」：推出 code review 產品，派出一組 agents 抓出 PR 中的嚴重 bug
    ↳ 程式寫得快，人工審核就跟不上。code review 產品會派一組 agent 分頭檢查 PR，專門抓出會造成嚴重問題的 bug。
  • 34:52 code review 每天有數千家公司使用，包含 Anthropic 所有內部團隊
    ↳ 講者說，每天有數千家公司在用這個審查功能，Anthropic 內部每個團隊也都在用。
  • 34:52 回應「想隨時隨地寫程式」：推出 remote control 以及 iOS、Android 版 Claude Code，不必綁在辦公桌前
    ↳ remote control 讓你不坐在電腦前，也能操控正在跑的 Claude Code。再加上 iOS 和 Android 手機版，人在外面也能看進度、下指令。
  • 35:23 回應「想讓 Claude Code 處理新的 ticket」：推出 routines，設定一次即可依排程、webhook 或 API 呼叫啟動 Claude Code
    ↳ ticket 是記錄待辦事項或問題的工單。routines 設定一次之後，就會照排程、webhook（別的系統發生某件事時自動發出的通知）或 API（程式之間互相呼叫的管道）自動叫 Claude Code 開工。
  • 35:23 routines 能接手過去需要人工手動啟動的工作
    ↳ 以前要有人記得手動按「開始」的例行工作，現在可以交給 routines 在時間到或事件發生時自己啟動。
  • 35:54 回應「程式碼產量太大、資安團隊跟不上」：推出 Claude security（字幕作 cloud security），會在夜間掃描整個 codebase
    ↳ AI 讓程式碼量暴增，資安人員看不完。Claude security 會在夜間自動掃過整個 codebase（一個專案裡的所有程式碼），找出安全漏洞。
  • 35:54 它會標出多種漏洞（包含它判斷最嚴重的），並讓你針對每個漏洞啟動一個 Claude Code session 處理
    ↳ 它會列出各種漏洞，並標出它判斷最嚴重的幾個。每個漏洞都能直接開一個 Claude Code session 去處理。
  • 35:54 回應「想跑大型重構、遷移等大規模任務」：推出 dynamic workflows
    ↳ 重構是功能不變、把程式整理重寫；遷移是把系統搬到新技術或新版本。這種動輒牽動大量檔案的大工程，就交給 dynamic workflows。
  • 36:26 dynamic workflows 讓 Claude Code 以確定性（deterministic）結構，在數十到數百個 agents 上平行執行
    ↳ deterministic（確定性）指的是流程事先定好、每次都照同一套步驟跑。dynamic workflows 用這種固定架構，同時指揮幾十到幾百個 agent 平行分工。
  • 36:26 這些 primitives 可以組合使用；以上所有功能個人開發者今天就能開始用
    ↳ primitives 指的是這些基本功能，像積木一樣可以互相搭配使用。講者強調，這些不只是給大公司，個人開發者今天就能開始用。
  • 36:57 Spotify 用 Claude 遷移數千個 repo：以 Claude Agent SDK 打造 background agent，讀取白話英文寫的遷移計畫後派出一群 agents 開 PR
    ↳ Spotify 要把數千個 repo（程式碼倉庫）改成新做法。他們用 Agent SDK 做了一個 background agent（在背景自動運作的 agent），讀懂白話英文寫的遷移計畫後，派一群 agent 去開 PR。
  • 36:57 Spotify 每月合併超過一千個 PR 進 production，遷移時間縮短 90%
    ↳ 成果是：Spotify 每個月有一千多個這樣產生的 PR 被合併、正式上線，遷移花的時間少了九成。
  • 37:29 日本 C2C 二手市集 Mercari（字幕作 Merkari）整個工程團隊都用 Claude Code，實測工程產出年增 90%
    ↳ Mercari 是日本的二手交易平台，整個工程團隊都用 Claude Code。實際量到的工程產出比前一年多了 90%。
  • 37:29 講者表示業界普遍如此：數百萬開發者比以前完成更多工作、品質也更高
    ↳ 講者認為這不是特例：全球數百萬開發者都比以前完成更多工作，品質也更好。這是講者的觀察，影片沒有給具體數據。
  • 37:59 Demo 情境：假設是 Kaizen operations 公司，行銷網站目前只有英文，要拓展到另外 13 個市場，需先把網站在地化
    ↳ 接下來是實際示範。假設一家叫 Kaizen operations 的公司，官網只有英文，要進軍另外 13 個市場，第一步得先 localize（在地化，把網站改成當地語言）。
  • 38:30 先用單一 Claude Code agent：下 prompt 要它把網站轉成日文，它會探索 codebase、建立語言切換器並翻譯所有文字
    ↳ 先示範只用一個 agent：叫它把網站改成日文。它會自己去翻程式碼、找出文字在哪，做一個切換語言的選單，再把所有文字翻完。
  • 38:30 完成一個日文翻譯約花 3 分鐘；剩 12 個語言若依序一個個做，要將近一小時，還得大量手動下 prompt
    ↳ 翻一個語言大約 3 分鐘。剩下 12 個語言如果一個接一個做，要將近一小時，而且你得一直守著，每個都重新下一次指令。
  • 39:00 改用 dynamic workflow：讓 Claude 建立可重複的流程，同時平行跑所有新語言的翻譯
    ↳ 改用 dynamic workflow：先讓 Claude 設計一套可以重複使用的流程，再讓所有新語言同時開始翻，不用排隊等。
  • 39:30 Claude 建好 workflow 後可在 Desktop app 的側邊窗格打開觀看，能看到 12 個翻譯 agents 同時運作
    ↳ 流程建好後，在 Desktop App 的側邊窗格打開，就能看到 12 個翻譯 agent 同時在工作。
  • 39:30 翻譯 agents 完成後，會再建立 12 個 agents 來驗證各語言的成果
    ↳ 翻完之後，它還會再派 12 個 agent，各自檢查一個語言翻得對不對，等於多了一道品管。
  • 40:01 原本需要跑 12 個獨立任務，現在一個 prompt 就能完成
    ↳ 原本你要開 12 個任務、分別交代，現在只要下一次指令，就全部完成。
  • 40:01 這個 workflow 可存成 JavaScript 程式碼，之後翻譯時重複使用
    ↳ 這套流程可以存成 JavaScript（一種常見的程式語言）檔案。下次要翻譯時直接拿出來跑，不用重新設計。
  • 40:01 成果：Claude 一次產出 12 個在地化版本的網站，可從下拉選單切換查看
    ↳ 最後，網站一次就多了 12 種語言版本，從下拉選單就能切換查看。
  • 40:33 dynamic workflows 也可用於大規模遷移、codebase 稽核、效能優化——任何需要以確定性結構同時跑多個 agents 的大型工作
    ↳ 不只翻譯，大規模遷移、全面檢查程式碼、提升效能也都適用。只要是需要很多 agent 照固定流程一起做的大工程，都可以用。
  • 40:33 以上功能今天都已推出，包含 dynamic workflows 與 Claude Desktop app 裡的 Claude Code
    ↳ 講者宣布這些功能今天都已上線，包括 dynamic workflows 和 Desktop App 裡的 Claude Code。
  • 40:33 最新模型 Claude Fable 5（字幕作 Quad Fable 5）已開放給所有 Claude Code 使用者

    ↳ 講者把整場串起來：Dian 講模型能力持續往上，Angelo 講 agent 可以跑在你自己能掌控的主機上，再加上這段介紹的工具，是同一件事的三個層次。

    ↳ 講者建議之後的場次這樣選：想了解新模型能做什麼，聽研究場；要做給使用者用的 agent，聽平台場；想每天寫程式都用 Claude Code，去工作坊。

📘 術語
auto mode（自動模式）：把權限交給 Claude，等 Claude Code 測完並開好 PR 後才回來檢查
CLI（命令列介面）：Claude Code 的起點，給想要極簡文字介面、最多控制與自訂的進階使用者
IDE（整合開發環境）：給想用同樣 agent、又想同步看到所有程式碼變更的使用者
multi-clauding（多開 Claude）：使用者對同時平行跑多個 Claude Code 的暱稱
control plane（控制面板）：Desktop 的側邊欄或 CLI 的 agents view，用來看各 agent 的狀態
agents view（agents 檢視）：CLI 裡的新介面，可看等待中、執行中、已完成的 session，並在同一列回覆
session（工作階段）：Desktop 可統一檢視本機與雲端的 session，可跳進跳出而不搞丟進度
Claude Agent SDK（Claude Agent 開發套件）：VS Code 擴充套件與 Desktop 版 Claude Code 的基礎；Spotify 也用它做 background agent
PR (pull request)（合併請求）：Claude Code 測完後開出、等人審查的變更；code review 產品會抓出其中的 bug
remote control（遠端控制）：為了讓人能隨時隨地寫程式而推出，和 iOS、Android 版 Claude Code 一起推出
routines（例行任務）：設定一次後，依排程、webhook 或 API 呼叫自動啟動 Claude Code
webhook（Webhook）：字幕列為觸發 routines 的方式之一
dynamic workflows（動態工作流程）：讓 Claude Code 以確定性結構，在數十到數百個 agents 上平行執行大型任務
deterministic structure（確定性結構）：dynamic workflows 用來組織大量 agents 平行跑的方式
background agent（背景 agent）：Spotify 做的 agent，讀取白話遷移計畫後派出一群 agents 開 PR
localize（在地化）：Demo 中把英文網站翻譯成各市場語言
