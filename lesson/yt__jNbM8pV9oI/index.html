🧑‍🏫 這支影片是 OpenAI 的 solutions engineer Stephanie Annani 分享她平常怎麼用 Codex 工作。她用 Codex 分析客戶收到的評論，再用 Codex 做出客戶網站的示範版本。值得看的地方是，這些用法都在幫她理解客戶、說服客戶，不只是寫程式。

  • 00:01 Solutions engineer Stephanie Annani 說，她的工作不只要做東西（build），也要理解客戶；客戶想知道 OpenAI 的技術能怎麼改善他們顧客的體驗
    ↳ Solutions engineer（解決方案工程師）是幫客戶把技術用在實際問題上的人。她說這份工作不只要動手做，也要先搞懂客戶在乎什麼，也就是 OpenAI 的技術能不能讓他們的顧客用得更好。
  • 00:01 她請 Codex 去看客戶在 Trustpilot 上的評論，產出大量分析，整理出顧客怎麼評價這家客戶
    ↳ Codex 是 OpenAI 的 AI 助手，能讀資料、寫程式、把任務做完。Trustpilot 是消費者留評價的網站。她讓 Codex 讀大量評論再整理分析，很快看出顧客對這家公司滿意和不滿的地方。
  • 00:31 接著用 Codex mock up 客戶的網站，直接在網站情境裡示範，要做出顧客要求的修改有多容易
    ↳ Mock up 是做一個看起來像真的、但沒有正式上線的示範版本。她用 Codex 仿做客戶的網站，直接在上面改出顧客想要的地方，讓客戶親眼看到改起來其實不難。
  • 00:31 用 Codex 工作時，有時 Codex 會把事情做得很完美；她會用 Skills 把這種時刻記下來，變成日後固定 workflow 的一部分
    ↳ Workflow 是每次都照著走的固定工作流程。Skills 是把 Codex 某次做得特別好的做法存起來。之後遇到同類工作就照那套做法再做一次，不必每次從頭摸索。
📘 術語
Solutions engineer（解決方案工程師）：工作不只是 build，也要理解客戶，向客戶展示技術怎麼解決他們的問題
Skills（技能）：用來記下 Codex 表現很好的那一刻，讓它變成之後固定 workflow 的一部分
