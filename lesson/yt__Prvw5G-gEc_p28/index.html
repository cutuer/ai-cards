🧑‍🏫 這段是 Grok 團隊「三天內用 AI 做出一門生意」直播的其中一段。前半看他們怎麼同時派好幾個 AI 幫手改網站、修 bug，後半請來 Stripe 的人，談怎麼讓 AI 安全地幫你花錢。想知道 AI 除了聊天還能幫人把事情做完，這段是很實際的現場示範。

  • 320:26 把 bot 分享成模板時，Grokbot 會刪掉這個 bot 的敏感資訊，不會外流到 workspace 以外，但會保留它的核心想法和核心記憶
    ↳ 「模板（template）」就是把你的 bot 打包起來，讓別人複製一份去用。分享時 Grokbot 會自動拿掉私人、敏感的資料，只留下 bot 的做事方式和它記住的重點，所以別人拿到的是乾淨的版本。
  • 320:26 在 team 帳號可以設定只給團隊用，也可以公開；流程最後會拿到一個可以分享的連結
    ↳ 如果用的是團隊方案，可以選只給同事用，也可以開放給所有人。設定完會得到一個網址，把它傳給別人，對方就能裝這個 bot。
  • 320:26 先前直播示範過怎麼安裝別人分享的 bot：他們幫 go-to-market 團隊的 Matt 裝了 cerebro
    ↳ 這個功能已經實際用過：之前直播時，他們幫負責 go-to-market（把產品推到市場上賣的團隊）的 Matt，裝了一個別人做好的 bot，叫 cerebro。
  • 321:01 想加的功能：把自己的 bot 匯入遊戲，組一支自己的 bot 團隊去做事
    ↳ 他們還想加一個功能：讓你把自己的 bot 放進他們做的遊戲裡，像組隊一樣派好幾個 bot 一起去完成任務。
  • 321:01 bot 剛送出一個改版排行榜的 PR，現在更好用，玩家可以在排行榜上找到自己
    ↳ PR（pull request）是「程式改好了，請審核後併進正式版」的申請。這次是 bot 自己寫程式、自己送出申請，改的是排行榜，玩家現在能直接找到自己的名次。
  • 321:32 新排行榜頂端有前三名頒獎台，也加上了分頁（pagination）
    ↳ 排行榜最上面做成頒獎台，放前三名。分頁（pagination）就是把很長的名單切成一頁一頁，像搜尋結果有第 1、2、3 頁，不用一路往下滑到底。
  • 322:04 製作單位提醒：大約 4 分鐘後、太平洋時間下午 2 點有下一段，預計 2:15 或 2:30 回來展示新進度
    ↳ 這條只是節目流程提醒：下一段大約 4 分鐘後開始，也就是太平洋時間下午 2 點；2:15 或 2:30 會回來，給大家看 AI 又做出了什麼。
  • 322:04 目前有幾個 agent 在做 UI 修飾和修先前講到的 bug；剛發布的 bot 模板也出現在畫面上了
    ↳ agent 是會自己動手、完成一連串工作的 AI，不只是回答問題。現在有好幾個 agent 在背景修飾 UI（使用者介面，就是畫面）、修 bug；剛分享的 bot 模板也已經出現在畫面上。
  • 322:35 新功能構想：做一個很簡單的輸入框，讓聊天室觀眾分享自己做的 bot 連結，先丟到 Slack，再挑幾個做成遊戲裡的 bot
    ↳ 構想很簡單：做一個輸入框，讓觀眾貼上自己 bot 的分享連結。連結會先送到 Slack（團隊用的聊天工具），團隊再從裡面挑幾個，做成遊戲裡的角色。
  • 323:06 目標是讓觀眾能在 ThursdayArena 裡玩到自己的 bot
    ↳ 換句話說，觀眾不只是看直播，還能在他們的遊戲 ThursdayArena 裡，看到自己做的 bot 上場。
  • 323:06 Matt 在 Cursor 裡改首頁：加上他們 X 帳號的連結，也在首頁放直播連結
    ↳ Cursor 是內建 AI 的寫程式工具。Matt 用它改網站首頁，加上他們 X 帳號的連結和直播連結，讓逛到網站的人找得到他們。
  • 323:37 Matt 在設定 cloud agent 環境：把 preview 用的 API key 和憑證交給 agent，讓它能像人一樣拉下 dev 環境並啟動
    ↳ cloud agent 是在雲端主機上跑的 agent，不佔用你的電腦。API key 和憑證就像鑰匙和通行證，交給它以後，它能像工程師一樣，自己把開發用的環境（dev 環境）架起來、跑起來。
  • 324:10 這呼應 Lauren 一直在講的「feedback loop（回饋迴圈）」概念
    ↳ feedback loop 指「做完馬上看到結果，再照結果修正」的循環。agent 能自己把環境跑起來看成果，就不用每次都等人幫它檢查，改起來更快。
  • 324:10 Matt 開始做探索性的 base ui 遷移，因為畫面上按鈕太雜亂；他先啟動了一個 planning agent
    ↳ 遷移（migration）是把畫面上的元件整批換成另一套工具來做。Matt 嫌按鈕樣式太亂，想試著換成 base ui。他先叫出 planning agent，就是先規劃、再動手的 agent。
  • 324:40 planning agent 會反過來問你需要什麼（elicitation），一起把需求釐清後再實作；Matt 覺得這很適合用來處理自己不常用的技術
    ↳ elicitation 是 agent 反過來問你問題，像裝潢師傅開工前先問你預算和想要的風格。碰到不熟的技術時特別好用，因為你常常連自己該交代什麼都不確定。
  • 324:40 base ui、radix 這類工具，本質上是用來建立元件庫、做出標準化使用者介面的系統
    ↳ base ui、radix 是現成的介面零件組，裡面有按鈕、選單、對話框這些元件。整個網站都用同一套零件，按鈕的長相和用法才會一致，不會東一個西一個。
  • 324:40 Matt 的看法：基礎打好之後，很多事情就可以直接丟給 cloud agent 處理
    ↳ 意思是：地基先打穩（環境設好、元件統一），之後很多小修改就可以放心直接交給雲端的 agent 去做，人不用每件事都盯著。
  • 325:13 修 shop 介面（現在能看到完整卡片）的 agent 交出了一個不錯的 PR，當場 merge，直播中修好一個 bug
    ↳ merge 就是把 PR 裡的修改正式併進網站。有個 agent 修好了商店頁面，原本卡片顯示不完整，現在能看到整張。團隊看過覺得沒問題就當場併入，直播中就修好一個 bug。
  • 325:48 回顧影片：72 小時內要打造一家公司；原則是做大家想要的東西，最好是自己也會用的，並且要有人味（human touch）
    ↳ 這裡插播之前的回顧片：挑戰是 72 小時內做出一家公司。原則是做大家真的想要、最好自己也會用的東西，而且要有人味，不能只是冷冰冰的 AI 產品。
  • 325:48 回顧影片提到的其中一個構想：在 San Francisco 辦實體的餐廳快閃活動（restaurant pop-up）
    ↳ 回顧片提到的其中一個點子，是在舊金山辦實體的餐廳快閃活動（pop-up，借場地短期營業的臨時店）。
  • 326:55 進度整理：今天是第三天，用 Grokbot 打造一門生意；兩天前開始，先探索各種點子，目標是週四前上線
    ↳ 幫中途進來的觀眾整理進度：今天是第三天，他們用 Grokbot 從零開始做一門生意。兩天前先發想各種點子，目標是週四前正式上線。
  • 326:55 今天早上遊戲已上線；他們的生意是遊戲工作室，第一款遊戲是 ThursdayArena.com，X 帳號為 @ThursdayArena
    ↳ 最後選的方向是開遊戲工作室。第一款遊戲 ThursdayArena.com 今天早上已經上線，X 帳號是 @ThursdayArena。
  • 327:30 來賓 Dan Hill 來自 Stripe，負責 Link；在 Grokbot 的 connector 裡可以找到 Link，另外也有其他 Stripe 相關的 connector
    ↳ Stripe 是很多網站背後用來收款的金流公司。來賓 Dan Hill 負責 Stripe 的 Link。connector 是 Grokbot 裡可以接上的外部服務，Link 就是其中之一，另外還有其他 Stripe 的服務。
  • 328:06 Link 讓 agent 能在網路上買東西；Dan 做遊戲時常需要買材質包，例如一組樹木素材
    ↳ Link 的用途是讓 agent 能自己上網付錢買東西。Dan 舉例：做遊戲常常要買素材包，像一整組樹木素材，這種事就能交給 agent 去買。

  • 328:37 Grokbot 裡有核准花費的介面，例如 agent 說要花 10 美元買樹木素材包，你按核准後，agent 才去安全地購買
    ↳ 花錢前 agent 一定會先問你，例如跳出「我要花 10 美元買樹木素材包」，你按了核准它才去買。錢要怎麼花，最後還是你決定。

    ↳ Dan 發現 AI 最近能做的事暴增，可是很多任務最後都卡在同一步：得付一筆錢才能買到東西，或把事情辦完。

    ↳ 第二種：創業者和 solopreneur（一人公司，一個人包辦所有事的創業者）。Dan 說他自己就有 17 個做到一半的專案。

    ↳ 這些專案常常一開始就得花錢，例如開通付費帳號、付費使用寄信服務，每一項都要刷卡。

    ↳ Stripe projects 已經整合進 Grok，也跟很多提供網站基礎服務的公司合作。想知道有哪些公司直接支援，可以到 projects.dev 看完整名單。

📘 術語
template（模板）：把 bot 分享出去的形式：刪掉敏感資訊，保留核心想法與記憶，可設為團隊限定或公開
PR（合併請求）：bot 送出改版排行榜的 PR；修 shop 介面的 PR 被當場 merge
pagination（分頁）：新排行榜加上的功能
cloud agent（雲端 agent）：給它 preview API key 和憑證，就能像人一樣拉下 dev 環境並啟動
dev server（開發伺服器）：Matt 提到 cloud agent 可能需要重新啟動 dev server
feedback loop（回饋迴圈）：Lauren 常講的概念，Matt 說設定 agent 環境跟這個有關
planning agent（規劃用 agent）：會問你需要什麼，和你一起把需求釐清後再實作
elicitation（需求引導）：agent 主動詢問你的需求、一起把事情理清楚
base ui / radix（UI 元件系統）：用來建立元件庫、實作標準化使用者介面的系統
connector（連接器）：Grokbot 裡可以接上的外部服務，Link 就是其中之一
Link（Stripe Link）：Stripe 的產品，讓 agent 用一次性卡片在網路上買東西
one-time use card（一次性使用卡）：Link 產生、讓 agent 拿去購物的卡片
Stripe projects（Stripe projects）：已整合進 Grok，連結一次 Stripe 帳號就能開通各家基礎設施服務
provision（開通／佈建）：開通資料庫、email、主機、網域等服務
solopreneur（一人創業者）：和創業者一起被列為需要 agent 付款的族群
✏️ 小考一題

根據 Dan Hill 的說法，Stripe 的 Link 用什麼方式讓 agent 在網路上買東西？

A. 直接把使用者的信用卡號交給 agentB. 由 Stripe 員工代替 agent 手動下單C. 讓 agent 用加密貨幣錢包付款D. 產生一次性使用的卡片給 agent 購物
