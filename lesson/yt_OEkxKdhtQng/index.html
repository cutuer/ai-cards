🧑‍🏫 這支影片是金融 AI 公司 Model ML 的案例分享：他們用 GPT-5.6 Sol 這個模型，讓 AI 自己從頭到尾做出一份投資備忘錄簡報。值得看的是它示範了 AI 怎麼從「產出一堆內容」走到「交出接近完成、能直接修改的成品」，也說明了人在這個流程裡該做什麼。

  • 00:01 AI 產出的垃圾內容很多，「粗製濫造」和「真正把工作做好」之間差距很大
    ↳ 現在用 AI 很容易生出一大堆看起來像樣、其實不能用的東西。講者要說的是：產出很多不難，難的是做出真的能交差、不用重做的成果。
  • 00:01 Model ML 提供現成與客製化的 agent，工作方式和他們的客戶完全一樣
    ↳ agent 是能自己一步步把任務做完的 AI，不只是回答問題。Model ML 有現成的 agent，也能依需求客製，這些 agent 做事的流程跟他們的金融業客戶本人一樣。
  • 00:01 他們先用內部評估系統測試模型，結果表現超越所有 benchmark
    ↳ benchmark 一般指業界用來比較模型的標準測驗。Model ML 會先用自家的內部評估系統測試新模型，講者說這個模型的表現超越了所有 benchmark。
  • 00:01 範例：使用者要製作投資備忘錄，只需提供簡短描述，並指出要去哪裡蒐集資訊
    ↳ investment memorandum（投資備忘錄）是向投資人說明一個投資案的文件。使用者只要寫幾句需求，再告訴 AI 去哪裡找資料，不用寫落落長的指令。
  • 00:31 5.6 版模型會先規劃簡報該有哪些投影片、每張該長什麼樣子
    ↳ 它不會一開始就埋頭做，而是先擬大綱：整份簡報要有哪些投影片、每張放什麼、版面長怎樣，先把架構定下來。
  • 00:31 接著自己做研究、做計算，再自行製作圖形、表格、圖表和 logo
    ↳ 架構定好之後，查資料、算數字、做圖形、表格和圖表，連 logo 都由它自己處理，不用人一項一項交代。
  • 00:31 最後一步會為每張投影片的視覺吸引力評分，講者表示沒看過其他模型做得這麼好
    ↳ 做完之後它還會自己檢查，替每張投影片好不好看打分數。講者說，他沒看過其他模型把這一步做得這麼好。
  • 00:31 最終交給使用者可編輯的 PowerPoint 檔，所有資料來源都有追蹤標註
    ↳ tracked sources 是指內容和數字都標出資料來源。最後交出的是可以直接修改的 PowerPoint，想查某個數字從哪裡來，也找得到。
  • 00:31 使用者應專注在做決策：調整假設、強化訊息，而不是重做一遍分析
    ↳ 人的角色從做苦工變成做判斷：看 AI 用的假設合不合理再調整，把要傳達的重點講得更有力，而不是把分析從頭再做一次。
  • 01:01 早期模型也能做分析師的工作，但使用者必須清楚拆解任務，並明確指定成果要長什麼樣子
    ↳ 舊模型也做得出分析師的工作，只是你得先把工作拆成一個個小步驟交代清楚，還要講明成品長什麼樣子，它才做得好。
  • 01:01 講者認為字幕中的 GPT 5.6 Soul 讓 agent 產出的成果更接近最終成品
    ↳ 講者的結論是，這個模型（標題寫 GPT-5.6 Sol，字幕寫成 Soul）讓 agent 交出的東西更接近最終成品，人要補的部分變少了。
📘 術語
agent（代理程式）：Model ML 提供的現成或客製化 AI，像客戶一樣執行工作
benchmark（基準測試）：字幕沒有解釋，只提到模型在內部評估中超越所有 benchmark
internal evaluation system（內部評估系統）：Model ML 用來測試模型表現的自家系統
investment memorandum（投資備忘錄）：範例任務，模型要產出含研究、計算和圖表的投影片
tracked sources（可追蹤的資料來源）：交付的 PowerPoint 會附上所有追蹤的資料來源
✏️ 小考一題

在投資備忘錄範例中，5.6 版模型完成投影片後的最後一步是什麼？

A. 把簡報翻譯成多國語言B. 將簡報轉成影片C. 為每張投影片的視覺吸引力評分D. 自動把簡報寄給客戶
看答案
答案：C。[00:31] 字幕提到模型最後會為每張投影片的視覺吸引力評分（rating each slide for visual appeal）
