📘 術語
credits（點數）：生成要花的點數。影片教你不要亂生成浪費它；Soul Cinema 字幕稱 8 張圖 1 credit。
plot twist（劇情反轉）：Claude 主動提議加入幾個 plot twist，作者同意後才給劇本。
asset / asset sheet（素材／素材表）：影片中的素材包含角色 character sheet、場景與道具，都收在 blog post。
character sheet（角色設定圖）：同一角色的多角度圖（正面、側面、全身、特寫），幫模型在每個場景把臉做對。
win rate（成功率）：可用生成結果的比例。灰背景、3/4 角度都能提高 win rate。
canvas（畫布）：作者的工作區，所有最終素材放在這個畫面上，方便檢視、不會遺失。
batch（批次）：一次跑一批生成。場景跑幾批，第一場在 cdance 跑四批。
3 quarters angle（3/4 角度）：斜側角度，能增加深度，讓攝影機移動時更有依據，win rate 比正面平拍高。
edit prompt（編輯用 prompt）：請 Claude 依你的調整需求（如帆改黑色）寫成完整的修圖 prompt，再交給 GPT image 2.0。
raw pass（初稿階段）：用 Soul Cinema 以簡單 prompt 生成幾次、取得大量變化的階段。
elements（元素）：把素材以和 Claude 相同的名稱加入平台，之後 prompt 會依這些 tags 自動對應輸入。
tags（標籤）：素材的名稱標籤，生成場景時 prompt 靠它自動對應素材，避免搞混。
skill（技能（Claude 擴充功能））：上傳到 Claude 的功能，路徑為 customize → skills → plus → upload a skill。
prompt builder skill（prompt 建構 skill）：作者做的 skill，內含 director hacks，會建立 plots 並寫出詳細 prompt。
director hacks（導演技巧）：作者的 prompt builder skill 內建的內容；字幕未進一步解釋。
extras（臨時演員）：用一個額外素材產生、與場景相符的配角人物。
aspect ratio（畫面比例）：第一場設定為電影感的 21:9。
