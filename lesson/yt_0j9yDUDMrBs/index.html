🧑‍🏫 這支影片是 OpenAI 的行銷人員親自示範，怎麼用 ChatGPT 的 work 模式，把散在各處的產品資料整理成一篇部落格草稿。值得看的地方是流程拆得很具體：先接上資料來源、再給範本、接著挑客戶引言，最後追蹤更新。平常要寫報告、公告或介紹文的人，也可以直接照著用。

  • 00:04 ChatGPT work 能把分散的產品文件整理成一份有結構的草稿，供產品發表時使用
    ↳ ChatGPT work 是 ChatGPT 專門處理工作任務的模式。它會把散在各處的產品資料讀過一遍，整理成分好段落、有架構的草稿，新產品要發表時就有底稿可以改。
  • 00:04 講者 Sahil 在 OpenAI 行銷部門工作；新產品上市時，部落格文章是產品推廣活動的基礎
    ↳ 講者 Sahil 在 OpenAI 做行銷。新產品上市時，官方部落格文章是整個推廣的地基，其他宣傳內容通常都從這篇延伸出去，所以要最先寫好。
  • 00:04 以前寫文章要花好幾天，從 Slack、會議紀錄、文件和使用者研究收集資訊，還要說明這對客戶為什麼重要
    ↳ 以前寫一篇要花好幾天。資料散在 Slack（很多公司用的團隊聊天軟體）、會議紀錄、文件和使用者研究裡，得一份份翻。翻完還要想清楚，這產品對客戶到底有什麼好處。
  • 00:35 講者表示，ChatGPT work 能在他通勤到辦公室的路上先完成第一部分的工作；影片用一篇真實文章當例子示範
    ↳ 他的意思是，最花時間的「蒐集、拼湊」可以交給 ChatGPT 先做，人還在通勤路上，初稿就開始成形了。影片用的是一篇真實文章，不是隨便編的範例。
  • 00:35 步驟一：打開 ChatGPT 桌面版 app，切換到 work 模式；也可以在 chat.openai.com 或手機上操作
    ↳ 第一步是打開 ChatGPT 桌面版 app，把模式切到 work。不用桌面版的話，用瀏覽器開 chat.openai.com，或用手機，也能做一樣的事。
  • 00:35 步驟二：透過 plugins 連接工具，讓 ChatGPT 能存取框架、文件、研究、筆記等資料
    ↳ plugins（外掛）是讓 ChatGPT 連到你平常用的其他工具的橋梁。接上之後，它才讀得到你的文件、研究和筆記。沒接的話，就只能靠你一份份手動貼上。
  • 00:35 講者偏好用語音輸入：可以邊想邊說，比打字快很多，感覺像在跟同事講話
    ↳ 他喜歡用語音輸入（voice input，用講的代替打字）下指令。想到哪說到哪，不用先把句子組織好，比打字快很多，感覺像在跟同事交代工作。
  • 01:05 指令範例：「Hi ChatGPT, gather relevant context from these sources into a draft post.」（從這些來源收集相關內容，整理成文章草稿）
    ↳ 指令其實很簡單，白話就是「從這幾個地方找出相關內容，整理成一篇文章草稿」。重點是講清楚兩件事：資料從哪裡找，最後要交出什麼。
  • 01:05 再提供團隊的範本和過去的文章範例，讓 ChatGPT 了解格式、結構、語氣，以及一篇成功的文章應該長什麼樣子
    ↳ 接著給它團隊的範本（template，固定的文章格式），加上幾篇以前寫過的文章，讓它照著學段落怎麼排、語氣要多正式。這樣寫出來的東西才像你們團隊的風格。
  • 01:05 他們的部落格文章不只是一大片文字，還有各種互動元件，幫助讀者了解產品和產品對他們的意義
    ↳ 他們的文章不是一整片文字，中間會穿插互動元件（interactive components，文章裡特別設計的區塊，例如客戶故事），讓讀者更容易看懂產品，知道跟自己有什麼關係。
  • 01:35 有了具備結構和文字的初稿後，接著用 ChatGPT 製作互動區塊
    ↳ 順序是先搭骨架、再加料。等初稿的結構和文字都有了，才回頭請 ChatGPT 做那些互動區塊，不用一開始就全部一起處理。
  • 01:35 例子：團隊喜歡講真實客戶試用產品、感受到產品魔力的故事；講者電腦裡有好幾份團隊錄下的客戶訪談逐字稿
    ↳ 以客戶故事為例，團隊很愛放真實客戶試用產品、覺得「哇好厲害」的經驗。講者電腦裡有好幾份訪談逐字稿（transcripts，把錄音一字一句打成文字的紀錄）。
  • 01:35 以前得花好幾個小時聽錄音，找出能強化論點、反映不同觀點的引言放進部落格
    ↳ 以前要花好幾個小時聽錄音，挑出能撐住文章論點的話。還要刻意挑不同立場的客戶，免得整篇只剩一種聲音。
  • 02:05 現在只要描述想要的客戶引言的形式和故事線，ChatGPT work 幾分鐘內就能掃過逐字稿，產出符合所有要求、可直接發表的評論
    ↳ 現在只要說清楚想要什麼樣的引言、要搭哪條故事線，ChatGPT work 幾分鐘就能翻完逐字稿，挑出符合條件、可以直接放進文章的客戶說法。
  • 02:05 最後請 ChatGPT 持續監看資料來源，如果發表過程中上市細節有變，就提出文章的更新建議
    ↳ 最後請它繼續盯著那些資料來源。上市前細節常常會改，一有變動，它就會提醒你文章哪裡該跟著改，不用自己一直回頭比對。
  • 02:05 成果：不到一天，就從分散的產品上市資訊產出一份完成、可分享的文章草稿
    ↳ 成果是：原本要花好幾天，現在不到一天，就把四散的上市資訊整理成一份完整、可以拿給同事看的草稿。要注意它的定位還是草稿，不是直接發表的成品。
📘 術語
ChatGPT work（ChatGPT 工作模式）：能把分散的產品文件整理成有結構草稿的功能；在桌面版 app 切換到 work 模式使用
plugins（外掛）：用來連接工具，讓 ChatGPT 能存取框架、文件、研究、筆記等資料
voice input（語音輸入）：講者可以邊想邊說，比打字快很多，感覺像在跟同事講話
template（範本）：提供給 ChatGPT，搭配過去的文章範例，讓它了解格式、結構和語氣
interactive components（互動元件）：文章裡的互動區塊，幫助讀者了解產品和產品對他們的意義，例如客戶故事
transcripts（逐字稿）：團隊錄下的客戶訪談文字紀錄，ChatGPT 會掃過它們找出合適的引言
