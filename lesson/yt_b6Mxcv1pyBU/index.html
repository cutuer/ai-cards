🧑‍🏫 這支影片介紹 Codex 的 Chrome extension。Codex 是 OpenAI 的 AI 工作助手，裝上這個 extension 後，Codex 可以直接在你平常用的 Chrome 裡幫你做事。影片也說明什麼時候該用 extension、什麼時候先用 plugin，對每天在瀏覽器裡工作的人很實用。

  • 00:01 Codex 幾乎什麼都能幫忙，但前提是它能在實際工作的地方運作；對很多人來說，那個地方就是 Chrome
    ↳ Codex 是 OpenAI 的 AI 助手，能幫你查資料、整理東西、寫程式。它要碰得到你工作的地方才幫得上忙，而很多人每天的工作都在 Chrome 裡。
  • 00:01 官方推出 Codex 的 Chrome extension，可搭配 Windows 與 macOS 上的 Codex app 使用
    ↳ Chrome extension 就是裝在 Chrome 上的擴充小工具。官方推出了 Codex 專用的版本，裝好後可以和電腦上的 Codex app 一起用，Windows 和 Mac 都支援。
  • 00:01 講者的習慣：如果需要的 app 有 plugin，通常先從 plugin 開始
    ↳ plugin 是讓 Codex 直接接上某個特定 app 的連接方式。講者的做法是：要用的 app 如果有 plugin，就先用 plugin，不急著動用瀏覽器。
  • 00:01 Connector 結構化又快，Codex 不必點過整個 UI，就能讀文件、查看訊息或建立檔案
    ↳ connector 就是這種直接連接的管道。它不用像人一樣在畫面上一路點按鈕，而是直接拿資料，所以讀文件、看訊息、建檔案都比較快也比較穩。
  • 00:31 需要 Chrome extension 的情況有三種：沒有 plugin、有 plugin 但所需功能只在完整 web app 裡，或所需脈絡就是已登入的 Chrome session
    ↳ 三種情況才需要 Chrome extension：app 沒有 plugin；有 plugin，但你要的功能只有網頁版才有；或你需要的正是已登入的狀態。session 就是登入後維持的那段連線。
  • 00:31 Chrome extension 讓 Codex 在你真正的瀏覽器裡工作：同一個 profile、session、cookies、分頁，以及同樣已登入的 app
    ↳ Codex 用的就是你平常那個 Chrome：同一個使用者設定（profile）、同樣的 cookies（網站用來記住你是誰的小檔案）、同樣的分頁。已經登入的網站，它不用重新登入。
  • 00:31 in-app browser 適合本機開發任務，也能用 annotations 給 Codex 詳細回饋
    ↳ in-app browser 是 Codex app 內建的瀏覽器，適合在自己電腦上開發網頁時測試。你可以用 annotations 直接在畫面上標註，告訴 Codex 哪裡要改。
  • 01:02 Chrome extension 能同時在多個分頁平行工作，也能使用真實瀏覽器的許多功能
    ↳ 用 Chrome extension 時，Codex 可以同時開好幾個分頁分頭做事，也能用到真實瀏覽器的許多功能。
  • 01:02 範例：讓 Codex 研究最新發表的使用者反應、找出新使用情境、點出痛點，再把結果整理成一份真正的試算表
    ↳ 舉例來說，你可以請它上網看大家對某個新產品的反應，整理出新用法和抱怨點，最後直接做成一份真的試算表，不只是給你一段文字摘要。
  • 01:02 和一般的 computer use 相比，Codex 不會接管整個瀏覽器，而是建立自己的 Chrome 分頁群組，在裡面工作
    ↳ computer use 是讓 AI 看著螢幕、移動滑鼠來操作電腦的方式。Codex 不會這樣接管整個瀏覽器，而是自己開一組 tab group（分頁群組），只在那組分頁裡做事。
  • 01:02 Codex 可以開多個分頁、捲動頁面、尋找內容，並在過程中一邊推理，確認方向是否正確
    ↳ 它會像人一樣開分頁、往下捲、找資料，而且邊做邊想「這個方向對不對」，不是照著固定步驟硬跑完。
  • 01:34 這些都在背景進行，使用者可以在自己的分頁繼續工作，不受干擾
    ↳ 這些操作都在背景進行。你可以照樣在自己的分頁回信、看文件，它不會搶走你的畫面。
  • 01:34 Chrome extension 可以和其他 plugin 搭配使用
    ↳ extension 和 plugin 不用二選一，同一個任務裡可以一起用。有 plugin 的部分走 plugin，其他部分再交給瀏覽器處理。
  • 01:34 報帳範例：用 plugin 查 email、搜尋最近一趟出差的相關信件、擷取資訊並填寫報帳表單，還能直接從電腦上傳缺少的收據
    ↳ 報帳就是一個例子：先用 email 的 plugin 找出最近那趟出差的信件、抓出需要的資訊，再到網頁上填報帳表單。缺少的收據，它也能直接從你電腦上傳。
  • 01:34 extension 能利用程式碼執行，讓 Codex 控制 Chrome 時不必重複「截圖、推理、移動滑鼠」的循環
    ↳ code execution 就是讓 Codex 寫一小段程式來操作瀏覽器。這樣它不必每一步都「截圖、想一下、移動滑鼠」，可以省掉很多來回。
  • 01:34 因此 Codex 可以用腳本處理重複性工作，也能在多個分頁平行作業
    ↳ 所以遇到重複性的工作，例如很多筆格式相同的資料要處理，它可以寫個小腳本一次搞定，也能在好幾個分頁同時進行。
  • 02:04 範例：講者開發的多人繪圖遊戲中，Codex 啟動多個 subagent 一起玩，每個 agent 有自己的分頁，可以平行遊玩並合作
    ↳ subagent 是 Codex 另外叫出來、各自分工的小幫手。在講者做的多人畫圖遊戲裡，Codex 叫出好幾個 subagent，每個各用一個分頁同時玩，還會互相配合。
  • 02:04 Chrome extension 把 Codex 連接到你已經在用的工具和 app，讓它能做更多事
    ↳ 重點是你不用換新工具。Codex 直接接上你已經在用的瀏覽器和帳號，能幫你做的事就多了很多。
📘 術語
Chrome extension（Chrome 擴充功能）：讓 Codex 在你真正的瀏覽器裡工作，沿用同一個 profile、session、cookies 和分頁
plugin（外掛）：讓 Codex 連接特定 app 的方式；講者說有 plugin 時通常先用 plugin
connector（連接器）：結構化且快速，Codex 不必點過 UI 就能讀文件、查訊息、建檔案
in-app browser（app 內建瀏覽器）：適合本機開發任務，可用 annotations 給 Codex 詳細回饋
annotations（標註）：在 in-app browser 中給 Codex 詳細回饋的方式
session（工作階段）：已登入的 Chrome session 本身就可能是 Codex 需要的脈絡
cookies（cookies）：extension 沿用和你相同的 cookies
tab group（分頁群組）：Codex 會建立自己的 Chrome 分頁群組，在裡面工作，不接管整個瀏覽器
computer use（電腦操作）：字幕拿來和 extension 對比：extension 不會接管整個瀏覽器
code execution（程式碼執行）：讓 Codex 控制 Chrome 時不必重複截圖、推理、移動滑鼠的循環
subagent（子代理）：Codex 啟動的個別 agent，每個有自己的分頁，可平行合作玩遊戲
