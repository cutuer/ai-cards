🧑‍🏫 這支影片介紹 @Claude：把 Claude 直接加進團隊平常聊天的地方，例如 Slack（很多公司用來取代 LINE 群組的工作聊天軟體），讓它像一位同事一樣跟大家一起做事。如果你的團隊每天都在 Slack 討論工作，這支影片會告訴你 Claude 能幫上哪些忙，以及公司要怎麼管它能看、能做的範圍。

  • 00:01 Claude 現在能在團隊已在用的地方與整個團隊協作：把 Claude 加進團隊工作區（如 Slack）的頻道，它就能即時跟上全隊進度
    ↳ team workspace 是團隊平常工作的地方，像 Slack；channel（頻道）是裡面依主題分開的討論區。把 Claude 拉進頻道，它就能看到大家在聊什麼，跟上進度。
  • 00:01 不必再來回切換到 Claude 聊天視窗，也不必複製貼上來提供 Claude 需要的所有脈絡
    ↳ 以前要問 Claude，得另外開它的視窗，再把討論內容一段段貼過去解釋。現在它本來就在頻道裡，這些搬資料、補背景的工夫都省了。
  • 00:01 @Claude 已經在團隊工作區裡跟著看，可以直接在頻道中請它做複雜任務
    ↳ 在頻道裡打 @Claude，就是點名叫它，就像 @某個同事一樣。你不必只問簡單問題，可以直接在那裡交代比較複雜、需要好幾步的工作。
  • 00:01 範例：整理本週待辦事項清單，檢查這個頻道過去 3 天的討論串、Google Drive 裡的會議紀錄，以及未完成的 Asana 任務
    ↳ 例如請它列本週待辦：它會去看頻道近 3 天的 thread（針對同一件事的回覆串）、Google Drive（雲端硬碟）的會議紀錄，和 Asana（任務管理工具）沒做完的事。
  • 00:31 @Claude 能翻查你授權給它的所有內容：聊天紀錄、共享文件，甚至團隊的 connectors 和工具
    ↳ 你開放給它的東西它都能查：聊天紀錄、共享文件，還有 connectors 和其他工具。connectors 影片沒多解釋，可以先理解成讓 Claude 接上其他服務的連線。
  • 00:31 它能快速回答問題、彙整多個來源的資訊，也能標記問題、起草整份文件，甚至直接在團隊工具裡做更新與修改
    ↳ 它不只回答問題，還能把不同地方的資訊整理在一起、指出有狀況的地方、寫出整份文件草稿，甚至直接進團隊的工具裡改資料。
  • 00:31 它用自己的帳號運作，會記錄每一項變更以及是誰要求的
    ↳ Claude 有自己的帳號，不是借用某個人的身分。它改了什麼、是誰叫它改的都會留下紀錄，事後要追查很清楚。
  • 00:31 它也能存取個人工具，在合適時代表你回覆，但每次都會先徵求你的許可
    ↳ 它也能接上你個人的工具，在適合的時候代替你回覆別人。但每次動手前一定會先問你，你同意了它才會做。
  • 01:03 @Claude 為協作而設計：頻道裡任何人都能接續既有的請求，或交給 Claude 新任務
    ↳ 它是給整個頻道用的，不是某個人專屬。同事交代到一半的事，你可以接著追問或補充，也可以直接丟一個新工作給它。
  • 01:03 Claude 會把任務拆成步驟，讓所有人在它工作時都看得到進度
    ↳ 它做事時會把工作拆成一步一步，而且攤在頻道裡。大家都看得到它做到哪、卡在哪，不用一直問「好了沒」。
  • 01:03 你去處理其他要事時它能繼續做，完成時或需要你做決定時會通知你
    ↳ 你交代完就能去忙別的事，它會繼續做。做完了會通知你；遇到需要你拍板的地方，也會叫你回來決定。
  • 01:03 可以從任何連接到工作區的裝置查看進度、後續追問
    ↳ 不管用電腦還是手機，只要那台裝置有登入團隊的工作區，就能看它的進度，或接著問它問題。
  • 01:38 Claude 在頻道中跟著看時，能記住重要細節，並儲存你給它的指示
    ↳ memory（記憶）是 Claude 在頻道裡存下來的重點和規則。它會記住重要細節，你交代過的做事方式也會一直記著。
  • 01:38 範例指示：「這個頻道請記住：回答問題時，直接附上活動試算表中原始資料的連結」，Claude 會存下來，不必一再重複說明
    ↳ 例如你說「這個頻道回答時，要附上活動試算表原始資料的連結」，它就會記下來。之後每次都照做，不用每次重講一遍。
  • 01:38 任何人都能在頻道中 tag Claude 來讀取或更新它的記憶
    ↳ 記憶不是只有一個人能管。頻道裡任何人 tag（也就是 @）Claude，都可以問它記了哪些東西，或叫它新增、修改。
  • 01:38 Claude 會學習團隊的風格與偏好，因此隨著時間可以交給它更難的任務
    ↳ 它會慢慢摸清你們團隊習慣怎麼寫、喜歡什麼格式。越了解你們，就越能放心把難一點的工作交給它。
  • 02:09 可以指引 Claude 參照風格指南、檢查清單等文件交叉比對；之後更新檢查清單，Claude 預設也會跟著保持最新
    ↳ 你可以叫它做事時對照風格指南或檢查清單。之後你更新了清單，它預設會照新版本做，不用再特別通知它。
  • 02:09 @Claude 提供給 Team 與 Enterprise 帳號使用
    ↳ Team 和 Enterprise 是 Claude 的團隊版和企業版付費方案。只有這兩種帳號能用 @Claude，一般個人帳號用不了。
  • 02:09 以組織需求設計，讓你完全掌控它對敏感資料與工具的存取程度
    ↳ 這個功能是照公司需求設計的。公司可以完全決定它能碰到哪些敏感資料、能用哪些工具，不會讓它什麼都看得到。
  • 02:09 在每個加入它的頻道中，可個別決定它做哪些事、多常插話，以及能自主做多少事
    ↳ 每個頻道可以分開設定：它能做哪些事、多常主動插話、能不能不問人就自己動手。例如閒聊頻道少開口，專案頻道放手多一點。
  • 02:39 可以讓它存取其他公開頻道的資訊與資料，而 DM 與私人頻道會保持私密
    ↳ 它可以去參考其他公開頻道的資料。但 DM（兩人之間的私訊）和私人頻道的內容，它不會拿出來用。
📘 術語
channel（頻道）：團隊工作區（如 Slack）中的討論空間，可把 Claude 加進去與全隊協作
team workspace（團隊工作區）：團隊已經在工作的地方，字幕舉 Slack 為例
thread（討論串）：頻道中的對話串，範例請 Claude 檢查過去 3 天的討論串
connectors（連接器）：字幕列為 Claude 可翻查的團隊資源之一，與工具並列，未進一步解釋
memory（記憶）：Claude 在頻道中儲存的重要細節與指示，任何人都能 tag Claude 讀取或更新
DM（私訊）：字幕說 DM 與私人頻道會保持私密
Team / Enterprise（Team／Enterprise 方案帳號）：@Claude 開放使用的帳號類型
