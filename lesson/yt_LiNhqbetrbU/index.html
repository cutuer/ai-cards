🧑‍🏫 這支是 OpenAI 介紹 plugin extensions 的影片。它讓各家產品把自己的操作畫面和工具放進 ChatGPT，你可以在同一個地方自己動手操作，也可以請 AI 幫忙。想知道 ChatGPT 之後會怎麼接上各種工作工具，或想自己做一個的人，可以看懂這個方向。

  • 00:00 開發 ChatGPT plugin 需要認識 plugin extensions，它能把產品的 UI 帶進 ChatGPT，做出更豐富、更有互動性的體驗
    ↳ plugin 是讓 ChatGPT 接上外部服務的外掛。plugin extensions 讓開發者把自家產品的操作畫面搬進 ChatGPT，你不只能打字問答，還能直接點選和操作。
  • 00:00 可以加入自己的工具、介面與工作流程，用起來像原生功能，不只是嵌入網頁或顯示 artifact
    ↳ 重點是「像原生」，用起來就像 ChatGPT 本來就有的功能。它不是塞一個網頁框，也不只是顯示一份 artifact（一般指 AI 產出、另外展示的文件或程式碼）。
  • 00:00 plugin 可以在 sidebar 有固定的入口，也可以在現有對話旁開一個可互動的 side panel
    ↳ sidebar 是左側側邊欄，plugin 可以在這裡有固定入口，隨時點開。side panel 是開在對話旁邊、可以互動的面板，讓你邊聊邊操作。
  • 00:00 開發者可以掌控版面配置、導覽和互動方式
    ↳ 畫面怎麼排、頁面怎麼切換、點下去會發生什麼，都由做 plugin 的人設計，不是被 ChatGPT 限制成固定樣子。
  • 00:30 開發者決定使用者能探索哪些內容，以及要怎麼操作
    ↳ 除了外觀，開發者也決定開放哪些內容給使用者看，以及使用者能做哪些動作。例如只開放查詢、不開放刪除。
  • 00:30 sidebar 最近新增的 code reviews、meetings 等項目，都是用同一套 plugin 系統做的
    ↳ ChatGPT 側邊欄最近出現的 code reviews（程式碼審查）、meetings（會議）等功能，用的都是同一套 plugin 系統。
  • 00:30 範例是一個設計編輯器：從 sidebar 打開就能修改，也能放在對話旁邊請 ChatGPT 幫忙，作品一直留在畫面上
    ↳ 設計編輯器範例：從側邊欄打開可以自己改，也能擺在對話旁請 ChatGPT 幫忙。作品一直留在畫面上，不用往上翻對話紀錄去找。
  • 00:30 extension 會把使用者的操作和對話串起來，例如選取設計的一部分，問「這裡能不能換個版面」
    ↳ 你在介面上的操作會跟對話串在一起。例如圈選設計的某一塊，直接問「這裡能不能換個版面」，不用先打字描述你指的是哪裡。
  • 01:01 在上述例子中，extension 能告訴 ChatGPT 使用者選取的是哪個元素
    ↳ 能這樣做，是因為 extension 會告訴 ChatGPT 你選的是哪個元素，所以它知道你說的「這裡」是哪一塊，回答才對得上。
  • 01:01 你可以在 ChatGPT 裡打造符合自家產品、團隊或工作方式的體驗
    ↳ 也就是說，開發者可以照自家產品、團隊習慣或工作方式，在 ChatGPT 裡量身打造一套用法，不必只靠通用的聊天方式。
  • 01:01 extensions 平台還能自訂：安裝 plugin 後的 onboarding 流程、composer 裡的 at mentions，以及新的控制項與設定，細節請看文件
    ↳ 還能自訂幾樣東西：裝好 plugin 後的引導流程（onboarding）、輸入框（composer）裡用 @ 叫出的項目（at mentions），以及新的控制項和設定。細節要看官方文件。
  • 01:01 範例 meetings：可以錄下對話內容，並在 ChatGPT 裡處理會議筆記
    ↳ 會議範例：可以錄下會議內容，之後直接在 ChatGPT 裡處理會議筆記，不用在不同工具之間來回搬資料。
  • 01:32 從 sidebar 選一場會議，問「我們決定了什麼、我要跟進什麼」，確認下一步之後再請 ChatGPT 起草追蹤訊息
    ↳ 實際流程是在側邊欄點一場會議，問「我們決定了什麼？我要跟進什麼？」。確認下一步之後，再請 ChatGPT 起草追蹤訊息。
  • 01:32 meetings 這個體驗用的，就是開發者也能使用的同一套 extension 平台
    ↳ 這個會議功能不是 OpenAI 內部專用的做法，用的是開發者也能使用的同一套平台，所以外部開發者也做得出類似的東西。
  • 01:32 範例 OpenAI Developers plugin：講者在 Codex 裡用 Plugin Creator 做出來
    ↳ 這個 plugin 是講者在 Codex（OpenAI 寫程式用的 AI 工具）裡，用 Plugin Creator 做出來的。Plugin Creator 是影片示範用來產生 plugin 的工具。
  • 01:32 OpenAI Developers plugin 可從 sidebar 打開查文件，裡面還有 plugin extensions、開發者工具和 DevDay 演講
    ↳ 這個 plugin 從側邊欄打開就能查開發文件，裡面也整理了 plugin extensions 的說明、開發者工具，以及 DevDay（OpenAI 開發者大會）的演講。
  • 01:32 這些例子展示了和 AI 合作的新模式：使用者可以在自己操作介面和請 ChatGPT 幫忙之間切換
    ↳ 這些例子在示範一種新的合作方式：不用全部丟給 AI，也不用全部自己來，可以隨時在「自己動手」和「請 ChatGPT 幫忙」之間切換。
  • 02:06 使用者可以先自己探索資訊、做出選擇，再檢視結果，然後決定下一步
    ↳ 流程會變成這樣：你先自己翻資料、做選擇，再檢查結果，然後決定下一步。主導權在你手上，需要時才請 AI 出手。
  • 02:06 plugin extensions 建立在 MCP 和 MCP apps 之上，讓產品的工具和介面進到同一個對話裡
    ↳ 技術上，它建在 MCP（Model Context Protocol，讓 AI 連接外部工具的公開標準）和 MCP apps 之上，讓產品的工具和介面都進到同一個對話裡。
  • 02:06 入門做法：挑一件使用者需要幫忙的事，用 Plugin Creator 做出第一版，再逐步改進
    ↳ 入門建議：先挑一件使用者真的需要幫忙的事，用 Plugin Creator 做出第一版，不求完美，之後再一步步改進。
📘 術語
plugin extensions（plugin 擴充功能）：讓你把更多產品 UI 帶進 ChatGPT，加入像原生一樣的工具、介面與工作流程
sidebar（側邊欄）：plugin 可以在這裡有固定入口；code reviews、meetings 等項目也放在這裡
side panel（側邊面板）：開在現有對話旁邊、可以互動的面板
artifact（產出物）：字幕沒有定義，只說 plugin extensions 不只是顯示 artifact
onboarding flow（新手引導流程）：安裝 plugin 後的引導流程，可以自訂
at mentions（@ 提及）：composer 裡可以自訂的項目之一，字幕沒有進一步說明
composer（輸入框）：字幕沒有解釋，只說 at mentions 是在 composer 裡
MCP / MCP apps（MCP／MCP 應用）：plugin extensions 的基礎，讓產品工具與介面進到同一個對話；字幕沒有解釋全名
