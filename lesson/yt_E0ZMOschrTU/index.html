🧑‍🏫 這支影片示範 OpenAI 團隊準備推出 Voice（語音）功能時，怎麼全程用說話指揮 ChatGPT 和 Codex 做事，從投影、寫文案、討論點子到抓 bug 都有。值得看的地方是，它展示了語音已經能帶著 AI 做正事，不只是聊天。

  • 00:00 用語音請 Chat 把畫面投到投影機（projector），並播放 daylist
    ↳ 對著電腦講話，請 ChatGPT（影片裡叫它 Chat）把畫面投到投影機，再播放 daylist（一份播放清單）。這些都不用滑鼠點，開口講就完成了。
  • 00:00 團隊要準備下週 voice launch 的上線素材，用語音請它協助草擬 blog posts
    ↳ 團隊下週要推出 Voice 功能，得準備上線素材。他們直接用說的，請它幫忙擬部落格文章（blog posts）的初稿，不用從空白頁開始寫。
  • 00:00 初稿文案範例：「Meet Voice in the desktop app」、「Voice makes it easier to move work forward naturally」
    ↳ 它寫出的句子像「在桌面版 App 認識 Voice」、「Voice 讓你更自然地把工作往前推」。這只是初稿，方向對了，再由人來調整就好。
  • 00:00 另一句文案：「Use your computer without breaking flow」，團隊決定「Let's ship it」
    ↳ 另一句是「用電腦時不必打斷手上的節奏」，也就是邊做事邊講話就行。團隊看完說「Let&#x27;s ship it」，意思是可以了，就這樣發出去。
  • 00:00 使用者提出一個上線前最後修飾（last-minute polish）的功能點子
    ↳ 上線前，使用者還想做一點最後修飾（last-minute polish），也就是不大改架構、讓成品更完整的小功能。他把這個點子丟給它討論。
  • 00:30 使用者先隨口講一段想法，再要求它提出問題並反駁（push back）
    ↳ 使用者先隨口講想法，沒整理好也沒關係。接著要它先提問，再反駁（push back），也就是挑毛病、點出風險，而不是只會附和。
  • 00:30 回應指出只在 shader 裡就能做到很多，因為 shader 已經有 audio 和 phase inputs
    ↳ shader 是負責畫面視覺效果的小程式。它回說很多事在 shader 裡就能做完，因為 shader 已經拿得到聲音（audio）和相位（phase）這兩種輸入資料。
  • 00:30 用語音請 Codex 檢查 feature flags，確認全部設定正確
    ↳ feature flag 是程式裡的功能開關，不用重新發布就能開啟或關閉某個功能。使用者用說的，請 Codex（OpenAI 寫程式的 AI 助手）檢查這些開關是否都設對。
  • 00:30 feedback channel 出現新的 bug report，要求開一個新 thread、做 pull request、找出 root cause
    ↳ 回報頻道出現新 bug。要它開新 thread（另開一條對話，不跟別的事混）、找 root cause（問題真正的源頭），再做 pull request（提出程式修改，讓人審過再併入）。
  • 00:30 找到原因：就是那個 feature flag 完全設定錯誤（totally misconfigured）
    ↳ 查到的原因很單純：就是那個功能開關完全設錯了（totally misconfigured）。這說明有時問題不在程式本身，而是出在設定上。
  • 00:30 做法總結：設定一個目標（goal），之後再標記（tag）團隊來 review
    ↳ 整套做法是先給它一個目標（goal），讓它朝那件事去做，之後再標記（tag）同事來審核（review）。AI 負責動手，人負責把關。
  • 01:00 使用者表示會從手機 check in；它回應會為此建立一個 follow-up goal
    ↳ 使用者說之後會用手機查看進度，它就另外建一個後續目標（follow-up goal），讓這件事繼續有人追，人不在電腦前也跟得上。
📘 術語
feature flag（功能旗標）：字幕未定義；影片中請 Codex 檢查它的設定，bug 的原因就是它設定錯誤
pull request（合併請求）：字幕未定義；處理 bug report 時要求做一個 pull request
root cause（根本原因）：字幕未定義；處理 bug 時要求找出 root cause
shader（著色器）：字幕未定義；只提到它已經有 audio 和 phase inputs
thread（對話串／工作串）：字幕未定義；處理新 bug 時要求開一個新 thread
goal（目標）：字幕未定義；設定 goal 後可標記團隊之後 review，也可建立 follow-up goal
