🧑‍🏫 這支影片講 Event Horizon Telescope 的研究者 CK，怎麼用 OpenAI 的 AI 寫程式工具 Codex 找出新的計算方法，讓以前電腦算不動的黑洞電漿模擬變得可行。值得看的地方是：AI 不只幫忙寫程式，還能在科學研究裡一次試很多點子，大幅加快試錯的速度。

  • 00:00 Event Horizon Telescope 計畫已經進行很多年，2017 年拍出第一張黑洞影像，今年正在製作第一支黑洞影片
    ↳ Event Horizon Telescope（事件視界望遠鏡）是一個專門拍黑洞的國際計畫。2017 年拍到第一張黑洞照片，現在要從拍「照片」進一步拍「影片」。
  • 00:00 我們之所以看得到黑洞，唯一的原因是有非常熱的電漿（plasma）落向黑洞
    ↳ 黑洞本身不發光，連光都逃不出去。我們看到的其實是周圍極高溫的電漿（plasma，帶電的高溫物質）在發光。所以想看懂黑洞影像，得先搞懂這團電漿。
  • 00:00 要正確模擬黑洞周圍的電漿，必須追蹤電子和離子沿著磁場的運動
    ↳ 電漿由帶電的電子和離子組成，會被磁場牽著走。要模擬得準，就得算出這些粒子怎麼順著磁場移動，不能把它當成一團普通氣體粗略處理。
  • 00:32 這個問題在計算上難以處理（computationally intractable）
    ↳ computationally intractable 指「計算量大到實際上算不完」。不是不知道怎麼算，而是照現有方法去跑，花的時間和電腦資源多到不切實際。
  • 00:32 有了 Codex，現在能找到新的演算法來模擬，讓以前不可能的模擬變成可能
    ↳ Codex 是 OpenAI 的 AI 程式助手，會寫程式也會執行程式。這裡的突破不是電腦變快了，而是靠 Codex 找到新的算法，讓原本算不動的模擬變得算得動。
  • 00:32 CK 曾參與 Event Horizon 團隊拍下第一張黑洞靜態影像，在系上被稱為「黑洞模擬專家」（the black hole simulation guy）
    ↳ CK 是影片裡的研究者，參與過拍下第一張黑洞照片的團隊，在系上專門做黑洞模擬，所以同事都叫 CK「黑洞模擬專家」。
  • 00:32 黑洞之所以有趣，是因為它打破了我們目前對物理的理解
    ↳ 物理學家特別在意黑洞，是因為在那麼極端的環境裡，現有的物理理論會有解釋不了的地方。研究黑洞，就有機會找到理論的漏洞。
  • 01:03 研究時不確定自己到底在找什麼；就算發現某個東西是錯的，也一樣在推動這個領域進步
    ↳ 前沿研究不像照著食譜做菜，常常連要找的東西長什麼樣子都不確定。證明某條路走不通也算成果，後面的人就不必再白走一次。
  • 01:03 站在前沿、學到從來沒人發現過的全新事物，是非常令人興奮的事
    ↳ 研究者最大的動力，是親眼看到全人類都還沒看過的東西。當「第一個知道」的人，就是做前沿科學最吸引人的地方。
  • 01:03 黑洞周圍那道「有去無回的邊界」叫做 event horizon（事件視界），能觀測到它，等於觸及整個宇宙的邊緣
    ↳ event horizon（事件視界）是黑洞周圍的一道界線，任何東西越過就再也出不來，連光也一樣。能觀測到這條界線，等於看到了人類能觀測的極限。
  • 01:35 模擬遇到的問題：如果只用標準方法，數值方法（numerical schemes）會不穩定
    ↳ numerical scheme（數值方法）是讓電腦一步一步逼近答案的計算方式。「不穩定」是說誤差會越滾越大，算到後來數字失控，結果完全不能用。
  • 01:35 CK 用 Codex 實作了一個 agent skill：Codex 會先試著理解問題，再規劃需要哪些評估，才能判斷哪個演算法比較好
    ↳ agent skill 是替 AI 寫好的一套工作流程，讓它照步驟自己做事。CK 的流程是：Codex 先搞懂問題，再自己決定用哪些測試，來比較哪個演算法（解題的計算步驟）比較好。
  • 01:35 Codex 會產生十種不同的數值方法，目前看到最好的一種快了一千倍
    ↳ Codex 一次提出十種不同的數值方法給研究者比較，到目前為止表現最好的那一種，速度快了一千倍。
  • 02:05 以前試十種不同的想法要花十天，現在 Codex 做同樣的事只要幾分鐘
    ↳ 以前一天大概只能試一個點子，試十個就要十天；現在交給 Codex，幾分鐘就跑完。試錯的成本降這麼多，研究者就敢大膽多試。
  • 02:05 人類是探險者，天文學是探索的終極疆界；如果拍到第一支黑洞影片，將開啟黑洞天文物理學的新時代
    ↳ 天文學是人類探索未知最遠的前線。如果真的拍出第一支黑洞影片，科學家就能看到黑洞周圍怎麼隨時間變化，不再只有一張定格照片。
  • 02:05 更仔細觀察宇宙時，事物往往和我們最初想像的很不一樣，這正是探索這麼有力量的原因
    ↳ 越仔細看宇宙，越常發現它和我們原本以為的不一樣。探索的價值就在這裡：它會不斷修正我們對世界的認識。
📘 術語
Event Horizon Telescope（事件視界望遠鏡）：字幕說這個計畫已進行多年，2017 年拍出第一張黑洞影像，今年要做第一支黑洞影片
event horizon（事件視界）：黑洞周圍那道「有去無回的邊界」（the surface of no return）
plasma（電漿）：落向黑洞的極熱物質，也是我們看得到黑洞的唯一原因；模擬時必須追蹤其中的電子和離子
computationally intractable（計算上難以處理）：字幕用來形容：要追蹤電子和離子沿磁場運動的電漿模擬問題
numerical scheme（數值方法）：字幕說用標準方法時數值方法不穩定；Codex 會產生十種不同的數值方法來比較
agent skill（agent skill）：CK 用 Codex 實作的東西，會先理解問題，再規劃用哪些評估來判斷哪個演算法比較好
