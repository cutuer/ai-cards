🧑‍🏫 這支是 OpenAI 負責手機版 DOT 的開發者 Alex 親自示範：怎麼在 ChatGPT 手機 App 開通 DOT、幫它取名換外觀，再實際交代一件工作給它做。值得看是因為它展示 AI 從「你問它答」變成「你交代，它自己去做、做完回報」，而且整個過程都在手機上完成。

  • 00:00 講者 Alex 負責行動版 DOTS 的開發
    ↳ 講者 Alex 負責把 DOTS 做到手機版，所以這支是開發者本人親自示範手機上怎麼設定、怎麼用。
  • 00:00 DOTS 是 always on 的 proactive agents，能幫你分擔手上的事情
    ↳ DOT 是一種 agent（代理，會替你動手做事的 AI）。always on 指它一直在線待命；proactive 指它會主動處理事情，不用每一步都等你下指令。
  • 00:00 以前只能在 desktop 和 web 上 claim DOT，現在也能在行動裝置上設定，iOS 和 Android 都支援
    ↳ claim 在這裡是「開通、領取」自己的 DOT。以前只能在電腦版或網頁版開通，現在 iPhone 和 Android 手機上也能直接設定。
  • 00:00 設定非常簡單，設計上 DOT 基本上會自己完成設定
    ↳ 你不用自己研究一堆選項。DOT 被設計成會自己帶著流程走，大部分設定由它完成，你主要是跟著回應就好。
  • 00:00 步驟：打開 ChatGPT app，點左上角的「Meet DOT」入口，就會建立一個和你的 DOT 對話的 thread
    ↳ thread 就是一串對話紀錄，像聊天軟體裡的一個對話視窗。點左上角「Meet DOT」，App 會開一個專門跟你的 DOT 聊天的對話串。
  • 00:31 DOT 接著會開始運作，可能會要求 calendar 存取權限，也可能請你連接 email
    ↳ 開始之後，DOT 會自己往下跑設定。過程中可能跳出請求，要你允許它讀取行事曆（calendar），或請你把 email 帳號連進來。
  • 00:31 Alex 強烈建議 calendar 和 email 都連接，因為能給 DOT 更多 context；context 越多，它能分擔的事越多
    ↳ context 是指讓它了解你狀況的背景資料。連了行事曆和 email，它才知道你哪天忙、在跟誰往來，能替你接手的事也就越多。
  • 00:31 DOT 可以個人化，能幫它取名字、設定 avatar
    ↳ 這一步讓 DOT 更像「你的」助理：可以幫它取名字，也能設定 avatar，也就是代表它的頭像或角色外觀。
  • 00:31 示範把 DOT 取名為 Flossie；外觀可以選 avatar，也可以使用自己的 Codex Pet
    ↳ 示範中把 DOT 取名 Flossie。外觀有兩種選法：選一個 avatar，或改用你的 Codex Pet。影片只說 Codex Pet 是另一個外觀選項，沒有多做介紹。
  • 01:03 Alex 選擇自訂 avatar：設成他最喜歡的藍色，先不加配件
    ↳ Alex 選擇自己調整 avatar，把顏色改成他最喜歡的藍色，配件先不加。可見外觀能細部自訂，不只是從現成的裡面挑一個。
  • 01:03 DOT 有自己的電腦，也能存取你的電腦，適合處理 coding、prototyping 等複雜任務
    ↳ DOT 有一台自己的電腦，也能用你的電腦。所以它不只會聊天，還能真的動手處理寫程式（coding）、做雛形（prototyping）這類步驟多的工作。
  • 01:03 示範打電話給 Flossie，請它 prototype 一個 iOS widget，讓它可以出現在主畫面上
    ↳ Alex 用講電話的方式請 Flossie 做 prototype（先快速做出看得到的雛形，不求完整）：一個 iOS widget，也就是 iPhone 主畫面上不用開 App 就能看資訊的小方塊。
  • 01:36 widget 需求：顯示 DOT 的 avatar、名字，以及它目前正在做什麼的簡短狀態
    ↳ 需求講得很具體：小方塊要顯示 DOT 的頭像、名字，再加一行簡短狀態，讓你瞄一眼主畫面就知道它現在在忙什麼。
  • 01:36 Flossie 會開一個 Codex thread 開始建置這個 widget
    ↳ Codex 是 OpenAI 寫程式用的 AI 工具，Codex thread 就是在裡面開一個工作對話串。Flossie 接到任務後，是自己開這一串去動手做 widget。
  • 01:36 同時請 Flossie 查 Slack，看有沒有其他人在做這個 widget，確保和對的人協作
    ↳ Slack 是很多公司在用的工作聊天軟體。Alex 同時請 Flossie 去 Slack 查查看，公司裡是不是已經有人在做同樣的東西，才能找對人合作、不做白工。
  • 01:36 Flossie 回報 Brian Somerset 和 Gavin Nelson 是該同步的人，他們已經在推進這個 widget
    ↳ Flossie 查完回報：同事 Brian Somerset 和 Gavin Nelson 已經在做這個 widget，Alex 應該先跟他們兩位對齊進度。
  • 01:36 Alex 請 Flossie 把他拉進和兩人的 Slack thread，並在原型完成後傳截圖讓他給意見
    ↳ Alex 接著交代兩件事：把他加進跟這兩人的 Slack 討論串；雛形做好後傳截圖給他，讓他可以給意見。
  • 02:06 Flossie 表示會草擬一則標記兩人的 Slack 回覆，交給 Alex 核准後再送出
    ↳ 關鍵在這裡：Flossie 不會直接用 Alex 的名義發訊息，而是先寫一則標記兩人的回覆草稿，等 Alex 核准才送出。對外發言前，會先讓你過目。
  • 02:06 Alex 讓 Flossie 繼續工作，打算回家坐到電腦前再查看最新進度
    ↳ 交代完，Alex 就放手讓 Flossie 繼續做，自己先離開，打算回家坐到電腦前再看進度。這就是「交出去、晚點再驗收」的用法。
  • 02:06 如果你正在用手機看這支影片，可以切到 ChatGPT app 設定你的 DOT
    ↳ 影片最後提醒：如果你現在就是用手機在看，可以直接切到 ChatGPT App，點「Meet DOT」開始設定。
📘 術語
DOT（DOT）：always on 的 proactive agent，能幫你分擔事情
proactive agent（主動式代理）：字幕用來描述 DOT：always on，主動幫你處理事情
thread（對話串）：點 Meet DOT 後會建立一個和 DOT 對話的 thread
context（脈絡資訊）：連接 calendar 和 email 能給 DOT 更多 context，它就能分擔更多事
avatar（頭像／形象）：可以為 DOT 設定的外觀，也能自訂顏色與配件
Codex Pet（Codex Pet）：設定 DOT 外觀時，除了 avatar 之外可選的另一個選項
prototype（原型／製作原型）：示範中請 DOT 快速做出 iOS widget 的雛形
widget（小工具）：示範中要放在 iOS 主畫面上，顯示 DOT 頭像、名字和工作狀態
Codex thread（Codex thread）：Flossie 開一個 Codex thread 來建置 widget
Slack（Slack）：示範中 DOT 在 Slack 查誰在做 widget，並草擬回覆給使用者核准
