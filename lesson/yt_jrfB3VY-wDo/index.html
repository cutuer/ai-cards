🧑‍🏫 這支影片示範 Claude Co-work 的新功能 Skill Record。Claude Co-work 是影片裡用來示範的 Claude 產品，它能看你的螢幕，也能幫你操作網頁。有了 Skill Record，你把一件事做一次給 Claude 看，它就會記起來，下次換它做。如果你每週都在重複同樣的電腦瑣事，這支影片教你怎麼把這種事交出去。

  • 00:02 Lydia 舉例：跟客戶喝完咖啡要報帳，下週、下下週也都得報。她希望只要做一次，之後就不用再想
    ↳ expense report（報帳）就是把花費連同收據交給公司申請費用。這件事不難，但每週都要做一次。Lydia 想要的是教一次就好，以後不用再記步驟，也不用再花腦筋。
  • 00:02 介紹 Claude Co-work 的新功能「Skill Record」：示範一次任務給 Claude 看，它會自動把流程轉成 skill，之後可以幫你執行
    ↳ Skill 是 Claude 能替你跑的一整套固定流程。有了 Skill Record，你不用自己寫步驟，直接做一遍給 Claude 看，它會自己整理成 skill，以後照著做。
  • 00:32 步驟一：在 Claude Co-work 打開「+」選單，點「Record Skill」
    ↳ 開始的方法很簡單：在 Claude Co-work 打開「+」選單，點 Record Skill，也就是開始錄製的選項，Claude 就準備好看你示範了。
  • 00:32 步驟二：Claude 會先問你是否同意錄製螢幕。同意後，Claude 就開始錄製螢幕
    ↳ Claude 要看你的螢幕才學得會，所以會先問你同不同意錄影。你按同意之後，它才會開始錄，不會自己偷偷開始。
  • 00:32 步驟三：照平常的方式報帳，包括上傳收據、填標題、描述和金額等欄位
    ↳ 這時你不用刻意配合，就用平常的方式報帳：上傳收據，填標題、描述、金額。Claude 會在旁邊看你每一步怎麼做。
  • 00:32 錄製過程中可以直接跟 Claude 說話來補充情境，例如「這筆一律歸到餐飲預算（food budget）」
    ↳ 有些規則光看畫面看不出來，例如「這類花費一律歸到餐飲預算」。錄的時候直接講給 Claude 聽，它會把這條規則一起記下來。
  • 01:02 除了點擊和螢幕截圖，口頭補充讓 Claude 掌握更多情境，因此知道需要哪些工具、該建立什麼 skill
    ↳ 畫面只看得到你點了哪裡，看不出你為什麼這樣做。你口頭補充背景，Claude 才知道要用哪些工具、這個 skill 該怎麼設計。
  • 01:02 完成後，整個流程會存成一個名為「submit expenses from receipt」的 skill
    ↳ 錄完之後，你示範的整套操作步驟（workflow）會存成一個叫「submit expenses from receipt」（依收據報帳）的 skill，之後隨時都能叫出來用。
  • 01:02 下次有收據時，只要交給 Claude 並執行這個 skill
    ↳ 下次再有收據，不用重新示範。把收據交給 Claude，請它跑這個 skill 就好。
  • 01:02 執行時，Claude 會讀出收據上的金額、商家、日期等資訊，再自己到報帳網站填完所有欄位，不需要你插手
    ↳ Claude 會自己讀收據，抓出金額、商家、日期，再到報帳網站把每個欄位填好。整個過程你不用動手。
  • 01:02 Claude 在跑 skill 的時候，你可以去做別的工作
    ↳ 它在跑的時候不用你盯著，你可以回信、開會或做別的事，等它做完就好。

    ↳ 影片最後鼓勵大家今天就打開 Claude Co-work，試著錄一個自己的 skill。
