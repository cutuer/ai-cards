🧑‍🏫 這支是 OpenAI 自家業務團隊的實際示範，展示怎麼用 ChatGPT agent（能自己連續完成多個步驟的 AI 助手）處理一筆生意：從發現機會、查客戶、寫開發信、準備會議，到會後追蹤。看完你會知道 AI 能在工作流程的哪幾個環節幫忙，哪些地方仍要由人決定。

  • 00:01 OpenAI 的業務重點：重新設計營收工作流程（revenue workflows），讓 agent 分擔更多工作，業務人員就能專心推動成交
    ↳ revenue workflows 指跟營收有關的整套工作流程，從找客戶到成交都算在內。OpenAI 想重新設計這些流程，把雜事交給 agent，讓業務專心談成生意。
  • 00:01 ChatGPT agent 根據某家公司最新財報的更新內容，在講者負責的客戶帳戶中偵測到一個訊號（signal）
    ↳ signal 是值得業務出手的線索。agent 讀了客戶公司最新財報的更新內容，發現可能跟生意有關的變化，就主動標出來提醒業務。
  • 00:01 agent 會附上財報電話會議（earnings call）的連結，想深入研究的話可以點進去看
    ↳ earnings call 是上市公司公布財報後，由高層說明營運成果、回答分析師提問的電話會議。agent 會附上連結，業務想查證或深入了解時點進去就好，不用自己找。
  • 00:01 ChatGPT 會產生一份 account report，把這些資訊跟後續建議行動整合在一起
    ↳ account report 是針對單一客戶公司的整理報告。它把剛找到的訊號跟「下一步該做什麼」放在同一份文件裡，業務不用自己東拼西湊。
  • 00:31 報告彙整這家公司的關鍵資訊，標出業務人員需要注意的重點
    ↳ 報告不會把資料一股腦丟給你。它會先挑出這家公司最要緊的資訊，再標明哪些地方業務要特別留意，省下自己過濾的時間。
  • 00:31 報告會直接從原始來源引用客戶實際說過的話，幫助推進銷售流程
    ↳ 報告會直接引用客戶在原始資料裡講過的話。拿對方自己說過的話去溝通，比轉述更有說服力，也方便回頭查出處。
  • 00:31 產生 stakeholder map，附上人物檔案，幫助了解買方、界定採購委員會，並知道要說服哪些人才能成交
    ↳ stakeholder map 是跟這筆生意有關的人物關係圖，每個人都附背景資料。企業採購常由一群人共同決定，稱為採購委員會（purchasing committee）。這張圖能幫你看清要說服哪些人。
  • 00:31 最後會產生一封對外 email，團隊可以寄給最重要的 stakeholder；影片中在 Gmail 打開這封信檢視
    ↳ 最後 agent 會寫好一封對外 email，收件人是最關鍵的那位 stakeholder（跟這筆生意有利害關係的人）。影片中是先在 Gmail 打開這封信檢查內容。
  • 01:01 下一步是潛在客戶預約會議：因為 ChatGPT 直接連接工作用的行事曆，一有預約就開始準備業務需要的資料
    ↳ 客戶一預約會議，因為 ChatGPT 直接連著工作用的行事曆，它看到新行程就會自動開始準備資料，不必等業務自己想起來才動手。
  • 01:01 依照「first call template」（首次通話範本）產生一份完成度很高的簡報
    ↳ first call template 是團隊事先定好的「第一次通話」簡報格式。agent 照著格式做出一份接近完成的簡報，業務只要稍微修改就能用。
  • 01:01 簡報會納入財報訊號的關鍵內容，轉成跟這場會議相關、可以直接行動的內容
    ↳ 簡報不是只放一般的公司介紹。它會把先前從財報找到的訊號，轉成這場會議能直接拿來討論、推進生意的內容。
  • 01:01 會議結束後，ChatGPT agent 會自動找到通話逐字稿，產生對話概覽
    ↳ 會議一結束，agent 會自己去找 call transcript（把通話內容轉成文字的逐字稿），再整理成對話概覽，方便快速回顧這次談了什麼。
  • 01:01 agent 會更新業務人員在 CRM 裡的紀錄，並建議 follow-up email 的內容
    ↳ CRM 是公司用來記錄客戶資料和往來紀錄的系統。agent 會幫業務把這次會議的內容更新進去，並擬好 follow-up（會後追蹤）email 的內容。
  • 01:31 agent 還會建議團隊接下來該採取哪些步驟
    ↳ 除了寫信，agent 也會建議團隊接下來要做哪些事，避免這筆生意因為沒人跟進就停在那裡。
  • 01:31 總結：ChatGPT agents 串起從 lead detection 到 follow-up 管理的每一步，讓業務有更多時間經營關係、推進商機
    ↳ 從 lead detection（找出潛在商機）到會後追蹤，每一步都由 agent 串起來。業務省下整理資料的時間，就能拿去經營客戶關係、推進成交。
📘 術語
revenue workflows（營收工作流程）：OpenAI 要重新設計的流程，讓 agent 分擔更多工作，業務專心推動成交
signal（訊號）：agent 根據客戶公司最新財報的更新內容，在客戶帳戶中偵測到的資訊
earnings call（財報電話會議）：字幕沒有解釋，只提到 agent 會附上它的連結，方便深入研究
account report（客戶報告）：ChatGPT 產生的報告，整合公司關鍵資訊、客戶原話和建議行動
stakeholder map（利害關係人地圖）：附人物檔案，幫助了解買方、界定採購委員會、知道要說服誰
purchasing committee（採購委員會）：字幕沒有解釋，只提到 stakeholder map 可以幫忙界定它
first call template（首次通話範本）：產生會議簡報時依據的範本
call transcript（通話逐字稿）：會議結束後 agent 自動搜尋，用來產生對話概覽
CRM（客戶關係管理系統）：字幕沒有解釋，只提到 agent 會更新業務在 CRM 裡的紀錄
lead detection（潛在商機偵測）：字幕沒有解釋，是 agent 串起的流程中的第一步
follow-up（後續追蹤）：會議結束後的追蹤；agent 會建議 follow-up email 的內容

看答案
答案：A。[01:01] 字幕提到：After the meeting, the ChatGPT agent automatically searches for the call transcript and generates an overview of the conversation.
