🧑‍🏫 這支是 OpenAI 的入門教學，示範怎麼用 ChatGPT 的 Work 模式同時讀 Gmail 和 Slack，把資料整理好並擬出回信。如果你常為了回一封信在好幾個 app 之間翻來翻去，這支教你怎麼把這件事交給 ChatGPT。

  • 00:03 多數被拖延的工作並不複雜，只是資訊很分散；ChatGPT Work 能幫忙把它們整合起來。
    ↳ 很多事一直拖，不是因為難，而是資料散在好幾個地方，光找就累。ChatGPT Work（ChatGPT 裡能幫你把事情做完的模式）就是幫你把這些資料收齊。
  • 00:03 Chat 與 Work 的差別：Chat 適合需要深思熟慮的回答；Work 更進一步，能從已在用的 app 帶入資訊，幫你真正完成任務。
    ↳ Chat（一般聊天模式）是你問、它答，適合需要想清楚再回答的問題。Work 多做一步，會到你平常用的 app 拿資料，把事情做完，而不只是給建議。
  • 00:03 示範情境：要確認下週的團隊晚餐。餐廳的 email 在 Gmail 裡，最新人數與飲食限制則在 Slack。
    ↳ 影片情境是確認下週的團隊聚餐。餐廳寄來的信在 Gmail（Google 的電子信箱），最新人數和飲食限制在 Slack（很多公司用的團隊聊天軟體）。
  • 00:33 資訊分散在收件匣和 Slack，不想為了回一封信兩邊翻找，這正是 Work 派上用場的地方。
    ↳ 平常你得先開信箱看一遍，再去 Slack 翻聊天紀錄，兩邊對照才寫得出回信。Work 就是要省掉這種來回切換、到處翻找的工夫。
  • 00:33 第一步是下載 ChatGPT desktop app。Work mode 也能在網頁版 chatgpt.com 使用，但 app 比較方便和其他已開啟的東西一起操作。
    ↳ 先安裝 ChatGPT 的 desktop app（裝在電腦上的版本）。網頁版 chatgpt.com 也能用 Work，但電腦版和你其他開著的視窗一起操作比較順手。
  • 00:33 下載方式：開啟下載頁面，選擇適合自己電腦的版本，再依安裝步驟完成。
    ↳ 到下載頁挑符合你電腦的版本，例如 Windows 或 Mac，再照安裝畫面一步步完成，跟裝一般軟體一樣。
  • 01:03 開啟 app 後，登入想使用的 ChatGPT 帳號，就能在 Chat 和 Work 之間切換。
    ↳ 打開 app，登入你要用的 ChatGPT 帳號，就能在 Chat 和 Work 兩種模式之間切換。
  • 01:03 Chat 用來問快速的問題。這個任務選 Work mode，因為要讓 ChatGPT 到 Gmail 和 Slack 找資訊，再用來擬 email。
    ↳ 判斷方式很簡單：只是問個問題就用 Chat；要它去 Gmail、Slack 找資料再幫你寫信，也就是要它跑腿做事，就選 Work mode。
  • 01:03 ChatGPT 要找 email 就需要 Gmail 的存取權，這時就要用 plugins。
    ↳ ChatGPT 本來看不到你的信箱。要它幫你找信，得先讓它取得 Gmail 的存取權，這一步要靠 plugins 來完成。
  • 01:35 Plugins 讓 ChatGPT 連接你已在用的 app，例如 Gmail、Slack、Calendar、Google Drive。
    ↳ Plugins（外掛）是讓 ChatGPT 連上其他 app 的功能。接上 Gmail、Slack、Calendar（行事曆）、Google Drive（雲端硬碟）之後，它才讀得到裡面的內容。
  • 01:35 安裝步驟：在 sidebar 點 Plugins，搜尋 Gmail，按 Install，登入並檢視權限後再連結帳號。這個設定只需做一次。

    ↳ 用同樣的方式接上 Slack，ChatGPT 就能把餐廳的信和團隊的最新狀況放在一起看，不用你自己拼湊。
  • 01:35 開一個新的 chat，並切換到 Work mode。
    ↳ 準備好之後開一個新對話，記得切到 Work mode，它才會去各個 app 找資料。
  • 02:05 說明需求：找到那封 email、到 Slack 查最新團隊資訊、擬一封回信。資訊可以讓 ChatGPT 去收集，但寄出前仍要自己審閱草稿。

  • 02:05 不需要寫出完美的 prompt，直接跟 ChatGPT 說你要什麼就好。
    ↳ prompt 就是你打給 ChatGPT 的指令。不用琢磨措辭或套公式，像交代同事一樣把要什麼講清楚就行。

    ↳ 開始執行後，它會自己去 Gmail 找出餐廳的信，再到 Slack 查最新人數和飲食限制，不用你一個個點開。

    ↳ 途中如果缺資料或缺權限，它會停下來問你。沒問題的話，你可以先去忙別的，等它跑完再回來看結果。

    ↳ 真正省事的不只是找到資料，而是它把兩個 app 的細節兜在一起，直接寫成一封準備好的回信，省下你整理和打字的時間。
  • 02:37 審閱草稿後做了一個小修改：詢問若有空位，能否安排安靜的桌子。
    ↳ 看草稿時覺得可以再補一句，就加上「如果還有位子，能不能安排安靜一點的桌子」。初稿由它寫，微調由你來。

    ↳ approve 是「核准」的意思。你確認草稿沒問題並按下去，信才會寄出；在你按之前，它不會自己送出任何東西。

    ↳ Wake Pet 是一個提醒功能。Work 做完事或需要你回應時，靠它就能輕鬆注意到，影片也說它的樣子很可愛。

    ↳ 開啟方式：打開選單，搜尋 Wake Pet 並開啟。之後就不必一直盯著對話等它跑完，好了會通知你。

    ↳ 真正的好處是信件、訊息、檔案和行事曆可以集中在同一個地方處理，不用在好幾個 app 之間跳來跳去。
📘 術語
ChatGPT Work / Work mode（ChatGPT 工作模式）：能從已在用的 app 帶入資訊，幫你真正完成任務
Chat（聊天模式）：需要深思熟慮的回答或問快速問題時使用
Plugins（外掛）：讓 ChatGPT 連接已在用的 app，例如 Gmail、Slack、Calendar、Google Drive
desktop app（桌面應用程式）：ChatGPT 的電腦版 app，方便和其他已開啟的東西一起操作
sidebar（側邊欄）：在這裡點 Plugins 來搜尋並安裝外掛
permissions（權限）：連結帳號前要先檢視；執行任務時若需要權限，ChatGPT 會詢問
prompt（提示詞）：不需要完美的 prompt，直接說你要什麼就好
approve（核准）：審閱草稿滿意後核准寄出；你同意前不會送出任何東西
Wake Pet（喚醒寵物）：Work 完成或需要注意時提醒你，完成時會收到通知
headcount（人數）：範例中放在 Slack 上的團隊晚餐最新人數
dietary restrictions（飲食限制）：範例中和人數一起放在 Slack 上的團隊資訊
