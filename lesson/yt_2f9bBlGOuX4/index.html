🧑‍🏫 這支影片記錄 OpenAI 辦的「Haha Hacks」活動：參加者用 AI 寫程式工具 Codex，比賽誰做出的東西最蠢、最荒謬。它值得看的地方是讓你看到，不會寫太多程式的人，只要把點子講清楚，也能很快做出能動的小作品。

  • 00:04 Haha Hacks 是一場好玩的 hack 活動，主題是做出蠢、荒謬、離譜的東西
    ↳ hack 在這裡指「動手快速做出一個小作品」的活動。這場的目標不是做實用的產品，而是比誰做得最蠢、最好笑，重點是好玩。
  • 00:04 主辦方提供參加者使用 Codex Pro plan，希望大家做出最異想天開、混亂、好玩又調皮的專案
    ↳ Codex 是 OpenAI 的 AI 寫程式工具，你用文字描述需求，它幫你寫出程式。Codex Pro plan 是 Codex 的付費方案，主辦方提供給參加者用，讓大家放手做最瘋、最調皮的點子。
  • 00:04 作品一「進我家請脫鞋」：偵測到門口有人；準備好脫鞋時會亮綠燈，表示有人準備好要進屋了
    ↳ 這個作品專門盯著門口：偵測到有人來，等對方準備好脫鞋就亮綠燈，表示可以進屋了。等於把「進門請脫鞋」這條家規交給機器來管。
  • 00:04 作品二：把無聊的信箱改造成讓人真的想打開、還會被逗笑的有趣信箱
    ↳ 一般信箱打開就是帳單跟廣告，很無聊。這組把信箱改造成會逗人笑的樣子，讓人開信箱變成一件期待的事。
  • 00:34 作品三：開發者左眼視力弱、看不清遠處文字，戴上有小孔的眼鏡後就能看清楚遠方文字；目前只做好左眼
    ↳ 開發者左眼看不清遠處的字，就做了一副有小孔的眼鏡，戴上之後遠方的字變清楚了。不過目前只做好左眼，右眼還沒做。
  • 00:34 作品四：偵測說謊的 app，抓到你說謊就往你臉上潑水，模擬冒汗
    ↳ 這個 app 會判斷你有沒有說謊，一抓到就往你臉上潑水，假裝你心虛到冒汗。偵測是認真做的，懲罰方式則是純粹搞笑。
  • 00:34 參加者分享：可以快速打開 Codex，把整個專案描述給它，它就做出了很棒的 app
    ↳ 參加者說，他打開 Codex，把整個專案想做什麼一次講清楚，它就直接做出一個很不錯的 app。重點是先講清楚「想要什麼」，不是自己一行一行寫程式。
  • 01:06 活動最後大家互相鼓掌，感謝所有人做出這些很棒的作品
    ↳ 活動最後大家互相拍手，感謝彼此做出這些作品。這場比的不是誰最厲害，而是大家一起把怪點子真的做出來。
