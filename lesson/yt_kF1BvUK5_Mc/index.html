🧑‍🏫 這支是 Claude 官方影片，介紹 Claude 的一個介面改變：原本分開的「聊天」和「協作（Cowork，讓 Claude 動手幫你完成工作的地方）」合成同一個對話了。常用 Claude 的人看完最有感的差別是：以後不用先想「這件事要去哪裡開」，打開就能直接交代。

  • 00:01 開場點出常見的猶豫：打開筆電想交代 Claude 一件事時，會先想「該從哪裡開始？」
    ↳ 很多人打開電腦要請 Claude 做事，第一個念頭常常不是事情本身，而是「這要開聊天還是開協作？」影片就是從這個小卡關開始講。
  • 00:01 講者 Jen Joy 負責 Claude apps 的設計
    ↳ 講者 Jen Joy 負責 Claude apps 的設計。Claude apps 就是你平常用的 Claude 網頁版、電腦版和手機版，她管的是這些介面長什麼樣、怎麼操作。
  • 00:01 從今天起，不用再在聊天（chatting）和協作（collaborating）之間二選一，兩者合成同一個對話
    ↳ 以前聊天（chatting，一問一答）和協作（collaborating，讓 Claude 動手做出成果）是兩個入口。現在合成同一個對話，不用再先選一邊。
  • 00:01 Claude 會自己帶進完成任務需要的所有東西
    ↳ 你只要說想要什麼，Claude 會自己把完成這件事需要的東西找齊，不用你先幫它準備好。
  • 00:01 團隊是在協作（Collaboration）裡發展出 Claude 處理大規模、多步驟任務的方法
    ↳ 讓 Claude 做 multi-step tasks（要好幾個步驟才做得完的大工作，例如先整理資料、再做成報告）的方法，是團隊先在協作（Collaboration）那邊發展出來的。
  • 00:01 Claude 越來越會判斷任務需要什麼，所以再把它放在另一個獨立的地方已經不合理
    ↳ Claude 越來越能自己看出一件事需要什麼，所以把「動手做事」的功能放在另一個獨立的地方已經不合理，乾脆合在一起。
  • 00:31 開始工作前，不用再先想這個任務屬於哪個區塊
    ↳ 也就是說，你不用再先分類「這算聊天還是算任務」，想到什麼直接講就好。
  • 00:31 現在各處都更容易用到協作功能
    ↳ 以前要特地切過去才用得到的協作功能，現在在更多地方都能直接用。
  • 00:31 原本的對話（chats）、任務（tasks）、skills 和 memory 都會保留在原處
    ↳ 舊東西不會不見：以前的對話、任務，還有 skills 和 memory 都會留在原處。skills 和 memory 在做什麼，影片沒有多說明。
  • 00:31 Claude 會配合你的工作流程：可以問它問題，也可以交代比較難的任務
    ↳ 你可以隨口問問題，也可以丟比較難的工作給它。是 Claude 配合你的做事方式，不是你去遷就它的介面。
  • 00:31 範例：把上週的數字給 Claude，請它做簡報或其他視覺化內容，它會直接在對話裡準備好
    ↳ 例如把上週的業績數字丟給它，請它做成簡報或圖表，它會直接在同一個對話裡做好，不用換地方。
  • 00:31 工作成果仍然屬於你，任何部分都可以照你的意思儲存、編輯或轉交（route）
    ↳ 做出來的東西還是你的。哪一部分要存、要改、要轉交（route，交給別人或別的地方接手），都由你決定。
  • 01:01 這只是第一步：模型進步的同時，和模型一起工作的體驗也會跟著改善
    ↳ 團隊說這只是第一步：模型本身會越來越強，跟它一起工作的方式也會跟著改得更順。
  • 01:01 團隊會和使用者一起開發，並邀請大家試用、分享使用感想
    ↳ 他們會跟使用者一起把功能做下去，邀請大家實際用用看，再告訴他們好不好用。
