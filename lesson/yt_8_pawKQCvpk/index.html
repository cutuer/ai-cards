🧑‍🏫 這支影片示範把 Claude 接上 Higgsfield（集合多種圖片、影片 AI 模型的生成平台），用聊天的方式做出動態字卡、logo 動畫、介面展示和產品廣告。重點是一個避開「AI 影片會把字弄壞」的做法：先用圖片模型把畫面做好，再讓影片模型只負責動起來。不會專業動畫軟體的人也能照著做。

  • 00:01 傳統做 motion graphics 要在 After Effects 花好幾小時設定圖層、keyframes 和微調；用 Claude Opus 5 可以直接從對話做出成果
    ↳ motion graphics（動態圖像）是讓文字、圖形動起來的影片。以前要開 After Effects（專業動畫軟體），設好 keyframes（標記某個時間點物件狀態的點）再慢慢調。現在跟 Claude 對話就能做出來。
  • 00:01 所有影片模型只要一讓文字動起來就會把字弄壞，所以要先學會一個繞過這個問題的技巧
    ↳ 影片模型是把文字或圖片變成影片的 AI。它們一碰到「字要動」，字就容易歪掉或變成亂碼。所以整支影片的關鍵，是一套避開這個弱點的做法。
  • 00:01 第一步：從說明欄連結開啟 Higgsfield，進入 MCP 頁面，選 Claude 分頁並把 MCP 開關打開
    ↳ MCP 是讓 Claude 呼叫外部工具的連接方式。在 Higgsfield 的 MCP 頁面選 Claude、把開關打開，等於先允許兩邊對接。
  • 00:31 複製 connector URL，到 Claude 的 customize → connectors 新增一個，命名 Higgsfield，貼上 URL，再連線並登入
    ↳ connector 是 Claude 裡接外部服務的連接設定。把 Higgsfield 給的網址貼進 Claude 設定，新增一個 connector，再登入帳號，兩邊就接通了。

    ↳ 接好後，在 Claude 的任何對話裡都能叫 Higgsfield 生圖、生影片。花的是你 Higgsfield 帳號的 credits（點數），用越多扣越多，記得先看方案夠不夠。
  • 00:31 要確認選的是 Opus 5，因為所有的思考都由它負責
    ↳ 實際生圖的是 Higgsfield 的模型，但想畫面、寫指令、排流程都是 Claude 在做。所以要選 Opus 5 來當這個「導演」。
  • 00:31 先跟 Claude 說明要做四個複雜度層級的 motion graphics，從最基本到最進階
    ↳ 作者一開始就跟 Claude 說好整體目標：做四支由淺到深的範例。Claude 知道全貌，才能幫你把每一步排好。
  • 01:01 Claude 給出處理文字的流程：先用圖片模型生成靜態圖，再把靜態圖餵給影片模型，依已核可的畫面鎖定視覺
    ↳ 解法是分工。圖片模型擅長把字畫清楚，就先用它產 stills（靜態畫面）。你確認滿意後，再交給影片模型只負責動，畫面的樣子就被固定住了。
  • 01:01 暖身範例是 stat card：一個大數字加底下一行字。Claude 給四個方向，各自已定好文字、顏色、氛圍；作者選 2.4 million 和 48 times

  • 01:32 GPT Image 2 解析度有 1K/2K/4K，品質有 low/medium/high，預設 low；因為畫面文字要給人讀，選 4K + high
    ↳ 解析度越高，畫面越細；品質越高，細節越多。預設是最低品質，但字要給人看清楚，所以作者直接選 4K 和 high，避免字糊掉。
  • 01:32 影片模型選項：SeaDance、Cling、Vio、Gemini Omni Flash、Cinema Studio（依字幕拼法）；都做得到，差在想要的動態；作者選 Sea Dance
    ↳ 這幾款影片模型都做得出來，差別在動起來的感覺。挑一款符合你想要的動態風格就好。

    ↳ 這種幾秒鐘的小字卡，不需要長片也不需要 4K，三個版本都夠用。作者選 2.5 只因為它最新，不是非它不可。
  • 02:02 比例選 16:9，另有 9:16、正方形、4:3；圖片和影片的比例必須一致，否則會被裁切或兩側出現黑邊
    ↳ 比例就是畫面的長寬比，16:9 是橫式、9:16 是手機直式。圖和影片的比例要一樣，不然影片會被切掉一塊，或兩側補上黑邊。
  • 02:33 比例要設成獨立設定、不寫進 prompt，因為 prompt 描述的比例和設定不同時，模型會混亂
    ↳ prompt 就是給 AI 的文字指令。比例在介面上設定就好，不要再寫進 prompt。兩邊講的不一致時，模型會不知道該聽誰的。
  • 02:33 到這裡只剩影片長度和是否有聲音沒定，這兩項每支都不同
    ↳ 其他設定都能一直沿用。只有片長和要不要聲音，要看每支影片的內容再決定。
  • 02:33 每個 prompt 開頭都一樣：先列出必須完全不變的東西（顏色、光線、顆粒），最後才講唯一要改變的那件事
    ↳ 每段 prompt 先列出「不能變」的顏色、光線、grain（畫面的顆粒質感），最後才說這次要改什麼。先把規矩講清楚，再交代任務。
  • 02:33 這樣能防止背景在兩張圖之間偏移；背景一偏移，動起來就會變成閃爍
    ↳ 兩張圖的背景只要色調或光線差一點，影片模型在兩張之間過渡時，背景就會忽明忽暗，看起來像在閃。
  • 03:03 第一張卡先做空背景：平的暖紙色、上面什麼都沒有
    ↳ 第一張刻意只做一張乾淨的暖色紙背景，上面什麼都不放，當作之後所有畫面的底。

    ↳ 作者把影片裡用到的 prompt 和模板整理成免費資料包，放在影片說明欄，可以直接拿來改。

    ↳ 背景是地基，後面每張圖都照它的顏色和光線走。地基先做對，疊上去的東西才不會走樣。
  • 03:03 再把同一張背景當 reference 放回去，把文字加上去，完成卡片
    ↳ reference 就是丟給模型的參考圖。把剛做好的空背景丟回去，請模型在上面加字，背景就能保持一模一樣。
  • 03:03 文字非常銳利，原因是它是用圖片做的，不是用影片模型做的
    ↳ 字是圖片模型畫的，影片模型只負責讓它出現，不會重畫字，所以字不會壞掉。

    ↳ 把空背景當開頭、完成的卡片當結尾，請影片模型補出中間的過程：元素淡入，到位後停住。長度 5 秒，不加聲音。

  • 04:35 第二張是單獨的 R，正中央、約畫面一半高；完整單字直接以這張為基礎生成，字形會延續，不用再重新描述
    ↳ 第二張只放一個 R，在畫面正中央。完整的單字直接拿這張 R 當參考來做，字型會自然延續，不用再描述一次。

📘 術語
motion graphics（動態圖像）：字幕未正式定義；傳統做法要在 After Effects 設定圖層、keyframes
After Effects（After Effects（動態設計軟體））：字幕指的「傳統做法」工具，要花數小時設定圖層、keyframes、微調
keyframes（關鍵影格）：字幕未解釋；作為傳統 After Effects 流程中要設定的項目被提及
MCP（MCP）：字幕未解釋；在 Higgsfield 的 MCP 頁面取得 connector URL，用來把 Higgsfield 接到 Claude
connector（連接器）：在 Claude 的 customize → connectors 新增，貼上 URL 後連線登入，對話就能用 Higgsfield 模型
credits（點數）：生成時消耗你自己的 Higgsfield credits，要確認方案涵蓋用量
stills（靜態圖）：先用圖片模型生成的畫面，再餵給影片模型以鎖定視覺
stat card（數據卡）：最簡單的 motion graphic：一個大數字，底下一行字
reference（參考圖）：把背景或前一張圖放回去當參考，讓新圖沿用顏色、光線、字形
grain（顆粒）：prompt 開頭要求保持不變的項目之一；背景若有顆粒，動畫時會在字底下移動
overshoot（過衝）：48 times 卡的動畫方式：彈入時稍微衝過頭再定住
start frame（起始影格）：動畫的起始畫面；若放格狀 storyboard，模型會直接動畫那張格子圖
product sheet（產品設定圖）：告訴模型產品長什麼樣的參考圖
storyboard（分鏡圖）：決定鏡頭出現順序的參考圖；作者規定不要放數字，以免數字跑進影片
hyper motion（hyper motion（極速動態風格））：字幕未解釋；作者要求產品廣告採用的風格，搭配快速鏡頭與 3D render
3D render（3D 算圖）：字幕未解釋；作者對產品廣告提出的要求之一
