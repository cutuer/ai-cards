🧑‍🏫 這段介紹 ClayPencil 這個外掛怎麼用：它能把在 Blender 裡畫的 2D 線條，直接變成有厚度、有體積的 3D 造型。講者示範了兩種工作方式，也說明目前還不成熟的地方和下載位置。如果你會畫圖但覺得 3D 建模門檻太高，這個方向很值得關注。

  • 11:28 試了幾次後找到合適的開發者：來自菲律賓的 Alfonso Martinez，他在 Blender chat 上叫 quackaroni。講者說有對的開發者，事情會容易很多
    ↳ 開發者 Alfonso Martinez 來自菲律賓，在 Blender chat 上叫 quackaroni，是試了幾次才找到的人選。講者的意思是：人找對了，專案會好推很多。
  • 11:28 目前的實作只是一個 add-on
    ↳ add-on 就是外掛，像手機另外裝 App 一樣，把額外功能加進 Blender。ClayPencil 現在只是外掛，還不是 Blender 內建的功能。
  • 11:59 如果大家覺得有意思，也許未來會原生整合進 Blender，但還不確定。這個專案結束後，要先評估它是否有用
    ↳ 它未來會不會變成內建功能還沒決定。要等這個專案結束，先看它到底實不實用、大家有沒有興趣，再做判斷。
  • 11:59 講者認為做東西就是無限慾望和有限資源之間的拉扯。他自己、Blender、Pixar、Marvel 都有同樣的問題，只是規模不同
    ↳ 想做的事永遠比做得到的多，這是所有做東西的人都會遇到的處境。個人創作者和 Pixar、Marvel 面對的是同一個問題，差別只在規模。
  • 12:34 因為資源有限，必須決定優先順序
    ↳ 資源有限，就只能先做最重要的，其他往後排。這也說明了為什麼現在功能還不完整。
  • 12:34 目前可以透過 materials 或 layers 使用。講者偏好 materials，因為比較直接，例如一個眼睛的材質
    ↳ 使用入口有兩種：material（材質，決定東西長什麼樣子的設定）或 layer（圖層）。講者偏好材質，因為一個部位配一個材質，例如「眼睛」，很直接好管理。
  • 13:05 示範：在材質裡新增 constructor 選項 ClayPencil，然後設定參數，例如 radius，也可以切換不同的 type
    ↳ constructor 是材質裡新增的選項，用來決定線條要被變成哪種立體形狀。示範時選了 ClayPencil，再調整 radius（半徑，也就是粗細），也可以切換不同 type。
  • 13:39 示範：在另一個材質加上 fill 選項並關掉線條。有很多選項可以做 remesh，講者另有影片說明得更好
    ↳ fill 是把線條圍起來的範圍填成面的選項。示範在另一個材質開啟 fill、關掉線條。remesh（重新整理模型表面）也有很多選項，講者另有影片講得更清楚。
  • 13:39 目前有三種 constructor，未來希望增加更多
    ↳ 目前只有三種 constructor 可以選，之後希望再增加更多種類。
  • 14:15 示範 loft：畫一條線、複製這條線，再加上 loft constructor。這是用來做出車子的主要方式
    ↳ loft 是在線與線之間連出一個面，像在兩根線中間撐起一塊布。示範時畫一條線、複製一份，再加上 loft。片中的車子主要就是用這招做的。
  • 14:45 有不同的 loft、extrude 等，操作很像建模。難的是怎麼把這些組合在一起，但本質上它只是材質或 layer 的一個選項
    ↳ 另外還有 extrude（擠出，把形狀往某個方向拉出厚度）等選項，用起來很像建模。單一功能不難，難在怎麼組合，但說到底它只是材質或圖層上的一個選項。
  • 14:45 講者歸納出兩種工作流程。第一種是 2D drawing workflow，比較直接
    ↳ 講者整理出兩種工作方式。第一種是 2D drawing workflow（2D 繪圖流程），照平常畫 2D 動畫的方式來做，比較直接。
  • 15:15 2D drawing workflow：先有 2D 動畫，再套用這些功能讓它有體積，像餅乾一樣。它不是真正的 3D 體積，但對某些風格已經夠用
    ↳ 先把 2D 動畫畫好，再用這些功能讓它長出厚度，像一片餅乾：有厚度，但不是真正圓滾滾的立體。對某些畫風來說，這樣就夠用了。
  • 15:15 第二種是 modeling workflow，例如車子。這種方式不是在畫，比較像在建模
    ↳ 第二種是 modeling workflow（建模流程）。這種做法不是一筆一筆畫，而是用這些形狀把物體「組」起來，例如那台車。
  • 15:15 making-of 範例：先有形狀，建立 fill，再建立 tube，把兩者結合後用 Remesh 和 Boolean 做出體積
    ↳ 幕後範例是這樣做的：先畫好形狀，一部分做成 fill（面），一部分做成 tube（管狀），合在一起後，再用 Remesh 和 Boolean（布林運算，把形狀相加或相減成一體）做出實心體積。
  • 15:47 可以加入更多形狀讓物體更 3D，例如老婦人的下巴用了很多形狀。用 modeling workflow 也能做出角色
    ↳ 疊上去的形狀越多，物體看起來就越立體。老奶奶的下巴就是用很多形狀拼出來的，可見建模流程不只能做車，也能做角色。
  • 16:28 示範把某個設定放進 custom data attribute，就能在 3D 裡做出這類東西
    ↳ 示範時把某個設定放進 custom data attribute（自訂資料屬性，可以想成附在物件上的額外資料欄位），就能在 3D 裡做出這類效果。字幕沒有細講原理。
  • 17:00 那個範例有 jaw controller 這類 rigging，已經不是 2D 繪製的形狀，基本上是在 3D 建模。講者認為這方式不錯
    ↳ 那個範例還加了 jaw controller（控制下巴開合的控制器）。它屬於 rigging，也就是幫模型裝骨架和控制桿，方便做動畫。做到這一步已經是 3D 建模了，講者覺得也不錯。
  • 17:00 不過在 Grandma 這部片，講者偏好比較直接、接近 2D 動畫的做法
    ↳ 不過做《Grandma》這部片時，講者還是選了比較直接、貼近傳統 2D 動畫的做法。
  • 17:32 兩種流程可以混用。例如 Brian Achat 的殭屍鏡頭大多是繪圖，但地上的殭屍偏 3D 建模
    ↳ 兩種流程不用二選一，可以混著用。例如 Brian Achat 做的殭屍鏡頭，大部分是用畫的，但地上那隻殭屍就比較偏 3D 建模。
  • 17:32 因為在 Blender 裡面，也能和 Blender 其他功能結合，例如標準 rigs 和 effects
    ↳ 因為它就在 Blender 裡面運作，可以直接搭配 Blender 原本的功能，例如標準骨架（rig）和各種特效。
  • 18:07 modeling workflow 不能取代用 sculpt 的標準建模。它的好處是用 Grease Pencil 可以把這些東西做成動畫，或改變形狀
    ↳ 建模流程不是要取代 sculpt（雕刻，像捏黏土一樣細修模型）這類正規建模。它的好處是可以用 Grease Pencil（Blender 裡在 3D 空間畫 2D 線條的工具）讓形狀動起來或變形。
  • 18:38 目前主要問題之一：Remesh 和 Boolean 很慢。原因是 Boolean 運算，加上要做出奶奶皺紋等細節需要大量幾何
    ↳ 目前的大問題之一是 Remesh 和 Boolean 很慢。Boolean 本身運算就重，加上奶奶皺紋這類細節需要大量幾何（很多面），速度就更慢。
  • 18:38 所以 Remesh 和 Boolean 目前只適合算圖時使用，還無法即時操作。只用 extrude 形狀等功能則可以即時運作
    ↳ 所以這兩個功能目前只適合在 render（算圖，也就是最後輸出成片）時開啟，工作中沒辦法即時看。只用 extrude 這類形狀的話，就能即時顯示結果。
  • 19:14 另一個問題是貼圖。貼圖是在 viewport 即時產生的，只有一般的 UV，所以需要用投影或 procedural materials
    ↳ 另一個問題是貼圖。形狀是在 viewport（Blender 的工作預覽畫面）即時產生的，只有基本的 UV（決定圖片怎麼貼上表面的座標），所以得改用投影，或 procedural materials（用規則算出來、不靠圖片的材質）。
  • 19:14 開發五個月後，UX 與 UI 仍有很多改進空間，例如按鈕要放在哪裡最好
    ↳ 開發了五個月，UX（使用體驗）和 UI（操作介面）還有很多地方要改，連按鈕放哪裡最順手都還在想。
  • 20:00 目前可以運作但還沒打磨，也有一些 bug，團隊還有很多功能想實作
    ↳ 簡單說：能用，但還很粗糙，也有 bug，團隊手上還有很多想做的功能。
  • 20:00 現在可以從 Blender lab 下載這個 add-on。要不要用由你決定，因為它是 Blender lab，不是 Blender final
    ↳ 現在就可以從 Blender lab 下載。Blender lab 是實驗性專案，不是正式版 Blender，所以要不要拿來用、能不能接受風險，要自己評估。
  • 20:32 Blender lab 頁面目前資訊不多，但有 release 可下載，昨天又出了一版改進。demos 裡有一些舊檔案
    ↳ Blender lab 頁面上的說明還很少，但有 release（發布版本）可以下載，昨天剛出了改進版。demos 裡有一些舊的範例檔。
  • 20:32 預計接下來幾週會把 Grandma 的所有檔案放上去供測試，因為一切都是公開的
    ↳ 接下來幾週，團隊會把《Grandma》所有的製作檔放上去讓大家測試，因為這個專案本來就是全部公開的。
  • 21:05 3D 流程的步驟很多：design、modeling、rigging、animation、shader、render。講者說這沒問題，但他個人偏好更簡單的流程
    ↳ 傳統 3D 流程步驟很多：設計、建模、綁骨架、動畫、shader（上材質）、算圖。講者不是說這樣不好，只是他個人喜歡更簡單的流程。
  • 21:05 2D 流程基本上是 design、animation、ink and paint，在動畫這一步就包含了很多事情
    ↳ 2D 流程基本上只有設計、動畫、ink and paint（描線上色）三步，很多事情都在「畫動畫」這一步一起完成了。
  • 21:37 ClayPencil 的概念是在 ink and paint 階段使用它，做出 3D 的最終外觀
    ↳ ClayPencil 的定位就是用在 ink and paint 這一步：動畫畫完後，靠它把畫面變成 3D 的最終樣子。
  • 21:37 講者的理念是「Use the pencil」：Grease Pencil、Storypencil、ClayPencil
    ↳ 講者的核心理念是「Use the pencil」，也就是用筆來做事。他列出三個工具：Grease Pencil、Storypencil（同一系列的工具之一），還有 ClayPencil。

    ↳ 講者覺得在 3D 空間裡用 2D 的方式工作很好玩。而且「筆」的形式越來越多，Wacom 繪圖板、VR、能在空中畫的裝置，都比滑鼠直覺。
  • 22:43 總結：用 2D 工作流程創作 3D
    ↳ 一句話總結：用畫 2D 的方式，做出 3D 的作品。
📘 術語
add-on（附加元件）：ClayPencil 目前的實作形式，未來也許會原生整合進 Blender
constructor（建構器）：材質裡的新選項，例如 ClayPencil、fill、loft。目前有三種，未來想增加
loft（放樣）：畫線並複製後套用，是用來做出車子的主要方式
extrude（擠出）：建模類操作之一。只用 extrude 形狀可以即時運作
fill（填充）：加在材質上的選項，可與 tube 結合做出體積
Remesh（重新網格化）：和 Boolean 一起用來做出體積。目前很慢，只適合算圖時使用
Boolean（布林運算）：用來結合形狀。因為是 Boolean 運算又有大量幾何，所以很慢
2D drawing workflow（2D 繪圖工作流程）：從 2D 動畫出發再加上體積，像餅乾，不是真正的 3D 體積
modeling workflow（建模工作流程）：不是用畫的，比較像建模，可以做出車子和角色
custom data attribute（自訂資料屬性）：示範時把設定放進這裡，就能在 3D 裡做出這類東西（字幕未詳細解釋）
jaw controller（下巴控制器）：一種 rigging，表示那個範例已經不是 2D 繪製的形狀
procedural materials（程序化材質）：貼圖只有一般 UV 時，可以用來替代投影的做法
Blender lab（Blender 實驗室）：可以下載 ClayPencil add-on 的地方，不是 Blender final
ink and paint（描線上色）：2D 流程的步驟之一，ClayPencil 就是在這個階段使用
Grease Pencil（Grease Pencil）：用它可以把形狀做成動畫或改變形狀，是「Use the pencil」理念之一
Storypencil（Storypencil）：講者「Use the pencil」理念列舉的工具之一
