🧑‍🏫 這段是 BCON26 的演講開場。講者 Sascha 分享自己用空閒時間，把手繪漫畫風格做進 Blender（一套免費的 3D 軟體）的個人專案，也說明他怎麼讓一個人的製作流程變快。你會拿到四個省時間的原則，還有他把漫畫感拆成形狀、線條、陰影三塊的思考方式。

  • 00:05 演講主題是「在 3D 做 2D 漫畫風格：形狀、線條、陰影」，也會帶到一點點動畫；講者自嘲另一個候選標題是「Grease Pencil Lines on a Deformed Mesh with Geometry Nodes」。
    ↳ 主題是把 2D 漫畫感做進 3D，拆成形狀、線條、陰影三塊。玩笑標題裡的 Grease Pencil 是在 3D 空間裡畫線的工具，Geometry Nodes 是用節點組規則來改造模型的功能。
  • 00:37 講者 Sascha Goedgebure，荷蘭人、住在葡萄牙，是 Omens Studios（位於新加坡與馬來西亞）的 showrunner。
    ↳ Sascha 是荷蘭人，住在葡萄牙，在新加坡與馬來西亞的 Omens Studios 當 showrunner。這個詞一般指影集的總負責人，但他自己笑說也講不太清楚。
  • 01:09 他工作上用不到 Blender，所以會不定期給自己一個大型個人專案來專注使用 Blender；這場演講是以個人身分分享個人專案。
    ↳ 他的正職完全用不到 Blender，所以會自己找一個大專案，逼自己專心用。這場分享是以個人身分談私人作品。
  • 01:09 第一個大型個人專案 Project Fuzzy 圍繞他自創的單一 IP，他在這個專案裡第一次學 Python 寫程式。
    ↳ 第一個大專案 Project Fuzzy 全部圍繞他自創的角色世界（IP，指原創作品和它的版權）。他也是在這個專案裡第一次學 Python 這種程式語言。
  • 01:43 他很後悔沒有早 20 年開始寫程式，建議藝術家能學就學 coding；他寫了許多 operator、工具並包進 add-on，重點是速度、效率與一人快速 pipeline。
    ↳ 他後悔太晚學寫程式，勸藝術家能學就學。他寫了很多 operator（按下就執行的指令），包成 add-on（外掛），目的都是讓一個人的製作流程（pipeline）跑得快。
  • 01:43 Project Fuzzy 結束後，他需要一個有不同藝術與技術挑戰的新專案。
    ↳ Fuzzy 做完後，他想換新題目，找藝術上和技術上都還沒碰過的難關來挑戰自己。
  • 02:17 新專案叫 Project 2D 3D，目標是把自己的 2D 作品放進 3D；他用 Blender 超過 20 年、畫畫超過 40 年，想結合兩個熱情。
    ↳ 新專案 Project 2D 3D 就是把自己的手繪作品變成 3D。他用 Blender 二十多年、畫畫四十多年，想把這兩個興趣結合起來。
  • 02:17 不一定只做單一風格，但明顯偏向漫畫風格。
    ↳ 他沒有限定自己只做一種畫風，但作品明顯偏向漫畫風。
  • 02:53 題材偏好：角色、怪東西、巫師（不是 Harry Potter）、大鼻子角色、表情豐富的角色、生氣的角色。
    ↳ 他愛畫的題材很有個人味：各種角色、怪東西、巫師（他特別說明不是哈利波特那種）、大鼻子、表情豐富或正在生氣的人物。
  • 02:53 專案目前處於 Phase One。
    ↳ 整個專案分階段進行，現在還在第一階段。
  • 03:24 Phase Two 會專注在動畫與動畫工具，創作與技術上都有挑戰。
    ↳ 第二階段才會專攻動畫，也會做動畫要用的工具。他認為那時創作和技術兩邊都會很有挑戰。
  • 03:24 Phase One 的目標是把他個人的 2D 風格帶進 3D，例如角色 Mr. Pencil；他覺得在 3D 做出風格的挑戰和在 2D 很相似。
    ↳ 第一階段的目標是把自己的畫風搬進 3D，例如角色 Mr. Pencil。他發現在 3D 裡抓風格遇到的難題，跟在紙上畫時很像。
  • 03:56 畫畫時要拿捏細節量（太多或太少），他發現 3D 也有同樣的挑戰。
    ↳ 畫畫時細節畫太多會亂，太少又顯得空。3D 也一樣，要決定哪些地方做細、哪些地方省略。
  • 03:56 雖然 Phase One 不含動畫，他仍要求 Grease Pencil 線條可以做動畫、能在變形後的幾何上運作，並為此做了測試。
    ↳ 雖然現在不做動畫，他還是先確認 Grease Pencil 線條能動，也能跟著變形後的 mesh（由點、線、面組成的 3D 模型）走，並特地做了測試。
  • 05:00 測試成功，這對 Phase Two 很有幫助。
    ↳ 測試結果可行，等於先替第二階段的動畫鋪好路，不會到時才發現線條跟不上。
  • 05:00 他一直重視快速有效率的工作流，因為是一個人利用空閒時間做，時間不多。
    ↳ 他是一個人，只能用空閒時間做，時間很少，所以每個環節都在想怎麼更快、更省事。
  • 05:00 原則一：不要什麼都建模。
    ↳ 第一個原則：不是每樣東西都要做成 3D 模型。
  • 05:32 這很取決於選擇的風格，例如 Mr. Pencil 不需要複雜的臉、嘴、眼睛建模；他基本上是混合 2D-3D pipeline。
    ↳ 要不要建模看畫風決定。像 Mr. Pencil 的臉、嘴、眼睛不用做成立體，所以他的流程其實是 2D 和 3D 混著用。
  • 05:32 原則二：擁抱 geometry nodes；不過他自己使用 geometry nodes 的經驗很有限。
    ↳ 第二個原則：大方去用 Geometry Nodes。不過他也坦白，自己用它的經驗其實不多。
  • 06:06 他覺得大家對 geometry nodes 既興奮又害怕；對他來說 coding 比較容易，因為 coding 偏語言，geometry nodes 偏數學。
    ↳ 他覺得大家對 Geometry Nodes 又期待又怕。對他來說，寫程式像學語言，比較好上手；Geometry Nodes 比較像數學，反而比較難。
  • 06:38 解決方法：給自己一個專案或目標，讓自己非用不可，就一定學得會。
    ↳ 他的解法很實際：替自己定一個非用它不可的專案或目標，被逼著用，就一定學得會。
  • 06:38 原則三：善用 assets；他為這些專案做了一份自己的 asset 清單。
    ↳ 第三個原則：多用 asset，也就是存起來、可以重複拿來用的素材或設定。他為這些專案整理了一份自己的 asset 清單。
  • 07:09 這些 asset 大多是 geometry nodes modifier asset，另外還有 toon shader asset。
    ↳ 清單裡大多是 Geometry Nodes 做的 modifier（套在物件上改變外形的效果），另外還有 toon shader，也就是讓顏色像卡通一樣分塊的材質。
  • 07:09 用 asset 的理由是速度：asset browser 可以拖放，工作流很快；另外標記成 asset 後，很容易放進程式碼裡使用。
    ↳ 用 asset 是為了快：從 asset browser（瀏覽素材的面板）直接拖進場景就好。而且東西標成 asset 後，寫程式時也很容易拿來用。
  • 07:45 原則四：做一個 add-on；不論做哪個大專案，他都會把自訂 operator 和既有的 operator、屬性集中放在 sidebar 之類的地方，方便快速取用。
    ↳ 第四個原則：替每個大專案做一個 add-on，把自己寫的和 Blender 內建的功能、設定，集中放在 sidebar（畫面旁的側邊面板），要用時馬上找得到。
  • 08:15 他開始專案時會用自製的「super preset button」；他知道可以建立自訂 workspace 或新的預設，但他不喜歡，想維持原樣，所以依專案做一顆這種按鈕。
    ↳ 每個專案他都會做一顆 super preset button，按一下就套好所有設定。他知道可以另做 workspace（上方的工作分頁）或改預設，但他不喜歡，想維持原樣。
  • 08:46 這顆按鈕會把 color management 設成 standard，因為做 2D 時不想要任何特殊的色彩管理。
    ↳ 這顆按鈕會把 color management（決定顏色怎麼顯示的設定）改成 standard，因為做 2D 風格時，他不想要任何特殊的色彩處理。
  • 08:46 這顆按鈕也會開啟 jittered shadows（他說不知道是什麼，但很酷），並開啟 depth pass，因為用 Grease Pencil 需要 depth pass。
    ↳ 按鈕也會開 jittered shadows（一個陰影選項，他笑說不知道是什麼但很酷），還會開 depth pass，也就是記錄畫面遠近的資訊。他說用 Grease Pencil 就需要它。
  • 08:46 這顆按鈕也會建立一整套專為這個 2D-3D pipeline 設計的 world shader。
    ↳ 按鈕還會自動建立一整套 world shader，也就是場景的背景和環境光設定，專門搭配這種 2D 加 3D 的做法。
  • 09:21 這顆按鈕也會設定筆刷與其他繪圖設定；add-on 裡放常用功能，例如快速切換 wireframe、關閉 3D cursor、關閉 origin points。
    ↳ 按鈕也會設好筆刷等繪圖設定。add-on 裡另外放了常用開關，像一鍵切換 wireframe（只看模型網格線），以及關掉 3D cursor（新物件的定位點）和物件中心點（origin points）。
  • 09:21 他很喜歡 Workbench（viewport 的算圖）的陰影，可以做出銳利陰影，特別適合這種 2D 風格的 pipeline。
    ↳ 他很喜歡 Workbench 的陰影。Workbench 基本上就是工作視窗（viewport）用的簡易算圖，陰影可以很銳利，特別適合 2D 風格。
  • 09:53 他把重點分成三個領域：3D shapes、Grease Pencil lines、toon shading，每個都一樣重要，不能跳過任何一個。
    ↳ 他把整件事拆成三塊：3D 形狀、Grease Pencil 線條、卡通陰影（toon shading）。三塊一樣重要，哪一塊都不能跳過。
  • 10:23 缺一個就可能全盤崩壞，例如形狀很好但線條或陰影不好，或形狀和線條都很好但陰影不好，整體都會垮掉。
    ↳ 三塊互相牽動：形狀做得再好，只要線條或陰影其中一個不對，整體畫面就會垮掉。
  • 10:23 還有第四個領域是動畫，動畫也能成就或毀掉 2D 風格，但那是下一階段的事。
    ↳ 其實還有第四塊：動畫。動得好不好一樣能成就或毀掉 2D 風格，但這留到下一階段處理。
  • 10:57 第一個領域是 3D shapes：其實在 2D 草圖裡就能找出 3D 形狀，例如很多扁平或有機形狀、腿明顯是管狀、頭部有體積。
    ↳ 第一塊是 3D 形狀。2D 草稿裡其實就看得出立體資訊：很多扁平或有機（自然彎曲、不規則）的形狀，腿明顯是管狀，頭也有體積。
  • 11:27 在 2D 裡畫陰影和 cross contour lines，是為了探索形體的體積與方向；他想在 3D 中也得到這種效果，作為基礎。
    ↳ 畫 2D 時加陰影和 cross contour lines（橫跨表面、順著形體彎曲的線），是為了摸清楚形體的體積和朝向。他希望在 3D 裡也有這種效果，當作基礎。
