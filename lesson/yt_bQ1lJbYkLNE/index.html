🧑‍🏫 這支影片示範怎麼讓 Claude 透過 Higgsfield 的免費外掛，在 3D 軟體 Blender 裡先排好場景和鏡頭走位，最後才交給 AI 生成影片。這樣就不用一直重新生成碰運氣，能省下生成點數，而且不會 Blender 也能照做。

  • 00:00 Higgsfield 推出全新免費 plugin，把 Claude 直接接進 Blender。用白話英文描述場景，Claude 會在 3D 裡建出來，你只需要生成最終影片

    ↳ connector（連接器）是讓兩個軟體互通的元件。第一步先到 higgsfield.ai/plugin/blender 下載給 Blender 用的連接器，完全免費。
  • 01:00 步驟 2：在同一頁往下捲到最底，找到 Higgsfield MCP Bridge，複製 bridge URL

    ↳ 打開網頁版 Claude，依序點加號（plus）→ connectors → manage connectors → add。connectors 是 Claude 外接其他服務的功能，這一步是在新增一個外接服務。

    ↳ remote MCP server URL 是填遠端服務網址的欄位，貼上剛才複製的 bridge 網址，名稱取個好認的，例如 Higgsfield Bridge。其他設定都不用動，按 continue，再按 add。

    ↳ 在 Blender 裡登入同一個 Higgsfield 帳號並授權。做完這步，Claude、Higgsfield、Blender 三邊才算真正串起來，可以開始工作。

    ↳ 幾分鐘後，Claude 就在 Blender 裡把場景搭好，你可以直接在 Blender 播放預覽。這裡看到的運鏡就是最後影片的運鏡，AI 生成時不會自己改掉。

📘 術語
credits（點數／額度）：字幕未明確定義；在 Higgsfield 每次生成影片都要花 credits，多次生成就花更多

previs（預覽影片／前期視覺化）：字幕未解釋；案例中請 Claude 在 Blender 做的 20 秒一鏡到底預演
one-shot / one continuous take（一鏡到底）：一個連續鏡頭，完全沒有剪接
Blender skill（Blender skill）：bridge 內附的說明，告訴 Claude 如何在 Blender 建立素材，所以不必另外提供 Blender 資訊
profile view（側面視角）：字幕未解釋；指鏡頭從側面拍跑者，講者要求跳躍後維持 3 或 4 秒
frame rate（幀率）：匯出設定之一，講者選 24

Seedance 2.0（Seedance 2.0）：在 Higgsfield video 區選用的影片生成模型；第二個案例字幕寫 SeaDance 2.5
hyper motion CGI（hyper motion CGI）：字幕未解釋；第二個案例香水瓶廣告的風格描述

drift（飄移）：沒用 Blender 的版本鏡頭較容易 drift
video-to-video generator（影片轉影片生成器）：Higgsfield 新推出的功能，名為 GenJitsu，在另一支影片介紹
