📘 術語
MCP（MCP（連接協定））：可想成一條線，把你的 AI 接到某一個特定平台（本片是 Higgsfield）
connectors / add custom connector（連接器／新增自訂連接器）：Claude 設定裡的區塊，在這裡新增自訂連接器、命名並貼上 MCP URL
MCP URL（MCP 網址）：串接第一步要複製的網址，貼進 Claude 的 custom connector
prompt（提示詞）：給 AI 的指令；Claude 會把你的白話描述寫成詳細的生成 prompt
aspect ratio（畫面比例）：Claude 生成前會問的設定之一，片中選 16:9
resolution（解析度）：生成設定之一；圖片選 4K，影片選 1080p（4K 較花 credits、較慢）
quality mode（品質模式）：選 GPT image 2 時多出來的設定，和在 Higgsfield 裡一樣，作者選 high
credits（點數）：在 Higgsfield 購買、用來生成圖片和影片的點數
supercomputer（Higgsfield supercomputer）：Higgsfield 新推出的功能，沒有獨立 token 額度，每則訊息都扣 Higgsfield credits
tokens（token 額度）：字幕提到 supercomputer 沒有獨立的 token 額度，改扣 credits
underlying settings（底層設定）：Higgsfield MCP 的底層設定，讓 Claude 像電影導演一樣寫專業影片 prompt
duration（影片長度）：生成影片時 Claude 會問的設定，可每支分別設，作者全設 8 秒
low hero angle / backlit rim glow / volumetric god rays（鏡頭角度、光線與大氣描述）：Claude 寫在 prompt 裡的鏡頭角度、光線、大氣感描述例子；字幕未逐一解釋
telephoto lens compression / anamorphic lens flare / film grade（技術鏡頭語言）：prompt 結尾的技術鏡頭語言例子，作者說自己幾乎沒聽過；字幕未逐一解釋
reference image / reference sheet（參考圖）：每個新場景上傳的角色或場地圖，用來維持一致性
free panel style template（free panel style 模板（字幕原文））：作者做的模板，給 Claude 後叫名字即可用；產出左全身、中背面、右臉的三格圖
elements（元素）：把角色圖存成 elements，Higgsfield 才知道是角色，整支影片角色才一致
dead frames（無效畫格）：組裝影片時要從每個鏡頭開頭或結尾剪掉的畫格
