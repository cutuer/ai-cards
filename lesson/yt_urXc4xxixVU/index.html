📘 術語
Scheduled task（排程任務）：讓 ChatGPT 依你選的時間（每小時、每天、每週等）自動執行同一件事，並決定任務何時執行
ChatGPT Work（ChatGPT Work）：可建立 scheduled task 的 ChatGPT 版本，可在 desktop app、網頁或行動版使用
Plugins（外掛）：用來連接 Google Calendar、Gmail 等服務的地方，沒連接可選 Install 並連接帳號
Skill（技能）：記住你喜歡的做事方式，例如文件格式
Brief（簡報摘要）：示範中為每場會議整理的簡短摘要
✏️ 小考一題

根據影片，scheduled task 和 skill 的分工是什麼？

A. skill 只能在 desktop app 使用，scheduled task 只能在網頁使用B. skill 記住你喜歡的做事方式，scheduled task 決定什麼時候執行C. skill 決定什麼時候執行，scheduled task 記住做事方式D. skill 負責連接 Gmail，scheduled task 負責連接 Google Calendar
看答案
答案：B。[01:03] 字幕提到：A skill remembers how I like the work done. The scheduled task decides when it happens.
