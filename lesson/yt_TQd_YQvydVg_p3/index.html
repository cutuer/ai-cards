    ↳ 原因很單純：講者改完程式忘了存檔，連線沒有生效。這剛好證明 agent 需要 context（回答問題要用的背景資訊），少了它就只能亂答。

📘 術語
MCP server（MCP 伺服器）：agent 連上它才能取得 context（例如蛋糕店口味），也能從中取得 prompt 和 welcome banner
system prompt（系統提示詞）：更新它可以讓 agent 有特定 persona，用特定方式打招呼
prompt（MCP 上的）（提示詞）：放在 MCP server 上、含 agent instructions 的現成 prompt，可以重複使用，簡化工作流程
persona（角色設定）：希望 agent 呈現的特定角色，透過 system prompt 設定
welcome banner（歡迎橫幅）：agent 啟動時顯示的自訂開場畫面，從 MCP server 取得
context（脈絡資訊）：agent 回答所需的資訊；少了它，agent 就不知道有哪些口味
customer ID（顧客編號）：agent 幫使用者註冊時產生的編號，之後再訂購會用到
voucher（兌換碼）：dashboard 上顯示的 6 字元代碼，約每分鐘更新，點餐時要輸入
dashboard（儀表板）：會場前方的大螢幕，顯示 voucher 和訂單狀態（準備中、ready for pickup）
Microsoft Foundry（Microsoft Foundry（平台名稱））：本次 workshop 介紹的平台，把 Sonnet 接進去使用
Azure credits（Azure 點數）：有免費的 Azure credits 可以用來試用
Microsoft Learn（Microsoft Learn（學習平台））：提供 Foundry 相關免費課程的地方
