🧑‍🏫 這段是 Grok 團隊直播實際玩他們的自動對戰卡牌遊戲 ThursdayArena，邊玩邊把想到的改進點子丟給 AI 整理。值得看的是他們怎麼看上線數據、找出「遊戲太難」和「新人變少」這兩個問題，接著想怎麼拉人、留人。一個產品剛上線的頭幾個小時怎麼調整，這段幾乎全程攤開。

  • 166:11 遊戲是策略遊戲：先排好陣容再開打；示範卡牌能把 50% 攻擊力分給前方隊友，所以考慮放後排
    ↳ 這是策略遊戲，開打前要先排好誰站前、誰站後。示範的那張卡能把自己 50% 的攻擊力分給前面的隊友，所以放後排比較划算：自己不衝，專門幫隊友加攻。
  • 166:11 開打後會和對手配對，對手各有能力，遊戲自己進行，類似 auto battle
    ↳ 按下開打後，系統會自動幫你配一個對手，對方的卡也各有能力。接著是 auto battle（自動對戰）：你只負責排陣容，過程遊戲自己打完。
  • 166:11 一場打三回合，回合之間可以買新 bot，繼續調整策略
    ↳ 一場分三回合，每回合中間可以買新的 bot 卡。看上一回合打得怎樣再改陣容，有點像邊打邊修改作戰計畫。
  • 166:44 例子：設計團隊 Manuel 做的設計評論 bot「critiquito」，對敵方前排造成 2 點傷害，是 uncommon 卡
    ↳ 卡牌的例子：設計團隊的 Manuel 做了一個評論設計的 bot「critiquito」，做成卡後能打敵方前排 2 點傷害，稀有度是 uncommon，也就是比普通卡稀有一級。
  • 166:44 卡牌分等級、有稀有度，這些邏輯都可以再調整
    ↳ 卡牌有等級和稀有度，但這些規則沒有寫死。團隊之後可以看大家玩起來的感覺，再改數值和規則。
  • 167:22 成長點子：分享自己做的 bot／卡牌，別人下載後可以換到更稀有的版本，把稀有度變成遊戲的一部分
    ↳ 成長點子：玩家把自己做的 bot 卡分享出去，別人下載後，分享的人可以換到更稀有的版本。等於拿稀有卡當誘因，讓玩家主動幫忙拉人。
  • 167:55 gold 是回合之間調整陣容的資源；示範時有 10 gold，賣掉一張卡
    ↳ gold 是遊戲裡的金幣，回合之間用來買卡、換卡、調整陣容。示範時手上有 10 gold，他們也賣掉了一張卡。
  • 167:55 點子：連打好幾回合不休息（跳過商店）可以拿到更多 gold，類似連勝機制
    ↳ 點子：連打好幾回合、跳過中間的商店不買東西，就給更多 gold。跟連勝獎勵類似，忍住先不花的人，之後本錢比較多。
  • 168:29 第三回合獲勝；點子：在勝利畫面加分享按鈕，讓玩家分享戰績、炫耀
    ↳ 第三回合贏了。點子：在勝利畫面放一個分享按鈕，讓玩家一鍵把戰績貼出去炫耀，順便幫遊戲曝光。
  • 168:29 點子：玩家可以直接挑戰特定玩家，對方要接受挑戰，類似 Words with Friends，也能帶動邀請朋友
    ↳ 點子：可以指定挑戰某位玩家，對方接受了才開打，類似跟朋友輪流對戰的拼字遊戲 Words with Friends。想跟朋友打，就得先邀朋友進來。
  • 169:04 他們即興講成長點子，用語音轉文字丟給 Grokbot；轉錄不完美，但 agent 會自己理解
    ↳ 他們邊玩邊用語音轉文字，把點子丟給 Grokbot（他們的 AI 助理）。轉出來的字有錯，但 agent（能自己判斷、執行任務的 AI）還是看得懂意思。
  • 169:37 bot 把所有回饋記到 Notion；之後讓 software factory 派 agent 處理這些點子，產出 PR 和 play test
    ↳ bot 把回饋都整理進 Notion（筆記兼資料庫工具）。之後交給 software factory 派 AI agent 去做，產出 PR（待審核的程式修改）和 play test（試玩版）來實驗。
  • 169:37 核心循環：練習、對戰、勝利畫面、回到首頁；可以看 leaderboard，這次沒拿到 elo 分數
    ↳ 主流程是：練習→對戰→勝利畫面→回首頁。首頁有 leaderboard（玩家排行榜）。這局沒拿到 elo，elo 是依勝負計算的實力積分。
  • 170:11 直播有很多同時在線觀眾，要引導大家做特定行動，例如追蹤 X 上的 ThursdayArena 帳號
    ↳ 直播同時有很多人在看，這是難得的人潮，要趁機請大家做一件具體的事，例如去 X 追蹤 ThursdayArena 的帳號。
  • 170:50 點子：有人追蹤 @ThursdayArena 就自動 DM 感謝，邀請試玩，可能送 10 free gold
    ↳ 點子：只要有人追蹤 @ThursdayArena，就自動發 DM（私訊）感謝，邀對方來試玩，可能再送 10 gold，讓「追蹤」直接變成「來玩」。
  • 170:50 把 X 當平台，用追蹤者替遊戲導流；目前的來源很窄，幾乎只有直播或 X 貼文
    ↳ 把 X 當成拉人的管道，追蹤者就是潛在玩家。問題是現在新玩家幾乎只從直播或 X 貼文來，來源太窄。
  • 171:27 用 X API 找誰在討論 ThursdayArena；Grokbot 已接好 X connector，現場請它搜尋回饋，連同使用者帳號整理進 Notion 新段落
    ↳ 用 X API（讓程式讀取 X 資料的接口）找誰在聊這款遊戲。Grokbot 已經接好 X connector（連到 X 的外掛），現場就請它搜回饋，連同帳號整理進 Notion。
  • 172:04 在 xAI 上線產品時，會開一個 metrics bot，每 15 分鐘回報使用人數、功能狀況、有沒有 bug，像一個資料實習生
    ↳ 他們在 xAI 上線產品時會開一個 metrics bot（回報數據的 bot），每 15 分鐘報告使用人數、功能是否正常、有沒有 bug（程式錯誤），像專門盯數字的實習生。
  • 172:38 也可以監看 Slack 的留言，和 Slack bot 搭配，想要什麼資料就隨時拿到
    ↳ 它也能盯 Slack（團隊聊天工具）裡的留言，跟 Slack bot 搭配。想看什麼數據，直接在聊天室問就拿得到，不用自己去翻。
  • 173:12 目前不登入也能練習，可選擇用 X 登入，刻意不設門檻
    ↳ 目前不登入也能直接練習，想登入再用 X 帳號登入。這是故意不設門檻，先讓人玩到，不要一開始就把人擋在門外。
  • 173:12 漏斗點子：連續練習兩三次後，再跳出用 X 登入的提示
    ↳ 漏斗點子：等玩家連續練習兩三場、看得出有興趣了，再跳出「用 X 登入」的提示。在這個時間點開口，比一進門就要求登入好。
  • 173:49 獎勵機制點子：練習時讓使用者比較容易贏，讓他們感受到遊戲好玩而想繼續玩
    ↳ 獎勵點子：練習模式故意讓玩家比較容易贏。先嚐到贏的感覺、覺得好玩，才會想繼續玩下去。
  • 174:20 遊戲引擎指標（上線第一小時）顯示對戰偏難，應該比較練習和已登入玩家的勝負比
    ↳ 上線第一小時的遊戲引擎數據顯示對戰偏難。他們想把練習玩家和已登入玩家的勝負比拿來比，看新手是不是輸太多。
  • 174:51 還沒有難度模式，被認為是好功能；目前是對 AI，對戰版還在整理
    ↳ 目前還不能選難度，大家都覺得加上會很好。現在玩家其實是在跟 AI 打，真人對戰的版本還在整理中。
  • 174:51 遊戲設計評論 bot 的評語：以上線來說，遊戲太難，需要修正
    ↳ 他們的遊戲設計評論 bot 也給了評語：以剛上線的遊戲來說太難了，需要修。這跟前面數據看到的是同一件事。
  • 175:30 上線高峰過後，新註冊數在下降，因此討論 outbound 行銷
    ↳ 上線高峰過後，新註冊人數開始往下掉，所以開始討論 outbound 行銷，也就是主動寄信、發私訊去找人，而不是等人自己上門。
  • 175:30 outbound 很難做，大多數人不想收到；關鍵是讓人真的讀你的東西
    ↳ outbound 難做，因為大多數人根本不想收到這種信。重點不在寄出去多少封，而在對方有沒有真的點開來讀。
  • 176:05 講者看信時先看寄件人名字，不是主旨，所以要用大家在 X、LinkedIn、宣傳影片上看過的熟面孔
    ↳ 講者說自己看信會先看寄件人是誰，不是先看標題。所以要找大家在 X、LinkedIn、宣傳影片上看過的熟面孔來寄，陌生名字很容易被略過。
  • 176:39 點子：讓 potato 用自己的名義寄 email／DM，借助她的粉絲群帶動使用
    ↳ 點子：讓團隊裡的 potato 用她自己的名義寄 email、發 DM，借助她原本的粉絲，讓人比較願意點開、來玩。
  • 177:10 講者最近常在實驗給 bot 一個 email 地址，讓它寄信、管理行銷活動
    ↳ 講者最近常在實驗：給 bot 一個自己的 email 信箱，讓它自己寄信、管理整個行銷活動，不用人一封一封手動寄。
  • 177:10 點子：在 LinkedIn 找大型遊戲工作室的開發者生態系相關人士，補上他們的工作 email，建立名單去聯絡
    ↳ 點子：在 LinkedIn 上找大型遊戲工作室裡負責開發者生態系（經營外部開發者與合作夥伴）的人，補上他們的工作 email，整理成名單去聯絡。
📘 術語
auto battle（自動對戰）：排好陣容後，遊戲自己打完，玩家只負責策略
uncommon card（非普通卡）：卡牌有等級和稀有度，critiquito 屬於 uncommon
gold（金幣）：回合之間用來改變陣容的遊戲資源
software factory（軟體工廠）：把點子丟給 agent，讓它們產出 PR 和 play test 來實驗
PR（程式碼合併請求）：software factory 讓 agent 產出的成果之一
play test（試玩測試）：software factory 會產出，用來實驗新點子
elo（elo 積分）：對戰後可能獲得的分數，這局沒拿到
leaderboard（排行榜）：回到首頁後可以看到的玩家排名
X connector / X API（X 連接器／X API）：讓 Grokbot 搜尋 X 上關於 ThursdayArena 的討論
funnel（漏斗）：例如從練習到用 X 登入的轉換流程
outbound marketing（主動外展行銷）：主動寄信／DM 給人；很難做，多數人不想收到

根據影片，11:25 AM 的數據中練習場數和 X 登入數大約是多少？

A. 約 1000 場練習、2200 次 X 登入B. 約 2200 場練習、1000 次 X 登入C. 約 2200 場練習、220 次 X 登入D. 約 1500 場練習、1000 次 X 登入
