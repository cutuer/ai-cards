📘 術語
previs / previz（預視覺化）：正式生成前先在 Blender 做的預覽動畫，用來調整動態、構圖、時間點與整體鏡頭
Higgsfield（Higgsfield（平台名））：以 AI 圖像與影片製作流程為核心的生成式創作平台
plugin（外掛程式）：Higgsfield Blender plugin 把 Blender 變成可控的 AI 影片 previs 工作區
credits（點數）：Higgsfield 生成用的點數，本流程只在最後生成影片時才花
bridge URL（橋接網址）：Higgsfield 提供的網址，Claude 連上後 agent 就能和 Blender 裡的工具溝通
Connectors / custom connector（連接器／自訂連接器）：在 Claude desktop app 的 Customize 裡新增，貼上 bridge URL 連接 Higgsfield + Blender
agent（代理程式）：連上 bridge 後可與 Blender 內工具溝通、代為建構場景的 Claude
N-panel（N 面板（右側欄））：Blender 右側欄，游標在 3D viewport 上按 N 可開關
3D viewport（3D 視埠）：Blender 顯示 3D 場景的區域，游標放在這裡按 N 開關 N-panel
device code（裝置碼）：plugin 產生的代碼，登入時要確認和瀏覽器顯示的一致
MCP（MCP）：授權畫面中出現「Blender plugin MCP」，需按 Allow 讓它存取 Higgsfield 帳號
phone camera mode（手機攝影機模式）：可用手機更自然地瞄準、移動 Blender 場景攝影機
Claude Code（Claude Code）：講者用來下 prompt、建 Blender 動畫的工具，搭配 Opus 5、high effort
camera rig（攝影機架設）：Claude 在場景中建立的攝影機設定，用來做完整的攝影機動畫
motion path（移動路徑）：Claude 替車子建立的行進路徑
motion reference（動態參考）：把 Blender 動畫算成影片，作為最終 AI 生成時動態的參考
rear pursuit shot（車尾追拍鏡頭）：鏡頭推進中從車後追拍的一段
Output Properties（輸出屬性）：Blender 中設定算圖解析度與 fps 的地方
fps（每秒格數）：600 格、20 秒的動畫維持 30 fps，也可用 24 fps
playblast（快速預覽算圖）：從 Blender 算出的輕量動畫影片，上傳到 SeaDance 當動態參考
SeaDance 2.5（SeaDance 2.5）：Higgsfield 影片區中的模型，負責最終寫實影片生成
bit rate（位元率）：SeaDance 生成設定之一，本例設為 high
