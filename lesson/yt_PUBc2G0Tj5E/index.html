🧑‍🏫 這支影片是 OpenAI 用一個「一行指令訂墨西哥捲餅」的小專案，示範 Codex CLI 的一批新功能。重點是你可以用講的一次交代好幾件事，讓 AI 同時進行，再從一個畫面甚至手機追蹤進度。就算你不寫程式，也能從中看出 AI 工具正從「一問一答」走向「同時派好幾件工作」。

  • 00:02 這次更新是給習慣在 terminal 工作的使用者；團隊聽到大家希望 Codex 快速、不礙事，並能在自己喜歡的環境開發
    ↳ terminal（終端機）是用打字下指令來操作電腦的視窗，很多工程師整天待在裡面。這次更新就是為他們做的：要快、不打斷手上的事。
  • 00:02 示範專案：一個用單一指令購買「我常點的墨西哥捲餅」的 CLI，並展示它的 help 說明
    ↳ CLI 是在終端機裡打指令就能用的程式，沒有按鈕畫面。講者做的這個，打一行指令就能訂他常吃的捲餅；help 是它內建的使用說明。
  • 00:32 講者想做一個網站讓別人安裝這個 CLI，並在 Codex CLI 中開啟專案
    ↳ Codex CLI 是 OpenAI 寫程式 AI 助手的終端機版本。講者在裡面打開捲餅專案，要請它做一個網站，讓別人也能安裝這個小工具。
  • 00:32 新的全螢幕介面：可往回捲動查看先前的輸出，輸入下一則訊息的 footer 會一直保留在畫面上
    ↳ 整個視窗變成 Codex 專屬的畫面，可以往上捲回去看 AI 之前做了什麼。footer（底部輸入列）固定在下方，隨時能打下一句話。
  • 00:32 可以用 voice mode（語音模式）開始下指令，直接用說的交代工作
    ↳ voice mode（語音模式）就是用講的代替打字。對著電腦說出要做的事，Codex 就開工，一口氣交代很多事時特別方便。
  • 01:02 用語音同時開三個任務：①網站加上重複墨西哥捲餅的新背景 ②檢查 CLI 測試，確保有測價格變動與訂單確認 ③產生 CLI 訂購流程的 Mermaid diagram
    ↳ 重點是一次講完三件不相干的事：改網站背景、檢查測試夠不夠完整、畫流程圖。Mermaid diagram 是用文字描述就能產生流程圖的格式。
  • 01:02 交代完可以把語音靜音；此時有三個實際任務分散在幾個專案中同時進行
    ↳ 講完就把麥克風靜音，不用一直開著。這時三件事各自在跑，不必等一件做完才開始下一件。
  • 01:32 按左方向鍵進入 agents 畫面：查看正在執行的任務，可篩選、依狀態分組、搜尋，並直接跳進某個任務
    ↳ agents 在這裡指正在替你做事的一個個 AI 任務。按左方向鍵會出現總覽，像待辦清單，可依狀態分類、搜尋，再點進去看細節。
  • 01:32 不需要在檔案系統裡翻找或另開 terminal 來找這些任務
    ↳ 想知道各任務做到哪，不用自己去翻電腦裡的資料夾，也不用多開幾個視窗找。一個畫面就全看得到。
  • 01:32 可以請 Codex 檢查其他任務的狀況，或對它們送出後續指示（follow-up）
    ↳ 你不必一個個點進去看。可以直接問 Codex 其他幾件做得怎樣，或請它補上新要求；follow-up 就是後續追加的指示。
  • 01:32 想往不同方向嘗試時，可把對話 fork 到新的 worktree：沿用相同脈絡，但是完全獨立的 checkout
    ↳ fork 是把對話分一份出去試別的做法。worktree 是同專案的另一份獨立工作資料夾，checkout 指取出來的那份程式碼，怎麼改都不影響原本的。
  • 02:04 也能從手機回到這些任務：在筆電上啟用 remote control，選擇這台電腦後，手機上看到的就是同樣的任務
    ↳ remote control 是遠端遙控：在筆電上打開這功能並選定這台電腦，手機就能連進來。看到的是同一批任務，不是另外新開的。
  • 02:04 離開鍵盤時，可以用手機查看進度、回答任務提出的問題
    ↳ AI 做到一半常會停下來問你問題。人不在電腦前時，用手機看進度、回答它，工作就能繼續，不會卡著等你回座位。
  • 02:04 回到 terminal 後，可看到哪些已完成、哪些需要處理；示範中變更內容與測試結果都已出現，並打開網站 demo
    ↳ 回到電腦後，畫面會標出哪些做完、哪些在等你處理。示範裡改了什麼、測試結果如何都列出來了，講者也打開網站看成果。
  • 02:04 Usage analytics（使用分析）可查看自己的使用活動
    ↳ usage analytics（使用分析）是你自己的使用紀錄統計，讓你回頭看這陣子用 Codex 做了哪些事。
  • 02:35 使用分析中會顯示最常用的對話，以及常用的 plugins 和 skills
    ↳ 統計會列出你最常用的對話，還有常用的 plugins（外掛，替 Codex 加功能）和 skills（預先教好它的特定做事方法）。
  • 02:35 Mermaid 畫的墨西哥捲餅訂購流程圖可以直接在 terminal 裡呈現
    ↳ 終端機一般以顯示文字為主。現在流程圖能直接畫在裡面，不用另外開瀏覽器或別的軟體才看得到圖。
  • 02:35 也支援在 terminal 呈現 LaTeX，示範了一段「墨西哥捲餅最棒」的數學證明
    ↳ LaTeX 是用來排數學式的寫法，學術界很常用。現在終端機裡能直接顯示成數學符號；那段「捲餅最棒」的證明只是搞笑示範。
  • 02:35 團隊表示希望 Codex 配合使用者習慣的工作環境，會持續改進 CLI，並歡迎大家繼續回饋
    ↳ 收尾是表態：不是要你換工具來配合 Codex，而是它來配合你習慣的工作環境。CLI 會繼續改，也希望使用者多給意見。
📘 術語
terminal（終端機）：字幕未解釋；指許多使用者習慣工作的地方，Codex CLI 就在這裡執行
CLI（命令列工具）：字幕未解釋；示範專案是用單一指令購買墨西哥捲餅的 CLI
Codex CLI（Codex 命令列版）：字幕未定義；本片介紹它的全螢幕介面、語音模式、agents 管理等新功能
footer（底部輸入區）：全螢幕介面中輸入下一則訊息的位置，捲動時一直保留在畫面上
voice mode（語音模式）：可以用說話的方式交代 Codex 開始任務，之後也可以靜音
agents（代理）：按左方向鍵進入的畫面，可查看、篩選、分組、搜尋正在執行的任務
follow-up（後續指示）：字幕只提到可以對其他任務送出 follow-up
fork（分岔）：把對話分出去，往不同方向嘗試開發
worktree（工作樹）：fork 對話時建立的新 worktree，沿用相同脈絡，但是完全獨立的 checkout
checkout（簽出的工作副本）：字幕只說新的 worktree 是「完全獨立的 checkout」
remote control（遠端控制）：在筆電上啟用並選擇該電腦後，就能從手機查看及處理同樣的任務
usage analytics（使用分析）：查看自己的活動，包括最常用的對話、plugins 和 skills
plugins（外掛）：字幕未解釋；僅提到使用分析會列出常用的 plugins
skills（技能）：字幕未解釋；僅提到使用分析會列出常用的 skills
Mermaid diagram（Mermaid 圖表）：示範中用來畫 CLI 訂購流程圖，可直接在 terminal 呈現
LaTeX（LaTeX）：字幕未解釋；支援的 LaTeX 可在 terminal 中呈現，例如數學證明
✏️ 小考一題

在 Codex CLI 中把對話 fork 到新的 worktree，字幕說會得到什麼？

A. 把三個任務合併成一個任務B. 相同的脈絡，但是完全獨立的 checkoutC. 把對話自動同步到手機上D. 全新的脈絡，但共用同一個 checkout
看答案
答案：B。[01:32] 字幕說："I can fork this conversation into a new worktree. The same context, but a completely separate checkout."
