🧑‍🏫 這段是甜甜圈系列第六集的前 11 分鐘，示範把馬克杯「剪開攤平」，讓貼圖正確包到杯子上。UV unwrapping 是做 3D 貼圖最容易卡關的一步。看完這段，你會知道貼圖為什麼會歪，也知道剪線該放在哪裡。

  • 00:00 這集要替馬克杯做 UV unwrap 和上材質。之前的糖霜、甜甜圈、盤子都很簡單，大多直接就能用；馬克杯比較複雜
    ↳ 這集要替馬克杯做 UV unwrap（把 3D 物件剪開攤平，好讓圖片貼上去），再上材質。前面的糖霜、甜甜圈、盤子形狀單純，幾乎直接就能貼。馬克杯多了把手，才需要動手處理。
  • 00:00 先套上材質，才能看出 UV unwrapping 有沒有做好。按 N 開 properties，用 Poliigon add-on 套上 ceramic texture
    ↳ 貼圖要先貼上去，才看得出攤平得好不好。按 N 叫出側邊的 properties（屬性面板），再用 Poliigon add-on（外掛，幫 Blender 加功能的程式）套上陶瓷材質。
  • 00:31 搜尋「donut 5」可找到本教學會用到的免費材質，這次用的是 rustic gold ceramic texture
    ↳ 在 Poliigon 裡搜尋「donut 5」，就能找到這系列會用到的免費材質。這次用的是叫 rustic gold ceramic 的陶瓷 texture（貼在表面的圖片）。
  • 00:31 已下載的材質會顯示 download 狀態。選取馬克杯後按 Apply；沒選取物件時按鈕會變成 Import，只會把材質載入成 fake user material 供參考
    ↳ 下載過的材質會標示已下載。先選取馬克杯再按 Apply 就會套上。沒選物件時按鈕會變成 Import，只把材質存進檔案當 fake user material（沒人用也會保留的材質），給你參考用。
  • 01:04 套上後把手完全不行，其他部分還算可以，但杯緣和杯底有拉伸
    ↳ 貼上後把手的花紋完全亂掉，杯身大致還可以，但杯口和杯底的圖案被拉長變形。這種狀況叫 stretching（貼圖被拉扯變形）。
  • 01:04 UV editor 裡的 islands 和 cylinder 一模一樣。原因是馬克杯從 cylinder 開始建模，而 Blender 會自動替 primitive object 做 UV unwrap
    ↳ UV editor（顯示物件攤平後樣子的視窗）裡的 islands（一塊塊攤平區）跟圓柱一模一樣。因為杯子是從 cylinder（圓柱）改出來的，Blender 會自動替 primitive object（內建基本形狀）攤好。
  • 01:37 還維持 cylinder 形狀的部分沒問題；從零做出來的部分（如把手）Blender 不知道怎麼處理，所以拉伸錯亂，要重新 unwrap
    ↳ 還保持圓柱樣子的地方貼得好好的。把手是後來自己做出來的，Blender 不知道該怎麼攤，所以貼圖亂掉，只能重新 unwrap。
  • 01:37 UV unwrapping 的想法：把物件想像成紙做的，要把它攤平到 2D 平面（UV editor）上
    ↳ 核心觀念：把杯子想成紙做的，要剪開、壓平在一張平面上，這張平面就是 UV editor。貼圖其實是印在這張攤平的紙上，再包回杯子。
  • 02:10 要思考在哪裡剪開才能攤平。最明顯的是把手，一定要先跟杯身分開
    ↳ 第一步是想清楚「剪哪裡才攤得平」。最明顯的是把手，它跟杯身黏在一起，不先剪開，怎麼壓都會皺。
  • 02:10 開始前建議：選取馬克杯，在 modifiers 裡打開 On Cage。關閉時會顯示未細分的結果，部分會被 mesh 擋住
    ↳ 動手前先選馬克杯，到 modifiers（修改器，自動加工模型的功能，例如讓表面變平滑）打開 On Cage。沒開時畫面顯示平滑後的樣子，部分 mesh（點、線、面組成的網格）會被擋住。
  • 02:42 開啟 On Cage 可以看到整個 mesh，讓 UV unwrapping 更容易
    ↳ 打開 On Cage 後，整個 mesh 都看得到，選邊、決定剪哪裡時不會漏看，做 UV unwrapping 會輕鬆很多。
  • 02:42 在把手接合處按住 Shift 選取頂點，按 Ctrl+E 選 Mark Seam
    ↳ 在把手和杯身的接合處，按住 Shift 逐一點選頂點，再按 Ctrl+E 選 Mark Seam。這樣就把這圈標成 seam（剪開線）。
  • 02:42 標完 seam 後 Blender 不會立刻更新。要全選 mesh，按 U 選 Unwrap 才看得到結果
    ↳ 標好 seam 只是做了記號，畫面不會馬上變。要全選 mesh，按 U 選 Unwrap，Blender 才會照剪線重新攤平。
  • 03:15 講者偏好並建議的做法：在 3D view 上方的 Options 下拉選單勾選 Live Unwrap，之後每標一次 seam 就自動 unwrap
    ↳ 講者建議在 3D 視窗上方的 Options 下拉選單勾選 Live Unwrap（即時展開）。之後每標一條 seam 就會自動重攤，不用每次手動按 U。
  • 03:15 剛開始看起來會變更糟，要先退一步才能前進。把手另一端同樣選取後按 Ctrl+E、Mark Seam
    ↳ 只剪一刀時，畫面反而看起來更糟，這是正常的過渡。接著把把手另一端的接合處也選好，按 Ctrl+E、Mark Seam。
  • 03:49 在 3D viewport 滑鼠移到某部分按 L，在 last use 面板選 Seam，就只會選到被 seam 圍起來的部分
    ↳ 滑鼠移到某一塊上按 L，會選取相連的部分。在剛才操作的設定面板裡選 Seam，就只會選到被剪線圍起來的那一塊，可以用來確認剪得對不對。
  • 03:49 標 seam 時應切換到 Edge Select Mode，因為 seam 是放在邊上
    ↳ seam 是標在「邊」上的，所以標之前要切到 Edge Select Mode（邊選取模式），確保選到的是邊而不是點或面。
  • 04:22 現在 mesh 分成杯身和把手兩部分。但若把手是紙做的，還需要再剪一刀才能攤平
    ↳ 現在杯身和把手已經分成兩塊。但把手本身是一圈環狀，就像紙管，不剪一刀是壓不平的。
  • 05:00 seam 常會在貼圖上產生對不齊的可見線條，很難看，所以通常放在隱藏的位置。講者把這刀放在把手中間稍偏旁邊
    ↳ 剪開處的圖案常常接不起來，會留下明顯的線，很難看，所以 seam 通常藏在不顯眼的地方。講者把把手這刀放在中間偏側邊。
  • 05:00 按住 Alt 選取那圈邊，Ctrl+E 選 Seam，把手就展得不錯了
    ↳ 按住 Alt 點一條邊，可以一次選到整圈相連的邊，再按 Ctrl+E 標成 seam，把手就攤得很漂亮了。
  • 05:30 杯身同樣處理。在杯內底部按住 Alt 選取那圈，Ctrl+E、Seam，把底部圓形單獨分開
    ↳ 杯身用同樣的方法：在杯子內側底部按住 Alt 選一整圈，標成 seam，讓底部那片圓形獨立成一塊。
  • 06:02 杯身還需要一刀縱向切口。為了隱藏接縫，放在靠近把手處；那裡已有其他 seam，集中在同一處也方便用鏡頭等方式藏起來
    ↳ 杯身是筒狀，還要從上到下剪一刀才攤得開。講者把這刀放在把手旁邊，因為那裡已經有剪線，集中在一起，拍的時候轉個角度就能一起藏住。
  • 06:02 按住 Alt 點選直線到把手處停下，再按住 Shift 選取其他段，最後 Ctrl+E、Mark Seam
    ↳ 按住 Alt 點那條直線，選取會停在把手處。再按住 Shift 補選其他段，最後按 Ctrl+E、Mark Seam。
  • 06:32 張力變小了，但杯底仍有 pinching（擠壓）效果，需要在杯子下方也標 seam
    ↳ 貼圖拉扯少很多了，但杯子外側底部還有 pinching（貼圖往中間擠成一團）的情況，表示杯子下方也要再剪一刀。
  • 06:32 想單獨檢視某個物件時，在 Object Mode 選取後按 forward slash（/），其他物件都會消失
    ↳ 想單獨看某個物件時，在 Object Mode（以整個物件為單位操作的模式）選取它，按斜線鍵 /，其他東西會暫時隱藏。
  • 07:04 孤立檢視時 Blender 只在上方顯示「Local」，很容易忘記。找不到場景時再按一次 / 就會回來
    ↳ 這叫 Local View（孤立檢視），畫面上方只會小小顯示「Local」，很容易忘記自己在裡面，以為場景不見了。再按一次 / 就會回到完整場景。
  • 07:04 沒有 / 鍵的話，可以用 View > Local View > Toggle Local View
    ↳ 鍵盤上沒有 / 鍵的話，可以從選單 View > Local View > Toggle Local View 切換，效果一樣。
  • 07:04 從杯底進入 Edit Mode，選取該處後按 Ctrl+E、Mark Seam
    ↳ 從杯底進入 Edit Mode（可以改點、線、面的編輯模式），選取底部那圈後按 Ctrl+E、Mark Seam。
  • 07:36 至此大致成功 UV unwrap。拉伸一定會有，只要不明顯通常就沒關係
    ↳ 到這裡 unwrap 大致完成。把立體攤成平面，一定會有一點變形，只要肉眼看不太出來就不用在意。
  • 07:36 在 UV editor 的下拉選單選 base color，載入實際貼圖，才能看出線條落在馬克杯哪裡
    ↳ 在 UV editor 的下拉選單選 base color（材質的基本顏色圖），讓真正的貼圖顯示在底下，才看得出剪線落在杯子圖案的哪裡。
  • 08:07 這個陶瓷貼圖是實際買一個馬克杯回來掃描的，所以跟店裡買得到的一致
    ↳ 這張陶瓷貼圖是真的買一個馬克杯回來掃描做成的，所以花紋跟店裡買得到的實品一樣。
  • 08:07 按 L 選取 island，按 R 旋轉並移動它，把杯底對到貼圖的底部
    ↳ 在 UV editor 按 L 選取整塊 island，按 R 旋轉，再移動它，把杯底那塊對到貼圖上的底部位置。
  • 08:07 不確定 island 對應哪裡時，切到 Face Select mode 選幾個面，UV editor 會同步顯示
    ↳ 分不清某塊 island 對應杯子哪裡時，切到 Face Select mode（面選取模式），在杯子上點幾個面，UV editor 會同步標出位置。
  • 08:40 想把線條擺直卻做不到：因為 mesh 一部分在低處、一部分在高處，兩條線一上一下對不上
    ↳ 杯身那塊想擺正，卻怎麼轉都不直。原因是攤開後的形狀一邊高、一邊低，上下兩條線對不上。
  • 08:40 要對齊，就得讓 island 變直，接近原本預設 cylinder 的樣子
    ↳ 要對齊，就得把那塊 island 整理得方方正正，接近當初圓柱自動攤開的樣子。

    ↳ 選一條線後按右鍵選 Align Auto（自動對齊），可以把這條線拉成直線。

    ↳ 麻煩的是 Align Auto 一次只處理一條線，整塊要一條一條拉，很費工。

    ↳ Blender 沒有內建一次拉直整塊 island 的工具，但有免費的 extension（擴充功能）可以做到。講者順便示範怎麼安裝 extension。

    ↳ 安裝路徑是 Edit > Preferences > Get Extensions。剛裝好的 Blender 會先問能不能連網，你沒同意之前，它不會自己上網。

    ↳ Get Extensions 右上角有個不起眼的下拉選單，點 Visit Extensions Platform 就能進去；也可以直接用瀏覽器開 extensions.blender.org。

📘 術語
UV unwrapping（UV 展開）：想像物件是紙做的，把它剪開攤平到 2D 平面上
UV editor（UV 編輯器）：顯示物件攤平後的平面，可看到 islands
island（UV 島）：UV editor 裡被 seam 分開的一塊塊展開區域
primitive object（基本幾何物件）：如 cylinder，Blender 會自動替它做 UV unwrap
seam（接縫／切口）：展開時的剪開處，常在貼圖上產生對不齊的可見線條，宜放在隱藏處
Mark Seam（標記接縫）：選取邊後按 Ctrl+E 選它，就能設為 seam
Live Unwrap（即時展開）：在 Options 下拉勾選後，每標一次 seam 就自動 UV unwrap
On Cage（On Cage）：modifiers 裡的選項，開啟可看到整個 mesh，關閉會有部分被遮住
Edge Select Mode（邊選取模式）：seam 放在邊上，所以標 seam 時要用這個模式
Face Select mode（面選取模式）：選面時，UV editor 會同步顯示對應位置
Local View（本地檢視（孤立檢視））：按 / 只顯示選取物件，上方會顯示 Local，再按 / 回到原場景
stretching（拉伸）：貼圖被拉扯變形；一定會有一些，不明顯通常沒關係
pinching（擠壓）：杯底出現的擠壓效果，需再標 seam 解決
Align Auto（自動對齊）：右鍵選它可把選取的一條線拉直，但一次只處理一條
base color（基礎顏色貼圖）：在 UV editor 下拉選單選它，可載入實際貼圖看線條位置
fake user material（fake user 材質）：沒選取物件時按 Import，材質會以此形式載入供參考
add-on（附加元件）：講者用 Poliigon add-on 套用材質
extension（擴充功能）：非 Blender 官方製作但免費，由社群擴充 Blender 功能
