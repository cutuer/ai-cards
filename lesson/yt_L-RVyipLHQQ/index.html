🧑‍🏫 這支是 OpenAI 圖片生成團隊的研究員示範新版 ChatGPT 圖片模型的兩項升級：圖片形狀可以自由決定，畫質也更高。如果你常用 AI 做海報、簡報圖或要印出來的東西，這兩點會直接影響成品能不能用。

  • 00:02 講者 Deva 是 Imagen 團隊的研究員，本集介紹 Imagen 2.0 的 aspect ratio 與 resolution
    ↳ 講者 Deva 是 OpenAI 圖片生成團隊的研究員。這集講兩件事：aspect ratio（長寬比，圖片寬和高的比例）和 resolution（解析度，圖片有多少像素、細節有多清楚）。
  • 00:02 可變的長寬比與解析度讓使用者能更有彈性，從新 Imagen 模型得到真正需要的圖
    ↳ 重點是彈性。以前拿到的圖尺寸是被框死的，現在可以照用途指定形狀和清晰度，直接拿到能用的圖，不用事後再裁切或硬放大。
  • 00:02 先前的模型只能輸出固定的 portrait（直式）、固定的 landscape（橫式）或正方形
    ↳ 以前只有三種選擇：固定的 portrait（直式，像手機畫面）、固定的 landscape（橫式，像電腦螢幕），或正方形。想要細長的圖只能自己裁。
  • 00:02 新模型能輸出各種不同寬度與高度的圖片，也能輸出更高解析度的圖片
    ↳ 現在寬和高可以自由搭配，不再只有三種規格。同時也能輸出像素更多的圖，放大或印出來時細節比較不會糊掉。
  • 00:32 範例一：製作介紹海洋不同分層的海報，prompt 為「Make me tall 3 by 1 poster」
    ↳ 第一個示範是做一張介紹海洋分層的科普海報。prompt（你打給模型的指令）只寫「幫我做一張高的 3 比 1 海報」，意思是高度是寬度的三倍。
  • 00:32 如果要把圖印出來，解析度就很重要，能讓內容清楚易讀、小字也好看
    ↳ 螢幕上看起來還行的圖，印出來常常會糊。解析度夠高，海報上的說明小字印出來才看得清楚，做實體印刷品時要特別在意這點。
  • 00:32 之前在 API 裡解析度最高只到 1K，現在最高可以要求到 2K
    ↳ API 是讓工程師用程式直接呼叫模型的管道。以前透過 API 最高只能拿到 1K 的圖，現在能要到 2K。數字越大，像素越多、細節越足。
  • 01:03 產出的海報中所有圖像都很清晰，講者認為已經可以拿到教室使用
    ↳ 成品海報裡的每個圖案都很清楚。講者覺得品質已經可以直接拿去教室當教材，不只是好玩的示意圖。
  • 01:03 範例二：米粒上的文字。預設的較低解析度下只看得出有字、幾乎讀不出來；較高解析度下可以清楚讀出文字，差異很大
    ↳ 第二個示範是把字寫在米粒上。低解析度只看得出上面有字，高解析度就能真的讀出內容。東西越細小，解析度的差別越明顯。
  • 01:35 模型只根據 prompt 就能判斷適合的 aspect ratio
    ↳ 你不一定要自己寫比例。模型會從你描述的用途判斷該做成什麼形狀，例如你說要全景圖，它就自動做成橫長的圖。
  • 01:35 範例三：製作想去但還沒去過的地方的 360 全景圖，prompt 為「Make a 360° panorama taken from the top of Half Dome」
    ↳ 第三個示範是做 360 panorama（可以轉一圈看四周的全景圖）。講者請模型生成從 Half Dome（美國優勝美地的知名巨岩）山頂看出去的景色。
  • 01:35 模型知道要用大約 2 比 1 的比例生成，因為大多數全景圖都是這個比例
    ↳ prompt 裡沒有寫比例，模型自己知道全景圖通常約 2 比 1（寬是高的兩倍），就照這個比例產出。這正是上一個重點說的自動判斷。
  • 01:35 為了驗證成果，講者請 Codex 快速叫出一個 panorama viewer 來檢視
    ↳ 全景圖要實際轉著看才知道做得好不好。講者請 Codex（OpenAI 會寫程式的 AI 工具）快速做出 panorama viewer，也就是可以拖曳轉動檢視全景圖的小程式。
  • 02:06 在 viewer 中確實能以 360 度檢視這張全景圖
    ↳ 把圖放進 viewer 後，真的可以轉一圈看。這代表它不只是一張寬寬的風景照，而是符合全景格式、可以實際使用的全景圖。
  • 02:06 幾乎看不到接縫（seam），模型讓圖片兩側邊緣彼此一致、接合得很好
    ↳ seam（接縫）是全景圖左右兩端接起來的地方，接不好會看到一條斷線。模型讓兩邊的景物對得上，轉到接合處幾乎看不出破綻。
📘 術語
aspect ratio（長寬比）：圖片寬度與高度的比例；新模型可輸出多種寬高，例如 3 比 1、2 比 1
resolution（解析度）：影響印刷時是否清楚易讀、小字是否好看；API 上限由 1K 提高到 2K
portrait / landscape（直式／橫式）：先前模型只能輸出固定的直式、固定的橫式或正方形
360 panorama（360 度全景圖）：可做 360 度檢視的圖，大多數約為 2 比 1 的比例
panorama viewer（全景圖檢視器）：講者請 Codex 叫出來，用來以 360 度檢視生成的全景圖
seam（接縫）：全景圖兩側邊緣相接處；模型讓兩邊一致，所以幾乎看不到
prompt（提示詞）：給模型的指令；模型能只根據 prompt 判斷適合的長寬比
API（應用程式介面）：字幕提到過去在 API 中解析度最高只到 1K，現在可到 2K
