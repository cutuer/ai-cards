🧑‍🏫 這段直播先回答觀眾兩個問題：別人分享的 bot 拿到手會帶什麼過來，以及怎麼知道交給 bot 的事太多了。接著示範怎麼叫好幾個 bot 一起發想 Grok Bot 快閃店的票券和周邊。想學怎麼跟 bot 分工、怎麼判斷它有沒有做偏，可以看這段。

  • 417:47 別人分享給你的 bot 是一份 template，可複製 memories、部分 context、instructions、first-party plugins 等，但不會帶到敏感資料或聊天資料
    ↳ bot template 就是分享 bot 時用的範本。它會複製 memories（它記住的事）、部分 context（手上的背景資訊）、instructions（指令），還有 first-party plugins（影片沒細講）。對方的敏感資料和聊天紀錄不會跟著過來。
  • 418:17 bot 看不到密碼；Grok Bot 用 secure entry 安全儲存密碼，使用者會看到一個填寫表單，不用擔心 bot 碰到敏感資料
    ↳ bot 看不到密碼。要用密碼時，Grok Bot 會用 secure entry（安全輸入）跳出表單讓你自己填，密碼另外安全存起來，bot 碰不到。
  • 418:17 拿到 bot template 後可以邊用邊調整，它有既定的行為與動作，但會變成你自己的版本，不是一模一樣的複製品
    ↳ 拿到範本後不用照單全收。它一開始有預設的做法，你邊用邊調整，它就會變成你自己的版本，跟原本那份不會一模一樣。
  • 418:48 怎麼判斷給 bot 的 scope 太大：觀察它的回應。就像人被交代太多事會混亂、講話不合理，AI 也要看輸出有沒有道理、品質好不好
    ↳ scope 是你交給 bot 的工作範圍。給太大就像一個人同時被丟十件事會亂掉，bot 的回答也會開始不合邏輯、品質變差。看它的輸出就判斷得出來。
  • 419:18 從 context 與 next token prediction 的運作方式可以理解原因，但這裡不深入，重點是感覺 bot 有沒有對準目標
    ↳ 原因跟 context 和 next token prediction 有關。後者是 AI 一小段一小段往下猜、慢慢接出回答的方式。講者沒深入講，只說重點是看 bot 有沒有對準目標。
  • 419:48 如果 bot 沒有往好的方向走，可能需要縮小 scope 或清除 context
    ↳ 發現 bot 越走越歪，可以把交代的範圍縮小，或清掉它累積的 context，讓它重新開始，不被前面的雜訊拖著跑。
  • 419:48 Lauren 先前提過想辦藝術展，她的 bot 就開始規劃 Grok Bot 藝術展；她現在想先設計很酷的票券來帶動氣勢
    ↳ Lauren 之前提過想辦藝術展，她的 bot 記住了，就開始規劃 Grok Bot 藝術展。她現在想先做出很酷的票券，把大家的興趣帶起來。

    ↳ Lauren 的靈感來自亮面的寶可夢卡。她希望第一場 Grok Bot 快閃店（pop-up，短期開的實體店）的票券本身就值得收藏。

    ↳ 辦實體快閃店是因為它很特別，不只是軟體。他們想讓 bot 發想 merch（周邊商品），除了絨毛娃娃和好品質帽T，還要有新奇的點子。

    ↳ 聊天室觀眾也丟了點子：馬鈴薯絨毛娃娃、SpaceX 火箭發射照片，還有做成不同 Grok Bot 造型的限量紓壓球。

    ↳ 可以替每個 Grok Bot 角色做絨毛娃娃。也可以讓參加者交出自己做的 bot template，挑出做得好的，幫它們做專屬周邊。

    ↳ 更大膽的點子是做會寫程式、各有用途的實體 Grok Bot。例如一個鑰匙圈 bot，專門顯示遠距離伴侶現在在哪裡。

📘 術語
bot template（bot 範本）：分享 bot 時的形式，可複製 memories、context、instructions、first-party plugins，不含敏感與聊天資料
first-party plugins（官方外掛）：template 可一起複製的內容之一，字幕沒有進一步說明
secure entry（安全輸入）：bot 儲存密碼的方式，使用者會看到一個表單，bot 看不到密碼
scope（任務範圍）：交給 bot 的工作範圍；太大時輸出會變得不合理、品質變差
context（上下文）：bot 不在狀態時可以清除 context 或縮小 scope
next token prediction（下一個 token 預測）：講者說可以用它理解 scope 太大的原因，但沒有深入說明
pop-up（快閃店）：他們想辦的實體活動，當作品牌的實體呈現，需要處理周邊、場地、票務
merch（周邊商品）：快閃店要賣的商品，如帽 T、絨毛娃娃等
stretch goal（延伸目標）：平台化被列為 stretch goal，先幫自己做工具，之後再決定
Grok Imagine（Grok Imagine）：merch bot 接上它來產生周邊設計圖
API（應用程式介面）：想透過 API 或網站把供應商的周邊選項餵給 bot 挑選
