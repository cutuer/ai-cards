📘 術語
prompt（提示詞）：由 Claude 產生，再貼進 Seedance 生成影片；有修改意見就回 Claude 更新。
batch（批次生成）：同一個 prompt 跑多個 batch 以便有選擇，再從各 batch 挑最佳片段組合。
asset（素材（角色、道具、場景圖））：附給 Claude 並標上名稱，例如舵手、道具、沙漠 location；字幕未另外定義。
location asset（場景素材）：把綠洲當成獨立的 location asset，模型就知道位置和地景，每次生成都一樣。
final edit（最終剪輯）：選中的生成片段會放進最終剪輯。
camera notes（運鏡說明）：prompt 裡對鏡頭的指示，講者說這是該鏡頭的重點。
near miss（險些擊中）：在第一格加入船邊大水花，表示炮彈差點打中。
credits（點數）：每避免一次失敗的 batch 就能省下 credits。
4K（4K 解析度）：講者說爆炸清晰厚重，不是常見的模糊 slop，所以值得用。
slop（粗糙內容）：字幕用來形容常見的模糊畫面（blurry slop）。
transition（轉場）：例如從海裡平順轉到下一場景，或從海盜場景轉到沙漠。
zoom in / zoom out（推近／拉遠）：例如對遠處箱子 sharp zoom in；大幅 zoom out「看起來很貴」。
comic relief（搞笑調劑角色）：鴕鳥在片中負責搞笑，所以牠們的反應要好笑。
breathing room（留白緩衝）：開場的留白讓從 scene one 切過來的剪接成立。
mix and match（混搭挑選）：從不同 batch 挑最好的部分組合起來。
camera cuts（鏡頭切換）：在 prompt 裡另外加入幾個特定的鏡頭切換。
jump cuts（跳接）：叢林場景有大量 jump cuts，是花最多嘗試的原因之一；字幕未進一步解釋。
POV（第一人稱視角）：以主角的眼睛呈現，要鏡頭「像他的眼睛」。
multi-shot（多鏡頭一次生成）：一個 prompt 包含多個動作與鏡頭；POV 場景用這方法失敗，改成只做單一鏡頭。
skills（技能（Claude 用））：其餘鏡頭的做法是使用 skills、描述場景、放入 asset；字幕未進一步解釋。
canvas（畫布）：放置該場景所有素材（location、望遠鏡、騎士）的地方；字幕未進一步解釋。
