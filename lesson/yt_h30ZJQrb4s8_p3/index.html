🧑‍🏫 這段接著幫甜甜圈上貼圖。重點有三個：糖霜為什麼要重新攤平（UV unwrap）、怎麼把掃描來的真實糖霜和甜甜圈套上去，以及怎麼用 displacement 讓表面真的凹凸起來。看完會懂貼圖歪掉的原因，也會知道掃描貼圖套上後，哪些設定要自己接手調整。

  • 21:17 盤子套用貼圖後的效果已經很適合盤子；也可以把 scale 調小一點，讓圓點變大。整個流程非常簡單
    ↳ 盤子套上貼圖後已經很像盤子了。想讓圓點變大，就把 scale（貼圖的縮放比例）調小，數字越小圖案越大。整個套貼圖的流程其實很簡單。
  • 21:17 回到 Layout，選取糖霜，按 N 叫出屬性面板，在 Textures: Free 分類中往下找 strawberry pink glaze 貼圖
    ↳ 回到 Layout（Blender 主要的編輯畫面），選取糖霜，按 N 打開側邊面板，在免費分類「Textures: Free」往下找 strawberry pink glaze（草莓粉紅糖霜）這張貼圖。
  • 21:17 這張 strawberry pink 貼圖的製作方式：把糖霜倒進鍋子，再用 stereoscopic scanner 從各個角度掃描
    ↳ 這張貼圖不是手繪的。做法是把糖霜真的倒進鍋子，再用 stereoscopic scanner（立體掃描器，從多角度拍攝來還原立體形狀）從各個角度掃描。
  • 21:49 這樣掃描可以取得高度資訊，例如糖晶體冒出來形成的小凸起
    ↳ 從多角度掃描的好處，是除了顏色還能抓到表面的高低。例如糖結晶冒出來的小顆粒，這些凹凸資訊都會存進貼圖裡。
  • 21:49 按 Apply 後糖霜上已經看得到紋理，盤子剛套用時卻什麼都沒有
    ↳ 按 Apply（套用）後，糖霜馬上看得到紋理；但前面盤子剛套用時卻什麼都沒出現。兩者差在哪，下一點會說明。
  • 22:19 差別的原因：torus 等部分 primitive 加進來時就已經建好 UV unwrapping，所以糖霜本來就有 UV
    ↳ 差別在 UV unwrapping（把立體模型攤平，對應到貼圖的座標）。torus（甜甜圈形狀的基本模型）這類 primitive（內建基本形狀）一加入就附帶 UV，所以糖霜本來就有 UV。
  • 22:19 既有的 UV 沒涵蓋後來的修改，包括底部往下 extrude 的部分，以及變得凹凸不平後的形變，所以要重新 UV unwrap，讓投影符合 mesh
    ↳ 但內建的 UV 是照原始形狀做的。糖霜後來往下 extrude（擠出延伸），又被改得凹凸不平，舊 UV 對不上新形狀，貼圖會拉歪，所以要重新展開。
  • 22:19 思考方式：把 mesh 想成一張紙，要攤平鋪在左側的貼圖上，這時切口該放在 mesh 的哪裡？
    ↳ 核心想法是：把模型想成一張紙，要攤平鋪在左邊的貼圖上。立體的東西不剪開就攤不平，所以要先想好剪刀該剪在哪裡。
  • 22:54 糖霜的第一刀切在邊緣。Alt+點擊那條邊可以選取一整圈，請確認有繞完整圈，否則下一步結果會怪怪的
    ↳ 第一刀剪在糖霜邊緣。按住 Alt 點那條邊，會一次選取整圈相連的邊。一定要確認整圈都有選到，中間斷掉的話，下一步展開會變形。
  • 22:54 選好之後按 Ctrl+E，再選 Mark Seam，就完成一道切口
    ↳ 選好後按 Ctrl+E，選 Mark Seam（標記接縫），就等於在這裡畫下一道「從這裡剪開」的線。
  • 23:26 切到 wireframe 模式並關掉選取，會看到一條紅線，那就是 seam；旁邊的紫線則是先前用 solidify 讓糖霜貼合甜甜圈時加的 crease
    ↳ 切到 wireframe（只顯示線框的模式）並取消選取，紅線就是剛做的 seam。紫線是 crease（折痕標記），是之前用 solidify（替模型加厚度）貼合甜甜圈時加的。
  • 23:26 做完 seam 外觀還不會變，因為還沒 UV unwrap
    ↳ 標完接縫，外觀不會有任何變化。因為現在只是畫好剪裁線，還沒真正攤開，要等下一步 UV unwrap 才會生效。
  • 23:57 甜甜圈內側正中間還要再切一刀：先隨便選內側一點，按 focus 鍵（tilde 3 或數字鍵盤的句點）拉近
    ↳ 甜甜圈內圈正中間還要再剪一刀。先隨便點內側一個點，按 focus 鍵（字幕說是 tilde 3 或數字鍵盤的句點）把畫面拉近過去，比較好操作。
  • 23:57 一樣按住 Alt 選取那一圈線，再按 Ctrl+E 做第二道 seam
    ↳ 一樣按住 Alt 點選內圈整圈邊，再按 Ctrl+E → Mark Seam，做出第二道接縫。
  • 23:57 接著選取整個 mesh，按 U 選 unwrap angle based。這次運算特別久，講者說他從沒看過卡這麼久
    ↳ 接著全選整個模型，按 U 選 unwrap angle based（依角度計算的一種展開方式）正式攤平。這次算得特別久，講者說他從沒看過卡這麼久，遇到不用慌。
  • 24:28 結果幾乎完美。攤開的樣子很平，像一張牛皮地毯
    ↳ 結果幾乎完美，攤開後又平又整，形狀像一張牛皮地毯。這代表兩刀剪的位置選對了。
  • 25:00 拉伸一定會有，不可能完美，只要拉伸量很小就算很好了
    ↳ 立體攤平一定會有 stretching（拉伸，也就是貼圖被拉長或擠壓）。就像橘子皮壓平一定會變形，只要拉伸很少就算成功。
  • 25:00 切到 material view 會看到原本的拉伸消失了，貼圖已正確 map 到整個糖霜，連內側都有
    ↳ 切到 material view（顯示材質的預覽模式），原本拉歪的地方不見了，貼圖正確包住整個糖霜，連內側都貼好了。
  • 25:30 貼圖 scale 可能不對。講者習慣先點上方的小方框關掉 overlays，連選取狀態都看不到，再來調整 scale 大小
    ↳ 貼圖大小可能還不對。講者習慣先點上方的小方框關掉 overlays（疊在畫面上的格線、選取框等輔助顯示），畫面乾淨了再調 scale。
  • 25:30 糖霜看起來偏淡偏粉的原因：按下套用時，貼圖覆寫了原本的材質
    ↳ 糖霜變得偏淡、偏粉，是因為按下套用時，貼圖把原本自己設好的材質蓋掉了。
  • 26:04 到 Shading 分頁可以看到，原本 base color 的粉紅色被相機拍到的草莓色取代了，但這個顏色比講者想要的淡
    ↳ 在 Shading 分頁（編輯材質節點的畫面）可以看到，原本 Base Color（物體的基本顏色）的粉紅，被相機拍到的草莓色取代，而這個顏色比講者想要的淡。
  • 26:04 所以把 color 斷開。這類材質的顏色資訊不多，資訊全在 bump 裡
    ↳ 所以把貼圖的顏色連線斷開，改回自己調色。這類糖霜貼圖的價值不在顏色，而在 bump（記錄表面細微凹凸的資訊）。
  • 26:34 metallic 用不到（裡面一定沒有金屬）；roughness 保留；subsurface amount 斷開以便自己控制。最後只留 roughness 和 normal
    ↳ metallic（金屬感）用不到；roughness（粗糙度，決定亮面或霧面）保留；subsurface amount（光透入的程度）斷開自己調。最後只留 roughness 和 normal（凹凸貼圖）。
  • 26:34 斷開節點連線的方法：按住 Ctrl 再按右鍵拖曳，就能切斷連線
    ↳ 斷開節點連線的方法：按住 Ctrl，再用滑鼠右鍵拖曳劃過那條線，就能像用刀一樣切斷。
  • 27:05 也可以直接點連接點再拉開來斷開，但講者偏好 Ctrl+右鍵拖曳
    ↳ 也可以直接點住連接點把線拉開。講者比較喜歡 Ctrl+右鍵拖曳，兩種都可以，挑你順手的。
  • 27:05 接著把數值設回之前的樣子：用目測挑好看的粉紅色，設定 subsurface amount，radius 設 1，再調 scale 到好看
    ↳ 斷開後把數值設回來：用眼睛挑好看的粉紅色，設定 subsurface amount，radius（光在內部擴散的距離）設 1，再把 scale 調到好看。
  • 27:05 成果：粉嫩的甜甜圈，加上會起泡的糖晶體、真實的糖霜質感
    ↳ 成果是粉嫩的甜甜圈，糖霜上有冒泡般的糖結晶，質感很真實。做法是顏色自己調、凹凸用掃描資料，兩者分工。
  • 27:39 接著處理甜甜圈本體。講者錄影前請團隊掃描一個真的甜甜圈（繞一整圈），map 到 torus 上，再取出資料
    ↳ 接著做甜甜圈本體。講者錄影前請團隊把一個真的甜甜圈繞一整圈掃描，對應到 torus 形狀上，再把資料取出來做成貼圖。

    ↳ 這份資料本來就是照 torus 的 UV 做的，跟內建 torus 對得上，所以直接 Apply 就會自動貼好，不用自己展開。
  • 28:14 套用後顏色好看、bump 也不錯，把糖霜顯示回來看效果已經很好

📘 術語
UV unwrapping（UV 展開）：把 mesh 像紙一樣攤平鋪在貼圖上，讓投影符合 mesh
primitive（基本幾何物件）：例如 torus；部分 primitive 加入時就已建好 UV unwrapping
torus（圓環體）：甜甜圈的基底形狀，加入時已附帶 UV
Mark Seam（標記接縫）：按 Ctrl+E 選它，等於在 mesh 上切一刀；wireframe 下顯示為紅線
crease（摺痕）：先前用 solidify 讓糖霜貼合甜甜圈時加的，顯示為紫線
solidify（加厚）：字幕只提到之前用它讓糖霜更貼合甜甜圈
wireframe mode（線框模式）：用來檢查 seam 紅線的顯示模式
unwrap angle based（依角度展開）：選取整個 mesh 後按 U 所選的展開方式
stretching（拉伸）：展開一定會有，不可能完美，量很小就算好
focus key（聚焦鍵）：tilde 3 或數字鍵盤的句點，用來拉近到選取的點
overlays（疊加顯示）：點上方小方框可全部關掉，連選取狀態都看不到
stereoscopic scanner（立體掃描器）：從各角度掃描倒進鍋裡的糖霜，取得高度資訊
Base Color（基礎顏色）：原本的粉紅色被相機拍到的草莓色覆寫了
bump（凹凸）：糖霜這類材質的資訊全在 bump 裡，顏色資訊不多
normal（法線（貼圖））：紫色的那張，是目前一直用來製造凹凸的方式
roughness（粗糙度）：講者選擇保留的貼圖連線之一
metallic（金屬度）：糖霜裡一定沒有金屬，所以用不到
subsurface amount / subsurface scattering（次表面散射）：被貼圖覆寫後要斷開並自己重設，例如設成 1
displacement map（置換貼圖）：另一種製造凹凸的方式，套用時預設沒接上
Displacement and Bump（置換與凹凸）：material properties 最下方 Displacement 要改成的選項
Subdivision Surface（細分曲面）：在 modifier 面板加入以增加幾何，讓 displacement 有足夠資料
Poliigon add-on（Poliigon 外掛）：用來套用貼圖的外掛；下一版會加入 displacement type 選項
Cycles（Cycles 算圖引擎）：目前在這裡已看得到 displacement type 選項
EEVEE（EEVEE 算圖引擎）：才剛加入啟用 displacement 的功能，add-on 還沒支援
