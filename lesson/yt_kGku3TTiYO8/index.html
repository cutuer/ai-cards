📘 術語
spec ad（自發提案廣告）：字幕未明確解釋；影片中指作者用自選產品，以 AI 製作的廣告
scroll stopper（滑動攔截畫面）：影片的 hook，要在前 5 秒左右讓正在滑手機的人停下來
hook（開場鉤子）：影片開頭吸引注意力的段落，即 scroll stopper
character sheet（角色設定表）：作者把自己的 character sheet 放入生成工具，用來產生畫面中的角色
timeline prompt（時間軸提示詞）：在 prompt 中說明什麼時間點發生什麼事
LLM（大型語言模型）：字幕舉例 GPT-4、Claude；建議先自己想點子，再用它們強化
lookbook（風格參考集）：從 Pinterest、Shotdeck、film.ai 收集喜歡的畫面與風格，彙整成一份參考
visual style reference prompt / style block（視覺風格提示詞區塊）：讓 AI 分析參考圖的光線與色彩後產生的風格 prompt，可放進每個 prompt
skill（技能檔）：作者提供下載，放進 Cloth 或 ChatGPT，輸入參考圖後即可寫出 style block
product sheet（產品設定表）：類似 character sheet，含多個視角、特寫、包裝細節與大約尺寸，用來維持產品一致性
ad multiplier（廣告倍增工具）：Higgsfield 的工具，可替換廣告中的產品口味或角色，複製出多支廣告
MCP（MCP）：把 Higgsfield MCP 連到 Claude 後，就能用它複製廣告、寫 prompt、生成影片
