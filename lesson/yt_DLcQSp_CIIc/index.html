📘 術語
ChatGPT Work（ChatGPT Work（工作模式））：在電腦上使用時，ChatGPT 不只對話，還能實際開始任務、把事情做完
Voice（語音模式）：用說話和 ChatGPT 互動；在 Work 裡可用來下指令、執行任務
Work tab（Work 分頁）：ChatGPT desktop app 裡的分頁，Voice 從這裡啟動
desktop app（桌面應用程式）：ChatGPT 的電腦版程式；片中這個版本的 Voice 在這裡執行
keyboard shortcut（鍵盤快捷鍵）：除了 Voice 按鈕以外，另一種啟動 Voice 的方式
Dev Day activation（Dev Day 現場活動企劃）：片中發想的主題，例如用 Game Boy 控制 Codex、T 恤設計攤位等
Codex（Codex）：字幕未定義；片中點子是用 Game Boy 控制它，或讓參與者用它為遊戲加入角色、關卡、音效
image generation（圖像生成）：片中用來設計 T 恤，以及製作簡報裡的概念圖
pitch deck（提案簡報）：片中請 ChatGPT 製作的視覺化簡報，用來呈現各個點子
OpenAI Slides template（OpenAI Slides 範本）：製作 pitch deck 時指定使用的投影片範本
connected tools（已連接的工具）：ChatGPT 開始任務時可以使用的、使用者已連接的工具

Remote（Remote（遠端連接））：把手機連接到電腦的方式，連上後就能從手機點按鈕啟動 Voice
