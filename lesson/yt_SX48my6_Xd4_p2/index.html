🧑‍🏫 這段是 BCON26 的實作示範：講者用 Blender 的 Grease Pencil，搭配筆刷、modifiers、遮罩和填色，快速畫人物、岩石和環境配色。重點不是做精緻成品，而是教你用最快的速度把腦中的畫面丟上畫布，拿去測試、拿去給人看。

  • 12:03 帶學員操作時要留意，他們可能誤點進 vertex painting 等模式。Blender 功能很多，初學者容易不知所措
    ↳ 帶新手上手時要注意：Blender 功能超多，新手常不小心切進 vertex painting（直接在模型頂點上塗顏色的模式）這類模式，畫面一變就慌了，旁邊要有人幫忙拉回來。
  • 12:35 姿勢可以自由擺，這是善用手邊現有素材的好方法
    ↳ 現成的人體模型可以隨意調姿勢，不用每次重做。手上已有的素材擺一擺，就能變成新的參考畫面，省下很多準備時間。
  • 13:08 用較大、紋理感強的筆刷模仿幾年前的酷炫效果。不必從零建模，直接用 human base meshes
    ↳ 講者用大尺寸、紋理明顯的筆刷，直接畫在 human base meshes（現成的基本人體模型）上，重現幾年前流行的手繪感 3D 效果，不必自己從頭建模。
  • 13:08 記得要 draw on surface。上方可選 draw at origin、draw at 3D cursor、draw at surface，或 draw to existing stroke 接在既有筆畫上
    ↳ Grease Pencil 是 Blender 裡能在 3D 空間畫筆畫的工具。下筆前要選筆畫落在哪：原點、3D 游標、模型表面，或接在舊筆畫上。要貼著模型畫就選 surface。
  • 13:41 從第二個攝影機視角，可以看到筆畫在最終 render 的呈現
    ↳ 筆畫是真的貼在 3D 模型上，所以換到另一台攝影機看，就能確認最後 render（算出成品畫面）時筆觸長什麼樣，不會只有一個角度好看。
  • 13:41 練習辨識光線從哪裡來。vizdev 很強大，lighting 是增加氛圍與情緒最重要的事之一。能透過形狀理解形體就贏了
    ↳ vizdev（視覺開發，前期決定作品長相的階段）很有用。多練習判斷光從哪打來，因為光線最能決定氣氛和情緒；看懂明暗怎麼塑造形狀，就抓到形體了。
  • 14:14 某支筆刷能畫出漂亮的斑塊（splotches），可用在人物，也能用在樹木等植物
    ↳ 有一支筆刷畫起來會自然出現斑點色塊，塗在人物身上好看，拿來畫樹葉、草叢這類植物也很適合，一支筆能用在很多地方。
  • 14:14 有人用墨水風格探索中國畫與日本 sumi ink 的紋理元素
    ↳ 有人用墨水風格的筆刷，去試中國水墨畫和日本 sumi ink（日本書畫用的墨）那類紋理，代表這套工具不只能做寫實，也能玩東方畫風。
  • 14:47 bristle brush 很適合用來找出、標示解剖結構
    ↳ bristle brush（模仿硬毛刷、筆觸會分岔的筆刷）很適合在模型上找出骨頭、肌肉的位置並做記號，等於直接在 3D 人體上做解剖筆記。
  • 15:18 解剖標示範例：seven cervical、ASIS。模型上有些部位與實際肌肉連接點吻合，有些不吻合
    ↳ 例如標出第七頸椎（seven cervical，低頭時後頸凸起的那節）和 ASIS（髂前上棘，腰側前方摸得到的骨盆突點）。現成模型有些部位跟真人肌肉接點對得上，有些對不上，要留意。
  • 15:18 pectoralis 附著到 humerus，共有三個部分，像扇子一樣彼此交疊
    ↳ 胸大肌（pectoralis）附著在上臂的肱骨（humerus）上，分成三塊，像打開的扇子一片疊一片。所以畫胸口要想成三片交疊，不是一整塊。
  • 15:50 pectoralis 三部分：一部分一路連到下方，一部分連在 sternum，還有一小部分連到 clavicle
    ↳ 這三塊的另一端各接不同地方：一塊一路往下延伸，一塊接在胸骨（sternum），還有一小塊接到鎖骨（clavicle）。
  • 15:50 在 Grease Pencil 裡可以替筆畫加 modifiers，這點用在環境上也很酷
    ↳ modifiers（修改器，疊在物件上、可隨時關掉或調整的效果）也能套在 Grease Pencil 筆畫上，自動改變筆畫的樣子。講者覺得拿來畫環境特別好玩。
  • 16:25 講者認為（自稱可能有誤）studio team 為 Project Gold、後來 Singularity 開發的 brush strokes add-on，筆刷引擎也是類似做法
    ↳ 講者自己說不太確定，但他認為 Blender studio 團隊替 Project Gold、之後的 Singularity 做的 brush strokes add-on（外掛），背後的筆刷做法跟這裡類似。
  • 16:25 可把功能性的作品（如 anatomy study）加上大量 modifiers，變成滿意的成品
    ↳ 原本只是練習用的東西，像解剖習作，疊上一堆 modifiers 之後就能變成拿得出手的作品，練習和成品不用分兩次做。
  • 16:25 接著示範快速岩石研究，用於 projection mapping
    ↳ 接下來換題材，快速畫一顆岩石，示範怎麼做成 projection mapping（把畫好的圖從攝影機方向投射到簡單模型上）要用的素材。
  • 16:59 projection mapping 能很快完成不需從各角度觀看的東西。之所以知道不需要，是因為 previz 做得好，已確認攝影機固定
    ↳ projection mapping 適合做「只會從一個角度看」的東西，很快就能完成。敢這樣省工，是因為 previz（正式製作前的粗略預演）已經確認這個鏡頭的攝影機不會動。
  • 16:59 講者研究 anime 發現其攝影機很少移動。即使同一鏡有多角度，也可建好環境後移動攝影機換角度
    ↳ 講者研究日本動畫，發現鏡頭很少移動。就算同一場戲有好幾個角度，也可以先把場景搭好，再把攝影機搬到新位置拍下一個角度。
  • 17:29 攝影機偶爾移動時可能非常突兀
    ↳ 反過來說，動畫裡攝影機偶爾突然動起來的時候，常常會讓人覺得很突兀、跟前後畫面接不起來。
  • 17:29 較成功的 3D anime pipeline 會移除攝影機移動的 keyframes，讓畫面感覺更舊、更 jaggedy
    ↳ keyframe 是標記某個時間點數值的動畫記號。做得好的 3D 動畫 pipeline（製作流程）會刪掉攝影機移動的 keyframe，讓鏡頭動得一格一格、有點卡，更有舊式動畫的味道。
  • 17:29 岩石示範要展示 oil painting brush，以及 Grease Pencil 的 masking，講者說它非常多用途
    ↳ 岩石示範有兩個重點：一是很漂亮的 oil painting brush（油畫筆刷），二是 Grease Pencil 的 masking（遮罩），講者說遮罩的用途非常廣。
  • 17:59 建議去健行拍上萬張岩石照片。要理解形體與形狀，沒有比畫岩石更好的方法
    ↳ 講者建議去健行，狂拍岩石照片當參考。要練習看懂體積和面向，畫岩石是最好的方法。
  • 17:59 步驟：在 linework 草圖上新增 layer，命名為 shape。把 strength 停用並拉到最高，再選基礎色
    ↳ 在線稿上方開一個新 layer（圖層，像疊一張透明片）叫 shape，把 strength（筆畫濃度）照講者的設定停用並拉到最高，讓色塊塗得實，再選底色。
  • 18:33 刪除預設 palette，只用少數幾個顏色（也教給你的 2D 朋友）
    ↳ 把預設的 palette（調色盤）刪掉，只留幾個顏色。顏色少，畫面比較統一，下決定也快；這招教給畫 2D 的朋友一樣好用。
  • 18:33 linework 若畫得整齊，可直接用 gradient fill，這是新功能。手動上色則能保留筆刷紋理，更有手工感
    ↳ 線稿如果畫得乾淨，可以直接用新的 gradient fill（漸層填色）上色；自己手動塗會留下筆刷紋理，比較有手作感。看需求二選一。
  • 19:05 再新增一層命名為 details，並替它加上 mask
    ↳ 再開一個新圖層叫 details，替它加上 mask（遮罩，讓內容只在指定範圍內顯示）。
  • 20:00 這個 mask 會「擷取」shape 的形狀，之後加的高光和陰影都會留在 mask 範圍內
    ↳ 這個 mask 會拿 shape 圖層的輪廓當範圍，之後在 details 上畫亮面、暗面，都只會出現在岩石裡面、不會塗出界，像先貼好紙膠帶再上色。
  • 20:33 這種做法適合 projection mapping 與單鏡前景元素。依工作流程不同，可能比較快，也可能不會
    ↳ 這種畫法很適合 projection mapping，或只出現在單一鏡頭裡的前景物件。至於會不會比較快，要看你原本的工作流程。
  • 20:33 判斷點子好不好，最快的方法就是畫出來，這是把腦中想法放到畫布上最快的方式
    ↳ 想知道點子好不好，別只在腦中想，直接畫出來最快。畫出來才看得到它到底行不行。
  • 21:40 previs 常見環境色彩研究（color studies）。新增幾個 layer，暫時命名 base layers，這次改用 fills
    ↳ previs 階段常做環境的色彩研究（color studies，用不同配色試畫面氣氛）。先開幾個圖層，暫時叫 base layers，這次改用 fills（填色）來畫。
  • 21:40 講者稱這方法為 Poor Man's Loish。Loish 即 Lois van Baarle，住在 Utrecht，她的作法之一就是用 fills
    ↳ 講者戲稱這招叫「窮人版 Loish」。Loish 是住在荷蘭烏特勒支的插畫家 Lois van Baarle，她的畫法之一就是用大塊填色。
  • 22:13 使用預先選好的 palette，這個方法要確保 transparency 關閉，然後直接畫出大塊形狀
    ↳ 先準備好選定的調色盤，確認透明度關掉，讓每塊顏色都完全不透明，然後直接畫出大塊形狀，先不管細節。
  • 22:46 一開始看起來很塊狀，但搭配 partial transparency 能增加趣味，畫面仍統一好看
    ↳ 剛畫完會很塊、很平。接著疊上部分透明的顏色，層次就出來了，畫面變有趣，整體仍然統一好看。
  • 22:46 關鍵是速度，因為目的是測試點子行不行得通
    ↳ 關鍵是快。這個階段只是要測試點子能不能成立，不是做精緻的完成圖。
  • 23:16 在商業製作或大型 pipeline 中，能早點讓人看到你的構想並取得回饋
    ↳ 在商業案子或大型製作流程裡，越早把構想拿給別人看，就能越早拿到回饋，少走冤枉路。
  • 23:16 回饋例子：導演可能說想要偏暗、偏 techno 的配色，而不是較 pastel 的配色
    ↳ 例如導演看了可能說：「我要暗一點、偏 techno 感的配色，不要這種粉嫩的 pastel 色。」早點聽到這句，就不會在錯的方向上畫完一整張。
  • 23:49 啟用 partial transparency 並調低數值，就能在大色塊上加入形體
    ↳ 最後打開 partial transparency（部分透明），把數值調低，在大色塊上疊出半透明的明暗，形體和立體感就慢慢出來了。
📘 術語
Grease Pencil（蠟筆（Blender 繪圖工具））：字幕未定義。提到可在 3D 中畫筆畫、加 modifiers、做 masking
vertex painting（頂點繪製）：字幕未解釋，只提到學員可能誤點進去
human base meshes（人體基礎網格）：可直接拿來用，不必從頭建立整個模型
draw at surface / 3D cursor / origin（繪製位置選項）：可選在原點、3D 游標、表面上畫，或接到既有筆畫
vizdev（視覺開發）：字幕只說它非常強大，並強調 lighting 能增加氛圍與情緒
previz / previs（預視覺化）：字幕未定義。提到靠 previz 得知攝影機固定，previs 常見環境色彩研究
bristle brush（鬃毛筆刷）：適合用來找出、標示解剖結構
oil painting brush（油畫筆刷）：講者認為很漂亮，用在岩石示範
modifiers（修改器）：在 Grease Pencil 中可加在筆畫上，把習作變成更好看的成品
projection mapping（投影貼圖）：快速製作不需從各角度觀看的東西的簡單方法，適合固定攝影機
keyframes（關鍵影格）：3D anime pipeline 會移除攝影機移動的 keyframes，讓畫面更舊、更 jaggedy
layer（圖層）：示範中新增並命名為 shape、details、base layers
palette（調色盤）：建議刪掉預設 palette，只用少數顏色
gradient fill（漸層填色）：新功能。linework 整齊時可直接使用
mask（遮罩）：會擷取 shape 的形狀，讓高光與陰影留在範圍內
fills（填色）：Poor Man's Loish 方法用 fills 畫大塊形狀做色彩研究
partial transparency（部分透明）：開啟並調低後可加入形體、增加趣味且保持統一
