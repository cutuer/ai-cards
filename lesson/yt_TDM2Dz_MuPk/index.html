🧑‍🏫 這支影片是美國家具家飾電商 Wayfair 分享，他們怎麼用 OpenAI 的模型，把 4,000 萬件商品的資料補齊、整理好。它的價值在於說明 AI 不只能拿來聊天，也能接手人力做不完的大量資料工作。

  • 00:01 Wayfair 很期待導入 Codex，打算把它用在公司還沒想出解法的難題上
    ↳ Codex 是 OpenAI 推出的 AI 工具，專門幫忙寫程式、處理軟體開發工作。Wayfair 不只想用它做例行小事，還打算拿它挑戰公司自己都還沒找到解法的難題。
  • 00:01 Wayfair 和 OpenAI 合作最有影響力的方式之一，是他們的 catalog enrichment program（商品目錄資料充實計畫）
    ↳ catalog enrichment（商品目錄資料充實）就是把每件商品的資料補齊、修正，例如尺寸、材質、風格標籤。Wayfair 認為，這是他們跟 OpenAI 合作之中效果最明顯的一塊。
  • 00:01 目標是把供應商提供的商品呈現得盡量準確，也盡量完整
    ↳ 供應商給的資料常常零散、有缺漏，寫法也不統一。這項計畫的目標，是讓網站上的商品頁把東西講對、講完整，顧客才不會買錯，也不會找不到想要的商品。
  • 00:32 Wayfair 用 OpenAI 的模型和 API 支撐目錄資料充實計畫的一大部分；影片中說「是模型在驅動我們」
    ↳ API 是讓公司自己的系統直接呼叫 AI 模型的接口，不用有人一筆筆貼進聊天視窗。這項計畫有很大一部分是模型自動在跑，他們甚至說是模型在推著他們前進。
  • 00:32 這種規模的工作量，根本不會有人想用人工去做，所以影響很大
    ↳ 4,000 萬件商品就算一件只整理幾分鐘，靠人工也根本做不完，所以沒人會考慮用人力處理。AI 讓原本不可能做的事變得做得到，這就是它影響大的原因。
  • 00:32 成果讓所有顧客受益，供應商也同樣受益
    ↳ 資料完整之後，顧客比較容易搜到商品、好比較，買起來也比較放心；供應商的商品也更容易被找到、被買走。同一件事，讓買方和賣方都得到好處。
