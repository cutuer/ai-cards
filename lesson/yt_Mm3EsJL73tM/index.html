🧑‍🏫 這支影片講 Oracle 怎麼用 ChatGPT work 改造招募的第一步，也就是開缺前「搞清楚要找什麼人」的準備工作。值得看的是具體的時間差：這段準備以前要花好幾天，現在大約 20 分鐘就能完成。

  • 00:00 Oracle 用 ChatGPT work 打造了 talent market intelligence tool，徹底改變招募流程的前端
    ↳ ChatGPT work 是 Oracle 拿來打造工具的 ChatGPT 平台。他們用它做出 talent market intelligence tool，也就是「人才市場情報工具」，專門處理招募一開始的準備階段。
  • 00:00 這個工具把各自分散的洞察收集起來，讓品質與做法一致，再提供給 hiring managers 和 TAs，讓大家用同一種方式做事
    ↳ 以前每個人各自查資料，各有一套判斷，品質參差不齊。這個工具把大家的洞察集中起來，交給用人主管和 TA（通常指負責招募的團隊）使用，讓所有人從同一個起點出發。
  • 00:00 流程第一步是從一份 job description 開始
    ↳ job description 就是職缺說明，寫清楚這個職位要做什麼、需要什麼條件。使用這個工具時不必從零開始，先把這份說明放進去就好。
  • 00:35 接著用他們自建的 GPT 搜尋多個外部來源，找出市場上類似的職缺，以及競爭對手的做法
    ↳ GPT 在這裡指 Oracle 在 ChatGPT 裡自己建立、設定好固定任務的專用助手。它會拿職缺說明去多個外部來源找類似職缺，看看市場上和競爭對手是怎麼開這類職位的。
  • 00:35 招募前端要和 hiring manager 坐下來蒐集需求，過去通常要花 2、3、4 天準備，現在只要約 20 分鐘，搭配 work 和自建的 GPT 就能完成
    ↳ hiring manager 是提出用人需求、之後會帶這個人的主管。招募人員得先和他坐下來對齊需求，以前光準備就要兩到四天，現在靠這套工具約 20 分鐘就能準備好。
  • 01:05 這套做法改變了 Oracle 進行人才搜尋的方式，範圍涵蓋 executive search 到 professional search
    ↳ executive search 是找高階主管，professional search 是找一般專業人才。意思是這套做法不只用在少數職位，從高層到一般專業職，Oracle 找人的方式都跟著改變了。
📘 術語
ChatGPT work（ChatGPT work）：Oracle 用來打造 talent market intelligence tool 的工具
talent market intelligence tool（人才市場情報工具）：Oracle 自建的工具，用來改造招募流程前端，彙整分散的洞察給招募相關人員使用
GPT（自建 GPT）：Oracle 自己建立的 GPT，可以根據職缺描述搜尋多個外部來源的同類職缺與競爭對手做法

TA（TA）：字幕沒有說明全名，只提到 TAs 和 hiring managers 都會拿到工具彙整的洞察
