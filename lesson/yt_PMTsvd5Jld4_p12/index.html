🧑‍🏫 這段直播示範一個小團隊怎麼從零開始想一門生意。他們想做一個幫人辦臨時餐飲活動的平台，過程中用 Grok Bot 找網頁設計參考、做出網頁初稿。後半段有來賓 Peter 分享創業建議，重點是先確認有人願意付錢，再把東西做大。對想用 AI 把點子變成實際成果的人，這段從怎麼跟 AI 溝通，到怎麼驗證點子，都講得很具體。

  • 131:20 講者的 prompt 習慣：先把高品質的 context 放進對話，再開始做原型
    ↳ prompt 就是你打給 AI 的指令。講者的習慣是先把 context（背景資訊，例如要做什麼、給誰用）交代清楚，再請它做原型，不會一開口就叫它生東西。
  • 131:20 做 landing page 前，先問 bot 有哪些好的 landing page 設計來源並找參考，挑選後拼成 mood board，再開始做自己的頁面
    ↳ landing page 是對外介紹產品或活動的單一網頁。先請 bot 找好看的範例，挑出喜歡的拼成 mood board（風格參考拼貼板），先定好想要的風格再動工。
  • 132:21 點子：打造一個 pop-up 平台，同時 dog food，也就是用自己的平台辦自己的 pop-up
    ↳ pop-up 是在某個城市短期辦的餐飲活動。點子是做一個幫人辦 pop-up 的平台，而且自己先用它辦一場。這叫 dog food，自己當第一個使用者，最快發現哪裡不好用。
  • 132:53 Grok Bot 已找到幾個優秀 landing page 的 gallery，接著讓它挑幾個設計方向，再選看起來最好的
    ↳ gallery 是收集優秀網頁設計的展示網站。Grok Bot 已經找到幾個，接著請它整理出幾種設計方向，團隊再從中挑最順眼的。
  • 133:55 討論是否需要兩個 landing page：一個給平台（有意經營餐飲的人），一個給自己的 pop-up（來買薯條的人）
    ↳ 兩群人要的資訊不一樣：想辦活動的人關心平台能幫他什麼，來買薯條的人只想知道時間地點。塞在同一頁，兩邊都講不清楚，所以考慮分成兩頁。
  • 134:25 目前還沒決定賣什麼食物；第一步是找場地等資源，頁面要看起來可信，說明在做什麼、連結哪些人、辦什麼活動
    ↳ 連要賣什麼都還沒決定，但不影響開始動。第一步是找場地這類資源，所以頁面要先讓人信得過，清楚說明在做什麼、要串連哪些人、辦什麼活動。
  • 134:56 不必一開始就把全部東西做出來：可以先做 outreach，例如寄 email、收集資訊，在寫軟體前先用人工流程跑
    ↳ outreach 是主動聯絡潛在的合作對象。不用先把系統寫好，可以先寄信、用手整理回覆，靠人工把流程跑一遍，確定有人要，再做成軟體。
  • 135:27 寫文件釐清方向對 bot 很重要：context 就是資訊，要把每個人腦中的資訊交給 bot
    ↳ bot 只知道你告訴它的事。團隊每個人腦中的想法它都看不到，所以要寫成文件交給它。方向寫得越清楚，它越不會亂猜。
  • 135:58 prompt 技巧：開麥克風講幾分鐘，最後請 bot「用你自己的話重述我剛說的」，確認它有理解，比自己重讀整段文字快
    ↳ 打字太慢就直接用講的。講幾分鐘後，請 bot 用自己的話重述一次，聽它的版本就能馬上發現哪裡被誤會，比自己回頭讀一大段文字快。
  • 136:28 bot（Steve）的重述：平台幫人在自己的城市辦食物 pop-up，是軟體加營運；需要不只一個對外頁面，而不是一個超大頁面
    ↳ Steve 是這個 bot 的名字。它的重述抓到兩個重點：這門生意不只是軟體，還包含實際營運；對外要分成幾個頁面各講各的，不是做一個什麼都塞的大頁面。
  • 136:28 需要的頁面：給專業人士、餐飲業者、想辦 pop-up 的營運者的平台頁，以及自家 pop-up 活動頁（也許辦個神祕 pop-up）
    ↳ 一頁給想辦 pop-up 的專業人士、餐飲業者和營運者，說明平台能幫什麼。另一頁給自家的活動，甚至可以辦個神祕 pop-up，先不公開細節來吸引人。
  • 136:58 Steve 的建議：現在的瓶頸不是架一堆 landing page，而是第一個循環：找場地、找營運者和做菜賣菜的人，參加者之後再找
    ↳ bot 直接點出：現在卡住的不是網頁，而是怎麼把第一場活動辦起來。先搞定場地、負責營運的人和會做菜賣菜的人，客人之後再找。
  • 137:28 一邊跑 pop-up 這個循環、一邊為它打造的軟體，基本上就是公司本身，例如找人訂位、找場地、找主廚各需要軟體
    ↳ 邊辦活動，邊把卡住的環節做成工具：訂位一套、找場地一套、找主廚一套。這些工具累積起來，就是這家公司本身。
  • 137:58 兩種形式：體驗型（找倉庫、主廚，賣桌位，需要很多人力和準備）vs. 櫃檯販售型（例如賣薯條，負擔較低，也不太需要訂位）
    ↳ 體驗型像包下倉庫、請主廚、賣座位的晚宴，人力和準備都很重。櫃檯型像擺攤賣薯條，買了就走，門檻低，也不太需要訂位。
  • 138:29 建議把原型推出去部署、拿到 preview link，讓東西真的上線
    ↳ deploy（部署）是把做好的東西放上網路，部署後會拿到 preview link，就是別人點了就能看的預覽網址。重點是讓作品真的上線，不要只停在自己電腦裡。
  • 138:29 目前有三個設計方向：一個深色主題、兩個看起來很企業風，第三個講者個人不太喜歡
    ↳ prototype 是先做出來看效果的初稿。目前有三個設計方向，一個是深色系，兩個偏公司行號的正式風格，其中第三個講者自己不太喜歡。
  • 139:01 這些原型是 Grok Bot 做的，不是用 Cursor；Grok Bot 可以直接給 HTML，HTML 和 CSS 在 Grok Bot 裡直接呈現，不用部署到任何地方
    ↳ Cursor 是工程師常用的 AI 寫程式工具，但這些原型不是用它做的。Grok Bot 直接產出 HTML（網頁內容）和 CSS（外觀樣式），在對話裡就能看到畫面，不用另外架站。
  • 139:01 下一步是給 bot 回饋，調整這些設計
    ↳ 初稿出來不是結束。接下來要告訴 bot 哪裡喜歡、哪裡要改，一輪一輪把設計調到滿意。
  • 139:32 Peter 的建議：solopreneur 要把事業設計成多做自己真正喜歡的事；有些選擇賺更多錢，卻讓你做不喜歡的事，就違背創業的初衷
    ↳ solopreneur 指一個人創業的人。Peter 提醒，時間有限，事業要設計成讓你多做喜歡的事。某個選擇賺更多，卻逼你整天做討厭的事，就違背了當初創業的理由。
  • 140:34 找點子要盡快取得市場訊號；以前當 PM 時會有很多內部爭論、寫一堆文件，產品推出後才發現沒人要
    ↳ market signal 是市場給你的真實反應。Peter 當 PM（產品經理，負責決定產品要做什麼）時，常在內部爭論、寫文件，推出後才發現沒人要。所以要盡早拿到外部反應。
  • 140:34 要跟客戶談、看他們願不願意付錢；客戶可能只是客氣說點子不錯，要相信的是他們真的付錢
    ↳ 別人很容易客套說「不錯喔」，但那不算數。真正的證據是對方願意付錢，所以要直接跟客戶談，看他們肯不肯掏錢。
  • 141:04 不要太執著於點子：點子很廉價，團隊才是重要的
    ↳ 點子人人都有，一點都不稀奇。真正重要的是能把事情做出來、一起調整方向的團隊，所以不用死守一開始的點子。
  • 141:04 landing page 要讓對的人看到；直播聊天室的人不一定是我們要找的餐廳
    ↳ 網頁放上網不等於找對人看了。直播聊天室的觀眾多半不是要合作的餐廳，頁面要送到真正的目標客戶面前才有用。
  • 141:34 現在任何人都能做出任何東西，所以純軟體更難賺錢；沒有實體或服務成分時，別人為什麼要付錢買一個背後接資料庫的 landing page？
    ↳ SaaS 是靠訂閱收費的純軟體服務。現在人人都做得出網頁加資料庫，光賣這個很難收到錢。要有實體或服務的部分，別人才有理由付費。
  • 141:34 要真正測試市場，拿到第一塊錢
    ↳ 所有討論最後都回到同一件事：有沒有人真的付錢。賺到第一塊錢，才算真正測試過市場，比任何計畫都有說服力。
  • 142:05 人們願意為困難的事付錢，例如 Grok Bot 建議的找到餐廳、實際做菜，而不是只做 landing page
    ↳ 網頁誰都做得出來，找到肯合作的餐廳、真的把菜做出來賣，才是麻煩又費力的部分。人們願意付錢的，正是這種困難的事。
  • 142:36 Peter 表示，這是他第一個用起來像在跟有個性的人對話，而不只是一堆聊天串的產品
    ↳ Peter 說，這是第一個讓他覺得像在跟有個性的人對話的產品，而不只是一串串的聊天紀錄。
  • 142:36 Peter 給 Grok Bot 使用者的建議：讓 bot 更主動，例如追蹤 landing page 指標、開發餐廳客源，並設定每週 cron job 或排程任務定期回報
    ↳ cron job 是設定好時間就會自動執行的排程任務。Peter 建議讓 bot 更主動，例如每週自動追蹤網頁數據、開發餐廳客源，再主動回報進度。
📘 術語
landing page（到達頁／形象頁）：字幕沒有定義；用來對外介紹平台或 pop-up 活動的網頁
mood board（情緒板／靈感板）：開始做 landing page 前，把挑選的參考設計組合起來
dog fooding（自家產品自己用）：用自己的軟體實際辦一場自己的 pop-up
pop-up（快閃店／快閃活動）：在某個城市臨時辦的餐飲活動，可以是體驗型或櫃檯販售型
context（脈絡資訊）：講者說 context 就是資訊，要把大家腦中的資訊交給 bot
prototype（原型）：Grok Bot 做出的 landing page 設計初稿，目前有三個方向
preview link（預覽連結）：原型部署後可以分享、讓作品上線的連結
solopreneur（一人創業者）：Peter 說一人創業時間不多，應把事業設計成多做喜歡的事
market signal（市場訊號）：盡早跟客戶談，看他們是否真的願意付錢
PM（產品經理）：Peter 說以前當 PM 時常內部爭論、寫很多文件，推出後才發現沒人要
SaaS（軟體即服務）：純軟體現在太容易做，沒有實體或服務成分就難讓人付錢
cron job（排程工作）：讓 bot 每週定期執行任務並主動回報進度

影片中分享的 prompt 技巧：對著麥克風講完一大段話後，最後通常會請 bot 做什麼？

A. 把內容翻成英文再回答B. 直接開始寫程式碼C. 把內容整理成 cron job 排程D. 用自己的話重述剛才說的內容，確認它有理解
