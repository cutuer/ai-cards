看全部 4 條重點

🧑‍🏫 這支是 OpenAI 官方教學系列 OpenAI Academy 給新手的第一課，教你第一次怎麼問 ChatGPT。重點不是教你寫出完美的問題，而是讓你敢開始問、懂得追問，也知道哪些答案一定要再查證。

  • 00:06 可以把 ChatGPT 想成一位永遠有耐心的助理；可以打字提問，也可以直接說出來。答案不太對的話，就再問一次，第一次不用做到完美
    ↳ 不用先想好完美的問法才開口。隨便先問，答案不對就補充或換個說法再問，一來一往慢慢修正。它不會嫌你煩，問幾次都可以。
  • 00:06 介面上有訊息框可以輸入文字，也有語音輸入按鈕，按下後就能用說的，不必打字
    ↳ message box 就是輸入文字、打問題的那一格。voice input button 是語音輸入按鈕，按下去直接講話就能送出問題，懶得打字或手上在忙時很方便。
  • 00:36 示範提問：「給我三個這週使用 ChatGPT 的簡單點子」。不用每個點子都採用，挑最喜歡的就好，再接著追問「可以簡化一下並建議第一步嗎？」
    ↳ 它一次給好幾個點子時，當成菜單挑一個喜歡的就好，不必全部照做。挑好後再追問「簡化一點、第一步做什麼」，空泛的建議就會變成馬上能做的事。
  • 01:06 ChatGPT 可能出錯或提供過時資訊。跟健康、財務、重要期限或政府文件有關的問題，一定要找可信任的專家或官方來源確認
    ↳ 它講得很篤定不代表就是對的，資料也可能已經過時。看病、理財、繳費截止日、辦證件這類事，它的答案只能參考，最後一定要問專業人士或查政府官網。
📘 術語
message box（訊息框）：輸入文字的地方
voice input button（語音輸入按鈕）：按下後可以用說的輸入訊息，不必打字
✏️ 小考一題

影片提醒，哪一類問題的答案一定要找可信任的專家或官方來源確認？

A. 規劃菜單與旅遊行程的問題B. 健康、財務、重要期限或政府文件相關的問題C. 翻譯與語言學習相關的問題D. 所有跟寫程式有關的問題
看答案
答案：B。[01:06] 字幕說 ChatGPT 可能出錯或提供過時資訊，所以如果問題跟 health、finances、important deadlines 或 government documents 有關，一定要找 trusted experts 或 official sources 確認
