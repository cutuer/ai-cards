📘 術語
voice mode（語音模式）：以語音通話和 bot 對話；bot 之間也能在此模式中互相溝通，手機上也可使用
proactive bot / proactivity（主動式 bot／主動性）：示範者的 main bot 即為 proactive bot；proactivity 預設開啟，註冊後就已啟用
primary bot / main bot（主要 bot）：使用者主要使用的 bot，可用手機 action button 直接開啟語音對話
team bot（團隊 bot）：給團隊使用的 bot，可設定 managers 和 users 兩種角色
connector（連接器）：連接外部服務（例如 Microsoft Teams）的元件，可在 marketplace 瀏覽；建議多開啟
plug-in（外掛）：例如 X plug-in，在 connect apps 搜尋並授權後使用
marketplace（市集）：可搜尋並加入 connector 和 integration（例如 1Password）的地方
read-only mode（唯讀模式）：GrokBot 現在內建以唯讀模式連接 X，不需要 plug-in
RBAC（以角色為基礎的存取控制）：透過 managers／users 角色，細緻控制誰能編輯、誰能使用 team bot
managers（管理者）：可以編輯 team bot 的 skills、plug-ins、memories
users（使用者）：可以使用該 team bot、bot 會出現在其應用程式中的人
skills（技能）：team bot 的設定之一，由 managers 編輯；敏感的 skills 可限制只給特定成員
memories（記憶）：team bot 的設定之一，managers 可以手動編輯
1Password integration（1Password 整合）：連結 1Password 後選擇要分享的憑證，使用前 GrokBot 會徵求同意
cloud agents（雲端 agent）：工程任務中可透過 voice mode 請 bot 啟動（spin up）
PR（Pull Request）：字幕提到可請 bot 建立 PR、修改程式碼
GTM (go-to-market)（上市策略）：Ari 的 GTM Helper bot 能研究客戶帳戶、準備會議、整理訊號、找參考客戶
pre-read / one-pager（會前閱讀資料／一頁簡報）：Dana 要在 airport authority 會議前先讀的一頁文件
EOD（當天下班前）：字幕中 one-pager 的期限是 today EOD
action button（動作按鈕）：手機上的按鈕，講者設定成一按就開啟與 primary bot 的語音對話
