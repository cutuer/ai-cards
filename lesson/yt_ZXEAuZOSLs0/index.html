Ramp 的 AI DevEx 負責人分享 Codex code review 與 GPT-5.4 如何加快工程師的工作

看全部 6 條重點

🧑‍🏫 這支是 OpenAI 的客戶分享影片。美國金融科技公司 Ramp 負責 AI 工具的主管，講他們團隊怎麼用 Codex 檢查程式、處理難題。值得看的地方是它講的是真實團隊的具體改變：等別人檢查程式，從好幾個小時縮短到幾分鐘。

  • 00:02 Ramp 將 Codex code review 稱為業界黃金標準，工程師會指名要用，他們也已經用了很長一段時間
    ↳ Codex 是 OpenAI 做的寫程式 AI。code review 指程式放上線前，先請別人檢查有沒有錯。Ramp 說 Codex 做檢查是業界標竿，工程師會主動指定要用它，而且他們已經用很久，不是剛開始試。
  • 00:02 講者 Austin Ray 帶領 Ramp 的 AI DevEx 團隊
    ↳ DevEx 是 developer experience 的縮寫，意思是工程師做事順不順手。AI DevEx 團隊負責用 AI 讓公司工程師工作更省力。Austin Ray 是這個團隊的主管，所以他分享的是第一線的使用心得。
  • 00:02 他目前在做 on-call assistant，這是一個 AI 驅動的 on-call 助手，目標是幫工程師扛下大部分 on-call 負擔
    ↳ on-call 是輪流待命：系統出狀況時，值班工程師就算在半夜也要馬上處理。他正在做 on-call assistant，也就是 AI 值班助手，目標是讓 AI 扛下大部分值班工作，值班的人不用每件事都自己來。
  • 00:32 他形容 Codex 是很紮實的 harness，讓 agent 形式的 AI 能解決複雜問題、進行軟體工程工作
    ↳ agent 是會自己拆步驟、一步步把事情做完的 AI，不只是回你一句話。harness 是包在 AI 外面的那套執行架構，讓它能實際動手做事。他的意思是 Codex 這套架構很穩，AI 才做得了真正的工程工作。
  • 00:32 他認為 Codex 搭配 GPT-5.4 特別擅長處理複雜問題，這類事情換成他自己做，需要花大量心力、犧牲很多睡眠，還得全神貫注
    ↳ GPT-5.4 是和 Codex 搭配使用的 OpenAI 模型。他的重點是：有些難題他自己要熬夜、全神貫注才解得開，現在交給這組工具也處理得來，省下的正是最耗精神的那部分。
  • 00:32 Ramp 工程師以前要等好幾個小時才拿到第一輪 review，現在 Codex 幾分鐘內就能給出有實質內容的回饋
    ↳ 以前工程師送出程式後，要等同事有空才有人看，常常一等就是好幾個小時。現在 Codex 幾分鐘就能回覆，而且會具體指出問題，不是隨便看看。工程師不用一直卡著等，可以馬上修改。
📘 術語
code review（程式碼審查）：Ramp 稱 Codex code review 為業界黃金標準，幾分鐘內就能給出有實質內容的回饋
on-call assistant（on-call 助手）：AI 驅動的 on-call 助手，用來幫工程師扛下大部分負擔
harness（執行框架）：講者形容 Codex 是很紮實的 harness，讓 agent 形式的 AI 能解決複雜問題、進行軟體工程
AI DevEx（AI 開發者體驗）：Austin Ray 在 Ramp 帶領的團隊名稱；字幕沒有進一步說明
