🧑‍🏫 這支影片是 OpenAI 的創意專員 Shad Nelson 分享他怎麼用 Codex 做廣告提案，一天內就生出一整套點子和畫面。Codex 是 OpenAI 的 AI 工具，一般以幫工程師寫程式聞名。這支影片的重點是，不寫程式、做創意的人也能拿它當搭檔。

  • 00:02 Shad Nelson 認為 Codex 不只是工具，某種程度上會成為合作夥伴（collaborator）
    ↳ Shad 的意思是，Codex 不只是你下指令、它照做的工具，更像能一起討論的合作夥伴（collaborator，指一起做事、會回應你想法的人）。
  • 00:02 講者 Shad Nelson 是 creative specialist，這支影片屬於「OpenAI on OpenAI」系列
    ↳ 講者 Shad Nelson 的職稱是 creative specialist，也就是負責創意工作的專員。這支影片屬於「OpenAI on OpenAI」系列，從名稱看，是 OpenAI 自己人分享怎麼用自家工具。
  • 00:02 他指出，擔任 creative director 的工作有很大一部分是提案（pitching ideas）
    ↳ creative director（創意總監）是帶領整體創意方向的人。他說這份工作很大一塊是 pitching ideas，也就是把點子講給客戶聽、說服對方買單。
  • 00:02 實際案例：最近他必須在一天之內向新客戶提出大量點子
    ↳ 舉個真實例子：他最近接了一個新客戶，得在一天之內丟出一大堆點子給對方，時間非常趕。
  • 00:02 他請 Codex 根據該品牌與產品，快速把整個廣告活動（campaign）視覺化呈現出來
    ↳ 他請 Codex 依照品牌和產品，快速把整個 campaign（圍繞同一個主題的一整套廣告）做成看得到的畫面，不必只靠嘴巴描述。
  • 00:32 他提供給 Codex 的資料包括品牌的 style guide
    ↳ 他交給 Codex 的資料包括品牌的 style guide（風格指南，規定品牌能用哪些顏色、字型、Logo 怎麼放等規範），讓產出符合品牌的樣子。
  • 00:32 他也提供 emotional cues，也就是這支廣告想探索的情緒特質
    ↳ 除了規範，他也給了 emotional cues，就是這支廣告想傳達的感覺，例如溫暖或熱血。等於同時告訴 Codex 要什麼「感覺」，不只要什麼外觀。
  • 00:32 他和 Codex 合作的方式，就像把它當成 art director 或 creative director
    ↳ 他跟 Codex 合作時，把它當成 art director（藝術總監，一般負責把創意落實成畫面）或創意總監，像在跟同事討論方向。
  • 00:32 很多人以為 Codex 只給工程師和開發者用
    ↳ 很多人以為 Codex 只是給工程師、開發者寫程式用的，跟做設計、做廣告的人沒關係。這支影片就是在打破這個印象。
  • 00:32 他很驚訝 Codex 懂 brand book、style guide、字型（fonts）和構圖（composition）
    ↳ 他很意外 Codex 看得懂 brand book（品牌手冊，說明品牌個性與視覺規範）、style guide、字型（fonts）和構圖（composition，畫面裡的東西怎麼擺）。
  • 00:32 Codex 了解這些設計基本功，能協助處理相關的挑戰與問題
    ↳ 因為 Codex 懂這些設計基本功，碰到版面怎麼排、字型搭不搭這類設計上的問題，它都能幫忙一起處理。
  • 01:02 Codex 能和他一起即興發想、延伸點子（riffing on ideas）
    ↳ riff 原本是樂手即興彈一段再往下延伸。他的意思是，你丟出一個想法，Codex 會接著延伸出新版本，你再挑、再改，一來一回把點子發展起來。
📘 術語
creative director（創意總監）：字幕說這個工作有很大一部分是提案；他把 Codex 當成創意總監來合作
art director（藝術總監）：字幕只提到他把 Codex 當成近似藝術總監的角色，沒有進一步解釋
campaign（廣告活動）：字幕沒有定義，只提到他請 Codex 快速把整個廣告活動視覺化
style guide（風格指南）：字幕沒有定義，只提到這是他交給 Codex 的資料，而且 Codex 能理解
brand book（品牌手冊）：字幕沒有定義，只列為 Codex 能理解的東西之一
emotional cues（情緒線索）：字幕說明是廣告想探索的情緒特質
composition（構圖）：字幕沒有定義，只列為 Codex 能理解的設計基本功之一
riff / riffing on ideas（即興發想、延伸點子）：字幕沒有定義，用來形容 Codex 和他一起發想點子
