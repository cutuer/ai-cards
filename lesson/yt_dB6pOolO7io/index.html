🧑‍🏫 這支影片介紹新版 ChatGPT app：它不只回答問題，還能直接操作網站、瀏覽器和電腦上的 app，把事情做完。如果你常被重複又瑣碎的電腦作業卡住，看完就知道哪些工作可以交給它。

  • 00:05 新的 ChatGPT app 能操控你平常就在用的網站和 app，幫你完成各種實際工作。
    ↳ 以前 ChatGPT 多半是給你答案，實際的點選、填寫還是你自己來。現在它能直接操作你平常用的網站和 app，從「告訴你怎麼做」變成「幫你做」。
  • 00:05 範例：分析社群論壇的近期貼文，找出過去一個月讓使用者感到挫折的主要問題。
    ↳ 影片舉的例子是：翻完社群論壇最近一個月的貼文，歸納大家最常抱怨什麼。這種事人工做很花時間，正適合交給它。
  • 00:05 ChatGPT 用 in-app browser 掃描論壇，並整理成一份 friction report。
    ↳ in-app browser 是 ChatGPT app 裡內建的瀏覽器。它用這個瀏覽器自己一頁頁看論壇，再整理成 friction report，也就是列出使用者主要卡關點和不滿的報告。
  • 00:05 in-app browser 內建 annotation tool，可以針對某個頁面給出具體回饋或提問，不用寫一大段冗長的指示。
    ↳ annotation tool 是內建瀏覽器附的標註工具。看到某個頁面有問題，可以直接在那一頁指出來、給意見或發問，不用寫一大段文字解釋你指的是哪裡。
  • 00:36 如果想沿用你現有瀏覽器的 context，可以透過 Chrome extension 把瀏覽器連接到 ChatGPT。
    ↳ Chrome extension 是裝在 Chrome 上的外掛，能把你平常用的瀏覽器接上 ChatGPT，讓它沿用瀏覽器現有的 context，也就是目前的狀態，例如已經開著的分頁。
  • 00:36 ChatGPT 可以使用你已經開著的分頁，也可以在背景開新分頁，不會打擾你。
    ↳ 它可以直接接手你已經開著的分頁，也能在背景另開新分頁做事。你眼前正在看的畫面不會被搶走或打斷。
  • 00:36 這種方式適合報帳（expense reports）或冗長的資料輸入流程。
    ↳ 報帳要一筆一筆填表單，大量資料也要重複輸入。這類流程最適合交給它，省下你機械式複製貼上的時間。
  • 00:36 如果要用的工具是桌面 app 而不是網站，可以用 Computer Use 控制 Windows 或 macOS 電腦上的任何 app。
    ↳ 如果要用的是裝在電腦上的軟體而不是網站，就用 Computer Use。這個功能讓 ChatGPT 能操作 Windows 或 macOS 電腦上的任何桌面 app。
  • 00:36 在 macOS 上，ChatGPT 有自己的游標，能在背景作業，你可以同時繼續做別的事。
    ↳ 在 Mac 上，ChatGPT 有自己的游標，和你的滑鼠分開，在背景作業。它做事的同時，你還能繼續用電腦做別的事。
  • 01:06 把新的 ChatGPT 直接連接到你每天使用的 app 和工具，就能完成更多事。
    ↳ 影片的結論：把 ChatGPT 接上你每天用的 app 和工具，它能幫你處理的事就越多。
📘 術語
in-app browser（App 內建瀏覽器）：ChatGPT app 裡的瀏覽器，可以用來掃描網站，例如論壇。
annotation tool（標註工具）：in-app browser 內建的工具，可在特定頁面給出針對性回饋或提問，不必寫冗長指示。
friction report（使用者摩擦點報告）：範例中 ChatGPT 整理的報告，彙整讓使用者感到挫折的主要問題。
Chrome extension（Chrome 擴充功能）：用來把你現有的瀏覽器連接到 ChatGPT，讓它使用瀏覽器的 context。
context（脈絡／既有狀態）：字幕指你現有瀏覽器的狀態，例如已經開著的分頁。
Computer Use（電腦操控功能）：讓 ChatGPT 控制 Windows 或 macOS 電腦上任何桌面 app 的功能。
