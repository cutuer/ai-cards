🧑‍🏫 這支影片示範怎麼用手機上的 ChatGPT Work，在還沒坐到辦公桌前就先追上工作進度、看看自己的財務狀況。真的需要用到電腦時，也能從手機遠端連過去。適合常在外面跑、想先掌握狀況再進公司的人參考。

  • 00:03 可以直接在手機上使用 ChatGPT Work，用來追進度、處理個人事務，在還沒到辦公桌前就先把事情做完
    ↳ ChatGPT Work 是影片介紹的功能，讓 ChatGPT 幫你處理工作和個人的事。重點是用手機就能做，通勤或排隊時先把該掌握的事搞定，進公司就不用從零開始。
  • 00:03 情境：休假結束、回辦公室前想先掌握狀況；使用語音輸入（dictation），用說的就好，不必打字
    ↳ 情境很常見：剛收假，還沒進公司就想知道錯過了什麼。dictation 就是語音輸入，你直接把需求講出來就行，不用在手機小螢幕上慢慢打字。
  • 00:03 指令範例：請 ChatGPT 查看過去一週的 Slack 和 Gmail，告知是否有重要事情、有沒有需要緊急處理的事
    ↳ Slack 是很多公司用的工作聊天工具，Gmail 是 Google 的信箱。你一句話就能請它把這兩邊過去一週的訊息看完，只回報重要和緊急的事。
  • 00:03 ChatGPT 會讀過 email 和 Slack，並特別留意使用者有在參與的頻道，整理出休假期間發生事情的完整樣貌
    ↳ 它不會把所有訊息平均摘要一遍，而是會特別注意你有參與的 Slack 頻道，因為那些通常跟你直接相關。最後拼出一份完整的「你不在時發生了什麼」。
  • 00:33 結果可看出哪些事有變動、哪些訊息真的需要回覆、哪些可以忽略，不必花上半天時間追進度
    ↳ 真正有用的是它幫你分類：哪些事有變動、哪些訊息一定要你回、哪些看過就好。收假第一天本來要花半天追進度，現在先看這份整理就能抓到重點。
  • 00:33 也可用於個人事務：不必自己逐一查看帳戶，直接問 ChatGPT 自己的狀況如何
    ↳ 同樣的做法也能用在自己的錢上。平常要分別登入銀行、信用卡去查，現在直接問一句「我最近財務狀況怎樣」，讓它幫你看就好。
  • 00:33 指令範例：請查看上個月的財務狀況、告知儲蓄進度如何，以及有沒有需要注意的支出
    ↳ 指令可以問得很具體：上個月整體財務如何、存錢進度有沒有跟上、有沒有哪筆支出要注意。問得越清楚，它的回答就越接近你真正想知道的。
  • 00:33 事先已連接 Finances plugin，ChatGPT 能查看帳戶和信用卡，使用者不必自己把資料一一叫出來
    ↳ plugin 是外掛，裝上後 ChatGPT 就多一種能力。Finances plugin 是用來連接你的帳戶和信用卡，事先設定好之後，它會自己去看資料，不用你一筆筆貼給它。
  • 00:33 Finances plugin 只有唯讀（read-only）權限
    ↳ read-only 是唯讀，意思是它只能看資料，不能修改。套在財務上，就是它能看你的帳戶和刷卡紀錄，但不能幫你操作帳戶。
  • 00:33 它能顯示儲蓄進度、哪裡花最多錢，以及是否有看起來不尋常的地方
    ↳ 它會整理出三件事：存錢進度到哪裡、錢主要花在哪、有沒有看起來不尋常的地方，例如一筆你沒印象的扣款，這樣就能早點發現。
  • 01:03 可以請它持續幫忙檢查，例如：「每天做一次這樣的檢查，有異常就通知我」，就不用自己記得每天去看
    ↳ 不只能問一次，還能請它定期做。例如跟它說「每天幫我檢查一次，有異常就通知我」，之後交給它盯著，你就不用記得每天自己去看。
  • 01:03 這些事大多完全不需要電腦；若需要筆電上的東西，可以用 Remote 連過去
    ↳ 上面這些事幾乎只要手機就能完成。只有需要用到筆電裡的東西時，才要用 Remote，也就是從手機連到你的電腦去查看和操作。
  • 01:03 Remote 連線步驟：在電腦上開啟 Remote，用手機上的 ChatGPT app 掃描配對碼（pairing code），再選擇自己的電腦
    ↳ 連線步驟：先在電腦上打開 Remote，畫面上會出現 pairing code（配對碼，讓手機和電腦認得彼此），用手機的 ChatGPT app 掃描它，再選你的電腦。
  • 01:03 連線後可開啟電腦上已在執行的任務，查看它正在做什麼，並指示它下一步要做什麼
    ↳ 連上之後，你能看到電腦上已經在跑的任務、它目前做到哪裡，也能直接下指令告訴它下一步要做什麼，等於在外面遠端帶著它繼續工作。
  • 01:03 即使是從手機查看，任務仍能使用筆電上的檔案和 app
    ↳ 雖然你手上拿的是手機，任務其實還是在筆電上跑，所以照樣能用筆電裡的檔案和 app，不需要先把檔案傳到手機。
  • 01:33 電腦必須保持喚醒且連線；可以讓 Mac 保持開著，或插上電源並開啟「Keep this Mac awake」
    ↳ 前提是電腦不能睡著或斷線。Mac 可以直接保持開著，或插上電源並開啟「Keep this Mac awake」（讓 Mac 保持喚醒的選項），出門前記得先設好。
  • 01:33 總結：工作和個人事務都能在手機上處理，需要電腦時有 Remote，到辦公桌前就能先跟上進度
    ↳ 總結：工作和私事都能先用手機處理，真的需要電腦時再用 Remote 連過去。等你坐到辦公桌前，大部分狀況已經掌握好了。

ChatGPT Work（ChatGPT Work）：影片介紹的功能，可直接從手機使用，用來追工作進度、處理個人事務

Keep this Mac awake（讓這台 Mac 保持喚醒）：插上電源後開啟此選項，讓電腦保持喚醒與連線，供 Remote 使用
