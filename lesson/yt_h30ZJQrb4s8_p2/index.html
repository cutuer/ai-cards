🧑‍🏫 這段教你把一組 PBR 貼圖（Physically Based Rendering，模擬真實材質的一整套圖）接到 Blender 材質上。影片先示範手動接，讓你知道每張圖該怎麼設定；再改用 Poliigon 外掛一鍵套用；最後用 UV unwrapping 解決「材質套上了卻看不到」的問題。看完你會懂寫實材質是怎麼組起來的。

  • 10:44 把貼圖接到 normal 輸入後已經有 bump 效果，但這只做對一部分：黃色輸出接到了紫色輸入
    ↳ 貼圖接到 normal 輸入後，表面已經有 bump（凹凸起伏的視覺效果），但接法還不完全對。節點插孔的顏色代表資料類型，黃色是色彩資料，紫色是另一種資料，兩者不該直接接在一起。
  • 10:44 黃色接灰色沒問題，因為灰色代表 grayscale，色彩資訊可以轉成灰階；但 normal 是 vector 資訊
    ↳ 黃色接灰色沒問題，因為灰色插孔代表 grayscale（灰階，只有明暗一個數值），色彩可以直接轉成灰階。但 normal 要的是 vector（向量，帶方向的一組數字），色彩不能直接拿來當方向用。
  • 11:14 normal 就是面朝向的那條隱形線；normal map 是在假造每個 pixel 的朝向
    ↳ Normal 是每個面「朝向哪裡」的那條隱形線，燈光靠它計算明暗。Normal map 則是用一張圖假造每個 pixel（像素）的朝向，讓平面看起來凹凸不平，但模型的形狀其實沒變。
  • 11:14 中間要加一個節點，把色彩資訊轉成 vector：Shift+A → Displacement → Normal Map；找不到也可以在搜尋列輸入 normal map
    ↳ 所以中間要加一個節點，把色彩資料轉成方向資料。操作是 Shift+A → Displacement → Normal Map；選單裡找不到的話，直接在搜尋欄輸入 normal map 最快。
  • 11:46 把 Normal Map 節點拖到連線上，等線亮起來後點一下，就會自動接進去
    ↳ 把 Normal Map 節點拖到原本那條連線上，等線亮起來再點一下，Blender 會自動把它插進中間，不用自己拆線重接。
  • 11:46 手動接 PBR 貼圖步驟很多，之後會教快速做法；但你可能會用到其他來源或製作檔裡的 PBR 貼圖，所以要先學會手動接
    ↳ 手動接很費工，影片之後會教快速做法。不過還是要先學會手動接，因為以後拿到別的網站或別人檔案裡的貼圖時，外掛不一定幫得上忙。
  • 11:46 PBR 貼圖中只有 base color 的 color space 要設成 sRGB
    ↳ Color space（色彩空間）決定程式怎麼解讀圖片裡的數值。整組 PBR 貼圖中，只有 base color（物件本身顏色那張）要設成 sRGB，因為只有它存的是真正的顏色。
  • 12:23 其他貼圖一律設成 Non-Color：不做任何轉換，直接用原始數值並以線性方式使用；其他軟體有時稱為 utility maps
    ↳ 其他貼圖一律設成 Non-Color，意思是數值原封不動照用，不做色彩轉換。這些圖記錄的是凹凸、粗糙度這類資料，不是顏色。其他軟體常把它們叫 utility maps（功能性貼圖）。
  • 12:54 切到 rendered view，把燈壓低貼近平面，就能看到表面投出粗糙的細小陰影；寫實材質就是這樣做出來的
    ↳ 切到 rendered view（接近最終成品的算圖預覽），把燈壓低、幾乎貼著平面打光，就會看到表面冒出粗糙的細小陰影。寫實感就是靠這些細節堆出來的。
  • 13:24 這種資訊只能靠昂貴的表面掃描取得，費用可達數千；多年來價格已大幅下降，但過程不容易、很無聊，除非想投入這個領域，否則不建議自己做
    ↳ 這些表面資料要靠昂貴的掃描取得，費用可能到數千。這幾年價格已經降很多，但過程麻煩又枯燥。不打算專做這一行的話，直接用現成的貼圖就好。
  • 13:54 加 roughness 貼圖：Shift+A → Texture → Image Texture → Open，選檔名結尾是 _roughness 的檔案，color space 設成 Non-Color
    ↳ 加 roughness（粗糙度，決定表面偏亮面或霧面）貼圖的步驟：Shift+A → Texture → Image Texture → Open，選檔名結尾是 _roughness 的檔案，color space 設成 Non-Color。
  • 14:25 接到 Roughness 輸入後材質會變得很霧，因為混凝土本來就是霧面；這是經過校準的正確數值
    ↳ 接上 Roughness 後材質會變得很霧，這不是接錯。混凝土本來就是霧面，這張貼圖是照實物校準過的數值，這樣才正確。
  • 14:25 需要自訂時可以不接貼圖，例如咖啡廳桌面的混凝土常經過拋光；想自由調滑桿就把貼圖斷開，完全沒問題
    ↳ 想要別的效果也可以不接。例如咖啡廳桌面的混凝土常經過拋光、會反光，這時把 roughness 貼圖斷開，自己拉滑桿調整就好，完全沒問題。
  • 14:58 追求寫實就把所有貼圖都用上，但有時不需要全用
    ↳ 追求最寫實就把整組貼圖都接上，但不是每次都要全用，看你要的效果決定。
  • 14:58 黃色的 ORM 貼圖 Blender 不用，是遊戲引擎用的；Poliigon 會提供，是因為要支援各種 renderer 與軟體
    ↳ 黃色標示的 ORM 貼圖（把遮蔽、粗糙度、金屬度三種資料合在同一張圖裡）Blender 用不到，那是給遊戲引擎用的。Poliigon 會附上，是為了支援各種軟體。
  • 14:58 Displacement 是跟 normal map 不同的做法，之後做甜甜圈會用到
    ↳ Displacement（置換）也能做出凹凸，但做法和 normal map 不同，它是真的改變表面形狀。之後做甜甜圈時會用到，這段先不用。
  • 14:58 Metallic 只有在材質含金屬時才用
    ↳ Metallic（金屬度）只有在材質裡含金屬時才需要接。
  • 15:31 Ambient occlusion map 用在有深縫隙的表面（例如碎石步道），代表縫隙裡累積的陰影；這次用不到
    ↳ Ambient occlusion map（環境遮蔽貼圖）用來表現深縫隙裡累積的陰影，例如碎石步道石頭之間的縫。這次用不到。
  • 15:31 base color、normal map、roughness 這三張就能處理約 90% 的材質
    ↳ base color、normal map、roughness 這三張就能處理大約九成的材質，先把這三張弄熟就很夠用。
  • 15:31 手動設定很繁瑣，要記 color space、接線、轉換，光三張貼圖就要約 30 次點擊
    ↳ 手動設定的麻煩在於每張都要記得設 color space、接對插孔、加轉換節點。光三張圖就要點大約 30 下，很容易漏掉一步。
  • 16:04 所以處理 PBR 貼圖的人多半改用 add-on，例如 Poliigon add-on
    ↳ 所以常處理 PBR 貼圖的人，多半改用 add-on（外掛，裝進 Blender 增加功能的小程式），例如 Poliigon 出的這個。
  • 16:04 poliigon.com/doughnut 頁面上方有 Download Poliigon Add-on 連結，或到 /blender 看安裝說明
    ↳ 到 poliigon.com/doughnut，頁面上方有 Download Poliigon Add-on 連結；也可以到 poliigon.com/blender 看安裝說明。
  • 16:04 安裝時不要解壓縮 zip，Blender 需要 zip 檔才能正確安裝；把 zip 拖進 Blender，它會辨識成 add-on，按安裝再按 OK
    ↳ 下載後不要解壓縮，Blender 要讀 zip 檔才能正確安裝。把 zip 直接拖進 Blender 視窗，它會認出這是外掛，按安裝，再按 OK。
  • 16:34 到 Edit → Preferences → Add-ons，看到 Poliigon 就代表安裝成功
    ↳ 裝完到 Edit → Preferences → Add-ons 檢查，清單裡有 Poliigon 就代表安裝成功。
  • 16:34 裝不起來可能是 Mac 自動解壓縮了，要重新壓成 zip 再拖進去
    ↳ 裝不起來的話，可能是 Mac 下載時自動幫你解壓縮了。把資料夾重新壓成 zip，再拖進 Blender 就行。
  • 16:34 在 3D viewport 按 N 打開屬性面板，會看到 Poliigon 分頁，點一下就能登入
    ↳ 在 3D viewport（中間顯示模型的主畫面）按 N 打開側邊屬性面板，會多出一個 Poliigon 分頁，點進去就能登入帳號。
  • 17:05 看到 login confirmed 後回到 Blender，材質會出現在捲動列；可搜尋（例如 sprinkles），也可依分類瀏覽
    ↳ 看到 login confirmed 後回到 Blender，材質會列在可以捲動的清單裡。你可以搜尋（例如輸入 sprinkles），也可以依分類瀏覽。
  • 17:05 一鍵下載、一鍵套用，所有設定自動完成
    ↳ 從這裡開始，點一下下載、再點一下套用，前面手動做的那些設定全部自動完成。
  • 17:37 自動套用的貼圖都已設成 Non-Color，每張貼圖都用在正確的位置
    ↳ 自動套用時，該設 Non-Color 的貼圖都已經設好，每張也都接在正確的插孔上。前面手動操作容易出錯的地方，外掛都幫你處理掉了。
  • 17:37 在 free 分類選 speckled glazed ceramic plate 給盤子用；點旁邊的下拉選單可以上網看更清楚的預覽圖
    ↳ 在 free（免費）分類選 speckled glazed ceramic plate（帶斑點的釉面陶瓷）給盤子用。點旁邊的下拉選單，可以開網頁看更清楚的預覽圖。
  • 18:08 要先按 download，檔案會存到 preferences 裡設定的資料夾；接著選取物件再按 Apply
    ↳ 要先按 download，檔案會存到 preferences 裡設定的資料夾。接著選取要上材質的物件，再按 Apply 套用。
  • 18:08 看不到 Apply 按鈕，就是沒有選取物件
    ↳ 看不到 Apply 按鈕，就是還沒選取物件。先在畫面上點選盤子，按鈕就會出現。
  • 18:08 材質套上了卻沒顯示，不是貼圖的問題，而是 texture mapping 的問題：貼圖是 2D、物件是 3D，而把貼圖套上物件的方法有很多種
    ↳ 材質套上了卻沒顯示花紋，不是貼圖的問題，而是 texture mapping（貼圖怎麼對應到物件表面）的問題。平面的圖要包到立體物件上，有很多種包法。
  • 18:41 最常見的是 UV unwrapping，也是預設方法；材質裡的 texture coordinate 就是 UVs
    ↳ 最常見、也是預設的包法叫 UV unwrapping，意思是把 3D 表面攤平成 2D，讓貼圖對得上。材質裡的 texture coordinate（貼圖座標）預設用的就是這套 UV。
  • 18:41 盤子這類物件很簡單：按 Tab 進 edit mode，全選 mesh，按 U（unwrap），選 Unwrap (Angle Based)，貼圖就會出現
    ↳ 盤子形狀簡單：按 Tab 進 edit mode（編輯點線面的模式），全選 mesh（組成模型的網格），按 U 選 Unwrap (Angle Based)，花紋就會出現。

    ↳ 到畫面上方的 UV Editing 分頁可以看結果。盤子這麼平，unwrap 就像拍一張快照，把整個表面放進 2D 平面裡。

    ↳ UV 視窗的下拉選單可以換成 color map，直接看到貼圖的哪一塊被用在模型上。
  • 20:30 在 mesh 上選一個點，UV 視窗會顯示對應的位置（例如陶瓷上的某個斑點）
    ↳ 在模型上選一個點，UV 視窗會標出它在貼圖上的對應位置，例如陶瓷上的某個斑點，方便你確認對得對不對。

    ↳ 在 UV 視窗按 A 全選，按 R 旋轉或直接拖動 UV，模型上的花紋會即時跟著變動。

    ↳ 按 S 可以縮放 UV，這很常用。你做的模型尺寸常和當初掃描的實物大小差很多，花紋看起來太大或太小時，就靠縮放來調整。

    ↳ Poliigon 這類細節貼圖，代表的實物大小是 30×30 公分，可以拿來判斷 UV 要縮放多少才合比例。
📘 術語
Normal（法線）：面朝向的那條隱形線
Normal Map（法線貼圖／法線貼圖節點）：假造每個 pixel 的朝向；節點用來把色彩資訊轉成 vector 資訊
Grayscale（灰階）：節點上的灰色插孔代表灰階，色彩資訊可以直接接過去
Vector（向量）：normal 屬於 vector 資訊（紫色插孔），不能直接接色彩
PBR texture maps（PBR 貼圖組）：一組各司其職的貼圖（base color、normal、roughness 等），可以手動接或用 add-on 自動接
sRGB（sRGB 色彩空間）：PBR 貼圖中只有 base color 要設成這個 color space
Non-Color（非色彩資料）：不做轉換，直接用原始數值並以線性方式使用；其他軟體稱為 utility maps
Roughness（粗糙度）：接上 roughness 貼圖後混凝土會變霧面，是校準過的正確值
ORM（ORM 貼圖）：Blender 不用，是遊戲引擎用的
Displacement（置換）：跟 normal map 不同的做法，之後做甜甜圈會用
Metallic（金屬度）：只有材質含金屬時才用
Ambient Occlusion（環境光遮蔽）：表現深縫隙裡累積的陰影，例如碎石步道
Rendered view（算圖預覽模式）：在這個模式下壓低燈光，可以看到表面的細小陰影
Add-on（外掛）：例如 Poliigon add-on，安裝時要用未解壓的 zip 檔
Texture mapping（貼圖映射）：把 2D 貼圖套到 3D 物件上的方法，有很多種
UV unwrapping（UV 展開）：最常見的預設貼圖映射方法；平的物件就像拍一張快照放進 2D 空間
Texture coordinate（貼圖座標）：材質目前使用的座標叫 UVs，移動 UV 時會即時更新
Edit mode（編輯模式）：按 Tab 進入，可以全選 mesh 後做 unwrap
UV Editing（UV 編輯分頁）：畫面上方的分頁，可以看 UV 在 2D 空間的位置
