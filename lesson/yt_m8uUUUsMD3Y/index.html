🧑‍🏫 OpenAI 和 Work Louder 團隊合作，推出一把專門搭配 Codex 的小鍵盤 Codex Micro。Codex 是 OpenAI 的 AI 工具，你交代它做事，它會幫你寫程式、做出成品。影片從頭到尾只用這把小鍵盤做完一個小遊戲，示範不碰筆電鍵盤也能對 AI 下指令、在好幾件工作之間切換。如果你常同時丟好幾件事給 AI，可以看看這種新的操作方式。

  • 00:05 Codex Micro 是與 Work Louder 團隊合作、專為 Codex 打造的鍵盤
    ↳ Codex Micro 是一把小鍵盤，但不是拿來打字的。它把 Codex 常用的操作做成實體按鍵、搖桿和旋鈕，按一下就完成，不用在畫面上找按鈕。
  • 00:05 示範內容：在 Codex 中使用 GPT-5.6 Sol 做一個小型文字遊戲，全程從 Micro 操控
    ↳ 示範者在 Codex 裡選用 GPT-5.6 Sol（影片中用的 AI 模型名稱）做一個小文字遊戲。整個過程都靠 Micro 操作，目的是證明它真的能從頭用到尾。
  • 00:05 語音輸入（voice dictation）：按住某個鍵就能直接對 Codex 說話
    ↳ voice dictation 就是語音輸入。按住指定的鍵開口講，你說的話就變成給 Codex 的指令，跟用手機語音打字很像，只是聽的人換成 AI。
  • 00:05 示範 prompt：做一個叫 One Letter Off 的瀏覽器遊戲，玩家一次改一個字母，把 cold 變成 warm
    ↳ prompt 是你交代 AI 的那段話。這次要它做一個網頁遊戲「One Letter Off」：每次只能改一個字母，一步步把 cold 變成 warm。
  • 00:36 prompt 還要求加入 30 秒計時器、連勝（streaks）和好看的方塊動畫；整段 prompt 不用碰筆電鍵盤就輸入完成
    ↳ 同一段話還加了細節：30 秒倒數、連勝（streaks，連續過關的次數）和好看的方塊動畫。要求這麼長這麼細，還是全用講的，筆電鍵盤一次都沒碰。
  • 00:36 頂部的類比搖桿可設定對應到最常用的 skills；預設往上推是使用 Plan mode
    ↳ 頂部的 analog stick 是一支可以往各方向推的搖桿，每個方向都能設成你最常用的 skills（影片沒解釋，可想成常叫 Codex 做的固定動作）。出廠設定是往上推進入 Plan mode，影片沒說明這個模式的細節。
  • 00:36 用旋鈕（dial）控制 reasoning effort，在快速任務與較深入的推理之間快速切換，不打斷工作節奏
    ↳ reasoning effort 是 AI 花多少力氣思考。調低就回得快，適合簡單小事；調高會想得久、比較周全，適合難題。轉一下旋鈕就能切換，不用停下來開設定頁。
  • 00:36 除了遊戲，Codex 同時在 pinned tasks 裡處理其他幾件工作，每個任務對應 Micro 上的一個鍵
    ↳ 做遊戲的同時，Codex 還在跑其他工作，這些工作放在 pinned tasks（釘選起來的任務）裡。每件工作綁一顆實體鍵，等於每件事都有自己的專屬按鈕。
  • 01:07 點按對應的鍵就能在任務間快速切換，一眼看出哪些正在執行、哪些需要你處理
    ↳ 按下某件任務的鍵，就直接跳到那件工作。從按鍵上也看得出哪些還在跑、哪些停下來等你回應，不用一個一個點開檢查。
  • 01:07 若 app 在背景，按兩下就能看到哪些任務需要你注意
    ↳ 就算 Codex 視窗被別的程式蓋住、在背景執行，按兩下也能叫出哪些任務在等你處理，比較不會漏掉。
  • 01:07 Codex 要求執行某項操作的權限時，可以切過去按下 Accept
    ↳ AI 要做某些動作前，會先停下來問你准不准。這時切到那件任務按 Accept（同意），它就會繼續做下去。
  • 01:07 可再切回來、按住語音鍵排入新任務，例如「讓獲勝畫面更有力，並加上連勝計數器」
    ↳ 處理完再切回遊戲，按住語音鍵補一句新要求，例如「讓獲勝畫面更有力，加上連勝計數器」，這件新工作就排進去讓 Codex 接著做。
  • 01:37 講者表示這讓在任務之間切換比以往容易許多
    ↳ 講者的感想是：以前在好幾件工作之間跳來跳去很麻煩，有了實體按鍵，切換容易多了。這也是這把鍵盤主打的地方。
  • 01:37 等待 Codex 完成任務時，類比搖桿也可以當紓壓玩具
    ↳ AI 做事需要時間，等待的空檔可以撥撥搖桿，把它當紓壓小玩具。
  • 01:37 遊戲完成上線，全程由 Micro 操控
    ↳ 最後遊戲做好上線，可以實際玩了，而且從頭到尾都是用 Micro 操控完成的。
  • 01:37 Codex Micro 所有控制都可自訂，對應最常用的 Codex 動作，例如常用 skills、建立 pull request，甚至觸發 pet
    ↳ 每個按鍵、搖桿和旋鈕都能改設定，對應你最常用的動作，例如常用 skills、建立 pull request（把改好的程式送出去請人審核、合併的請求），甚至觸發 pet（影片沒說明）。
  • 02:07 可在 openai.com/supply 購買
    ↳ 想買的話，可以到 OpenAI 官網的 openai.com/supply 頁面購買。影片沒有提到價格。
