用 Object Info Random 加 Color Ramp 幫糖針上隨機顏色，再做色彩管理與次表面散射
  • 24:32 前一種做法會讓各色糖針在甜甜圈上分布不理想，更好的方法是使用隨機顏色（random colors）。
  • 30:36 例子：可以做萬聖節甜甜圈，講者說萬聖節常見黑、橘、綠、紫，Reese's Pieces 也主打這些顏色。
  • 36:20 盤子加糖針時要先套用 solidify modifier，才能在盤子正確的那一面繪製，糖針也才會出現。
💡 你可以怎麼用：想讓一堆物件各有不同顏色時，用 Object Info 的 Random 接一個 Color Ramp，插值改成 constant，再拖色標控制比例，記得一個主色配少量點綴。算最終圖時把 look 換成 Medium High 或 High Contrast，糖果類材質記得開 subsurface scattering。

🧑‍🏫 這段教你讓甜甜圈上每顆糖針自動拿到不同顏色，還能精準控制各色比例，不用一顆一顆手動上色。後半段講配色原則、色彩管理和讓糖針看起來像真糖果的 subsurface scattering，這幾步直接決定成品看起來廉價還是可口。

  • 24:32 前一種做法會讓各色糖針在甜甜圈上分布不理想，更好的方法是使用隨機顏色（random colors）。
    ↳ 前一種做法會讓各色糖針在甜甜圈上分得不好看。改用 random colors（隨機顏色），讓 Blender 自動替每顆糖針挑色，分布會自然很多。
  • 25:04 所有糖針都給同一個材質：選取全部糖針，最後選的那顆要有材質，按 Control L 把資料從一個物件傳到多個物件，再選 Materials。
    ↳ 先選取全部糖針，最後點的那顆要已經有材質（決定表面顏色和光澤的設定），再按 Control L（把資料從一個物件傳給多個物件的快捷鍵）選 Materials，全部就共用同一份材質。
  • 25:36 材質名稱旁邊的數字代表共用這份資料的使用者數量，例如六顆糖針共用就顯示 6。建議把材質命名為 Sprinkles。
    ↳ 材質名稱旁的數字叫 users，代表有幾個物件在共用這份材質，六顆糖針共用就顯示 6。取名 Sprinkles 以後比較好找。
  • 25:36 切到 Shader 分頁編輯材質。講者說 node 能做的事幾乎沒有限制。
    ↳ Shader 分頁是專門編輯材質的工作區。材質在這裡用 node（節點，一個個小方塊用線串起來）組合，講者說能做的事幾乎沒有上限。
  • 26:11 按 Shift A 可以叫出各種屬性節點。這裡要用 Object Info 節點，它有 location 等多種輸出，本次使用 Random。
    ↳ Shift A 會叫出新增選單，可以加各種節點。Object Info 節點會提供物件本身的資訊，例如位置 location。這次用的是它的 Random 輸出。
  • 26:43 Random 會替每個使用這個材質的物件挑一個 0 到 1 的隨機值。接到顏色時，0 是黑、1 是白。
    ↳ Random 會替每個用這份材質的物件各抽一個 0 到 1 的數字。直接接到顏色上的話，0 是黑、1 是白，所以每顆糖針會是不同深淺的灰。
  • 26:43 小技巧：複製（duplicate）一次之後按住 Shift R，就能一直重複複製，產生更多糖針。
    ↳ duplicate 是複製物件。複製一次後一直按 Shift R，Blender 就會重複上一個動作，一直多出新的糖針，適合快速做出一堆來測試顏色。
  • 27:17 黑到白的效果不實用。在兩個節點之間插入 Color Ramp（Add 或 Shift A → Color → Color Ramp），拖到連線亮起時放下。
    ↳ 黑白灰不實用，要換成真正的顏色。在兩個節點中間插一個 Color Ramp（把 0 到 1 的數字對應成顏色的節點），拖到連線亮起來時放開，就會自動接好。
  • 27:47 把 Color Ramp 兩端改成藍色和橘色，每顆糖針會落在漸層上的不同位置，產生顏色變化。
    ↳ 把 Color Ramp 兩端設成藍和橘。每顆糖針抽到的數字不同，會落在漸層的不同位置，所以顏色會從藍、中間色到橘都有。
  • 28:20 漸層並不寫實：真實糖針同色都是同一色調，因為糖霜是用一批食用色素調好後擠出來的，所以每色是固定顏色。
    ↳ 這樣不寫實。真的糖針是一批糖霜加食用色素調好再擠出來的，同一色每顆都一樣，不會有介於藍和橘中間的顏色。
  • 28:54 小技巧：糖針隱藏後就點不到它們的材質。可以選取 icing，按加號新增材質欄位，從下拉選單選 Sprinkles，不會影響 icing。
    ↳ 糖針藏起來之後就點不到它的材質。可以選 icing（糖霜），按加號多開一個材質欄位，選 Sprinkles 來調，icing 本身不會被影響。
  • 29:24 一個物件可以堆疊多個材質並指定給網格的不同部分（本教學不做）。也可以不指定，只拿來快速調整材質。
    ↳ 一個物件可以放好幾個材質，分別指定給 mesh（網格，也就是物件的形狀）的不同區塊，這集不教。多開的欄位不指定也可以，只當調材質的入口。
  • 30:00 把 Color Ramp 色標的插值從 linear 改成 constant，就會變成硬邊界，只有整段藍或整段橘，不再是漸層。
    ↳ interpolation 是色標之間怎麼過渡。linear 是平滑漸層，改成 constant 會變成硬切，每顆糖針只會是整塊藍或整塊橘，就像真的糖針。
  • 30:36 例子：可以做萬聖節甜甜圈，講者說萬聖節常見黑、橘、綠、紫，Reese's Pieces 也主打這些顏色。
    ↳ 配色可以配合主題。講者舉萬聖節為例，常見黑、橘、綠、紫，Reese&#x27;s Pieces 糖果主打的也是這幾色，照這個配就很有節日感。
  • 31:14 講者的甜甜圈走粉彩風，選了 aqua 色調和紫色。
    ↳ 講者自己的甜甜圈走粉彩風，選了 aqua（偏藍綠的水色）加紫色，整體看起來柔和。
  • 31:46 顏色不要用到 100% 飽和。算圖時加對比或提亮高光可能會讓顏色爆掉，飽和度偏低也比較耐看。
    ↳ saturated 指顏色飽和度拉滿。之後算圖加對比或提亮時，全飽和的顏色容易爆掉，細節不見。飽和度低一點也比較耐看。
  • 31:46 用 Color Ramp 可以直接用滑桿精準控制各色糖針的比例（藍、紫、粉、黃等）。
    ↳ Color Ramp 上每個色標佔的長度，就是那個顏色的糖針比例。拖動滑桿就能精準決定藍、紫、粉、黃各佔多少。
  • 32:29 配色建議：以一個主色為大宗，再點綴少量其他顏色，這樣大腦比較好消化畫面；各色平均分配會看起來像雜訊。
    ↳ 配色時讓一個主色佔大多數，其他顏色少量點綴，眼睛比較好抓重點。每色平均分配反而會亂，看起來像雜訊。
  • 33:05 預設色彩管理會讓顏色偏灰、偏低飽和，設計上是方便調色，不適合在 None look 下當最終算圖。
    ↳ color management（色彩管理）決定畫面顏色最後怎麼顯示。預設刻意偏灰、偏淡，方便後續調色。look 是它的預設風格，選 None 不適合拿來當最終成品。
  • 33:38 最終算圖建議用 Medium High 或 High Contrast，YouTube 縮圖用 Very High Contrast。這些是正規的 S-curve 轉換，不會爆掉。
    ↳ 最終算圖選 Medium High 或 High Contrast，縮圖要搶眼就用 Very High。這些是 S-curve（暗處壓暗、亮處提亮的對比曲線），是正規轉換，不會把顏色弄爆。
  • 34:09 講者調回糖針比例（多一點藍，加些粉、白、黃），並把 icing 調得更鮮豔、稍微偏紫。
    ↳ 講者重新調了糖針比例：藍色多一點，再加些粉、白、黃。也把糖霜調得更鮮豔、稍微偏紫，讓整體更搭。
  • 34:44 參考實物可以發現糖針其實有一點亮，所以要讓材質稍微有光澤。
    ↳ 對照真的糖針照片會發現它表面有點反光，所以材質要調得稍微亮一點、有光澤，不然會像塑膠或粉筆。
  • 34:44 糖針需要 subsurface scattering：radius 全拉成 1、weight 設為 1、scale 調得很低，效果差很多。
    ↳ subsurface scattering 是光稍微透進表面再散出來的效果，像糖果、蠟燭的微透感。radius 三個值都設 1，weight 設 1，scale 調很低，糖針會好看很多。
  • 35:17 講者練習時忘了加 subsurface scattering，糖針就是不好看，可見它影響很大。
    ↳ 講者練習時漏了 subsurface scattering，糖針怎麼調都不對勁，可見這一步影響很大，別跳過。
  • 35:17 作業一：做出自己風格的甜甜圈，例如把長條糖針換成圓形或星形、改甜甜圈顏色、把甜甜圈疊起來。
    ↳ 作業一是做出自己風格的甜甜圈，例如把長條糖針換成圓形或星形、換甜甜圈顏色，或疊好幾個甜甜圈。
  • 35:47 自己實驗能培養獨立思考，練習去找功能在哪裡、回想學過的內容。
    ↳ 自己動手改能培養獨立解決問題的能力：練習去找功能放在哪、回想之前學過的步驟，不再只是照著影片按。
  • 35:47 作業二（可選）：在盤子上加糖針，步驟和之前的 scattering on surface 基本相同。
    ↳ 作業二（可選）是在盤子上也撒糖針，做法跟之前教的 scattering on surface（在表面上散佈物件）幾乎一樣。
  • 36:20 盤子加糖針時要先套用 solidify modifier，才能在盤子正確的那一面繪製，糖針也才會出現。
    ↳ modifier 是加在物件上的效果，solidify 會替薄片加厚度。盤子要先套用 solidify modifier，才能畫在正確的那一面，糖針也才會出現。
  • 36:20 下一集是最後一集，內容是打光與算圖（lighting and rendering）。
    ↳ 下一集是系列最後一集，教 lighting and rendering（打光與算圖），也就是把場景打亮、輸出成最終圖片。
📘 術語
Control L（連結／傳遞資料）：把資料從一個物件傳到多個物件，選 Materials 就能共用材質
users（使用者數）：材質旁的數字，表示有幾個物件共用這份資料
Shader tab（Shader 分頁）：用來編輯材質節點的工作區
Object Info（物件資訊節點）：提供 location、Random 等物件相關輸出的節點
Random（隨機值）：替每個使用該材質的物件挑一個 0 到 1 的隨機值
Shift R（重複上一個動作）：複製一次後按住 Shift R，會一直產生更多複製品
Color Ramp（色彩漸層節點）：把 0 到 1 的單一數值轉成顏色
linear / constant interpolation（線性／固定插值）：linear 是漸層；constant 是硬邊界，只會出現單一顏色
saturated（飽和）：全飽和的顏色在加對比時容易爆掉，最好維持偏低飽和
color management（色彩管理）：預設畫面偏灰、偏低飽和，是為了方便調色
look (None / Medium High / High / Very High Contrast)（色彩外觀設定）：None 不適合最終算圖；建議 Medium High 或 High，縮圖用 Very High
S-curve（S 曲線）：這些對比 look 是正規的 S-curve 轉換，不會爆掉
subsurface scattering（次表面散射）：糖針非常需要它；radius 設 1、weight 設 1、scale 調低
solidify modifier（加厚修改器）：在盤子上加糖針前要先套用，才能畫在正確的那一面
scattering on surface（在表面上散佈）：之前教過的散佈步驟，盤子加糖針也用同樣的方法
