🧑‍🏫 這段講者示範怎麼把 3D 角色做得像 2D 漫畫：身體不用手動捏，而是用曲線和參數自動長出來；線條則用自製工具加粗細變化和雜訊，讓電腦算出來的線看起來像手畫。想做漫畫風 3D，或想知道怎麼把 Blender 內建功能改成順手工具的人，這段很實用。

  • 11:54 講者做出一個看起來像 2D 的真 3D 角色。它用一條 curve，裡面有 10 條 spline。

  • 11:54 每條 spline 各自變形一個不同的物件。每個物件都有兩個 Geometry Node modifier。
    ↳ 10 條線各負責一個身體部位的物件。每個物件掛兩個 modifier（疊在物件上、可隨時調整或拿掉的加工步驟），都是用 Geometry Nodes（用節點連線組規則的工具）做的。
  • 11:54 這個角色仍然完全是 procedural，還沒有任何建模。講者說建模可能是下一步。
    ↳ 整個角色是 procedural（靠規則和參數自動算出來），完全沒有手動捏過模型。講者說下一步可能才會進入手動建模。

    ↳ 還有缺點：腳部的 topology（模型表面點、線、面的排列方式）不理想，一彎曲就變形走樣。講者還在想辦法修。
  • 12:24 講者推薦 Blue Zoo animation studio 去年的演講，請觀眾去看。
    ↳ 講者推薦 Blue Zoo 動畫工作室去年在同一個活動的演講，跟這次主題有關，建議找來看。

  • 13:29 capsulinder 的功能：可以改變端蓋，也能移除或加上端蓋。端蓋可以做得更尖或更短鈍，還能縮放整體或兩端，藉此程序化做出很多形狀。
    ↳ 重點是一個形狀能變出很多零件：端蓋可有可無、可尖可鈍，整體或兩端的粗細都能縮放。調參數就能換造型，不用重做模型。

📘 術語
curve（曲線）：一條 curve 可以包含多條 spline。講者說它不適合做動畫，但很適合做形狀。
spline（樣條／曲線段）：curve 裡的單一線段，每條都有 index 編號。可指定 modifier 跟隨某一條。
Geometry Nodes（幾何節點）：講者用它做 modifier 和基本形狀。從 Blender 4.3 起支援 grease pencil。
procedural（程序化）：講者用來形容角色完全沒有建模，只靠 curve 和 modifier 產生。
topology（拓撲）：字幕提到腳部的 topology 造成變形問題，講者正在改善端蓋的 topology。
capsulinder（膠囊圓柱（講者自創））：講者自製的形狀，可以是 capsule 或 cylinder，端蓋可調整。
spline object（spline 物件）：講者對「跟隨 spline 的物件」的稱呼。一條 spline 可以變形多個這種物件。
edit mode / curve edit mode（編輯模式／曲線編輯模式）：講者用 pin 屬性的方式，讓自己能一直停留在 curve edit mode。
mirror modifier（鏡像修改器）：講者先用它鏡像 spline object，最後階段再移除。
silhouette（剪影）：講者在最後階段會快速檢查。line art modifier 也會產生 silhouette 線。
armature（骨架）：可以利用 capsule 或 curve 起點、終點的位置資訊來建立，也就是把骨頭放在那些位置。
grease pencil（蠟筆（Blender 2D 繪圖功能））：字幕中的線條分為生成的線和手繪的線兩種。
line art modifier（線稿修改器）：用來生成 silhouette 和 contour lines。預設線條粗細均勻，講者覺得無聊。
contour lines（輪廓線）：line art modifier 生成的線條之一。
noise（雜訊）：講者加在線條上，讓線條有一點瑕疵、粗糙感。
seed（亂數種子）：講者想讓 collection 裡不同物件有不同的 seed，他認為現有 modifier 做不到。
cut-off distance（截止距離）：在這個距離線條粗細不變，比它近的變細，比它遠的變粗。
vertex group（頂點群組）：決定 modifier 對特定頂點的影響程度。一般只作用在自身物件，講者改成讀取目標物件的。
stroke placement（筆畫放置方式）：在 mesh 上繪製時要設為 surface，筆畫才不會出現在 3D cursor 或其他地方。
offset（偏移）：筆畫和幾何體之間的距離。講者從 0 開始設定。
3D cursor（3D 游標）：字幕提到 stroke placement 沒設成 surface 時，筆畫可能出現在 3D cursor 的位置。
