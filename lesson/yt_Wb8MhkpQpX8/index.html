🧑‍🏫 這支影片示範怎麼用 ChatGPT Work，把同一份 dashboard（儀表板，把重要數字和圖表集中在同一頁的畫面）改成不同對象都看得順的版本。同一份數據常常要給主管、客戶、同事看，但每個人在意的重點不一樣。學會這招，就不用為每個人從頭重做一份。

  • 00:03 每個 stakeholder、每個組織檢視資料的偏好都不同；可以直接編輯文字，例如把 organizations 改叫 clients，做法跟在 analytics report 裡一樣
    ↳ stakeholder 指跟這件事有關、會看報告的人，例如主管或客戶，每個人習慣的說法都不同。你可以直接改字，像把 organizations 改成 clients，改法跟在 analytics report（分析報告）裡一樣。
  • 00:03 進入 edit the graph 可以更換圖表類型，例如把 bar chart 改成 line graph；也可以做出以 KPI 為主、能切換檢視的 business-oriented dashboard
    ↳ 進入 edit the graph（編輯圖表）可以換圖表種類。例如把適合比大小的長條圖 bar chart，改成適合看趨勢的折線圖 line graph。也能做成以 KPI（衡量成效的關鍵數字）為主、可切換檢視的商業版儀表板。
  • 00:33 client 層級有 tree map；下一個 tab 可以追蹤需求隨時間的變化，點選特定 cluster 後所有指標會跟著變，增加互動性又不顯得雜亂
    ↳ tree map 用大小不同的方塊表示各部分的占比，這裡用來看各客戶。下一個 tab（分頁）追蹤需求隨時間的變化。點選某個 cluster（一群性質相近的資料），全頁數字會一起更新，能互動又不雜亂。
📘 術語
stakeholder（利害關係人）：每個 stakeholder、每個組織檢視資料的偏好都不同
tree map（樹狀圖）：影片中在 client 層級使用的視覺化
cluster（群集）：點選特定 cluster 後，dashboard 上所有指標都會跟著變
