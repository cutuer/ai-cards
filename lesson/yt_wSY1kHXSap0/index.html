📘 術語
MCP（MCP（模型上下文協定））：字幕沒解釋名稱；只說 config 裡寫的是 MCP server 的定義（03:01）
connector（連接器）：在 Claude 按 plus > connectors 搜尋安裝，例如 Blender，一鍵完成（01:31）
add-on（附加元件／外掛）：Blender 的 MCP 裝好後，可以在 Edit > Preferences > Add-ons 找到（01:31）
API key（API 金鑰）：使用 full AI、3D AI studio 時要填的金鑰，從各平台的 API keys 頁面取得（03:01）
config (JSON)（設定檔）：Claude desktop 從 settings > developer > edit config 打開的 JSON 檔，可以用 notepad 編輯（02:31）
aggregator（聚合平台）：字幕形容 full AI 集合各種 API，以 API 為主，不是以網站為主（03:01）
frontier models（前沿模型）：字幕只說透過 full AI 幾乎在發布當天就能用（03:01）
PBR（PBR 材質）：字幕沒解釋；只說 patina 模型能生成 PBR 材質（03:32）
shading（著色工作區）：字幕沒解釋；作者切到 shading 查看材質節點怎麼接（04:33）
skill（技能包）：可以隨時取用的擴充；要壓成 zip、skill.md 放在根目錄後上傳，裝完要重啟 Claude（06:03）
.env file（環境變數檔）：skill 資料夾裡的檔案，只寫一行「3D AI studio API key=金鑰」（06:03）
high poly / low poly（高面數／低面數模型）：字幕沒解釋；角色同時有兩種版本，用來 bake（07:33）
bake（烘焙）：字幕沒解釋；示範中把 normal map 與 AO map 烘焙出來再接到 shader（07:33）
normal map（法線貼圖）：字幕沒解釋；bake 出來後接到 shader 上（07:33）
ambient occlusion map（環境光遮蔽貼圖）：字幕沒解釋；bake 出來後接到 shader 上（07:33）
