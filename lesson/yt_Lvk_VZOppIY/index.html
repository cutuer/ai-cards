🧑‍🏫 Codex 是 OpenAI 的 AI 代理工具，你交代任務，它會自己動手做完。這支影片示範幫它裝上資料分析套件後，它能在幾分鐘內從好幾個系統抓資料，做出給主管看的商業報告，再匯出成簡報。值得看的地方是，原本要花好幾個小時的報告工作，幾乎整段都交給它做。

  • 00:00 影片示範如何透過新推出的 data analytics plugin，讓 Codex 成為資料分析團隊的一員
    ↳ plugin 是可以裝進 Codex 的擴充套件，裝了就多一套專門能力。影片示範裝上資料分析專用的 plugin 後，Codex 就能像團隊裡的一位分析師一樣分擔工作。
  • 00:00 data analytics plugin 內含 skills 與 data sources，指向講者的工作流程與工具，用來解決她獨特的商業問題
    ↳ 這個 plugin 裡有兩樣東西。skills 是事先設定好的做事流程和工具，讓 Codex 照講者的方式處理她公司特有的問題。data sources 是資料來源，告訴它要去哪裡拿資料。
  • 00:00 Codex 扮演 agentic data analyst，替使用者建立 business impact reports（商業影響報告）
    ↳ agentic data analyst 指會自己動手的分析師，你給目標，它自己查資料、整理結果。business impact report 是說明某件事對生意帶來多少影響的報告。
  • 00:00 幾分鐘內，Codex 就能從多個不同系統蒐集所有相關脈絡來建立報告
    ↳ 公司的資料常分散在不同系統，平常要一個一個打開、匯出、對照。Codex 會自己去各處把相關資料湊齊，幾分鐘就拼出一份報告。
  • 00:30 產出的 data science artifact 包含詳細分項、圖表與分析，講者說這些平常要花她好幾個小時才做得出來
    ↳ artifact 指分析做完後產出的成品。這裡是一份有細項拆解、圖表和分析說明的報告，講者說這種報告她自己做要花好幾個小時。
  • 00:30 可以即時修改圖表，讓內容對商業使用者更友善
    ↳ 圖表看了覺得不夠清楚，可以直接叫 Codex 改，例如改成業務或主管一眼就看得懂的呈現方式，改完馬上就能看到。
  • 00:30 示範在 Codex 裡把報告做成可編輯的介面
    ↳ 報告不是一張固定的圖，而是在 Codex 裡可以直接操作、修改的畫面，方便一邊看一邊調整。
  • 00:30 可以查看報告背後的 data sources，讓人看清 Codex 如何產出這些報告，也方便判斷是否要在自己的系統裡執行
    ↳ 你可以看到 Codex 用了哪些 data sources 做出這份報告，等於檢查它的數字從哪裡來。確認合理之後，再決定要不要在自己公司的系統裡照樣跑一次。
  • 01:00 為主管準備報告時，Codex 是可以即時編輯、隨時修改的地方
    ↳ 給主管的報告常常要來回修好幾輪。在 Codex 裡可以隨時修改，改完立刻看到結果，準備報告的過程都在同一個地方完成。
  • 01:00 把報告匯出成 Google Slides，以便用主管習慣的既有範本寄給主管
    ↳ Google Slides 是 Google 的線上簡報工具，用法類似 PowerPoint。把報告匯出成 Google Slides，就能套用主管平常看慣的範本，直接寄給主管。
  • 01:00 可以再送一則 follow-up，讓 Codex 參照特定工作流程與範本，確保商業端使用者拿到他們習慣的報告格式
    ↳ follow-up 就是再補送一則指示。例如叫 Codex 照公司固定的流程和範本調整報告，讓業務端的同事拿到他們熟悉的格式。
  • 01:00 最後在 Codex 中看到依公司商業範本產生的報告，而且仍然可以即時修改
    ↳ 最後做好的報告已經套上公司的商業範本，而且還是在 Codex 裡，想改哪裡都可以直接改。
  • 01:32 結論：Codex 成為一站式處理資料分析需求的地方
    ↳ 影片的結論是：從抓資料、分析、做圖表、修改，到做成簡報，整個資料分析流程都可以在 Codex 裡一次處理完。
📘 術語
plugin（外掛）：這裡指 data analytics plugin，內含 skills 與 data sources，指向使用者的工作流程與工具
skills（技能）：plugin 的組成之一，指向解決特定商業問題所需的工作流程與工具
data sources（資料來源）：plugin 的組成之一；查看它可以了解 Codex 是怎麼產出報告的
agentic data analyst（代理式資料分析師）：字幕中形容 Codex 的角色，負責替使用者建立商業影響報告
business impact report（商業影響報告）：Codex 替講者產出的報告，給主管看
artifact（產出物）：這裡指 data science artifact，包含詳細分項、圖表與分析
follow-up（後續追問）：再送一則指示，讓 Codex 參照特定工作流程與範本調整報告
