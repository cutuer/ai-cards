  • 00:03 AI 成為日常工作的一部分後，IT 管理員的角色更具策略性，要負責管理存取權限、成本，並衡量成果。
    ↳ 以前 IT 管理員多半在開帳號、修問題。現在全公司天天用 AI，他得決定誰能用、錢要花多少、用了有沒有效果，工作從維護變成規劃。
  • 00:03 OpenAI 為管理員打造專用工具；新的 APIs for admins 讓管理員能在更大規模下工作。
    ↳ API 是讓程式直接跟系統溝通的管道，不必有人一頁一頁點後台。APIs for admins 是專門給管理員用的 API，人數一多，就能靠它一次查資料、改設定。
  • 00:03 本影片以 ChatGPT Enterprise 為例示範實際操作。
    ↳ ChatGPT Enterprise 是給企業用的 ChatGPT 版本，由公司統一管理帳號和設定。影片拿它當實例，一步一步示範管理員實際怎麼操作。
  • 00:03 第一步：建立 restricted admin key 並存放在 Keychain，讓 worker agent 能安全地使用 API。
    ↳ 先建一把 restricted admin key，也就是權限有限的管理員金鑰，存進 Keychain（電腦裡保管密碼的地方）。worker agent（替妳跑任務的 AI 助手）就能安全地使用 API。

    ↳ Work 就是影片裡這個 worker agent。它會整理出 adoption，也就是大家實際使用 ChatGPT 的程度，並指出使用量集中在哪些人或群組。
  • 00:33 這能幫管理員看出哪些團隊投入程度高，以及哪些地方可能需要更多支援。

    ↳ Work 會把花費偏高的群組標出來，管理員一眼就看得到異常，可以在費用失控之前先去查原因。

    ↳ 針對花最多錢的群組，可以請 Work 建議每人每月的花費上限，並先算出設了上限之後大概會有什麼影響，再決定要不要改。
  • 01:03 Work 會提供清楚的建議，以及做任何變更前應考慮的背景資訊。
    ↳ Work 給建議時不會只丟一個數字，還會附上變更前應該考慮的相關資訊，讓管理員知道這個建議的來由，不是盲目照做。

    ↳ 兩者分工不同：Work 負責日常管理，用聊天就能處理；APIs for administrators 是底層，讓每個 workflow（固定的工作流程）都拿得到資料，也能控制設定。
📘 術語
APIs for admins / APIs for administrators（管理員 API）：新推出的管理員專用 API，讓管理員能在更大規模下工作，並為每個 workflow 提供資料與控制功能。
restricted admin key（受限管理員金鑰）：示範中第一步建立的金鑰，存放在 Keychain，讓 worker agent 能安全使用 API。
Keychain（鑰匙圈（金鑰儲存處））：字幕只提到把 restricted admin key 存放在這裡。
worker agent / Work（工作代理）：透過 API 執行任務的 agent，能摘要使用狀況、提出建議並套用變更。
adoption（採用程度）：Work 會摘要的使用程度，並顯示使用量集中在哪裡。
workspace（工作區）：ChatGPT Enterprise 中管理的範圍，可比較群組花費與 workspace 平均。
admin interface（管理介面）：Work 套用上限後，管理員在這裡檢查變更，確保完全掌控。
workflow（工作流程）：APIs for administrators 為每個 workflow 提供資料與控制功能。
