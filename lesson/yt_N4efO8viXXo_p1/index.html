🧑‍🏫 這是 Anthropic 在東京辦的開發者大會開場演講。他們在會上發表了第五代模型 Fable 5 和 Mythos 5，也用樂天、Canva 這些實際案例，說明 AI 已經從「幫忙寫一小段」進步到「自己把整件事做完」。想知道 AI 進步多快、企業怎麼用它，看這段就能掌握全貌。

  • 01:53 這是 Code with Claude 第一次在日本舉辦。開場講者是 Anthropic 的 Claude 平台工程負責人 Caitlyn。
    ↳ Code with Claude 是 Anthropic 辦給開發者的活動，這次第一次在日本舉行。開場的 Caitlyn 負責 Claude 平台的工程，也就是開發者拿來串接 Claude 的那一整套工具。
  • 02:23 上午會談三件事：模型、平台、產品。
    ↳ 上午分成三塊：模型，也就是 Claude 本身的大腦；平台，給開發者用來打造服務的工具；產品，一般人直接拿來用的東西。
  • 02:23 幾小時前 Anthropic 發表了第五代 Claude 模型 Claude Mythos 5 和 Claude Fable 5，是他們至今能力最強的兩個模型。
    ↳ 活動前幾小時才剛發表第五代 Claude：Mythos 5 和 Fable 5。「第五代」代表整個系列進入新一輪，官方說這兩個是他們目前最強的模型。
  • 02:54 Claude 平台提供開發者工具，讓他們在 Claude 上面建系統、運用它的智慧。講者說這是幫忙解決世界重要問題最有槓桿效果的方式。
    ↳ Anthropic 自己能做的事有限。把 Claude 的能力做成工具交給開發者，讓很多人拿去解決各自領域的問題，影響力就會放大好幾倍，這就是「槓桿」的意思。
  • 02:54 講者說 Anthropic 是一家平台公司，因為開發者在平台上創造的價值，遠超過 Anthropic 自己做得出來的。
    ↳ platform company（平台公司）是指靠別人在上面做東西來創造價值的公司。講者直接承認，外面開發者做出來的應用加起來，遠比 Anthropic 自己做得出來的多。
  • 03:24 講者說現在有大量強大的應用正在上線，其中很多來自日本。
    ↳ 意思是這些不是紙上談兵，已經有大量真的上線、有人在用的服務，而且其中不少來自日本本地。
  • 03:24 Rakuten 案例：一開始用 Claude Code 加快開發，後來在 Claude Managed Agents 上打造內部自訂 agent，用在工程、產品、業務和財務部門。
    ↳ 樂天先用 Claude Code（讓 Claude 幫忙寫程式的工具）加快開發，再用 Claude Managed Agents（建立、部署 agent 的平台服務）做內部 agent，也就是會自己完成任務的 AI，用到業務和財務部門。
  • 03:55 Rakuten 有一位產品經理帶領多個 agent 團隊，方式就跟主管帶人類團隊一樣。
    ↳ 一位產品經理同時帶好幾組 agent，派工作、看成果，就像主管帶真人團隊。人的角色從親手做事，變成帶隊和把關。
  • 03:55 Rakuten 的大版本發布從每季一次變成每兩週一次。
    ↳ 大版本從一季發一次變成兩週發一次，一年大約從 4 次變成 26 次，新功能到使用者手上的速度快了好幾倍。
  • 03:55 Canva 案例：Canva 是澳洲的設計平台，有數億人在用，大部分使用者從沒寫過程式。
    ↳ Canva 是很多人拿來做海報、簡報的線上設計工具。它的使用者大多不會寫程式，所以這個案例是在說明 AI 讓不懂程式的人也能用上程式的能力。
  • 04:27 透過 Canva Code，使用者可以在設計裡直接要求地圖、計算機、小工具這類互動元件，Claude 會把它做成能直接放進頁面的小型 app。
    ↳ Canva Code 讓你在設計裡直接說「我要一個地圖」或「放個計算機」，Claude 就會做出能實際操作的小 app 放進頁面，你完全不用碰程式碼。
  • 04:27 講者說各地的人正在用 Claude 打造以前沒人做得出來的系統，變化速度比以往都快。
    ↳ 以前沒有人做得出來的系統，現在各地都有人在做，而且這種變化來得一波比一波快。
  • 04:58 Anthropic 的使命是不斷做出更強的模型，把「能做出什麼」的上限一直往上推。
    ↳ Anthropic 把自己的工作定位成持續做出更強的模型。模型每變強一次，開發者能做到的事的天花板就跟著往上升。
  • 04:58 幾年前，前沿模型的能力只到寫簡單的 commit message。
    ↳ commit message 是工程師每次修改程式時附上的一句簡短說明，例如「修正登入錯誤」。幾年前最先進的 AI 也只做得到這種小事。
  • 04:58 一年前的第一屆 Code with Claude，主角是 Opus 4，當時 Claude 能獨力完成整個功能，讓大家很震撼。
    ↳ 一年前的第一屆大會，主角是當時的 Opus 4。它能自己把一整個功能從頭做到完，不只是寫片段，當時讓大家很震撼。
  • 05:29 六個月前，agent 已經能整晚執行，完成長時間的自主任務。
    ↳ 半年前，agent 已經能在你下班後自己跑一整晚，連續處理好幾個小時的任務，不用有人一直盯著。
  • 05:29 兩個月前，Mythos 讀完整個 OpenBSD 原始碼，找到一個存在 27 年的漏洞，近三十年來都沒被人工審查或靜態分析發現。
    ↳ OpenBSD 是以安全著稱的開源作業系統；static analysis（靜態分析）是不執行程式、直接掃程式碼找錯的工具。這個漏洞躲過人工和工具整整 27 年，最後被 Mythos 找到。
  • 05:29 Fable 5 在幾乎所有測過的 AI 能力 benchmark 都是業界最佳，在軟體工程、知識工作、科學研究、視覺等方面表現特別好。
    ↳ benchmark 是業界共用的標準測驗，用來比較不同 AI 的能力。Fable 5 在幾乎所有這類測驗都拿第一，寫程式、知識工作、科學研究、看圖都特別強。
  • 06:00 能力進步的幅度越來越大，間隔卻越來越短。
    ↳ 把前面的時間軸排起來看：幾年前、一年前、半年前、兩個月前。每次進步的幅度都更大，間隔卻越來越短。
  • 06:00 模型能力呈指數成長，大多數企業的能力卻還在線性成長，所以 AI「做得到的」和「實際幫人做到的」差距越拉越大。講者說縮小這個差距是大家共同的機會。
    ↳ 指數成長像每次翻倍，線性成長像每次加一點。AI 用翻倍的速度在進步，企業卻一步一步慢慢跟上，所以 AI 做得到的和實際用上的差距越拉越大，補上這段差距就是機會。
  • 06:30 Claude 平台的 API 用量比去年同期成長將近 17 倍。
    ↳ API 是讓其他程式直接呼叫 Claude 的接口，開發者做產品都要靠它。API 用量一年成長將近 17 倍，代表有越來越多產品在背後使用 Claude。
  • 07:00 上午議程：先由 Diane 介紹模型（Mythos 5、Fable 5 和接下來的計畫），再由 Angela 和講者示範怎麼用 Claude Managed Agents 大規模建立和部署 agent，最後由 Cat 介紹 Claude Code。
    ↳ 上午的流程：Diane 先講新模型和接下來的計畫；再由 Angela 和 Caitlyn 示範怎麼用 Claude Managed Agents 大量建立、上線 agent；最後由 Cat 介紹 Claude Code。
  • 07:00 Claude Managed Agents 新功能一：可以排程部署，讓 agent 照你需要的頻率執行。
    ↳ schedule deployments（排程部署）就是幫 agent 排時間表，例如設定每天早上自動跑一次，不用每次都手動叫它開始。
  • 07:00 Claude Managed Agents 新功能二：環境變數可以存在 vault 裡，agent 能安全地發出需要驗證的 API 請求，但拿不到金鑰本身。
    ↳ environment variables（環境變數）是程式執行時讀取的設定，常拿來放密碼或金鑰。vault 就像保險箱：agent 能用裡面的金鑰去存取服務，卻看不到金鑰本身，比較不怕外洩。
  • 07:31 Claude Code 的一般開發者現在每週跟 Claude 相處 20 小時。Cat 會介紹新的 agent view 和 dynamic workflows。
    ↳ 一般開發者每週和 Claude 一起工作約 20 小時，大概是半個工作週。agent view 和 dynamic workflows 是 Claude Code 的新功能，這段只提到名稱，細節留給 Cat 介紹。
  • 07:31 大多數人不會自己串 Claude API，也不會打開終端機輸入 Claude。他們是透過開發者在 Claude 平台上做的產品接觸到 AI。
    ↳ 終端機是用打字下指令來操作電腦的視窗。大多數人不會這樣用 Claude，而是透過別人做好的 app 間接用到它，所以平台上的開發者是讓 AI 普及的關鍵。
  • 08:01 舉例：業務靠 Slack agents 在重要會議前掌握完整資訊；律師用 Lagora 更快交出文件；開發者使用各種頂尖的 coding agent。
    ↳ Slack 是公司常用的聊天工具，業務在上面用 agent 在重要會議前把資訊整理齊全。律師用 Lagora 這個產品更快交出文件，工程師則用各種會寫程式的 agent。
  • 09:02 第二位講者 Diane 是研究產品管理負責人，2023 年加入 Anthropic，從 Claude 2 起參與每一版 Claude。
    ↳ Diane 負責研究產品管理，大致是銜接研究團隊和產品的角色。她 2023 年加入 Anthropic，從 Claude 2 開始每一版都有參與。
  • 09:33 Diane 參與過 21 個版本的 Claude，橫跨 Haiku、Sonnet、Opus，現在加上 Fable 和 Mythos。
    ↳ Haiku、Sonnet、Opus 是 Claude 從輕快到強大的不同型號系列。Diane 經手過 21 個版本，現在又多了 Fable 和 Mythos 兩個新系列。
  • 09:33 Claude Fable 5 和 Claude Mythos 5 是第五代的第一批模型。
    ↳ Fable 5 和 Mythos 5 是第五代最先推出的兩個模型，代表 Claude 正式進入新的一代。
  • 10:03 Fable 5 是 Anthropic 至今正式開放（generally available）的模型中能力最強的，和 Mythos 5 建立在相同的基礎上。
    ↳ generally available（正式開放）是指大家都能正式取用，而不是限定少數人試用。Fable 5 是目前正式開放的模型中最強的，而且和 Mythos 5 建立在同一套基礎上。
  • 10:03 這些模型已經在加速 Anthropic 內部的工作。對開發者來說，Claude 會更強，大家的起跑線也會往前移。
    ↳ Anthropic 自己的員工已經在用這些模型加快工作。對開發者來說，Claude 變強，大家的起跑點就一起往前，以前做不到的事可能變得做得到。
  • 10:03 Diane 接著開始解釋 Anthropic 常說的「exponential（指數成長）」實際上是什麼意思（本段在此結束）。
    ↳ exponential（指數成長）是 Anthropic 常掛在嘴邊的詞。Diane 正要解釋它實際代表什麼，這段影片就停在這裡，後續接在下一段。
📘 術語
Claude Managed Agents（Claude 託管 agent 服務）：在 Claude 平台上大規模建立、部署 agent 的方式；新增排程部署和 vault 功能
agent（代理程式）：能自主執行任務的 AI 系統；六個月前已能整晚執行長時間自主任務
vault（保管庫）：存放環境變數，讓 agent 能發出需要驗證的 API 請求，但拿不到金鑰
environment variables（環境變數）：可以存在 vault 裡，供 agent 發出需要驗證的 API 請求
schedule deployments（排程部署）：讓 agent 照你需要的頻率執行
Canva Code（Canva Code）：在 Canva 設計裡要求互動元件，由 Claude 做成可直接放進頁面的小型 app
commit message（提交訊息）：幾年前前沿模型的能力只到寫簡單的 commit message
static analysis（靜態分析）：字幕提到那個 27 年的漏洞躲過了人工審查和靜態分析
benchmark（基準測試）：Fable 5 在幾乎所有測過的 AI 能力 benchmark 都是業界最佳
generally available（正式開放）：Fable 5 是至今正式開放的模型中能力最強的
exponential vs. linear（指數 vs. 線性）：模型能力呈指數成長，企業能力仍是線性，兩者差距越來越大
agent view（agent 檢視）：Claude Code 新功能，字幕只提到名稱，由 Cat 介紹
dynamic workflows（動態工作流程）：Claude Code 新功能，字幕只提到名稱

✏️ 小考一題

根據演講，Rakuten 用 Claude Managed Agents 打造內部 agent 後，大版本的發布頻率變成怎樣？

A. 從每年一次變成每月一次B. 從每季一次變成每天一次C. 從每季一次變成每兩週一次D. 從每月一次變成每週一次
看答案
答案：C。[03:55] 講者說 Rakuten 現在每兩週發布一次大版本，以前是每季才一次。
