📘 術語
Track Changes（追蹤修訂）：開啟後 Claude 每個修改都會顯示出來，由你決定接受或拒絕
redline（紅線修改）：修正在動到文件前以卡片顯示的確切修改內容，套用後成為追蹤修訂
review cards（審閱卡片）：Claude 提出的修改以卡片呈現，可展開下方分頁查看推理
Allow once（僅允許一次）：Claude 改變文件編輯模式前徵詢時，使用者點選的選項
Box（Box（檔案儲存服務））：影片中團隊存放 Early Access 成效文件的地方，Claude 可去那裡找文件
skill（技能）：處理可重複任務的功能；有內建的，也能在 Claude 帳號自建，輸入 / 叫出
copy edit skill（文字校對 skill）：專注於拼字、文法、標點與一致性的內建 skill
social proof（社會認同）：影片中指「9,000 個團隊與 Fortune 500」這句，是 VP 想要的內容
Claude for Microsoft 365（Claude for Microsoft 365）：Claude for Word 所屬的產品，可在 Microsoft AppSource marketplace 取得
✏️ 小考一題

影片中，使用者請 Claude 「接受所有追蹤修訂」時，對註解串下了什麼指示？

A. 只保留 Priya 與 Daniel 的註解串B. 保留註解串，讓團隊看到改了什麼C. 把註解串匯出成另一份摘要文件D. 刪除所有已處理的註解串
看答案
