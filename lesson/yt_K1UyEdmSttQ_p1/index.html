🧑‍🏫 這段教你在 Blender 裡匯入一張參考照片，把它擺好角度和大小，再照著照片把原本很陽春的咖啡杯捏成像樣的形狀。重點不只是操作，還有一個建模觀念：人的記憶會自動省略細節，所以要看著實物照片做，不要憑印象。

  • 00:00 本段目標：把原本像「可憐小杯子」的咖啡杯，修成真正像咖啡杯的樣子
    ↳ 上一段做出來的杯子只是粗胚，形狀很陽春。這段的目標是把它修到一眼就看得出是咖啡杯。
  • 00:00 3D 裡憑想像建模，結果幾乎都會有點怪，因為大腦很擅長把對它不重要的資訊抽象化、省略掉
    ↳ 人記東西只記重點，細節會被大腦自動略過。所以光憑腦中印象做 3D，成品總會少了些東西，看起來怪怪的。
  • 00:32 門把例子：憑印象只想得到球體＋圓柱，做出來很簡陋；實物還有內側小唇邊、鑰匙小孔、接縫邊框、前方隱私鎖等被大腦忽略的細節
    ↳ 你以為門把就是一顆球加一根棒子。真的去看，才會發現內側小凸邊、鑰匙孔、接縫邊框、隱私鎖這些平常根本沒注意的東西。
  • 01:05 連咖啡杯這麼常見的東西也一樣，所以可以的話要用參考圖（reference images）
    ↳ 咖啡杯天天在用，一樣會記錯。所以建模時最好準備參考圖（reference images，就是邊做邊對照的照片），不要只靠想像。
  • 01:05 參考圖可從網路任意取得，例如在 Google Images 搜尋「handmade coffee mug」，挑任何想做的杯子
    ↳ 參考圖不必找專業素材，上網搜就行。例如搜「handmade coffee mug」（手工馬克杯），挑一個你喜歡、想做的樣子。
  • 01:40 題外話：看到手工杯要價 $123.25（原價 145 打折），還有九則評論代表真的有人買
    ↳ 講者順口吐槽：找圖時看到一個手工杯打折後還要 $123.25，而且有九則評論，表示真的有人買。
  • 02:13 題外話：大家常忘記人工成本，手工杯要花好幾小時製作，$33 大概只是打平成本
    ↳ 他接著說，大家常忘了手工要花好幾個小時，把工錢算進去，$33 大概也只是打平。這段跟操作無關，聽聽就好。
  • 02:47 講者使用的參考圖連結在影片下方，放在他的網站上，本教學用到的所有連結都在那裡
    ↳ 想用跟講者一樣的圖，可以到影片說明欄找連結。連結會連到他的網站，這整套教學用到的連結都放在那裡。
  • 02:47 加入圖片方法一：Add 選單 → Image → Reference，再選取參考圖檔案
    ↳ 第一種放圖方式：點上方的 Add（新增）選單 → Image → Reference，選好檔案後，圖就會出現在場景裡當參考。
  • 02:47 加入圖片方法二：從電腦直接拖放進 Blender，會被辨識為圖片並以 image object 匯入（以前不能這樣做）
    ↳ 第二種更快：直接把圖片從電腦資料夾拖進 Blender 視窗，它會自動變成 image object（場景裡的圖片物件）。講者說以前不能這樣做。
  • 03:20 匯入後環繞視角會發現圖片角度怪怪的，講者推測是鎖定在匯入當下的視角，他從來不需要這樣
    ↳ 放進來後轉一下視角，會發現圖片歪歪斜斜的。講者猜是它沿用了匯入當下的視角方向，但他自己從來用不到這個功能。
  • 03:20 先清除旋轉：按 Alt R，或走選單 Object → Clear → Rotation，效果相同；清除後圖片會平躺
    ↳ 先按 Alt+R 把旋轉歸零，效果跟選單 Object → Clear → Rotation 一樣。歸零後圖片會平躺，像一張放在桌上的照片。
  • 03:50 按 R 旋轉時是自由旋轉，而且相對於目前觀看的角度
    ↳ 接著按 R 旋轉。這時是自由轉，而且以你目前看畫面的角度為準，換個視角轉出來的結果就不一樣。
  • 03:50 在 rotate、scale、grab 等移動狀態下，按下軸的字母即可鎖定在該軸
    ↳ 小技巧：在旋轉（rotate）、縮放（scale）、移動（grab）的過程中，按某個軸的字母，物件就只會沿那條軸動，不會亂跑。
  • 05:00 不知道軸的字母時可看右上角：紅色是 X 軸，這裡按 X 鎖定
    ↳ 3D 空間有 X、Y、Z 三條軸。忘了哪條是哪條，就看右上角的小座標圖示，紅色是 X。這裡要讓圖片立起來，所以按 X。
  • 05:00 要轉 90 度：按住 Control 會以 5 度為單位轉動，或直接鍵盤輸入 90 再按 Enter
    ↳ 要剛好轉 90 度有兩種做法：按住 Ctrl 拖曳，每次會跳 5 度；更省事的是直接打 90 再按 Enter。
  • 05:32 圖片太大，按 S 縮放；杯子被圖片擋住，就把杯子往前移
    ↳ 圖片通常太大，按 S 縮小。如果杯子被圖片擋住看不到，就把杯子往前移一點。
  • 05:32 點畫面上方的小 -Y 可切到正面視角
    ↳ 畫面右上角的座標圖示上有個小小的 -Y，點它就會切到正對物件的正面視角。
  • 06:02 數字鍵盤快捷鍵：Numpad 1 正面、Numpad 3 側面、Numpad 7 頂視；沒有數字鍵盤就用畫面上的按鈕
    ↳ 有數字鍵盤的話，Numpad 1 是正面、3 是側面、7 是從上往下看。筆電沒有數字鍵盤，就點畫面上的座標按鈕。
  • 06:02 滾輪縮放畫面，Shift＋滑鼠中鍵平移
    ↳ 滑鼠滾輪可以拉近拉遠。按住 Shift 再按住滾輪（中鍵）拖曳，可以平移畫面。
  • 06:02 把圖片縮到跟杯子差不多大；因為杯子相對甜甜圈的大小已正確，以它為基準即可
    ↳ 把圖片縮到跟杯子模型差不多大。杯子和甜甜圈的比例之前已經調好，所以拿杯子當尺就對了。
  • 06:34 對齊標準：讓圖片中杯口頂端的邊，大致對上杯子模型的相對位置（杯底也對齊）
    ↳ 對齊方法：讓照片裡杯口的上緣大致對到模型杯口的高度，杯底也對到杯底，大小就差不多了。
  • 06:34 照片是真實相機拍的、帶有透視，但我們在 3D 軸向視角看是扁平的，所以很難完全對齊
    ↳ 照片是相機拍的，有近大遠小的透視；現在用的視角卻是沒有透視的平面視角，所以一定對不完美，差不多就好。
  • 06:34 點畫面上的小按鈕可回到 perspective mode，會看到角度等出現透視變形
    ↳ 點畫面上的小按鈕可以切回 perspective mode（透視模式，像人眼一樣近大遠小），會看到畫面角度跟著變形。
  • 07:04 最好的參考是正交（orthographic）的，例如藍圖，但通常拿不到，只能用一般照片大概估計
    ↳ 最理想的參考是 orthographic（正交，沒有透視的平面圖），例如藍圖。但手工杯通常沒有藍圖，只能用照片抓個大概。
  • 07:04 按 Tab 進出 edit mode，開始把模型塑形成參考圖的杯子
    ↳ 按 Tab 進入 edit mode（編輯模式，可以直接拉點、線、面來改形狀），再按一次就離開。接下來就在這裡照參考圖捏杯子。
  • 07:04 觀察整體外形：杯身往上收窄，大約在某個中間點開始反轉往另一方向
    ↳ 先別急著動手，看整體輪廓：杯身往上漸漸變窄，到某個位置後又往反方向走。這條曲線就是要做出來的樣子。
  • 07:38 這是很平滑的物件，非常適合用已加上的 Subsurf modifier
    ↳ 杯子表面很圓滑，很適合之前加的 Subsurf modifier（細分曲面，會自動把稜角磨圓）。所以不用自己拉很多線。
  • 07:38 進入 edge select mode，按住 Alt 左鍵點杯口那圈線的中段選取整圈；點在中間的點上會選到別的邊
    ↳ 切到 edge select mode（選邊模式），按住 Alt 點杯口那圈線的中段，整圈會一起被選取。點到線上的點，會選到別的方向。
  • 08:10 將杯口那圈縮小一點；再 Alt 點選下面一圈，同樣縮放，大約縮一半的幅度
    ↳ 杯口那圈按 S 縮小一點。再用 Alt 點選下面一圈，也縮小，大約縮一半的幅度。
  • 08:10 杯身最寬處大約在杯子往上 20% 的位置，底部還有一圈唇邊
    ↳ 對照照片看，杯身最胖的地方大約在從底部往上 20% 的位置，最底下還有一圈小小的凸邊。
  • 08:10 連按兩下 G（GG）可沿模型滑動邊線，把那圈線往上移到最寬處
    ↳ 快速按兩次 G（GG），選到的線會貼著模型表面滑動，形狀不會被拉壞。用它把那圈線推到最寬的位置。
  • 08:45 按 S 把該圈往外拉讓它變寬；再把旁邊不太對的那圈也稍微放大
    ↳ 按 S 把那圈放大，讓杯身變胖。旁邊那圈看起來不順的，也稍微放大，讓曲線接得自然。
  • 08:45 底部需要更多細節，用 GG 把線往上滑，讓邊緣呈現更彎曲的收窄，再按 S 縮放
    ↳ 底部需要更多轉折：先用 GG 把線往上滑，讓底邊收得更圓，再按 S 調整大小。
  • 10:00 講者全憑目測估計形狀；只靠移動、滑動線條和縮放，就能很快塑造任何物件
    ↳ 講者完全用眼睛估，沒有量數字。重點是：只靠移動、滑線、縮放這三招，就能很快捏出大部分物件的外形。
  • 10:00 按 3 或切到 face select mode，接下來要處理杯底那個面，把它做成底部的小唇邊（lip）
    ↳ 按 3 切到 face select mode（選面模式），下一步要處理杯底的面，做出底部那圈小唇邊（lip，杯底微微突出的邊）。
📘 術語
reference images（參考圖）：建模時參照的圖片，避免憑想像建模漏掉細節，可從網路取得
image object（圖片物件）：把圖片拖放進 Blender 後，會被辨識並以 image object 匯入
Alt R（Clear Rotation）（清除旋轉）：清除物件的旋轉，等同 Object → Clear → Rotation
axis lock（鎖定軸向）：在 rotate、scale、grab 狀態下按軸的字母，就會鎖定在那個軸
X axis（X 軸）：畫面右上角紅色的那條軸
perspective mode（透視模式）：點畫面上的小按鈕可回到此模式，會看到角度等出現透視變形
orthographic（正交）：最好的參考圖是正交的，例如藍圖，但通常拿不到
edit mode（編輯模式）：按 Tab 進出，在這裡對模型塑形
Subsurf modifier（Subsurf 修改器）：已加在杯子上，很適合用在杯子這種平滑的物件
edge select mode（邊選取模式）：選取邊的模式；按住 Alt 點線的中段可選整圈邊
GG（edge slide）（滑動邊線）：連按兩下 G，可讓選取的邊沿模型滑動
face select mode（面選取模式）：選取面的模式，也可以直接按 3 切換
Numpad 1 / 3 / 7（數字鍵盤視角）：1 是正面、3 是側面、7 是頂視
