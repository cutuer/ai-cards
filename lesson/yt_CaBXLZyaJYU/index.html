🧑‍🏫 這支影片示範 ChatGPT for Excel（直接在 Excel 裡用的 ChatGPT）怎麼檢查一份財務模型：先找出問題，只修安全的部分，再把做過的事都記在檔案裡。很多重要決定都靠一份沒人仔細驗過的 Excel，這支影片教你怎麼在交出去前先把關。

  • 00:10 財務模型常在還沒完整審查前，就被拿來支撐重要決策
    ↳ 財務模型（financial model，就是用 Excel 算營收、成本、未來預估的那套表）常常還沒被人從頭到尾檢查過，就已經被拿去當重大決定的依據。
  • 00:10 含財務模型的 Excel 活頁簿可能支撐預測、董事會會議或其他重要財務決策
    ↳ 一個 Excel 檔（workbook，活頁簿，也就是整個檔案，裡面可以有很多分頁）可能撐著明年預測或董事會報告，錯一格，影響的可能是整個決策。
  • 00:10 活頁簿可能有公式被覆寫、儲存格損壞或資料過時，導致對財務模型本身的假設不準確
    ↳ 常見毛病有三種：公式被人改成手打數字、儲存格壞掉、資料沒更新。表面上看不出來，大家就誤以為模型是對的。
  • 00:10 透過 ChatGPT for Excel，財務團隊可以直接在工作發生的地方審查並清理活頁簿
    ↳ 不用把檔案搬到別的工具，ChatGPT 直接在 Excel 裡幫忙檢查和整理。平常在哪裡工作，就在哪裡處理。
  • 00:42 ChatGPT for Excel 由 skills 驅動，例如 finance model Q&A 和 model audit tie out
    ↳ skills 是預先設計好的工作方法，告訴 ChatGPT 遇到某類任務該怎麼做。影片舉了 finance model Q&A 和 model audit tie out 兩個，但沒細講內容。
  • 00:42 這些 skills 讓財務審查流程貼近團隊實際運作與做生意的方式
    ↳ 這些 skills 是照財務團隊平常的做事流程設計的。它不是隨便聊天，而是按實務習慣一步步審。
  • 00:42 功能包含檢查財務模型，以及對活頁簿套用安全的修正
    ↳ 它做兩件事：一是檢查模型哪裡有問題，二是對檔案做安全的修改，也就是不會動到計算邏輯的那種。
  • 00:42 skills 引導 ChatGPT 像真人財務分析師一樣進行審查
    ↳ 有了 skills，ChatGPT 檢查的順序和重點會接近有經驗的財務分析師，不是隨便掃過去。
  • 00:42 審查步驟包括：對應各分頁（mapping the tabs）、檢查公式
    ↳ 它會先搞清楚每個分頁在做什麼、彼此怎麼連動（mapping the tabs，等於畫一張分頁地圖），再逐一檢查公式。
  • 01:13 也會標記可能影響預測或董事會敘事的問題
    ↳ 它會特別指出哪些錯可能讓預測數字，或向董事會報告的內容走樣，讓你知道最要緊的是哪裡。
  • 01:13 在做任何修改之前，會先產生一個 QA 檢視
    ↳ 動手改之前，它會先給一份 QA 檢視（QA view，品質檢查的總覽），讓你看清楚問題全貌，再決定下一步。
  • 01:13 活頁簿問題被分成「重要的問題」與「可以安全清理的問題」兩類
    ↳ 問題分兩堆：一堆會影響結論，需要人好好看；另一堆只是單純整理性質，修了也不會改變判斷。
  • 01:13 接著要求 ChatGPT for Excel 只套用機械性清理，需要判斷的部分留給模型擁有者決定
    ↳ 影片中是明確要求它只做機械性清理（mechanical clean up，照規則就能修、不用判斷的整理）。需要判斷的事（judgment calls）留給負責這份模型的人決定。
  • 01:47 清理活頁簿機械性問題時會保留原本的財務邏輯
    ↳ 清理時不動原本的算法和假設，只修整理層面的問題，模型的財務邏輯維持原樣。
  • 01:47 仍需人工審查的項目會被記錄下來
    ↳ 它不會假裝全部都處理好了。還需要人看的項目會一條條記下來，不會漏掉。
  • 01:47 ChatGPT for Excel 直接在檔案中新增分頁：QA issue log、fixes applied、remaining risks 等
    ↳ 它直接在同一個 Excel 檔裡新增分頁：問題紀錄（QA issue log）、已套用的修正（fixes applied）、剩下的風險（remaining risks），打開檔案就看得到。
  • 01:47 結果得到公式正確、建模正確、可靠的活頁簿
    ↳ 最後得到一份公式正確、建模正確，可以放心使用的檔案。
  • 02:18 幫助財務團隊在活頁簿送到主管階層前降低模型風險（model risk）
    ↳ model risk 指模型本身出錯、導致決策跟著出錯的風險。在檔案送到主管手上之前先處理，這個風險就降低了。
  • 02:18 取代人工翻找活頁簿，團隊得到乾淨的檔案、稽核軌跡，以及待審查項目的清單
    ↳ 以前要人工一格一格翻，現在會得到三樣東西：乾淨的檔案、稽核軌跡（audit trail，記錄改過什麼、方便事後追查），以及還要人看的清單。
  • 02:18 財務模型因此更容易被信任，可安全用於重要財務決策
    ↳ 有檢查、有紀錄、有待辦清單，別人拿到這份模型時比較敢相信，也能放心拿來做重要決定。
📘 術語
financial model（財務模型）：放在 Excel 活頁簿中，用來支撐預測、董事會會議等財務決策的模型
workbook（活頁簿）：Excel 檔案，影片中包含財務模型，可能有覆寫公式、壞掉的儲存格或過時資料
skills（技能）：驅動 ChatGPT for Excel 的能力，引導它像真人財務分析師一樣審查
finance model Q&A（財務模型問答）：字幕列舉的 skill 之一，未進一步說明
model audit tie out（模型稽核核對）：字幕列舉的 skill 之一，未進一步說明
QA view（品質檢查檢視）：修改前產生的檢視，把問題分成重要的和可安全清理的
mechanical clean up（機械性清理）：只做機械層面的清理，保留財務邏輯，判斷性的部分留給模型擁有者
judgment calls（需判斷的決定）：不自動處理、留給模型擁有者決定的事項
audit trail（稽核軌跡）：清理後檔案附帶的紀錄，搭配待審查項目清單
model risk（模型風險）：ChatGPT for Excel 幫助在活頁簿送到主管前降低的風險
✏️ 小考一題

影片中，ChatGPT for Excel 被要求清理活頁簿時，對於「需要判斷的部分（judgment calls）」如何處理？

A. 寄給主管階層審核B. 全部刪除以避免錯誤C. 留給模型擁有者決定，只套用機械性清理D. 由 ChatGPT 依財務分析師標準自動修正
看答案
答案：C。[01:13] 字幕說只要求套用 mechanical clean up，並把 judgment calls 留給模型擁有者（owner of the model）
