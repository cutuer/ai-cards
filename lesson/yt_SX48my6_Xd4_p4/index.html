🧑‍🏫 這段是 BCON26 講座最後一段，示範怎麼用 Blender 的 Grease Pencil 把 2D 手繪和 3D 場景混在一起，做出 previz（正式製作前的預覽版影片）。重點不只是技巧，講者也說明為什麼要在前期花力氣反覆修改故事，以及怎麼用這個粗略版本去跟導演、客戶溝通。

  • 36:11 用材質做描邊：準備兩個材質，一個白色、一個外框（outline），材質要勾選 backface culling
    ↳ 描邊先準備兩個材質：白色當本體，另一個當外框（outline）。材質要勾 backface culling，這個選項會讓物件背面不顯示，外框才不會蓋住本體。
  • 36:11 接著在 modifiers 加 Solidify modifier，翻轉 normals，再設定 material offset。講者說很簡單，可以自己 Google
    ↳ 接著加 Solidify modifier（替物件長出一層厚度的工具），翻轉 normals（每個面朝外的方向），再用 material offset 讓這層外殼套上外框材質。細節講者請大家自己查。
  • 36:11 這個做法能讓 3D 物件看起來像 2D，又不會像很彆扭的基本形狀（primitive shapes）
    ↳ 做完之後，3D 物件看起來像手畫的 2D 圖，不會一眼就被認出是方塊、圓柱這類生硬的 primitive shapes（Blender 內建的簡單幾何體）。
  • 36:45 很多背景是用前面環境探索的方法做的。植物不用上色，用簡單的黑白就能增加明暗（value）
    ↳ 很多背景沿用前面探索環境的做法。植物不用上色，只用黑白就能拉出 value（畫面的深淺明暗），讓畫面有層次。
  • 36:45 這種做法讓專案明顯 lag。建議做完後，繼續製作專案時先把它停用
    ↳ 缺點是很吃電腦效能，專案會明顯 lag（卡頓）。建議效果確認好就先停用，做後面的部分會比較順。
  • 37:19 講者畫草稿時喜歡用 pencil 4B 筆刷，但也說用什麼都可以
    ↳ 講者畫草稿愛用 pencil 4B 筆刷，但他也說這不是重點，用自己順手的就好。
  • 37:19 做 2D/3D 混合時，講者喜歡進入攝影機視角並把 pass out（字幕原文）調高，因為周圍空間會讓他分心
    ↳ 做 2D/3D 混合時，他會切到攝影機視角，把字幕寫成 pass out 的設定調高，應該是指讓鏡頭框外變暗的選項。這樣眼睛只看畫面內，不會被周圍分心。
  • 37:54 如果從物件切不進 Draw 模式，記得要先選到 grease pencil 物件，才能進入 Draw
    ↳ 切不進 Draw（畫圖）模式時，多半是選錯東西。要先選到 grease pencil 物件，也就是 Blender 裡專門拿來畫 2D 線條的物件，才能進去畫。
  • 38:24 示範畫道路草稿。道路有很好的透視，能幫你掌握畫面的透視感
    ↳ 他示範先畫道路草稿。道路往遠方收窄，透視非常明顯，先把它畫出來，等於先幫整個畫面定好透視方向。
  • 38:24 Grease pencil 可以徒手畫，也可以用 line 畫出乾淨的線條，還能搭配新的 grease pencil 筆刷使用 line
    ↳ Grease pencil 可以徒手畫，也能用 line（畫直線的工具）拉出乾淨的線條。新版的 grease pencil 筆刷也可以搭配 line 使用。
  • 38:56 常見流程：先畫一層 sketch（草稿），再畫一層 refined lines（精修線條）
    ↳ 常見做法分兩層：先畫一層 sketch（草稿）抓出大概，再疊一層 refined lines（精修線條），把輪廓畫乾淨。
  • 38:56 line 工具畫完後，如果想換位置，還可以直接調整。講者說「問題解決」
    ↳ 用 line 畫好的線，位置不對可以直接拉動調整，不必擦掉重畫。講者一句「問題解決」，意思是改起來很省事。
  • 39:28 非常推薦用這種方式發想。storyboard artists 會把很簡單的東西一改再改，直到故事完美
    ↳ 他很推薦用這種方式發想。storyboard artists（分鏡師）會把很簡單的畫面一改再改，直到故事講得順為止。
  • 39:28 反覆修改很重要，因為這能讓其他人參與你的流程。也不要害怕刪掉原本說故事的方式
    ↳ 反覆修改的價值在於別人能參與進來、一起給意見。原本說故事的方式如果不好，就刪掉，不要捨不得。
  • 39:28 講者的理論：早期 Pixar 很強，是因為技術很陽春，頭髮與水的模擬要花很久才搞定
    ↳ 講者自己的推論：早期 Pixar 之所以強，正是因為技術很陽春，頭髮和水的模擬要花很久才做得出來。
  • 40:00 承上：這段時間故事團隊就能反覆琢磨，找出講好那場戲的最佳方式
    ↳ 技術在慢慢處理的這段時間，故事團隊剛好有空反覆打磨，找出那場戲最好的講法。
  • 40:00 你以為第一次就會做對？不會。要保持謙虛
    ↳ 別以為第一版就會對，通常都不會。保持謙虛，把修改當成正常流程的一部分。
  • 40:00 box tool 可以玩出很多效果。講者另外複製了一個 cloud brush（雲朵筆刷）
    ↳ box tool 是字幕中提到的畫圖工具之一，講者說能玩出很多效果。他另外複製了一支 cloud brush（雲朵筆刷）來用。
  • 40:31 cloud brush 能增加深度、引導視線，但很耗效能，因為它是非常有體積感的 grease pencil
    ↳ cloud brush 畫出來像一團團雲霧，能讓畫面有深度，也能把視線帶到重點。但它的筆觸體積感很重，非常吃效能。
  • 40:31 用法：選 freeform 而不是 line，設很低的 opacity、很大的 size，就能引導視線，為 previz 鏡頭加一點氛圍
    ↳ 用法：選 freeform（自由手繪），不要選 line；opacity（不透明度）調很低、size（筆刷大小）調很大，淡淡刷上去，就能帶視線、替 previz 鏡頭加一點氛圍。
  • 41:01 建議參考 Mad Max 在 eye tracking 上的做法。剪輯時要注意鏡頭切換之間觀眾的視線落在哪裡
    ↳ 他建議參考 Mad Max 的 eye tracking，也就是掌握觀眾眼睛看哪裡。剪輯時要注意鏡頭切換的前後，觀眾的視線落在哪裡。
  • 41:01 這類筆觸很適合引導觀眾視線，尤其是飛車穿越場景的蒙太奇這種容易讓人混亂的段落
    ↳ 這類筆觸特別適合引導視線，尤其是車子飛馳穿過場景的 montage（蒙太奇，把很多快速鏡頭接在一起）這種容易看亂的段落。
  • 41:33 小技巧：用了這種體積感很重的筆觸後先停用它，繼續做其他部分，到專案最後再重新啟用
    ↳ 小技巧：刷完這種很重的筆觸就先停用，繼續做其他部分，等專案收尾時再打開，電腦才不會一直卡。
  • 42:04 這個方法很適合增加氛圍、營造情緒、引導視線
    ↳ 總結它的用途：增加氛圍、營造情緒、引導觀眾看哪裡。
  • 42:04 最終版本 Demo 3 的音訊切成三段：懸疑段落、Japanese City Pop、以及帶入一點吉他的段落
    ↳ 最終版 Demo 3 的配樂切成三段：懸疑段落、Japanese City Pop（日本城市流行樂），以及加入一點吉他的段落。
  • 42:40 用同樣的重疊節拍技巧，讓歌曲的一段疊到下一段。講者說之後也許可以加音效
    ↳ 段落之間用同樣的重疊節拍技巧，讓前一段音樂疊進下一段，換段時才不突兀。講者說之後也許會再加音效。
  • 42:40 previz 的好處是能看清鏡頭數量，判斷城市裡那麼多鏡頭是否都值得保留
    ↳ 做 previz 的好處是鏡頭數量一目了然，可以判斷城市裡那麼多鏡頭，是不是每一顆都值得留下。
  • 43:13 可以拿去問導演：車穿越城市的鏡頭會不會太多？會不會太混亂、太快？這個故事節點有沒有傳達到？
    ↳ 可以拿 previz 去問導演：穿越城市的鏡頭會不會太多、太亂、太快？這個故事節點（劇情關鍵點）觀眾有沒有看懂？
  • 43:13 講者現場問觀眾：她上車這件事明顯嗎？觀眾回答明顯
    ↳ 講者當場問觀眾：「她上車這件事看得出來嗎？」觀眾說看得出來。這就是用 previz 確認故事有沒有傳達到。
  • 44:22 背景放在同一個圖層，角色另外建圖層，方便鎖定與解鎖
    ↳ 背景放在同一個 layer（圖層），角色另外開圖層。要畫角色時把背景鎖住，就不會誤動到背景。
  • 45:00 Grease pencil 可以 parent。常見流程：在 3D 環境放入 primitive humans，像傳統舞台劇一樣 block out 場景
    ↳ Grease pencil 可以 parent（綁到別的物件上跟著動）。常見做法是先在 3D 場景放 primitive humans（簡單的人形替身），像舞台劇排走位一樣 block out（先粗排位置和動線）。
  • 45:32 在 3D 環境中放 2D 角色時，要思考 proscenium、舞台劇那種前方擺放的概念
    ↳ 在 3D 場景放 2D 角色時，要考慮 proscenium（舞台劇的台口，也就是觀眾從正面看進去的那個框），用擺在觀眾面前的概念來安排。
  • 45:32 先放 primitives，之後再附上 grease pencil 畫出角色。講者說這很有價值也很好玩
    ↳ 先放 primitives 排好位置，之後再用 grease pencil 在上面畫出角色。講者覺得這個流程很有價值，也很好玩。
  • 45:32 把 grease pencil parent 到物件上，角色畫面就會跟著做 blocking 的 primitives 一起移動
    ↳ 把 grease pencil parent 到替身物件上之後，替身怎麼移動，畫出來的角色就會跟著怎麼移動。
  • 46:05 可以在 3D 場景中把東西往前移一點，讓它們在實際 3D 空間裡有正確的前後層次
    ↳ 也可以在 3D 場景裡把東西往前挪一點，讓前後遮擋的關係在真實空間裡是正確的。
  • 46:39 鼓勵多玩新筆刷，例如 charcoal、oil。光用 foliage 就能快速加入質感，讓人一眼看懂你要表達什麼
    ↳ 鼓勵大家多試新筆刷，像 charcoal（炭筆）、oil（油畫）。光用 foliage（植物葉叢筆刷）就能快速加上質感，讓人一眼看懂你想表達什麼。
  • 46:39 previz 可用來和投資人溝通，或和客戶確認需求；講者舉例這支是 spec spot，若真的接 Mitsubishi 的案子就會這樣問客戶
    ↳ previz 可以拿去跟投資人溝通，或跟客戶確認需求。這支是 spec spot（沒人委託、自己做的示範廣告），講者說如果真的接到 Mitsubishi 的案子，就會這樣問客戶。
  • 47:13 也能讓合作的藝術家有共識，而且成本很低
    ↳ 它也能讓合作的藝術家對方向有共識，而且做起來成本很低。
  • 47:13 很多人因為喜歡 Pixar 電影入坑 3D，但那些作品很長。要把力氣花在值得講的故事上，就要投資 previz 和 visual development
    ↳ 很多人因為喜歡 Pixar 電影才入坑 3D，但那種作品很長、很費工。要把力氣花在值得講的故事上，就得先投資 previz 和 visual development（前期的美術設定與風格探索）。
📘 術語
backface culling（背面剔除）：用材質做描邊時要在材質上勾選的選項；字幕未進一步解釋原理
Solidify modifier（加厚修改器）：描邊做法中要加入的 modifier，搭配翻轉 normals 與 material offset 使用
normals（法線）：描邊做法中要翻轉（flip）的項目；字幕未解釋定義
material offset（材質偏移）：描邊做法的最後一步設定；字幕未進一步解釋
Grease Pencil（蠟筆（Blender 的 2D 繪圖工具））：可徒手畫、用 line 畫乾淨線條，也能 parent 到物件上跟著移動
previz（預視化）：字幕中用來檢視鏡頭、氛圍與故事是否清楚，且成本很低
storyboard artist（分鏡師）：會把很簡單的東西一改再改，直到故事完美的人
opacity（不透明度）：cloud brush 要調到很低，搭配大 size 來引導視線
eye tracking（視線追蹤）：剪輯時注意鏡頭切換間觀眾視線落點；講者建議參考 Mad Max
montage（蒙太奇）：字幕舉例：車子飛馳穿越場景的蒙太奇，容易讓觀眾混亂
layer（圖層）：背景放一層、角色另建圖層，方便鎖定與解鎖
parent（父子綁定）：把 grease pencil 綁到物件上，讓它跟著做 blocking 的 primitives 移動
primitive（基本幾何體）：放進 3D 環境當角色替身，像舞台劇一樣 block out 場景
block out / blocking（走位／佈局）：用 primitive humans 像傳統舞台劇一樣安排場景與移動
proscenium（鏡框式舞台）：3D 環境配 2D 角色時要思考的概念，像舞台劇把東西擺在你面前
spec spot（自主提案廣告）：講者說這支是 spec spot，若真的接 Mitsubishi 案子會拿來問客戶
visual development（視覺開發）：講者結語建議與 previz 一起投資，確保力氣花在值得講的故事上
