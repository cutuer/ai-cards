🧑‍🏫 這支 OpenAI 官方影片在介紹 Codex ambassador program（Codex 大使計畫）。Codex 是 OpenAI 用來幫人寫程式的 AI 工具，這個計畫則是請世界各地的人在當地辦活動、帶大家一起玩 Codex。影片講了計畫怎麼從小規模變成全球社群、幾場最精彩的活動，以及什麼樣的人適合加入。如果你對 AI 寫程式有興趣、想找人一起學，這支可以讓你知道有這個管道。

  • 00:33 Codex ambassador program 起初只打算在全球招募約 15 到 20 位 ambassador，辦幾場實體或線上活動
    ↳ 這個計畫一開始規模很小，只打算在全世界找 15 到 20 位 ambassador（大使，就是在自己城市辦活動、帶社群的人），辦幾場聚會或線上活動試試看。
  • 00:33 計畫的初衷是讓社群更接近 Codex 與 GPT-5 系列模型的魅力
    ↳ 出發點是讓一般人有機會親手用 Codex 和 GPT-5 系列模型（OpenAI 的 GPT-5 這一代 AI 模型），自己體會它們好用在哪裡，而不是只聽別人講。
  • 01:05 現在已有 150 多位 ambassador，分布在 80 多個國家，辦過 300 多場線上與實體活動
    ↳ 結果遠超原本的預期：大使從預計的十幾二十位變成 150 多位，分布在 80 多個國家，累積辦了 300 多場活動。想學的人比原本想像的多很多。
  • 01:05 核心理念是讓想動手玩、追求創意、想探索可能性的人更接近這些模型
    ↳ 他們最想服務的是 tinker 型的人，也就是喜歡自己動手試、拆開來玩的人。重點不在聽課，而是讓大家實際操作模型，試出新點子。
  • 01:40 最令人印象深刻的活動：印度 Kochi 的 ambassador 在行駛中的捷運上舉辦整場 Codex 社群活動
    ↳ 最讓人難忘的一場在印度城市 Kochi。當地大使把整場 Codex 活動辦在行駛中的捷運上，大家是在移動的車廂裡參加活動。
  • 02:10 Kochi 活動的參加者坐滿車廂，一起用 Codex 寫程式、實現想法，之後還帶動了這股風潮
    ↳ 那次車廂坐滿參加者，大家邊搭車邊用 Codex 寫程式，把腦中的點子做出來。這種新鮮辦法後來還帶起一股熱潮。
  • 02:10 另一位講者最喜歡的社群時刻是 Build Week
    ↳ 影片另一位講者最喜歡的社群時刻是 Build Week，也就是集中一整週、大家一起動手做東西的活動週。
  • 02:41 Build Week 配合新系列模型發布，目的是讓社群更了解這些模型，以及模型搭配 Codex 能做到什麼
    ↳ Build Week 特地挑新一代模型推出時舉辦，讓大家趁新鮮就搞懂新模型強在哪裡，以及跟 Codex 一起用可以做出什麼。
  • 02:41 動員 ambassador 網絡後，一週內在全球舉辦了 60 多場活動
    ↳ OpenAI 請各地大使分頭辦，短短一週全球就辦了 60 多場。這就是大使網絡的價值：一個號召發出去，各地能同時動起來。
  • 02:41 Build Week 期間全天候都有活動，地點包括東京、印度、倫敦和 SF
    ↳ 大使分散在不同時區，東京、印度、倫敦、SF（舊金山）像接力一樣輪流辦，所以 Build Week 期間 24 小時都有地方在辦活動。
  • 03:11 講者每天早上都會在 Slack 看到 ambassador 分享的活動照片，以及參加者做出的作品
    ↳ 講者每天早上打開 Slack（很多團隊在用的工作聊天軟體），就會看到各地大使貼上的活動照片，還有參加者做出來的作品。
  • 03:45 ambassador 之所以出色，是因為他們不論辦什麼活動或演講，都「用心在 build」
    ↳ 講者認為大使做得好的原因，是他們不管辦活動還是上台分享，都真心在 build（動手把東西做出來），不是只做表面宣傳。
  • 04:16 成為 ambassador 的首要條件是好奇心：想重新想像可能性、挑戰多數人眼中的現實，並把模型推到極限
    ↳ 想當大使，最重要的是好奇心：願意想像新的做法，不把多數人覺得「做不到」的事當成定論，也想試試模型的極限到底在哪裡。
  • 04:47 第二個條件是熱衷於幫助大家跟上最新發布的內容，並營造包容、讓人敢發問的環境
    ↳ 第二個條件是樂於帶人：喜歡幫大家搞懂最新推出的功能，並營造友善的環境，讓新手敢開口問問題。
  • 04:47 ambassador 不需要一開始就懂 Codex 的一切，只要保持好奇、願意付出時間就很適合
    ↳ 不用是 Codex 專家才能當大使。就算一開始懂得不多，只要保持好奇、願意花時間投入，就很適合。
  • 05:18 不論身在世界哪裡，都歡迎加入 Codex 社群，一起 build
    ↳ 影片最後強調，不管你住在哪個國家，都歡迎加入 Codex 社群，跟大家一起動手做東西。
📘 術語
Codex ambassador program（Codex 大使計畫）：由分布全球的 ambassador 舉辦線上與實體活動，讓社群更接近 Codex 與模型
Build Week（Build Week（建置週））：配合新系列模型發布舉辦的活動週，一週內全球辦了 60 多場活動
GPT-5 series（GPT-5 系列模型）：字幕中提到計畫希望讓社群更接近的模型系列
tinker（動手玩、摸索嘗試）：字幕用來描述想實際動手嘗試模型的人
