🧑‍🏫 這支是 OpenAI 示範用 ChatGPT 的 Workspace agents 功能，做出一個叫 Trove 的 AI 助手，幫公司檢查合作廠商有沒有風險。值得看的地方是，整個建置過程幾乎都用聊天完成，不用寫程式，做好後還能直接試跑、檢查它每一步怎麼判斷。

  • 00:03 講者 Hojun 示範打造 Trove，一個第三方風險管理（third-party risk manager）agent
    ↳ 講者 Hojun 要做一個叫 Trove 的 agent，也就是能自己分步驟把事情做完的 AI 助手。它的角色是 third-party risk manager，專門幫公司評估合作廠商的風險。
  • 00:03 Trove 類似財務團隊現在使用的 agent，用來加速耗時的供應商盡職調查（vendor due diligence），並提升一致性與掌控度
    ↳ 公司跟新廠商合作前，要先做 vendor due diligence（供應商盡職調查），把對方的底細查清楚，很花時間。Trove 讓這件事變快，而且每次查法都一樣，主管也更好掌握。
  • 00:03 建置流程從一段 prompt 開始，內容描述工作流程，以及這個 agent 需要的 tools、skills 與系統
    ↳ 第一步是寫一段 prompt，就是給 AI 的文字指示。內容要說明工作怎麼進行，還有它需要用哪些 tools（它可以使用的工具）、skills，以及要連接哪些系統。
  • 00:03 加入財務團隊現在做供應商風險評估時使用的 skill，裡面定義了他們的最佳做法
    ↳ skill 可以想成一份打包好的做事準則。這裡把財務團隊平常評估廠商風險的標準做法放進去，agent 就會照團隊原本的方式做，不用重新教一次。
  • 00:33 這個 skill 包含必要的指示與 metadata，讓 agent 能一致且準確地完成工作
    ↳ skill 裡除了做事步驟，還附有 metadata，也就是用來描述內容的補充資訊，例如標籤和說明。靠這兩樣，agent 每次做出來的結果才會穩定、準確。
  • 00:33 只花幾秒，ChatGPT 就列出 Trove 的計畫，並可以開始實作
    ↳ 送出後只要幾秒，ChatGPT 就會先列出它打算怎麼建 Trove。你看過沒問題，就能直接開始做，不用自己從頭想架構。
  • 00:33 左側窗格用自然語言和 ChatGPT 對話，持續建置與調整 agent；右側則同步設定它的 tools、skills 與 apps
    ↳ 畫面分成兩邊。左邊像聊天一樣，用平常講話的方式告訴它要改什麼。右邊會同步更新對應的 tools、skills 和 apps 設定，apps 就是它可以連接使用的應用程式。
  • 00:33 ChatGPT 會把這些內容產出成一套調校好的指令集（instruction set），不需要動用技術工程資源
    ↳ 你講的需求，ChatGPT 會自己整理成 instruction set，也就是 agent 實際照著執行的一整套指令。重點是整個過程不用找工程師幫忙。
  • 01:05 Trove 完成後，可在同一個流程中啟動 preview，測試 agent 的行為
    ↳ 做好之後，在同一個畫面就能開 preview，也就是試跑。先看它實際會怎麼做，確認沒問題再拿來用。
  • 01:05 透過同樣直覺的引導式介面監看 preview 執行過程
    ↳ 試跑的畫面一樣是引導式介面，會一步一步帶你看。你可以跟著看 agent 正在做什麼，不懂技術也看得懂。
  • 01:05 可以查看 agent 所有的 run traces，包括 tool calls、輸入內容與它做的決策
    ↳ run traces 是 agent 的完整工作紀錄，裡面有 tool calls（它每次呼叫了哪個工具）、當時輸入的內容，以及它做了哪些判斷。結果怪怪的時候，可以回頭查是哪一步出問題。
  • 01:05 agent 會蒐集證據，運用 skill 進行嚴謹的風險評估，並在多個系統之間協調工作
    ↳ 實際執行時，agent 會先去找資料當證據，再照 skill 裡的標準仔細評估風險，過程中還會在好幾個系統之間來回處理工作。
  • 01:37 agent 最後產出一份結構化、完整精緻的報告，交給人類分析師審閱
    ↳ 最後它會交出一份格式固定、內容完整的報告。不過最後拍板的還是人，由分析師審閱後再做決定。
  • 01:37 整件工作只要幾分鐘就完成，讓分析師不必再處理流程中耗時的手動部分
    ↳ 原本要花很多時間手動整理的部分，現在幾分鐘就跑完了。分析師可以把力氣留給真正需要專業判斷的地方。

third-party risk manager（第三方風險管理者）：本片示範的 agent（Trove）的角色，用來加速供應商盡職調查
vendor due diligence（供應商盡職調查）：字幕形容這是很耗時的工作，Trove 用來加速這項工作
