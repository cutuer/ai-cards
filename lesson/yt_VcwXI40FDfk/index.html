📘 術語
MCP（MCP）：基本上是讓 Claude 和 Blender 能互相理解的「翻譯器」
MCP Bridge server（MCP 橋接伺服器）：在 Blender add-ons 裡啟動，讓 Claude 和 Blender 連線；啟動錯誤時要允許網路存取
connectors（連接器）：Claude desktop 設定裡的功能，在這裡搜尋並安裝 Blender
add-on（附加元件）：Blender 端需要的那一半橋接，把檔案拖進 Blender 安裝
start frame（起始幀）：整個鏡頭圍繞的單一畫面，提供最終影片的精緻風格
render（算圖輸出）：把 Blender 裡建好的運鏡輸出成影片，成為給 Seedance 的參考
camera movement reference only（僅作運鏡參考）：標註 Blender 影片用，讓 Seedance 只複製攝影機怎麼動，不複製畫面外觀
prompt builder（prompt 產生器）：作者做的小檔案，丟進 Claude 後它會寫出為 Seedance 格式化好的完整 prompt
Soul Cinema（Soul Cinema）：Higgsfield 的圖片模型，專為電影感鏡頭打造
timeline（時間軸）：一個時刻一個時刻地描述整段鏡頭，取代一句模糊的 prompt
