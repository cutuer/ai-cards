📘 術語
computer use（電腦操作能力）：讓 Codex 像人一樣看畫面、移動滑鼠、點擊、打字，使用電腦上的任何 app
coding agent（寫程式代理）：Codex 最初的定位，現在已演變成能處理任何任務的隊友
graphical user interface（圖形化使用者介面）：人類靠看畫面、移動滑鼠、點擊、打字來操作的軟體介面
virtual machine (VM)（虛擬機）：Ari 用 UTM 建立，用來在舊版 Mac 作業系統上測試軟體
multimodal model（多模態模型）：能看見介面截圖，並依座標點擊與打字的模型
accessibility framework（無障礙框架）：可取出 app 介面隱藏資訊的機制，提供描述介面的文字，連捲到畫面外的內容都能得知
non-multimodal model（非多模態模型）：不處理影像的模型；因 computer use 不一定需要影像，可用這類快速模型如 Codex Spark
Codex Spark（Codex Spark）：非多模態、速度非常快的模型，搭配 computer use 操作軟體可比人還快
plugins（外掛）：讓 Codex 存取各種線上服務的功能
✏️ 小考一題

依影片說明，為什麼 computer use 可以搭配 Codex Spark 這類非多模態模型使用？

A. 因為 Codex Spark 是專門為 computer use 訓練的獨立模型B. 因為 computer use 會接管整台電腦，所以不需要看畫面C. 因為 Codex Spark 會把截圖先轉成座標再點擊D. 因為透過 accessibility framework 取得描述介面的文字資訊，不一定需要影像
看答案
答案：D。[05:40] Ari 說擷取描述介面的文字資訊，因為不一定需要影像，所以可以使用 Codex Spark 這種非多模態模型。[07:12] 提到專門訓練的模型是早期的 Operator 和 ChatGPT agent；[03:05] 說明 Codex 不會接管整台電腦。
