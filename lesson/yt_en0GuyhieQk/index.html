📘 術語
artifact（成品類型（artifact））：字幕沒有解釋這個詞，只說 Claude Dashboards 和 Claude Motion 是兩種新的 artifact 類型。
Claude Dashboards（Claude 儀表板）：Claude 把從資料倉儲拉出的資料整理成 dashboard 的功能。
Claude Motion（Claude 動畫）：能把 dashboard 轉成動畫敘事的功能，可以在影片上用留言調整。
dashboard（儀表板）：字幕中指 Claude 把一年份騎乘資料排版呈現出來的成果。
data warehouse（資料倉儲）：字幕中指團隊存放騎乘資料的地方，Claude 從這裡拉出一年份資料。
all hands meeting（全員大會）：字幕中指要向整個團隊說明故事、爭取大家支持的會議。
animated narrative（動畫敘事）：Claude Motion 把 dashboard 轉成的成品，用動畫來說故事。
