🧑‍🏫 這支影片是軟體公司 Endava 的技術主管，分享他們團隊怎麼用 OpenAI 的 Codex 工作。重點在於 Codex 不只是寫程式的工具，也改變了老手和新手的合作方式，以及每個人的工作角色。就算你不寫程式，也可以參考他們怎麼把 AI 當成幫手，而不是只把它當成打字機。

  • 00:02 Codex 讓小團隊在非常壓縮的時間內交付極大的價值
    ↳ Codex 是 OpenAI 做的 AI 工具，原本主打幫忙寫程式。這條的意思是：人少、時間又趕，也能做出以前要一大群人才做得完的成果。
  • 00:02 講者 Jordan Levy 是 Endava 的 regional CTO（字幕拼作 Andava）
    ↳ CTO 是技術長，負責公司的技術方向；regional 是「區域」，代表他管某個地區。字幕把公司名稱拼成 Andava，其實指的就是 Endava。
  • 00:02 Codex 同時幫到光譜的兩端：資深架構師與團隊裡較資淺的成員
    ↳ 「光譜兩端」指經驗最多的人和經驗最少的人。意思是 Codex 不是只有高手用得上，新手也一樣受益，兩種人都用得到。
  • 00:02 資深架構師能說清楚自己要什麼，Codex 再把這些內容轉成資淺成員也容易理解的資訊
    ↳ 老手很清楚自己要什麼，但講得很精簡，新手常常聽不懂。Codex 像中間的翻譯，把老手的想法展開成新手看得懂的說明。
  • 00:32 資淺成員採用 Codex 後，能產出接近資深、成熟水準的成果
    ↳ 新手用了 Codex，等於補上一部分經驗不足，交出來的東西品質會接近老手。影片說的是「接近」，不是完全一樣。
  • 00:32 他們認為 Codex 已經成熟，不只是寫程式的工具，而是更像通用的桌面 agent
    ↳ agent 指能自己一步步完成任務的 AI，不只是回答問題。desktop agent 的意思是它在電腦上能幫你處理各種工作，不限於寫程式。
  • 00:32 他們把 Codex 用在整個生命週期，而不是只鎖定寫程式的能力
    ↳ life cycle（生命週期）指一個專案從開始到完成的整個過程。他們在每個階段都用 Codex，不只用在寫程式那一段。
  • 00:32 使用範例：請 Codex 把內容畫成圖表，讓客戶更容易理解
    ↳ 舉例來說，把複雜的技術內容請 Codex 畫成圖表，拿給不懂技術的客戶看。客戶看圖就懂，雙方溝通省下很多力氣。
  • 00:32 工作模式從自己大量寫程式，轉變成監督 Codex 產出的工作
    ↳ 以前是自己一行一行寫程式，現在改成交代 Codex 去做，自己負責檢查、修正、把關方向。角色比較像審稿的主管。
  • 01:02 講者表示，轉變之後產出的品質呈指數級提升
    ↳ 講者說轉變後的品質是「指數級」提升，也就是大幅跳升，不是只好一點點。這是他自己的感受，影片沒有給具體數字。
