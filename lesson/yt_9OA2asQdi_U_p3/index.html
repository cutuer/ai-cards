🧑‍🏫 這段是甜甜圈教學裡做糖霜的收尾。先把滴垂的形狀調得自然，再解決糖霜翹起來、沒貼住甜甜圈的問題，最後改用雕刻的方式，補上液體堆積的細節。看完你會知道什麼時候該換工具，這是 3D 新手最常卡住的地方。

  • 20:55 3D 不像畫圖，線畫壞了不必擦掉重來，直接抓點移動就好，這是 3D 的樂趣之一。
    ↳ 畫圖時線畫歪了，多半得擦掉重畫。3D 模型是由一個個點連起來的，形狀不滿意就把點抓過去挪一挪，不用整個重做，所以試錯的代價很低。
  • 20:55 可以一次選幾個點一起往下拉，讓糖霜的滴垂形狀更有變化。
    ↳ 一次只拉一個點，每條滴垂容易長得一模一樣。同時選幾個相鄰的點往下拉，就能拉出長短粗細不同的滴垂，比較像真的流下來。
  • 21:25 作者拿掉底部一個滴垂，再把其他幾個拉出來，讓整圈都有變化。可以暫停自己調，目標是整體好看。
    ↳ 滴垂重點是分布自然，不是越多越好。作者刪掉一個、再多拉幾個，是為了讓整圈沒有哪一段太空或太擠。沒有標準答案，暫停自己調，看順眼就好。
  • 21:25 糖霜會往上翹、和甜甜圈分開，原因在 subsurf modifier 的運作方式：兩點之間必須做出很圓的形狀。
    ↳ modifier 是疊在物件上的自動效果，不會直接改原本的點。subsurf 會把表面自動磨圓，但它在兩點之間一定要繞出圓弧，所以糖霜邊緣會圓圓地翹起，沒貼住甜甜圈。
  • 22:00 真實液體黏在物體上時，接觸的地方會緊貼表面，其餘部分才是圓的。
    ↳ 想像蜂蜜沾在碗邊：碰到碗的那一面是平貼的，只有外露的部分才圓滾滾。糖霜翹起來看起來很假，就是因為違反了這個常識。
  • 22:00 Solidify 的設定裡，Edge Data 底下有 Crease 選項，可以解決糖霜翹起的問題。
    ↳ Solidify 是幫薄片加上厚度的 modifier，糖霜的厚度就是它做出來的。它的設定裡有一區叫 Edge Data（邊緣相關設定），底下的 Crease 選項就能解決翹起的問題。
  • 22:35 Crease 讓邊緣收緊，不做大圓弧。效果類似馬克杯加 geometry，但不必增加 geometry。會有一點拉伸，但在這裡不明顯。
    ↳ Crease 讓邊緣收緊，不再磨成大圓弧。做馬克杯時要多加點和面（geometry）才能讓邊變利，這裡改一個數值就好。代價是表面會稍微被拉扯，但這裡看不出來。
  • 23:08 甜甜圈內側的糖霜也可以用同樣方式調整。作者最終版忘了做這一步。
    ↳ 甜甜圈中間洞口那一圈糖霜也有同樣的問題，可以用同一套方法修。作者自己的成品漏了這一步，這是你可以做得比示範更好的地方。
  • 23:08 內側不好看時，按住 Alt 點中間那一圈，再按 focus 鍵（numpad period，或 tilde 再選 view）鎖定選取的 vertices。focus 在 Edit Mode 也能用。
    ↳ vertices 就是模型上的點。按住 Alt 點一下可以選取整圈點，再按 focus（數字鍵盤的小數點，或 ~ 鍵再選 View）把視角對準它們。這招在選點、移點用的 Edit Mode 裡也能用。
  • 23:41 把內側的點往下拉即可，相機其實不太看得到。重點是別完全筆直，作者最終算圖的內側就太直。
    ↳ 內側往下拉一點就好，反正相機幾乎拍不到，不必花太多力氣。唯一要避免的是整圈垂得筆直，會很像機器做的。作者的成品就犯了這個錯。
  • 24:12 從上方（相機的位置）看，糖霜蓋太低、甜甜圈露太少。用 proportional editing 把點往上拉，露出更多甜甜圈。
    ↳ 要用相機會拍的角度來檢查。從上往下看，糖霜蓋太多，甜甜圈本體露太少。proportional editing 是移動一個點時，周圍的點會柔和地跟著動，用它把糖霜邊往上推。
  • 24:12 變化多一點更像手工甜甜圈。Krispy Kreme 這類專業甜甜圈大概沒這麼多變化，但這樣有助於真實感。
    ↳ 手工甜甜圈的糖霜本來就歪歪扭扭，連鎖店量產的反而很整齊。現實中不一定這麼不規則，但刻意多一點變化，畫面會更像真的東西，而不是電腦做出來的。
  • 24:44 糖霜需要厚度變化：目前每處厚度都一樣，但現實不是這樣。
    ↳ 現在的糖霜像一層厚度完全一致的塑膠殼。真的糖霜淋上去，一定有的地方厚、有的地方薄，這種過度均勻就是一眼看出是假的原因。
  • 24:44 滴垂的液滴停住時會堆積，末端應該稍微鼓起、更圓；每條邊緣也應比其他部分更鼓。
    ↳ 液體往下流、停住時會積在尾端，所以滴垂末端要比較胖、比較圓。糖霜的每條邊緣也是同樣道理，會比中間平坦的部分稍微鼓一點。
  • 25:17 這些細節聽起來不起眼，但實際加上去真的能提升真實感。
    ↳ 這些細節觀眾不會刻意去注意，但少了就會覺得怪怪的。真實感常常不是來自大形狀，而是來自這種小地方。
  • 25:17 目前只有幾個點可以調，做不出這些細節。要像做馬克杯時一樣，打破 non-destructive workflow，apply modifiers。
    ↳ 糖霜底層只有少數幾個點，modifier 做出來的效果又不能直接捏。要細修，就得放棄隨時可改的 non-destructive workflow，把效果 apply（固定成真正的點和面）。
  • 25:17 Apply modifier 必須由上往下。雖然主要想 apply 的是 solidify，但 shrinkwrap 排在第一個，要先 apply，否則會出問題。
    ↳ modifier 有先後順序，像流水線一樣由上往下處理。雖然真正想固定的是 solidify，但排第一的 shrinkwrap（讓點自動貼在甜甜圈表面）要先 apply，跳著套結果會出錯。
  • 25:48 Apply shrinkwrap 後，點已經貼在 mesh 上，但失去自動吸附，這時拉出來會和 mesh 分離。
    ↳ shrinkwrap 固定之後，點還停在甜甜圈表面，但已經不會自動吸附了。之後把點拉離表面，它就真的離開，不會自己黏回去，修改時要留意。
  • 25:48 接著 apply solidify，才能編輯糖霜的 mesh。
    ↳ 接著固定 solidify，糖霜的厚度就變成實際的點和面，這時才能直接去改它的形狀。
  • 26:23 關掉 proportional editing 拉出幾個點會好一些，但細節不夠，需要更多 geometry，所以要 apply subsurf modifier。
    ↳ 關掉 proportional editing、單獨拉幾個點，雖然有改善，但點太少，做不出細緻的鼓起。所以再把 subsurf 也 apply，把它磨圓時產生的大量點和面變成可以編輯的材料。
  • 26:23 快捷鍵 Ctrl+A 可以 apply 選取的 modifier，不用每次開下拉選單。
    ↳ 選好要套用的 modifier 後按 Ctrl+A，就能直接 apply，不用每次點開下拉選單找。連續套好幾個時很省事。
  • 26:55 在 Edit Mode 可以開 proportional editing 選點塑形，或拉個別點，但很繁瑣，不是適合的工具。
    ↳ 點變多之後，在 Edit Mode 還是可以一個個拉，或開 proportional editing 帶一片拉，但這樣調太累。做得到不代表適合，這時就該換工具了。
  • 27:25 3D 裡每件事都有對應的工具。從畫面頂端的 Layout 切換到 Sculpting。
    ↳ 3D 軟體把不同的工作分給不同的工具。畫面最上方的分頁就是工作區：原本在 Layout（一般建模用），現在切到 Sculpting（雕刻專用）。
  • 27:25 切到新的工作區時，會套用 Blender 預設視角（大約是物體 10 m 長的尺度），甜甜圈看起來很小，要 focus 到選取物件上。
    ↳ 切到新的工作區時，視角會回到預設值，看的範圍大約是十公尺長的物體，小小的甜甜圈看起來就很小。要先把視角對準選取的物件。
  • 27:59 Sculpt Mode 裡按 numpad period 沒反應。要先切到 Object Mode，按 numpad period 或 View Selected，再切回 Sculpt Mode。
    ↳ Sculpt Mode（拿筆刷直接在模型上雕）裡按數字鍵盤小數點沒反應。要先切到以整個物件為單位操作的 Object Mode，按小數點或 View Selected 對準，再切回 Sculpt Mode。
  • 27:59 在 Sculpt Mode 要確認選的是糖霜，不是甜甜圈。在上面畫就會直接雕進糖霜的 mesh。
    ↳ 雕刻會改到你選取的那個物件，選錯就會雕到甜甜圈本體。下筆前先確認選的是糖霜，畫上去的每一筆都會直接改變糖霜的形狀。
  • 28:30 換成這裡最有用的筆刷：Inflate Deflate brush。
    ↳ 筆刷有很多種，這裡最好用的是 Inflate Deflate brush：畫過的地方會膨脹，正好用來做液體堆積的鼓起。
  • 28:30 筆刷大小可以用上方的 size 調整，或按快捷鍵 F，再用滑鼠決定大小。
    ↳ 筆刷太大會一次影響太多地方。可以在上方的 size 欄位調整大小，或按 F 鍵後移動滑鼠，直接拉出想要的大小。
  • 28:30 在液滴末端畫過，就會稍微膨脹。不要做過頭，加一點膨脹就能讓它看起來更真實。
    ↳ 在滴垂尾端輕輕刷過，它就會微微鼓起來。重點是適量，刷太多會變成腫包，只要一點點就能讓它像真的液滴。
  • 29:00 作者常用的另一個筆刷是 Grab brush，可以直接拉動 mesh，移動各部位來塑形、加細節。
    ↳ Grab brush 就像用手指按住黏土拖動，能直接把一塊區域拉到別的地方。作者常用它移動各部位、調整形狀、補上細節。
  • 29:34 邊緣也要稍微鼓起，因為液體會在邊緣堆積。
    ↳ 除了滴垂尾端，糖霜的外圈邊緣也要稍微刷鼓一點，因為液體會在邊緣聚集，不會平平地收尾。
  • 30:07 堆積的原因是重力讓液體停住：張力會大過往下拉的重力。
    ↳ 液體流到邊緣或末端時，拉住它的張力大過往下拉的重力，所以會停下來越積越多，形成鼓鼓的邊。這就是前面要把邊緣做鼓的原因。
  • 30:07 作業：做出畫面中藏起來的物件，也就是放甜甜圈的盤子。
    ↳ 作業：畫面裡其實藏著一個東西，就是放甜甜圈的盤子，請你自己把它做出來。
  • 30:37 觀察盤子的形狀，想想怎麼做，然後自己試。就算沒信心也先試試看。
    ↳ 先仔細看盤子長什麼樣子，想想可能怎麼做，再動手。就算沒把握也先試試看，這是練習把前面學過的東西組合起來用。
  • 30:37 提示：右側有使用的 modifiers，作者也展示了 wireframe 給大家參考。
    ↳ 卡住時可以參考畫面右側列出的 modifiers，還有作者展示的 wireframe（只顯示點和線的線框圖），從線的排法可以推測它是怎麼建出來的。
  • 30:37 下一段會快速示範怎麼做盤子。完全卡住可以直接跟著下一段做，但請先自己嘗試。
    ↳ 下一段會快速示範盤子的做法。真的做不出來可以直接跟著做，但先自己試過再看，你會更清楚自己卡在哪裡。
📘 術語
Subsurf modifier（細分曲面修改器）：兩點之間會做出很圓的形狀，所以糖霜會翹起。apply 後會產生更多 geometry 可以編輯。
Solidify（加厚修改器）：字幕中是糖霜使用的 modifier，設定裡的 Edge Data 底下有 Crease 選項。
Edge Data（邊資料）：Solidify 設定中的一個區塊，Crease 選項就在這裡。
Crease（摺痕）：讓邊緣收緊、不做大圓弧。效果類似加 geometry，但不增加 geometry，會有一點拉伸。
Shrinkwrap（收縮包裹修改器）：讓點自動吸附在 mesh 上。apply 後點仍貼著，但失去自動吸附。
Non-destructive workflow（非破壞性工作流程）：要做更多細節時，必須打破它，把 modifiers apply 掉。
Apply（套用）：把 modifier 的效果套到 mesh 上。要由上而下套用，快捷鍵 Ctrl+A。
Proportional editing（比例編輯）：字幕中用來一次帶動一片點，例如把糖霜往上拉。
Geometry（幾何結構）：可以編輯的點和面。點不夠就做不出細節，apply subsurf 後會增加很多。
Vertices（頂點）：選取的點。用 focus 可以把視角鎖定在選取的 vertices 上。
Focus / View Selected（聚焦選取）：按 numpad period 或 tilde 再選 view，把視角對準選取的東西。Edit Mode 可用，Sculpt Mode 無效。
Edit Mode（編輯模式）：可以選取、移動點的模式，但用來做細緻形狀很繁瑣。
Object Mode（物件模式）：在 Sculpt Mode 無法 focus 時，要先切到這個模式再按 View Selected。
Layout / Sculpting（版面配置／雕刻工作區）：畫面頂端的工作區切換。前面都在 Layout，這裡切到 Sculpting。
Sculpt Mode（雕刻模式）：在物件上畫，就會直接雕進它的 mesh。
Inflate Deflate brush（膨脹／收縮筆刷）：畫過的地方會稍微膨脹，用來讓液滴末端和邊緣鼓起。
Grab brush（抓取筆刷）：直接拉動 mesh 來塑形、移動各部位。
Wireframe（線框）：作者展示盤子的線框，當作作業提示。
