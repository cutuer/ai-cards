🧑‍🏫 這是講者在 BCON26 演講的最後一段。他把自己做的即時動畫工具，直接套用在正式製作用的角色上，示範「在 3D 畫面裡直接捏動作」怎麼運作，也講了背後的加速技巧。想了解 Blender 動畫以後可能變得多直覺，這段最實際。

  • 43:52 選取任何東西都有即時的 motion path。動畫沒有預先快取，打開檔案後直接讀 F curves，靠骨骼之間的簡單關係「預測未來」。
    ↳ motion path 是把骨骼一路會經過的位置畫成一條線。F curves 是記錄數值隨時間變化的曲線。工具不先算好存起來，而是直接讀曲線，靠骨骼之間的關係推算接下來的位置。
  • 45:00 講者強調這些實驗對既有動畫也有用。他有很多功能的 roadmap，同時已經把演講中的許多工具帶到 production rig 上。
    ↳ rig 是讓角色能被操控的骨架加控制器，production rig 是正式製作用、功能完整的版本。講者的意思是：這些工具也能拿來改已經做好的動畫，而且已經能接上實際在用的 rig。
  • 45:00 示範 Pierrick 的檔案：畫面上看到的是 motion path，還有真正的 onion skins。
    ↳ onion skins（洋蔥皮）是把前後幾格的姿勢半透明疊在畫面上，一眼就能看出動作怎麼變化。這裡用的是 Pierrick 的真實檔案，不是講者特別準備的示範場景。
  • 45:35 這個檔案用的不是 Motionator rig，而是一般 rig。控制方式差不多而且即時，但這裡也能用 splined animation。
    ↳ 這裡沒用講者自製的 Motionator rig，而是一般的 rig，一樣能即時控制。也支援 splined animation，也就是在關鍵格之間由電腦用平滑曲線自動補出來的動畫。
  • 45:35 講者自己做了一套「曲線在空間中代表什麼」的抽象層。可以逐格調整曲線離 slider 的遠近。
    ↳ 他在曲線上包了一層，讓你不用懂曲線數學，只要看它在 3D 空間裡長什麼樣子。slider 是拖拉調數值的控制條，可以逐格調整曲線跟它的距離。
  • 46:11 底層其實是在操作真實動畫的 handle：把 handle 拉近，同時保持平行或保持斜率，藉此在 3D 中調整。
    ↳ handle 是關鍵格兩側的小把手，決定曲線怎麼彎進、彎出。你在 3D 裡拖曲線，背後其實是在動這些把手。拉近時會維持平行或原本的斜率，所以曲線形狀不會亂掉。
  • 46:11 經 Pierrick 同意後，講者故意破壞他的部分影格，示範更新是即時的，沒有任何計算等待。
    ↳ 他當場把別人的動畫弄亂，路徑和畫面馬上跟著變，不用按計算，也不用等。這證明整套東西是真的即時運算，不是事先算好的畫面。
  • 46:43 onion skins 即時出現，可用開關切換。面板可以加入角色並自動抓取；可選 frame step 或 snapshot，例如從每 5 格改成每 3 格，動畫被破壞後也照樣即時更新。
    ↳ 洋蔥皮可以一鍵開關，把角色加進面板就會自動套用。frame step 是每隔幾格顯示一次，snapshot 是抓特定的姿勢。間隔從 5 格改成 3 格，或動畫被改亂，都會馬上更新。
  • 47:13 開啟 auto-keying 後旋轉控制器，動畫會直接轉移。可以在 3D 空間操作真實曲線，也能調整控制器的 tension，把它推向或拉離下一個 key。
    ↳ auto-keying 是一動控制器就自動記下關鍵格（key）的模式。開著它轉控制器，動畫立刻跟著改。tension 是曲線的鬆緊，用來調整動作要貼近下一個 key，還是離遠一點。
  • 47:13 講者說這改變了他的工作方式：可以直接從 blocking 進入 splining，不會覺得彆扭，因為 splining 出現的怪異之處能馬上看見、當場修正。
    ↳ blocking 是先只擺出幾個關鍵姿勢的草稿階段，splining 是再讓電腦補成順暢的動作。以前轉過去常冒出怪動作，現在能立刻看到、當場修，所以轉換起來不再卡卡的。
  • 47:46 splining 時常需要加 support keyframe 來修 arc。用這個工具就不需要了，直接抓住影格，就能用很少的格數得到想要的 arc。
    ↳ arc 是動作走過的弧線，像揮手時手畫出的軌跡。以前弧線不對，得多插 support keyframe（輔助關鍵格）去拉。現在直接抓那一格拖就好，用更少的格數就能做出好弧線。
  • 48:16 spliner／motion sculpting 同樣用在 production rig 的密集動畫上。側邊面板有 AnimSculpt，可以即時移動路徑，按住 Shift 可平滑路徑。
    ↳ dense animation 指幾乎每一格都有 key 的密集動畫，例如動作捕捉資料。AnimSculpt 是側邊面板的工具，可以直接拖動路徑，按住 Shift 刷過去就能把路徑抹平順。
  • 48:49 可以直接影響 production rig 的 root，在沒有停留的影格上修改動畫，人只要看著別的影格就能調整。
    ↳ root 是帶著整個角色移動的最上層主控骨。你不用跳到要改的那一格，停在別格看著畫面，就能修改其他時間點的動作。
  • 48:49 選任何一根骨骼（例如手臂）都會即時給出 motion path。還可以做 offset motion path、修正旋轉、做 aim space 相關操作。
    ↳ 點任何一根骨骼都會馬上出現路徑。另外還列了 offset motion path、修正旋轉、aim space 等功能，影片沒有細講，只知道它們都建立在同一套即時路徑上。
  • 49:19 技巧：Blender 每個 cycle 只能評估一次 depsgraph，要計算未來每一格會很慢。講者依電腦核心數建立場景的 shallow copies，平行讀取。
    ↳ depsgraph 是 Blender 算出「這一格場景長怎樣」的機制，一次只能算一格，要看未來很多格就會很慢。講者依 CPU 核心數開出多份輕量的場景複本（shallow copies），同時分頭計算。
  • 49:52 教訓：以前每次都重新上傳 onion skins，非常慢。後來改成只上傳一次，再依 weight paint 變形，等於只在 GPU 上重做 armature skinning 的權重。
    ↳ weight paint 標出每塊皮膚跟著哪根骨頭動，armature skinning 則依照這些權重讓模型跟著骨架變形。他改成模型只傳一次給顯示卡（GPU），之後的變形交給顯示卡算。
  • 49:52 限制：如果有 corrective modifier 之類的東西，onion skin 可能不會一比一，但講者認為夠用，比沒有好得多。
    ↳ corrective modifier 是在特定姿勢修正變形的額外設定，例如彎手肘時修肌肉的形狀。有這類設定時，洋蔥皮不會完全準確，但拿來判斷動作已經很夠用。
  • 50:27 這套做法在密集動畫上也能用。講者從其他 stateless add-on 實驗得到另一個點子：對已完成的動畫，在同一個 rig 同時取得 IK 和 FK 的優點（字幕原文寫作「AK FK」）。
    ↳ stateless add-on 大致是指不另外存狀態、直接從現有動畫計算的外掛。IK 是拉手腳末端來帶動整條肢體，FK 是一節一節轉。他想讓做好的動畫同時享有兩者的好處。
  • 50:59 可以做 aim space（講者說會有點複雜），也可以在這裡用 wormholes：production rig、動畫、onion skins 都是同樣概念。
    ↳ wormholes 是講者的功能名稱，下一條會解釋。重點是 aim space 和 wormholes 也能套在正式 rig 上，因為它們跟路徑、洋蔥皮用的是同一套底層概念。
  • 50:59 wormholes 讓動畫幾乎「原地」呈現，實際上仍在空間中移動。可以看到動作相對於自身、而非相對於世界的 arc，再到任何地方繼續修。
    ↳ 角色邊跑邊動時，路徑會拉成一長條，很難看清楚。wormholes 把整體位移扣掉，讓動作像在原地做，只看手腳相對身體的弧線。修完之後，角色還是照原本的路線移動。
  • 51:33 講者說這對清理 arc 和做一些相關技巧很有價值。
    ↳ 弧線乾不乾淨，決定了動作順不順。能扣掉位移、單看身體本身的弧線，清理起來就快很多，這是講者覺得它最有價值的地方。
  • 51:33 這些實驗與工具統稱 Motionator，還沒準備好用於正式製作，但已經可以拿來玩。講者會開放給支持他的人使用。
    ↳ Motionator 是這整批實驗工具的總稱。它還沒穩定到能放心用在正式案子，但已經可以拿來玩。講者會先開放給贊助支持他的人使用。
  • 52:08 講者請大家支持 Blender Foundation：負擔得起可以支持他，負擔不起就先支持 Blender，因為沒有 Blender 就沒有他做的東西。
    ↳ Blender Foundation 是維護 Blender 的非營利組織。講者的意思是：預算有限的話，就先支持 Blender，因為他的工具全都建立在 Blender 上。
  • 52:52 問答：有人問是否聽過 Stephane Sovin 的 Ephemeral Rigging，說它也有不預先處理密集動畫的想法。
    ↳ 觀眾提到 Stephane Sovin 的 Ephemeral Rigging，它也主張不必先處理密集動畫就能直接操控，想知道兩者是不是同一個思路。
  • 53:25 講者回答：這是很類似的系統，差別在他的工具原生存在於 Blender 裡，並用了很多不同技巧。
    ↳ 講者承認兩者概念很像。差別在於他的工具是直接做在 Blender 裡面的，而且背後用了很多不同的技巧。
  • 53:56 問答：能否復原十分鐘前對膝蓋或手肘的修改？目前不行。講者計畫改成建立 snapshot 而不是直接覆寫動畫，可以在修改和 snapshot 之間 blend，也計畫擴充工具組。
    ↳ 目前改完會直接覆蓋原本的動畫，沒辦法回到十分鐘前的版本。之後打算改成修改前先存快照，還能在新舊版本之間調整比例混合，也會再加更多工具。
