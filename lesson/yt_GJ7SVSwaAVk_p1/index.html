🧑‍🏫 這段是 Blender 年度大會 BCON26 的演講。講者 Daniel Martínez Lara 說明 ClayPencil 怎麼從他自己拼出來的實驗工具，變成 Blender 官方的測試專案。重點在一個好點子要變成大家能用的工具，中間會卡在哪些地方。

  • 00:03 講者先播放用 ClayPencil 製作的 Grandma Set 短片，再介紹整個專案。播放時影片聲音出了問題
    ↳ 開場先播用 ClayPencil 做的短片 Grandma Set，讓觀眾先看到成果。ClayPencil 是把 Grease Pencil 和 Geometry Nodes 結合起來的工具。播放時聲音出了狀況，是現場的小插曲。
  • 04:27 講者 Daniel Martínez Lara，來自 Pepe-School-Land。第一個熱情是教學：他在巴塞隆納有自己的動畫學校，主要為專業人士與工作室提供 Grease Pencil 的訓練與顧問
    ↳ Grease Pencil 是 Blender 內建的繪圖工具，可以在 3D 空間裡用筆畫做 2D 動畫。講者在巴塞隆納開動畫學校，主要教專業人士和工作室用這套工具，也當他們的顧問。
  • 04:27 第二個熱情是動畫短片，他提到 Alike 是他第一部用 Blender 製作的短片
    ↳ 除了教學，他也自己做動畫短片。他說 Alike 是他第一部用 Blender 做的短片，代表他是真的拿這套軟體做作品的創作者。
  • 05:00 另一項是 Grease Pencil 加上 Geometry Nodes 做出的效果，講者展示一個去年的快速範例，說做法很直接
    ↳ Geometry Nodes 是 Blender 裡用節點拼接、讓電腦依規則自動產生或變形物件的功能。講者秀了去年把它跟 Grease Pencil 搭在一起的快速範例，說做法其實不複雜。
  • 05:00 Grandma Set 是一支小動畫，屬於 Blender Lab 底下的一個專案
    ↳ Grandma Set 本身只是一支小動畫，主要用來展示工具。它是 Blender Lab 底下某個專案的成果，所以同時也是這個專案的示範作品。
  • 05:30 專案目的是評估把 clay pencil 工具納入 Blender 的可行性。這不是未來一定會納入的承諾，只是測試它是否有用，以及最好的實作方式
    ↳ 這個專案是在評估 Blender 要不要、能不能把 ClayPencil 做成內建功能。講者特別說明，這不代表以後一定會加進去，現在只是在確認它有沒有用、該怎麼做最好。
  • 06:02 這個構想始於兩年前：講者想結合 Grease Pencil 與 Geometry Nodes，因此開始學 Geometry Nodes，做出他自稱粗糙的實作
    ↳ 兩年前他想把 Grease Pencil 和 Geometry Nodes 結合，為此才開始學 Geometry Nodes。第一版是邊學邊做出來的，他自己也承認做得很粗糙。
  • 06:36 add-on 本身是 Antonio Vazquez 為 Grease Pencil 做的，粗糙的是講者自己的 Geometry Nodes 實作。他把 add-on 放上網、拍了教學影片，上一場演講也在講這個
    ↳ add-on 是外掛，裝進 Blender 就能多出新功能。這個外掛是 Antonio Vazquez 為 Grease Pencil 寫的，粗糙的是講者自己做的節點部分。他把整套放上網路並拍了教學。
  • 06:36 社群有人開始用這個粗糙實作做出不錯的作品
    ↳ 即使工具還很粗糙，社群已經有人拿它做出不錯的作品。這讓講者確定這個方向有人需要。
  • 07:08 講者看到社群有興趣。依他做 Grease Pencil 的經驗，有個好點子和擁有能用於製作的工具，是完全不同的兩件事
    ↳ 他從做 Grease Pencil 的經驗學到一件事：想到好點子很容易，要把它做成可以放進正式製作流程、穩定可靠的工具，難度完全不同。
  • 07:40 他稱之為 long-term relationship challenges（長期關係的挑戰）：愛上一個點子時，會想像它被用在電影或影集的製作中
    ↳ 他把這種狀況叫做「長期關係的挑戰」。一開始愛上點子，會想像它將來出現在電影或影集的製作裡，但真正的考驗在後面要長期經營。
  • 08:14 就像 Grease Pencil 一樣，在電影院看到 Spider-Man、Unicorn Wars 這類作品用到自己的工具，會很有成就感
    ↳ 他舉 Grease Pencil 為例：在電影院看到 Spider-Man、Unicorn Wars 這類作品用到自己參與的工具，那種成就感很大，也是他想讓 ClayPencil 走同一條路的原因。
  • 08:44 實際投入後問題浮現：缺資源、缺錢、找不到合適的開發者、自己的 Geometry Nodes 能力有限，還有其他職責（例如經營動畫學校）
    ↳ 真的開始做以後，問題一個個冒出來：沒資源、沒錢、找不到適合的工程師，他自己的 Geometry Nodes 功力也有限，還要顧學校等其他工作。
  • 09:16 Blender 一出新版本就有大量變動，ClayPencil 教學也會過時，必須持續維護，因為它不只是點子，而是給人使用的產品
    ↳ Blender 每出一版改動都很多，舊的做法和教學影片很快就不適用了。他提醒，工具一旦給別人用，就是產品，得一直跟著更新維護。
  • 09:48 遇到困難時會想改用 AI。講者提到用 AI 把 2D 動畫轉成 3D 是有趣的方向
    ↳ 卡關的時候，人會想乾脆改用 AI。他也承認，用 AI 把 2D 動畫轉成 3D 是有意思的方向。
  • 10:22 但他的目標是讓這套工具存在 Blender 內部
    ↳ 不過他真正想要的，是讓這套工具直接內建在 Blender 裡，大家打開軟體就能用，不用另外找外部方案。
  • 10:22 去年與 Blender 討論後，Blender 決定把 ClayPencil 放進 Blender Lab 專案底下
    ↳ 去年他和 Blender 官方談過後，官方決定把 ClayPencil 收進 Blender Lab。Blender Lab 是官方拿來試驗新點子的專案框架。
  • 10:56 Blender Lab 是用來嘗試新東西的，不做承諾，只測試好不好用。這個專案讓 ClayPencil 取得資金，團隊約 5 個月前開始進行
    ↳ Blender Lab 的原則是先試、不保證會正式納入。這樣安排讓 ClayPencil 拿到經費，也有了團隊，大約五個月前正式開工。
