  • 00:00 最新版 Windows Codex app 新增 Computer Use 與 mobile access（行動裝置存取），整體 app 體驗也有一系列改進
    ↳ Windows 版 Codex（OpenAI 的 AI 助理 app）這次加了兩個新功能：Computer Use，以及 mobile access（用手機遠端查看、指派電腦上的工作）。介面和操作也有一批改進。
  • 00:00 Computer Use 可以操控電腦上的任何 app，代替你執行任務
    ↳ Computer Use 讓 Codex 自己操作電腦。它能打開、點選你電腦上的任何 app，把事情做完，不只是告訴你步驟。
  • 00:00 如果任務能在瀏覽器裡完成，可以改用 Codex for Chrome 整合。它能同時在多個分頁、全程在背景作業；其他情況則適合用 Computer Use
    ↳ 事情在網頁上就能做完的話，改用 Codex for Chrome（接進 Chrome 瀏覽器的版本）。它能同時開多個分頁、全在背景做。要用到其他軟體時，才用 Computer Use。
  • 00:31 開始使用：到 Codex app 的設定裡開啟 Computer Use 選項
    ↳ 這功能要自己開。到 Codex app 的設定裡，把 Computer Use 選項打開。
  • 00:31 開新對話時，在 composer 裡用 Add computer 就能啟用 Computer Use
    ↳ composer 是你打字下指令的輸入框。開新對話時，在這裡點 Add computer，等於告訴 Codex 這次可以操作你的電腦。
  • 00:31 可以用 @mention 指定電腦上已安裝的特定 app
    ↳ @mention 是打 @ 再選名稱的指定方式。打 @ 加上 app 名稱（例如 Excel），就能明確告訴 Codex 這次要用哪個已安裝的軟體。
  • 00:31 Codex 開始作業後會接管螢幕和游標，作業期間桌面與游標的外觀會出現變化
    ↳ Codex 開始做事後，螢幕和滑鼠游標都由它控制，桌面和游標的樣子也會變。看到畫面變了不用緊張，這代表它正在操作。這段時間電腦是它在用。
  • 00:31 Codex 工作時你可以離開座位，例如起來伸展、倒杯水或去開會。筆電留在桌上讓 Codex 做事，你只要帶本筆記本
    ↳ 它在電腦上自己做事，你不用盯著。可以起來伸展、倒水、去開會，筆電留在桌上繼續跑，你帶本筆記本就好。

    ↳ 想知道它做到哪裡，不用走回座位。打開 iPhone 或 Android 手機上的 ChatGPT app 就能看進度。

    ↳ 要把手機連上電腦，有兩個入口：點 Codex app 最下面的手機圖示，或進入 Settings（設定）→ Connections（連線）。
  • 01:01 必須先登入 ChatGPT 帳號，才能啟用行動裝置存取
    ↳ 前提是先在 Codex app 登入 ChatGPT 帳號。沒登入的話，手機存取功能開不了。
  • 01:01 登入後掃描 QR code，並在 ChatGPT 手機 app 登入 Codex，你的 Windows 裝置會自動出現在清單中
    ↳ 登入後畫面會出現 QR code（用手機相機一掃就能連線的方格圖）。用手機掃描，再到 ChatGPT app 登入 Codex，你的 Windows 電腦就會自動出現在清單裡。
  • 01:01 只要電腦保持開機並連上網路，就能在手機上查看執行中的任務，或開始新任務
    ↳ 條件是電腦要開著、有連網。這樣你就能在手機上查看正在跑的任務，也能直接交代新任務。

    ↳ plugins 是外掛功能，讓 Codex 多接一些工具或服務。人在外面時，原本裝好的 plugins 照樣能用，也能從手機開一個需要操作電腦的新任務。
  • 01:31 這些更新讓 Codex 在 Windows 上能完成更多事，你不必被綁在電腦前
    ↳ 整體來說，Codex 在 Windows 上能做的事變多了。你不用一直坐在電腦前，工作也能繼續進行。
📘 術語
Computer Use（電腦操控）：可操控電腦上任何 app，代替你執行任務；作業時會接管螢幕與游標
Codex for Chrome（Codex 的 Chrome 整合）：適合瀏覽器能完成的任務，可同時在多個分頁、在背景作業
composer（輸入區）：字幕未解釋；開新對話時在這裡用 Add computer 啟用 Computer Use
@mention（@ 提及）：用來指定電腦上已安裝的特定 app
mobile access（行動裝置存取）：透過 iOS／Android 的 ChatGPT app 查看或開始 Codex 任務
QR code（QR 碼）：登入 ChatGPT 帳號後掃描，用來在手機 app 登入 Codex
plugins（外掛）：字幕未解釋；只提到外出時可使用現有的 plugins
