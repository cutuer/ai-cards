📘 術語
VRAM（顯示卡記憶體）：VRAM 越大，能生成的影片尺寸越大；有人用 8GB 搭配 dynamic VRAM 也能跑
dynamic VRAM（動態 VRAM）：8GB 顯示卡要能跑，需要系統 RAM 足夠並啟用這個功能
Sage Attention（Sage Attention 加速）：用來加快速度；適用 Windows 與 Nvidia 顯示卡，30 到 50 系列應該都能正常運作
bat file（批次檔）：用來更新 ComfyUI、安裝 Sage Attention，或帶參數啟動 ComfyUI 的檔案
Git pull（Git 拉取更新）：非 easy install 版本的使用者，可以用它手動更新 Pixaroma nodes
manager（節點管理器）：也可以用來更新 Pixaroma nodes；Pixaroma 曾因 GitHub 問題被下架一段時間
workflow manager（workflow 管理器）：作者自製，按 W 或 Alt+W 開啟，可以移動、排列、重新命名 workflow
quantization（量化）：兩個模型各有不同 quantization 的版本；作者推薦 pruned int8
pruned int8（pruned int8 版本）：作者推薦所有人都用這版；其他版本比較慢，品質也沒有明顯提升
first-last frame to video（首尾影格轉影片）：MiniMax H3 的兩個模型之一
reference to video（參考圖轉影片）：MiniMax H3 的另一個模型，給其他 workflow 使用
text encoder（文字編碼器）：這裡用的是 Qwen 模型，32 billion 參數，放在 text_encoders 資料夾
parameters（參數量）：Qwen 有 32 billion；之前用的模型是 4 和 8 billion
VAE（VAE）：有兩個模型，因為這個模型也支援音訊；兩個都放進 VAE 資料夾
diffusion_models（diffusion_models 資料夾）：放 MiniMax 模型的位置，作者在裡面另建 h3 資料夾
license（授權條款）：排除歐盟、英國、韓國、美國；被排除地區的使用者可以填申請表
custom nodes（自訂節點）：這些 workflow 只用到 Pixaroma nodes
node definitions（節點定義）：模型下載完後按 R 重新整理
portrait / landscape（直式／橫式）：切換這兩個選項會決定影片比例
