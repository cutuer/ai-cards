📘 術語
context（上下文／背景資訊）：可以給 bot 大量 context，把它需要知道的東西都教給它
agent（代理人）：字幕提到「agent 時代」，以及用 agent 購物買鞋
auto battler（自動戰鬥遊戲）：他們最初的遊戲概念，最後聚焦成純 auto battle 機制
cosmetics（外觀道具）：早期的變現構想之一，後來被捨棄
PR (pull request)（合併請求）：bot 會修 PR、自動核准 PR，再 merge 進 main
mash（（團隊用語）merge PR）：bot 取的馬鈴薯主題名稱：每次 merge PR 都叫 mash
main（主分支）：PR 核准後 merge 進去的地方
prod（正式環境）：被一個有問題的 SQL query 搞掛，註冊因此暫停
SQL query（SQL 查詢）：software factory 送出有問題的 SQL query，導致 prod 掛掉
software factory（軟體工廠）：由 chief bot 帶一群 bot 做 playtest、修 PR、自動核准並 merge
chief bot（主管 bot）：負責帶其他 bot 一起做 playtest、修 PR
playtest（試玩測試）：factory 裡 bot 團隊做的工作之一
data bot（數據 bot）：用來抓取最終數據的 bot
moderation（內容審核）：審核使用者上傳的內容；當時壞了，出價沒有完全成功
SVG（向量圖檔格式）：廣告出價時上傳的 logo 必須是 SVG
vibe coded（憑感覺寫的程式）：用來形容廣告預覽畫面，字幕沒有進一步解釋
sponsored bid（贊助出價）：廣告主出價搶頂位，還沒辦法顯示在最上方
