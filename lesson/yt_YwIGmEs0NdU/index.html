📘 術語
MCP / Blender MCP（Blender MCP 伺服器）：讓 Claude 連上 Blender 的元件；官方版最近才發布，不要跟社群版搞混，要先在 Blender 裝 add-on
add-on（外掛）：可以拖放進 Blender 安裝，在 Edit > Preferences > Add-ons 確認
auto start（自動啟動）：啟用後，每次開 Blender，MCP 都會自動啟動
dangerously skip permission（略過權限確認模式）：讓 Claude Code 不再詢問就直接執行；作者聲明不建議
continue command（continue 指令）：重開 terminal 時用它回到前一個 session
geometry nodes（幾何節點）：可以加在任何物件上，例如把物件散佈到平面上，或做可調參數的泡泡動畫
world scale（世界尺度）：第一版泡泡太大，就是因為沒考慮 world scale
Cycles render（Cycles 算圖器）：作者場景原本為 Cycles 設定，所以最後簡化了 shading
splats（splats）：World Labs 生成的世界內容；只能在網頁用 spark gs 看，要在 Blender 好好 render 比較難
collider（碰撞體）：World Labs 新增可產生的真正 mesh，讓物件看起來能和環境互動
retarget（動畫重定向）：把 Mixamo 動畫套到另一副骨架不同的角色上
rig（骨架綁定）：角色在 accurate／echo rig 做 rig，字幕說 echo rig 免費
rest pose（靜止姿勢）：字幕說 rest pose 是原始姿勢；作者誤以為兩者相同，匯出的其實是動畫的某一格
FBX（FBX 檔）：從 Mixamo 下載動畫時用的格式
PBR materials（PBR 材質）：實驗花費的項目之一
