🧑‍🏫 這是 OpenAI 介紹新版 ChatGPT「work」模式的官方示範影片。重點是 ChatGPT 接上你的行事曆、聊天工具、檔案，甚至能直接操作電腦，所以它能把整件工作做完，不只是回答問題。影片用一家虛構銀行推出 App 當例子，讓你看到行銷、資料分析、工程三種工作交給它時實際的樣子。

  • 00:03 推出全新 ChatGPT，涵蓋 web、desktop 和 mobile。它透過連接你的所有工具，從只回答問題進化成直接幫你做事
    ↳ 新版 ChatGPT 在 web（網頁版）、desktop（電腦應用程式）、mobile（手機 App）都能用。它接上你平常用的工具之後，除了回答問題，也能實際動手把事情做完。
  • 00:03 介面可從 chat 切換到 work。畫面和原本很像，但不只是對話，可以直接把實際工作交出去
    ↳ 介面多了一個切換：從 chat（聊天）切到 work（工作）。畫面跟以前差不多，差別在於你是把一件工作直接交給它處理，而不是來問問題。
  • 00:03 示範：請它查看行事曆、Slack 和 Drive，幫忙準備今天的行程
    ↳ 講者請它同時查看行事曆、Slack（團隊聊天工具）和 Drive（雲端硬碟），整理出今天要準備的東西。也就是讓它自己去翻你散在各處的資料。
  • 00:33 Plugins：有些連接你平常用的 app，有些把特定角色的工作流程打包好，例如業務、資料科學、行銷等
    ↳ Plugins（外掛）是替 ChatGPT 加上的能力，分兩種：一種接上你常用的 app，另一種把業務、資料科學、行銷等職位常用的工作流程先包好，拿來就能用。
  • 00:33 結果：它找出當天所有相關資訊、筆記，並整理出下一場會議要怎麼準備
    ↳ 它把當天相關的訊息和筆記都找出來，也列出下一場會議該準備的東西。你不必自己一個一個 app 翻找，再把資料拼起來。
  • 00:33 設定自動化：請它當 Chief of Staff，每天早上給一份當日準備簡報
    ↳ 講者請它當 Chief of Staff（幕僚長，替主管打理大小事的人），再設成 automation（設定一次就會定期自動執行），每天早上送一份當日準備簡報。
  • 00:33 世界盃期間也可請它回報德國隊及其他關心賽事的比分
    ↳ 自動化不只能用在工作上。像世界盃期間，也可以請它固定回報德國隊或其他你關心的比賽比分。
  • 01:03 自動化設好之後，明天不必再記得重新問一次
    ↳ 設好之後，它會按時自己執行。你不用每天記得重新開口，也不會因為忘了問就漏掉資訊。
  • 01:03 同一段對話會同步到手機，可以在 web 開始，離開座位後繼續在 mobile 上進行
    ↳ 同一段對話會在各裝置同步。例如在電腦網頁上交代一件事，離開座位後打開手機，就能接著看進度、繼續回覆。
  • 01:03 要處理本機檔案和專案時改用 desktop app。左側列出所有專案、ChatGPT 正在進行的工作，也包含本機檔案
    ↳ 要處理存在自己電腦裡的檔案或專案，就改用 desktop app。畫面左側會列出你的專案、ChatGPT 正在進行的工作，還有本機檔案。
  • 01:33 講者認為這是一大轉變：提供脈絡、把工作交出去，等它需要你或完成時再回來
    ↳ 講者認為用法變了：以前是你問一句、它答一句。現在是你給它背景資料、把工作交出去，然後去忙別的，等它需要你確認或做完了再回來看。

    ↳ 最後請它把這些素材整理成 deck（簡報檔），直接拿到當天的上線檢討會議上用，省下自己整理和排版的時間。

📘 術語
Plugins（外掛）：有些連接你使用的 app，有些打包業務、資料科學、行銷等角色專屬的工作流程
Chief of Staff（幕僚長）：示範中請 ChatGPT 扮演的角色，每天早上提供當日準備簡報
automation（自動化）：設定一次後，不必每天再提醒它執行
desktop app（桌面版應用程式）：要讓 ChatGPT 處理本機檔案和專案時使用
neobank（數位銀行）：示範用的虛構公司 Hudson 的類型
image generation（圖像生成）：用來產生上線網站的所有視覺素材
mood board（情緒板）：用來呈現廣告活動可能樣貌的視覺拼貼
deck（簡報）：把內容整理成可以和團隊分享的簡報
skills（技能）：遇到資料問題時，ChatGPT 會自動帶入合適的 skills 和工作流程
activation rate（啟用率）：儀表板中的指標之一；墨西哥偏低是因為手機號碼驗證出錯
onboarding funnel（新手引導漏斗）：ChatGPT 產出的分析內容之一
data warehouse（資料倉儲）：除了自己的 data store 和試算表，資料也可以放在這裡
dashboard（儀表板）：講者認為比簡報更實用的即時指標呈現方式
in-app browser（內建瀏覽器）：可以預覽儀表板，並點選畫面加註解
Sites（Sites）：讓你直接從 ChatGPT 發布網站
Codex（Codex）：用來處理工程問題；和既有的 Codex 相同，現在放在 ChatGPT 裡
Simulator（模擬器）：用來把 app 開在螢幕上
appshot（appshot）：更聰明的截圖，提供正在看的 app 和採取行動所需的脈絡；按 Cmd-Cmd 拍攝
Computer Use（電腦操作）：ChatGPT 在背景直接操作你的電腦或 app，沒有專屬 plugin 時使用
Chrome extension（Chrome 擴充功能）：讓 ChatGPT 在瀏覽器裡複製貼上資料、瀏覽網站、檢查工作流程
diff（差異比對）：在 Codex 裡查看修正內容的變更
PR（PR（合併請求））：審查變更後發布，以推出新版 app
