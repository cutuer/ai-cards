📘 術語
GPT-5.5 / 5.5（GPT-5.5 模型）：Codex 使用的新模型，可選 low、medium、high、extra high 等級
benchmark（基準測試）：講者說 benchmark 顯示它比 Claude、Gemini 更強、準確度更高
onboarding（新手引導）：安裝後的設定流程，可選工作類型、匯入 projects 與工具
plugins（外掛）：可把大量不同 app 連接進 Codex 的地方
Automations（自動化）：設定排程任務，例如每天 9:00 讀 email 並寄報告
projects（專案）：可工作的資料夾，集中放同一個 app 或網站的相關內容
sandbox（沙盒）：預設權限在安全 sandbox 執行，對電腦沒有太多存取權
auto review（自動審核）：較敏感的任務會請你審核
full access（完全存取）：讓 Codex 存取你整台電腦
tokens（tokens）：講者說 high 模式不會消耗太多 tokens
plan mode（規劃模式）：從加號按鈕進入；Codex 先產出計畫，建置時會參照
connectors（連接器）：讓 Codex 存取不同工具的方式，如 GitHub、Slack、Gmail
browser use（瀏覽器操作）：給權限後 Codex 有自己的瀏覽器，能捲動、截圖、測試
computer use（電腦操作）：講者推薦開啟的 connector 之一
landing page（到達頁／宣傳頁）：demo 做的 AI newsletter 頁面，聚焦價值主張與訂閱
call to action（行動呼籲）：計畫中要求頁面要有明確的 call to action
UI（使用者介面）：字幕說 UI 即 user interface
copy（文案）：字幕說 copy 是 written material，也就是文字內容
Hyperframes by HeyGen（Hyperframes by HeyGen）：可用 Codex 製作 motion graphics 與宣傳影片的 connector
motion graphics（動態圖像）：用 Hyperframes 製作的宣傳影片動畫
voiceover（旁白配音）：影片可選擇加或不加，也能請 Codex 做
carousels（輪播圖）：可用圖像模型製作的社群輪播貼文
✏️ 小考一題

在 Codex 的權限設定中，「default permissions」代表什麼？

A. Codex 可以存取你的整台電腦B. 較敏感的任務會先請你審核C. 只能讀取 Google Drive 的檔案D. 在安全的 sandbox 中執行，對電腦沒有太多存取權
看答案
答案：D。[03:12] default permissions 是在 secure sandbox 執行、權限不多；auto review 才是請你審核敏感任務；full access 才是存取整台電腦
