🧑‍🏫 這支影片介紹 Claude Code 的各種安裝和使用方式，包括終端機、VS Code 等程式編輯器、Claude 電腦版和網頁版。Claude Code 是能直接讀取、修改你電腦裡檔案的 Claude 工作模式。看完你會知道每種方式怎麼裝，也知道哪一種比較適合自己。

  • 00:06 Claude Code 安裝很簡單，可以在終端機（terminal）、網頁（web）或 IDE 中使用
    ↳ 終端機（terminal）是用打字下指令來操作電腦的視窗。IDE 是寫程式用的編輯軟體。Claude Code 在這兩種地方和網頁上都能用，安裝步驟都不複雜。
  • 00:06 macOS、Linux 或 WSL：用 curl 指令一次完成安裝
    ↳ Mac、Linux 或 WSL（在 Windows 裡執行 Linux 的功能）的使用者，貼上一行 curl 指令就能裝好。curl 是從網路下載東西的指令工具。
  • 00:06 也可以用 Homebrew 的 brew install 安裝，但這種方式沒有自動更新功能
    ↳ Homebrew 是 Mac 上常用的軟體安裝管理工具，打 brew install 就能安裝。缺點是沒有自動更新（auto-update），出新版時要自己手動更新。
  • 00:06 Windows 有幾種方式：在 PowerShell 用 Invoke-RestMethod 指令；在 CMD 用 curl 指令
    ↳ Windows 內建兩種指令視窗：PowerShell 和 CMD。在 PowerShell 裡貼 Invoke-RestMethod（用來抓網路資料的指令）那一行；在 CMD 裡則貼 curl 那一行。
  • 00:06 Windows 也可以用 winget 指令安裝，但跟 Homebrew 一樣不會自動更新
    ↳ winget 是 Windows 內建的軟體安裝工具，也能用來裝 Claude Code。不過它和 Homebrew 一樣不會自動更新，要記得自己定期更新。
  • 00:37 安裝後進入專案資料夾（project directory），執行 claude 啟動
    ↳ 裝好後，先在終端機切換到專案資料夾（project directory，也就是放這份工作檔案的資料夾），再輸入 claude 按 Enter 就會啟動。
  • 00:37 第一次啟動會有初始設定，例如選擇顏色主題、登入 Claude 帳號（Pro、Max 或 Enterprise），也可以改用 API key
    ↳ 第一次啟動會帶你做設定，例如挑選畫面配色、登入 Claude 付費帳號（Pro、Max 或 Enterprise）。也可以改用 API key，這是一串代表你身分的金鑰，通常按用量計費。
  • 00:37 如果你的組織有 Claude Enterprise 帳號，登入時記得選這個選項
    ↳ 如果公司有幫你開 Claude Enterprise（企業版），登入時要選企業版的選項，才能用到公司的帳號。
  • 00:37 在哪個資料夾執行 Claude，它就能存取那個資料夾和底下所有子資料夾
    ↳ 你在哪個資料夾啟動 Claude，它就能讀取、修改那個資料夾和裡面所有的子資料夾。所以只在你要它處理的專案資料夾裡啟動就好。
  • 00:37 VS Code：打開擴充功能面板，搜尋 Claude Code
    ↳ VS Code 是很常見的程式編輯器。打開它的擴充功能（extension，也就是幫軟體加功能的外掛）面板，搜尋 Claude Code。
  • 01:07 認明 Anthropic 發布、有藍色勾勾的擴充功能再按安裝；裝完可能要重新啟動 VS Code
    ↳ 搜尋結果可能有別人做的同名外掛，要選發布者是 Anthropic（開發 Claude 的公司）、有藍色認證勾勾的那個。裝好後如果沒出現，就重開 VS Code。
  • 01:07 按 Ctrl（或 Command）+ Shift + P 開啟面板，搜尋 Claude Code，然後開啟新分頁
    ↳ 按 Ctrl+Shift+P（Mac 按 Command+Shift+P）會跳出指令面板，可以用來搜尋所有功能。輸入 Claude Code，選擇開新分頁就能開始用。
  • 01:07 有開檔案時，如果看到 Claude 圖示，也可以直接點它開啟
    ↳ 如果你正開著某個檔案，畫面上會出現 Claude 圖示，直接點它也能打開，不用記快捷鍵。
  • 01:07 也可以在設定檔中關掉圖形介面，直接使用終端機模式
    ↳ 不喜歡按鈕式的圖形介面的話，可以在設定裡關掉，改成純文字的終端機模式，用起來就跟在終端機裡一樣。
  • 01:07 JetBrains IDE：到 JetBrains Marketplace 安裝 Claude Code plugin
    ↳ JetBrains 是另一家做程式編輯器的公司，例如 PyCharm。它的外掛叫 plugin，要到官方外掛商店 JetBrains Marketplace 搜尋 Claude Code 來安裝。
  • 01:41 JetBrains 裝好後要重新啟動 IDE，再開時會看到 Claude 圖示，點了會打開終端機模式的窗格，在旁邊跟你一起工作
    ↳ 裝好後要重開軟體。重開後點 Claude 圖示，旁邊會打開一個終端機窗格，你一邊看檔案，Claude 就在旁邊一起工作。
  • 01:41 Claude Desktop 也能用 Claude Code：安裝並登入後，上方會有一個「code」切換開關
    ↳ Claude Desktop 是 Claude 的電腦版應用程式。安裝並登入後，畫面上方會有一個「code」開關，切過去就是 Claude Code，完全不用碰終端機。
  • 01:41 Desktop 的 Claude Code 外觀和 Claude 聊天介面相似，但可以指定資料夾工作、調整權限，甚至在雲端環境中執行
    ↳ 外觀就像平常和 Claude 聊天，但可以指定它在哪個資料夾工作、設定它能做哪些事（權限），還能改在雲端環境執行，也就是在遠端的電腦上跑。
  • 02:15 網頁版在 claude.ai/code，用起來跟 Desktop 很像，但只能用在 GitHub repository
    ↳ 網頁版在 claude.ai/code，操作方式和 Desktop 很像。限制是只能處理 GitHub repository，也就是放在 GitHub 網站上的專案。
  • 02:15 想隨時用到最新功能，終端機是最好的選擇，新功能最先在那裡推出
    ↳ 想第一時間用到新功能就選終端機，因為影片說新功能都會最先在終端機版推出。
  • 02:15 IDE 整合版的體驗大致跟終端機非常接近，適合想讓 Claude Code 跟慣用編輯器結合的人
    ↳ IDE 版的體驗和終端機版非常接近，好處是在你平常用的編輯器裡就能用，不必一直切換視窗。
  • 02:15 Desktop 適合讓 Claude 在背景跑，你同時做其他事
    ↳ Desktop 版適合把任務交出去：讓 Claude 在背景自己跑，你同時去做別的事，做完再回來看結果。
  • 02:45 網頁版適合透過 GitHub repository 遠端處理專案，或同時平行跑多個 session
    ↳ 網頁版適合不在自己電腦前時，透過 GitHub 上的專案遠端處理工作；也可以同時開好幾個 session（各自獨立的工作階段），平行處理不同任務。
  • 02:45 要用哪種方式使用 Claude Code，由你自己決定
    ↳ 沒有哪一種是標準答案，看你的習慣和需求，自己決定用哪一種方式就好。
