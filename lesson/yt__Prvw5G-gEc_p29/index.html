🧑‍🏫 這段是 Grok Bot Galaxy 第三天的直播片段。團隊要在三天內做出一門生意，這次請來 Stripe 的來賓，一起討論他們的卡牌遊戲 ThursdayArena 要怎麼賺錢，也聊到怎麼用講話來指揮 AI agent。想知道小產品可以怎麼收費，或想更會交代 AI 做事的人，都值得看。

  • 332:19 週末做 side project 時，agent 常卡在需要人去做的手動任務上，樂趣就沒了；大家想要的是讓它自動跑下去
    ↳ 週末做小專案時，agent（會自己動手把任務做完的 AI 助理）常停下來等人處理手動雜事，一卡住就不好玩了。大家想要的是它能一路自己做到完。
  • 332:49 在 projects 這部分，可以直接從 Grok Bot 開好所有需要的 provider，然後繼續做下去
    ↳ projects 是 Grok Bot 裡管理專案的區塊。provider 指專案要用的外部服務，例如資料庫。在這裡就能一次開好，不用跳去各家網站設定，做到一半也不會斷掉。
  • 332:49 這次的目標是三天內做出一門生意，目前已經推出第一個產品
    ↳ 這次的挑戰是三天內從零做出一門真的能營運的生意，不只是寫個程式玩玩。錄到這段時，第一個產品（就是下面的卡牌遊戲）已經推出了。
  • 333:23 團隊走典型舊金山新創的路線：先拉使用者，之後再想怎麼賺錢；原本考慮過廣告和賣周邊商品
    ↳ 舊金山很多新創的做法是先求有人用，之後再想怎麼收錢。團隊一開始想到的是最常見的兩種收入：放廣告和賣周邊商品。
  • 333:53 ThursdayArena 有 practice mode 和 play mode；卡牌角色來自 Grok bot marketplace（xAI/bot/marketplace）上的 bot，被匯入成遊戲角色
    ↳ ThursdayArena 是他們做的卡牌遊戲，practice mode 是練習模式，play mode 是正式對戰。卡牌角色取自 Grok bot marketplace（大家上架、分享 bot 的市集）裡的 bot。
  • 333:53 卡牌設計參考了 Magic the Gathering 和 Yu-Gi-Oh
    ↳ 卡牌設計參考了《魔法風雲會》和《遊戲王》這兩款很有名的集換式卡牌遊戲，玩過的人應該會覺得卡面和規則很眼熟。
  • 334:23 玩法：購買並選出陣容，安排順序和能力，按 fight 後跟對手配對；回合之間可以花贏來的 gold（他們想把它改名叫 tokens）
    ↳ 玩法：先買卡組隊，排好出場順序和能力，按 fight 後系統幫你配對手。贏了會拿到 gold（遊戲幣），回合之間可以拿來花。他們想把 gold 改名叫 tokens。
  • 334:54 賺錢方式一：廣告。需要很多人看才有效，但很適合用來支撐免費產品
    ↳ 廣告收入要看有多少人看，人少就賺不到什麼。好處是玩家一毛錢都不用花，所以很適合拿來撐一個免費產品。
  • 335:27 來賓提議讓玩家付費升級或解鎖更好的卡；團隊不想做 pay to win，認為這類遊戲是在利用玩家想贏的心態
    ↳ 來賓建議讓玩家付錢升級或解鎖更強的卡。團隊不想做 pay to win（花錢就能變強、比較容易贏），他們認為這種遊戲是在利用玩家想贏的心態。
  • 335:57 賺錢方式二：贊助角色，例如跟 Pokemon、Disney 聯名，或讓品牌替遊戲做客製卡（類似 Snap 的客製濾鏡）
    ↳ 第二種是贊助角色：跟寶可夢、迪士尼這類品牌聯名，或讓品牌付錢做專屬卡，就像 Snapchat 讓品牌做客製濾鏡。
  • 336:32 用一個記錄 go-to-market／賺錢點子的 bot，以語音記下：合作夥伴可付費出現在卡牌上，但不改變卡牌的效果
    ↳ 他們有個 bot 專門記 go-to-market（產品怎麼推出、怎麼賣）和賺錢的點子。這次用講的記下：合作夥伴可以付費出現在卡面上，但卡的效果不變。
  • 337:10 遊戲資料庫用 PlanetScale；PlanetScale 的朋友給了一個幫忙做資料庫管理的 bot，引發一個想法：公司可以直接推出包含所需全部技能的 bot，而不只是 plugin
    ↳ 遊戲資料放在 PlanetScale（雲端資料庫服務）。對方給了一個會管資料庫的 bot，他們因此想到：公司可以直接推出一整套技能都會的 bot，而不只是 plugin（外掛的小功能）。
  • 337:46 例如做一個 StripeLink bot 幫人整合、設定卡片；可以讓公司付費，把自家 bot 列為 featured bot
    ↳ 例如 Stripe（知名的線上金流公司）可以推出 StripeLink bot，幫人整合、設定卡片。平台也可以向公司收費，把它的 bot 放在推薦位置（featured bot）。
  • 338:20 來賓說：兩年前是打程式碼，一年前是打 prompt，現在直接拿出手機用講的跟 Grok 溝通
    ↳ 來賓感嘆變化很快：兩年前大家自己寫程式，一年前改成打 prompt（給 AI 的文字指令），現在連字都不用打，拿起手機跟 Grok 用講的就好。
  • 338:55 Grokbot 新增語音互動，一小時前才剛宣布，會在接下來幾天陸續推出
    ↳ Grokbot 新增語音互動，也就是 voice dictation：用講的下指令，不用打字。這功能是錄影前一小時才宣布的，接下來幾天會陸續推出，不是馬上每個人都有。
  • 339:30 語音適合走路、搭地鐵等不方便打字的場合；例子：邊走邊口述，五分鐘內請 bot 排好週年紀念日行程
    ↳ 走路、搭捷運這種不方便打字的時候最好用。影片裡的例子：一邊走一邊講自己要什麼，五分鐘內 bot 就把週年紀念日的行程排好了。
  • 340:02 用口述處理知識型工作（協調事情、寄 email 等）也很好用；agent 是語言模型，擅長處理文字，可以直接丟一大堆內容給它
    ↳ 協調事情、寄 email 這類知識型工作也很適合用講的。agent 背後是語言模型，本來就擅長處理文字，想到什麼可以一股腦全丟給它。
  • 340:36 技巧：請 agent 用自己的話重述計畫，確認它真的聽懂，就像確認實習生聽懂了再讓他動手
    ↳ 小技巧：交代完之後，請它用自己的話把計畫講一遍。就像交代實習生做事，先確認他真的聽懂，再讓他動手，免得做錯方向。
  • 341:11 模型越來越強，瓶頸變成你能不能把想法講清楚；可以先隨意講五分鐘，再請它重述，檢查它有沒有理解
    ↳ 模型越來越聰明，卡關的地方反而變成你有沒有把想法講清楚。可以先隨口講五分鐘，再請它複述，對照看看它理解得對不對。
  • 341:11 賺錢方式三：freemium，先免費玩幾場，之後每月付 $2 訂閱才能繼續玩，或把部分功能鎖在付費牆後面
    ↳ 第三種是 freemium（基本免費、進階收費）：先免費玩幾場，之後每月付 2 美元訂閱才能繼續玩，或把部分功能放在付費牆後面，付錢才能用。
  • 341:41 付費功能的點子：多隊（five team）對戰，或讓玩家跟朋友自己辦聯賽，呼應以前實體集換式卡牌遊戲的聯賽
    ↳ 可以收費的功能，例如多隊一起混戰，或讓玩家跟朋友自己辦聯賽，就像以前實體集換式卡牌遊戲的聯賽那樣。
  • 341:41 訂閱能帶來穩定的收入，對全新的遊戲工作室很重要，也可以拿來資助下一款遊戲
    ↳ 訂閱每個月都有固定收入，錢比較好預估。這對剛起步的遊戲工作室很重要，這筆錢也可以拿去做下一款遊戲。
  • 342:13 點子：工作室就叫 Thursday，推出 Thursday 訂閱，月費可以玩全部遊戲；遊戲越多，訂閱越有價值
    ↳ 點子是：工作室就叫 Thursday，推出 Thursday 訂閱，付月費就能玩旗下所有遊戲。遊戲出得越多，同樣的月費就越划算，訂閱也越有吸引力。
  • 342:43 訂閱用戶已經付費投入，會是新遊戲的早期使用者，會搶先試玩並給意見
    ↳ 已經付錢的訂閱用戶投入比較深，新遊戲一推出，他們會搶先試玩、給意見，等於工作室自己就有一群早期測試玩家。
  • 342:43 聊天的同時 UI 一直在變，因為 Lauren 建的 coding factory 在持續發 PR
    ↳ 他們聊天的時候，畫面上的遊戲介面一直在變，因為 Lauren 建的 coding factory（會自動寫程式、送出修改的系統）在背景持續送出 PR。
  • 343:17 工程師 bot「Bake」從認真開始做這個點子到現在已經發了 235+ 個 PR，可以看到所有事件的即時紀錄（event stream）
    ↳ PR（pull request）就是一份「我改了這些程式，請合併進去」的修改提案。工程師 bot Bake 已經送出超過 235 個，event stream 可以即時看到它在做的每件事。
  • 343:17 轉向問來賓觀察到的趨勢：商業模式可能在改變，也提到 open router
    ↳ 主持人轉頭問來賓觀察到的趨勢：做生意、收錢的方式可能正在改變。也提到 open router（用同一個入口就能呼叫多家 AI 模型的服務）。
  • 343:53 來賓準備從消費者端和企業端兩個角度，談 Stripe 怎麼看這個趨勢（本段在這裡結束）
    ↳ 來賓準備從一般消費者和企業兩個角度，談 Stripe 怎麼看這個趨勢。不過這一段就停在這裡，後續要看下一段。
📘 術語
pay to win（付費取勝）：讓玩家花錢買更強的能力；字幕說這類遊戲利用玩家想贏的心態
sponsored cards（贊助卡牌）：合作夥伴付費出現在某張卡上，但不改變卡牌的效果
freemium（免費增值模式）：先免費玩幾場，之後付訂閱費（例如每月 $2）才能繼續玩，或把部分功能鎖在付費牆後面
marketplace（市集）：Grok bot marketplace，遊戲卡牌角色就是從這裡匯入的 bot
go-to-market（上市策略）：團隊用一個 bot 記錄 go-to-market 和賺錢的點子
coding factory（程式工廠）：Lauren 建立的系統，會持續自動發 PR
PR（Pull Request）：字幕提到工程師 bot Bake 已經發了 235+ 個 PR
event stream（事件串流）：即時顯示正在發生的所有事情的紀錄
voice dictation（語音輸入）：直接用講的跟 Grok 或 agent 溝通，不用打字
