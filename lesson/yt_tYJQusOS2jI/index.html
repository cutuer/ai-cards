📘 術語
Claude skill（Claude 技能）：講者做好的檔案，安裝後 Claude 寫 prompt 時會參考裡面的資料與結構
video prompt builder（影片 prompt 產生器）：講者提供的 Claude skill 名稱，會把 prompt 拆成極細的分鏡內容
first frame / start frame（第一幀／起始畫面）：要轉成影片的第一張圖片，上傳後作為影片的起點
seamless transition（無縫轉場）：一鏡到底、不切鏡的轉場；寫進要求後，prompt 結尾會註明 No cut
shot list（鏡頭清單）：從 shot one 到最底下的部分，複製 prompt 時只需要這一段
hex code（色碼）：skill 在 prompt 裡為顏色標註的具體色碼
frame-by-frame breakdown（逐格拆解）：skill 的一部分，讓 Claude 知道要拆到多細，並標上時間碼
character limit（字元上限）：SeaArt 上限 4,000 字元，有些平台是 3,000；超過就請 Claude 縮短
aspect ratio（畫面比例）：生成前可調整，例如 16:9
Omni reference（全方位參考）：把角色設定圖、地點圖等素材上傳到 prompt 欄，SeaDance 會理解並全部放進影片
character sheet（角色設定圖）：讓模型知道角色長相的參考圖，用於 Omni reference
character reveal（角色揭露）：開頭看不到角色的臉，之後才露臉的說故事手法
VFX（視覺特效）：影片中的特效，例如變形、爆炸、假人解體
Meta ads（Meta 廣告）：可用一個 prompt 生成 15 秒影片，做成多支不同廣告投放
