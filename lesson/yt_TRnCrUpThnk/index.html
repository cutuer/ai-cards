    ↳ viewport 是 Blender 裡邊做邊看的工作視窗，一片紫色代表還沒上材質。Claude 會自己轉攝影機換角度檢查，講者全程沒動手，這一點才是重點。

    ↳ Claude 先看數據：224 個三角面、0 個四邊面，判斷與其修補不如照原尺寸重做。loop flow 指線條順著模型繞成完整的一圈，重建時它會照顧到。
  • 09:25 重建後 Claude 發現端蓋雖然是 quads，但呈螺旋狀，原因是它在各圈之間加了角度偏移，造成扭曲；接著做了一段數學分析
    ↳ 重建完它自己發現端蓋變成螺旋狀、面被扭到，追出原因是每一圈多轉了角度，再用計算修正。它會檢查自己的成品，不是做完就交差。
  • 09:56 過程中跳出「upgrade to keep chatting」，講者用完了 five hour message limit，要到 7:10 p.m. 才重置；講者說模型被修好了，而且比自己手做快

    ↳ 講者自己修的方法：選取物件按 Alt+J（把三角面合併成四邊面），再手動 dissolve（刪掉邊但保留面）幾條邊。這是熟手的做法，Claude 則是選擇從頭重建。

📘 術語
Blender MCP（Blender MCP）：字幕沒有解釋，只說在 Google 搜尋它，從第一個連結下載 add-on
add-on（外掛）：字幕沒有解釋，只說拖曳到 Blender 就能安裝（講者用 5.1）
connector（連接器）：在 Claude 裡新增 Blender connector 後，Claude 就能控制你的 Blender
Python / Bpy（Python / Bpy）：Claude 說它是用 Python/Bpy 來建立和修改 3D 物件
junior 3D generalist（初階 3D 通才）：Claude 說這類人大部分時間在做設定場景、重新命名、批次套材質之類的重複性工作
viewport（視埠）：Claude 提到材質要 render 後才看得出完整效果，viewport 顯示的是一片紫色
render（算圖）：字幕沒有解釋，Claude 說材質要 render 才看得出完整效果
architectural visualization（建築視覺化）：字幕沒有解釋，講者拿平面圖轉 3D 牆的測試來談這個領域
product visualization（產品視覺化）：講者說自己主要做這個，例如替網站做太陽眼鏡的乾淨渲染圖
topology（拓樸）：字幕沒有明確定義；講者檢查模型是不是全 quads、有沒有三角面或 n-gon
quads（四邊面）：講者說全 quads 的拓樸看起來不錯，也是完美 sub-D 的要求
n-gon（多邊面）：字幕沒有定義；講者說好的拓樸不應該有，圓柱端蓋的 n-gon 要刪掉改用 grid fill
tris / triangulate（三角面／三角化）：用 Ctrl+T 把物件三角化；Claude 分析出 224 個 tris
sub-D（細分曲面）：字幕沒有定義；講者說全 quads、沒有 n-gon、沒有扭曲的面就是完美的 sub-D 拓樸
retopology（重新拓樸）：字幕沒有解釋，只開玩笑說做 retopology 的人也完蛋了
grid fill（網格填充）：講者刪掉圓柱上下的 n-gon 後，用它來補上端蓋
loop cut（環切）：字幕沒有解釋，講者在圓柱上加了幾條
triangulated fan topology（三角扇形拓樸）：Claude 用這個詞描述圓柱端蓋，說它對 sub-D 是一場惡夢
loop flow（環線走向）：Claude 說重建時會保持正確的 loop flow
three-point lighting（三點打光）：講者請 Claude 用它；結果是前、後、上方各一盞燈
environment lighting（環境光）：講者通常用漸層之類的東西當背景環境光
Alt+J（Alt+J）：講者手動修拓樸時用它去掉三角面
dissolve（溶解（邊））：講者用 Alt+J 之後，還要 dissolve 幾條邊
