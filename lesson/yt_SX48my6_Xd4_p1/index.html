🧑‍🏫 這支是 Blender 年度大會 BCON26 的演講，講者 Laura Gingrich 示範 Grease Pencil 的新功能。這一段先講為什麼要在製作前期花力氣做視覺開發，接著實際示範新的炭筆筆刷、筆壓設定，以及怎麼用 Blender 練人體速寫。想用 Blender 畫 2D、或想練畫畫的人，看這段可以同時學到觀念和實際操作。

  • 00:01 講者 Laura Gingrich 示範 Blender Studio 與開發者近一兩年做的新功能，內容包含 grease pencil 與 non-linear editor
    ↳ 這場在介紹 Blender Studio（Blender 官方的製作團隊）和開發者近一兩年做的新功能。Grease Pencil 是 Blender 裡能直接在 3D 空間畫 2D 圖的工具；non-linear editor 是另一個主題，這段沒細講。
  • 00:01 講者經歷：從真人商業廣告製作起步（例如 Skittles pox 廣告），之後做紀錄片，用既有素材剪輯說故事
    ↳ 她一開始做真人拍攝的商業廣告，例如 Skittles 的廣告。後來轉做紀錄片，工作是拿已經拍好的素材，靠剪輯把故事串起來。
  • 00:32 之後做新聞，成為熟練剪輯師；她發現只要學會畫畫，就能開始處理累積一二十年的劇本
    ↳ 後來她做新聞，剪輯練得很熟。她手上有累積一二十年的劇本，發現只要學會畫畫，就能自己把這些故事畫出來、開始動工。
  • 01:06 前半段主題：grease pencil 在 visual development（視覺開發）很有用
    ↳ 前半場的主題是：Grease Pencil 很適合拿來做 visual development（視覺開發），也就是正式製作前先畫出角色、場景、氛圍，確定作品要長什麼樣子。
  • 01:06 製作流程觀念：流程開頭犯錯很便宜，後段犯錯非常昂貴
    ↳ Production pipeline（製作流程）是一部作品從點子到完成的整條工作線。越早發現問題，改起來越省；拖到後面才改，前面做好的東西常常要整批重做。
  • 01:38 交給建模、環境、燈光團隊之前，要盡量在流程前段把事情想清楚
    ↳ 建模、做場景、打光都很花人力和時間。所以在交給這些團隊之前，故事、造型、畫面方向要盡量先定好，免得他們做到一半又被推翻。
  • 01:38 要確認故事值得說；點子很便宜，有了 AI 之後更便宜，所以投資的點子要 100% 值得
    ↳ 點子本身不值錢，有了 AI 之後更容易冒出一大堆點子。真正貴的是把點子做出來的成本，所以要先確認這個故事真的值得花錢花時間去做。
  • 02:09 視覺開發也適合跟投資人溝通：拿 prototype、animatic 給他們看，讓他們清楚知道自己資助的是什麼
    ↳ Prototype 是粗略的試做版，animatic 是把分鏡圖接成有時間長度的預覽影片。拿這些給投資人看，他們就能具體看到錢會花在什麼作品上。
  • 02:09 Spider-Verse 的例子：Julien、Vivian、David 把工具設計成模仿既有的實體材料
    ↳ 動畫電影《蜘蛛人：新宇宙》（Spider-Verse）的團隊，包括 Julien、Vivian、David，在設計畫面工具時刻意去模仿真實世界裡已經存在的材料和手法。
  • 02:44 類比 90 年代的 Photoshop：dodge、screen 等功能，都以 lightroom 裡實際能做的事為基礎
    ↳ 90 年代的 Photoshop 也一樣：dodge（局部加亮）、screen（讓畫面疊加變亮的混合模式）這些功能，都是照著沖洗照片時真的做得到的手法設計的，不是憑空發明。
  • 02:44 新的 grease pencil 工具同樣在模仿真實媒材
    ↳ Grease Pencil 的新筆刷也走同一個方向，目標是做出像炭筆、鉛筆這些真實畫材的手感和痕跡。
  • 03:15 Spider-Verse 模仿 offset printing（平版印刷）；一般拍片時，焦點前後的景物會因景深而模糊
    ↳ Offset printing（平版印刷）是漫畫、雜誌常用的印刷方式。一般拍片時有 depth of field（景深）：鏡頭對準的焦點（focal point）最清楚，前後離焦點越遠就越模糊。
  • 03:15 Spider-Verse 改用漫畫印刷的 cyan、magenta、yellow 色版，離焦點越遠，色版錯位越大
    ↳ Spider-Verse 不用模糊，改成模仿印刷時青、洋紅、黃三色版沒對準的樣子。東西離焦點越遠，三色錯開得越多，看起來就像印歪的漫畫。
  • 03:45 Spider-Verse 的突破不是靠想更酷的算圖方式，而是回頭從其他來源找靈感；鼓勵大家也用筆記本、傳統媒材探索
    ↳ 他們的突破不是在電腦裡想出更炫的算圖效果，而是從印刷這種舊技術找靈感。講者也鼓勵大家多拿筆記本、用傳統畫材去摸索。
  • 04:15 示範 charcoal brush（炭筆筆刷），這是講者最愛的筆刷
    ↳ 接著她示範 charcoal brush（炭筆筆刷），這是她最喜歡的一支筆刷。
  • 04:50 講者認為是 5.2 版：新筆刷會出現在下方，帶有雲朵圖示
    ↳ 她印象中是 Blender 5.2 版開始有的。新筆刷會列在筆刷清單下方，旁邊有一個雲朵圖示。
  • 04:50 Blender 要連上網路，按雲朵圖示後會直接下載檔案
    ↳ 雲朵圖示代表這支筆刷還沒下載。電腦要連上網路，點一下雲朵就會自動下載，下載好就能用。
  • 05:24 炭筆筆刷內建兩種角度；講者在 media cache 複製了一份翻轉版，想要也可以從後端自己做兩個版本
    ↳ 炭筆筆刷內建兩種筆觸角度。講者另外複製了一份左右翻轉的版本，你也可以自己多做幾個不同角度的版本。
  • 05:24 炭筆會促使你看角色的形體而不只是線條，適合在前期「我們到底要做什麼」階段實驗
    ↳ 炭筆畫出來是一塊一塊的面，不是細線，所以你會自然去看角色的體積和輪廓。這很適合前期還在摸索「到底要做什麼」的時候拿來試。
  • 05:59 講者做過 365 天人體速寫，體會是重複做的事就會變強
    ↳ 她曾經連續 365 天每天畫人體速寫，最大的心得是：同一件事天天做，就一定會進步。
  • 05:59 她在 iPad 的 Fresco 練得很熟，回到 Blender 才後悔沒一開始就在 Blender 練，那樣知識能直接帶進 3D 工作
    ↳ 她原本在 iPad 的繪圖 App Fresco 練得很熟，換到 Blender 後才後悔沒一開始就在 Blender 練，因為在 Blender 練的手感可以直接用在 3D 工作上。
  • 06:34 引用 Dave 前一天的演講：放輕鬆玩、drawing is seeing（畫畫就是觀察），帶筆記本去咖啡廳、公園畫人畫景
    ↳ 她引用前一天另一位講者 Dave 的話：放輕鬆玩就好，畫畫的本質是學會觀察。帶本筆記本去咖啡廳、公園，畫路人和風景。
  • 07:07 翻轉版炭筆畫軀幹能得到更有趣的輪廓；畫躺著的人時她多用預設版，因為曲線較能表現水平線
    ↳ 用翻轉版炭筆畫軀幹，輪廓會比較有變化。畫躺著的人她多用預設版，因為預設版筆觸的弧度比較適合表現橫躺的水平線條。
  • 07:40 建議用預設炭筆練 60 秒姿勢速寫，靠筆刷材質就能畫出很好的動態，可以做 5 張或 10 張
    ↳ 建議用預設炭筆練 60 秒速寫，就是每個姿勢只給自己一分鐘。炭筆的質感會幫你畫出動態，一次畫 5 張或 10 張就好。
  • 07:40 不方便出門的話，YouTube 上有大量速寫素材
    ↳ 沒辦法出門找人畫的話，YouTube 上有很多專門給人練速寫的姿勢影片或照片，可以直接拿來練。
  • 08:14 精修時她會複製筆刷、把尺寸調小一點，這樣隨時能回到原本的大筆刷
    ↳ 要修細節時，她會把筆刷複製一份再調小尺寸，不直接改原本那支。這樣原本的大筆刷一直都在，隨時能切回去。
  • 08:44 畫垂直線用一版，再切換到水平版繼續畫
    ↳ 炭筆的筆觸有方向性。畫直向的線條用其中一個版本，畫橫向時換成另一個版本，兩個搭配著用。
  • 08:44 一律由大到小：人體速寫重點不在線條，而是量感（volumes）、陰影形狀、建立形體
    ↳ 畫的順序永遠是先大後小。人體速寫的重點不是把線描漂亮，而是先抓出整體的量感和陰影的形狀，把身體的立體感建立起來。
  • 08:44 grease pencil 可以調整筆刷的 sensitivity（筆壓感應）：進入 tool settings，找到 brush settings
    ↳ Sensitivity（筆壓感應）是讓筆畫隨你下筆的輕重改變。要調它的話，進入 tool settings（工具設定），裡面找到 brush settings（筆刷設定）。
  • 09:16 brush settings 裡有曲線，可依需求調整 strength（強度）與 size（大小）的感應，旁邊的按鈕用來開關感應
    ↳ Brush settings 裡有曲線，可以設定下筆輕重怎麼影響 strength（筆畫濃淡）和 size（筆畫粗細）。旁邊有按鈕，用來開關這個感應功能。
  • 09:16 講者希望 3D 使用者對 2D 感興趣，好吸引更多 2D 藝術家加入
    ↳ 她希望習慣 3D 的人也對 2D 感興趣，這樣 Blender 才能吸引更多畫 2D 的藝術家來用。
  • 09:16 預設 pen 筆刷沒有開感應，但她幾乎都會開
    ↳ 預設的 pen 筆刷沒有開筆壓感應，所以不管多用力畫出來都一樣。講者幾乎每次都會把它打開。
  • 09:49 她的做法是啟用 strength 感應，再把曲線拉到最高，只留下最細微的淡出效果
    ↳ 她的設定是開啟 strength 感應，再把曲線整條拉到最高。這樣筆畫大多是實的，只在收筆時留一點點自然的淡出。
  • 10:19 學人體要在速寫與解剖之間來回交替進步，再加上 lighting 會讓一切更複雜，但也很有趣
    ↳ 學人體要在「速寫抓動態」和「研究骨骼肌肉的解剖」之間輪流練，兩邊互相帶著進步。再加上 lighting（光影），會更難，但也更好玩。
  • 10:19 可以找 pose library 或自己在咖啡廳畫的人物當參考；Blender 檔案內有 base human meshes 可以拉進來
    ↳ 參考可以用 pose library（姿勢參考資料庫），或自己在咖啡廳畫的人。Blender 也附有 base human meshes，就是基本的人體 3D 模型，可以拉進場景擺姿勢。
  • 10:50 拉進 base human mesh 後，記得 instance 並 make local（講者略過細節）
    ↳ 拉進人體模型後要做 instance 和 make local。一般來說，這是把引用進來的模型轉成這個檔案自己的東西，才能自由擺姿勢。講者沒細講步驟。
  • 10:50 別忘了加入 grease pencil，繪圖時一定要在 grease pencil 上作業
    ↳ 要記得在場景裡新增一個 Grease Pencil 物件，並且在它上面畫。沒有選到它的話，筆畫沒有地方可以落。
  • 11:22 約 4 年前流行 2D 藝術家把 3D 雕塑和 2D 疊在一起畫，這對加強解剖練習也很有用
    ↳ 大約四年前，很流行 2D 畫家把 3D 雕塑的人體模型放在底下，直接在上面疊著畫。這對練解剖很有幫助，因為身體結構都看得到。
  • 11:22 可以把角色擺成任意姿勢、稍微偏移，再拿來練習
    ↳ 你可以把 3D 人體擺成任何姿勢，角度稍微轉一下，就能拿來練習那些很難找到參考照片的動作。
  • 11:53 講者建議把這個方法教給 2D 朋友
    ↳ 她建議把這套方法分享給畫 2D 的朋友，讓他們知道 Blender 也能當練畫的工具。
📘 術語
Grease Pencil（蠟筆工具）：Blender 的繪圖工具，講者說在視覺開發很有用，畫圖時一定要加入它
non-linear editor（非線性剪輯器）：本場示範的主題之一，本段字幕未進一步說明
visual development（視覺開發）：製作流程前段的工作，能便宜地修正錯誤、確認故事值得說
production pipeline（製作流程）：開頭犯錯便宜，後段犯錯非常昂貴
animatic（動態分鏡）：可以和 prototype 一起拿給投資人看，讓對方知道自己資助的是什麼
offset printing（平版印刷）：Spider-Verse 模仿的漫畫印刷，用 cyan、magenta、yellow 色版
depth of field / focal point（景深／焦點）：一般拍片時，焦點前後的景物會模糊
charcoal brush（炭筆筆刷）：新筆刷之一，內建兩種角度，能促使你看形體而不只是線條
sensitivity（筆壓感應）：在 brush settings 用曲線調整 strength 與 size，可以用按鈕開關
base human meshes（基礎人體網格）：Blender 檔案內附的人體模型，可拉進場景擺姿勢當參考
instance / make local（實例化／轉為本地）：拉進 base human mesh 後要記得做的步驟，講者略過細節
