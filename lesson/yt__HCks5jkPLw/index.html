🧑‍🏫 這支影片示範財務團隊在季末把報告交給管理層和董事會之前，怎麼用 ChatGPT 自動核對所有文件裡的數字，找出錯誤並修到可以發出。重點是讓 AI 在上千行、好幾百頁的資料裡抓出人眼容易漏掉的不一致，發出去的數字才讓人放心。

  • 00:04 在 ChatGPT 視窗切換到 work 分頁，準備開始做稽核（audit）
    ↳ work tab 是 ChatGPT 視窗裡的一個工作用分頁，講者切換到這裡開始做稽核（audit），也就是逐一檢查數字有沒有錯、前後有沒有對上。
  • 00:04 手上的資料包括季末資料、給管理層的 earnings report、董事會資料包（board of directors' package），以及財務模型（financial model）
    ↳ 要檢查的資料有四種：季末原始數字、給主管看的財報說明、要交給董事會的資料包，還有財務模型（financial model，推算營收、成本等預測的試算表）。
  • 00:04 使用 plugin 功能，把這些資料直接傳進 ChatGPT
    ↳ plugin 是把外部資料直接接進 ChatGPT 的功能。有了它，不用一份份手動上傳檔案，ChatGPT 可以直接讀到資料原本存放的地方。
  • 00:04 送出的請求是：「We just closed the quarter. Please review the latest financials stored in my Google Drive.」
    ↳ 講者只下了一句很日常的指令：「這季剛結束，幫我檢查 Google Drive 裡最新的財務資料。」不用寫複雜的提示詞，只要說清楚資料在哪、要做什麼。
  • 00:34 ChatGPT 把這些內容拉進來，並與核心財務系統 NetSuite 裡輸入的資料做核對（reconcile）
    ↳ NetSuite 是公司的核心財務系統，實際入帳的數字都在裡面。reconcile 是對帳，ChatGPT 把報告裡的數字和系統裡的數字逐一比對，看兩邊有沒有對上。
  • 00:34 資料量很大，有上千行、好幾個分頁；ChatGPT 找出兩個關鍵問題，因此判定為「not ready」
    ↳ 資料有上千行、好幾個分頁，人工很難全部對完。ChatGPT 找到兩個關鍵問題，直接判定「not ready」，意思是現在還不能發出去。
  • 00:34 第一個問題：NetSuite 更新了六月的 actuals（實際數）
    ↳ actuals 是實際數，也就是已經發生的真實數字，跟預估數相對。NetSuite 裡六月的實際數有更新過，所以報告裡用到這些數字的地方都要跟著修正。
  • 00:34 第二個問題：earnings note 裡用的是過時的預測數字，和財務模型裡的不一致
    ↳ forecast 是預測數字。earnings note（財報說明）裡用的是舊版預測，跟財務模型裡最新的預測對不上，同一份報告裡就會出現兩套說法。
  • 01:04 ChatGPT 會協助把這些錯誤一個一個修正
    ↳ ChatGPT 不只挑出錯誤，還會陪你一項一項把錯誤改掉，不是丟一張問題清單就結束。
  • 01:04 可以用內建的聊天瀏覽器打開文件，傳訊息或留言請團隊修正（例如「Please fix it」），也能在所有受錯誤影響的分頁之間切換
    ↳ ChatGPT 裡有內建的瀏覽器可以直接打開文件，在上面留言請同事修改，例如寫「Please fix it」，也能在所有受錯誤影響的分頁之間來回切換。
  • 01:04 很多文件篇幅很長，例如給管理層的 memo 就有 20 頁
    ↳ 這類文件通常很長，光是給管理層的備忘錄（memo）就有 20 頁，更不用說其他資料。
  • 01:35 文字量大時很容易漏看數字，ChatGPT 會用紅色標出需要更新的地方，讓人在修改前就知道要改哪裡
    ↳ 字多的時候，數字很容易看漏。ChatGPT 會把需要更新的地方用紅色標出來，還沒動手改之前，就先知道哪些地方要改。
  • 01:35 請團隊修改後，可以反覆重新執行檢查，幾分鐘內就能知道是否可以發出（ready to ship）
    ↳ 同事改完之後可以重新跑一次檢查，而且可以一直重跑，幾分鐘就知道是不是已經 ready to ship，也就是可以正式發出去了。
  • 01:35 講者認為這個流程最重要的是帶來信心，而且這些 plugin 可以用在更廣泛的情境
    ↳ 講者認為這套流程最大的價值是讓人有信心：發出去的數字已經確實對過。這些 plugin 也不只能用在財報，其他工作也用得上。
  • 02:05 例如 34 頁的董事會資料包，會併入一份上百頁的完整報告；同一個 skill 可以用來核對數字，也能找出不同文件之間互相矛盾的主題
    ↳ skill 是一套可以重複使用的檢查能力。像 34 頁的董事會資料包會併進上百頁的完整報告，同一套 skill 能核對數字，也能找出不同文件之間說法互相矛盾的地方。
  • 02:05 講者認為這是很好的入門 skill，能確保對外發布的數字值得信賴
    ↳ 講者建議把這個當成入門的第一個 skill 來學，因為它守住的是最基本的事：對外公布的數字一定要可靠。
📘 術語
work tab（work 分頁）：ChatGPT 視窗中的分頁，講者切換到這裡來開始稽核
plugin（外掛功能）：用來把資料直接傳進 ChatGPT 的功能
NetSuite（NetSuite）：講者公司的核心財務系統，ChatGPT 會拿它的資料來核對
reconcile（核對、對帳）：把拉進來的內容和 NetSuite 裡輸入的資料互相比對
actuals（實際數）：字幕提到 NetSuite 更新了六月的 actuals，是找到的第一個問題
forecast（預測數字）：earnings note 裡的預測已經過時，和財務模型裡的不一致
financial model（財務模型）：講者準備的資料之一，用來和 earnings note 的數字比對
board package（董事會資料包）：要交給董事會的資料，字幕中的例子有 34 頁，會併入上百頁的報告
skill（skill（技能））：可以重複使用的檢查能力，用來核對數字、找出文件間互相矛盾的主題
