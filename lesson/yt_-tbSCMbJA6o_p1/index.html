🧑‍🏫 這支是 Blender 經典「甜甜圈教學」2026 年新版的開頭，針對 Blender 5.0 重做。前半段從下載安裝、轉動視角，一路帶到擺出甜甜圈和咖啡杯的基本形狀，並學會移動、旋轉、縮放。完全沒碰過 3D 的人照著做就能上手，後面的內容都建立在這段操作上。

  • 00:00 Blender 可以做 3D modeling、texturing、lighting、shading 和 rendering，本教學會透過製作甜甜圈教你這些功能
    ↳ Blender 是免費的 3D 軟體。modeling 是捏形狀，texturing 是替表面上花紋，lighting 是打光，shading 是調材質質感，rendering 是把場景算成最後的圖片。這套教學用做一顆甜甜圈把這些全串起來。
  • 00:00 講者表示，從沒打開過 Blender 的完全新手也做得到；已有數百萬名初學者做出甜甜圈，這是本教學的第五個版本
    ↳ 門檻很低，沒開過 Blender 也能跟。已經有數百萬個新手靠它做出甜甜圈，教學也改版到第五版，內容被很多人驗證過。
  • 00:31 每次 Blender 大版本更新都會重做這套教學，這一版針對 Blender 5.0
    ↳ Blender 每次大改版，按鈕位置和功能都可能變，所以講者會跟著重錄。這版對應 Blender 5.0，版本相同就比較不會找不到按鈕。
  • 00:31 如果已經用舊版做過甜甜圈，講者另外推出給「做完甜甜圈之後的初學者」的課程，連結在影片下方
    ↳ 如果以前用舊版做過甜甜圈，可以不用重來，直接看講者另外做的進階初學課程。連結放在影片說明欄。
  • 00:31 下載方式：到 blender.org 按大大的下載按鈕
    ↳ 官方網站是 blender.org，首頁有一個很大的下載按鈕，按下去就能下載。從官網下載最安全。
  • 01:04 Windows 會下載執行檔，要安裝；Mac 是應用程式，拖進 Applications 資料夾即可
    ↳ Windows 下載的是安裝程式，要一步步安裝。Mac 下載的是整個 App，把它拖進「應用程式」資料夾就能用。
  • 01:04 學校或公司電腦不能安裝軟體時，可以下載 portable zip 版，解壓縮後直接從資料夾執行 Blender
    ↳ portable zip 是免安裝版的壓縮檔。電腦沒有安裝權限（例如學校或公司電腦）時，解壓縮後直接點資料夾裡的 Blender 就能開。
  • 01:04 打開 Blender 後，點 splash screen 以外的任何地方就能關掉它
    ↳ splash screen 是開 Blender 時跳出的歡迎視窗。不用找關閉鈕，點它外面任何地方就會消失。
  • 01:35 畫面中間的大片灰色區域是 3D viewport，大約 98% 的時間都在這裡工作，做角色或場景都在這裡進行
    ↳ viewport 是看 3D 場景的視窗。中間那片灰色大區域就是 3D viewport，也就是你的 3D 世界，捏形狀、擺場景幾乎都在這裡做。
  • 01:35 Orbit（環繞視角）：把滾輪按下去直到發出喀一聲，那就是滑鼠中鍵，按住中鍵拖曳即可環繞
    ↳ orbit 是繞著焦點轉動視角，像繞著桌上的東西走一圈看它。做法是把滾輪當按鈕按下去，聽到「喀」一聲就是中鍵，按住拖曳就能轉。
  • 02:08 沒有中鍵（例如用筆電觸控板）會比較吃力，有滑鼠會容易很多；替代做法是在右上角的小圓圈上點住拖曳
    ↳ 用筆電觸控板沒有中鍵會很卡，講者建議接一顆滑鼠。沒滑鼠的話，可以在畫面右上角的小圓圈上按住拖曳來轉視角。
  • 02:08 第三種替代做法：Edit > Preferences > Input 勾選 Emulate 3 Button Mouse，之後按住 Alt 加左鍵拖曳就能環繞
    ↳ 第三招是到 Edit > Preferences（偏好設定）> Input（輸入），勾 Emulate 3 Button Mouse，意思是模擬三鍵滑鼠。之後按住 Alt 加左鍵拖曳，就等於中鍵轉視角。
  • 02:42 4K 螢幕上介面字會很小，可在 Preferences 的 Interface 把 Resolution Scale 調到至少 1.5，講者平常用約 1.8，錄教學時會調更高
    ↳ 4K 螢幕上字會小到看不清。到 Preferences 的 Interface（介面），把 Resolution Scale（介面放大倍率）調到 1.5 以上，講者平常用 1.8 左右。
  • 03:12 Pan（平移視角）：Shift＋中鍵拖曳，或點側邊的小手圖示
    ↳ pan 是平移，畫面上下左右滑動，但角度不變，就像把相機往旁邊挪。按住 Shift 加中鍵拖曳，或點側邊的小手圖示。
  • 03:42 Zoom（縮放）：滾動滾輪，或點放大鏡圖示拖曳，或按 Ctrl＋中鍵拖曳
    ↳ zoom 是拉近拉遠。可以滾滾輪、在放大鏡圖示上拖曳，或按 Ctrl 加中鍵拖曳，三種擇一，挑你順手的。
  • 03:42 講者整理了一份免費的 Google Doc，列出最常用的快捷鍵，連結在影片下方，可以印出來貼在牆上
    ↳ hotkey（快捷鍵）是按一個鍵就直接執行功能。講者把常用快捷鍵整理成免費的 Google 文件，連結在說明欄，印出來貼在旁邊，邊做邊查。
  • 04:15 視角轉到迷失方向、甚至上下顛倒時，可點右上角彩色圓圈的 gizmo（代表各軸）來重新定位，點 Z 就是從上方看
    ↳ gizmo 是畫面上用來操作的小圖示。右上角彩色圓圈代表各個 axes（軸向），Z 是朝上的軸。轉到暈頭或畫面顛倒時，點 Z 就會變成從正上方往下看。
  • 04:48 講者很推薦有 numpad 的鍵盤，用 Blender 很方便；現在很多鍵盤已經不附 numpad
    ↳ numpad 是鍵盤右邊那塊數字區。講者說它在 Blender 裡很好用，但現在很多鍵盤已經拿掉這一塊了。
  • 04:48 沒有 numpad 的話，按住 tilde 鍵（Esc 下方那顆），拖到「View Selected」再放開，效果一樣
    ↳ 沒有數字區也有替代做法：按住 tilde 鍵（Esc 正下方那顆），拖到「View Selected」再放開。
  • 05:21 上面的操作可以快速把視角聚焦到選取的物件，會很常用到；之後講者都會用 Numpad period
    ↳ View Selected 是把鏡頭對準你選的東西，找不到物件時很好用。講者之後會改按數字區的小數點鍵，做同一件事。
  • 05:21 刪除預設的 cube：按 Delete 鍵，或按 X 再選 Delete；講者偏好 X，因為手指剛好就在旁邊
    ↳ 新檔案一開啟就有一個預設的 cube（方塊）。刪掉它可以按 Delete，或按 X 再選 Delete。講者習慣按 X，因為手本來就放在左邊。
  • 05:53 新增物件：點畫面上方的 Add 選單，或按快捷鍵 Shift+A，物件會出現在游標所在的位置，兩者的清單相同
    ↳ 要加新東西，點上方 Add 選單，或按 Shift+A，兩種跳出的清單一樣。新物件會出現在游標所在的位置。
  • 05:53 Add 清單內容非常多，有些東西講者用 Blender 21 年都沒用過，例如 Speaker
    ↳ Add 清單的項目多到嚇人，但不必全懂。講者用了 21 年，像 Speaker 這種都沒用過。
  • 05:53 大多時候要找的是 Mesh 底下的 primitive 物件，做東西時先挑形狀最接近成品的那一個
    ↳ mesh 是由點、線、面組成的網格物件。primitive 是 Mesh 底下現成的基本形狀。挑最接近成品的那個開始改，會省很多功夫。
  • 06:28 舉例：做郵筒可以從 cube 開始，做路燈柱可以從 cylinder 開始；做甜甜圈就從 torus 開始
    ↳ 舉例來說，郵筒從方塊開始，路燈柱從圓柱 cylinder 開始。torus 就是圓環形，本身長得就像甜甜圈，所以直接拿來用。
  • 06:28 預設的 torus 看起來太細，左下角有「Add Torus」面板，可以調整額外選項
    ↳ 預設的圓環太細，不像甜甜圈。剛加完物件時左下角會出現「Add Torus」小面板，可以在裡面調粗細等設定。
  • 07:02 如果不小心點掉、面板消失了，有時可按 F9 暫時叫回，但前提是還沒改動其他東西；講者通常直接重做一次
    ↳ 不小心點掉面板的話，還沒做其他操作前，有時可以按 F9 叫回來。講者嫌麻煩，通常直接刪掉重加一次。
  • 07:02 這個功能叫 last used function：在 Blender 做完一個動作後，左下角有時會出現可調整的額外選項
    ↳ 這種面板叫 last used function，意思是「剛剛那個動作」的補充選項。做完一個動作後，左下角有時會出現，讓你回頭微調。
  • 07:02 torus 預設尺寸是 1 公尺（約 3 英尺），太大了，應該是大約 10%，所以改成 0.1，約 10 公分
    ↳ Blender 的單位是公尺，預設圓環有 1 公尺那麼大。真實甜甜圈大約 10 公分，所以尺寸改成 0.1。尺寸照真實比例設，之後打光和材質比較好處理。
  • 07:34 放大視角、轉到可以看到內側，再調整 minor radius，直到看起來像甜甜圈
    ↳ minor radius 是圓環「麵體」本身的粗細。先把鏡頭拉近、轉到看得見中間的洞，再慢慢調，調到看起來像甜甜圈就好。
  • 08:04 也可以調整甜甜圈的解析度，太低看起來會像 PlayStation 1 的畫面
    ↳ 解析度指形狀由多少面組成。面太少會像 PlayStation 1 那種早期遊戲，稜角分明、看起來一格一格的。
  • 08:34 一個解析度維持 48，另一個提高到 18，多一點解析度有助於之後塑形甜甜圈
    ↳ 一個方向維持 48，另一個提高到 18。多一點面，之後把甜甜圈捏得不規則、更自然時，比較好塑形。
  • 08:34 設定好後在其他地方點一下，選項就消失，代表設定已經確定，這就是甜甜圈的起點
    ↳ 調好後點畫面其他地方，面板會消失，代表設定定案。這顆圓環就是甜甜圈的底。
  • 09:10 mesh 有 smooth shading 和 flat shading 兩種狀態，預設是 flat，所以看起來有稜角
    ↳ shading 在這裡指表面怎麼呈現明暗。預設是 flat shading，每個面各自一塊，所以看起來有稜有角。
  • 09:10 改成平滑：對物件按右鍵，選 Shade Smooth
    ↳ 要讓表面變圓滑，在物件上按右鍵，選 Shade Smooth 就行。
  • 10:00 Shade Smooth 會讓面與面之間看起來平滑，但不會增加額外的運算時間，只是肉眼看起來平滑
    ↳ Shade Smooth 只改變光線在表面上的呈現，讓面與面之間看不出接縫。它沒有真的增加面數，所以不會讓電腦變慢。
  • 10:00 舊版教學這時會開始做糖霜，但比較複雜，很多人在這裡卡關，所以這一版改成先做比較簡單又實用的咖啡杯
    ↳ 舊版教學這時會開始做糖霜，但糖霜比較難，很多人在這裡放棄。新版先做簡單又實用的咖啡杯，讓你先熟悉操作。
  • 10:36 用 Shift+A 從 Mesh 底下新增 cylinder 來做咖啡杯
    ↳ 咖啡杯一樣按 Shift+A，到 Mesh 底下選 cylinder（圓柱）開始做。
  • 10:36 cylinder 剛加入時很大，會把甜甜圈整個蓋住；在左下角 Add Cylinder 面板先調 radius，之後也能再改大小，但先調好方便一起看比例
    ↳ 圓柱剛加進來很大，會把甜甜圈整顆蓋住。先在左下角 Add Cylinder 面板把 radius（半徑）改小，才看得出兩個東西的大小比例。
  • 11:07 按住 Shift 拖曳，把 radius 設為 0.13
    ↳ 一樣按住 Shift 拖曳微調，把半徑設成 0.13，也就是大約 13 公分。
  • 11:07 depth 就是高度，之後也能再改，這時只要大致對就好
    ↳ depth 在這裡就是圓柱的高度，之後隨時能改，現在抓個大概就好。
  • 11:07 最重要的是 vertices，這裡反而要調得更低解析度，所以形狀會變得很鋸齒
    ↳ 最關鍵的是 vertices，也就是頂點數量，決定圓柱周圍有幾個角。這裡反而要調少，所以圓柱會變得很有稜角。
  • 11:07 原因：之後會加上 subsurf modifier，它會在現有 mesh 上加倍幾何並讓表面變平滑
    ↳ 原因是之後會加 subsurf modifier。modifier 是疊在物件上的效果，不直接改動原形。subsurf 會把現有的面切得更細、讓表面變圓滑。
  • 11:42 如果一開始解析度就太高，幾何量會一再加倍，很快就會變得運算太吃重；預計要做 subdiv 時，先從粗糙的低解析度開始，這裡設為 14
    ↳ subsurf 每加一層就把面數再加倍。起點面數太多，加倍幾次電腦就跑不動。所以打算用 subdiv 的物件，要從粗糙的形狀開始，這裡設 14。
  • 12:12 兩個物件重疊時，可以用左側的 Move tool 移動：啟用後會出現 gizmo，可以沿軸移動，拖白色小圓圈則能自由移動
    ↳ 兩個東西疊在一起時，可以用左側工具列的 Move tool 移動。它會出現箭頭 gizmo，拖箭頭就沿那個方向移動，拖中間白色圓圈則可以自由移動。
  • 12:12 大多數使用者不這樣移動，因為每次都要到側欄啟用工具，太費工，他們會記快捷鍵
    ↳ 不過熟手很少這樣做，因為每次都要跑去側邊點工具，太慢，他們會直接用快捷鍵。
  • 12:44 移動的快捷鍵是 G（G for grab）；一按 G 就立刻進入移動狀態，物件會跟著游標走，不用點擊
    ↳ 移動的快捷鍵是 G（grab，抓起來的意思）。按下 G 物件就黏在游標上跟著走，不用再點任何東西。
  • 13:16 按 G 時游標不需要靠近物件，在畫面另一邊也行；游標移出畫面一側會從另一側出現，可以無限循環
    ↳ 按 G 時游標在哪裡都行，不用對準物件。游標滑出畫面一邊，會從另一邊繞回來，可以一直移下去。
  • 13:16 旋轉是 R、縮放是 S，和 G 一樣，一按下去不論游標在哪裡都會立刻進入該狀態
    ↳ R 是旋轉（rotate），S 是縮放（scale），用法跟 G 一樣，按下去馬上生效，游標位置不影響。
  • 13:49 一開始可能不太習慣，但在 3D 裡移動、旋轉、縮放的次數很多，一鍵啟用可以省掉切換工具、移游標、點擊的步驟
    ↳ 一開始會覺得物件突然在動，有點嚇人。但 3D 工作裡移動、旋轉、縮放用得超頻繁，按一個鍵就搞定，能省掉切工具、移游標、點擊這一串動作。
📘 術語
splash screen（啟動畫面）：打開 Blender 時出現的畫面，點它以外的任何地方就會關閉
portable zip（免安裝壓縮檔版）：解壓縮後可直接從資料夾執行 Blender，適合不能安裝軟體的學校或公司電腦
3D viewport（3D 視窗）：中間大片灰色區域，也就是 3D 世界，約 98% 的時間都在這裡工作
orbit（環繞視角）：按住滑鼠中鍵拖曳，繞著目前的焦點轉動視角
middle-mouse（滑鼠中鍵）：把滾輪按下去直到喀一聲，就是中鍵
Emulate 3 Button Mouse（模擬三鍵滑鼠）：在 Preferences 的 Input 裡開啟後，可用 Alt＋左鍵拖曳來環繞視角
resolution scale（介面縮放比例）：在 Interface 設定裡調整；4K 螢幕字太小時，講者調到 1.5 至 1.8
pan（平移視角）：Shift＋中鍵拖曳，把視角移到別的地方
zoom（縮放視角）：滾動滾輪，或用放大鏡圖示、Ctrl＋中鍵拖曳
hotkey / keyboard shortcut（快捷鍵）：用按鍵直接執行功能，例如 Shift+A 新增物件、G 移動
gizmo（操作圖示）：右上角彩色圓圈加線條代表各軸，點一下可以重新定位視角；Move tool 也會出現 gizmo
axes / Z axis（座標軸／Z 軸）：gizmo 上的彩色圓圈就是各軸，Z 是朝上的軸
numpad（數字鍵盤）：鍵盤右側的數字區，講者說用 Blender 很方便，現在很多鍵盤已經沒有
tilde key（波浪鍵）：Esc 下方那顆鍵，按住後可拖到 View Selected
View Selected（檢視選取物件）：快速把視角焦點切到選取的物件上
Mesh / primitive（網格／基本形狀）：Add 選單中 Mesh 底下的基本物件，挑最接近成品形狀的那個開始做
torus（圓環體）：基本上就是甜甜圈的形狀，用來當甜甜圈的起點
minor radius（小半徑）：調整這個值，直到 torus 看起來像甜甜圈
last used function（上次操作面板）：做完動作後左下角出現的額外選項；消失後有時可按 F9 暫時叫回
flat shading（平面著色）：mesh 的預設狀態，看起來有稜角
smooth shading / Shade Smooth（平滑著色）：讓面與面之間看起來平滑，但不會增加運算時間；右鍵物件即可選
cylinder（圓柱體）：用來做咖啡杯的基本形狀
radius（半徑）：在 Add Cylinder 面板調整，講者設為 0.13
depth（深度）：就是 cylinder 的高度
vertices（頂點數）：講者調低到 14，讓形狀更低解析度，因為之後要加 subsurf modifier
subsurf modifier / subdiv（細分曲面修改器）：在現有 mesh 上加倍幾何並讓表面平滑；一開始解析度太高會太吃運算
Move tool（移動工具）：左側工具列的工具，可沿軸移動，或拖白色圓圈自由移動
grab (G)（抓取／移動）：移動的快捷鍵 G，一按就進入移動狀態，跟著游標走
rotate (R) / scale (S)（旋轉／縮放）：R 旋轉、S 縮放，一按就立刻進入該狀態
✏️ 小考一題

新增 torus 後不小心點掉了左下角的「Add Torus」面板，在還沒改動其他東西的情況下，可以按哪個鍵暫時叫回？

A. XB. F9C. GD. Shift+A
看答案
答案：B。[07:02] 講者說面板消失後，只要還沒改動其他東西，可以按 F9 暫時叫回。Shift+A 是新增物件，X 是刪除，G 是移動。
