🧑‍🏫 這是 OpenAI DevDay 2026 開場演講的最後一段。內容有四塊：Codex 可以把任務丟到雲端跑，現場用機器鴨示範 AI 能看、能畫、能對話，一系列幫開發者曝光和賺錢的新工具，最後是 Sam 對 AI 未來的看法。想知道 ChatGPT 接下來會多出哪些功能、外部 app 怎麼進到 ChatGPT 裡，看這段最清楚。

  • 40:13 Codex 可以把大型任務送到雲端執行，不必一直開著筆電。
    ↳ Codex 是 OpenAI 幫你寫程式的 AI 助手。「送到雲端」是讓任務在 OpenAI 的伺服器上跑，你的筆電可以闔上，不用開著等它做完。
  • 40:13 示範：建立新任務時選擇 cloud 與環境，送出「把整個 backend 用 Rust 重寫」的 prompt。任務要跑一段時間，之後再回來查看即可。
    ↳ 開任務時選 cloud（雲端）和執行環境，再下 prompt（給 AI 的指令）。示範是把 backend（使用者看不到的後台程式）改用 Rust 語言重寫，這種大工程丟出去後，晚點回來看就好。
  • 40:13 執行途中可以從手機送出其他想法，做到無縫交接（seamless hand-off）。
    ↳ seamless hand-off 是「無縫接手」：任務還在雲端跑，你在外面想到什麼，用手機補一句，它就接著做，不必回到電腦前。
  • 40:50 這是很多人一直要求的功能，今天正式推出。
    ↳ 雲端跑任務是使用者要求很久的功能，這次不是預告，發表當天就能用。
  • 40:50 OpenAI 目前有橫跨文字、語音、影像生成與視覺理解的模型。自家產品和 Codex 使用的工具，跟 API 開放給開發者的完全相同。
    ↳ OpenAI 的模型能處理文字、語音、生圖，也能看懂圖片。API 是開發者把這些模型接進自家產品的管道；重點是 OpenAI 自己用的工具和開發者拿到的一模一樣。
  • 40:50 Hugging Face 借出新款可程式化機器人 Microduck 的早期預覽版，這台叫做 Lavender。
    ↳ Hugging Face 是知名的 AI 開源社群平台。它借來還沒正式上市的機器人 Microduck，「可程式化」是指能寫程式控制它的動作。現場這台叫 Lavender。
  • 41:21 講者前一晚請 Codex 把整套系統接好，現場請它看著觀眾畫一張很酷的圖。
    ↳ 講者前一晚才請 Codex 把機器人的各個系統串起來，上台直接叫它看著觀眾畫一張圖，等於當場驗收。
  • 41:52 機器人整合了 Astra（視覺）、GPT Image 2.5（影像生成）和 GPT Live 1（即時語音互動），幾個小時內就用 Codex 做出來。
    ↳ 三個模型各有分工：Astra 負責看，GPT Image 2.5 負責畫，GPT Live 1 負責即時對話。重點是把它們接在一起只花了幾個小時，而且是 Codex 做的。
  • 42:26 現場請 Lavender 呱呱叫、問它興不興奮，並展示它為觀眾畫的照片。機器鴨也能走動，Astra 還能教它很多新技能。
    ↳ 現場讓機器鴨叫、跟它聊天、秀它畫觀眾的圖，還讓它走路。影片說 Astra 能再教它很多新技能，代表它的能力還能繼續往上加。
  • 42:26 一位做機器人的朋友表示，很期待把 OpenAI 的 API 用在硬體上。
    ↳ 做實體機器人的人也想用這些 API，表示 OpenAI 的模型不只用在螢幕裡的軟體，也開始被拿去控制真實的機器。
  • 43:02 新的 decisions API 能處理視覺輸入，可以幫助機器人依據看到的畫面，近乎即時地快速行動。
    ↳ decisions API 是新的開發介面，讓機器人看到畫面後幾乎馬上決定下一步。機器人要動得順就不能慢半拍，這就是它要解決的問題。
  • 43:02 OpenAI 認為這會開啟在真實世界與 AI 互動的全新方式。
    ↳ 過去跟 AI 互動多半是在螢幕上打字或講話。OpenAI 認為 AI 能看、能動之後，會出現在現實環境裡跟人互動的新用法。
  • 43:41 進入第三部分：幫助大家找到開發者做的東西，並協助開發者建立事業。
    ↳ 前面談的是工具，這段開始談曝光和收入：讓更多人找到開發者做的東西，開發者也能靠它經營事業。
  • 43:41 Sam 坦承過去的類似嘗試成效好壞參半。
    ↳ Sam 是 OpenAI 執行長 Sam Altman。他主動承認，以前類似的做法效果有好有壞，不是每次都成功。
  • 44:11 這次有信心的原因是：開發者拿到的工具，就是 OpenAI 自己打造 ChatGPT 所用的工具。
    ↳ 他說這次不一樣，因為開發者拿到的就是 OpenAI 做 ChatGPT 時自己用的工具，不是另外做給外人的簡化版。
  • 44:11 Sign in with ChatGPT：使用者可以用 ChatGPT 帳號登入你的 app，並使用自己 ChatGPT 方案裡包含的 tokens。
    ↳ Sign in with ChatGPT 就像「用 Google 帳號登入」。token 是 AI 用量的計算單位，使用者登入後，用的是自己 ChatGPT 方案裡已經包含的額度。
  • 44:44 好處是使用者更容易試用你的產品，開發者也不必替他們負擔 token 成本。首批有 16 個合作夥伴，之後會很快擴大。
    ↳ 使用者不用另外註冊付費就能先試用，開發者也不用幫每個人付 AI 用量費，兩邊的門檻都降低了。首批有 16 個合作夥伴，之後會擴大。
  • 44:44 推出 plug-in extensions：開發者可以做出像 ChatGPT 原生功能的完整應用程式，並透過 OpenAI 發佈。
    ↳ plug-in extensions 是「外掛擴充」。開發者做的不只是小工具，而是完整的應用程式，放進 ChatGPT 後用起來像內建功能，並透過 OpenAI 上架。
  • 45:18 用 plug-in extensions 可以把編輯器、儀表板或整個工作空間直接做進 ChatGPT 和 Codex。
    ↳ 也就是說，不用離開 ChatGPT 或 Codex，就能在裡面直接開編輯器、看數據儀表板，甚至用整個工作區。
  • 45:18 範例一：新的 Meetings app 能在 ChatGPT 裡看到行事曆上的會議，點選「take notes」後會開出新空間，讓隊友與文件一起處理後續待辦事項。
    ↳ Meetings app 範例：ChatGPT 讀到你行事曆上的會議，按「take notes」（做筆記）就會開一個共用空間，隊友和相關文件都在裡面，大家一起把會後待辦處理完。
  • 45:18 範例二：Figma 把更多既有產品功能帶進 ChatGPT。
    ↳ Figma 是很多人在用的線上設計工具。這次它不只放個簡單連結，而是把更多原本產品裡的功能搬進 ChatGPT。
  • 45:52 在 Figma 範例中，可以開啟設計稿、看團隊留言、請 ChatGPT 修改，一邊對話一邊改設計。
    ↳ 實際用起來是這樣：在 ChatGPT 裡打開設計稿、看同事留言，再用講的請它修改，邊聊邊改，不用在兩個軟體之間切來切去。
  • 45:52 範例三：Adobe 讓使用者在 ChatGPT 裡直接使用喜歡的 Photoshop 功能。Adobe 和 Figma 都在數十個首批合作夥伴之列。
    ↳ Photoshop 是 Adobe 的修圖軟體，你常用的修圖功能可以直接在 ChatGPT 裡使用。Adobe 和 Figma 都在首批數十個合作夥伴裡。
  • 45:52 這些 plug-ins 現在也能用在 ChatGPT sites。
    ↳ ChatGPT sites 是在 ChatGPT 裡建立網站的功能。剛剛介紹的那些外掛，現在也能裝到這些網站上用。
  • 46:25 ChatGPT sites 推出幾個月內，已經有數百萬個各類型網站被建立。
    ↳ 這個功能推出才幾個月，就已經有數百萬個網站被做出來，用途五花八門，看得出需求很大。
  • 46:25 現在網站可以支援連接 plug-ins 和資料。分享給團隊後，成員可以用自己的帳號登入並帶入自己的 agent，體驗會依使用者而不同。
    ↳ 網站現在可以接外掛和資料。agent 是能替你代辦事情的 AI 助手。成員用自己的帳號登入、帶自己的 agent，所以同一個網站，每個人用起來都不一樣。
  • 46:57 除了一般搜尋 plug-in library，plug-ins 也能在對話過程中被發現：ChatGPT 判斷你的 plug-in 能幫上忙時，使用者可以當場連接。
    ↳ plug-in library 是搜尋外掛的地方。除了自己去找，聊天時 ChatGPT 覺得某個外掛幫得上忙也會提出來，使用者當場就能接上，開發者因此多了一個被看見的機會。
  • 46:57 OpenAI 聽取回饋，會簡化 plug-in 的送審流程。
    ↳ 開發者反映外掛上架的審核很麻煩，OpenAI 表示會簡化這個流程。
  • 47:34 新流程可以追蹤審查進度、查看需要修正的地方、申請人工審查，更新 plug-in 工具時也不必整個重新送審。
    ↳ 新流程看得到審到哪一步、哪裡要修改，也可以要求真人審查。外掛的工具有更新時，不用整個重新送審。
  • 47:34 推出 OpenAI marketplace，首批有 30 個以上合作夥伴，包括 Code Rabbit、Notion、Vercel 等。
    ↳ OpenAI marketplace 是讓開發者把產品賣給企業的市集。首批有 30 多家合作夥伴，包括 Code Rabbit、Notion、Vercel 等。
  • 47:34 企業客戶可以用既有 OpenAI commitment 的一部分購買你的產品；開發者自己的 OpenAI commitment 也能在 marketplace 使用。
    ↳ OpenAI commitment 是企業事先承諾向 OpenAI 採購的額度。企業可以拿其中一部分買你的產品，開發者自己的額度也能在市集裡用，企業採購會更容易。
  • 48:08 透過與 Base10 的合作，從今天起可以在 marketplace 取用開源模型。
    ↳ open source models（開源模型）是公開釋出、大家都能拿去用的模型。透過和 Base10 合作，從今天起在市集裡就能取用。
  • 48:08 今日發表總整理（一）：用 docs 和 spaces 與 AI 協作的新方式。
    ↳ 總整理第一項：docs（文件）和 spaces（空間）是跟 AI 一起協作的新方式。這一段沒有細講它們怎麼用。
  • 48:40 今日發表總整理（二）：新模型 GPT-6.1 Soul 與 Ultrafast（依字幕原文）、decisions API、agents API、Codex in the cloud，以及協助開發者建立事業、導入消費者的多種方式。
    ↳ 新模型名稱是照字幕寫的，可能和官方寫法不同。agents API 在這段只列了名字，沒說明用途。其他幾項是本段前面講過的雲端任務、機器人應用和商業化工具。
  • 49:12 開發者正在用這項技術研究免疫系統、讓教育更普及、打造幫助他人創作的工具。接著播放現場開發者的影片。
    ↳ 這裡把焦點拉回實際用途：有人拿這些技術研究免疫系統、讓更多人受教育、做幫別人創作的工具。接著播放現場開發者的影片。
  • 50:13 Peter 會在主舞台主持特別場次，談如何持續投入開源社群，其他場次會深入介紹今天發表的內容。
    ↳ Peter 會在主舞台主持一場，主題是怎麼持續投入開源社群。其他場次則會深入介紹當天發表的內容。
  • 50:13 當天最後，Thibaut、Tejal 和 Sam 會回到台上進行現場 Q&A。
    ↳ 活動最後，Thibaut、Tejal 和 Sam 會回到台上，現場回答大家的問題（Q&A）。
  • 50:13 現場舉辦 Codex Game Studio 場次，可以用 Codex 做自己的復古遊戲。
    ↳ Codex Game Studio 是現場的動手活動，來賓可以用 Codex 做一款自己的復古風小遊戲。
  • 50:13 每位現場來賓可以帶回一台 DevDay 限定的 Chromatic 復古掌上遊戲機，在 merch shop 領取。
    ↳ 每位現場來賓可以到周邊商品區（merch shop）領一台 DevDay 限定的 Chromatic 復古掌上遊戲機。
  • 50:46 因為今天發表很多新東西，現場由 Thibaut 按下 reset。Sam 提到他們做過很多次 reset，Thibaut 甚至提議把公司改名為 reset company。
    ↳ 字幕沒有說明 reset 具體重置的是什麼。Sam 自嘲他們已經 reset 過很多次，Thibaut 還開玩笑說乾脆把公司改名叫 reset company。
  • 51:48 這次 reset 適用於全世界的人，不只是 DevDay 現場觀眾。
    ↳ 這次的 reset 不只給現場觀眾，全世界的使用者都適用。
  • 51:48 Sam 表示，大家常把 AI 形容成新的工業革命，他對這個說法很反感。
    ↳ 很多人說 AI 是「新的工業革命」，Sam 對這個說法很反感。
  • 52:20 最好的 AI 不是把人變成巨大機器裡的齒輪。生活中有些部分不能、也不該被自動化。
    ↳ 他的意思是，AI 不該把人當成大機器裡的一顆零件。生活中有些部分本來就不能、也不應該交給自動化。
  • 52:20 Sam 認為，若做對了，未來會更像新的文藝復興：AI 應該讓人更能掌握自己的人生，擁有更多創作、學習、探索與擴展知識的工具。
    ↳ 他希望 AI 帶來的是新的「文藝復興」：人有更多工具去創作、學習、探索，更能掌握自己的人生，而不是被推著走。
📘 術語
Codex in the cloud（雲端 Codex）：把任務送到雲端執行，不必開著筆電，之後再回來看，也能從手機接續。
seamless hand-off（無縫交接）：任務在雲端跑的同時，可以從手機送出其他想法接續工作。
Microduck（Microduck 機器鴨）：Hugging Face 的新款可程式化機器人，現場借來的早期預覽版。
decisions API（decisions API）：能處理視覺輸入，幫助機器人依據看到的畫面近乎即時地快速行動。
Sign in with ChatGPT（用 ChatGPT 登入）：使用者用 ChatGPT 登入你的 app，並使用自己方案內含的 tokens。
token（token）：ChatGPT 方案內含的用量；使用者用自己的 tokens，開發者就不必負擔成本。
plug-in extensions（外掛擴充）：開發者打造、在 ChatGPT 裡像原生功能一樣的完整應用程式，透過 OpenAI 發佈。
ChatGPT sites（ChatGPT 網站）：可建立網站，現在支援連接 plug-ins 和資料，團隊成員可用自己的帳號登入。
agent（agent）：網站使用者登入後可以帶入自己的 agent。
plug-in library（外掛庫）：可搜尋 plug-ins 的地方；plug-ins 現在也能在對話中被發現。
OpenAI marketplace（OpenAI 市集）：販售開發者產品給企業的市集，首批有 30 個以上合作夥伴。
OpenAI commitment（OpenAI 承諾額度）：企業客戶可以用既有 commitment 的一部分在 marketplace 購買產品。
open source models（開源模型）：透過與 Base10 合作，可在 marketplace 取用。
agents API（agents API）：字幕只在發表總整理中列出名稱，未另外解釋。
