🧑‍🏫 這段教你先做出糖粒，再用 Blender 5.0 新增的 Scatter on Surface 把糖粒撒滿甜甜圈的糖霜。重點是先做出好幾種不同的糖粒，並用 Collection 整理好，撒出來才自然、不假。以前要用麻煩的舊工具或自己接一堆節點，現在內建一個功能就搞定。

  • 00:00 本集用 Blender 5.0 新增的 Scatter on Surface modifier 替甜甜圈加上糖粒；但要先建模糖粒，因為不能散佈「不存在的東西」
    ↳ Scatter on Surface 是 Blender 5.0 新增的 modifier，modifier 是掛在物件上自動加效果的功能，這個能把東西撒在表面上。但要撒糖粒，得先有糖粒模型。
  • 00:00 想把糖粒加在甜甜圈上方或附近，方便對照確認糖粒相對於甜甜圈的大小是否正確
    ↳ 糖粒放在甜甜圈旁邊做，可以隨時比對大小，才不會做出跟甜甜圈比例不對的糖粒。
  • 00:30 新增物件的位置由 3D cursor 決定；按住 Shift＋右鍵拖曳，可把 3D cursor 放到滑鼠下方的表面上
    ↳ 3D cursor 是畫面裡那個紅白小圈，新增的物件會出現在它的位置。按住 Shift＋右鍵拖曳，它會直接貼到滑鼠指著的表面上。
  • 00:30 作者把 3D cursor 再往上移一點，放在甜甜圈正上方
    ↳ 把游標再往上拉一點，放到甜甜圈正上方，新做的糖粒就會出現在甜甜圈上面，方便對照。
  • 00:30 Add → Mesh → Cylinder 新增圓柱當糖粒；想做圓形糖粒也可以用 sphere
    ↳ 從 Add → Mesh → Cylinder 加一個圓柱當糖粒。Mesh 就是由點、線、面組成的模型。想做圓球狀的糖粒，改用 sphere（球體）也可以。
  • 01:04 作者偏好長條糖粒，所以用 cylinder；在 last used settings 面板把 radius 調到最小
    ↳ 作者喜歡細長條的糖粒，所以選圓柱。新增後會跳出 last used settings 面板，可以改剛新增物件的參數，先把 radius（半徑）調到最小。
  • 01:04 直接點擊拖曳數值變化太猛；按住 Shift 拖曳會用較小的增量調整
    ↳ 直接拖曳數值，一動就跳很多，很難調準。按著 Shift 再拖，每次變動會變小，適合微調。
  • 01:35 加大 depth 讓糖粒變長；這只是之後編輯前的起始形狀
    ↳ depth 是圓柱的長度，調大糖粒就變長。現在只是大概的形狀，後面還會再修改。
  • 02:08 要用 subsurf modifier 做圓角；32 個頂點時每多一級細分會翻倍（64、128），太多了
    ↳ subsurf（Subdivision Surface）會把模型細分，讓邊角變圓。圓柱預設一圈 32 個點，細分一級變 64、兩級變 128，對一顆小糖粒來說太多。
  • 02:08 因此把 vertices 降到 6，變成超低面數（low poly）
    ↳ 所以把一圈的點數（vertices）降到 6，變成 low poly，也就是面數很少、形狀很簡單的模型，圓滑的部分交給細分處理。
  • 02:40 Add Modifier → Generate → Subdivision Surface 加上細分
    ↳ 從 Add Modifier → Generate → Subdivision Surface 加上細分，糖粒就開始變圓。
  • 02:40 出現菱形是因為細分取每個面的中點做平均；想讓兩端圓角更緊，就要在靠近兩端處各加一圈點
    ↳ 細分是拿每個面的中點去平均，面太大就容易變成菱形。在靠近兩端的地方各加一圈點，兩端的圓角會收得比較緊，比較像真的糖粒。
  • 03:13 Tab 進 edit mode，Ctrl+R 加 loop cut，點擊後滑到接近頂端；底部也照做一次
    ↳ 按 Tab 進入 edit mode（可以直接改點、線、面的模式），按 Ctrl+R 加 loop cut，也就是繞模型一圈的切線。點下去後往頂端滑，底部也照做一次。
  • 03:13 對照甜甜圈檢查糖粒大小；右鍵選 Shade Smooth 看看平滑後的效果
    ↳ 再跟甜甜圈比一次大小。接著按右鍵選 Shade Smooth，讓表面看起來平滑，不會一格一格的。
  • 03:50 此時就能散佈，但同一顆糖粒到處重複，在眼睛看來很假
    ↳ 做到這裡其實已經可以撒了，但每顆糖粒都一模一樣，人眼一看就覺得假。
  • 03:50 真實糖粒是用擠花袋擠出、乾掉後再折斷，所以大小形狀各異；因此要做多種形狀與大小的糖粒
    ↳ 真的糖粒是用擠花袋擠出、乾掉後再折斷，所以每顆長短、形狀都不同。要多做幾種形狀和大小，撒出來才自然。
  • 03:50 按 F2 把物件改名為 Sprinkle
    ↳ 按 F2 可以替選取的物件改名，這裡改成 Sprinkle（糖粒），之後比較好找。
  • 04:26 Collection 基本上就是「桶子」，物件可以移進移出；把 Sprinkle 拖出預設 collection，放到 Scene Collection
    ↳ Collection 像收納桶，用來把物件分組，物件可以隨時移進移出。Scene Collection 是最外層的總桶，先把 Sprinkle 拖到這裡。
  • 05:00 對原本的 collection 按 exclude：它不會出現在 viewport 與 render，等於暫時從場景消失，但可輕鬆恢復，方便單獨編輯
    ↳ 對原本的 collection 按 exclude，裡面的東西會暫時從畫面（viewport）和算圖（render）消失，只剩糖粒方便專心修改，之後可以輕鬆叫回來。
  • 05:00 按 1 切到 front view，再按 Numpad period 聚焦到糖粒
    ↳ 按 1 切到正面視角，再按數字鍵盤的小數點，畫面會拉近、對準選取的糖粒。
  • 05:31 作業：複製糖粒並做出不同彎曲、扭轉與形狀的變體；作者不示範，跟著系列走的人應該做得到
    ↳ 作業是把糖粒複製幾份，各自彎一彎、扭一扭、改變形狀。作者不示範，因為跟著前面幾集學過來，這些操作應該都會了。
  • 05:31 業配段：Blender 下載時沒要信用卡，讓全世界都能免費接觸 3D；缺點是 Blender 開發經費不足
    ↳ 這段是替 Blender 募款：它下載不用信用卡，全世界的人都能免費學 3D；代價是 Blender 的開發經費一直不夠。
  • 06:02 想改進但缺經費的領域：texture painting、整個物理引擎、sculpting 工具、compositor
    ↳ 作者舉出幾個想改進但缺錢的地方：直接在模型上畫貼圖的 texture painting、整個物理引擎、雕刻工具，以及做後製合成的 compositor。
  • 06:02 Blender 總部在荷蘭 Amsterdam，聘有全職開發者，也有來自世界各地的全職 contractor
    ↳ Blender 總部在荷蘭阿姆斯特丹，有全職開發者，也有來自世界各地的全職約聘人員（contractor）。
  • 06:35 經費來自 Dev Fund；作者呼籲加入每月捐款 5、10，或 25 以上
    ↳ 這些人的經費來自 Dev Fund（開發基金），作者呼籲大家加入每月捐款，金額可選 5、10，或 25 以上。
  • 07:05 作者提到 Autodesk 去年靠 3ds Max 和 Maya 賺了 $315 million，Blender 沒有這種資金；捐款連結在影片下方
    ↳ 作者拿 Autodesk 對比：它去年靠 3ds Max 和 Maya 兩套軟體賺了 3.15 億美元，Blender 沒有這種資金，所以很需要捐款。連結在影片下方。
  • 07:05 回到教學：把原場景恢復顯示，準備把糖粒移到新的 collection
    ↳ 回到教學，先把剛才 exclude 的原場景恢復顯示，接著要把所有糖粒整理進一個新的 collection。
  • 07:37 可用頂部的小按鈕新增 collection 再改名；也可以一邊移動一邊建立 collection
    ↳ 建立 collection 有兩種方式：用上方的小按鈕先新增再改名，或是在移動物件時順便建立。
  • 07:37 在 viewport 或 Outliner 選取所有糖粒後按 M，可移到既有 collection，或建立新 collection
    ↳ Outliner 是列出場景所有物件的清單。在畫面或 Outliner 選好全部糖粒後按 M，就能移到現有的 collection，或建立一個新的。
  • 08:07 新 collection 命名為 Sprinkles，並取消勾選隱藏；散佈系統引用它時不需要看得到，否則會礙事
    ↳ 新的 collection 取名 Sprinkles，並取消勾選讓它隱藏。散佈功能引用它時不需要看得到，原始糖粒留在畫面上反而會擋路。
  • 08:07 選取 icing，加入全新的 Scatter on Surface modifier
    ↳ 選取糖霜（icing），在它身上加入 Scatter on Surface，因為糖粒要撒在糖霜上。
  • 08:39 此 modifier 從 Blender 5.0 才有；找不到代表你用的不是 5.0 或更新版本
    ↳ 這個功能從 5.0 才有，找不到就代表你的版本比 5.0 舊，要先更新。
  • 08:39 作者很喜歡這個 modifier，設定很多但做得很好；首先要在 instancing 指定要散佈的物件
    ↳ 作者很推這個 modifier，設定很多但設計得好。第一步是在 instancing 指定要撒什麼，也就是拿現成的物件大量複製擺放。
  • 09:10 不是 instance 單一物件，而是整個 collection：選 Collection，再點 Sprinkles
    ↳ 要撒的不是單一顆糖粒，而是整個 collection：選 Collection，再點 Sprinkles。
  • 09:10 一開始只出現一個是因為 density 很低；調高 density 就會變多，但結果仍然不對
    ↳ density 是密度。一開始數值很低，所以只看到一顆；調高後糖粒會變多，但擺放方式還是不對。
  • 09:10 要在 Instancing 下勾選 Pick Instance
    ↳ 接著要在 Instancing 底下勾選 Pick Instance。
  • 09:41 勾 Pick Instance 後，不會把整組當成一個物件散佈，而是引用 collection 裡的個別糖粒
    ↳ 勾了之後，它會從 collection 裡一顆一顆挑來撒，不會把整組糖粒當成一個東西撒。
  • 09:41 再用 reset transform：原本依距離中心多遠來擺放，reset 後改以糖粒本身的點為準
    ↳ 再按 reset transform。原本擺放時會帶著每顆糖粒離中心點的距離一起算，重設後改用每顆糖粒自己的點當基準。
  • 10:14 density 調越高，糖粒越多
    ↳ density 調越高，糖粒撒得越滿，看你想要多密。
  • 10:14 在 Transform 下改 alignment axes，一直切換直到正確，這裡看起來是 Y
    ↳ Transform 底下的 alignment axes 決定糖粒朝哪個方向擺，一個一個軸切換，直到看起來正確為止，這裡是 Y 軸。
  • 10:47 勾選 Randomize 可為旋轉加上隨機變化；把 Y 軸旋轉調到 360，糖粒就撒在甜甜圈上了
    ↳ 勾選 Randomize，讓每顆糖粒旋轉的角度都不同。把 Y 軸旋轉設為 360，糖粒就會朝各個方向散開，撒在甜甜圈上了。
  • 10:47 頂部的 Surface Offset：糖粒陷進糖霜太深，濕糖霜雖會讓糖粒稍微下沉，但不會這麼多
    ↳ 上方的 Surface Offset 控制糖粒離表面多高。現在糖粒陷太深；濕糖霜雖然會讓糖粒稍微下沉，但不會沉這麼多。
  • 11:18 按住 Shift 拖曳，把 Surface Offset 稍微調高，讓糖粒剛好停在糖霜表面
    ↳ 按住 Shift 慢慢把 Surface Offset 往上調，調到糖粒剛好停在糖霜表面。
  • 11:18 散佈簡史：最舊的方法是 particle system，老舊、屬於 legacy、程式寫得差，能用但很煩
    ↳ 最早的散佈方法是 particle system（粒子系統），但它是老舊的 legacy 功能，程式寫得差，能用但很煩。
  • 11:50 之後有 Geometry Nodes，以數學為基礎，但要做這種效果需要很多設定工作
    ↳ 後來出現 Geometry Nodes，用節點串接數學運算來產生效果，但要做出這種散佈，得自己做很多設定。
  • 11:50 現在的 Scatter on Surface 本身仍是 Geometry Nodes；頂部有 Geometry Nodes 分頁，點開就能看到節點
    ↳ 新的 Scatter on Surface 其實也是 Geometry Nodes 做的，點上方的 Geometry Nodes 分頁就看得到裡面的節點。
  • 11:50 好處是它現在直接內建在 Blender 裡
    ↳ 差別在於它現在直接內建在 Blender 裡，不用自己從頭接節點，加上去就能用。
📘 術語
Scatter on Surface modifier（表面散佈修改器）：Blender 5.0 新增，可把物件撒在表面上；本身仍是 Geometry Nodes，現已內建
3D cursor（3D 游標）：決定新增物件的位置；Shift＋右鍵拖曳可放到滑鼠下方的表面
last used settings（上次操作設定面板）：新增物件後可在這裡調 radius、depth、vertices 等
vertices（頂點數）：圓柱預設 32，細分每級翻倍，所以降到 6
low poly（低面數）：作者把頂點降到 6 時稱它為超低面數
Subdivision Surface (subsurf)（細分曲面）：做圓角用，取每個面的中點做平均，每多一級頂點會翻倍
loop cut（環切）：Ctrl+R 新增一圈點，滑到兩端附近讓圓角更緊
Shade Smooth（平滑著色）：右鍵選擇，用來看平滑後的效果
Collection（集合）：像桶子一樣組織物件，可在 Blender 其他地方引用
Scene Collection（場景集合）：最上層的 collection，作者把 Sprinkle 拖到這裡
exclude（排除）：讓 collection 不出現在 viewport 和 render，可輕鬆恢復
Outliner（大綱視窗）：可在這裡選取物件，再按 M 移到 collection
instancing（實例化）：指定要散佈哪個物件或 collection
density（密度）：數值越高，散佈的糖粒越多
Pick Instance（挑選實例）：勾選後引用 collection 裡的個別物件，而非整組當一個
reset transform（重設變換）：改以糖粒自身的點為準，而非依距離中心多遠
alignment axes（對齊軸）：在 Transform 下切換，直到方向正確，這裡是 Y
Randomize（隨機化）：勾選後可為旋轉加入隨機變化
Surface Offset（表面偏移）：調整糖粒陷入或浮在表面的程度
particle system（粒子系統）：最舊的散佈方法，legacy、程式寫得差、用起來煩
Geometry Nodes（幾何節點）：以數學為基礎的節點系統，舊做法設定很費工
Dev Fund（開發基金）：Blender 聘請開發者與 contractor 的經費來源
✏️ 小考一題

A. 讓它引用 collection 裡的個別糖粒，而不是把整組當成一個物件散佈B. 讓糖粒浮到糖霜表面，不再陷進去C. 讓糖粒自動沿 Y 軸對齊D. 讓糖粒數量自動變多
