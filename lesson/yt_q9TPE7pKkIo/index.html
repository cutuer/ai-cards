    ↳ real-time analytics（即時數據分析）是指看當下最新的數字，不用等月底報表。營收主管靠它及早發現哪裡要處理，馬上動手。

📘 術語
real-time analytics（即時分析）：營收主管用 ChatGPT 取得的即時數據分析，用來聚焦重點並快速行動。
segment（區隔／事業部門）：組織內的不同區塊，摘要會列出每個 segment 的整體狀態。
guide site（互動式導覽網站）：ChatGPT 把輸入與 context 轉成的互動網站，可在 app 內開啟，並依緊急程度列出優先事項。
context（脈絡資訊）：ChatGPT 用來產生 guide site 的背景資訊，與輸入內容一起轉換。
key account（重點客戶）：符合條件、適合採用建議銷售策略的客戶，開啟後會附上 action plan。
action plan（行動計畫）：執行銷售策略的逐步計畫，內含關鍵步驟與期限。
computer function（電腦操作功能）：ChatGPT 用來實際操作的功能，例如建立 channel、加入成員、草擬訊息。
account owner（客戶負責人）：被 ChatGPT 加進新 channel 的相關客戶負責人。
sales manager（業務經理）：與 account owner 一起被加進新 channel 的人員。
