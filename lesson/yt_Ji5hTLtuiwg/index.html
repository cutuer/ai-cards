📘 術語
Higsfield plugin（Higsfield 外掛）：字幕說是免費、可下載安裝的外掛，用來連接 Claude 與 Blender
bridge URL（橋接網址）：從 Higsfield plugin 複製，貼到 Claude connectors 裡新增連線
connectors（連接器）：Claude 設定裡的項目，按 add 貼上 URL 就能新增，連上後會出現綠色勾勾
MCP（MCP）：字幕只出現在 connector 名稱範例「Higsfield Bridge MCP」，沒有另外解釋
blocking pass（初步場景配置）：作者給 Claude 的 prompt 要求做 blocking pass，也就是三個鏡頭的粗略場景
credits（點數）：Higsfield 的計費單位；用 Claude 建場景不扣，15 秒鏡頭花了 135 credits
Active Camera（作用中攝影機）：透過 View → Cameras → Active Camera 查看攝影機拍到的畫面
keyframe（關鍵影格）：在 y 軸設定攝影機位置的關鍵點，用來做運鏡
eased（緩入緩出）：keyframe 預設的狀態，作者說這不是他要的效果
Interpolation Mode / Linear（插值模式／線性）：右鍵把 keyframe 設成 Linear 就不會 ease，運鏡像滑軌般自然
Omniscent（Omniscent）：iPhone app（也有 Android 版），用手機錄製真實運鏡並同步到 Blender
AR（擴增實境）：在 Omniscent 按 AR 後移動手機，Blender 攝影機會跟著移動
Cinema Studio（Cinema Studio）：作者設定影片長度、比例、參考素材並生成影片的地方
Seedance 2.5（Seedance 2.5）：作者選用的生成模型，依參考影片的運鏡做出寫實畫面
found footage（現成素材畫面）：字幕在估算紀錄片成本時提到，指除了 3D 動畫之外的素材
