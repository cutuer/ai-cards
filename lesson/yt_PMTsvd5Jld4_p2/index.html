🧑‍🏫 這是 Grok 團隊連續三天、從零開一家公司的直播第一天。這段在講他們怎麼看待「做生意」、準備用哪些工具，也介紹了他們的開源工具包 Pstack。如果你好奇 AI bot 能不能真的扛起一家小公司的工作，這段可以讓你看到實際的起步流程。

  • 11:56 開發時會用一般創業會用的工具：用 cursor 寫程式，再用 Grockbot 處理困難的手動工作
    ↳ Cursor 是內建 AI 的程式編輯器。他們用 Cursor 寫程式，需要一步步手動處理的麻煩事，就交給自家的 Grockbot（可以派 bot 幫你做事的服務）。
  • 12:26 前一天向觀眾和 SpaceX 員工徵求點子，收到上千則回覆；第一步是請 bot 讀這些回覆，做市場調查
    ↳ 前一天他們問觀眾和 SpaceX 員工「該做什麼」，收到上千則回覆，人工根本讀不完。第一步就請 bot 全部讀完、歸納整理，也就是做 market research（市場調查：找出大家要什麼）。
  • 12:56 目標是在第一天就決定要做的點子
    ↳ 他們給自己很短的期限：第一天就要決定做哪個點子。不在選題上拖，後面才有時間真的做出來。
  • 13:26 對 business 的看法：做有用、別人想要的東西，最好是自己也會用的東西，這樣比較能同理使用者
    ↳ 他們認為 business（生意）的起點，是做出別人真的想要的東西。最好自己也會用，因為自己就是使用者，最清楚哪裡不好用。
  • 13:26 dogfooding：團隊用 Grockbot 來開發 Grockbot 本身，成為自己產品的重度使用者，並持續改進它
    ↳ dogfooding 字面上是「吃自己的狗食」，意思是自己天天用自家產品。團隊用 Grockbot 開發 Grockbot，自己先碰到問題、先修好，產品就越用越順。
  • 13:56 business 也要賺錢，要看到錢真的進到銀行帳戶
    ↳ 東西有用還不夠，生意要能賺錢。他們的標準很實際：要看到錢真的進到銀行帳戶才算數。
  • 14:26 做 business 最終是在服務人；就算由 agent 執行任務，下指令的還是人
    ↳ 就算以後很多事交給 AI agent（能自己接任務、一步步完成的 AI），下指令、想要這個結果的還是人。所以做生意最終服務的是人。
  • 15:28 重點在做出讓人覺得神奇或能為生活帶來價值的東西，讓人開心到願意付錢、還想再買
    ↳ 要做的是讓人一用就覺得「哇」，或真的讓生活變好的東西。好到讓人願意掏錢，用完還想再買。
  • 15:28 在 Grockbot 可以給 bot 一張信用卡（Stripe 的 Link card）；構想中的產品，人和 bot 都能進來買東西
    ↳ Stripe 是知名的線上金流公司。在 Grockbot 裡可以給 bot 一張 Stripe 的 Link card（信用卡），讓 bot 自己付款。他們構想的產品是人和 bot 都能進來買東西。
  • 15:58 建議觀眾建立 Grockbot 帳號，讓自己的 bot 來買東西；產品預計在這三天內做出來
    ↳ 他們建議觀眾先開 Grockbot 帳號、準備好自己的 bot，等產品上線就讓 bot 去買。產品預計在這三天內做出來。
  • 16:30 討論要做數位產品、配送實體商品（例如咖啡豆），還是線下活動；舊金山正在舉辦 Dreamforce，多了 50,000 人
    ↳ 他們還在考慮要做數位產品、寄送實體商品（例如咖啡豆），還是辦線下活動。剛好舊金山正在辦 Dreamforce（Salesforce 的大型年會），城裡多了五萬人。
  • 16:30 主持人的目標：用數位的東西在現實世界做出觀眾也能互動的成果，但還不確定做不做得到
    ↳ 主持人想挑戰的是：用線上做出來的東西，在真實世界做出觀眾也能參與的成果。他也坦白說，還不確定做不做得到。
  • 17:31 需要準備的工具：給團隊和 bot 聊天的 Slack channel、Notion 空間，也許用 Linear 管理 ticket
    ↳ Slack 是團隊聊天工具，開個頻道讓人和 bot 一起溝通。Notion 是寫文件、整理資料的地方。Linear 用來管理 ticket（一張張待辦工作單）。
  • 18:01 有人回報 bug 可以直接自動修掉（「何必開 issue，直接開 PR 就好」）；先從 Slack 開始，把 Slack 當作 control plane
    ↳ bug 是程式錯誤；issue 是「回報問題的單子」；PR 是「送出一份修改」。意思是有人回報 bug，bot 就直接修好送出，不用先開單排隊。他們先把 Slack 當 control plane（總控台）。
  • 18:01 會把 factory 接到 Slack 的 issues channel
    ↳ 他們會把 factory 接到 Slack 專門回報問題的 issues 頻道。影片沒細講 factory 是什麼，從前後文看，應該是會自動接手處理這些問題的機制。
  • 18:32 Pstack 是免費的開源 plugin，打包了作者平常做嚴謹工程工作用的 skills 和 workflows，讓大家都能重複使用
    ↳ plugin 是外掛到工具上的擴充包。Pstack 免費又開源（程式碼公開，誰都能用），裡面打包了作者平常嚴謹寫程式用的 skills（技能）和 workflows（固定流程），大家都能拿去重複使用。
  • 19:02 作者說上個月用 Pstack 把大約兩千到兩千五百個 PR 送上 production
    ↳ 作者說，上個月他靠 Pstack 把大約兩千到兩千五百個 PR 送上 production（使用者實際在用的正式版本），用這個數字說明它能產出多少東西。
  • 19:33 可以到 Grockbot marketplace 搜尋 Pstack 來試用
    ↳ marketplace 是 Grockbot 裡的應用市集，概念就像手機的 App Store。想試用 Pstack，進去搜尋名字就能安裝。
  • 19:33 換算：一個月 2500 個 PR 約是每天 83 個，3 天約 250 個；後來決定不開 PR、直接 merge to main，改在畫面上放 commit 計數器
    ↳ 一個月 2500 個 PR，大約是每天 83 個、三天 250 個。後來他們乾脆不開 PR，直接 merge to main（修改直接併進主版本），改在畫面上計算 commit（每一次存下的修改）。
  • 20:03 Grockbot 這個 app 是 SpaceX 的人用這類工具快速迭代做出來的；直播會完整呈現產品從零到出貨的過程
    ↳ Grockbot 這個 app 本身，就是 SpaceX 的人用這類 AI 工具快速改版做出來的。這次直播會把一個產品從零到出貨的完整過程攤開給大家看。
  • 20:33 可能還需要資料庫、infra，以及 payments infra（會找 Stripe 的 Link 團隊）；之後可能會用白板規劃
    ↳ 除了程式，可能還需要資料庫（存資料的地方）、infra（讓服務能運作的主機等基礎設施），以及收款用的 payments infra，這部分會找 Stripe 的 Link 團隊。之後可能會用白板規劃。
  • 21:34 還需要大量的 tokens，這也是整個構想的核心
    ↳ tokens 是 AI 計算讀寫文字量的單位，用得越多，AI 做的事就越多。他們說需要大量 tokens，而這正是整個構想的核心。
  • 21:34 計畫盡量全部用 Grockbot 來推動：為這三天新建了一個 Grockbot team，每個人各自有一組 bot
    ↳ 他們打算盡量全部用 Grockbot 來推動：為這三天新開了一個 Grockbot team（團隊空間），每個成員各自帶一組 bot。
  • 22:04 要當成獨立的公司經營：開了一個完全空白的 GitHub org，叫「Ship by Thursday」，之後可能開源部分內容
    ↳ 他們要當成一家獨立的新公司來經營：在 GitHub（存放程式碼的平台）開了一個完全空白的組織帳號，叫「Ship by Thursday」（週四前出貨），之後可能開源部分內容。
  • 23:05 從零開始：全新的 Grockbot 帳號裡 bot 數量是 0；接下來會示範安裝 Pstack，並做市場調查
    ↳ 真的是從零開始：新的 Grockbot 帳號裡，bot 數量是 0。接下來會示範安裝 Pstack，然後開始做市場調查。
  • 23:05 已經有 user research bot，marketplace 也有整套 bot template 可以直接拿來用
    ↳ 也不必全部從頭來：已經有專門做使用者研究的 bot，marketplace 裡也有整套 bot template（現成範本），挑了就能直接用。
  • 23:35 打算「雇用」founding engineer bot、intern bot；也考慮讓 bot 每天幫忙做點東西，當作市場調查的一部分
    ↳ 他們打算像招人一樣「雇用」bot，例如 founding engineer bot（創始工程師）和 intern bot（實習生）。也考慮讓 bot 每天做點小東西，當作市場調查的一部分。
📘 術語
dogfooding（吃自己的狗食／自用自家產品）：用自己的產品來開發它本身，成為自家產品的重度使用者，並藉此改進產品
market research（市場調查）：請 bot 讀大家回覆的上千個點子，藉此決定要做什麼
PR (pull request)（合併請求）：字幕說「何必開 issue，直接開 PR」，意思是回報 bug 後直接送出修正
merge to main（直接合併到主分支）：不開 PR，直接把修改放進 main，因此改成計算 commit 數
control plane（控制中樞）：提議用 Slack 當作團隊和 bot 的控制中樞
plugin（外掛）：Pstack 是開源 plugin，裡面打包了作者的 skills 和 workflows
Grockbot marketplace（Grockbot 市集）：可以搜尋、安裝 Pstack，也有整套 bot template
tokens（tokens）：字幕說需要大量 tokens，而且這是整個構想的核心
Link card（Link 卡）：在 Grockbot 裡可以給 bot 的信用卡，由 Stripe 提供
