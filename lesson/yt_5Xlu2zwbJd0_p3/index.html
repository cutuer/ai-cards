🧑‍🏫 這段教你怎麼幫甜甜圈、糖霜、杯子和盤子設定材質，讓它們看起來像真的東西。重點是 subsurface 這個設定，它讓食物有牛奶般的柔潤感。最後用一片平面當桌子，順便回顧整個建模段落。

  • 22:23 不必每次都按渲染才能看結果：上方視圖圖示中的 rendered view mode 會在 viewport 裡即時顯示渲染結果
    ↳ 「rendered view mode」是畫面上方視圖圖示裡的一種模式。它直接在 viewport（中間編輯模型的工作視窗）顯示渲染（算出成品圖）的樣子，所以可以邊改邊看。
  • 22:56 以前渲染引擎很慢，一次渲染可能要好幾個小時。現在電腦夠快，可以在工作時持續渲染，通常也不太吃運算資源
    ↳ 以前渲染一張圖可能要等好幾小時，只能等到最後才算。現在電腦夠快，開著即時渲染一邊工作很正常，通常也不太會拖慢電腦。
  • 22:56 目前使用的是速度快很多的 Eevee；Cycles 會稍微慢一些
    ↳ Eevee 和 Cycles 是 Blender 的兩個渲染引擎，也就是負責算出成品畫面的程式。影片用的是快很多的 Eevee，Cycles 會慢一點。
  • 23:26 先從糖霜開始：到下方的 material properties 按 new material，就會出現一堆影響表面外觀的選項
    ↳ 材質要一個物體一個物體設，先從糖霜開始。選取糖霜後，到下方的 material properties（材質設定面板）按 new material，就會出現一整排控制表面長相的選項。
  • 23:26 Metallic 會讓物體看起來像金屬；Roughness 會改變反射的銳利程度
    ↳ Metallic 決定東西像不像金屬。Roughness 是表面粗糙度，決定反光是清楚銳利還是糊開的，差別就像拋光的碗和磨砂杯。
  • 23:58 Base color 是物體的基本顏色，幾乎每個物體都要調整它。這裡把糖霜設成粉紅色
    ↳ Base color 是物體本身的顏色，幾乎每個東西都會先調它。這裡把糖霜設成粉紅色。
  • 23:58 糖霜原本太 diffuse，看起來像粉筆。把 roughness 調低可以變亮面，但太低會變成鏡面反射
    ↳ 糖霜一開始太 diffuse（反光散開、霧霧的），看起來像粉筆。把 roughness 調低會出現光澤，但低過頭就會像鏡子一樣映出周圍。
  • 24:28 糖霜的 roughness 大約設在 0.2
    ↳ 糖霜的 roughness 抓 0.2 左右，有一點油亮光澤，又不會像鏡子。
  • 24:28 之後加入其他物體、換燈光設定時，某些材質設定可能會看起來不太對。燈光都設好後重新檢視材質是很常見的做法，而且完全 non-destructive，隨時可以改
    ↳ 材質先大概設好，等其他物體和燈光都到位再回頭微調，是很常見的做法。材質是 non-destructive（非破壞性），改數值不會毀掉東西，隨時能再改。
  • 25:00 示範把杯子做成黑色、亮面的陶瓷杯，但刻意不調到全黑
    ↳ 杯子示範做成黑色、有光澤的陶瓷杯，但顏色刻意不拉到純黑。
  • 25:00 通則：不要用全黑、全白，顏色也不要用 100% 飽和度，否則會 clip。現在 color management 進步了，這點可能有點過時，但仍是一般原則
    ↳ 一般原則是顏色別用純黑、純白或 100% 飽和度，否則會 clip（超出能表現的範圍，細節被切掉）。現在 color management（色彩管理）進步了，這條沒以前那麼嚴，但仍值得遵守。
  • 25:00 真正的黑是 Vantablack，一種以科學方式製造、幾乎不反射光的材料。你眼中很黑的杯子，大概也不是完全的黑
    ↳ 現實中真正的全黑是 Vantablack，一種特別製造、幾乎不反光的材料。你覺得很黑的杯子其實還是會反光，所以 3D 裡也不該設純黑。
  • 25:35 這些材質只是暫時的 placeholder，用來示範怎麼建立簡單材質。盤子調得稍微亮面一點，甜甜圈設為偏棕的淺色再調暗一些
    ↳ 這些材質只是 placeholder（暫時頂替用），重點是學會建立簡單材質。盤子調得稍有光澤；甜甜圈設成偏棕的淺色，再壓暗一點。
  • 25:35 有一個數值對食物和角色這兩類東西特別重要，糖霜和甜甜圈都用得到
    ↳ 接下來這個設定對食物和角色（人或生物）特別關鍵，糖霜和甜甜圈都會用到。
  • 26:07 有機物質是軟的，光會進入物體內部、在裡面散射，再從表面射出，這叫 subsurface scattering。例如手放在強光前可以看到光透過來，甚至看到骨頭
    ↳ subsurface scattering（次表面散射）是指光鑽進軟軟的有機物裡面，散開後再透出來。像手擋在強光前會透出紅光，甚至看得到骨頭輪廓。
  • 26:07 Subsurface 的 weight 要直接拉到 1。它不是強度，這個值應該是 0 或 1，不該介於兩者之間
    ↳ Subsurface 的 weight 不是調強弱的滑桿。依影片說法它只有開或關，設 0 或 1，不該用中間值。要用就直接拉到 1。
  • 26:07 效果多寡由 scale 控制，也就是光會穿透表面多深；調高或調低就能看到光進入物體的程度
    ↳ 效果要多或少是調 scale，也就是光能鑽進表面多深。把數值調大調小，就能看出光透進物體的程度。
  • 26:39 預設的 subsurface 顏色偏紅，作者認為這是個錯誤。紅色適合角色，因為角色體內有血，但食物等其他東西不該是紅的
    ↳ 預設的 subsurface 顏色偏紅，作者認為這是錯的。紅色適合角色，因為皮膚底下有血；食物裡沒有血，不該透出紅光。
  • 26:39 Subsurface 顏色分成 R、G、B 三個值（作者理解是因為不同波長在表面內的傳遞速度不同），預設為紅 1、綠 0.2、藍 0.1，要全部改成 1
    ↳ subsurface 顏色拆成 R、G、B（紅綠藍）三個數值，預設是 1、0.2、0.1，所以透出來偏紅。作者的理解是不同波長的光在裡面傳得不一樣。這裡全部改成 1。
  • 27:11 小技巧：在 Blender 裡可以按住並往下拖過多個數值欄位，輸入 1 後按 Enter，就能一次全部設成 1
    ↳ 小技巧：在 Blender 裡按住第一個數值欄位往下拖，可以一次選到好幾格。輸入 1 按 Enter，就能全部一起改好。
  • 27:11 調整後糖霜看起來更像牛奶般的質感。甜甜圈也開啟 subsurface，顏色設為 1，其他維持預設值
    ↳ 改完後，糖霜多了像牛奶那種柔潤、微透的質感。甜甜圈也打開 subsurface，顏色設 1，其他照預設就好。
  • 27:42 用渲染 slots 做前後對比：slot 1 開啟 subsurface、slot 2 關閉後再渲染一次，按 J 來回切換比較
    ↳ 渲染視窗有 slot（存放渲染結果的格子）。在 slot 1 渲染開 subsurface 的版本，換到 slot 2 關掉後再渲染，按 J 來回切換比較差別。
  • 27:42 開啟 subsurface 後，原本全暗的地方有光透過，這就是產生牛奶般質感的原因，而且大多適用於食物這類東西
    ↳ 開了 subsurface 後，原本全黑的暗面會透出一點光，這就是牛奶感的來源。這招主要適合食物這類東西。
  • 28:15 接著加桌子（貼圖留到下一集）。大型場景需要真的建模一張桌子，但如果確定攝影機只會在這個位置，就只有桌面重要
    ↳ 接著做桌子，貼圖留到下一集。大場景要真的建一張完整的桌子，但如果確定鏡頭只從這個角度拍，就只有桌面看得到，其他都不用做。
  • 30:00 桌子只要 Shift+A 新增 Plane，再稍微放大就完成了
    ↳ 做法很簡單：按 Shift+A 新增一個 Plane（一片沒有厚度的平面），稍微放大，桌子就完成了。
  • 30:00 3D 裡這很常見：電影 3D 場景拆解中到處都是假的，例如建築物只是貼上貼圖的平面（cards）。只有攝影機會移動時，才可能需要好好建模
    ↳ 「看不到就不做」在 3D 很常見。電影場景拆開來看到處都是假的，很多建築只是貼了圖的平面，叫 cards。鏡頭會移動、看得到側面時，才需要好好建模。
  • 30:30 對從沒用過 3D 的人來說，做出盤子上的甜甜圈加杯子是一項成就。在 90 年代，做得出這個大概能拿獎學金
    ↳ 沒碰過 3D 的人能做出盤子上的甜甜圈加一個杯子，已經很了不起。作者說在 90 年代，做得出這個大概能拿獎學金。
  • 30:30 要存檔圖片：點 Image 再選 Save，可以存成 PNG、JPEG 等格式
    ↳ 要把渲染好的圖存下來，在渲染視窗點 Image → Save，可以存成 PNG、JPEG 等常見圖檔格式。
  • 31:02 接下來幾集會做貼圖、讓桌子更好看、幫物體加上陶瓷貼圖等，讓成品好看很多。本集是甜甜圈教學建模段落的結尾
    ↳ 後面幾集會加貼圖、把桌子弄好看、幫杯盤加上陶瓷貼圖，成品會好看很多。這集是甜甜圈教學「建模」部分的最後一集。
  • 31:02 建模段落回顧：基本 primitives、輕微變形、用 extrude 做出有機外形、一點 sculpting，以及建立杯子
    ↳ 回顧建模學過的：用 primitives（內建基本形狀，如圓環）起頭並稍微變形、用 extrude（把面往外擠出）做出自然外形、一點 sculpting（像捏黏土般雕塑），還有做杯子。
  • 31:34 杯子用了 modifiers 和 Subsurf 建立大致外形。這些是未來做很多物體會用到的部分技巧
    ↳ 杯子用了 modifiers（套在物體上、自動加工形狀的工具），其中的 Subsurf 會把表面細分得更圓滑，用來做出大致外形。之後做很多東西都會用到這類技巧。
  • 31:34 還有很多其他技巧：精確建模、硬物件建模與維持直線、高度客製與變形的建模、把 mesh 當成 guide mesh 使用
    ↳ 這次沒教的建模技巧還很多：精準尺寸建模、有稜有角的硬物件要保持直線、高度客製的變形，以及把一個 mesh（模型網格）當 guide mesh，用來參考形狀。
  • 32:05 角色相關技巧：從零雕刻角色、轉成有 subdivision 讓手臂能動，再做 rigging，讓手臂能像木偶一樣動。這些甜甜圈教學沒時間教
    ↳ 角色方面還有：從零雕出角色，轉成有 subdivision（可細分的乾淨網格）的模型讓手臂能動，再做 rigging（裝骨架），讓手臂像木偶一樣被操控。這些甜甜圈教學來不及教。
  • 32:05 上述技巧在作者的課程 The Beginners Academy 裡有教。只想免費學 Blender、只做甜甜圈也沒問題
    ↳ 上面那些技巧，作者的課程 The Beginners Academy 有教。如果你只想免費學 Blender、只做完甜甜圈，也完全沒問題。

    ↳ 這門課想教你像 3D 藝術家一樣思考，把腦中的點子做出來，拿去 3D 列印、渲染成圖或做其他視覺化。連結在影片下方。

    ↳ 課程是為做完甜甜圈的完全新手設計的。不過看到這裡已經學了不少，也可以直接去上。

    ↳ 如果繼續跟這個系列，下一集會進入 texturing（貼圖），也就是給物體表面加上圖案和細節，讓成品更逼真。
📘 術語
rendered view mode（渲染預覽模式）：上方視圖圖示中的模式，讓渲染在 viewport 裡即時顯示，不必按渲染等待
Eevee（Eevee 渲染引擎）：速度快很多的渲染引擎，影片目前使用它
Cycles（Cycles 渲染引擎）：另一個渲染引擎，比 Eevee 稍微慢一些
material properties（材質屬性面板）：位於下方的面板，按 new material 就能建立材質並調整各種選項
Metallic（金屬感）：會讓物體看起來像金屬
Roughness（粗糙度）：改變反射的銳利程度；調太低會變成鏡面反射
Base color（基本顏色）：物體的基本顏色，幾乎每個物體都要調整的主要選項
diffuse（漫射）：字幕用來形容糖霜看起來太霧、像粉筆的樣子
non-destructive（非破壞性）：材質數值隨時可以再修改，不會造成不可逆的改變
clip（截斷／爆掉）：全黑、全白或 100% 飽和度時，畫面會開始 clip，所以不建議這樣設定
color management（色彩管理）：現在進步很多，已經知道怎麼處理高飽和與很暗的東西
Vantablack（Vantablack）：真正的黑，一種以科學方式製造、幾乎不反射光的材料
subsurface scattering（次表面散射）：光進入有機物體內部散射後再射出；對食物和角色特別重要
weight (subsurface)（權重）：不是強度，應設為 0 或 1，影片建議直接拉到 1
scale (subsurface)（尺度）：光會穿透表面多深，用來控制 subsurface 效果的多寡
slot (render)（渲染槽）：用不同 slot 各存一次渲染，按 J 來回切換做前後對比
Plane（平面）：用 Shift+A 新增；攝影機固定時，用它當桌子就夠了
cards（卡片／貼圖平面）：電影場景中的建築物常只是貼上貼圖的平面
primitives（基本幾何體）：建模段落回顧中提到的基本形體
extrude（擠出）：用來做出有機外形的建模操作
sculpting（雕刻）：建模段落中做過一點；也可以用來從零雕刻角色
modifiers / Subsurf（修改器／Subsurf）：用來建立杯子大致外形的工具
guide mesh（引導網格）：把 mesh 當成引導來建立形狀
subdivision（細分）：讓雕刻出的角色轉換後手臂能夠活動
rigging（綁定）：讓角色的手臂能像木偶一樣被操控移動
texturing（貼圖）：下一集的內容，會讓桌子等物體看起來好很多
