🧑‍🏫 這是 BCON26 講座的後半段。講者拆解 A24 電影《Backrooms》裡他們用 Blender 做的特效，包括髒地毯、讓人頭暈的 Vertigo room、全 CG 的開場，以及算圖設定。值得看的原因是它示範了免費軟體怎麼撐起院線片，而且很多做法其實很樸實、很手工。

  • 12:01 片場實際搭了 30,000 平方英尺的 Backrooms，其餘數十萬平方英尺的空間都是 CG
    ↳ 片場真的蓋了 3 萬平方英尺的場景，但電影裡的空間大得多。另外數十萬平方英尺都是 CG（電腦繪圖）做出來的。
  • 12:01 地毯有兩張片場掃描（carpet 1、2），另做一張髒污版叫 Carpet Nasty，因為片場地毯很乾淨
    ↳ 片場的地毯被掃描成兩張數位貼圖。但實體地毯太乾淨，不像荒廢的空間，所以團隊另外做了一張刻意弄髒的版本，叫 Carpet Nasty。
  • 12:34 Carpet Nasty 成為導演 Kane 最愛的地毯，他在片後約 15 分鐘的 Everything Must Go 也用了它
    ↳ 這張髒地毯後來成了導演 Kane 最喜歡的版本，他在之後的作品 Everything Must Go 裡也用了它。
  • 12:34 地毯是可無限 tile 的貼圖，相當簡單；用 noise texture 的 distortion 參數做出條紋狀腳印
    ↳ 地毯做成 tileable texture（上下左右接起來看不出接縫、可無限重複的貼圖），所以不難做。腳印則用 noise texture 的 distortion（扭曲）參數拉出條紋。
  • 13:09 貼圖盡量程序化，但每個轉角、每次鏡頭轉向都逐段做美術指導
    ↳ 能用程式規則自動產生的貼圖（程序化）就盡量用，比較省工。但每個轉角、每次鏡頭轉向看到的畫面，仍然有人逐段調整美感。
  • 13:09 大量 decal：把血跡染成棕色看起來像泥巴，另有很多咖啡漬 decal
    ↳ 大量使用 decal（像貼紙一樣疊在表面上的貼圖）。例如把血跡染成棕色，看起來就像泥巴；另外還貼了很多咖啡漬。
  • 13:09 Decal 做法：帶 alpha 的貼圖接進 BSDF，關掉 shadow casting 即可當 decal，也能再 shrink wrap
    ↳ 做法是拿一張帶 alpha（透明度資訊）的圖，接進 BSDF（決定表面怎麼反光的著色節點），再關掉 shadow casting（投射陰影）。還能用 shrink wrap 讓它緊貼凹凸表面。
  • 13:42 用 decal 移來移去就能做出獨特外觀，不必做大量貼圖工作
    ↳ 同幾張污漬換位置、重新組合，每個角落看起來就不一樣，不必為每面牆重畫貼圖。
  • 13:42 加了蜘蛛網（討論過蜘蛛能否 no-clip 進 Backrooms），Kane 很喜歡；講者猜他在 Everything Must Go 也用了同一張
    ↳ 團隊還加了蜘蛛網，並開玩笑討論蜘蛛會不會 no-clip（遊戲術語，穿牆掉進別的空間）進來。Kane 很喜歡，講者猜他在 Everything Must Go 也用了同一張。
  • 14:16 Vertigo room：Mary 被 Captain Clark 追的段落，目的是讓觀眾感到暈眩（vertigo）
    ↳ Vertigo room 是女主角 Mary 被 Captain Clark 追的段落。整個場景的設計目的，就是讓觀眾看了頭暈、產生懼高感。
  • 14:48 Vertigo room 是全片最大、最複雜的場景：28 層摩天樓式 Backrooms，上百個房間與道具
    ↳ 這是全片最大、最複雜的場景：像 28 層摩天樓那樣疊起來的 Backrooms，裡面有上百個房間和道具。
  • 14:48 Kane 想要「像蓋好 Backrooms 後從正中間 Boolean cut 下去」，團隊就真的在 Blender 裡這樣做
    ↳ Kane 的想像是「把蓋好的 Backrooms 從正中間剖開」。團隊就真的在 Blender 用 Boolean cut（拿一個形狀去切掉另一個物體）照做。
  • 14:48 片場走廊（陽台）約 3–4 英尺寬，後來再做窄，讓 Mary 更貼近邊緣、加強暈眩感
    ↳ 片場的陽台走道原本約 3–4 英尺寬（約 1 公尺），後來又改得更窄，讓 Mary 更貼近邊緣，懼高感更強。
  • 15:21 只做一小段陽台，往下的部分用 VFX 延伸
    ↳ 實際只做了一小段陽台，往下延伸的樓層都用 VFX（視覺特效）補上。
  • 15:21 建模大多沒用程序化系統：講者認為刻意手工設計比程序生成有趣，原圖爆紅靠的是空間之間的關係
    ↳ 建模大多沒用程式自動生成。講者認為刻意手工設計更有意思，因為 Backrooms 原圖會爆紅，靠的是空間和空間之間的關係，而這需要人去安排。
  • 15:51 全部手工打造、做美術指導，再用系統把設計往下複製到每一層
    ↳ 流程是先全部手工做好、調好美感，再用系統把這個設計往下複製到每一層，兼顧手感和效率。
  • 15:51 用 Solidify 與 Boolean modifier：畫一個頂點再 extrude，就有正確厚度與高度，可自由畫出樓層
    ↳ 用 Solidify（自動幫平面加厚度的工具）加 Boolean。只要畫一個點再 extrude（往外擠出延伸），牆就有正確的厚度和高度，可以像畫平面圖一樣畫樓層。
  • 16:23 材質用 Geometry Nodes：Mesh Boolean 切出區塊，再用 Set Material 套材質
    ↳ 材質分區用 Geometry Nodes（用節點規則處理模型的系統）：先用 Mesh Boolean 切出區塊，再用 Set Material 替每一塊套上材質。
  • 16:23 牆面上半是抹泥的裸 drywall、下半是 chevron，因為透過 drop ceiling 會看到沒貼壁紙的牆
    ↳ 牆的上半部是抹過泥的裸石膏板，下半部是 V 字紋（chevron）壁紙。因為從 drop ceiling（吊掛式天花板）的縫隙往上看，會看到沒貼壁紙的牆。
  • 16:55 大約做了 7 種樓層，再複製、旋轉、移動，最後拿一個 cube 從正中間切下去
    ↳ 大約做了 7 種樓層樣式，經過複製、旋轉、移動疊成高樓，最後拿一個方塊從正中間切開，就成了剖面。
  • 16:55 細節逐步疊加：從素牆開始，加 drop ceiling、掉落的天花板磚、垂掛電纜、flex piping
    ↳ 細節是一層一層加上去的：從素牆開始，再加吊頂天花板、掉在地上的天花板磚、垂下來的電纜和可彎曲的軟管。
  • 17:28 常請教做 sheet metal 的朋友 T-bar 天花板、出風口數量與管線怎麼走；講者說做 VFX 總會學到新行業知識
    ↳ 講者常請教做鈑金的朋友：T-bar 天花板（用 T 型金屬條架起的吊頂）怎麼搭、出風口要幾個、管線怎麼走。他說做特效總會學到別的行業知識。
  • 17:28 Cold open 是 Naren 之死，用來把觀眾帶回 Kane 早期影片爆紅的 found footage 風格
    ↳ 電影的 cold open（正片前的開場段落）是 Naren 之死。用意是把觀眾帶回 Kane 早期爆紅的 found footage（假裝是撿到的真實錄影）風格。
  • 18:02 開場段落全是 CG，但把最終 EXR 真的錄到 VHS 上（覆蓋 Fellowship of the Ring 的 VHS），不做後製模擬
    ↳ 這段全是 CG，但他們把最終的 EXR（高品質影像檔）真的錄進 VHS 錄影帶，蓋掉一卷《魔戒首部曲》，而不是用後製去模擬老帶質感。
  • 18:35 目的是抓住老粉絲，同時把新粉絲帶進這個 IP
    ↳ 這樣做一方面抓住 YouTube 時期的老粉絲，一方面把新觀眾帶進這個 IP（作品品牌與世界觀）。
  • 18:35 Kane 與講者共同設計世界：Kane 做原始地圖配置，講者團隊 upres 到定稿
    ↳ 世界是兩人一起設計的：Kane 先排出原始地圖配置，講者團隊再 upres（把粗稿提升成高品質）做到定稿。
  • 18:35 開場段落 7,500 格、約 5 分鐘；算完圖後光輸出 QuickTime 就花約 2 小時
    ↳ 開場共 7,500 格，約 5 分鐘。算完圖之後，光是輸出成 QuickTime 影片檔就花了約 2 小時。
  • 19:09 用虛擬攝影機取代手 K 加 noise 做晃動；共 13 個 take 接起來，手腳為手 K、全為 CG
    ↳ 鏡頭晃動沒有用手 K（手動設定 keyframe 關鍵影格）再加雜訊，而是用虛擬攝影機實拍，共 13 個鏡次接起來。畫面裡的手腳是手 K 的，全部都是 CG。
  • 19:09 開場環境 180,000 平方英尺，現實中蓋不出來，所以用 Blender 做
    ↳ 開場環境有 18 萬平方英尺，現實中不可能蓋這麼大的場景，所以用 Blender 做。
  • 19:44 給 Kane 一個 Parsec 帳號登入講者的工作站，兩人一起調鏡頭
    ↳ 講者給 Kane 一個 Parsec（遠端連線軟體，可以操作另一台電腦）帳號，讓他連進講者的工作站，兩人一起調鏡頭。
  • 19:44 VCam 拍攝成員含 Kane、講者、VFX supervisor Ed Douglas、製片與剪接師 Greg
    ↳ VCam（虛擬攝影機：拿著實體裝置移動，3D 場景裡的鏡頭會跟著動）拍攝成員有 Kane、講者、特效總監 Ed Douglas、製片和剪接師 Greg。
  • 20:14 VCam 目的是做出細膩有機的手持感（手做非常耗時），讓 Kane 實際操作攝影機才有這感覺
    ↳ 手持鏡頭那種細微、自然的晃動，用手做非常耗時。讓 Kane 本人實際拿攝影機操作，才抓得到那種感覺。
  • 20:14 Beyond Capture 在最後一刻（某個週六）組隊提供棚拍，講者認為救了這部片的開場
    ↳ Beyond Capture 在最後關頭（某個週六）臨時組隊提供攝影棚。講者認為是他們救了這部片的開場。
  • 20:49 片場直接用真的 Blender 場景檔當 previz；地上貼 marker，講者持機跑動操作
    ↳ 片場直接拿真正的 Blender 場景檔當 previz（拍攝前的粗略預演畫面）。地上貼標記對應場景位置，講者拿著設備跑動操作。
  • 20:49 先做粗略 previz，再透過攝影機觀景窗重拍一次
    ↳ 先做一版粗略的預演，確定大致怎麼走，再透過攝影機觀景窗實際重拍一次。
  • 20:49 接 take 前先請剪接鎖定節奏並挑好 take，避免瞎猜
    ↳ 接鏡次之前，先請剪接師把節奏定下來、挑好要用的鏡次，免得特效組靠猜的做白工。
  • 21:24 黃色的 active camera 是 hero camera，其他是虛擬攝影機的 pickup，用 Child Of constraint 逐段接起來
    ↳ 黃色的 active camera 是 hero camera（最終輸出用的主攝影機），其他是虛擬攝影機補拍的片段。各段用 Child Of constraint（讓物體跟隨另一個物體的綁定）逐段接起來。
  • 21:24 技巧：在 graph editor（curve editor）按 Alt+S 可讓曲線平滑
    ↳ 小技巧：在 graph editor（也叫 curve editor，用曲線顯示動畫數值變化的編輯器）按 Alt+S，可以把曲線抹平，讓動作更順。
  • 21:24 技巧：curve editor 也能用 proportional editing 旋轉、縮放 keyframe，處理 motion capture 差很多
    ↳ 在 curve editor 也能開 proportional editing（改一個點，周圍的點按比例跟著動）來旋轉、縮放 keyframe，處理動作捕捉的密集資料時差很多。
  • 21:57 講者有一套為此案維護的算圖 pipeline，花了一段時間才找出合適設定
    ↳ 講者為這個案子維護一套固定的算圖流程（pipeline），光是找出合適的設定就花了一段時間。
  • 21:57 Beauty 加 AOV 流程用 DWAB 壓縮、half float 效果很好；cryptomatte 則要用 PIZ 壓縮
    ↳ 主畫面（beauty）加各種拆分圖層（AOV）時，用 DWAB 壓縮搭配 half float（半精度數值）效果很好。cryptomatte（自動產生物件遮罩的圖層）則要改用 PIZ 壓縮。
  • 21:57 離線算圖常用 pass：color、Z depth、position、normal、cryptomatte
    ↳ 離線算圖常輸出的 pass（分開存檔的圖層）有：顏色、Z depth（每一點離鏡頭多遠）、位置、法線（表面朝向）和 cryptomatte，方便後製分開調整。
  • 22:29 茶壺算圖：為了找行銷能過關的畫作，提議讓 Backrooms「生成一張很爛的 CG 算圖」，Kane 很喜歡
    ↳ 為了找一張行銷能過關的畫作，講者提議讓 Backrooms「生成一張很爛的 CG 算圖」，也就是這張茶壺圖，Kane 很喜歡。
  • 23:05 算圖裡本來就有地毯；片中逐格看得到這張圖
    ↳ 這張算圖裡本來就有那張地毯，電影裡逐格暫停就看得到。
  • 23:05 講者覺得能向 Kane 的成果致敬，也看到 Blender 在 A24 這部成功作品中於最高層級競爭
    ↳ 講者很高興能向 Kane 的成果致敬，也看到 Blender 在 A24 這部成功作品中，跟最高層級的製作一起競爭。
📘 術語
Decal（貼花）：帶 alpha 的貼圖接進 BSDF、關掉 shadow casting 就能當 decal 用
BSDF（BSDF 著色器）：decal 貼圖要接進去的著色節點
Shadow casting（投射陰影）：做 decal 時要關掉的設定
Shrink wrap（收縮包覆）：decal 也可以 shrink wrap 貼附到表面上
Noise texture distortion（雜訊貼圖的扭曲參數）：講者平常少用，這次拿來做條紋狀腳印
Tileable texture（可無縫拼接貼圖）：Carpet Nasty 是可無限 tile 的貼圖
No-clip（穿牆進入）：用來開玩笑說蜘蛛也可能 no-clip 進 Backrooms
Boolean cut（布林切割）：蓋好 Backrooms 後用 cube 從正中間切下去做出 Vertigo room
Solidify modifier（加厚修改器）：搭配 Boolean，畫頂點 extrude 後就有正確厚度與高度
Extrude（擠出）：從單一頂點擠出來畫樓層
Geometry Nodes（幾何節點）：用來做材質分區的節點設定
Mesh Boolean / Set Material（網格布林／設定材質節點）：在 Geometry Nodes 中切出區塊並套上材質
Drop ceiling / T-bar ceiling（輕鋼架天花板）：透過它會看到沒貼壁紙的牆；講者向鈑金朋友請教
Found footage（偽紀錄片（尋獲影像）風格）：Kane 早期影片爆紅的風格，開場要把觀眾帶回這感覺
EXR（EXR 影像檔）：開場段落的最終輸出檔，被錄到 VHS 上
Upres（提升解析度／細緻度）：Kane 做原始地圖，講者團隊 upres 到定稿
Virtual camera / VCam（虛擬攝影機）：讓 Kane 實際操作攝影機，取代手 K 加 noise 做晃動
Previz（預視）：片場直接用真的 Blender 場景檔當 previz
Parsec（Parsec 遠端連線）：讓 Kane 登入講者的工作站一起調鏡頭
Hero camera（主攝影機）：黃色的 active camera，其他為 pickup
Child Of constraint（Child Of 約束）：用來把各攝影機片段接起來
Graph editor / Curve editor（曲線編輯器）：按 Alt+S 可平滑曲線
Proportional editing（比例編輯）：在 curve editor 可用來旋轉、縮放 keyframe
Keyframe（關鍵影格）：7,500 格的時間軸有大量 keyframe
AOV（輸出通道）：beauty 加 AOV 流程適合 DWAB、half float
DWAB / PIZ（EXR 壓縮格式）：beauty 與 AOV 用 DWAB，cryptomatte 用 PIZ
Half float（半精度浮點）：搭配 DWAB 壓縮效果很好
Cryptomatte（Cryptomatte 遮罩）：講者常用的 pass 之一，需用 PIZ 壓縮
Z depth（深度通道）：講者常用的算圖 pass 之一
✏️ 小考一題

講者的算圖設定中，cryptomatte 應該使用哪種壓縮？

A. ZIP 壓縮B. 不壓縮C. PIZ 壓縮D. DWAB 壓縮
看答案
答案：C。[21:57] 講者說 beauty 與 AOV 用 DWAB 壓縮、half float 效果很好，但 cryptomatte 應該用 PIZ 壓縮。
