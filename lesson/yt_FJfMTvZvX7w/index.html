📘 術語
script（劇本）：錄影前寫好角色、地點、表演方式和拍法，決定整支影片的成果
reference（參考素材）：可以是多種東西也能放多個，例如人物、帽子、T 恤、海報圖片
movement reference / acting reference（動作參考／表演參考）：原始影片只提供動作和表演，人物換成參考圖中的角色
raw footage（原始素材）：自己用 iPhone 錄的未處理影片
edit video（影片編輯功能）：上傳原始影片和參考圖、貼上 prompt 後生成的功能
MD file / skill（MD 檔／技能）：作者提供的檔案，安裝到 Claude 後可用 SD25/p 協助優化 prompt
prompt（提示詞）：描述想要結果的文字，由 Claude 看過原片與參考後幫忙寫出
tripod / static shot（三腳架／固定鏡頭）：讓畫面穩定，一人分飾多角疊合畫面時一定要用
credits（點數）：生成要花的點數；把鏡頭接起來一次生成、先用低解析度試都能省點數
480p / 720p / 1080p（解析度）：不確定時先用 480p 試；1080p 很貴，作者常用 720p
Whisper Flow（Whisper Flow）：作者用來口述參考、目標與意圖的工具
grain / blur（顆粒感／模糊）：剪輯時加上去可讓畫面看起來更真實

影片中提到，怎麼做能在 Seedance 2.5 生成多鏡頭場景時大量節省 credits？

A. 每個鏡頭都換成不同的參考圖B. 每個鏡頭分開生成，各自搭配參考圖C. 一律使用 1080p 一次生成到位D. 先把多個鏡頭的原始素材接成一段，再一次生成
