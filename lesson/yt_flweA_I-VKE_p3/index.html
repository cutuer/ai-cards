🧑‍🏫 這是 OpenAI 訪談節目的最後一段，Hearth AI 創辦人 Ashe 分享她怎麼讓 AI 幫她發文、用 Slack 管理生活，以及她想做的穿戴裝置。後半段她談品味、好奇心和面對不舒服，想用 AI 打造自己生活工具的人可以參考。

  • 22:33 Ashe 沒有行銷背景。OpenClaw 最能幫她的地方是跨平台 distribution：她在 X 發文後，由 OpenClaw 和 agents 把內容再分享到 Reddit 等平台
    ↳ 她沒學過行銷，最缺的是 distribution（把想法散到各平台讓人看到）。她只在 X 發文，再交給 OpenClaw（替她跑任務的 AI 工具）和 agents（會自己動手做事的 AI 助手）轉到 Reddit 等平台。
  • 22:33 她強調不能讓人覺得是 spam，這條界線很細
    ↳ 自動轉發最怕被當成 spam（洗版、垃圾訊息）。同一段話到處貼，別人一看就知道是機器在灌，反而傷信譽，所以分寸很難拿捏。
  • 23:05 做法是用各平台自己的語言重新表達同一個想法，因為每個平台都不同。在 Reddit 上效果很好，很快就收到看起來像真人的回覆
    ↳ 她的解法不是複製貼上，而是讓 agents 用每個平台各自習慣的說話方式，改寫同一個想法。結果在 Reddit 上很快就有看起來像真人的留言回應。
  • 23:05 對需要做 distribution 的人來說，也許不必花大量時間經營 Reddit、LinkedIn、Instagram，讓 agents 幫忙，自己專注在想法上
    ↳ 意思是：要經營很多平台的人，不一定要每天自己在 Reddit、LinkedIn、Instagram 寫文、回文。改寫和發布可以交給 agents，自己把力氣花在想出好點子。
  • 23:36 她很常用 Slack。OpenClaw 只是她整套 agentic 系統的其中一部分
    ↳ Slack 是常見的團隊聊天工具，她用得很重。OpenClaw 只是她整套 agentic 系統（由多個 agents 自動分工處理事情的系統）其中一塊。
  • 23:36 她用 Slack 的 channel 來區分 agentic workflows，例如 news、birthdays、goals、money。生活中每件重複的事都有對應的 channel 和 agents
    ↳ 她用 Slack 的 channel（分主題的聊天室）區分 agentic workflows（交給 agents 自動跑的固定流程），像新聞、生日、目標、金錢各一個。生活裡每件重複的事都有專屬頻道和 agents。
  • 23:36 重點是讓 agents 反過來管理她，減少螢幕時間，讓她能專心陪伴身邊的人
    ↳ 一般是人去盯工具，她想反過來：讓 agents 提醒她、安排她。這樣她不必一直看螢幕，可以把注意力留給身邊的人。
  • 24:11 她曾在酒吧展示這個 Slack workspace，對方問她是不是唯一的成員。她說是，而這就是未來：她和她的 agents
    ↳ 她在酒吧展示這個 Slack 工作區，對方問成員是不是只有她。她說是，還說這就是未來：一個真人，加上一群替她做事的 agents。
  • 24:46 她正在做 wearable／硬體。動機是想過得專注、與人有連結，並盡量減少手機和電腦的使用時間
    ↳ wearable 是戴在身上的裝置，像手環、眼鏡。她正在做這類硬體，出發點是想活得專注、多跟人連結，盡量少用手機和電腦。
  • 25:16 她不喜歡 ambient recording（背景持續錄音），但認為未來需要把意識流系統化，存進「second brain」
    ↳ ambient recording 是裝置在背景一直錄音。她不喜歡這種做法，但認為未來要把腦中的想法有條理地存進 second brain（替你記事情的外部系統）。
  • 25:16 她設想一種社交禮儀：對方說了有趣的話，看到她碰觸身體某處，就知道這會被存進 second brain，對方也可以表示不同意
    ↳ 她想像的規矩是：聊天時對方說了有意思的話，她碰一下身上某處，對方就知道這句會被存起來。對方不想被記，也可以直接表示不同意，而不是被偷偷錄下來。
  • 25:16 她想先探索未來的社交禮儀，希望做法優雅、不失禮
    ↳ 她想先摸索未來的 social etiquette（社交禮儀，大家默認的相處規矩）。科技進到人際場合，要做得優雅、讓人自在，不能讓對方覺得被冒犯。
  • 25:46 第二個目標是類比式的體驗，讓 second brain 幫她記住身邊的人，她就能專心聆聽對方說話
    ↳ 第二個目標是「類比式」的體驗，也就是不用盯著螢幕操作。second brain 幫她記住身邊的人，她當下就能專心聽對方說話。
  • 25:46 人腦處理人際關係的能力有限，而每個人都有很多面向。她認為關係的核心是：我是誰、對方是誰、對方隨時間對我而言是誰
    ↳ 人腦能記住、照顧的關係有限，每個人又有很多面向。她認為關係的核心是三件事：我是誰、對方是誰、對方這些年來對我的意義是什麼。
  • 26:20 她說關係是映照自己的鏡子，期待有一層 intelligence layer 引導她經營豐富的人際連結
    ↳ 她覺得和別人的關係會照出自己是怎樣的人。她希望有一層 intelligence layer（在生活上方幫你整理、提醒的 AI 層），引導她把人際連結經營得更豐富。
  • 26:50 被問到工程師該如何面對這個時代，她說首先要回到自己的自我感。這個時代讓人能打造個人化的軟體層
    ↳ 被問到工程師怎麼面對這個時代，她說要先回頭弄清楚自己是誰、想要什麼。現在每個人都能替自己量身打造專屬的軟體，所以先要認識自己。
  • 27:25 她也希望 building in public 時能更真實地呈現自己
    ↳ building in public 是一邊做產品、一邊公開分享過程。她希望分享時更真誠，呈現真實的自己，而不只是包裝好的成果。
  • 27:25 她很重視美感、視覺與美。未來做的任何東西，連管理 agents 在內，互動起來都要讓她覺得美
    ↳ 她非常在意美感和視覺。以後做任何東西，就算只是管理 agents 的介面，用起來也要讓她覺得美。對她來說，美是必要條件。
  • 27:25 她覺得 Codex 酷的地方之一，是管理大量被啟動的 agents 和 subagents 時，體驗很美
    ↳ Codex 是 OpenAI 寫程式的 AI 工具。她喜歡它的一點是：同時開很多 agents 和 subagents（主 agent 分派出去做子任務的 agent）時，管理起來的體驗還是很美。
  • 27:56 她期待未來每個和 agents、系統、硬體、board design 的接觸點都像藝術品，讓人有共鳴、受到啟發
    ↳ 她期待未來人和 agents、系統、硬體、board design（電路板設計）的每個接觸點，都做得像藝術品，讓人有共鳴、受到啟發，而不只是能用。
  • 27:56 主持人提到，AI 從只能寫一點程式碼，進步到能可靠地承擔大量工作，例如 Ashe 一次就把整個 prototype 做成完整產品
    ↳ 主持人說，AI 以前只能幫忙寫幾行程式，現在已經能穩定扛起大量工作。例如 Ashe 一次就把 prototype（測試用的雛形）做成完整的產品。
  • 28:27 她用的是 Codex app，也會在 Cursor、Claude Code、Codex 等系統之間頻繁切換
    ↳ 她主要用 Codex 的 app，但也常在 Cursor、Claude Code、Codex 之間切換。這些都是協助寫程式的 AI 工具，她沒有綁定單一一套。
  • 28:27 整個生態變化太快，每天都不一樣，她覺得自己像一個以爆發式節奏工作的創作者
    ↳ 工具和整個生態每天都在變。她覺得自己不像照表操課的上班族，比較像創作者，用爆發式的節奏工作。
  • 28:58 做 the aesthetic.video 時，她馬上覺得 5.4 是合適的夥伴：速度快又可靠，理解產品需要 user authentication 和 Stripe
    ↳ 她做 the aesthetic.video 這個產品時，覺得她說的 5.4 很合拍：快又可靠，也懂產品需要 user authentication（登入與身分驗證）和 Stripe（常見的線上收款服務）。
  • 28:58 她的節奏是衝刺幾個小時，停下來發布產品、拍影片、換做別的事，工作內容和流程每天變化很大。她認為這是這個時代的新現象
    ↳ 她的節奏是衝刺幾個小時，然後停下來發布產品、拍影片、轉做別的事，每天的內容和流程都不一樣。她認為這是這個時代才有的新現象。
  • 29:31 以前當工程師時，她每天連續 11 小時做類似的事。現在她更適合依照自己何時最有創意來衝刺，而不是跑馬拉松
    ↳ 以前當工程師，她每天連續 11 小時做差不多的事，像跑馬拉松。現在她照自己最有創意的時段短程衝刺，這樣比較適合她。
  • 30:02 談到 taste 與好奇心：要真正專注於自己和自己的身體，積極追求讓你有共鳴的方向（電影、攝影、產品等），並收集相似的東西
    ↳ taste 指品味，也就是判斷什麼是好東西的能力。她說培養品味要回到自己和身體的感受，主動追求讓你有感的東西，像電影、攝影、產品，再把相似的收集起來。
  • 30:02 給年輕時自己的建議：要願意不舒服，成長和把自己公開出去都會伴隨不適
    ↳ 她給年輕時自己的建議是：要願意不舒服。成長和把自己公開給別人看，本來就會帶來不自在，這是過程的一部分。
  • 30:38 每次發布帶有自己一部分的作品都很可怕，要冒被看見的風險。但值得練成這種反射和肌肉，因為能帶來真實世界的回饋，讓人更有創意、持續打造
    ↳ 發布帶有自己一部分的作品很可怕，因為會被看見、被評價。但她說值得把這練成反射動作，因為真實世界的回饋會讓人更有創意，也更願意繼續做。
  • 30:38 她提到 Peter 和 OpenClaw：作品發布後，很多人投入心力回饋，成長出超乎所有人預期的湧現特質。這就是與其他 builders 建立關係和回饋迴圈的魔力
    ↳ 她舉 OpenClaw 的發布者 Peter 為例：作品公開後，很多人投入心力回饋，讓它長出沒人預料到的樣子。這就是和其他 builders（動手做產品的人）建立 feedback loop（回饋循環）的魔力。
  • 31:10 主持人說 OpenClaw 令人驚豔的除了 Peter 的獨到洞見，還有它的社群：很多人戴著龍蝦帽，熱衷打造自己的 personal agents
    ↳ 主持人補充，OpenClaw 厲害的不只是 Peter 的眼光，還有它的社群。很多人戴著龍蝦帽，熱衷打造自己的 personal agents（專門替自己辦事的個人 agents）。
  • 31:42 她認為 taste 的核心是自我調諧與個體性。讓你有共鳴的東西就值得熱情追求、分享出去，並允許意外發生
    ↳ 她說品味的核心，是聽懂自己、保有自己的個人特色。讓你有感的東西就大方去追、分享出去，也留空間給意料之外的發展。
  • 32:13 主持人提到她的經歷：ML engineer、做過衛星和賽車、當過幾次創辦人
    ↳ 主持人提到她的經歷：當過 ML engineer（機器學習工程師，做 AI 模型的人），做過衛星和賽車相關的東西，也當過好幾次創辦人。
  • 32:13 給剛開始探索 AI 工具的 builders 的建議：保持好奇、享受樂趣，尊重自己的好奇心，讓渴望引導你，並勇於冒險
    ↳ 給剛開始玩 AI 工具的人：保持好奇、玩得開心，認真對待自己感興趣的事，讓「想做」的念頭帶路，也要敢冒險嘗試。
  • 32:46 她認為好奇心一直是工程師歷史中很神奇的部分。即使一切都在改變，這個支柱不變：由好奇心驅動，實現新近才可能做到的東西
    ↳ 她認為好奇心一直是工程師最神奇的特質。工具再怎麼變，這一點不變：被好奇心推著走，去做出最近才變得做得到的東西。
  • 32:46 主持人指出，這和 Peter 的建議很相似：一路上要享受樂趣，追隨熱情與好奇心
    ↳ 主持人說這和 Peter 給的建議很像：過程中要好好享受，跟著熱情和好奇心走。

✏️ 小考一題

Ashe 如何用 Slack 組織她的 agentic 系統？

A. 只拿 Slack 和同事溝通，agents 另外放在 Codex app 裡B. 用 Slack 自動錄下她和朋友的對話，存進 second brainC. 把所有 agents 集中在同一個 channel，方便一次管理D. 用不同 channel 區分生活中重複進行的事務，每個 channel 都有對應的 agents

答案：D。[23:36] 她說 Slack 能依 channel 自然區分 agentic workflows，例如 news、birthdays、goals、money，每件重複的事都有 channel 和對應的 agents
