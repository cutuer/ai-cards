🧑‍🏫 這支影片示範品牌怎麼在 ChatGPT 裡投廣告，以及怎麼直接用聊天的方式查廣告成效、問原因、拿改善建議。重點在兩件事：廣告出現在人們正在做購買決定的時候，而且看成效不用再翻複雜報表。有在做行銷、投廣告的人值得看。

  • 00:04 ChatGPT 已成為人們做決定的地方，使用者帶著自己的目標來問 ChatGPT
    ↳ 很多人現在不只拿 ChatGPT 查資料，而是帶著「要買哪個、選哪個」的問題來問它。影片的意思是，最後的決定常常就在這段對話裡決定。
  • 00:04 使用者不只輸入幾個關鍵字，而是說明想達成什麼、什麼對自己重要、有哪些限制
    ↳ 在搜尋引擎打「耳機 推薦」，對方能給的資訊很少。在 ChatGPT 裡，人會講完整需求，例如預算、在意什麼、不能接受什麼，所以更清楚這個人真正要什麼。
  • 00:04 例子：使用者要找工作、旅行、在家都能用的耳機，但不確定哪些功能適合自己
    ↳ 她說得出用途，卻不知道降噪、續航這類功能哪些對自己重要。這時候她最需要有人幫忙判斷，也最容易被好的建議說動。
  • 00:04 透過 ChatGPT 廣告，可以在消費者找產品、比較選項、決定購買時接觸到他們
    ↳ 廣告出現的時間點，是對方正在找、在比較、快要下單的時候，不是在她根本沒想買東西時硬塞給她。
  • 00:35 示範案例：為 Nova Electronics 的耳機顯示廣告
    ↳ Nova Electronics 是影片拿來示範的耳機品牌，後面的廣告和成效數據都以它為例。
  • 00:35 廣告不會影響 ChatGPT 的回答；信任是這個機會的基礎，廣告平台的設計重點是保護這份信任
    ↳ 付錢買廣告，不會讓 ChatGPT 的回答偏向你的產品。使用者是因為信任回答才來問，一旦覺得回答被收買，這個平台就沒有價值了。
  • 00:35 依照原則，廣告會清楚標示，並和 ChatGPT 的回答分開顯示
    ↳ 使用者一看就知道哪一塊是廣告。廣告不會混在 ChatGPT 的回答文字裡，兩者分得很清楚。
  • 01:05 查看廣告成效通常很複雜，需要看報表、使用很多工具
    ↳ 投過廣告的人都知道，要看成效通常得進不同後台、匯出報表、自己拉試算表比對，很花時間，也要看得懂數字。
  • 01:05 ChatGPT 廣告報表可以透過 API 或廣告 dashboard 存取
    ↳ 原本拿報表有兩種方式。dashboard 是網頁上的圖表儀表板，點進去就能看；API 是讓程式自動抓資料的接口，通常是工程師串接系統時用。
  • 01:05 現在推出 ChatGPT 的廣告管理 plugin，可以直接在 ChatGPT 裡用完全對話的方式詢問廣告成效
    ↳ plugin 是外掛，裝上後 ChatGPT 會多一項能力。這個外掛讓你不用開後台，直接在聊天框用平常講話的方式問廣告跑得怎樣。
  • 01:05 示範提問：我們想知道廣告的成效如何
    ↳ 提問就這麼一句白話，不用先學報表怎麼操作。這正是示範想讓你看到的地方。
  • 01:35 目前有三則廣告：「Your world」、「Your focus」、「Every detail is created for you.」
    ↳ 這三則是同一個品牌的三個不同文案版本，接下來拿它們互相比較，看哪種寫法比較有效。
  • 01:35 可以看到點閱率、轉換等數據；「Your World」和「Your Focus」的表現看起來比較好
    ↳ 點閱率（click-through rate）是看到廣告的人當中，有多少比例點進去。轉換（conversion）是點進去後真的完成購買、註冊等目標動作。前兩則在這些數字上比較好。
  • 01:35 這些只是基本報表；真正令人興奮的是能知道「為什麼」，這點很難從傳統報表工具得到
    ↳ 傳統報表只告訴你哪則好，至於為什麼好，要靠人自己推敲。這裡的賣點是 AI 能直接幫你解釋原因。
  • 01:35 直接問模型：為什麼有些廣告表現比其他廣告好？
    ↳ 就像問一個懂行銷的同事，你不用自己翻數據推理，直接問為什麼，模型會根據成效數據給你解釋。
  • 01:35 要採取行動時，再問模型下一步該怎麼做、要怎麼改善 campaign
    ↳ campaign 是一整檔廣告活動，裡面有多則廣告、預算和目標。知道原因後可以繼續追問該怎麼調整，從看報告變成拿到具體的行動建議。
  • 01:35 可以在 Ads Manager 的成效數據和素材製作流程之間形成循環，更快改善廣告素材
    ↳ Ads Manager 是管理和投放廣告的後台；creative 是廣告素材，像文案和圖片。流程是看完成效就改素材、再投、再看，這個循環會跑得更快。
  • 02:07 ChatGPT Ads 讓行銷人員能影響那些左右決策的關鍵時刻，這是以前從來沒有過的能力
    ↳ 意思是品牌能在對方正在考慮買哪個的當下出現，影響他的選擇。影片認為，這是過去的廣告做不到的事。
  • 02:07 ChatGPT Ads 目前在全球 40 個市場推出，最近又在歐洲新增了 31 個市場
    ↳ 這不是小範圍的測試功能，已經在很多國家開放，歐洲是最新擴大的地區。台灣有沒有在名單上影片沒講，要自己去查。
  • 02:07 想開始使用或了解更多，可以到 ads.openai.com
    ↳ 這是官方入口網址。想投廣告或看詳細說明，就從這裡進去。
