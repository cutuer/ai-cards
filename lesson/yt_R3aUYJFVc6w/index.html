🧑‍🏫 這支影片請 NVIDIA 的 AI 研究員分享他怎麼用 GPT-5.5 做研究，從想題目到跑實驗都有。值得看的地方是，AI 在這裡不只幫忙寫程式，也被拿來發想研究方向、推進整個研究流程。

  • 00:01 講者 Shaurya Joshi 是 NVIDIA 的 AI 研究員
    ↳ 這支影片的分享者 Shaurya Joshi 在 NVIDIA 做 AI 研究。NVIDIA 是做顯示卡、AI 晶片的大公司，所以他是每天都在用 AI、研究 AI 的人。
  • 00:01 他覺得的「magic moment」：他問了一個很抽象的問題，GPT-5.5 有足夠的智慧回給他一個解法
    ↳ 「magic moment」就是讓人眼睛一亮的那一刻。對他來說，是他問了一個很抽象、還沒講清楚的問題，GPT-5.5 卻能抓到重點，回給他一個解法。
  • 00:01 他去吃午餐時，GPT-5.5 正在幫他 refactor 整個 code base
    ↳ code base 是一個專案全部的程式碼；refactor 是不改功能，把程式重新整理得更乾淨、更好維護。他去吃午餐的時候，AI 在背景整理整個專案的程式。
  • 00:01 他覺得 GPT-5.5 似乎比一些競爭對手更有創意，prompt 它之後會回一個更出色的點子
    ↳ prompt 就是你輸入給 AI 的指令或問題。他的感覺是，同樣下指令，GPT-5.5 似乎比其他家的模型更有創意，回的點子更出色，不只是中規中矩的答案。
  • 00:33 例子：他請 GPT-5.5 依他給的研究資料，建議可做的研究領域或新實驗
    ↳ 具體例子是：他把手上的研究資料交給 GPT-5.5，請它根據這些資料建議還有哪些方向可以研究、可以做哪些新實驗，把它當成一起想題目的夥伴。
  • 00:33 GPT-5.5 反過來提議建一個 knowledge graph，把他丟進去的檔案裡的想法視覺化
    ↳ knowledge graph（知識圖譜）是把各種概念畫成點，再用線標出彼此關係的圖。GPT-5.5 沒有只列建議，而是反過來提議做這種圖，把他檔案裡的想法畫出來。
  • 00:33 跑實驗的速度基本上快了 10 倍
    ↳ 他說跑實驗的速度基本上快了 10 倍。這是他自己的使用感受，意思是整個實驗流程的進度比以前推得快很多。
  • 00:33 原因是它能處理 end-to-end workflow：找研究點子、在 machine learning infrastructure 上寫 script、訓練模型
    ↳ end-to-end workflow 是從頭到尾一整條流程；machine learning infrastructure 是訓練 AI 模型用的運算系統。變快是因為它能一路做完：想點子、寫 script（自動執行的小程式）、訓練模型。
📘 術語
refactor（重構）：字幕沒有解釋，只提到 GPT-5.5 幫他 refactor 整個 code base
code base（程式碼庫）：字幕沒有解釋，只提到被 GPT-5.5 整個 refactor 的對象
knowledge graph（知識圖譜）：用來把他丟進去的檔案裡的所有想法視覺化
end-to-end workflow（端到端工作流程）：從找研究點子、寫 script，到訓練模型的完整流程
machine learning infrastructure（機器學習基礎設施）：字幕沒有解釋，只提到要在上面寫 script 來訓練模型
✏️ 小考一題

講者請 GPT-5.5 建議研究方向時，GPT-5.5 主動提議做什麼？

A. 立刻開始訓練一個新模型B. 跟競爭對手的模型比較結果C. 直接寫一篇論文摘要D. 建一個 knowledge graph，把檔案裡的想法視覺化
看答案
答案：D。[00:33] 它回答：「how about I build a knowledge graph for you and help you visualize all the ideas within the files」
