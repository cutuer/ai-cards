📘 術語
repo（程式庫（repository））：放在 GitHub 上的專案。作者說 repo 已包含設定所需的所有指示，Claude 會照著自動設定
clone（複製）：字幕有兩種用法：Claude 把 repo clone 到電腦上；也指把參考影片「複製」成自己產品的版本
bypass mode（略過核准模式）：不用一直按核准，但比較危險，使用前要了解風險
API key（API 金鑰）：要貼進 .env 檔，Claude 才能呼叫 Arcads 上傳內容；不要貼在聊天視窗，較不安全
.env（環境設定檔）：存放 API key 的檔案，可在文字編輯器開啟，裡面標示了貼上位置
client ID / client secret（用戶端 ID／用戶端密鑰）：在 Arc Ads 的 settings → public API 點 get new credentials 後取得
UGC style video（UGC 風格影片）：字幕未解釋，作者用這個詞要求 Claude 生成影片
skill（技能）：說 commit this to a skill 就會儲存，之後可呼叫並重複同樣做法，也能當 template
template（範本）：內建在 agent 裡，也可把 clone 的影片存成 skill 當 template 重複使用
FFmpeg（FFmpeg）：Claude Code 用它從影片擷取多張影格，用來理解畫面內容
beat（段落節拍）：字幕未解釋，分析時說來源影片有 8 個 beats，並保留 beat structure
stitch（拼接）：把多支生成的影片接成一支，例如把 Arcads 生成的三支影片拼起來
Nano Banana 2（Nano Banana 2）：作者用來做假產品圖的工具，也可用來生成 starting scene images
vibe coding（vibe coding）：字幕未解釋；作者說這做法像 vibe coding，但變成 vibe creating
custom GPTs（custom GPTs）：字幕未解釋；作者拿它對比現在會跟著你學習的完整 AI agents
