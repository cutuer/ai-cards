  • 00:02 Sites 是新的 plugin，幾分鐘內就能建立功能完整的 web app，內建 hosting 與 storage，可以馬上發布，不必另外設定服務
    ↳ Sites 是新的 plugin（外掛，裝上後 ChatGPT 多一項能力），幾分鐘就能做出可操作的 web app（用瀏覽器打開的網站程式）。放網站的 hosting 和存資料的 storage 都內建，不必自己去租。
  • 00:02 直接在聊天視窗描述需求就能開始，例如：幫設計研討會做一個發表網站，要有講者卡片、可篩選的議程，還有簡潔極簡的 editorial 風格
    ↳ 不用會寫程式，直接打字描述需求就能開始。像範例那樣講清楚用途、要有哪些區塊、想要什麼風格就行。editorial 風格指像雜誌排版，字體講究、留白多、版面乾淨。
  • 00:34 它會在背後建立專案、寫程式，一直做到第一版完成，接著可以打開成品自己試用
    ↳ 送出需求後，它會自己開專案、寫程式碼，過程中不用你插手，直到做出第一版。之後你可以直接點開網站，像一般訪客一樣實際點點看好不好用。
  • 00:34 可以用一般的白話持續給回饋（例如讓議程更好瀏覽、讓 keynote 更像主秀），實作細節由它在背後處理
    ↳ 覺得哪裡不對，用平常講話的方式說就好，例如「議程好難找」「keynote（開場主題演講）要更醒目」。要改哪段程式、怎麼改，它會自己處理。
  • 00:34 可以在 in-app browser 打開網站，用內建的 annotation tool 留下針對特定位置的註解，告訴它要改哪裡
    ↳ in-app browser 是 ChatGPT 裡內建的瀏覽器，不用切出去就能看網站。搭配 annotation tool（註解工具），可以直接在畫面上圈出位置寫要改什麼，比用文字描述更精準。
  • 01:05 完成後可以按 publish，或直接叫 ChatGPT 部署
    ↳ 改到滿意後，按 publish（發布）網站就會上線，別人拿到網址就能看。也可以直接跟 ChatGPT 說「幫我部署」，部署就是把網站放上網路，讓別人連得到。
  • 01:05 Sites 可以搭配 Build Web Apps 等其他 plugin，它提供設計、實作、測試方面的 skills，提升網站品質；示範用它做了一款 2000 年代初風格的 2D 橫向捲軸遊戲
    ↳ Sites 可以和其他 plugin 一起用。Build Web Apps 提供設計、實作、測試方面的 skills（預先教好的專業做法），讓網站品質更好。示範甚至做出一款 2000 年代初風格的橫向捲軸小遊戲。
📘 術語
Sites（Sites plugin）：新的 plugin，能在幾分鐘內建立完整的 web app，內建 hosting 與 storage
Build Web Apps（Build Web Apps plugin）：可以搭配 Sites 的 plugin，提供設計、實作、測試的 skills 來提升網站品質
annotation tool（註解工具）：在 in-app browser 裡使用的內建工具，可以留下針對性的註解，告訴它要改哪裡
in-app browser（內建瀏覽器）：用來打開網站、搭配 annotation tool 使用
