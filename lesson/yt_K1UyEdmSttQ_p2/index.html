🧑‍🏫 這段接著做甜甜圈旁邊的馬克杯：先把杯底做紮實，再從杯身擠出把手。重點是講者故意示範錯誤做法，讓你看懂為什麼要先 Apply 厚度效果，這個觀念之後做任何模型都用得到。

  • 10:26 先把杯底那一圈稍微 scale 往內縮。起點位置靠目測判斷即可
    ↳ 先選杯底最下面那一圈，用 scale（縮放）稍微往內收。縮多少沒有標準，看起來像杯底就好。
  • 10:26 想從選取的 face 往外拉出形狀，需要更多 geometry。直接往下拉只會把面拉伸變形
    ↳ geometry 是模型上可以選取、操作的點、線、面。面不夠時硬往下拉，只會把原本的面拉長變形，不會長出新形狀。
  • 10:26 增加 geometry 往外拉出的操作叫 extrusion，快捷鍵取英文首字母 E
    ↳ extrusion（擠出）是從選取的面長出新的面再往外拉，有點像擠牙膏。快捷鍵 E，取 Extrude 的第一個字母。
  • 11:05 和 inset 等其他功能一樣，按下 E 就進入該模式。可以往上或往下拉，這裡往下拉，點一下確認
    ↳ inset（內插面）是在一個面裡面再縮出一圈面。它和擠出一樣，按下快捷鍵就開始操作，移動滑鼠決定方向和距離，點一下才確定。
  • 11:05 想讓杯子像甜甜圈一樣看起來平滑，可以使用 Shade Smooth
    ↳ Shade Smooth 是讓表面顯示成平滑、看不出一塊塊稜角的設定。上一集的甜甜圈也是這樣處理的。
  • 11:05 杯底那條線變得很緊，形成一個平滑的小凸塊。原因是 subsurf modifier 的運作方式
    ↳ Subsurf modifier 會把模型細分得更圓滑。它讓杯底邊緣收得太緊，鼓出一個小凸包。這不是你做錯，是它的計算方式造成的。
  • 11:37 subsurf 會從一點經過中間點往內漸縮，另一點也要漸縮來平滑線條。解法是加更多 geometry，讓平滑不要從太高的地方開始
    ↳ Subsurf 會在兩點之間補中間點，再慢慢往內收圓。線隔得遠，圓弧就從很高的地方開始收；在底部附近多加線，圓弧範圍就會變小。
  • 11:37 加 loop cut：可從選單 Edge > Loop Cut and Slide，快捷鍵 Ctrl+R。先點一下 face 決定位置
    ↳ loop cut 是沿著模型繞一整圈切出一條新線。按 Ctrl+R（或從 Edge 選單點），滑鼠移到面上會看到預覽，點一下決定切的位置。
  • 12:18 接著會問要滑到哪裡。第一條滑到最底部並點擊確認，再按 Ctrl+R 放在同一處往上拉出第二條，杯底就變緊實了
    ↳ 點完後可以沿著面滑動那條線。第一條滑到最底部點擊確認，再按一次 Ctrl+R，在同處切出第二條往上拉，杯底邊緣就變利落了。
  • 12:18 杯底出現類似海星的放射紋路，可以選取那個 face 做 inset 來整理。這步不是必要的，別人不太會注意到
    ↳ 杯底中心的線從一點往外散，像海星，看起來有點亂。選那個面做 inset 可以整理，但不做也沒關係，一般人不會注意到。
  • 12:49 接下來挑戰做把手：從某處開始擠出，繞一圈後接回杯身
    ↳ 把手的做法是：從杯身某個面開始擠出，一段段繞出一個弧，最後再接回杯身。
  • 12:49 把手與杯身的接合處必須是杯子本身 geometry 的一部分。不能讓把手獨立懸在空間中，否則看起來不會接在一起
    ↳ 把手必須從杯子本身長出來，接合處要是同一個模型的一部分。另外做一個飄在旁邊的把手，接縫會看得出沒有真的連在一起。
  • 13:31 要在 mesh 上找一個起點來擠出把手。講者特地這樣建模，就是為了留出這個位置
    ↳ mesh 是模型本身的結構，也就是那些點線面的組合。講者前面切線時就刻意留了一格面，正好當把手的起點。
  • 13:31 講者先示範錯誤做法：直接擠出並做完把手，之後回頭看杯子會發現形狀跑掉了
    ↳ 講者故意先示範錯的：直接擠出、做完整個把手，回頭一看，杯子形狀變怪了。先讓你看到問題長什麼樣子。
  • 14:07 原因是 Solidify modifier 不屬於 mesh 本身，而是事後才套上去的。它會替所有 mesh 加厚度，連把手也一起加厚
    ↳ modifier 是套在模型上的效果，不會改動 mesh 本身。Solidify 負責加厚度，所以後來擠出的把手也被自動加厚，形狀就亂了。
  • 15:00 解法是把 modifier 變成真正的 geometry：先用 Ctrl+Z 復原，再到 modifier 右上角下拉選單（小相機圖示旁）按 Apply
    ↳ 解法是 Apply：把 modifier 的效果變成真正的點線面。先按 Ctrl+Z 退回，再到 modifier 右上角相機圖示旁的下拉選單按 Apply。
  • 15:00 Apply 之後 modifier 會消失，進入 Edit mode 就能看到原本沒有的 geometry。關掉 Subsurf 也能看出來
    ↳ Apply 後，modifier 會從清單消失。進 Edit mode（編輯點線面的模式）會看到多出杯壁厚度的點線面，關掉 Subsurf 也看得出來。
  • 15:00 套用後可以單獨修改杯子內側，不會影響其他部分
    ↳ 杯壁內側現在是真實存在的面，可以單獨選起來修改，不會牽動外側或其他地方。
  • 15:35 缺點是不再是 non-destructive，調整杯子厚度的滑桿沒了，想改厚度只能自己手動選取修改
    ↳ non-destructive（非破壞式）是指效果隨時能調、能拿掉，不動到原模型。Apply 後就沒有厚度滑桿了，想改厚度只能自己選點線面調。
  • 15:35 講者認為這沒關係：想加入客製化，終究要打破這種工作流程
    ↳ 講者的看法是：想做出自己要的細節，本來就得在某個時間點放棄「隨時回頭調整」的方便。
  • 15:35 開始擠出前要確認選對 face。選錯的話，把手一扭轉很快就會亂掉
    ↳ 擠出前先確認選對面。選錯位置的話，把手一轉彎，形狀很快就歪掉，很難救。
  • 16:07 正確的 face 要讓紅線剛好穿過杯子正中央。可以切到 top view 檢查是否在中間
    ↳ 選到的面要讓畫面上的紅線剛好穿過杯子正中央。切到 top view（從正上方往下看）就能檢查有沒有偏。
  • 16:07 選好後用 Numpad 1 或點那個綠色的東西切到 front view，再按 E 擠出
    ↳ 選好後按數字鍵盤的 1（Numpad 1），或點畫面上綠色的那個點，切到 front view（正面視角），再按 E 擠出。
  • 16:07 E 擠出時是依照 normals 的方向，也就是 mesh 上每個 face 隱藏的方向
    ↳ normals（法線）是每個面隱藏的朝向，代表這個面「面向哪邊」。按 E 時，新的面會沿著這個方向長出去。
  • 16:39 偶爾擠出會失敗，原因是那個 face 的 normals 有問題。解法是選取該 face 按 Shift+N 來 clear normals
    ↳ 偶爾擠出會失敗，通常是那個面的 normals 有問題。選取那個面按 Shift+N，把法線方向重新整理好。
  • 16:39 講者整理了疑難排解指南「Unstuck Yourself guide」，收錄做這個教學可能遇到的各種問題，連結在影片下方
    ↳ Unstuck Yourself guide 是講者整理的疑難排解清單，收錄做這個教學常卡住的問題，連結在影片下方。
  • 17:10 Blender Guru Discord 可以發問、分享 render，連結在下方。因為很多人問同樣的問題，才整理出這份 FAQ。遇到問題請先查它
    ↳ Blender Guru 有 Discord 群，可以發問、分享 render（算好的成品圖）。因為太多人問同樣的問題才整理出 FAQ，卡住先查它。
  • 17:10 擠出一點後，按 G（grab）把它往上移。再按 Tab 切到 Object mode，選取參考圖片
    ↳ 擠出一小段後，按 G（grab，移動）往上移。再按 Tab 切到 Object mode（以整個物件為單位操作的模式），點選參考圖。
  • 17:44 按 G 再按 X，把參考圖移到旁邊，方便對照杯子判斷把手該在哪裡、長什麼形狀
    ↳ 按 G 再按 X，代表只沿左右方向移動。把參考圖挪到杯子旁邊對照，才看得出把手該從哪裡長、長成什麼形狀。
  • 17:44 把手是以斜角接進杯身，所以看起來會歪斜。選取該 face 後按 R 旋轉來調整
    ↳ 參考圖裡的把手是斜斜接進杯身的，所以看起來有點歪。選取那個面按 R（旋轉）調整角度。
  • 18:16 突出的部分在杯子上像個小凸塊，所以需要 loop cut。按 Ctrl+R 加一條並往下拉到接合處底部，再用 face select mode 重新選取 face
    ↳ 剛擠出的部分在杯身上鼓成小包，所以要再切線：按 Ctrl+R 加一條，拉到接合處底部，再切到 face select mode（只選面的模式）重選那個面。
  • 18:46 想讓把手細一點：選取頂端的 edge，連按兩下 G 讓它往下滑，把手就變薄了
    ↳ 想讓把手細一點：選頂端那條邊，連按兩下 G，邊會貼著表面滑動。往下滑，把手就變薄了。
  • 18:46 之後在 face select mode 反覆操作：E 擠出、G 調整位置、R 旋轉
    ↳ 之後就在 face select mode 重複同一套：E 擠出一段、G 調位置、R 轉角度，一節一節做出去。
  • 20:00 每次旋轉都要讓把手順著參考圖的輪廓繞一圈。流程是 E、點擊、G、點擊、R
    ↳ 每轉一次都對照參考圖的輪廓，讓把手沿著弧線繞一圈。節奏是 E、點、G、點、R，一直重複。
  • 20:00 另一種擠出方式：按住 Control 再按右鍵。它除了擠出，還會旋轉 face 讓方向對齊，比一直按 E、G、R、S 輕鬆
    ↳ 比較省力的做法：按住 Ctrl 再按右鍵，會擠出並自動把面轉到對的方向，不用一直輪流按 E、G、R、S（縮放）。
📘 術語
geometry（幾何結構）：模型上可操作的點線面。要往外拉出形狀就需要更多 geometry
extrusion / Extrude（擠出）：增加 geometry 並從 face 往外拉出，快捷鍵 E
inset（內插面）：字幕用它來整理杯底的海星狀紋路；和 extrusion 一樣，按下就進入該模式
Object mode（物件模式）：字幕中用來查看整體杯子，以及選取、移動參考圖片的模式（用 Tab 切換）
Edit mode（編輯模式）：Apply 之後進入這個模式，就能看到原本沒有的 geometry
Shade Smooth（平滑著色）：讓模型像甜甜圈一樣看起來平滑
Subsurf modifier（細分曲面修改器）：會在點之間經由中間點做漸縮平滑，導致杯底線條變緊、形成小凸塊
Loop Cut and Slide（環切並滑動）：位在 Edge 選單，快捷鍵 Ctrl+R。先點選位置，再滑動並點擊確認
Solidify modifier（實體化修改器）：替 mesh 加上厚度。它不屬於 mesh，是事後套上的，所以也會把把手加厚
modifier（修改器）：不屬於 mesh 本身，是事後才作用在模型上的效果
Apply（套用）：在 modifier 下拉選單（相機圖示旁），把 modifier 變成 mesh 裡真正的 geometry
non-destructive（非破壞性）：Apply 之後就不再是 non-destructive，調整厚度的滑桿會消失
mesh（網格）：模型本身的結構。把手的起點要在 mesh 上找
normals（法線）：mesh 上每個 face 隱藏的方向。擠出時依照這個方向進行
Shift+N（清除法線（字幕說法））：擠出失敗通常是 normals 有問題，選取 face 按 Shift+N 可以 clear normals
face select mode（面選取模式）：選取 face 以便擠出把手的模式
front view / top view（前視圖／頂視圖）：front view 可用 Numpad 1 或點綠色的東西切換；top view 用來檢查 face 是否在正中央
Numpad 1（數字鍵盤 1）：切換到 front view 的快捷鍵
G / G then X / double-tap G（移動／沿 X 軸移動／沿邊滑動）：G 是 grab 移動；G 再按 X 是橫向移動圖片；連按兩下 G 讓 edge 往下滑
R（旋轉）：按 R 旋轉選取的 face，讓把手順著輪廓走
Unstuck Yourself guide（脫困疑難排解指南）：講者整理的 FAQ 資料庫，收錄做這個教學可能遇到的問題
✏️ 小考一題

直接擠出把手後，杯子的形狀跑掉了，因為 Solidify modifier 也替把手加了厚度。講者用什麼方法解決？

A. 按 Ctrl+R 在把手根部多加一條 loop cutB. 選取 face 後按 Shift+N 來 clear normalsC. 對整個杯子使用 Shade SmoothD. 在 modifier 下拉選單（相機圖示旁）按 Apply，讓它變成真正的 geometry
看答案
答案：D。[15:00] 講者說要把 modifier 變成真正的 geometry：先 Ctrl+Z 復原，再到 modifier 下拉選單（相機圖示旁）按 Apply。Shift+N 是用來處理擠出失敗的 normals 問題（16:39），不是解決加厚問題。
