🧑‍🏫 這段是 BCON26 的演講開場。講者 Dave Furner 主張，要讓 Blender 做出來的「手繪感」畫面更好看，關鍵不是新節點或新技巧，而是走出門觀察、動手寫生，練出「每一筆都有目的」的設計判斷。想做風格化 3D 畫面的人，看這段能先抓到方向：為什麼要做、要做到哪裡就夠。

  • 00:38 講者說這個技巧在許多 NPR 演講中常被預設或暗示，但從沒被明確提出，所以今天專門談它
    ↳ 很多 NPR 講者心裡都默認這件事，卻很少有人講出口。他乾脆把這個被略過的前提拿出來，當成整場演講的主題。
  • 01:12 演講內容會放上 YouTube，所有檔案也會提供
    ↳ 演講影片會上傳，他用的檔案也會公開。現場沒跟上的人，之後可以自己打開檔案慢慢研究。
  • 01:12 講者 Dave Furner 是倫敦小型動畫工作室 Real Good Liars 的共同創辦人，Instagram 上有作品和幕後花絮
    ↳ 講者自我介紹：他和夥伴在倫敦開一間小動畫工作室，想看作品和製作過程，可以去他們的 Instagram。
  • 01:48 工作室人數依專案而定，最多時 8 人，全職只有 2 人：講者和事業夥伴 Rosie，因此達成性別平等
    ↳ 這是自嘲的玩笑。工作室看案子找人，最多 8 人，但正職只有他和 Rosie 一男一女，所以剛好「男女各半」。
  • 01:48 NPR 是很廣的詞，但他們的詮釋非常特定，而且隨著越清楚自己想要什麼而越來越特定
    ↳ NPR 指不走寫實路線的算圖風格，範圍很大。他們只做其中很窄的一種，而且越清楚自己要什麼，路線就收得越窄。
  • 02:20 工作室 showreel 中 90% 是 Blender 專案，風格基本上是講者喜歡的東西
    ↳ showreel 是工作室的作品精華剪輯，用來給客戶看。裡面九成是用 Blender 做的，風格也就是講者自己喜歡的樣子。
  • 02:20 他們也嘗試其他 NPR 風格；BCON 獨家預告：之後會做 NPR 版 Blender 甜甜圈教學（向 doughnut guy 致歉）
    ↳ 他們也會嘗試別種風格。他順便預告會出一支 NPR 版的甜甜圈教學，拿網路上最有名的 Blender 甜甜圈入門教學開玩笑。
  • 02:52 提供網址可下載一批 Blender 檔案，不是工作坊必需，只是讓觀眾邊聽邊玩
    ↳ 現場有網址可以下載他們的 Blender 檔案。聽講不需要這些檔案，下載只是讓你能一邊聽一邊打開來玩。
  • 03:30 這些是真實製作檔案，沒整理過但相當有條理；全部在 Blender 內組裝，沒有外部剪輯、也沒有外部合成
    ↳ 這些是真的拿去做案子的檔案，沒特別整理，但還算有條理。剪接和合成（把多層畫面疊成最終畫面）都在 Blender 裡完成。
  • 03:30 多數檔案在 viewport 就是所見即所得，全部使用 Eevee，講者說很適合他們的工作方式
    ↳ viewport 是 Blender 裡編輯場景的主畫面。Eevee 是 Blender 的即時算圖引擎。多數畫面在編輯時看到的就是成品，改了馬上看得到效果。
  • 03:30 有使用一些外部向量繪圖工具，尤其是和其他藝術家合作時
    ↳ 他們不是什麼都在 Blender 裡做。尤其跟其他畫家合作時，會用外部的向量繪圖軟體畫圖，再把圖帶進來。
  • 04:01 檔案內附粗糙但可用的 importer；授權為 Creative Commons BY 4.0，可拿去延伸與學習
    ↳ importer 是把外部檔案匯入 Blender 的小工具，他們附的這個簡陋但能用。CC BY 4.0 授權的意思是，只要標註出處，就能拿去改、拿去學。
  • 04:33 NPR 是 non-photoreal rendering（R 是 rendering 還是 real 講者不確定），指任何不追求寫實的東西；講者詮釋為看起來像手繪的東西
    ↳ 連講者都不確定縮寫的 R 是 rendering 還是 real，反正指的是不求逼真的畫面。他自己追求的是看起來像手畫出來的效果。
  • 04:33 要讓畫面好看，要用 screen space 而不是 world space 思考；這是講者去年在同一間會議室向 Julien 學到的
    ↳ world space 是 3D 空間裡的真實位置，screen space 是畫面上看起來的位置。要好看，就要照觀眾在畫面上看到的樣子來調。
  • 05:04 檔案中有大量把 2D 美術帶進 3D 空間的技巧與節點
    ↳ nodes（節點）是 Blender 裡一塊塊拼接起來做材質和效果的積木。檔案裡有很多這類設定，用來把平面的畫放進 3D 場景。
  • 05:04 也附有用 mesh 驅動 grease pencil 動畫、用 grease pencil 驅動 mesh 動畫的工具
    ↳ grease pencil 是 Blender 裡能在 3D 空間畫 2D 筆畫的工具，mesh 則是 3D 模型。檔案附的工具能讓兩者互相帶動動畫。
  • 05:34 其中一個是從手繪 grease pencil 方框產生的 lattice deformer；但今天不談，這些都不是那個技巧
    ↳ lattice deformer 是包住物體的變形籠子，拉籠子物體就跟著變形。他能用手畫的方框直接生出籠子，但強調這些都不是今天要講的招。
  • 05:34 NPR 演講常有一個特定焦點，講者稱為「Ghibli cloud problem」
    ↳ 講者觀察到，很多 NPR 演講都在處理同一件事，他半開玩笑地把這件事叫做「吉卜力雲問題」。
  • 06:04 這類教學試圖在 Blender 重現 Studio Ghibli 風格，成功程度不一，但講者認為都沒做到被模仿的藝術家們都做過的事
    ↳ 指的是一堆教人用 Blender 做出吉卜力風格的教學。有的像、有的不像，但他認為這些教學都漏掉了原作畫家們真正做過的功課。
  • 06:41 展示 Kazuo Oga（Totoro、Mononoke 美術監督）的「真正吉卜力雲教學」：出去看雲，這就是本技巧的精髓
    ↳ 男鹿和雄是《龍貓》《魔法公主》的美術監督。講者說他的「雲教學」只有一步：出門看真的雲。這就是整場演講的核心。
  • 07:13 講者說這技巧怪，但一點也不簡單
    ↳ 這招聽起來很怪，好像沒什麼技術含量。講者提醒，真的要做到其實很難。
  • 07:13 講者說的「drawing」是直接創造影像，可用鉛筆、畫筆或滑鼠；重點是你與影像直接接觸，畫面中一切都來自你
    ↳ 他說的「畫」不限工具，鉛筆、畫筆、滑鼠都算。重點是畫面上每樣東西都是你親手決定放上去的，中間沒有別的東西幫你產生。
  • 07:13 觀察世界讓我們能向他人呈現事物在自己眼中的樣子；寫生練習也會建立你的觀看方式
    ↳ 觀察世界，你才能把「我看到的樣子」傳達給別人。而反覆寫生，也會慢慢改變你看東西的方式。
  • 07:44 引用名言：「learning to draw is learning to see」（學畫就是學看）
    ↳ 這句話的意思是，畫畫的功夫多半不在手，而在眼睛。你得先真正看懂東西，才畫得出來。
  • 07:44 講者隨身帶速寫本，用鋼筆墨水直接畫、不打底稿，看到有趣的東西就隨手畫
    ↳ 講者隨身帶速寫本，看到有趣的東西就直接用鋼筆畫，不先打鉛筆稿。這樣畫錯也擦不掉，逼自己下筆前先想清楚。
  • 08:15 每次畫都得決定要放什麼、不放什麼、怎麼傳達、想說什麼故事，這些都在鍛鍊大腦
    ↳ 每畫一張，都要決定哪些放、哪些省、怎麼表達、想講什麼。這些取捨做多了，判斷力就練起來了。
  • 08:15 重點不在完成的插畫，而像重量訓練：目的不是舉起重物，而是發展自己
    ↳ 畫出來的成品好不好看不重要。就像上健身房，目的不是把槓鈴舉起來，而是讓自己的肌肉變強。
  • 08:15 講者也常用照片參考畫動態姿勢（例如摔角），照片參考是很好的學習方式
    ↳ photo reference 就是照著照片畫。他也常這樣練，例如畫摔角選手的動作，因為照片能停住很快的瞬間，很適合學動態。
  • 08:45 但照片的主題、角度、構圖和拍攝時機都是別人選的；實地寫生能捕捉只有你看到的瞬間，傳達你自己的經驗
    ↳ 照片的題材、角度、構圖、按快門的時機都是攝影師決定的。你到現場寫生，抓到的才是你自己看到、自己經歷的那一刻。
  • 08:45 這些練習迫使講者思考形狀要怎麼在螢幕或任何影像上傳達
    ↳ 寫生時他得一直想：一個形狀要怎麼畫，放到螢幕或任何畫面上，別人才看得懂。
  • 09:20 寫生也迫使你有意圖、有意義地畫：在外面不知道有多少時間，所以要盡快把資訊記下來
    ↳ 在外面寫生，對象隨時會走掉，你不知道還有多少時間，只能先抓最重要的資訊。這會逼你下筆時很清楚自己在畫什麼。
  • 10:00 每條線都必須有意圖，像是可能是最後一筆，因此每條線都承載大量資訊
    ↳ 每一筆都當成最後一筆來畫，所以不能亂畫。結果每條線都得扛很多資訊。
  • 10:00 講者認為這和 AI art 相反：AI 能填上千個細節，但它們有意義、有意圖嗎？還是只是填滿空間？
    ↳ 講者拿 AI 生成圖當對照：AI 可以塞滿上千個細節，但那些細節有意義、是刻意放的嗎？還是只是把空白填滿？
  • 10:34 一些被打斷的速寫反而是講者最愛；時間更多的話加細節會變糟；被打斷只留下最重要的，每條線都是 load-bearing
    ↳ load-bearing 原本指承重，就像承重牆拆不得。畫到一半被打斷，只剩最關鍵的線條，反而最精彩；時間多了硬補細節，常常會畫壞。
  • 10:34 這直接影響講者在 Blender 的做法：他喜歡最佳化每一筆傳達的資訊量
    ↳ 寫生習慣直接影響他在 Blender 的做法：每做一個元素，都想用最少的東西傳達最多的資訊。
  • 10:34 例：屋頂他會做 tile shader，但瓦片屋頂不是畫面焦點，所以只用最低限度來表示
    ↳ shader 是決定物體表面長什麼樣子的設定。他會做瓦片的 shader，但屋頂不是畫面重點，所以只放剛好讓人認得出瓦片的量。
  • 11:04 窗戶也一樣：這樣做其實沒有比較省工，還有點繁瑣，但觀眾只接收必要資訊，得到很濃縮的體驗
    ↳ 窗戶也照同樣原則處理。這樣做其實沒比較省工，甚至更麻煩，但觀眾只接收到必要的資訊，看起來更精煉。
  • 11:04 月亮不是焦點，只是圖形元素：沒有線條、只有兩種顏色，沒畫滿隕石坑，也沒做 displacement shader
    ↳ 月亮只是畫面裡的圖形元素，所以沒描邊、只用兩個顏色。他沒畫滿坑洞，也沒用 displacement（真的把表面推出凹凸）做隕石坑。
  • 11:36 月亮只做到足以表示光線方向、形體體積和表面質感，讓人看出是月亮，沒有多餘的東西
    ↳ 這個月亮只交代三件事：光從哪來、它是顆球、表面大概什麼質感。看得出是月亮就夠了，其他一概不做。
  • 11:36 講者主張（他自稱有爭議）實地寫生對設計感的提升，大概超過任何單一技術技巧
    ↳ 他自己承認這說法會有人不同意：出門寫生對設計眼光的幫助，大概比學會任何一個軟體技巧都大。
  • 12:10 寫生也是很有用的製作工具；畫圖是最直接的造像方式，其他方式都得透過中介（本段到此結束）
    ↳ 寫生不只是練功，做案子時也很好用。畫畫是最直接產生畫面的方法，其他方式都隔了一層工具或流程。
📘 術語
NPR (non-photoreal rendering)（非寫實渲染）：任何不追求寫實的東西；講者詮釋為看起來像手繪的東西
showreel（作品集影片）：字幕說是工作室的作品混剪，其中 90% 是 Blender 專案
Eevee（Eevee 渲染引擎）：講者提供的檔案全部使用 Eevee，他說很適合他們的工作
viewport（視埠）：多數檔案在 viewport 裡就是所見即所得
compositing（合成）：字幕說檔案都在 Blender 內組裝，沒有外部合成
importer（匯入工具）：檔案中附有粗糙但可用的 importer
Creative Commons BY 4.0（創用 CC 姓名標示 4.0）：檔案採用的授權，可以拿內容去延伸、學習
screen space / world space（螢幕空間／世界空間）：講者說要讓畫面好看，應以 screen space 而非 world space 思考
nodes（節點）：字幕未解釋；只提到檔案裡有很多節點可以玩
grease pencil（Grease Pencil（蠟筆））：字幕未解釋；提到可用它和 mesh 互相驅動動畫
lattice deformer（晶格變形器）：講者的工具會從手繪 grease pencil 方框產生 lattice deformer
Ghibli cloud problem（吉卜力雲問題）：講者對 NPR 演講常見焦點的稱呼：試圖在 Blender 重現 Studio Ghibli 風格
photo reference（照片參考）：照著照片畫；適合學動態姿勢，但主題、角度、構圖、時機是別人選的
underdrawing（底稿）：講者的速寫是鋼筆墨水直接畫，沒有打底稿
load-bearing（承重的（每筆都有作用））：形容被打斷的速寫中，每條線都不可或缺
tile shader（瓦片著色器）：講者會做，但屋頂不是焦點，所以選擇只用最少筆觸表示
displacement shader（置換著色器）：畫月亮時沒有用它做隕石坑，只做足以辨識的程度
✏️ 小考一題

講者所說「提升 NPR 的一個怪招」，精髓是什麼？

A. 所有專案都改用 Eevee 並在 viewport 完成B. 走出去觀察真實的雲等事物並寫生C. 用手繪 grease pencil 方框產生 lattice deformerD. 用 screen space 取代 world space 思考
看答案
