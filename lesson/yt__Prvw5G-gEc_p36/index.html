    ↳ 接著請 Grokbot 派出多個 cloud agent，在雲端同時寫程式。想親自看時，把程式碼拉到自己電腦用 Cursor 檢查，沒問題就回 Grokbot 下一個 prompt（給 AI 的指令）。

📘 術語
cloud agent（雲端 agent）：Grokbot 派出去實際寫程式、建置專案，或調查修正 bug 的 agent
computer use（電腦操作）：講者靠它重現問題、做粗活、把 bug 修乾淨，自己再看程式碼
ephemeral bot（臨時 bot）：projects manager bot 依特定用途 spawn 的 bot，例如 researcher 或 coder
Kanban board（看板）：projects manager bot 用它管理任務，在 Notion 可看各任務和專案的狀態
marketplace（市集）：可取得 bot 並按 import 複製一份；ThursdayArena 的 bot 都出自這裡
tokens（代幣）：遊戲內貨幣，黃色按鈕改叫 tokens；開局 10 個，common bot 約 3 個
iteration loop（迭代循環）：講者認為做遊戲工作室的好處在這裡，用 Grokbot 建工廠能快速迭代
voice mode（語音模式）：用語音跟 bot 對話回報 bug，結束後可以看逐字稿
PR（合併請求）：修好廣告競價功能的 PR 還在進行中，合併後就能競價買廣告
ticker（跑馬燈）：畫面下方能看到誰在做什麼，被提議當作廣告位
xAI voice agent（xAI 語音 agent）：電話號碼背後的機制，用 xAI 的 custom voice agent builder 做，接上工具
guardrails（防護規則）：例如對方想玩 prompt 花招時，語音 agent 就直接掛斷
