🧑‍🏫 這支影片介紹 Codex 的新功能 Sites。Codex 是 OpenAI 用來幫忙寫程式的 AI 工具，現在不會寫程式的人也能請它做出內部用的小網頁 app，幾分鐘內就能分享給同事。如果你常在整理會議資料、做簡報或彙整專案文件，這支影片會讓你看到另一種做法。

  • 00:00 Codex 推出 Sites：團隊中任何人都能把想法變成安全的應用程式，並在幾分鐘內直接從 Codex 發布
    ↳ Sites 是 Codex 的新功能。你用說的描述想要什麼，Codex 就幫你做成一個有登入管控的網頁 app，幾分鐘就能上線給同事用。不是工程師也能做。
  • 00:00 OpenAI 內部用 Sites 做內部工具、mini apps，以及原本可能做成文件或簡報的可分享資源
    ↳ OpenAI 自己也在用，拿來做內部小工具和小型 app（mini apps），也用來取代以前會寫成文件或簡報的資料，改成大家點開就能看、能互動的網頁。
  • 00:00 Sites 內建 hosting、authentication、storage 和 database 支援，開箱即用
    ↳ 做網站原本要自己處理的事都內建了：hosting 是把網站放上網讓人連得到，authentication 是確認登入的人是誰，storage 用來存檔案，database 用來存整理好的資料。
  • 00:00 可透過 Codex plugins 和 skills，把團隊現有工具中的脈絡與分析帶進來
    ↳ Codex plugins 和 skills 是 Codex 的擴充功能，能讓它接上團隊平常用的工具，讀到裡面的資料和分析。這樣做出來的 app 內容才會符合實際狀況。
  • 00:31 請 Codex 建立應用程式並發布給其他人開啟，之後可用對話持續修改，不必架設基礎設施或寫部署程式碼
    ↳ 流程是：請 Codex 做、發布、分享給別人開。之後要改就再跟它講。不用自己架 infrastructure（伺服器這類底層設備），也不用寫 deployment code（把程式放上線的程式）。
  • 00:31 範例一 Account Lens：高階主管業務檢討前，帳戶團隊可看到客戶脈絡、核准的談話重點與財務指標圖表
    ↳ 範例 Account Lens：業務團隊和客戶高層開業務檢討會之前，打開一個頁面就能看到這個客戶的背景、公司核准過的談話重點，還有財務數字的圖表。
  • 00:31 這類聚焦的內部 app 可用可信任的資料建立，幫團隊準備會議
    ↳ 這種 app 的重點是「只為一件事而做」。資料來自團隊信得過的來源，大家開會前看同一頁準備，不用各自翻好幾份檔案。
  • 01:03 範例二：外部能源高峰會，整理議程、與會者、核准訊息、開場話題與行前計畫，讓所有參加者使用同一份資料
    ↳ 範例二是參加外部的能源高峰會。議程、出席名單、公司核准的說法、可以用來開啟對話的話題、行前安排都整理在一起，所有參加的人看的是同一份資料。
  • 01:03 範例三 Compass Memo：評估內部投資時，把提案、預算、guardrails、風險、審查者與證據集中成一份主管備忘錄
    ↳ 範例 Compass Memo：評估內部投資案時，把提案、預算、guardrails（事先定好不能越過的界線）、風險、審查者和佐證資料集中成一份主管備忘錄。
  • 01:36 主管能看出哪些事需要解決，不會漏掉細節
    ↳ 資料集中整理好之後，主管一眼就能看出哪些問題還沒解決，細節不會散在不同的信件或檔案裡被漏掉。
  • 01:36 其他可做的例子：預測 dashboard、onboarding hub、產品委員會簡報、互動式資料故事
    ↳ 其他用途還有：看預測數字的 dashboard（數據儀表板）、新人 onboarding（到職導覽）的入口頁、給產品委員會的簡報，以及可以點選互動的資料故事。
  • 01:36 Sites 可像 workspace 資產一樣分享與管理，能分享給特定使用者或整個 workspace
    ↳ 做好的 site 可以像 workspace 裡其他資產一樣管理。workspace 是公司在 ChatGPT 上的團隊共用空間。可以只分享給特定幾個人，也可以開放給整個 workspace。
  • 01:36 檢視者只要用 ChatGPT 帳號登入即可開啟 site
    ↳ 看的人只要用 ChatGPT 帳號登入就能打開 site，不用另外裝軟體或申請帳號。登入這一步也確保只有被分享到的人看得到內容。
📘 術語
Sites（Sites（Codex 功能））：在 Codex 中把想法做成安全應用程式並在幾分鐘內發布的功能
hosting（主機代管）：Sites 開箱即提供的支援之一
authentication（身分驗證）：Sites 開箱即提供的支援之一；檢視者以 ChatGPT 帳號登入
storage（儲存空間）：Sites 開箱即提供的支援之一
database（資料庫）：Sites 開箱即提供的支援之一
Codex plugins and skills（Codex 外掛與技能）：用來把團隊現有工具中的脈絡與分析帶進 Codex
infrastructure（基礎設施）：使用 Sites 迭代應用程式時不需要自行架設
deployment code（部署程式碼）：使用 Sites 時不需要撰寫
workspace（工作區）：Sites 可像 workspace 資產一樣管理，並可分享給整個 workspace
