🧑‍🏫 這一段是 Grok 節目主持人和金流公司 Stripe 的來賓聊天，主題是 AI 不只幫你想事情，也開始幫你付錢買東西、管錢。雖然有一段現場示範沒成功，但片中有很多真實的生活用法，像是讓 AI 買鞋、送生日禮物、寄紙本信、盯住外食預算。想知道 AI 助理下一步會怎麼走進日常生活，這段很值得看。

  • 344:10 消費者在 AI 訂閱上的支出（例如 Grokbot、OpenAI、Muse）過去幾年穩定增加
    ↳ 這幾年大家花在 AI 訂閱的錢一直增加，像 Grokbot、OpenAI（做 ChatGPT 的公司）、Muse 這類月費服務。AI 已經從嘗鮮變成固定開銷。
  • 344:40 今年起，每月花超過 100 美元買 AI 產品的人數成長約 5 倍；原因是不必有深厚工程背景也能 build、create 東西
    ↳ 今年起，每月在 AI 上花超過 100 美元（約台幣三千多）的人多了大約 5 倍。原因是不會寫程式的人，也能靠 AI 做出工具和作品，所以覺得值得。
  • 345:12 企業端新創和大型 lab 大量出現；Stripe 最近開始和 metronome 合作，越來越多 AI 公司考慮採用 usage-based billing（UBB）
    ↳ 企業這邊，AI 新創和大型 lab（開發大模型的研究機構）越來越多。Stripe（很多網站在用的線上收款公司）最近和 metronome 合作，因為越來越多 AI 公司想改用 UBB（usage-based billing，按用量計費，用多少付多少）。
  • 345:12 講者好奇 UBB 會不會擴展到消費者端：他自己的訂閱都能加購 credits，把任務做完
    ↳ 講者好奇這種收費方式會不會也用到一般消費者身上。其實已經看得到：他的訂閱額度用完時，可以加買 credits（額外點數），把手上的任務跑完。
  • 345:44 Stripe 目前的重點工作之一是幫 AI 公司處理 risk 和 fraud：確認訂閱者是正常用戶，並降低詐騙
    ↳ Stripe 現在很重要的一項工作，是幫 AI 公司處理 risk and fraud（風險和詐騙），也就是確認付錢訂閱的是正常的真人用戶，減少盜刷、詐騙帳號。
  • 346:18 Stripe 上已經有 Grok connector，內含 Stripe best practices（建立整合）、Stripe directories（找商家）、Stripe projects（佈建服務）
    ↳ Stripe 已經做好給 Grok 用的 connector（連接器，讓 AI 能直接操作某個服務）。裡面有三塊：教 AI 正確串接 Stripe、幫忙找商家、幫忙開通要用的服務。
  • 346:18 把 Stripe connector 接上後，指派一個 Grokbot 去設定訂閱，應該就能完成
    ↳ 意思是只要把這個 connector 接上，跟 Grokbot 說一聲「幫我設定訂閱收費」，它應該就能自己把整套流程做完，你不用自己研究金流設定。
  • 346:52 這天下午的 stretch goal：讓節目做的遊戲賺到第一塊錢
    ↳ 當天下午的 stretch goal（加碼目標，做到最好，做不到也沒關係）是：讓節目現場做出來的遊戲真的收到第一筆錢，證明從做東西到收錢都能靠 AI 完成。
  • 347:22 主持人想現場示範 Link，但不想露出信用卡號和個資，所以請製作團隊先切到廣角鏡頭，暫時不顯示螢幕
    ↳ 主持人想現場示範 Link，但操作時會露出信用卡號和個資，所以先請導播切到廣角鏡頭，暫時不讓觀眾看到螢幕畫面。
  • 347:22 Link 目前的重點是幫 agents 買需要的東西，不管是個人用品還是為了經營事業
    ↳ Link 是 Stripe 的付款工具，現在主打讓 agent（能替你動手辦事的 AI 助理）自己去買需要的東西，不管是個人用品，還是做生意要用的東西。
  • 348:00 具體做法：幫 agents 看懂 checkout forms，並能在 Stripe merchants 無摩擦購買；一開始只開放美國，其他國家陸續推出
    ↳ 做法是讓 agent 看懂 checkout forms（結帳頁要填的表單），在用 Stripe 收款的商店順利買完、不卡關。目前只開放美國，其他國家之後陸續上線。
  • 348:00 financial insights：讓 Grok 匯入信用卡和銀行資料來處理個人理財；做生意的人也可以連接商業帳戶
    ↳ financial insights（財務分析）是讓 Grok 讀取你的信用卡和銀行資料，幫你整理花費、管理個人財務。做生意的人也可以把公司帳戶接進來。
  • 348:34 商業帳戶的例子：agent 發現信用卡額度快用完時提醒你，並建議怎麼優化你的事業
    ↳ 公司帳戶的例子：agent 發現公司信用卡額度快刷滿時，會先提醒你，還會根據帳上的資料，建議生意哪裡可以調整得更好。
  • 348:34 主持人有一個 GROC agent 專門管個人理財，幫忙記住容易忘記的帳單和稅務事項
    ↳ 主持人有一個專門管個人財務的 Grok agent，負責記住那些很容易忘記的繳費期限和報稅事項，免得逾期或漏掉。
  • 349:04 因為手上有資料，agent 可以設定排程或 routine，例如每週回報一次帳戶餘額
    ↳ 因為 agent 看得到帳戶資料，就能設定 routine（固定時間自動執行的例行任務），例如每週自動回報一次各帳戶還剩多少錢，不用自己登入網銀查。
  • 349:04 if this then that 的例子：這個月外食花超過 X 美元就通知我，幫我守住預算
    ↳ if this then that（「如果發生 A，就做 B」的自動規則）的例子：這個月外食花超過某個金額就通知我。還沒超支就先收到提醒，比月底看帳單才後悔有用。
  • 349:04 來賓的設定：一週運動次數不夠，就讓 Link 代他捐款給慈善機構
    ↳ 來賓的玩法：一週運動次數沒達標，就讓 Link 自動捐一筆錢給慈善機構。用「會心痛的懲罰」逼自己去運動，錢也不會白白浪費。
  • 349:40 主持人問最特別的 Link 用例，提到之前聽過一個跟 parking ticket 有關的例子
    ↳ 主持人問來賓看過最特別的 Link 用法，提到之前聽過一個跟 parking ticket（停車罰單）有關的例子，不過這段沒有細講是怎麼做的。
  • 350:16 來賓很驚訝大家這麼快就願意讓 Grokbot 處理重大購買，例如訂機票、旅遊；他認為關鍵是有 approval steps，而且 agent 很會用瀏覽器
    ↳ 來賓很意外，大家這麼快就敢讓 Grokbot 訂機票、安排旅遊這種大額消費。來賓認為關鍵有兩個：付錢前有 approval steps（要你按確認才會付款），而且 agent 很會操作瀏覽器。
  • 350:16 主持人說在 X 上看到有人用 Link 預購 Tesla
    ↳ 主持人說在 X（以前叫 Twitter）上看到有人用 Link 預購 Tesla。連買車這麼大的訂單，都已經有人交給 agent 去下了。
  • 350:48 現場示範沒成功：這台電腦（或這個 profile）可能還沒設定 passkey；原本想捐 1 美元給 Stripe Climate，後來改成向 Nike 買鞋
    ↳ 現場示範沒成功，可能是這台電腦或這個 profile（瀏覽器的使用者設定檔）還沒設好 passkey（用指紋、臉部等解鎖來代替密碼的登入方式）。原本想捐 1 美元給 Stripe Climate，後來改成向 Nike 買鞋。
  • 351:26 製作團隊成員現在穿的鞋就是用 Grokbot 買的；示範方式是拍鞋子照片，請它找同款 size 12
    ↳ 製作團隊有人現在穿的鞋就是 Grokbot 買的。做法很簡單：拍一張鞋子的照片給它，說「找同一款、size 12」（美國尺碼），它就會去找。
  • 351:58 講者曾對 agent 說「買現在熱門的男鞋，size 12，你挑」，三天後收到貨，雖然不知道是什麼鞋但很喜歡
    ↳ 講者曾經只跟 agent 說「買現在熱門的男鞋，size 12，你幫我挑」，三天後就收到貨。雖然不知道是什麼鞋，但很喜歡。也就是說，連「挑哪一雙」都能交給它決定。
  • 351:58 產品點子：每週一次驚喜購物，例如給 agent 100 美元，讓它幫你買禮物
    ↳ 由此想到一個產品點子：每週一次驚喜購物。例如給 agent 100 美元的預算，讓它自己決定買一份禮物，你收到才知道是什麼。
  • 351:58 同事把家人生日都輸入進去，生日前兩週讓 agent 建議禮物，選好後由 Link 直接購買
    ↳ 有同事把家人的生日都輸入進去，agent 會在生日前兩週建議禮物，同事選好之後，由 Link 直接下單付款，不會再忘記或臨時手忙腳亂。
  • 352:32 Grokbot 團隊收到許多回饋：bot 已經在管生活、財務、任務和 email，再接上付款功能很好用
    ↳ Grokbot 團隊收到很多回饋：bot 本來就在幫忙管生活、財務、待辦事項和 email，再加上能付錢，就從「提醒你去做」變成「直接幫你做完」。

    ↳ 前幾天節目上有位創作者分享了很多讓 bot 走出螢幕的用法，例如每天早上讓印表機印出當天的 newsletter（電子報），當成實體報紙來讀。
  • 353:33 講者家牆上有一台 32 吋顯示器，以前要自己寫 custom code；之後打算讓 bots 自由放提醒、笑話、當日新聞，完成後會發在 X 上
    ↳ 講者家牆上有一台 32 吋螢幕，以前想放什麼內容都得自己寫程式。之後打算讓 bots 自己決定要放提醒、笑話還是當日新聞，做好會發在 X 上。
  • 354:09 來賓的個人 Grokbot：shopper bot（買鞋、T 恤，因為他討厭逛街）、finance bot（看支出是否合理）、規劃週年紀念週末的 bot
    ↳ 來賓自己有好幾個分工的 Grokbot：shopper bot 負責買鞋和 T 恤（因為來賓很討厭逛街）、finance bot 檢查花費合不合理，還有一個專門規劃週年紀念的週末。

    ↳ 個人專案一：讓一個 bot 用 3GS（字幕原文如此）做遊戲，目標是一個可以在裡面走動、地圖無限延伸的世界。

📘 術語
usage-based billing (UBB)（用量計費）：越來越多 AI 公司考慮的收費模式；講者舉例：訂閱之外還能加購 credits 把任務做完
credits（額度點數）：訂閱之外可以額外購買的額度，用來完成任務
risk and fraud（風險與詐騙）：Stripe 幫 AI 公司確認訂閱者是正常用戶，並降低詐騙
connector（連接器）：Stripe 上的 Grok connector，接上後就能讓 Grokbot 設定訂閱
Link（Link（付款服務））：幫 agents 買需要的東西，能看懂 checkout forms，並在 Stripe merchants 無摩擦購買
checkout forms（結帳表單）：Link 協助 agents 理解並使用的購物結帳表單
financial insights（財務洞察）：讓 Grok 匯入信用卡和銀行資料，處理個人理財或企業財務
routine（例行排程）：agent 可以設定的排程，例如每週回報一次餘額
if this then that（條件觸發規則）：例如這個月外食超過 X 美元就通知我
approval steps（核准步驟）：Grokbot 裡的購買確認步驟，來賓認為這是大家敢讓它訂機票的原因之一
passkey（通行金鑰）：示範時可能還沒在這台電腦或 profile 設好，所以購買沒成功
spin up（快速建立）：想到重複要做的任務時，就快速建立一個 bot 去處理
