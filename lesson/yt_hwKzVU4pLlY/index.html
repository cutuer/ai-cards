  • 00:00 Muse 是 Meta 宣傳已久的全新個人 AI agent
    ↳ Muse 是 Meta 預告很久的個人 AI agent。AI agent 就是能替你到別的 app 動手辦事的 AI，不只是陪你聊天、給答案。
  • 00:00 Muse 能訂行程、購物、預約、打電話、幫你在網路上發文，手機上其他 app 能做的動作幾乎都能代勞
    ↳ 你平常在手機上點來點去完成的事，例如訂行程、買東西、約時間、打電話、發貼文，Muse 幾乎都想接手替你做。
  • 00:00 過去幾年大家用 ChatGPT 等生成式 AI app，多半是提問、它回覆，屬於傳統聊天機器人體驗
    ↳ 過去幾年大家熟悉的 ChatGPT 屬於生成式 AI（generative AI），也就是你問、它生出內容回你。回答完之後，事情還是得你自己去做。

    ↳ 業界現在的方向叫 agentic behavior，意思是 AI 從「給答案」變成「去做事」。例如它不只推薦餐廳，還直接幫你訂位。

    ↳ ChatGPT 和 Claude 也有 agent，靠 connectors（把 AI 接上其他 app 的功能）去操作別的服務，不過主要瞄準公司和工作上的用途。

    ↳ Meta 則是第一家真正把 agent 主打給一般人日常生活用的公司。這跟它的背景有關，Meta 本來就是做 Facebook、Instagram 這類大眾社群產品的。

    ↳ 既然要交出這麼多個人資料，Meta 特別強調安全，向使用者保證你給 agent 的資訊都會被妥善保管。

    ↳ 旁邊還有一個叫 Sentinel 的模型專門盯著主 agent，確認它沒會錯你的意思。遇到付錢這類高風險動作，它也會特別檢查。

    ↳ 缺點也很大：你等於把幾乎整個數位生活交給一個 agent，而它背後的技術目前還不算可靠。

    ↳ 生成式 AI 會出現 hallucination，也就是一本正經地講出不實的資訊。它也可能犯錯或誤解你的意思，所以替你動手時就可能做錯事。

📘 術語
AI agent（AI 代理）：能代替你到其他 app 執行動作的 AI，例如訂行程、購物、打電話
generative AI（生成式 AI）：像 ChatGPT 這類 app，你提問、它回傳回應
agentic behavior（代理式行為）：agent 不只回答問題，而是到另一個 app 代你採取行動
connectors（連接器）：讓 agent 連到其他 app 的功能；ChatGPT、Claude 的偏工作用途
secure virtual machine（安全虛擬機）：Meta 維護的雲端專用電腦，用來隔離每個人的 session，主 agent 住在裡面
session（工作階段）：字幕只說 virtual machine 設計用來讓大家的 session 彼此隔離
Sentinel（哨兵（模型名））：另一個監看主 agent 的模型，確認照使用者意思做並檢查高風險動作
authorization credentials（授權憑證）：和密碼一樣屬敏感資料，存在獨立區塊
hallucinations（幻覺）：生成式 AI 捏造不實資訊
