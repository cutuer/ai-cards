🧑‍🏫 這支影片介紹 Codex（OpenAI 協助寫程式的 AI 工具）新推出的 plugin 分享功能。你可以把自己做好的工具分給同事，也能收到同事分享的工具，還可以用一條網址直接打開。對常跟團隊合作的人來說，好用的做法不用再各自重做一遍。

  • 00:00 Codex 推出 plugin sharing（plugin 分享）功能，讓你能輕鬆把 plugin 分享給一起工作的人。
    ↳ plugin 是打包好、可以重複使用的功能套件。新功能讓你把自己做的 plugin 直接分給一起工作的同事用。
  • 00:00 示範用的例子是講者自己做的 first week quest plugin：在 plugin directory 找到它、點進去，就能看到它可用的 default prompts。
    ↳ 講者用自己做的 first week quest 示範。plugin directory 就是放 plugin 的清單頁，點進去會看到 default prompts，也就是它預先寫好、直接點就能用的指令。
  • 00:00 要分享給隊友時點 share 按鈕，會跳出 modal，可以指定要分享給誰，也可以改成 anyone in the workspace。
    ↳ 要分享就按 share，畫面上會跳出 modal（蓋在畫面上的小視窗）。你可以指定幾個人，也可以選 anyone in the workspace，讓整個團隊共用空間（workspace）的人都能用。
  • 00:30 按下 save 後，這個 plugin 就分享給 workspace 裡的所有人了。
    ↳ 設定好之後要按 save 才會生效。之後同一個 workspace 的人都拿得到這個 plugin，不用一個一個傳給大家。
  • 00:30 可以複製連結傳給團隊，隊友會在他們自己的 plugin directory 裡看到這個 plugin。
    ↳ 你也可以複製連結丟到團隊群組通知大家。隊友打開自己的 plugin directory，就會看到你分享的這個 plugin。
  • 00:30 分享也能反過來用：回到 plugins directory 的 shared with you 分頁，可以看到隊友分享給你的所有 plugin。
    ↳ 分享也能反過來看。同事分享給你的 plugin 都集中在 plugins directory 的 shared with you 分頁，想找同事做好的工具，先來這裡看。
  • 00:30 舉例：finalize code plugin，在完成 PR 之前很有用，可以拿來做驗證（validation）和程式碼重構（code refactoring）。
    ↳ 例如 finalize code 這個 plugin，適合在 PR（把改好的程式碼提交給別人審核的請求）完成前跑一次。它會檢查有沒有問題，也會做 code refactoring，也就是不改功能、只把程式碼整理乾淨。
  • 01:02 finalize code plugin 也能確保 PR 在送審（review）前處於很好的狀態。
    ↳ 它的用處是讓你在送審前先自己檢查一輪，審核的人拿到的是整理好的版本，而不是半成品。
  • 01:02 Codex 也為 curated directory 加入 share URLs，可以直接傳 plugin 頁面給對方，不必讓對方自己去搜尋。
    ↳ curated directory 字面意思是經過挑選整理的 plugin 目錄。現在裡面每個 plugin 頁面都有 share URL（專屬網址），直接貼給對方就能打開，不用對方自己搜尋。
  • 01:02 以 Slack 為例：複製連結、在 Chrome 開啟並貼上網址，就會 deep link 直接開進 Codex。
    ↳ 示範中從 Slack 複製連結，貼到 Chrome 瀏覽器打開，就會直接開進 Codex。這種連結叫 deep link，意思是能直接打開 App 裡特定位置的連結。
  • 01:02 核心概念：你為團隊做的 workflow 不必只留在自己的電腦上。某個 plugin 對一位隊友有幫助就分享出去；別人分享給你的，會出現在你需要的地方。
    ↳ 核心想法是：你摸索出來的做事流程（workflow）不該只留在自己電腦裡。覺得對某個同事有用就分享出去，別人分享給你的，也會出現在你需要的地方。
📘 術語
plugin（外掛）：字幕未直接定義；示範中可在 Codex 分享給隊友、查看其 default prompts 的功能套件。
plugin directory（plugin 目錄）：在這裡可以找到自己做的 plugin；隊友收到分享後，也會在自己的 directory 看到。
default prompts（預設提示詞）：點進 plugin 後能看到它提供的預設 prompts。
modal（彈出視窗）：點 share 按鈕後出現的視窗，用來指定要分享給誰。
workspace（工作區）：分享對象可設為 anyone in the workspace，儲存後 workspace 裡的人都能取得。
shared with you（與你分享）：plugins directory 裡的分頁，列出隊友分享給你的所有 plugin。
PR（PR）：字幕未定義；提到 finalize code plugin 適合在完成 PR 前、送審前使用。
code refactoring（程式碼重構）：字幕未定義；列為 finalize code plugin 可以做的事之一，與 validation 並列。
curated directory（精選目錄）：字幕未定義；Codex 為它加入 share URLs，可以直接分享特定 plugin 頁面。
share URL（分享網址）：可以把特定 plugin 頁面直接傳給別人，對方不用自己搜尋。
deep link（深層連結）：在 Chrome 貼上分享網址後，會直接連進 Codex。
✏️ 小考一題

影片以 Slack 為例示範 curated directory 的 share URL。把複製的連結貼到 Chrome 之後會發生什麼事？

A. 自動下載 plugin 安裝檔B. 跳到搜尋頁，讓對方自己搜尋 pluginC. 直接 deep link 開進 CodexD. 在 Chrome 裡開啟 Slack 網頁版
看答案
答案：C。[01:02] 講者複製連結、在 Chrome 貼上網址後說 "it deep links directly into Codex"。同一段也提到 share URLs 的用意是傳送確切的 plugin 頁面，"instead of making them search"。
