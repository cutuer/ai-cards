看全部 5 條重點

🧑‍🏫 這支是 OpenAI 發表 GPT-5.5 時的官方影片，由 NVIDIA 一位工程師分享他實際用 Codex 和 GPT 5.5 做軟體的經驗。值得看的是，他講的是真實做出來的東西，還有他對這個模型的信任從哪裡來，不只是規格介紹。

  • 00:03 NVIDIA coding agents 團隊的資深軟體工程師 Dennis Hannish 說，GPT 5.5 的超能力是「能把事情做完」。
    ↳ Dennis Hannish 在 NVIDIA 做 coding agents，也就是能自己寫程式、自己執行的 AI 助手。他說 GPT 5.5 最大的長處是交代的事會一路做到完成，不會做到一半停下來等你收尾。
  • 00:03 他這週用 Codex desktop app 做出 podcast 錄製軟體，可以存下錄影和錄音，不必再用第三方服務錄 podcast。
    ↳ Codex 是 OpenAI 的寫程式 AI 工具，desktop app 是裝在電腦上的版本。他這一週就用它做出自己的 podcast 錄製軟體，能存錄影和錄音，不必再靠外面的服務來錄。
  • 00:03 他認為 Codex 和 GPT 5.5 拉高了「什麼值得動手做」的門檻。
    ↳ 意思是：有 AI 幫忙之後，做一個東西的成本變低。以前覺得太費工、不划算而放著的點子，現在變得值得動手，能做的東西也可以更有野心。
  • 00:34 他先用 GPT 5.4 做出內部平台的 MVP，再用 Codex GPT 5.5 把它推到 production 等級、可擴展的 app。
    ↳ MVP 是先做出能用的陽春初版，用來驗證想法。production 等級是可以正式上線給大家用的品質，可擴展是指使用者變多也撐得住。他分兩步：先做初版，再用新模型把它做成正式產品。
  • 00:34 他更信任 GPT 5.5 了，因為它會主動指出他交代範圍以外的 bug 和缺漏。
    ↳ bug 就是程式裡的錯誤。他沒叫 GPT 5.5 檢查的地方，它也會主動說哪裡有錯、哪裡漏了。因為它不只照字面做事，他才更放心把事情交給它。
📘 術語
MVP（最小可行產品）：字幕中指他先用 GPT 5.4 做出的內部平台初版，之後再推到 production 等級
Codex desktop app（Codex 桌面版應用程式）：講者用來做出 podcast 錄製軟體的工具
✏️ 小考一題

Dennis Hannish 說他這週用 Codex desktop app 做出了什麼？

看答案
答案：D。[00:03] 他說這週用 Codex desktop app 做出 podcast 錄製軟體，會存下錄影和錄音，這樣就不必用第三方服務錄 podcast。
