💡 你可以怎麼用：你可以學 1Password 的 skills 做法，把自己常用的工作規範（例如公司的品牌用語、報帳規定）整理成一份固定指示，每次交給 AI，讓它照你的標準做事。下次有新點子時，也可以試著在同一段對話裡，從構想一路做到能直接用的初稿。

🧑‍🏫 這支影片是 1Password（做密碼管理的資安公司）分享他們怎麼在公司裡用 OpenAI 的工具：一邊讓財務、行銷這些非工程同事用，一邊讓工程師用 Codex 加快開發。值得看的地方是，它講的是一家注重資安的公司實際怎麼導入 AI，不只是展示功能。

  • 00:01 許多工程師覺得最大的收穫，是從規劃到在 production 看到功能上線的週期被縮短了
    ↳ production 是真正給使用者用的線上環境。工程師最有感的不是 AI 幫忙寫了幾行程式，而是從開始規劃到功能真的上線，整段時間變短了。
  • 00:01 OpenAI 提供很多種與模型互動的方式
    ↳ 同一個模型有好幾個入口：聊天介面、寫程式用的 Codex（OpenAI 的程式開發助手），或是 API（讓程式直接呼叫模型的接口）。不同角色可以挑最順手的入口來用。
  • 00:01 知識工作者方面，講者團隊也負責推廣給財務、行銷等團隊；對這些人來說，chat 介面用起來很自然
    ↳ 講者團隊除了服務工程師，也負責把 AI 推廣給財務、行銷等部門。這些同事不寫程式，所以像傳訊息一樣的 chat 介面最容易上手。
  • 00:01 現在可以 one shot，從點子到 prototype，一路做到能在 production 完整運作的成品
    ↳ one shot 指一口氣做完：從點子做出 prototype（可以先看、先試的雛型），再一路做到正式上線、真的能用，中間不必停下來分好幾輪重做。
  • 00:31 對他們來說，建立 AppSec skills 是一大突破：把公司的資安政策與資安態勢寫進 skills 裡，對資安公司尤其重要
    ↳ skills 可以想成寫給 AI 的固定工作守則，AppSec 指應用程式的資安。他們把公司的資安規定和目前的防護狀況寫進 skills，AI 做事就會照公司標準走。對資安公司來說，這點特別重要。
  • 00:31 工程方面，他們剛開始一個專案：打造內部的 AI SRE agent，會完全透過 API 來建構
    ↳ SRE 是負責讓系統穩定、不出包的工程工作，agent 則是能自己執行任務的 AI 助手。他們剛開始打造內部用的 AI SRE agent，而且全部透過 API 來做，影片沒有再多談細節。
  • 00:31 具體到 Codex，它幫助團隊更快完成功能上線
    ↳ Codex 在這裡的作用很直接：幫工程團隊更快把功能做完、推上線，也呼應第 1 點提到的週期縮短。
  • 00:31 如果能加快「顧客回饋到快速修改 UI」這個 feedback loop，就能提升顧客 CSAT，對業務也有很多幫助
    ↳ feedback loop 指「顧客反映問題 → 修改畫面 → 再交給顧客用」這個循環，CSAT 是顧客滿意度分數。這個循環跑得越快，顧客滿意度就越高，對生意也有幫助。
📘 術語
one shot（一次到位）：從點子到 prototype，再到能在 production 完整運作，一次完成
production（正式環境）：字幕指功能實際上線、可以看到並運作的地方
prototype（原型）：字幕提到的流程：點子 → prototype → 正式運作的成品
AppSec skills（應用程式資安技能）：把公司的資安政策與資安態勢寫進 skills 裡
AI SRE agent（AI 網站可靠性工程代理）：字幕只說是內部剛啟動的專案，會透過 API 建構，未進一步解釋
feedback loop（回饋循環）：從顧客回饋到快速修改 UI 的流程
CSAT（顧客滿意度）：字幕說加快 feedback loop 能提升顧客 CSAT，未另外解釋
