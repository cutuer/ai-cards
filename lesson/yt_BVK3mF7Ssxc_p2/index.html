📘 術語
reference（參考素材）：放進 prompt 當參考的影片或圖片，例如用 slash 選擇影片作為續拍參考
walk-through（導覽影片）：逐一走進各房間介紹的影片，字幕以房屋物件和樹屋室內為例
green screen（綠幕）：人物在前、背景放其他畫面的影片。字幕中是網紅在前，背後是社群頁面截圖
CapCut（CapCut（剪輯工具））：作者用它內建的一鍵去背按鈕移除影片背景
AI avatar（AI 虛擬人物）：AI 生成的網紅角色，字幕說它的表現看起來像真人
street interview（街頭訪問）：一種廣告風格，字幕中是路上訪問路人對品牌的看法
ASMR（ASMR）：字幕中的做法是不放音樂、麥克風增益調高、網紅輕聲細語地開箱
mic gain（麥克風增益）：ASMR prompt 中要求調高（high mic gain）
claymation（黏土動畫）：與 Pixar 風並列的卡通廣告風格，常見於保健食品、製藥品牌
Nano Banana 2（Nano Banana 2）：作者在 Arc Ads 裡用來改圖、生成參考圖的工具，例如換品牌名、加樹屋
time-lapse（縮時影片）：呈現施工或居家改造過程的影片，字幕以樹屋建造為例
API（API（應用程式介面））：Claude Code 透過它串接 Arc Ads AI，上傳 prompt 並處理影片
custom GPT（自訂 GPT）：作者以前的做法，放入 prompting 準則，再在聊天和 Arc Ads 之間來回切換
GitHub repo（GitHub 儲存庫）：作者發布完整 Claude Code agent 和 skills 的地方，複製網址即可使用
