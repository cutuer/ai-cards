🧑‍🏫 這支影片示範一個工作流程：看到一支別人投放成效好的影片廣告，直接丟給 Claude Code（Anthropic 推出、可以用打字指揮它在電腦上做事的 AI 助理），它會拆解原片、寫好台詞，再透過 Arc ads 生成一支你自家產品的版本。值得看的原因是，整個過程你幾乎只要挑影片、給產品圖、確認台詞，剩下的拆解、生成、剪接都由 AI 處理。

    ↳ 先看成果：用 C Dance 2.0（字幕裡的影片生成模型名稱）在 Arc ads（實際產出影片、會扣點數的平台）做出一支帽子廣告，演員邊展示邊講賣點，長度 10 秒。
  • 40:26 也可以做 15 秒版本，或做成多支接續的影片，延伸到原片約 36 秒的長度，列出更多功能
    ↳ 10 秒不夠講完也沒關係，可以改做 15 秒，或做好幾段接起來，拉到跟原片差不多的 36 秒，就能塞進更多產品賣點。

📘 術語
Arc ads（Arc ads 平台）：實際生成影片的平台，生成會扣 credits；給 Claude code API key 後可使用它的功能
Inspo tab（靈感分頁）：Motion 裡的功能，可依視覺格式瀏覽各種風格的廣告範例
testimonial（見證型廣告）：Inspo 分頁中的一種廣告格式，點選後會列出所有見證型廣告
days active（投放天數）：篩選條件；投放 3 個月的廣告比較可能是表現最好的廣告
Whisper（Whisper 語音轉文字）：Claude code 複製影片時用來轉錄音訊
session（工作階段）：在 Claude code 開新 session，就能同時讓另一個 agent 做另一支廣告
problem payoff（問題／解答兩段式）：壓縮影片時的選項之一，把廣告拆成兩段系列
beat map（節奏拆解圖）：它把原影片的敘事、鏡頭、場景、語氣拆解出來，等於把影片變成公式
AI creative strategist（AI 創意策略師）：作者形容用 Claude code 的感覺，像跟員工即時反覆調整產出
credits（點數）：Arc ads 的計費單位，送出前它會先列出預估花費
UGC（UGC）：字幕沒有定義，用來形容演員在沙發、浴室、有瑕疵的自然樣貌
stitch（拼接）：把兩段生成的影片接成一支，示範的結果是 30 秒版本
API key（API 金鑰）：提供之後，就能用這套工具操作 Arc Ads 的功能
reference audio（參考音訊）：上傳自己錄的聲音，讓 AI 角色一字不差說出同樣的內容
