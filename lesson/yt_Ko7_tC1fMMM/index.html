📘 術語
Remote Control（遠端控制）：讓 Claude Code web 或 Claude mobile app 連到你電腦上執行中的 Claude Code session
session（工作階段）：字幕沒有定義，只說是在你電腦上執行、可以從其他裝置接續的 Claude Code 對話
Claude Code web（Claude Code 網頁版）：可以用 Remote Control 給的網址連進 session 的網頁介面
QR code（QR 碼）：按空白鍵後出現，用手機掃描就能在手機上開啟 session
MCP servers（MCP 伺服器）：字幕沒有解釋，只說遠端連線時還是能用同樣的 MCP servers
/config（設定指令）：可以在這裡設定讓所有 session 都啟用 Remote Control
spawn mode（生成模式）：從遠端建立新的 session，可以開多個 Claude Code instance
environment button（environment 按鈕）：在 Claude web 或手機上點它來選擇你的裝置
✏️ 小考一題

用 Remote Control 從手機連上 Claude Code session 時，程式實際上是在哪裡執行？

A. 整個 session 會搬到 Anthropic 的雲端伺服器上執行B. 檔案系統留在電腦上，工具和 MCP servers 改在雲端執行C. 還是在你自己的電腦上，沒有任何東西搬到雲端D. 改在手機上的 Claude app 裡執行

答案：C。[01:07]–[01:37] 字幕說：Everything is still running on your machine. Nothing is moved to the cloud.
