🧑‍🏫 這支影片是幾位開發者分享試用 GPT-6 Astra 的第一印象，用三個實際例子展示它的能力：做出 3D 歷史倫敦、設計網站、破解解謎比賽。值得看的原因是，新模型不只回答得更準，還能從頭到尾完成一整套又長又複雜的工作。

  • 00:00 開發者覺得 Astra 更聰明，能做到很多以前做不到的工作流程
    ↳ 開發者試用後的第一個感覺是 Astra 更聰明了。更大的差別是，以前要拆成很多步驟、還常常做到一半卡住的工作，現在它能整套做完。
  • 00:00 範例一：用 voxel 做出歷史上的倫敦 3D 模型，涵蓋中世紀、Tudor 等不同時代，而且都在同一張地圖裡轉換
    ↳ voxel（體素）就是把 3D 畫面拆成一顆顆小方塊堆起來，很像樂高或 Minecraft。開發者用它堆出中世紀、都鐸王朝等不同時代的倫敦，而且都能在同一張地圖裡切換。
  • 00:00 這個倫敦模型可以實際玩，同一個角色可以一路玩到現代
    ↳ 這個倫敦不只能看，還能實際玩。同一個角色可以從古代一路走到現代，所以模型做出來的其實是一個能互動的小世界。
  • 00:31 只多下幾個 prompt 就把視角改成俯瞰，看起來像 GTA 2，變成一個真的能跑的模擬／遊戲
    ↳ prompt 就是你打給 AI 的指令。開發者只多下了幾句，就把畫面改成從上往下看，很像老遊戲 GTA 2，變成真的能跑的遊戲。可見要大改一個作品，花的力氣很小。
  • 00:31 範例二：請它設計抹茶店網站，照片放在正中央、周圍加圓圈，它還為這張照片的生成寫了很有意思的 prompt
    ↳ 第二個例子是抹茶店網站，要求把照片放在正中央、周圍加圓圈。它除了排版，還自己寫了一段用來生成那張照片的指令，連素材要怎麼做都一起想好了。
  • 01:02 它還做出另一個完全不同的版本，也會想到使用者自己想不到的點子，可以當成新的靈感來源
    ↳ 它還主動做了一個風格完全不同的版本，裡面有使用者自己沒想到的點子。所以它不只是照指令做事的工具，也可以是幫你想點子的夥伴。
  • 01:02 範例三：DEF CON 大會的解謎挑戰，開發者和朋友花了好幾天才解
    ↳ DEF CON 是一場大型研討會（在資安、駭客圈很有名），會舉辦大型解謎挑戰。這裡要讓你知道題目有多難：開發者和朋友花了好幾天才解開。
  • 01:02 其中一道大題是把一堆魔術方塊排成奇怪的 3×4 陣列，要從中推出一段訊息
    ↳ 其中一道大題，是把一堆魔術方塊排成奇怪的 3×4 陣列，要從中推出一段隱藏訊息。這種題目沒有固定解法，只能一直猜、一直驗證。
  • 01:34 Astra 解這題三次成功三次，但需要先給它出題者提供的官方提示（跟人類參賽者拿到的一樣）
    ↳ Astra 解了三次，三次都成功，可見不是運氣好。前提是要先給它出題方的官方提示，不過人類參賽者拿到的也是同一份提示，所以這是公平的比較。
  • 01:34 解題方式：模型先提出假設，再派另一個 agent 去測試；這些 agent 平行執行，由主 agent 統籌協調
    ↳ agent 是能自己動手執行任務的 AI 助手。它解題的方式就像帶一個團隊：主 agent 先提出猜測，再派好幾個 agent 同時去驗證，最後由主 agent 整合結果、決定下一步。
  • 01:34 開發者發現這個模型更能讓自己維持在正軌上、跳出 doom loop，這是它能持續專注並解出問題的主因
    ↳ doom loop 是指 AI 卡在同一個錯誤裡一直打轉，越做越偏。開發者認為 Astra 比較不會陷進去，也能把自己拉回正軌，這是它能一直專注、最後解出題目的關鍵。
  • 02:04 很多以前的模型解不了、一直累積下來的問題，現在 Astra 能一個一個解決
    ↳ 開發者手上累積了很多以前的模型解不開、只好先放著的問題，現在 Astra 能一題一題解決，代表它能做到的事情確實比以前多了。
📘 術語
voxel（體素）：字幕沒有解釋，只說用它做出歷史倫敦的 3D 呈現
prompt（提示詞）：字幕沒有定義，只提到多給幾個 prompt 就能改視角，模型也會替照片寫生成用的 prompt
agent（代理）：模型提出假設後，派另一個 agent 去測試；多個 agent 平行執行
main agent / orchestrating（主 agent／統籌協調）：主 agent 負責統籌協調多個平行執行的 agent
doom loop（死循環）：字幕沒有定義，只說 Astra 比較能跳出 doom loop，所以能持續專注在任務上
DEF CON（DEF CON 大會）：字幕說它是一場大型研討會，有大型解謎挑戰
