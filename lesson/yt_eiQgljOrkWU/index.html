🧑‍🏫 這支是 OpenAI 介紹 Codex 最新改版的影片。Codex 是 OpenAI 幫人寫程式、改程式的 AI 助手，這次它被併進 ChatGPT，還多了更強的模型、一鍵發布網站、手機管理任務等功能。就算你不是工程師，也能從這支看出：用講的做出一個能上線的小工具，已經比以前容易很多。

  • 00:00 Codex 與 ChatGPT 合併成同一個 app；對開發者來說仍是同一個 Codex
    ↳ 以前 Codex 和 ChatGPT 是兩個分開的 app，現在合成一個。已經在用的開發者不用重學，功能和操作還是原本的 Codex，只是入口搬進了 ChatGPT。
  • 00:31 Codex 在 ChatGPT 裡有自己的專屬空間，位在新的 work agent 旁邊
    ↳ 打開 ChatGPT，Codex 有自己的專屬區塊，旁邊是新的 work agent（另一個幫你做事的 AI 助手）。寫程式的事到 Codex 那格處理，不會和一般聊天混在一起。
  • 00:31 每週都在推出改進，過去兩個月已有超過 150 項更新
    ↳ 兩個月超過 150 項更新，平均一週十幾項。意思是這個工具變化很快，上個月做不到的事，現在可能已經做得到了。
  • 00:31 GPT-5.6 Sol 是新的 frontier model，所有人都能用，能長時間處理困難問題
    ↳ frontier model 指目前能力最頂尖、走在最前面的模型。GPT-5.6 Sol 是最新這一款，所有人都能用，特點是能長時間專心處理難題，不會做一下就放棄。
  • 00:31 GPT-5.6 可搭配新的 Ultra 模式；再結合 Goal 指令，可以交付一直拖著沒做的高難度專案
    ↳ Ultra 是讓模型更用力思考的模式，Goal 指令用來設定要達成的目標。兩個搭配起來，適合拿來處理那種一直嫌太難、拖著沒碰的大案子。
  • 01:02 Ultra 讓 Sol 有更大的 reasoning budget，但也會更快用掉你的 token 額度
    ↳ reasoning budget 是模型回答前能花多少力氣思考；token 是 AI 計算用量的單位，你的方案有使用額度。Ultra 想得更深，額度也燒得更快，簡單的事不必開。
  • 01:02 Codex 會自動把工作拆給多個 subagent，不需要你開口；可以個別追蹤，也可以開面板看整個團隊平行運作
    ↳ subagent 是分出來的小幫手。工作量大時，Codex 會自己拆成幾份，分給多個 subagent 同時做，像組長分工。你可以點進去看單一個的進度，也能開面板一次看全部。
  • 01:02 Sol 在電腦操作與瀏覽器操作上表現出色，搭配 GPT-5.6 速度快很多
    ↳ 電腦操作、瀏覽器操作，指 AI 自己動滑鼠、點按鈕、開網頁。Sol 在這方面很強，搭配 GPT-5.6，做這些動作的速度快很多。
  • 01:32 在 Mac 按 Cmd-Cmd 可以對 Simulator 拍 appshot，再請 Codex 瀏覽每個畫面，擷取英文與法文的 App Store 截圖
    ↳ Simulator 是在 Mac 上模擬 iPhone 的程式，開發 app 時拿來測試。按兩下 Cmd 拍一張 appshot，再請 Codex 逐頁瀏覽，自動截好上架 App Store 要用的英文版和法文版畫面。
  • 01:32 appshot 可以想成更聰明的截圖：Codex 同時拿到畫面與 app 的 context，因此能自己操作 Simulator
    ↳ context 指 AI 做事需要的背景資訊。一般截圖只是一張圖；appshot 還附上 app 本身的資訊，Codex 知道畫面上每個東西是什麼，所以能自己在 Simulator 裡點來點去。
  • 02:02 Codex 會在背景自己點擊操作，你可以同時繼續使用電腦
    ↳ Codex 點擊操作是在背景進行，不會搶走你的滑鼠和螢幕。它在跑的時候，你照樣可以回信、查資料、做別的事。
  • 02:02 範例是用 GPT-5.6 做的紙飛機遊戲：可在 in-app browser 直接開啟、試玩，查看 Codex 做了什麼
    ↳ in-app browser 是內建在 Codex 裡的瀏覽器。示範中 Codex 做了一個紙飛機小遊戲，不用另外開瀏覽器，直接在裡面打開就能玩，也能對照看 Codex 做了哪些事。
  • 02:02 在瀏覽器裡用點選的方式標註想修改的部分，Codex 會取得這些視覺 context 來改
    ↳ 想改哪裡，不用打字描述「左上角那個按鈕」，直接在畫面上點選標出來。Codex 會拿到你指的是哪個地方，改起來更準。
  • 02:32 瀏覽器新增許多功能，現在也能處理需要登入的應用程式，並支援 passkeys
    ↳ passkeys 是用指紋、臉部辨識等方式取代密碼的登入方法。內建瀏覽器現在能進入需要登入的應用程式，能測試的範圍不再只有公開頁面。
  • 02:32 diff view 現在可以直接 inline 精準編輯程式碼；若只知道想要的行為，也可以請 Codex 從那裡接手
    ↳ diff view 是標出程式改動前後差異的畫面。現在可以直接在上面動手改（inline 就是就地修改）；如果你只知道想要什麼效果，說出來讓 Codex 接手就好。
  • 03:03 可以視覺化操作，也可以直接改程式碼，感覺更接近真的在和模型結對寫程式
    ↳ 結對寫程式是兩個人一起寫同一份程式。現在你可以在畫面上點選，也可以直接改程式碼，和 Codex 來回配合，感覺更像旁邊坐著一個夥伴。
  • 03:03 Sites 上個月先推出 Enterprise 版，讓團隊在內部分享應用程式；現在開放給所有人，適用任何用 Codex 做的網頁應用程式
    ↳ Sites 是把 Codex 做好的網頁放上網讓別人使用的服務。上個月先開放給企業版，讓公司在內部分享；現在所有人都能用，只要是 Codex 做的網頁 app 都能發布。
  • 03:03 只要說「publish this to Sites」就能發布
    ↳ 發布不用自己研究怎麼上線，對 Codex 說一句 publish this to Sites（把這個發布到 Sites）就可以了。
  • 03:34 Sites 內建 hosting、authentication、persistent database 和檔案儲存，讓你從點子做到 full-stack 應用程式，不必操心基礎設施
    ↳ hosting 是放網站的主機，authentication 是登入驗證，persistent database 是關掉也不會消失的資料庫。full-stack 指畫面和後台資料都齊全的完整 app，這些 Sites 都內建好了。
  • 03:34 Codex 也能幫你管理它自己的 Codex 任務，適合同時推進好幾件獨立工作
    ↳ Codex 不只能接任務，還能當管理者，幫你開、分派、追蹤其他 Codex 任務。手上有好幾件互不相干的事要同時推進時特別好用。
  • 04:05 範例：從 Linear 找 5 個 bug，各自建立獨立任務與隔離的 worktree，並釘選最關鍵的；可在協調 thread 看到全部進度
    ↳ Linear 是團隊追蹤工作和 bug 的工具；worktree 讓每個任務有各自隔離的工作區，互不干擾。示範中 5 個 bug 各開一個任務，最急的釘選起來，再從一個總控對話看全部進度。
  • 04:05 這些任務之間可以互相引用
    ↳ 任務之間可以互相引用，一個任務的內容能拿到另一個任務裡用，不必每個都從頭交代。
  • 04:36 在 ChatGPT 或 deep research 裡探索過的對話，可以用 @mention 把完整 context 帶進 Codex，不用再複製貼上
    ↳ deep research 是 ChatGPT 深入查資料的功能。先在 ChatGPT 把想法聊清楚，再到 Codex 用 @ 標記那段對話，整段來龍去脈會直接帶過去，不用複製貼上。
  • 04:36 行動版 ChatGPT 大升級（一）：可以在手機的對話裡建立、搜尋、開啟、管理任務
    ↳ 手機版 ChatGPT 現在可以直接在對話裡開新任務、搜尋、打開、管理 Codex 任務，人不在電腦前也能交代工作、看進度。
  • 05:07 行動版（二）：檢視變更時可篩選 staged、unstaged、branch，或比較不同 branch
    ↳ branch 是程式的分支版本。staged 是已經挑好、準備存下的改動，unstaged 是還沒挑的。手機上可以按這些分類看改動，也能比較兩個分支差在哪。
  • 05:07 行動版（三）：可以直接連到 SSH host（例如 dev box），從手機開新任務
    ↳ SSH host 是可以遠端連進去操作的電腦，dev box 是專門拿來開發的遠端機器。手機可以直接連上去，在那台機器上開新任務。
  • 05:38 Codex 知道每個任務在哪個 branch 上；該 branch 有開啟的 PR 時，summary pane 會自動顯示，可追蹤、處理問題並 merge
    ↳ PR（pull request）是「請把我的改動併進主程式」的申請，merge 就是正式併進去。Codex 知道任務在哪個分支，有 PR 會自動顯示在摘要欄，可以追蹤、處理並合併。
  • 05:38 如果 check 失敗或有人留 comment，可以直接請 Codex 帶著完整 context 就地修正
    ↳ check 是 PR 送出後自動跑的檢查。檢查沒過或有人留意見時，直接叫 Codex 當場修，它本來就知道前因後果，你不用再解釋一遍。
  • 06:08 新的 Pull Requests 分頁可以瀏覽所有變更、留 inline comments、完成完整 review，也能把自己的 PR 標為 ready 並 merge，不用跑去 GitHub.com
    ↳ GitHub 是最常用的程式碼存放與協作平台。現在 Codex 裡就有 PR 分頁，可以看改動、針對某幾行留言（inline comments）、做完整審查、合併，不必切去 GitHub 網站。
  • 06:08 邀請參加 OpenAI Build Week，可以線上參加，也可以到全球將近 30 場實體活動
    ↳ Build Week 是 OpenAI 辦的動手做活動週。可以線上參加，也能到全球將近 30 場實體活動，想邊學邊做、認識同好的人可以留意。
