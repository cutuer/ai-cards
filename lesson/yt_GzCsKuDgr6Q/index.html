🧑‍🏫 這支影片示範在 ChatGPT Work 裡，從一個商業問題出發，做出一個 dashboard（把關鍵數字和圖表集中在同一頁的儀表板）。過程會用到 data plugin（一般指把資料來源接進來的外掛）和 semantic layer（一般指事先定義好「每個指標怎麼算」的一層規則，讓大家算出來的數字一致）。值得看的地方是：做報表、畫圖、更新資料，都在同一個地方完成。

  • 00:02 示範的需求：用 data plugin 和網站的 semantic layer 建立一個 dashboard，衡量網站的採用率（adoption）與使用程度（usage levels）
    ↳ 需求很明確：看網站的 adoption（採用率，也就是有多少人開始用）和使用程度（用得多頻繁、多深）。資料透過 plugin 接進來，指標照網站原本定義好的算法去算。
  • 00:02 畫面右側顯示建好的 dashboard 樣子
    ↳ 做好的 dashboard 就放在畫面右邊，你可以一邊對話、一邊看成品長什麼樣。
  • 00:02 可以在 dashboard 裡建立許多不同的特殊視覺化圖表
    ↳ 不只一般的長條圖、折線圖，還能做各種比較特殊的圖表，依你想回答的問題挑合適的呈現方式。
  • 00:02 範例之一：可以看到隨時間變化的 funnel
    ↳ 例如 funnel（漏斗圖，看使用者一步步往下走時，每一步還剩多少人），而且能看它隨時間的變化，知道哪一段流失的人變多或變少。
  • 00:02 dashboard 上方有多個分頁（tabs）
    ↳ dashboard 上方有好幾個 tabs（分頁），跟瀏覽器分頁一樣，把不同主題的圖表分開放，不會全擠在同一頁。
  • 00:02 例如 organizations 分頁，可以用客戶區隔（customer segment）的呈現方式看各種指標
    ↳ 例如 organizations（客戶組織）分頁，會按 customer segment（客戶區隔，例如依規模或類型把客戶分群）來看各項指標，方便比較不同群的差異。
  • 00:02 dashboard 上方會顯示資料最後更新的時間，也可以手動再更新一次
    ↳ 上方會標示資料最後更新的時間，讓你知道眼前的數字新不新。想看最新的，也可以手動再更新一次。
  • 00:32 也可以設定 scheduled refresh，定期從任何資料來源抓取資料
    ↳ 也能設定 scheduled refresh（排程更新），讓它定期自動從資料來源抓新資料，不用每次都自己按更新。
📘 術語
dashboard（儀表板）：字幕中用來衡量網站採用率與使用程度的成品，裡面有多種視覺化圖表和分頁
data plugin（資料外掛）：字幕未解釋，只說建立 dashboard 時會用到它
semantic layer（語意層）：字幕未解釋，只說是網站的 semantic layer，建立 dashboard 時會用到
adoption（採用率）：字幕中 dashboard 要衡量的項目之一，與使用程度並列
funnel（漏斗）：字幕中的視覺化範例，可以看到隨時間變化的 funnel
customer segment（客戶區隔）：organizations 分頁中呈現各種指標所用的方式
scheduled refresh（排程更新）：定期從任何資料來源抓取資料的設定
✏️ 小考一題

根據影片，設定 scheduled refresh 可以做到什麼？

A. 自動為 dashboard 新增分頁B. 自動把 dashboard 寄給團隊成員C. 定期從任何資料來源抓取資料D. 定期刪除過期的舊資料
看答案
答案：C。字幕 [00:02]–[00:32] 提到可以設定 scheduled refresh，定期從任何資料來源抓取資料；其他選項字幕都沒有提到
