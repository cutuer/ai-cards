🧑‍🏫 講者把 DEF CON（一場知名的大型駭客資安會議）裡最難的謎題，丟給 OpenAI 新的 Astra 模型試試看。結果它解出兩題，也讓人看到它怎麼指揮一群 AI 分工合作。這支值得看，是因為它示範了想讓 AI 做複雜的事，關鍵在於你怎麼下指示。

  • 00:01 講者曾參加大型會議 DEF CON，會中有高難度謎題，他和朋友花了好幾天解題
    ↳ DEF CON 會場有很燒腦的解謎挑戰。講者以前去參加過，和朋友一起卡了好幾天才解出來，所以他很清楚這些題目有多難。
  • 00:01 講者把該競賽中最難的幾題交給新的 Astra 模型，結果它解出其中兩題，出乎講者意料
    ↳ 他把那場比賽裡最難的幾題交給 Astra 模型，本來沒抱太大期待，結果它真的解出兩題。這些題目連講者和朋友都得花好幾天才能解。
  • 00:01 其中一題是大型謎題：多個 Rubik's cube 以奇特的 3 by 4 方式排列，需從中推導出一段訊息
    ↳ 其中一題規模很大：好幾顆 Rubik&#x27;s cube（就是魔術方塊）排成少見的 3 乘 4 陣列，要從這些方塊裡看出規律，拼出一段藏起來的訊息。
  • 00:01 這題模型嘗試三次、三次都成功解出
    ↳ 這題模型試了三次，三次都解對。這代表它不是碰巧猜中，而是真的有穩定的解題能力。
  • 00:31 模型只需要謎題出題者的一個官方提示，和講者當初解題時拿到的提示相同；拿到後就找到正確解答
    ↳ 它也不是完全靠自己。它需要出題者給的一個官方提示，而且這個提示跟講者當年拿到的一模一樣，等於和人類站在同一個起跑點。拿到提示後，它就找到正解。
  • 00:31 講者認為模型很擅長拆解非常複雜的任務
    ↳ 講者的觀察是：這個模型很會把一個超複雜的大問題，切成一塊一塊的小問題，再逐一處理。
  • 00:31 運作方式：模型先提出一個理論，派另一個 agent 去測試，再觀察結果如何
    ↳ agent 是被派出去獨立做一件事的 AI 小幫手。模型的做法像做實驗：先猜一個可能的答案，派一個 agent 去驗證，再看結果決定下一步。
  • 00:31 模型有 10 個 slot 可以放其他 agent 來完成任務，這些 agent 全部平行運作，lead agent 只負責協調它們的工作
    ↳ 模型有 10 個 slot（空位），可以一次派出 10 個 agent。它們是 parallel，也就是同時各做各的。lead agent 是帶頭的那個，自己不下場，只負責分工和協調。
  • 00:31 若給模型清楚的指示，說明該如何工作與協調行動，它能展現非常出色的成果
    ↳ 前提是你要把話講清楚：該怎麼工作、怎麼分工、怎麼協調。指示給得清楚，這種多個 agent 一起合作的方式就能交出很亮眼的成果。
📘 術語
DEF CON（DEF CON（會議名稱））：一場大型會議，會中有高難度謎題
agent（代理程式）：模型可派出其他 agent 去測試理論、完成任務，最多可放 10 個
lead agent（主導 agent）：負責協調其他平行運作的 agent 的工作
parallel（平行運作）：多個 agent 同時進行各自的任務
