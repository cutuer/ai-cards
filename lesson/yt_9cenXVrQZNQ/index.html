🧑‍🏫 這支是雲端檔案服務公司 Box 的人，分享他們測試 GPT-5.5 的心得。重點在金融業常見的「多步驟推理」任務，新模型比上一版明顯進步。如果你好奇新模型在真實工作上到底強在哪，這支給了一個具體的數字和場景。

  • 00:02 講者看到評測結果時不敢相信，認為跟以往相比是很大的躍進
    ↳ 講者說看到測試分數時一度不敢相信。意思是這次不是小幅改善，而是跟以往版本比起來，一口氣往前跳了一大步。
  • 00:02 講者認為 GPT-5.5 對客戶是 game-changer，特別是金融業，因為模型很擅長多步驟推理
    ↳ game-changer 指「會改變做事方式的東西」。multi-step reasoning 是多步驟推理，也就是要一步接一步想、前一步答案會影響下一步。金融工作大多是這種連環計算，所以特別受惠。
  • 00:02 在金融領域一個困難的知識型任務中表現極佳，能根據結構化與非結構化資料做財務模型預測
    ↳ financial model projection 是財務預測，例如推估公司明年營收。結構化資料是像 Excel 表格那樣整齊的數字，非結構化資料是像報告、郵件這種文字。模型能把兩種資料一起讀懂來做預測，這很難。
  • 00:34 這項任務比前一版提升了 19 個百分點
    ↳ 19 個百分點是直接相減的差距。舉例來說，如果答對率從 50% 變成 69%，就是多了 19 個百分點。在同一項困難任務上進步這麼多，幅度算很大。
  • 00:34 講者認為這些改進能減輕知識工作的負擔，讓知識工作者更有效率，產出的品質和準確度都更高
    ↳ 講者的意思是，很多繁瑣的整理、計算、比對可以交給模型處理，人就能省下力氣。而且不只變快，做出來的東西也更準、品質更好。
  • 00:34 講者很期待 GPT-5.5 為 Box Agent 和客戶帶來的改變
    ↳ Box Agent 在影片裡沒有多做解釋，從名字看應該是 Box 自家的 AI 助理功能。講者只是表達很期待新模型接上去之後，能帶給他們的產品和客戶什麼改變。
