🧑‍🏫 Virgin Atlantic（英國的維珍航空）員工現身說法，講他們怎麼用 ChatGPT 把原本要花好幾週的工作縮短到幾小時。這支片不談技術細節，而是讓你看到一般企業團隊實際拿 AI 來做什麼：看懂顧客、整理資料、更快推出新功能。

  • 00:04 一位客服經理表示，ChatGPT 幫助他們找出顧客需求、判斷優先順序，並更快採取行動；在時間和金錢上都更划算，也能更快把產品交給團隊。
    ↳ ChatGPT 讓客服團隊從顧客的反應裡更快看出大家真正要什麼、哪件事最急，然後馬上動手處理。這樣省下時間和成本，也能更早把做好的東西交給團隊使用。
  • 00:04 他們認為很有價值的用例之一：用 Codex ChatGPT 整合不同來源的多個資料集，做出客製化的 dashboard 和報表介面，進而改善旅客的整體顧客體驗。
    ↳ Codex 是 OpenAI 幫忙寫程式的 AI 工具。他們用它把分散在不同地方的資料接在一起，量身做成 dashboard（把數字畫成圖表的看板）和報表，團隊看清狀況後就能改善旅客體驗。
  • 00:37 ChatGPT 讓他們從想法到功能上線的速度快很多，也更快走完產品生命週期，因此能提出並交付對顧客重要的新功能。
    ↳ product lifecycle（產品生命週期）是指一個功能從想點子、開發、上線到之後修改的整段過程。有了 ChatGPT，這段路走得更快，他們就能更早把顧客在意的新功能做出來。
📘 術語
custom dashboards and reporting interfaces（客製化儀表板與報表介面）：用來自不同來源的多個資料集建立，幫助團隊了解狀況並做決策
product lifecycle（產品生命週期）：字幕提到有了 ChatGPT 能更快走完，進而提出並交付新功能
✏️ 小考一題

影片中提到，他們在 Codex ChatGPT 裡覺得很有價值的用例之一是什麼？

A. 自動回覆所有旅客的客服信件B. 用不同來源的多個資料集建立客製化 dashboard 和報表介面C. 即時預測航班延誤D. 自動排定機組人員班表
看答案
答案：B。[00:04] 字幕提到："the ability to create custom dashboards and reporting interfaces using multiple different data sets from different sources"。
