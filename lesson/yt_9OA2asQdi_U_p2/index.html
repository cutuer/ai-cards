🧑‍🏫 這段教你替甜甜圈的糖霜做出往下流的滴落。重點在三個工具：用 Extrude 拉出新形狀，用 Subdivision Surface 讓它變圓滑，再用 Shrinkwrap 自動把它貼回甜甜圈表面。除了操作，作者也講到 modifier 順序為什麼重要，以及怎麼觀察現實、把好看的細節誇張化。

  • 10:30 開啟 proportional editing 時才會出現一串選項，關掉就消失；調整影響範圍大小的快捷鍵是 Page Up／Page Down
    ↳ Proportional editing（比例編輯）是移動一個點時，周圍的點也跟著被帶動的模式。打開它才會出現相關選項，影響範圍用 Page Up／Page Down 放大縮小。
  • 10:30 如果看不到那個圓圈，就持續按 Page Down 或滾動滑鼠滾輪，直到圓圈縮到畫面上看得到的大小
    ↳ 影響範圍會用一個圓圈顯示。畫面上找不到圓圈，通常是它大到超出畫面。一直按 Page Down 或滾滑鼠滾輪把它縮小，直到看得到為止。
  • 11:00 徒手拖曳時，看起來像是往正下方移動，實際上可能有點歪斜，因為是在 3D 空間裡從不同視角觀看
    ↳ 螢幕是平的，物件卻在立體空間裡。從斜角看像是往下拉，實際上可能也往前後偏了一點，只是這個角度看不出來。
  • 11:00 所以移動物件時要先想清楚沿哪個軸移動
    ↳ 所以動手前先決定方向。Axis（軸）就是 X、Y、Z 三個方向。限定只沿某個軸移動，點就不會亂跑。
  • 11:31 要讓點往正下方移動，先按 G 再按 Z，然後往下拉
    ↳ G 是移動，再按 Z 就把移動鎖在上下方向。這時往下拉，點只會垂直往下，不會歪掉。
  • 11:31 在幾個地方各往下拉一點，並可以調整 falloff 的量來試不同效果
    ↳ 不要只拉一處，挑幾個地方各拉一點，糖霜邊緣就有自然起伏。Falloff 是影響力往外遞減的方式，可以換不同設定試看效果。
  • 11:31 重新開啟 Solidify modifier 後厚度就回來了，甜甜圈上的糖霜也有了起伏變化
    ↳ Modifier 是疊在模型上的效果，不會直接改動原本的點。Solidify 負責加厚度。重新打開後，糖霜恢復厚度，邊緣也有了高低變化。
  • 12:05 往下拉時不要拉太多，因為之後要加上滴落（dribble），也就是沿著甜甜圈往下流的小水滴
    ↳ 這一步只是做出微微下垂的底子，別拉過頭。真正往下流的部分，之後會另外用滴落（dribble）來做。
  • 12:05 糖霜會部分穿插進甜甜圈，原因是 proportional editing 連帶把上方的點也拉下來了
    ↳ 有些地方糖霜陷進甜甜圈裡，因為比例編輯的範圍太大，把上面不該動的點也一起往下帶了。
  • 12:39 穿插問題有 Solidify 時還可以接受，之後做滴落時會加另一個 modifier 一併修好
    ↳ 目前有厚度撐著，看起來還過得去，不用急著一個個修。後面做滴落時會加另一個 modifier，順便解決。
  • 12:39 挑一塊往下流的區域做滴落；直接把現有的點往下拉只會形成尖角，效果不好，需要更多 geometry
    ↳ Geometry 指模型的點、線、面。現有的點太少，直接拉只會拉出尖角。要先有更多點和面，才做得出圓潤的滴落形狀。
  • 13:10 Extrude 的快捷鍵是 E；但不能只 extrude 一個點，因為沒有面，只拉一個點出來不會有東西被 render
    ↳ Extrude（擠出）是從原有部分延伸出新的點和面，快捷鍵 E。Render 是算出最終畫面。只有一個點沒有面，最後畫面上什麼都不會出現。
  • 13:10 正確做法是選兩個點，按 E、再按 Z、往下拉後放開，開啟 Solidify 後就能看到多出來的 geometry
    ↳ 選相鄰兩個點再擠出，中間就會連成面。按 E、再按 Z 鎖住上下、往下拉，打開 Solidify 就看得到多出來的一段。
  • 13:40 加上做馬克杯時用過的 Subdivision Surface modifier；作者說這個很常用，大部分物件可能都會加
    ↳ Subdivision Surface（簡稱 Subsurf）modifier 會把模型的面切得更細，之前做馬克杯時用過。作者說它很常用，大部分物件都可能會加。
  • 13:40 Subdivision Surface 除了增加細節，還會把形狀變平滑，讓原本生硬的方塊變成平滑的水滴形
    ↳ 它不只讓面變多，還會把稜角磨圓。原本方方正正的一條，會變成比較像真的水滴。
  • 13:40 但加完後，滴落部分和甜甜圈分開了
    ↳ 問題是加上之後，滴落那段和甜甜圈表面分開了，沒有貼在上面。
  • 14:15 以前的教學教過讓它貼附到甜甜圈上的方法，但太複雜，很多人在這一步把 mesh 弄壞了
    ↳ Mesh 是由點、線、面組成的模型本體。作者舊版教學有另一套貼合做法，但步驟太複雜，很多人在這裡把模型弄壞。
  • 14:15 也可以手動一塊一塊拉回去，但沒必要，因為有 modifier 能自動處理
    ↳ 也可以手動把點一個個拉回表面，但很費工，而且有 modifier 能自動做到。
  • 14:15 到 Add Modifier → Deform，找名為 Shrinkwrap 的 modifier
    ↳ Deform（變形）是 Add Modifier 選單裡的一類，放的都是會改變形狀的 modifier，Shrinkwrap 就在這裡。
  • 15:00 如果找不到，可以在上方直接輸入 Shrinkwrap 搜尋
    ↳ 選單裡找不到也沒關係，在上方搜尋欄直接輸入 Shrinkwrap 就行。
  • 15:00 Shrinkwrap 會把物件收縮貼附到某個 mesh 上，但必須先指定目標 mesh，否則完全沒有作用，紅色就是在提示它沒運作
    ↳ Shrinkwrap 會把物件包緊、貼到另一個模型表面上。但要先指定貼到誰（target），沒指定就完全不作用，顯示紅色就是在提醒這點。
  • 15:00 Target 可以從下拉選單選，多數人會點小滴管（eye dropper）再點選物件
    ↳ Target 可以從下拉選單挑。比較快的做法是點小滴管（eye dropper），再直接點畫面上的甜甜圈。
  • 15:00 指定後出現嚴重的 z fighting，也就是面互相重疊，這種情況絕對要避免
    ↳ 指定完後畫面出現破碎錯亂的樣子，這叫 z fighting：兩個面疊在同一個位置，互相搶著顯示。一定要避免。
  • 15:35 Modifier 是由上往下執行；目前順序是先加厚度、再加細節，最後才把整個厚度 shrinkwrap 到甜甜圈上
    ↳ Modifier 會由上往下依序套用，這一串叫 modifier stack。目前是先加厚、再細分，最後才貼合，結果整個厚度都被壓到表面上。
  • 15:35 要調整順序：把 Shrinkwrap 一路移到最上面，移到一半也沒有用
    ↳ 要把 Shrinkwrap 一路拖到最上面。只往上移一半沒有用，因為前面還有其他效果先執行。
  • 16:05 正確順序：先 Shrinkwrap 貼附到 mesh，接著 Solidify，最下面是 Subsurf
    ↳ 正確順序是：先貼到甜甜圈表面，再加厚度，最後細分變平滑。這樣厚度才會長在已經貼好的表面上。
  • 16:05 Subsurf 的 viewport 可以提高到 level 2，多一點細節；再往上加最後會讓電腦變很慢，也沒什麼意義，目前用 level 2 就好
    ↳ Viewport 是你工作時看到的預覽畫面。Subsurf 的預覽調到 level 2 就夠了，再高電腦會變很卡，看起來也差不多。
  • 16:36 Shrinkwrap 的原理：懸空的部分會尋找下方 mesh 上最近的點，然後貼附到那個點
    ↳ 原理很單純：懸空的點會往下找甜甜圈表面上最近的位置，然後貼過去。
  • 16:36 可以拉得滿遠，但有極限；拉太遠就會找不到 mesh，所以超過某個程度時要自己把東西往 mesh 靠。它不是魔法
    ↳ 離表面有點距離還找得到，但太遠就找不到了。拉得太開時，要自己先把它往甜甜圈挪近一點。
  • 17:13 Shrinkwrap 讓工作輕鬆很多：拉出大的滴落時不用太在意位置，會自動貼附到甜甜圈，只要確保滴落是直的
    ↳ 有它在，拉大滴落時不必擔心有沒有貼在表面上，它會自動貼好。你只要顧好滴落是直直往下的。
  • 17:13 作者建議要看參考資料，並說會把參考放在下方連結的網站上
    ↳ 作者建議動手前先看真實照片當參考（reference），並說會把參考放在影片下方連結的網站上。
  • 17:50 水滴形成時，重力會在一點累積，上方被往下吸，因此中間較細、底部是一團圓球（globule）
    ↳ 真實水滴受重力影響，液體往一處聚集，上方被往下拉細，所以中間細、底部鼓成一團圓球（globule）。
  • 17:50 實作上就是讓底部那段比上方稍微粗一點
    ↳ 實際做法很簡單：把滴落最下面那段做得比上面稍微粗一點。
  • 17:50 一個滴落不夠，要繞一圈加更多，重複同樣步驟：在小點上 extrude 再往下拉
    ↳ 一條不夠，要繞著甜甜圈多做幾條。步驟都一樣：在邊緣的點上擠出，再往下拉。
  • 18:30 作者第一個甜甜圈只做了一條滴落，總想把攝影機對準它，因為那是最有趣的部分；後來學到要誇張化，到處都加滴落
    ↳ 作者第一個甜甜圈只有一條滴落，拍照時總想對準它，因為那是最有趣的地方。後來他學到要誇張化，乾脆到處都加。
  • 18:30 當藝術家很重要的一點：觀察現實，找出真正討喜的部分，然後把它誇張化
    ↳ 他認為當藝術家的關鍵是：先觀察現實，找出真正討喜的細節，再刻意把它放大。
  • 19:05 甜甜圈通常不會有這麼多滴落，但這樣很好看，看起來黏稠、糖霜很多
    ↳ 真的甜甜圈很少滴成這樣，但滴落多一點，看起來更黏稠、糖霜更足，反而更好看。
  • 19:05 不要每處都做同樣形狀，例如做半截的滴落，並找地方加入不同形狀
    ↳ 別讓每條都長一樣。有的只流一半，有的換個形狀，看起來才自然，不像複製貼上。
  • 19:05 作者錄影時做了還原（revert），結果留下一個不該存在的大面
    ↳ 作者錄影時做了還原（revert，退回先前的狀態），結果模型上留下一個不該存在的大面。
  • 19:44 作者用 knife tool 修正：在 mesh 上切割，徒手加入更多 geometry；觀眾照做應該不會遇到這個問題
    ↳ 他用 knife tool（刀具）在模型上切出新的線，手動補上點和面來修好。照著步驟做的人應該不會遇到這個問題。
  • 19:44 繼續加滴落：開 proportional editing 往下拉；選兩個點、關掉 proportional 再加一段；加入一些變化，再做一個大的
    ↳ 接著繼續加：有時開比例編輯往下拉，有時選兩點、關掉比例編輯再接一段。做出一些變化後，再做一條大的。
  • 20:16 麻煩的地方是要從側面看位置再把它拉直，但用眼睛去塑形、隨意調整是 3D 好玩的地方
    ↳ 麻煩的是要轉到側面檢查位置，再把滴落拉直。但憑眼睛慢慢調整形狀，正是 3D 好玩的地方。
  • 20:16 很多人投入 3D 是因為想創作藝術，但拿起鉛筆總畫不出想要的線條
    ↳ 很多人想創作藝術，但拿起筆總畫不出心裡想要的線條，於是轉向 3D。
  • 20:46 3D 的好處是由點構成，事後還能移動這些點；不是徒手畫，所以不會有畫壞一條線的情況
    ↳ 3D 模型由點組成，事後隨時能回頭移動修改，不像在紙上一筆畫歪就沒救了。
📘 術語
Proportional Editing（比例編輯）：開啟後會出現額外選項，移動一個點時也會帶動周圍的點；範圍用 Page Up／Page Down 調整
Falloff（衰減）：字幕只說可以調整它的量來試效果，未進一步解釋
Axis（軸向）：移動物件時要想清楚沿哪個軸移動，例如 G 再按 Z 就是往正下方
Solidify modifier（實體化修改器）：開啟後讓糖霜恢復厚度（add thickness）
Geometry（幾何結構）：要拉出好看的滴落需要更多 geometry，只拉現有的點只會形成尖角
Extrude（擠出）：快捷鍵 E；只擠出一個點沒有面、不會被 render，要選兩個點
Face（面）：只有一個點時沒有面，就沒有東西會被 render
Render（算圖／渲染）：字幕提到只拉一個點時沒有東西會被 render
Subdivision Surface modifier (Subsurf)（細分曲面修改器）：非常常用，除了增加細節也會把形狀變平滑，方塊會變成水滴形
Deform（變形（修改器分類））：Add Modifier 選單裡的分類，Shrinkwrap 就在這裡
Shrinkwrap（收縮包裹修改器）：把物件收縮貼附到指定 mesh，會找下方最近的點貼上；拉太遠會找不到
Target（目標）：Shrinkwrap 要貼附的 mesh，必須指定，否則沒有作用（顯示紅色）
Eye dropper（滴管工具）：點小滴管後再點選物件，就能指定 target
Z fighting（Z 衝突／面重疊閃爍）：面互相重疊的情況，很糟糕，絕對要避免
Modifier stack（修改器堆疊）：modifier 由上往下執行，順序會影響結果
Viewport（視窗預覽）：Subsurf 可以設定 viewport 的 level，例如 level 2
Dribble（滴落（糖霜流下））：沿甜甜圈往下流的小水滴
Globule（小圓球）：水滴底部那團，作者說其實就是底部那段
Reference（參考資料）：作者說應該要看參考，並會放在網站連結上
Revert（還原）：作者錄影時還原後，留下了一個不該存在的大面
Knife tool（刀具工具）：在 mesh 上切割，徒手加入更多 geometry 的方法
✏️ 小考一題

加上 Shrinkwrap 後出現 z fighting，作者說應該怎麼調整 modifier 的順序？

A. 把 Shrinkwrap 留在最下面，只把 Subsurf 移到最上面B. 刪掉 Solidify modifier，只保留 Shrinkwrap 和 SubsurfC. 把 Shrinkwrap 一路移到最上面，讓它最先執行D. 把 Shrinkwrap 移到 Solidify 和 Subsurf 中間
看答案
答案：C。[15:35] modifier 由上往下執行，要把 Shrinkwrap 移到最上面，移到一半沒有用；[16:05] 順序是 Shrinkwrap → Solidify → Subsurf
