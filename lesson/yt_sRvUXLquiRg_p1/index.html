🧑‍🏫 這是 Claude 官方影片的第一段。講者介紹 Claude Code（Anthropic 給開發者用的 AI 寫程式工具）最近的三個新功能：從手機接手電腦上的工作、不再閃爍的全螢幕畫面，還有改版後的桌面 app。如果你常用 Claude Code，這三個都會直接影響你每天用起來順不順。

  • 00:17 講者 Ralph 是 Anthropic 的 technical staff，負責和歐洲各地的合作夥伴及客戶合作，協助他們用 Claude 開發
    ↳ 講者 Ralph 在 Anthropic（開發 Claude 的公司）擔任技術人員，平常和歐洲的合作夥伴及客戶合作，協助他們用 Claude 開發產品。
  • 00:17 過去幾個月團隊在 changelog 發布了非常多功能，這場只挑其中一部分介紹
    ↳ changelog 就是官方的「更新紀錄清單」。最近新功能多到清單看起來像在滑動態牆，一場講不完，所以只挑一部分介紹。
  • 00:48 第一大類是開發者體驗（developer experience），目標是讓每天使用這個工具的人用起來更愉快、更方便
    ↳ 第一類叫 developer experience（開發者體驗），講的是天天使用的人順不順手。這類功能在處理日常用起來卡卡、麻煩的小地方。
  • 01:19 第二大類是自主性（autonomy），讓 Claude 在不需要打擾你的時候就自己把工作做完
    ↳ 第二類叫 autonomy（自主性），意思是不需要你出手的事，Claude 就自己做完，不一直停下來問你，你也少被打斷。
  • 01:19 最後會告訴大家去哪裡找更多資訊，跟上最新功能
    ↳ 新功能更新得很快，一場講不完。講者最後會告訴大家去哪裡追最新消息，之後自己也跟得上。
  • 01:51 第一個功能是 remote control。現場舉手調查，用過的人只佔很小一部分
    ↳ 第一個介紹的是 remote control（遠端操控）。講者現場請用過的人舉手，只有少數人舉手，代表很多人還不知道這個功能。
  • 02:22 remote control：在電腦上開一個 session，然後可以在手機的 Claude app 或其他裝置的瀏覽器上接著做
    ↳ session 是你和 Claude 的一段工作對話。remote control 讓你在電腦上開始的對話，可以換到手機 app 或別台裝置的瀏覽器接著做，不用重來。
  • 02:22 使用情境：把任務丟出去後去辦事、遛狗，Claude 需要你輸入時，app 會跳通知給你
    ↳ 你不用一直守在電腦前：任務交代完就可以去辦事、遛狗。等 Claude 需要你回覆時，手機 app 會跳通知提醒你。
  • 02:54 remote control 設定起來很簡單，講者接著現場示範
    ↳ 這個功能不需要複雜的設定，講者接著就在現場示範。
  • 03:28 示範：輸入 remote control 指令後按 Enter，session 就同時在網頁和手機上啟用。示範的 prompt 是「給我十個關於倫敦天氣的笑話」
    ↳ 在 Claude Code 輸入 remote control 指令、按 Enter，同一段對話就同時能在網頁和手機上使用。示範時請它講十個關於倫敦天氣的笑話。
  • 04:02 可以幫 session 改名。沒有給參數的話，Claude 會依照 session 內容自動取名，例如「London rain joke」，在手機上就看得出這個 session 在做什麼
    ↳ 對話可以改名。沒有指定名字的話，Claude 會看內容自動取名，例如「London rain joke」。對話一多，在手機上就看得出每段在做什麼。
  • 04:02 可以在手機上的 session 和電腦上的 session 之間來回對話，例如再要十個關於 tube 的笑話
    ↳ 手機和電腦上是同一段對話，兩邊都能輸入。例如在手機上接著要十個 tube（倫敦地鐵）的笑話，對話會接續下去。
  • 04:36 電腦上的所有工具和開發環境，都能從 Web UI 和 Claude 手機 app 存取
    ↳ Web UI 就是網頁版的操作畫面。你雖然用手機或網頁操作，實際做事的還是你的電腦，所以電腦上的工具和開發環境都照樣能用。
  • 04:36 Pro tip：在設定 JSON 檔（字幕中為 cloudsettings.json）把 remote control 設為一直開啟，每個 session 就都能遠端存取
    ↳ Pro tip 就是進階小技巧。在設定檔（JSON 格式的文字設定檔）裡把 remote control 設成一直開啟，之後每個對話都能從手機接手。
  • 05:09 第二個功能是無閃爍（flickering free）體驗，很多觀眾早就在等
    ↳ 第二個功能是解決畫面閃爍（flickering）的問題，很多觀眾早就在等這個修正。
  • 05:09 閃爍的原因：舊的做法是把新資料 append 到終端機上，scrollback 很長時很難做對，可能整個終端機重新繪製，畫面就會閃爍
    ↳ append 是把新內容接在最後面；scrollback 是終端機往上捲能看到的舊內容。舊內容太長時，每加一段可能要整個畫面重畫，畫面就會閃。
  • 05:39 Claude Code 新增全螢幕模式，把整個終端機的 scrollback 虛擬化。Claude Code 不只是跑在終端機裡，它本身就是終端機
    ↳ 新增的全螢幕模式把 scrollback 虛擬化（virtualize）。講者的意思是，畫面不再交給終端機處理，而是由 Claude Code 自己管，等於它本身就是終端機。
  • 05:39 只渲染你實際看得到的那部分畫面
    ↳ 虛擬化的做法是：只畫出你眼前看得到的那一段，捲到哪裡才畫到哪裡。
  • 06:11 所以即使是非常長的 session，記憶體用量也能維持得很平穩
    ↳ 所以就算對話拉得非常長，記憶體用量也能維持平穩，不會越用越吃資源。
  • 06:11 虛擬化之後還能在終端機裡做可點擊的元素，例如展開文字、各種按鈕
    ↳ 畫面改由 Claude Code 自己管之後，原本只能打字的終端機裡，也能放可以點擊的東西，例如展開全文和各種按鈕。
  • 06:44 開啟方式：輸入 slash command /tui（Terminal User Interface）加上參數 fullscreen，Claude 會重新載入並進入無閃爍的渲染模式
    ↳ slash command 是 Claude Code 裡以 / 開頭的指令。輸入 /tui fullscreen（TUI 指終端機裡的文字操作介面），會重新載入並切換到不閃的全螢幕模式。
  • 07:14 示範：請 Claude 寫一個有十個歐洲小知識的檔案、另一個有十個英國小知識的檔案。以往只會顯示檔案的幾行內容
    ↳ 示範時請 Claude 寫兩個檔案：一個是十個歐洲小知識，一個是十個英國小知識。以前畫面上只會顯示檔案的幾行內容。
  • 07:44 全螢幕模式下可以直接點擊展開，看到完整的十個小知識
    ↳ 在全螢幕模式下，直接點一下就能展開，十個小知識全部顯示在畫面上。
  • 08:14 底部有跳到對話最下方的選項。有新訊息時會提示你，點一下就能直接跳到底部
    ↳ 畫面底部有跳到對話最下方的選項。有新訊息時會提醒你，點一下就能直接跳到底部，不用自己一路捲。
  • 08:14 全螢幕 UI 也可以設為預設，每個新 session 都會用它；團隊內部大多也是這樣用
    ↳ 全螢幕畫面可以設成預設，之後每個新對話都會自動使用。講者說團隊內部大多也是這樣設定。
  • 08:46 第三個是 Claude Code Desktop 的 UI 全面改版。講者承認很多人（包括他自己）比較喜歡 CLI，但還是邀請大家回來再看一次
    ↳ 第三個是 Claude Code Desktop（桌面版 app）全面改版。CLI 是在終端機打指令操作的方式；講者承認很多人包括他自己比較喜歡 CLI，但還是邀請大家再回來看看。
  • 09:16 觀察到有些使用者在特定任務上偏好 Desktop app。不是要你整天都用它，但某些情況下 Desktop 的體驗好得多
    ↳ 講者不是要你整天都用桌面版，而是團隊觀察到，有些使用者在特定工作上偏好桌面版，因為那些情況下用起來好得多。
  • 09:49 Desktop 左側列出所有 session，可以分類分組。講者喜歡依專案分組，也就是依照 GitHub repo 或你在做的 repo 來分
    ↳ 桌面版左側列出所有對話，可以分類分組。講者喜歡依專案分組，也就是依 repo 來分；repo 是存放一個專案所有檔案的地方，GitHub 是常用的存放網站。
  • 10:19 依專案分組後，同時開很多 session 平行工作的人，可以清楚看出每個 session 屬於哪個專案
    ↳ 依專案分組之後，同時開很多對話平行工作時，就能清楚看出每個對話屬於哪個專案。
  • 10:19 在某個 session 的上方，可以查看當初啟動這段對話的 plan
    ↳ 在某段對話的上方，可以看到當初啟動這段對話的 plan（計畫），方便回顧這段工作原本打算怎麼做。
📘 術語
changelog（更新紀錄）：記錄發布了哪些功能的清單；講者說功能多到它看起來像動態消息
remote control（遠端控制）：在電腦上開 session，再從手機 app 或其他裝置的瀏覽器接著操作
session（工作階段）：你和 Claude 的一段工作對話；可以改名，沒給參數時 Claude 會自動取名
flickering（畫面閃爍）：新內容 append 到終端機時整個畫面重新繪製，就會造成閃爍
scrollback（終端機捲動歷史）：終端機往上可以捲回去看的內容；太長時 append 新資料容易出問題
virtualize（虛擬化）：只渲染你實際看得到的那部分畫面，讓記憶體用量保持平穩
TUI (Terminal User Interface)（終端機使用者介面）：/tui 指令的全名，加上 fullscreen 參數就會進入全螢幕模式
slash command（斜線指令）：在 Claude Code 裡以 / 開頭的指令，例如 /tui
CLI（命令列介面）：講者說很多人做大部分事情時比較喜歡用 CLI，而不是 Desktop
Claude Code Desktop（Claude Code 桌面版）：UI 全面改版的桌面 app，可以依專案（repo）把 session 分組
✏️ 小考一題

要在 Claude Code 開啟無閃爍的全螢幕模式，講者示範的做法是？

A. 輸入 /remote-control 並加上參數 fullscreenB. 輸入 /tui 並加上參數 fullscreenC. 輸入 /fullscreen 後重新啟動終端機D. 在 Claude Code Desktop 左側選單切換成全螢幕

答案：B。[06:44] 講者說可以用 slash command /tui（Terminal User Interface），加上參數 fullscreen，Claude 就會重新載入並進入無閃爍的渲染模式。
